Kısayollar tek bir `const` kayıt defterinden gelir: `lib/core/constants/keybindings.dart` içindeki `KeybindingRegistry`. Bu kayıt defteri **48 bağlama** barındırır. Ayarlar → Siz → Kısayollar, bu kayıt defterini **salt okunur bir referans** olarak gösterir: yeniden atama arayüzü yoktur ve kullanıcı kısayol dosyası bulunmaz.

Aşağıdaki `Cmd`, birincil komut değiştiricisidir — macOS’ta ⌘, Windows ve Linux’ta Ctrl. Bir bağlama ancak komutunun geçerli ekranda kayıtlı bir işleyicisi varsa ve `when` koşulu sağlanıyorsa devreye girer; `!textInputFocus`, tuşun bunun yerine odaklanmış bir metin alanına aktarıldığı anlamına gelir.

Rakam tuşlarıyla gezinme kısayolu yoktur. Gelen kutusu, biletler, pull request’ler ve diğerlerine kenar çubuğundan ya da ⌘K ile ulaşılır. Gözlemlenebilirliğin de kısayolu yoktur.

## Genel (19)

Kapsam `global` olduğundan, kabuk içinde her yerde geçerlidirler.

### Sistem

| Kısayol                                     | Eylem                                              | Koşul                                                          |
| ------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Komut paleti                                       | —                                                              |
| `Shift + /` (`?`)                           | Klavye kısayolları listesi                         | Bir alana yazı yazmıyor olmak                                  |
| `Cmd/Ctrl + Z`                              | Geri al                                            | Bir alana yazı yazmıyor olmak (odaklanmış alan kendi geri almasını korur) |
| `Cmd/Ctrl + Shift + Z`                      | Yinele                                             | Bir alana yazı yazmıyor olmak                                  |
| `Cmd/Ctrl + Shift + T`                      | Temayı değiştir                                    | —                                                              |
| `Cmd/Ctrl + ,`                              | Ayarları aç (`/settings/you/appearance` sayfasına düşer) | —                                                              |
| `Cmd/Ctrl + Shift + Alt + F`                | Odak modunu aç/kapat                               | —                                                              |
| `Cmd/Ctrl + Shift + W`                      | Çalışma alanı değiştiriciyi aç/kapat               | —                                                              |
| `Cmd/Ctrl + ]`                              | Sonraki çalışma alanı                              | —                                                              |
| `Cmd/Ctrl + [`                              | Önceki çalışma alanı                               | —                                                              |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | 1–9. çalışma alanına geç                          | —                                                              |

## Pull request listesi (3)

Kapsam `/pull-requests`. Hepsi `route == '/pull-requests'` koşulunu ve odaklanmış bir metin alanı olmamasını gerektirir; bu yüzden PR ayrıntı rotası listenin üzerinde açıkken devreye girmezler.

| Kısayol | Eylem                  |
| -------- | ---------------------- |
| `R`      | Yenile                 |
| `Enter`  | PR aç                  |
| `F`      | Filtre menüsünü aç     |

`Enter` (`pr.list-open`) kayıt defterinde tanımlıdır ve kısayollar referansında görünür, ancak **liste ekranı bunun için bir işleyici kaydetmez**, dolayısıyla şu anda devreye girmez. `F` aramayı değil, filtre menüsünü (`pr.list-open-filter`) açar.

## Pull request ayrıntısı (2)

Kapsam `/pull-requests/`. Yenile, odaklanmış bir metin alanı gerektirmez. Sekme kapatmanın metin girişi koruması yoktur (⌘ ile değiştirilmiş bir tuş vuruşu hiçbir zaman düz metin değildir) ve listede devreye girmemesi için bir rota düzenli ifadesi vardır.

| Kısayol        | Eylem         | Koşul                              |
| -------------- | ------------- | ---------------------------------- |
| `R`            | Yenile        | Bir alana yazı yazmıyor olmak      |
| `Cmd/Ctrl + W` | Sekmeyi kapat | Bir `/pull-requests/<…>` konumunda |

Sekme değiştirme (`1`/`2`/`3`), dosyayı görüldü olarak işaretleme/daraltma (`V`/`C`), dosya listesi (`T`) ve diff içinde arama (`Cmd/Ctrl + F`), diff görüntüleyicinin kendi işleyicisine aittir — bkz. [Kayıt defteri dışındaki diff görüntüleyici tuşları](#kayıt-defteri-dışındaki-diff-görüntüleyici-tuşları).

## GitHub kullanıcı ve ekip profilleri (3)

Kapsam `/users/`. `when` koşulu, `/users/<login>` **veya** `/teams/<organization>/<slug>` ile eşleşen bir düzenli ifadedir; ayrıca odaklanmış bir metin alanı olmamalıdır.

| Kısayol        | Eylem         |
| -------------- | ------------- |
| `R`            | Yenile        |
| `/`            | Aramaya odaklan |
| `Cmd/Ctrl + F` | Aramaya odaklan |

## Alanlar (8)

Kapsam `/spaces`. `when` koşulları bir düzenli ifade kullanır; böylece hem alan listesinde (`/spaces`) hem de seçili bir alanda (`/spaces/<id>`) devreye girerler.

| Kısayol                | Eylem                              | Koşul                  |
| ---------------------- | ---------------------------------- | ---------------------- |
| `Enter`                | Mesaj gönder                       | —                      |
| `Cmd/Ctrl + N`         | Yeni alan                          | Bir `/spaces` rotasında |
| `J`                    | Sonraki alan                       | Bir alana yazı yazmıyor olmak |
| `K`                    | Önceki alan                        | Bir alana yazı yazmıyor olmak |
| `Cmd/Ctrl + Shift + D` | Bas konuş dikte                    | —                      |
| `Cmd/Ctrl + T`         | Düzenleyici sekmesini aç           | Bir `/spaces` rotasında |
| `Cmd/Ctrl + W`         | Düzenleyici sekmesini kapat        | Bir `/spaces` rotasında |
| `Cmd/Ctrl + B`         | Düzenleyici kenar çubuğunu aç/kapat | Bir `/spaces` rotasında |

Enter ile gönderme, composer metin alanına aittir; bas konuş ise composer’ın mikrofon düğmesine aittir (kendi donanım klavyesi işleyicisi). Her ikisi de ayarlar referansı için kayıt defterinde listelenir.

## Kayıt defteri dışındaki diff görüntüleyici tuşları

PR diff görüntüleyici bunları kendisi işler (`PrDiffKeyboardHandler`). Arama/görüldü/daraltma yalnızca ayarlar referansı için kayıt defteri yorumlarında listelenir — hiçbir dağıtıcı işleyici kaydedilmediğinden, dağıtıcı bunları diff görünümüne bırakır. Bunlar, kısayollar referansında kendi satırları olarak görünmez.

| Kısayol         | Eylem                                                 |
| --------------- | ----------------------------------------------------- |
| `Cmd/Ctrl + F`  | Diff içinde ara                                       |
| `J` / `K`       | Sonraki / önceki dosya                                |
| `V`             | Odaklanmış dosyada görüldü durumunu aç/kapat          |
| `C`             | Odaklanmış dosyada daraltmayı aç/kapat                |
| `T`             | Dosya listesini göster                                |
| `Enter`         | Sonraki arama eşleşmesi (yalnızca diff içinde arama açıkken) |
| `Shift + Enter` | Önceki arama eşleşmesi                                |
| `Escape`        | Diff içinde aramayı kapat veya diff metin seçimini temizle |
| `Cmd/Ctrl + C`  | Diff seçimini kopyala                                 |

## Tarayıcıya ayrılmış kombinasyonlar

Web yapımında tarayıcı, bazı hızlandırıcıları sayfa onları görmeden tüketir; bu yüzden eşleşen bağlamalar orada asla devreye giremez. Masaüstünde normal şekilde çalışırlar. Birincil komut değiştiricisiyle birlikte kullanıldığında ayrılanlar: `T`, `W`, `N` ve `1`–`9` rakamları.

Bu, `Cmd/Ctrl + Alt + 1`–`9` çalışma alanı geçişini, `Cmd/Ctrl + N` kombinasyonunu (yeni alan, yeni çalışma alanı, yeni ajan, depo ekle) ve alanlardaki ve PR ayrıntısındaki `Cmd/Ctrl + T` / `Cmd/Ctrl + W` kombinasyonlarını kapsar.
