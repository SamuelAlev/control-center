Bir Linear API anahtarını, tıpkı bir forge bağlarken yaptığınız gibi, sunucuya
kullanıcı kimliğinize bağlı olarak yapıştırın. Biletler, projeler, bağlantılar,
ortak çalışanlar, devretme ve atama, harici bir hizmete gerek kalmadan Control
Center’ın kendi veritabanı üzerinde çalışır — bkz. [Bilet oluşturma ve
yönetme](/tr-TR/kilavuz/nasil-yapilir/biletleri-yonetme/).

## Linear anahtarınızı saklama

**Bilet API anahtarı**, **Ayarlar → Çalışma alanı → Genel** altındaki Biletler
kartında bulunur. Anahtarı sunucuda kullanıcı kimliğinize bağlı olarak saklar.
Sunucunun gözetimsiz işler için kullandığı kendi anahtarı, `LINEAR_API_KEY` ya
da **Sağlayıcı uygulamaları** kartından gelir. Bir ajanın sandbox'ına hiçbir
biletleme anahtarı konmaz: ajanlar biletleri, önce **Harici takip sistemine
yaz** kuralına soran Control Center'ın kendi araçlarıyla yazar.

## Yeni biletleri Linear olarak işaretleme

**Bilet sağlayıcısı** (ilk kurulumun ilk adımı ve
`/workspaces/<workspaceId>/api-keys`) `local` ve `linear` seçeneklerini sunar.
`linear` seçildiğinde, o andan itibaren oluşturduğunuz biletlere
`provider: linear` işaretlenir.
