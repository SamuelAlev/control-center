레퍼런스 페이지는 **무엇이 있는지**를 논평 없이 빠짐없이 설명합니다. 이미 찾는
대상이 무엇인지 알고 있을 때 — 정확한 도구 이름, 단계 종류, 상태 전이, 라우트,
단축키 — 값을 확인하는 데 사용하십시오.

이 글들은 처음부터 끝까지 읽도록 쓰이지 않았습니다. 그런 용도라면
[개념](/ko-KR/매뉴얼/개념/)을, 실제로 무언가를 완수하려면
[사용 가이드](/ko-KR/매뉴얼/사용-가이드/)를 보십시오.
