## 에이전트 엔터티 필드

| 필드                    | 타입                   | 필수 | 설명                                                                                                                                                                                                |
| ----------------------- | ---------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | 예   | 고유한 에이전트 식별자                                                                                                                                                                              |
| `name`                  | `String`               | 예   | @멘션에 쓰이는 짧은 식별자                                                                                                                                                                          |
| `title`                 | `String`               | 예   | 사람이 읽을 수 있는 역할 직함                                                                                                                                                                       |
| `agentMdPath`           | `String`               | 예   | 에이전트의 `.md` 정의 파일에 대한 절대 경로                                                                                                                                                          |
| `workspaceId`           | `String`               | 예   | 소유 워크스페이스(널 불가)                                                                                                                                                                          |
| `reportsTo`             | `String?`              | 아니요 | 상위 에이전트 ID                                                                                                                                                                                   |
| `skills`                | `AgentSkills`          | 예   | 스킬 식별자 집합                                                                                                                                                                                    |

| `adapterId`             | `String?`              | 아니요 | 추론 어댑터 id                                                                                                                                                                                     |
| `modelId`               | `String?`              | 아니요 | 어댑터 내의 모델 id                                                                                                                                                                                |
| `strictMode`            | `bool`                 | 아니요 | 기본값 `false`. 행과 에이전트의 `AGENTS.md`에 기록됩니다                                                                                                                                            |
| `effort`                | `String?`              | 아니요 | 추론 수준 id(예: `'low'`, `'xhigh'`), 선택한 모델의 `thinkingLevels`에서 가져옵니다                                                                                                                |
| `contextSize`           | `int?`                 | 아니요 | 최대 컨텍스트 창 크기                                                                                                                                                                              |
| `role`                  | `AgentRole?`           | 아니요 | 에이전트 역할                                                                                                                                                                                      |
| `monthlyBudgetMicros`    | `int`                  | 아니요 | 월 지출 상한(마이크로달러 단위, 기본값 `0`은 무제한)                                                                                                                                                        |
| `silenceTimeoutMinutes` | `int?`                 | 아니요 | 무응답 감시(silence timeout) 재정의(분 단위)입니다. null이거나 1–240 범위여야 합니다(생성자에서 강제)                                                                                               |
| `maxConcurrentTasks`    | `int`                  | 아니요 | 기본값 `1`. 프레즌스 모델이 보고하는 용량 수치입니다(실행 중 및 대기 중 개수를 이 값과 비교합니다)                                                                                                  |
| `visibility`            | `AgentVisibility`      | 아니요 | 기본값 `workspace`                                                                                                                                                                                 |
| `lifecycleStatus`       | `AgentLifecycleStatus` | 아니요 | 거버넌스 상태(기본값 `active`)입니다. 예산 강제 중지가 기록하며, 조직도와 프레즌스 로스터에 렌더링됩니다. `paused` 에이전트의 작업도 디스패치는 여전히 받습니다                                       |
| `budgetPolicyId`        | `String?`              | 아니요 | 공유 예산 정책 id입니다. null이면 `monthlyBudgetMicros`가 직접 적용됩니다                                                                                                                            |
| `runtimeProfileId`      | `String?`              | 아니요 | 사용자 지정 런타임 프로필 id                                                                                                                                                                       |

`name`과 `title`은 모두 비어 있으면 안 됩니다(생성자에서 강제). `monthlyBudgetMicros`의
기본값 `0`은 무제한을 뜻합니다. 상한은 `agents.upsert`로 기록합니다.

## 권한

에이전트는 권한 플래그를 갖지 않습니다. 푸시, 풀 리퀘스트 열기와 게시, 트래커에 쓰기, 네트워크 이그레스는 작업 클래스(`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`)이며, [가드레일](/ko-KR/매뉴얼/개념/가드레일/)이 워크스페이스, 에이전트, 스페이스 범위에서 해석합니다. 실행의 GitHub 토큰은 항상 읽기 범위이며, 푸시는 에이전트 실행 게이트웨이를 거치고 게이트웨이는 전달하기 전에 `gitPush` 규칙에 묻습니다.

## AgentSkills

스킬 식별자의 불변이며 대소문자를 구분하지 않는 집합입니다. 디스패치 시점에 이 슬러그들이 에이전트 오버레이의 스킬 링크로 동기화되며, 그러면 하네스가 링크된 스킬의 프런트매터를 프롬프트에 자동 로드합니다.

## 셸 훅

셸 훅을 쓰면 서버 소유자가 내장 하네스 실행 주변에서 자체 스크립트를 실행할 수 있습니다. 세션 시작 시 한 번, 각 도구 호출 전, 그리고 각 도구 호출 후입니다. 훅은 임의의 코드이므로 호스트 설정입니다. 서버 소유자만 서버 머신에서 직접 설정하며, 앱에는 이를 설정하는 항목이 없고 이를 쓰는 작업도 없습니다.

에이전트의 훅은 서버 데이터 디렉터리 아래 에이전트 자신의 폴더에 있습니다:

```text
<data dir>/_agent_hooks/<workspace id>/<agent slug>/hooks.json
```

`<agent slug>`는 워크스페이스에서 에이전트 폴더(`agents/<slug>/`)의 이름입니다. 이 폴더는 모든 워크스페이스의 저장소 밖에 있고, 모든 샌드박스는 데이터 디렉터리를 숨기므로, 어떤 구성원, 실행 또는 터미널도 이를 쓸 수 없습니다.

`hooks.json`은 세 키 중 하나를 훅 폴더 기준 상대 경로의 스크립트에 매핑합니다:

| 키             | 실행 시점                 | 종료 코드의 의미                                               |
| -------------- | ------------------------- | -------------------------------------------------------------- |
| `sessionStart` | 실행이 시작될 때 한 번    | 없음. 훅은 관찰만 합니다                                       |
| `preTool`      | 도구 호출 전마다          | `0`이면 호출을 허용하며, 그 밖의 값은 호출을 거부합니다        |
| `postTool`     | 도구 호출 후마다          | 없음. 훅은 관찰만 합니다                                       |

- 각 스크립트는 셸이나 인자 없이 독립 실행 파일로 시작되므로, 실행 권한이 있어야 하며 셔뱅(shebang) 줄로 시작해야 합니다. 이벤트는 stdin으로 JSON을 받습니다. 이벤트 이름과, 도구 훅의 경우 도구 이름 및 인자(`preTool`) 또는 결과(`postTool`)가 담깁니다.
- 훅은 실행의 도구 프로세스 중 하나로, 해당 실행의 에이전트 디렉터리에서 실행됩니다. 서버가 에이전트를 샌드박스로 격리하면 실행의 샌드박스 안에서 돌아갑니다. 최소한의 환경만 받으며 실행의 자격 증명은 하나도 받지 않습니다. forge나 제공업체 토큰도, 게이트웨이 접근도 없습니다.
- 각 훅은 30초를 가집니다. 출력은 읽은 뒤 버려집니다.
- `preTool`은 실패 시 닫힙니다. 0이 아닌 종료 코드, 시간 초과, 시작할 수 없는 스크립트는 도구 호출을 거부합니다.
- 절대 경로이거나, 없거나, 훅 폴더를 벗어나는 경로(링크를 해석한 뒤 기준)는 거부되며, 실행 로그에 어떤 훅이 왜 거부되었는지 나옵니다. 거부되었거나 읽을 수 없는 `preTool` 훅은 고쳐질 때까지 모든 도구 호출을 거부합니다.
- 저장소에 있든 에이전트 자신의 폴더에 있든, `.agents/harness.json`의 `hooks` 블록은 무시됩니다. 저장소는 흔히 다른 사람의 코드이고, 에이전트 폴더는 구성원과 실행이 쓸 수 있기 때문입니다. 실행 로그에는 그 블록이 무시되었다는 것과 훅을 대신 어디서 읽는지가 나옵니다.

셸 훅은 내장 하네스에만 적용됩니다. 설정된 `preTool` 또는 `postTool` 훅이 있으면 실행은 도구를 한 번에 하나씩 호출합니다.

## AgentLiveState(파생)

저장되지 않습니다. 값은 일곱 개입니다. 선언 순서가 우선순위 순서이며(`sortPriority`, 테스트로 고정됨), 로스터가 정렬하는 순서이기도 합니다:

| 상태        | `sortPriority` | 조건                                                                                                     |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | 실행 로그 중 상태가 `running`인 것이 있습니다                                                            |
| `blocked`   | 1              | 최신 실행의 활성 상태가 `blocked`, `stalled`, `looping` 중 하나입니다                                    |
| `failed`    | 2              | 최신 실행의 상태가 `error`이거나, 활성 상태가 `failed` 또는 `dead`입니다                                 |
| `queued`    | 3              | 실행이 디스패치되었지만 실행 중이 아닙니다. 같은 에이전트의 다른 실행 뒤에 대기 중이거나, 기록되었지만 아직 시작되지 않았습니다 |
| `succeeded` | 4              | 실행이 성공적으로 끝났습니다                                                                             |
| `idle`      | 5              | 에이전트가 이전에 실행된 적이 있고 진행 중인 작업이 없습니다                                             |
| `neverRun`  | 6              | 실행 로그가 없습니다                                                                                     |

`queued`와 `succeeded`는 **실행 단위 전용**입니다. 에이전트의 로스터 상태를 계산하는 `deriveAgentLiveState`는 이 둘을 결코 만들어 내지 않습니다. 이 함수는 `neverRun`, `running`, `failed`, `blocked`, `idle` 중 하나를 반환합니다.
