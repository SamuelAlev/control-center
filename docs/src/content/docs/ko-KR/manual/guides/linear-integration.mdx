## Linear 키 저장

**티켓팅 API 키**는 **설정 → 워크스페이스 → 일반**의 티켓팅 카드에 있습니다. 이
키는 내 사용자 id에 연결되어 서버에 저장됩니다. 무인 작업을 위한 서버 자체 키는
`LINEAR_API_KEY` 또는 **프로바이더 앱** 카드에서 옵니다. 에이전트의 샌드박스에는
티켓팅 키가 놓이지 않습니다. 에이전트는 Control Center 자체 도구로 티켓을 쓰며,
그 도구들이 먼저 **외부 트래커에 쓰기** 규칙에 묻습니다.

## 새 티켓을 Linear로 표시

**티켓팅 제공자**(온보딩의 첫 단계 및 `/workspaces/<workspaceId>/api-keys`)는
`local`과 `linear`를 제공합니다. `linear`를 선택하면 이후 생성하는 티켓에
`provider: linear`가 표시됩니다.
