각 가이드는 **이미 제품에 익숙한 사람을 위해 하나의 문제를 해결합니다**. Control Center가
설치되어 있고 워크스페이스가 준비되어 있다고 전제하며, 제목에서 목표를 밝히고 그 목표가
달성되면 끝납니다.

아직 제품을 익히는 중이라면 [튜토리얼](/ko-KR/매뉴얼/튜토리얼/)부터 시작하십시오.
어떤 것이 _왜_ 그렇게 동작하는지 이해하고 싶다면
[개념](/ko-KR/매뉴얼/개념/)을 읽으십시오.
