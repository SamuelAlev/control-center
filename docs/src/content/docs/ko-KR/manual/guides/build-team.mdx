이 가이드에서는 팀을 만들고 리더를 지정하고 팀으로 작업을 라우팅하는 방법을 설명합니다.

팀이란 하나의 워크스페이스 안에 있는 이름 붙은 에이전트 그룹이며, 그중 한 에이전트가 **리더**로 지정됩니다. 티켓을 팀에 할당하면 리더가 깨어나 작업을 분해해 멤버에게 위임하고, 멤버의 실행이 끝나면 리더가 다시 깨어나 다음에 무엇을 할지 결정합니다.

팀의 생성, 이름 변경, 인원 구성은 **설정 → 워크스페이스 → 에이전트 → 팀**에서 합니다. 팀으로 작업을 라우팅하는 방법은 두 가지입니다. 에이전트가 해당 팀의 `team_id`와 함께 `assign_ticket`을 호출하거나, 파이프라인의 **Team dispatch** 노드가 (티켓을 할당하지 않고) 팀을 디스패치합니다. 티켓 담당자 선택기에는 본인과 개별 에이전트가 나열됩니다.

## 팀 만들기

1. **설정 → 워크스페이스 → 에이전트**(`/settings/workspace/agents`)를 엽니다.
2. 페이지 헤더에서 **팀**을 클릭합니다.
3. **팀 추가**를 클릭합니다.
4. **이름**(예: "backend" 또는 "review squad")과 선택 사항인 **설명**을 입력한 다음 **만들기**를 클릭합니다.

팀이 만들어지고 선택되며, 오른쪽 창에 편집기가 열립니다.

## 리더 설정

이 기능 전체가 좌우되는 단계입니다. 팀 편집기에서:

1. **리더** 아래에서 에이전트를 고릅니다. 도움말 텍스트가 이를 그대로 설명합니다. "팀에 할당된 작업을 받아 가장 적합한 멤버에게 위임하는 조정자입니다."
2. 선택 사항으로 **운영 지침**을 채웁니다. 라우팅된 모든 티켓과 함께 리더에게 전달되는 자유 텍스트입니다.

에이전트를 리더로 승격하면 아직 멤버가 아니었더라도 멤버가 됩니다. **리더 없음**으로 남겨 둔 팀은 아무 동작도 하지 않습니다. 작업을 라우팅해도 아무것도 디스패치되지 않고, 멤버 목록에서 현재 리더를 제거하면 팀은 다시 리더 없는 상태가 됩니다.

## 멤버 추가

같은 편집기에서 멤버 카드를 사용해 워크스페이스의 에이전트를 추가하거나 제거합니다. 멤버는 리더가 위임할 대상이 되는 명단입니다.

팀은 워크스페이스 범위입니다. 이 워크스페이스의 에이전트만 참여할 수 있습니다.

## 팀에 스페이스 부여

팀 스페이스는 자동으로 만들어지지 않습니다. 필요하다면 **스페이스**에서 일반 스페이스를 만들고 팀의 에이전트를 추가하세요. `Team`은 이름, 설명, 리더, 지침, 멤버를 가지며 스페이스 연결은 없습니다.

## 보고 체계는 별개입니다

각 에이전트에는 **보고 대상** 필드도 있으며, **설정 → 워크스페이스 → 에이전트**에서 설정합니다. 이 필드가 워크스페이스의 보고 트리를 만들고, 에이전트 페이지의 **조직도** 버튼으로 확인할 수 있습니다.

이것은 팀 라우팅을 좌우하지 않습니다. 리더는 보고 체인이 아니라 팀의 멤버 명단에서 스킬과 역할을 기준으로 위임 대상을 고릅니다. 메모리 접근 권한 부여는 보고 체인이 아니라 에이전트의 역할을 키로 삼으며, 팀이나 계층 구조로 집계하는 분석 화면은 없습니다. 위임 가드는 깊이를 제한하고 순환을 감지하지만, 대상이 하위에 있어야 한다고 요구하지는 않습니다.

## 라우팅된 티켓의 동작

티켓에 팀 할당이 포함된 경우:

1. 티켓, 운영 지침, 멤버 명단과 함께 팀의 리더가 디스패치됩니다.
2. 리더는 멤버에게 위임하고 `record_team_activity` 도구로 자신의 평가를 기록합니다. `action`(위임함), `no_action`(더 할 일이 없으며 이후 재트리거를 중지함), `failed` 중 하나입니다.
3. 완료되는 각 멤버 실행은 리더를 다시 깨우며, no-action 가드로 상한이 정해집니다.

파이프라인의 **Team dispatch** 노드가 다른 진입점입니다. 이 노드는 팀 id, 프롬프트, 디스패치 모드를 받습니다.

- `allParallel` — 멤버마다 하나의 작업을 공유 숨김 대화로 넣고 모든 실행이 완료될 때까지 일시 중단하며, 각 멤버의 출력은 노드의 출력 키 아래에 모입니다
- `manager` — 리더만 디스패치하고, 리더가 대화에서 조정합니다
