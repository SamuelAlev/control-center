이 가이드에서는 대화의 이전 지점으로 돌아가 다른 방향으로 진행하면서, 떠나온 경로를 그대로 유지하는 방법을 설명합니다.

## 꼭 알아야 할 한 가지

**브랜치는 아무것도 기록하지 않습니다.** 대화는 끝에 포인터가 있는 메시지 트리이며, 이전으로 돌아가는 것은 포인터를 옮기는 일입니다. 삭제되는 것도, 숨겨지는 것도 없고, 다시 되돌아가는 것도 포인터를 한 번 더 옮기는 것뿐입니다.

그래서 여기서는 프롬프트를 편집해 다시 실행해도 안전합니다. 비교하던 답변이 그대로 남아 있기 때문입니다.

## 분기 보기

```
/tree
```

탐색기는 모든 메시지를 나열하고 분기마다 들여쓰기하며, 현재 경로를 **이 분기**로 표시합니다. 한 번도 분기한 적 없는 대화는 늘 그랬듯 평평한 목록으로 표시됩니다. 탐색할 대상이 생기기 전까지는 탐색기를 봐도 부담이 없습니다.

각 행에는 두 가지 작업이 있습니다.

| 작업                          | 효과                                                    |
| ------------------------------- | --------------------------------------------------------- |
| **여기서 이어서 진행**          | 포인터를 옮깁니다. 다음 메시지는 그 메시지에서 이어집니다. |
| **새 대화로 포크** | 그 메시지까지의 경로를 새 대화로 복사합니다. |

## 브랜치: 다른 접근 시도

1. `/tree`
2. 다시 시작할 메시지를 찾습니다. 보통은 마지막으로 만족했던 메시지입니다.
3. **여기서 이어서 진행.**
4. 새 프롬프트를 입력합니다.

이전 이어짐은 여전히 트리에 남아 있습니다. 이제 `/tree`는 그 지점에서 두 개의 경로를 보여주며, 둘 사이를 자유롭게 오갈 수 있습니다.

:::note[떠나온 경로는 그대로 남아 있습니다]
브랜치는 아무것도 숨기거나 삭제하지 않습니다. `/tree`는 모든 경로를 나열하고 현재 경로를 **이 분기**로 표시하며, 이것이 전환하는 방법입니다.
:::

## 포크: 다른 곳으로 가져가기

포크는 경로를 같은 스페이스의 **새 대화**로 복사합니다. 두 방향이 계속 갈라질 예정이고, 전환하기보다 나란히 두고 보고 싶을 때 사용합니다.

복사본은 새 메시지 ID를 가집니다. 두 대화가 행을 공유하면 서로의 이후 메시지가 보이게 되는데, 포크는 바로 그것을 막기 위한 기능입니다.

## 되돌리기와 브랜치 비교

둘은 서로 다른 도구이며 그 차이는 중요합니다.

|                     | 되돌리기                                             | 브랜치                          |
| ------------------- | -------------------------------------------------- | ------------------------------- |
| 이후 메시지  | 대화 기록에서 숨겨짐                          | `/tree`에 계속 표시됨         |
| **워크트리**    | 해당 턴의 스냅샷으로 되돌림                 | 그대로 유지                        |
| 실행 취소                | **되돌리기 취소**로 변경 묶음을 복원                  | 포인터를 뒤로 이동            |

에이전트가 바꾼 *파일*을 되돌리고 싶을 때는 되돌리기가 알맞습니다. 대화가 잘못된 방향으로 흘렀지만 파일은 괜찮을 때는 브랜치가 알맞습니다.

되돌리기는 브랜치 끝도 옮기므로, 다음 메시지가 아무도 볼 수 없는 꼬리가 아니라 올바른 지점에서 이어집니다.

## 앱 밖으로 가져가기

### `/export`

**자체 포함형 HTML 파일**을 작성합니다. 대화 전체와, 각 호출에 무엇이 주어졌고 무엇이 반환되었는지 보여주는 접이식 도구 카드가 담깁니다. 스타일시트도, 스크립트도, 이미지 호스트도 필요 없습니다. USB 스틱에서도 열리고 5년 뒤에도 열립니다.

- **데스크톱:** `Documents/ControlCenter/exports/`, 두 번째 내보내기가 첫 번째를 덮어쓰지 않도록 타임스탬프가 붙습니다.
- **웹:** 브라우저 다운로드.

### `/dump`

대화 기록을 markdown으로 클립보드에 복사하며, 도구 호출은 접이식 블록에 들어갑니다. 이슈에 붙여넣을 때 쓰는 것이 바로 이것입니다.

추론은 일부러 제외됩니다. 그것은 모델의 작업 공간이며, 버그 리포트는 사람이 읽기 때문입니다.
