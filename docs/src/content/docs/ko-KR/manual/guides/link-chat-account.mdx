이 가이드에서는 내 채팅 신원을 Control Center 사용자에 연결하는 방법과 연결을 해제하는 방법을 설명합니다.

모든 멤버는 채팅 제공자마다 이 작업을 한 번씩 수행합니다. 이는 앱 연결과는 별개입니다. 연결은 워크스페이스 전체가 봇에 접근할 수 있게 하고, 계정 연결은 그 안에서 _나_를 알아볼 수 있게 합니다.

## 계정 연결이 필요한 이유

브리지는 워크스페이스 멤버로 확인할 수 없는 채팅 계정을 대신해 동작하지 않습니다. 이는 의도된 동작입니다. 연결이 없으면 Slack에서 오는 모든 메시지를 앱을 설치한 사람에게 귀속시켜야 하므로 감사 기록, 주체 단위 속도 제한, 티켓 보고자가 모두 잘못된 사람을 가리키게 됩니다.

연결하지 않은 멤버가 봇을 멘션하면 해당 Slack 스레드에 연결 방법을 설명하는 답장이 달립니다. 아무것도 디스패치되지 않습니다.

## 코드로 연결하기

1. **설정 → 워크스페이스 → 프로필 및 신원**으로 이동해 **연결된 채팅
   계정** 카드까지 스크롤합니다
2. Slack 블록에서 **내 Slack 계정 연결**을 클릭합니다
3. 표시되는 명령을 복사합니다. 예를 들면 다음과 같습니다.

```text
/cc link K7M2QP
```

4. Slack에서 봇에게 그 명령을 보냅니다. DM이 가장 간편한 곳입니다
5. 봇이 어느 Control Center 사용자에게 연결되었는지 확인해 주고, 열어 둔 대화 상자도 같은 순간에 그렇게 바뀝니다. 창을 닫았다가 다시 확인할 필요가 없습니다

코드는 다음과 같습니다.

- 일회용이며 발급된 뒤 **15분** 후에 만료됩니다
- 항상 _나_를 위해 발급되며, 동료를 위해 발급되는 일은 없습니다
- 이미 보유한 코드를 대체하므로, 버튼을 다시 누르면 이전 코드가 무효화됩니다
- 메모리에만 존재하므로 서버가 재시작되면 미사용 코드가 무효화됩니다. 버튼을 다시 누르세요

알 수 없거나 만료되었거나 다른 워크스페이스용으로 발급된 코드는 구분할 수 없을 만큼 동일한 방식으로 실패합니다. “해당 코드는 유효하지 않습니다(또는 만료되었습니다)”.

## 이메일로 자동 연결

Slack 프로필에 **이미 이 워크스페이스의 멤버인** Control Center 사용자와 일치하는 인증된 이메일이 있으면, 브리지와 처음 대화할 때 자동으로 연결됩니다. 코드가 필요하지 않습니다.

두 조건이 모두 중요합니다. 이메일 일치는 신원을 증명하지만 접근 권한은 멤버십만이 부여하므로, 서버에 이메일만 우연히 존재하는 외부인은 아무것에도 연결되지 않습니다. 명단에는 각 연결이 어떻게 만들어졌는지(“이메일로 매칭됨” 또는 “코드로 연결됨”)가 표시됩니다.

자동 연결에는 `users:read.email` 스코프가 필요합니다. 이 스코프가 없으면 Slack이 주소를 공개하지 않으므로 코드 흐름이 유일한 경로입니다.

## 누가 연결되어 있는지 확인하기

명단은 워크스페이스 관리에 속하므로 화면의 다른 쪽에 있습니다.
**설정 → 워크스페이스 → 일반 → 채팅 브리지 → 연결된 계정**입니다. 여기에는
워크스페이스에서 연결된 모든 멤버가 각자 매핑된 Slack 계정과 연결 방식과 함께
나열됩니다.

내 상태는 프로필 페이지에 있습니다. **내 Slack 계정 연결** 행은 연결된 뒤에는
“_your-slack-id_에 연결됨”으로 표시되고, 연결되지 않았으면 연결하라고
안내합니다.

명단은 실시간 구독입니다. 변경이 반대편에서 일어나기 때문입니다. 코드는 Slack에서
입력하므로, 앱에서 보내는 어떤 요청도 그 결과를 되가져올 수 없습니다.

## 연결 해제

워크스페이스 명단의 행에서 **연결 해제**를 클릭합니다.

- 누구나 자기 자신의 연결을 해제할 수 있습니다
- 관리자만 다른 멤버의 연결을 해제할 수 있습니다
- 연결을 해제하면 해당 멤버의 미사용 연결 코드도 함께 무효화됩니다

연결을 해제하면 그 Slack 계정은 다시 연결할 때까지 에이전트를 구동할 수 없습니다. 기존 스페이스, 트랜스크립트, 티켓은 원래 귀속을 그대로 유지합니다. 연결 해제는 지난 작업을 취소하는 것이 아닙니다.

## 문제 해결

### 봇이 이 워크스페이스의 멤버가 아니라고 합니다

Slack 계정이 어떤 Control Center 사용자에 연결되어 있지만, 그 사용자가 이 워크스페이스에 멤버십을 갖고 있지 않습니다. 관리자에게 초대를 요청하세요. [멀티플레이어 — 신원, 멤버십, 프레즌스](/ko-KR/매뉴얼/개념/멀티플레이어/)를 참고하세요.

### 봇이 내 역할이 읽기 전용이라고 합니다

`viewer` 및 `guest` 역할은 작업을 시작할 수 없습니다. 관리자가 내 역할을 `member` 이상으로 올려야 합니다.

### 슬래시 명령이 인식되지 않습니다

슬래시 명령이 Slack에 존재하는지, 그리고 설정 대화 상자에 표시된 명령을 보내고 있는지 확인하세요. 관리자가 이름을 바꿨을 수 있으며, 그 경우 대화 상자에는 현재 이름이 표시됩니다.
