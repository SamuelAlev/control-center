튜토리얼은 **학습 과정**입니다. 각 튜토리얼은 정해진 하나의 경로를 따라 실제
작업을 처음부터 끝까지 수행하게 하며, 도중에 내려야 할 결정이 없습니다. 단계를
그대로 따르면 제대로 동작합니다.

제품 전반을 익히기 위한 자료입니다. 제품의 전체 구조를 파악한 뒤에는
[사용 가이드](/ko-KR/매뉴얼/사용-가이드/)가 특정 작업을 더 빠르게 수행하는 길입니다.

다음 순서대로 진행하세요. 각 튜토리얼은 이전 튜토리얼을 마쳤다고 가정합니다.

1. [첫 워크스페이스](/ko-KR/매뉴얼/튜토리얼/첫-워크스페이스/) — 워크스페이스를 만들고, 저장소를 추가하고, 격리 모델을 확인합니다
2. [첫 에이전트 디스패치](/ko-KR/매뉴얼/튜토리얼/첫-에이전트/) — 에이전트에 어댑터와 모델을 지정한 뒤 실제로 작업시킵니다
3. [첫 풀 리퀘스트 리뷰](/ko-KR/매뉴얼/튜토리얼/첫-풀-리퀘스트/) — diff를 읽고, 댓글을 달고, 병합합니다
4. [첫 파이프라인 만들기](/ko-KR/매뉴얼/튜토리얼/첫-파이프라인/) — 단계를 DAG로 연결하고 실행합니다

두 개는 독립적으로 진행할 수 있습니다. 동작하는 워크스페이스가 준비되면 둘 중 아무 것이나 하면 됩니다.

- [Slack을 워크스페이스에 브리지](/ko-KR/매뉴얼/튜토리얼/첫-채팅-브리지/) — Slack 스레드에서 에이전트를 지시합니다
- [SSO로 팀 로그인](/ko-KR/매뉴얼/튜토리얼/sso/) — ID 공급자를 연결하고 로그인을 처음부터 끝까지 수행합니다

:::note[시작하기 전에]
먼저 Control Center를 설치하세요. [설치](/ko-KR/매뉴얼/설치/)를 참고하세요. 실행 중인
에이전트까지 가는 가장 짧은 경로만 원한다면 대신 [빠른 시작](/ko-KR/매뉴얼/빠른-시작/)을
진행하고 나중에 여기로 돌아오세요.
:::
