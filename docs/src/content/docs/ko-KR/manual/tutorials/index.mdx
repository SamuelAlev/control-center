Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/ko-KR/매뉴얼/사용-가이드/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/ko-KR/매뉴얼/튜토리얼/첫-워크스페이스/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/ko-KR/매뉴얼/튜토리얼/첫-에이전트/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/ko-KR/매뉴얼/튜토리얼/첫-풀-리퀘스트/) — read the diff, comment and merge
4. [Build your first pipeline](/ko-KR/매뉴얼/튜토리얼/첫-파이프라인/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/ko-KR/매뉴얼/튜토리얼/첫-채팅-브리지/) — drive agents from a Slack thread
- [Sign your team in with SSO](/ko-KR/매뉴얼/튜토리얼/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/ko-KR/매뉴얼/설치/). If you only want the
shortest possible path to a running agent, take the [quick start](/ko-KR/매뉴얼/빠른-시작/)
instead and come back here afterwards.
:::
