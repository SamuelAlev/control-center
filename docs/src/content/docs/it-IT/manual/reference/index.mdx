Le pagine di riferimento descrivono **ciò che esiste**, in modo esaustivo e senza
commenti. Usale per cercare qualcosa quando sai già cosa ti serve: il nome esatto di uno
strumento, un tipo di passaggio, una transizione di stato, una route, una scorciatoia.

Non sono scritte per essere lette dall'inizio alla fine. Per quello, usa i
[concetti](/it-IT/manuale/concetti/); per portare a termine un'attività, usa le
[guide pratiche](/it-IT/manuale/guide/).

## La superficie del prodotto

- [Strumenti MCP](/it-IT/manuale/riferimento/strumenti-mcp/) — ogni strumento registrato dal server MCP, per famiglia
- [Strumenti agent integrati](/it-IT/manuale/riferimento/strumenti-agente/) — strumenti dell'harness legati al server (LSP, AST, debug, eval, vibe)
- [Comandi slash](/it-IT/manuale/riferimento/comandi-slash/) — funzioni integrate del composer, `/skill:` e comandi utente
- [Mappa delle route](/it-IT/manuale/riferimento/mappa-delle-route/) — ogni schermata e l'URL che vi porta
- [Scorciatoie da tastiera](/it-IT/manuale/riferimento/scorciatoie-da-tastiera/) — l'intero registro delle combinazioni di tasti
- [Eventi di dominio](/it-IT/manuale/riferimento/eventi-di-dominio/) — ogni evento pubblicato sul bus di dominio
- [Rig](/it-IT/manuale/riferimento/rig/) — ogni superficie dei rig, verbo di azione, stato del ciclo di vita, porta e valore predefinito
