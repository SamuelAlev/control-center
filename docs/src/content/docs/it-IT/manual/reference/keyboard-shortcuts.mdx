Le scorciatoie provengono da un unico registro `const`, `KeybindingRegistry` in `lib/core/constants/keybindings.dart`. Contiene **49 associazioni**. Impostazioni → Tu → Tasti rapidi mostra quel registro come **riferimento di sola lettura**: non esiste un'interfaccia per riassegnare i tasti né un file di scorciatoie utente.

Nel seguito `Cmd` indica il modificatore di comando principale: ⌘ su macOS, Ctrl su Windows e Linux. Un'associazione si attiva solo quando il suo comando ha un gestore registrato nella schermata corrente e la sua clausola `when` è soddisfatta; `!textInputFocus` significa invece che il tasto viene passato a un campo di testo attivo.

Non esiste alcuna scorciatoia di navigazione con i tasti numerici. Alla posta in arrivo, ai ticket, alle pull request e al resto si accede dalla barra laterale o con ⌘K. Anche l'osservabilità non ha scorciatoie.

## Elenco delle pull request (3)

Ambito `/pull-requests`. Tutte richiedono `route == '/pull-requests'` e nessun campo di testo attivo, quindi non si attivano mentre la route di dettaglio della PR è aperta sopra l'elenco.

| Scorciatoia | Azione                 |
| ----------- | ---------------------- |
| `R`         | Aggiorna               |
| `Enter`     | Apri PR                |
| `F`         | Apri il menu dei filtri |

`Enter` (`pr.list-open`) è dichiarato nel registro e compare nel riferimento dei tasti, ma **la schermata dell'elenco non registra un gestore per esso**, quindi al momento non si attiva. `F` apre il menu dei filtri (`pr.list-open-filter`), non la ricerca.

## Dettaglio della pull request (2)

Ambito `/pull-requests/`. Aggiorna richiede che non ci sia un campo di testo attivo. Chiudi scheda non ha alcun controllo sull'input di testo (una combinazione con ⌘ non è mai testo semplice) e usa una regex di route, così non si attiva nell'elenco.

| Scorciatoia    | Azione        | Condizione                         |
| -------------- | ------------- | ---------------------------------- |
| `R`            | Aggiorna      | Non stai digitando in un campo     |
| `Cmd/Ctrl + W` | Chiudi scheda | In una posizione `/pull-requests/<…>` |

Il cambio di scheda (`1`/`2`/`3`), il contrassegno come visualizzato/compressione del file (`V`/`C`), l'elenco dei file (`T`) e trova nel diff (`Cmd/Ctrl + F`) sono gestiti dal gestore interno del visualizzatore di diff — vedi [Tasti del visualizzatore di diff fuori dal registro](#tasti-del-visualizzatore-di-diff-fuori-dal-registro).

## Spazi (9)

Ambito `/spaces`. Le clausole `when` usano una regex, quindi si attivano sia nell'elenco degli spazi (`/spaces`) sia in uno spazio selezionato (`/spaces/<id>`).

| Scorciatoia            | Azione                                      | Condizione             |
| ---------------------- | ------------------------------------------- | ---------------------- |
| `Enter`                | Invia messaggio                             | —                      |
| `Cmd/Ctrl + N`         | Nuovo spazio                                | In una route `/spaces` |
| `J`                    | Spazio successivo                           | Non stai digitando in un campo |
| `K`                    | Spazio precedente                           | Non stai digitando in un campo |
| `Cmd/Ctrl + Shift + D` | Dettatura vocale (premi per parlare)        | —                      |
| `Cmd/Ctrl + T`         | Apri scheda editor                          | In una route `/spaces` |
| `Cmd/Ctrl + W`         | Chiudi scheda editor                        | In una route `/spaces` |
| `Cmd/Ctrl + B`         | Attiva/disattiva barra laterale dell'editor | In una route `/spaces` |
| `Cmd/Ctrl + P`         | Vai al file                                 | In una route `/spaces` |

«Vai al file» apre un selettore sui file della conversazione. Senza digitare nulla elenca i file aperti più di recente; digitando cerca in tutti i file dei worktree della conversazione. `Enter` apre il file selezionato in una nuova scheda, `Cmd/Ctrl + Enter` o il pulsante di divisione sulla riga lo apre in un riquadro a destra e la `×` su una riga recente lo rimuove dall’elenco.

L'invio con Invio è gestito dal campo di testo dell'editor dei messaggi; il premi per parlare è gestito dal pulsante microfono dell'editor dei messaggi (con un proprio gestore della tastiera hardware). Entrambi sono elencati nel registro per il riferimento delle impostazioni.

## Tasti del visualizzatore di diff fuori dal registro

Il visualizzatore di diff delle PR gestisce questi tasti da sé (`PrDiffKeyboardHandler`). Ricerca, visualizzato e compressione sono elencati nei commenti del registro solo per il riferimento delle impostazioni: non è registrato alcun gestore nel dispatcher, quindi il dispatcher li lascia alla vista di diff. Non compaiono come righe proprie nel riferimento dei tasti.

| Scorciatoia     | Azione                                                |
| --------------- | ----------------------------------------------------- |
| `Cmd/Ctrl + F`  | Cerca nel diff                                        |
| `J` / `K`       | File successivo / precedente                          |
| `V`             | Attiva/disattiva visualizzato sul file attivo         |
| `C`             | Attiva/disattiva compressione sul file attivo         |
| `T`             | Mostra l'elenco dei file                              |
| `Enter`         | Risultato di ricerca successivo (solo mentre trova nel diff è aperto) |
| `Shift + Enter` | Risultato di ricerca precedente                       |
| `Escape`        | Chiudi trova nel diff o cancella la selezione di testo nel diff |
| `Cmd/Ctrl + C`  | Copia la selezione del diff                           |

## Combinazioni riservate al browser

Nella build web il browser intercetta alcuni acceleratori prima che la pagina li veda, quindi le associazioni corrispondenti non possono mai attivarsi lì. Sul desktop funzionano normalmente. Sono riservate se combinate con il modificatore di comando principale: `T`, `W`, `N` e le cifre `1`–`9`.

Questo vale per il cambio di spazio di lavoro con `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nuovo spazio, nuovo spazio di lavoro, nuovo agente, aggiungi repository) e `Cmd/Ctrl + T` / `Cmd/Ctrl + W` negli spazi e nel dettaglio della PR.
