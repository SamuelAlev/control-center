Questa pagina di riferimento elenca tutti i campi dell'entità agente, oltre alle enumerazioni e ai flag che usa. Per una procedura dettagliata di creazione o modifica di un agente nell'app, vedi [Crea e configura un agente](/it-IT/manuale/guide/crea-agente/).

## Campi dell'entità agente

| Campo                   | Tipo                   | Obbligatorio | Descrizione                                                                                                                                                                                                              |
| ----------------------- | ---------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                    | `String`               | Sì           | Identificatore univoco dell'agente                                                                                                                                                                                       |
| `name`                  | `String`               | Sì           | Identificatore breve per le @-menzioni                                                                                                                                                                                   |
| `title`                 | `String`               | Sì           | Titolo del ruolo leggibile da una persona                                                                                                                                                                                |
| `agentMdPath`           | `String`               | Sì           | Percorso assoluto del file di definizione `.md` dell'agente                                                                                                                                                              |
| `workspaceId`           | `String`               | Sì           | Spazio di lavoro proprietario (mai null)                                                                                                                                                                                 |
| `reportsTo`             | `String?`              | No           | Id dell'agente padre                                                                                                                                                                                                     |
| `skills`                | `AgentSkills`          | Sì           | Insieme di identificatori di skill                                                                                                                                                                                       |
| `persona`               | `String?`              | No           | Istruzioni comportamentali in testo libero                                                                                                                                                                               |
| `systemPrompt`          | `String?`              | No           | Sostituisce il prompt di sistema predefinito                                                                                                                                                                             |
| `adapterId`             | `String?`              | No           | Id dell'adattatore di inferenza                                                                                                                                                                                          |
| `modelId`               | `String?`              | No           | Id del modello all'interno dell'adattatore                                                                                                                                                                               |
| `strictMode`            | `bool`                 | No           | Predefinito `false`. Scritto nella riga e nell'`AGENTS.md` dell'agente                                                                                                                                                   |
| `effort`                | `String?`              | No           | Id del livello di ragionamento (ad es. `'low'`, `'xhigh'`), tratto dai `thinkingLevels` del modello selezionato                                                                                                          |
| `contextSize`           | `int?`                 | No           | Dimensione massima della finestra di contesto                                                                                                                                                                            |
| `role`                  | `AgentRole?`           | No           | Ruolo dell'agente                                                                                                                                                                                                        |
| `capabilities`          | `AgentCapabilities?`   | No           | Valore predefinito delle capacità per agente; quando è null, al momento dell'invio si applica il valore predefinito del livello utente e una conversazione può comunque sovrascriverlo                                    |
| `monthlyBudgetCents`    | `int`                  | No           | Limite di spesa mensile in centesimi (predefinito `0`, illimitato)                                                                                                                                                       |
| `silenceTimeoutMinutes` | `int?`                 | No           | Override del timeout di silenzio in minuti; deve essere null o compreso tra 1 e 240 (verificato dal costruttore)                                                                                                         |
| `maxConcurrentTasks`    | `int`                  | No           | Predefinito `1`. Cifra di capacità che il modello delle presenze riporta (i conteggi delle esecuzioni attive e in coda vengono confrontati con essa)                                                                     |
| `visibility`            | `AgentVisibility`      | No           | Predefinito `workspace`                                                                                                                                                                                                  |
| `lifecycleStatus`       | `AgentLifecycleStatus` | No           | Stato di governance (predefinito `active`). Scritto dall'arresto forzato del budget e mostrato nell'organigramma e nell'elenco delle presenze. L'invio accetta comunque lavoro da un agente `paused`                      |
| `budgetPolicyId`        | `String?`              | No           | Id della policy di budget condivisa; quando è null si applica direttamente `monthlyBudgetCents`                                                                                                                          |
| `runtimeProfileId`      | `String?`              | No           | Id del profilo di runtime personalizzato                                                                                                                                                                                 |
| `createdAt`             | `DateTime`             | Sì           | Data e ora di creazione                                                                                                                                                                                                  |

`name` e `title` devono essere entrambi non vuoti (verificato dal costruttore). Un
`monthlyBudgetCents` predefinito di `0` significa illimitato. Imposta un tetto di spesa con
`agents.upsert`.

| Ruolo      | Etichetta | Descrizione                    |
| ---------- | --------- | ------------------------------ |
| `ceo`      | CEO       | Coordinamento e delega         |
| `coder`    | Coder     | Implementazione del codice     |
| `reviewer` | Reviewer  | Revisione e analisi delle PR   |
| `qa`       | QA        | Test e garanzia della qualità  |
| `designer` | Designer  | Implementazione UI/UX          |
| `security` | Security  | Revisione e audit di sicurezza |

| `pm`       | PM        | Gestione del prodotto          |

## Enumerazione AgentVisibility

| Valore      | Descrizione                                                               |
| ----------- | ------------------------------------------------------------------------- |
| `workspace` | Il valore predefinito; i valori memorizzati sconosciuti e null vi ricadono |
| `private`   | Privato per l'utente che lo ha creato                                     |

## Enumerazione AgentLifecycleStatus

| Valore     | Descrizione                                                                             |
| ---------- | --------------------------------------------------------------------------------------- |
| `active`   | Il valore predefinito. `isDispatchable` è true solo per questo valore                   |
| `paused`   | Impostato dall'arresto forzato del budget. Mostrato nell'elenco delle presenze; l'invio accetta comunque lavoro |
| `archived` | Ritirato e nascosto dagli elenchi delle presenze attive                                  |

## Flag di AgentCapabilities

Risolti a ogni invio: il valore predefinito dell'agente, con fallback sul valore predefinito del livello utente quando è null, e sopra un override per conversazione. Applicati per assenza — il broker delle credenziali semplicemente non emette né inietta ciò che copre una capacità disabilitata.

| Flag               | Tipo   | Predefinito | Descrizione                                                                                                |
| ------------------ | ------ | ----------- | ---------------------------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false`     | Push dei commit verso il remoto; controlla l'iniezione del token GitHub insieme a `canCallGitHubApi`        |
| `canCallGitHubApi` | `bool` | `false`     | Chiama api.github.com; controlla l'iniezione di `GH_TOKEN` e i domini di uscita GitHub                      |
| `canCallTicketing` | `bool` | `false`     | Chiama l'API del provider di ticketing; controlla l'iniezione della chiave API del provider e i suoi domini di uscita |
| `canAccessNetwork` | `bool` | `true`      | Uscita di rete arbitraria. Controlla anche gli strumenti `web_fetch` e `web_search` dell'harness            |

`AgentCapabilities.safeDefault` corrisponde ai quattro valori predefiniti del costruttore. `legacyDefault` (tutti e quattro true) è usato solo dalla migrazione che ha riempito retroattivamente le conversazioni create prima che esistessero le capacità. Un blob memorizzato malformato o vuoto viene interpretato come `safeDefault`; la chiave legacy `canCallLinear` viene letta come `canCallTicketing`.

## AgentSkills

Un insieme immutabile e senza distinzione tra maiuscole e minuscole di identificatori di skill. Al momento dell'invio quegli slug vengono sincronizzati come collegamenti di skill nell'overlay dell'agente; l'harness carica poi automaticamente il frontmatter delle skill collegate nel prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (derivato)

Non memorizzato. Sette valori. L'ordine di dichiarazione è l'ordine di priorità (`sortPriority`, fissato da un test), che è l'ordine con cui ordina l'elenco:

| Stato       | `sortPriority` | Condizione                                                                                                                    |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `running`   | 0              | Un qualsiasi log di esecuzione ha stato `running`                                                                              |
| `blocked`   | 1              | La vitalità dell'ultima esecuzione è `blocked`, `stalled` o `looping`                                                          |
| `failed`    | 2              | Lo stato dell'ultima esecuzione è `error`, oppure la sua vitalità è `failed` o `dead`                                           |
| `queued`    | 3              | Un'esecuzione è stata inviata ma non è in corso — in attesa dietro un'altra esecuzione dello stesso agente, oppure scritta ma non ancora avviata |
| `succeeded` | 4              | L'esecuzione si è conclusa correttamente                                                                                       |
| `idle`      | 5              | L'agente ha già eseguito e non ha nulla in volo                                                                                |
| `neverRun`  | 6              | Non esiste alcun log di esecuzione                                                                                             |

`queued` e `succeeded` sono **solo per singola esecuzione**. `deriveAgentLiveState`, che calcola lo stato dell'elenco per un agente, non ne produce mai nessuno dei due — restituisce `neverRun`, `running`, `failed`, `blocked` o `idle`.
