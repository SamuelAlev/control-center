Incolla una chiave API di Linear sul server associandola al tuo utente, come
faresti per collegare un forge. Ticket, progetti, collegamenti, collaboratori,
delega e assegnazione funzionano tutti sul database di Control Center, senza che
sia necessario alcun servizio esterno — vedi
[Crea e gestisci i ticket](/it-IT/manuale/guide/gestisci-ticket/).

## Salva la tua chiave Linear

**Chiave API ticketing** si trova in **Impostazioni → Spazio di lavoro → Generale**,
sulla scheda Ticket. La chiave viene archiviata sul server associandola al tuo ID
utente. La chiave del server per il lavoro senza supervisione proviene da
`LINEAR_API_KEY` o dalla scheda **App del fornitore**. Nel sandbox di un agente
non viene messa alcuna chiave di ticketing: gli agenti scrivono i ticket tramite
gli strumenti di Control Center, che prima interrogano la regola **Scrivere su un
tracker esterno**.

## Contrassegna i nuovi ticket come Linear

**Provider di ticket** (il primo passaggio dell'onboarding, e
`/workspaces/<workspaceId>/api-keys`) offre `local` e `linear`. Scegliendo
`linear` viene applicato `provider: linear` ai ticket che crei da quel momento in
poi.
