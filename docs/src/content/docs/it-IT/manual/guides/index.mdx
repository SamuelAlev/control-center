Ogni guida risolve **un problema per chi conosce già bene gli strumenti**. Presuppongono
che Control Center sia installato e che uno spazio di lavoro sia configurato, dichiarano
un obiettivo nel titolo e si fermano quando l'obiettivo è raggiunto.

Se stai ancora imparando il prodotto, inizia dai [tutorial](/it-IT/manuale/tutorial/).
Se vuoi capire _perché_ qualcosa si comporta in un certo modo, leggi i
[concetti](/it-IT/manuale/concetti/).
