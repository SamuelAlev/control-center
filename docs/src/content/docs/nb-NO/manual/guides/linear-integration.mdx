Lim inn en Linear API-nøkkel på serveren knyttet til brukeren din, på samme måte
som du kobler til en kodevert. Saker, prosjekter, lenker, samarbeidspartnere,
delegering og tildeling fungerer alle mot Control Centers egen database, uten at
noen ekstern tjeneste er nødvendig — se
[Opprett og administrer saker](/nb-NO/handbok/slik-gjor-du/administrer-saker/).

## Lagre Linear-nøkkelen din

**API-nøkkel for saker** ligger under **Innstillinger → Arbeidsområde →
Generelt**, på Saker-kortet. Den lagrer nøkkelen på serveren knyttet til
bruker-id-en din. Serverens egen nøkkel for uovervåket arbeid kommer fra
`LINEAR_API_KEY` eller kortet **Leverandørapper**, og injiseres som
`TICKETING_API_KEY` bare når den agenten har kapasiteten **Tillat API-kall for
saker**.

## Stempl nye saker som Linear

**Saksleverandør** (første steg i onboarding, og
`/workspaces/<workspaceId>/api-keys`) tilbyr `local` og `linear`. Velger du
`linear`, blir saker du oppretter fra da av stemplet med `provider: linear`.
