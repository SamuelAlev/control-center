Snarveiene kommer fra ett `const`-register, `KeybindingRegistry` i `lib/core/constants/keybindings.dart`. Det inneholder **48 bindinger**. Innstillinger → Deg → Hurtigtaster viser dette registeret som en **skrivebeskyttet referanse**: det finnes ingen grensesnitt for å tilordne på nytt, og ingen fil for egne tastatursnarveier.

`Cmd` nedenfor er den primære kommandomodifikatoren — ⌘ på macOS, Ctrl på Windows og Linux. En binding utløses bare når kommandoen har en registrert behandler på gjeldende skjerm, og `when`-klausulen er oppfylt; `!textInputFocus` betyr at tasten i stedet sendes videre til et tekstfelt som har fokus.

Det finnes ingen snarvei for navigasjon med tallsiffer. Innboksen, saker, pull requests og resten nås fra sidepanelet eller med ⌘K. Observabilitet har heller ingen snarvei.

## Global (19)

Omfanget er `global`, så de er aktive overalt i skallet.

## Pull request-liste (3)

Omfanget er `/pull-requests`. Alle krever `route == '/pull-requests'` og ingen tekstfelt med fokus, så de utløses ikke mens PR-detaljruten ligger åpen over listen.

| Snarvei | Handling          |
| ------- | ----------------- |
| `R`     | Oppdater          |
| `Enter` | Åpne PR           |
| `F`     | Åpne filtermeny   |

`Enter` (`pr.list-open`) er deklarert i registeret og vises i referansen over tastaturbindinger, men **listeskjermen registrerer ingen behandler for den**, så den utløses foreløpig ikke. `F` åpner filtermenyen (`pr.list-open-filter`), ikke søket.

## Pull request-detaljer (2)

Omfanget er `/pull-requests/`. Oppdater krever ingen tekstfelt med fokus. Lukk fane har ingen vakt mot tekstinndata (et ⌘-modifisert tastetrykk er aldri ren tekst) og et rute-regex, så den ikke utløses på listen.

| Snarvei        | Handling   | Betingelse                        |
| -------------- | ---------- | --------------------------------- |
| `R`            | Oppdater   | Ikke mens du skriver i et felt    |
| `Cmd/Ctrl + W` | Lukk fane  | På en `/pull-requests/<…>`-plassering |

Fanebytte (`1`/`2`/`3`), vist/sammenfoldet for en fil (`V`/`C`), fillisten (`T`) og søk i diffen (`Cmd/Ctrl + F`) hører til diff-visningens egen behandler — se [Taster i diff-visningen utenfor registeret](#taster-i-diff-visningen-utenfor-registeret).

## GitHub-bruker- og teamprofiler (3)

Omfanget er `/users/`. `when`-klausulen er et regex mot `/users/<login>` **eller** `/teams/<organization>/<slug>`, pluss ingen tekstfelt med fokus.

| -------------- | -------------- |
| `R`            | Oppdater       |

## Områder (8)

Omfanget er `/spaces`. `when`-klausulene bruker et regex, så de utløses både på områdelisten (`/spaces`) og i et valgt område (`/spaces/<id>`).

| Snarvei                | Handling                        | Betingelse                    |
| ---------------------- | ------------------------------- | ----------------------------- |
| `Enter`                | Send melding                    | —                             |
| `Cmd/Ctrl + N`         | Nytt område                     | På en `/spaces`-rute          |
| `J`                    | Neste område                    | Ikke mens du skriver i et felt |
| `K`                    | Forrige område                  | Ikke mens du skriver i et felt |
| `Cmd/Ctrl + Shift + D` | Diktering med trykk for å snakke | —                            |
| `Cmd/Ctrl + T`         | Åpne editorfane                 | På en `/spaces`-rute          |
| `Cmd/Ctrl + W`         | Lukk editorfane                 | På en `/spaces`-rute          |
| `Cmd/Ctrl + B`         | Slå editor-sidepanelet av/på    | På en `/spaces`-rute          |

Sending med Enter hører til tekstfeltet i meldingsfeltet; trykk-for-å-snakke hører til mikrofonknappen i meldingsfeltet, som har sin egen behandler for fysisk tastatur. Begge står i registeret for at innstillingsreferansen skal føre dem opp.

## Taster i diff-visningen utenfor registeret

PR-diff-visningen håndterer disse selv (`PrDiffKeyboardHandler`). Søk/vist/sammenfold står i registerets kommentarer bare for innstillingsreferansen — ingen behandler i dispatcheren er registrert, så dispatcheren overlater dem til diff-visningen. De vises ikke som egne rader i referansen over tastaturbindinger.

| Snarvei         | Handling                                                       |
| --------------- | -------------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Søk i diffen                                                   |
| `J` / `K`       | Neste / forrige fil                                            |
| `V`             | Slå «vist» av/på for filen med fokus                           |
| `C`             | Slå sammenfolding av/på for filen med fokus                    |
| `T`             | Vis filliste                                                   |
| `Enter`         | Neste treff (bare mens søk i diffen er åpent)                  |
| `Shift + Enter` | Forrige treff                                                  |
| `Escape`        | Lukk søk i diffen, eller fjern tekstmarkeringen i diffen       |
| `Cmd/Ctrl + C`  | Kopier markeringen i diffen                                    |

## Kombinasjoner som nettleseren reserverer

I nettbygget bruker nettleseren noen hurtigtaster før siden ser dem, så de tilhørende bindingene kan aldri utløses der. På skrivebordet fungerer de normalt. Reservert i kombinasjon med den primære kommandomodifikatoren: `T`, `W`, `N` og sifrene `1`–`9`.

Det dekker arbeidsområdebytte med `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nytt område, nytt arbeidsområde, ny agent, legg til arkiv) og `Cmd/Ctrl + T` / `Cmd/Ctrl + W` i områder og PR-detaljer.
