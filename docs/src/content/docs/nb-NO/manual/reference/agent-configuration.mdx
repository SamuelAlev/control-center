Denne referansen lister opp alle feltene på agententiteten, i tillegg til enumene og flaggene den bruker. En stegvis gjennomgang av å opprette eller redigere en agent i appen finner du i [Opprett og konfigurer en agent](/nb-NO/handbok/slik-gjor-du/opprett-agent/).

## Felter på agententiteten

| Felt                    | Type                   | Påkrevd | Beskrivelse                                                                                                                                                                                         |
| ----------------------- | ---------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ja      | Unik identifikator for agenten                                                                                                                                                                      |
| `name`                  | `String`               | Ja      | Kort identifikator for @-omtaler                                                                                                                                                                    |
| `title`                 | `String`               | Ja      | Lesbar stillingstittel                                                                                                                                                                              |
| `agentMdPath`           | `String`               | Ja      | Absolutt sti til agentens `.md`-definisjonsfil                                                                                                                                                      |
| `workspaceId`           | `String`               | Ja      | Arbeidsområdet som eier agenten (ikke null)                                                                                                                                                         |
| `reportsTo`             | `String?`              | Nei     | Id-en til overordnet agent                                                                                                                                                                          |
| `skills`                | `AgentSkills`          | Ja      | Sett med skill-identifikatorer                                                                                                                                                                      |
| `persona`               | `String?`              | Nei     | Fritekst med atferdsinstruksjoner                                                                                                                                                                   |
| `systemPrompt`          | `String?`              | Nei     | Overstyr systemprompten som er standard                                                                                                                                                             |
| `adapterId`             | `String?`              | Nei     | Id for inferensadapteren                                                                                                                                                                            |
| `modelId`               | `String?`              | Nei     | Modell-id innenfor adapteren                                                                                                                                                                        |
| `strictMode`            | `bool`                 | Nei     | Standard `false`. Skrives til raden og til agentens `AGENTS.md`                                                                                                                                     |
| `effort`                | `String?`              | Nei     | Id for resonneringsnivået (f.eks. `'low'`, `'xhigh'`), hentet fra den valgte modellens `thinkingLevels`                                                                                              |
| `contextSize`           | `int?`                 | Nei     | Maksimal størrelse på kontekstvinduet                                                                                                                                                               |
| `role`                  | `AgentRole?`           | Nei     | Agentens rolle                                                                                                                                                                                      |
| `monthlyBudgetCents`    | `int`                  | Nei     | Månedlig utgiftstak i cent (standard `0`, ubegrenset)                                                                                                                                               |
| `silenceTimeoutMinutes` | `int?`                 | Nei     | Overstyring av stillhetsvakten i minutter; må være null eller i området 1–240 (sjekket av konstruktøren)                                                                                            |
| `maxConcurrentTasks`    | `int`                  | Nei     | Standard `1`. Kapasitetstallet som tilstedeværelsesmodellen rapporterer (antall kjørende og antall i kø sammenlignes med det)                                                                       |
| `visibility`            | `AgentVisibility`      | Nei     | Standard `workspace`                                                                                                                                                                                |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Nei     | Styringsstatus (standard `active`). Skrives av budsjettets harde stopp og vises på organisasjonskartet og tilstedeværelsesoversikten. Utsending godtar fortsatt arbeid fra en agent som er `paused` |
| `budgetPolicyId`        | `String?`              | Nei     | Id for en delt budsjettpolicy; når den er null, gjelder `monthlyBudgetCents` direkte                                                                                                                |
| `runtimeProfileId`      | `String?`              | Nei     | Id for en egendefinert kjøretidsprofil                                                                                                                                                              |
| `createdAt`             | `DateTime`             | Ja      | Tidsstempel for oppretting                                                                                                                                                                          |

`name` og `title` må begge være ikke-tomme (sjekket av konstruktøren). Standardverdien
`0` for `monthlyBudgetCents` betyr ubegrenset. Skriv et tak med `agents.upsert`.

## AgentVisibility-enumet

| Verdi       | Beskrivelse                                             |
| ----------- | ------------------------------------------------------- |
| `workspace` | Standardverdien; ukjente og null-lagrede verdier tolkes som den |
| `private`   | Privat for brukeren som opprettet den                   |

## AgentLifecycleStatus-enumet

| Verdi      | Beskrivelse                                                                           |
| ---------- | ------------------------------------------------------------------------------------- |
| `active`   | Standardverdien. `isDispatchable` er bare sann for denne verdien                      |
| `paused`   | Settes av budsjettets harde stopp. Vises i tilstedeværelsesoversikten; utsending godtar fortsatt arbeid |
| `archived` | Trukket tilbake og skjult fra aktive oversikter                                       |

## Tillatelser

En agent har ingen tillatelsesflagg. Pushing, åpning og publisering av pull requests, skriving til et oppfølgingssystem og utgående nettverkstrafikk er handlingsklasser (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) som [tillatelsesreglene](/nb-NO/handbok/konsepter/tillatelsesregler/) løser opp i omfanget arbeidsområde, agent eller område. GitHub-tokenet til en kjøring er alltid lesebegrenset; pusher går gjennom agentkjøringsgatewayen, som spør `gitPush`-regelen før de sendes videre.

## AgentSkills

Et uforanderlig sett med skill-identifikatorer uten hensyn til store og små bokstaver. Ved utsending synkes disse slug-ene som skill-lenker i agentens overlay; harnesset laster deretter frontmatteren til de lenkede skillene automatisk inn i prompten.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (utledet)

Lagres ikke. Sju verdier. Rekkefølgen i deklarasjonen er prioritetsrekkefølgen (`sortPriority`, låst av en test), som er rekkefølgen oversikten sorterer etter:

| Tilstand    | `sortPriority` | Betingelse                                                                                                          |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Enhver kjøringslogg har statusen `running`                                                                          |
| `blocked`   | 1              | Livsstatusen til den siste kjøringen er `blocked`, `stalled` eller `looping`                                        |
| `failed`    | 2              | Statusen til den siste kjøringen er `error`, eller livsstatusen er `failed` eller `dead`                            |
| `queued`    | 3              | En kjøring er sendt ut, men kjører ikke — satt på vent bak en annen kjøring av samme agent, eller skrevet, men ikke startet ennå |
| `succeeded` | 4              | Kjøringen fullførte vellykket                                                                                       |
| `idle`      | 5              | Agenten har kjørt før og har ingenting i gang                                                                       |
| `neverRun`  | 6              | Det finnes ingen kjøringslogger                                                                                     |

`queued` og `succeeded` gjelder **bare per kjøring**. `deriveAgentLiveState`, som beregner oversiktstilstanden for en agent, produserer aldri noen av dem — den returnerer `neverRun`, `running`, `failed`, `blocked` eller `idle`.
