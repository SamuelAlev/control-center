Um projeto é um agrupamento de tickets no escopo de um espaço de trabalho em
torno de um objetivo comum. Os projetos existem apenas no Control Center — eles
nunca são sincronizados com um provedor externo como o Linear.

## Criar um projeto

1. Expanda o grupo **Tickets** na barra lateral do espaço de trabalho. Ele lista
   **Todos os tickets**, uma linha por projeto não arquivado e, depois,
   **Novo projeto**.
2. Clique em **Novo projeto**.
3. Preencha **Nome do projeto**, uma **Descrição** opcional e escolha uma
   **Cor**.
4. Clique em **Criar projeto**.

Você é levado à visão geral do novo projeto, e o projeto aparece como uma linha
na barra lateral, sob **Tickets**.

## Adicionar tickets a um projeto

Projeto é um campo de ticket único, definido em um de dois lugares:

- Abra o ticket e defina **Projeto** no painel de propriedades dele.
- Clique com o botão direito no ticket na lista e use o submenu **Projeto**.

O seletor do painel de propriedades também oferece **Novo projeto**, então você
pode inserir um ticket em um projeto criado na hora. **Sem projeto** limpa o
campo.

Um ticket pertence a no máximo um projeto.

:::note[Projeto não é uma ação em massa]
A barra flutuante que aparece quando você seleciona vários tickets cobre status,
prioridade, responsável, etiquetas e exclusão. Ela não tem chip de projeto, então
inserir muitos tickets significa fazer um de cada vez.
:::

Você também pode começar pelo projeto: **Novo ticket** na visão geral do projeto
cria um ticket e o insere ali.

## Ler o progresso de um projeto

Abra um projeto pela linha dele na barra lateral ou acesse
`/workspaces/<workspace-id>/projects/<project-id>`.

A visão geral mostra o ícone e o nome do projeto, um selo de status, a descrição
e uma barra de progresso de concluídos em relação ao total. Abaixo disso, os
tickets do projeto são agrupados por status.

Ela não agrega mais nada — não há divisão por responsável nem distribuição por
prioridade. Para isso, filtre a lista principal de tickets.

## Alterar o status de um projeto

Os projetos têm três estados:

| Status        | Significado                  |
| ------------- | ---------------------------- |
| **Ativo**     | O trabalho está em andamento |
| **Concluído** | Todo o trabalho foi feito    |
| **Arquivado** | Referência histórica         |

Use o menu **⋯** no cabeçalho do projeto. Ele oferece **Editar projeto**,
**Marcar como concluído** / **Marcar como ativo**, **Arquivar** / **Restaurar**
e **Excluir projeto**.

Arquivar oculta o projeto da lista da barra lateral e dos seletores de tickets.
É reversível — **Restaurar** devolve o projeto ao estado ativo —, mas o projeto
só é acessível por URL enquanto está arquivado.

## Projetos criados para você

Aprovar uma orquestração cria um projeto e insere o ticket pai nele, junto com
tudo o que você inseriu manualmente. Os itens de trabalho gerados são etapas de
pipeline, não linhas de ticket, então eles não aparecem no quadro do projeto.
Esse é o único caminho automatizado: nenhum nó de pipeline cria tickets, então um
pipeline não pode popular um projeto. Consulte
[Executar uma orquestração](/pt-BR/manual/guias/executar-orquestracao/).

:::note[Projetos são uma superfície do operador]
Crie, liste, atualize e exclua projetos no app. Os agentes não têm ferramentas
de projeto.
