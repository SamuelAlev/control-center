Este guia mostra como vincular sua identidade de chat ao seu usuário do Control Center e como desfazer um vínculo.

Cada membro faz isso uma vez por provedor de chat. É algo separado de conectar o app: a conexão torna o bot alcançável para todo o espaço de trabalho; o vínculo torna _você_ reconhecível dentro dele.

## Por que o vínculo é obrigatório

A ponte se recusa a agir em nome de uma conta de chat que ela não consegue resolver para um membro do espaço de trabalho. Isso é proposital — sem um vínculo, toda mensagem vinda do Slack teria de ser atribuída a quem instalou o app, e a trilha de auditoria, os limites de taxa por Principal e os autores dos tickets apontariam todos para a pessoa errada.

Um membro sem vínculo que menciona o bot recebe uma resposta naquele thread do Slack explicando como vincular. Nada é despachado.

## Vincular com um código

1. Vá em **Configurações → Espaço de trabalho → Perfil e identidade** e role até o cartão **Contas de chat vinculadas**
2. No bloco do Slack, clique em **Vincular minha conta do Slack**
3. Copie o comando que ele mostra, por exemplo:

```text
/cc link K7M2QP
```

4. No Slack, envie esse comando ao bot — uma DM é o lugar mais simples
5. O bot confirma com qual usuário do Control Center você está vinculado agora, e a caixa de diálogo que você deixou aberta se atualiza para dizer o mesmo no exato momento — você não precisa fechá-la para conferir

O código:

- É de uso único e expira **15 minutos** depois de ser gerado
- É sempre gerado para _você_, nunca para um colega de equipe
- Substitui qualquer código que você já tenha, então apertar o botão de novo invalida o anterior
- Vive apenas na memória, então reiniciar o servidor invalida os códigos pendentes — aperte o botão de novo

Um código desconhecido, expirado ou gerado para outro espaço de trabalho falha da mesma forma indistinguível: "esse código não é válido (ou expirou)".

## Vinculação automática por e-mail

Se seu perfil do Slack traz um e-mail verificado que corresponde a um usuário do Control Center que **já é membro deste espaço de trabalho**, a ponte vincula você na primeira vez que você conversa com ela. Nenhum código é necessário.

As duas metades importam: a correspondência de e-mail prova a identidade, mas só a associação concede acesso, então um desconhecido cujo e-mail por acaso existe no servidor não vincula nada. A lista mostra como cada vínculo foi feito ("associado por e-mail" ou "vinculado com um código").

A vinculação automática precisa do escopo `users:read.email`. Sem ele, o Slack não divulga o endereço e o fluxo por código é o único caminho.

## Ver quem está vinculado

A lista é administração do espaço de trabalho, então ela fica na outra metade da superfície: **Configurações → Espaço de trabalho → Geral → Pontes de chat → Contas vinculadas**. Ela lista todos os membros vinculados no espaço de trabalho, com a conta do Slack à qual cada um corresponde e como o vínculo foi feito.

O seu próprio estado fica na sua página de perfil: a linha **Vincular minha conta do Slack** mostra "Vinculado a _your-slack-id_" quando você já tem vínculo e pede que você vincule quando não tem.

A lista é uma assinatura ao vivo, porque a mudança acontece do outro lado — você digita o código no Slack, então nenhuma requisição do app pode trazer a resposta de volta.

## Desvincular

Clique em **Desvincular** em uma linha da lista do espaço de trabalho.

- Qualquer pessoa pode desvincular a si mesma
- Só um admin pode desvincular outro membro
- Desvincular também revoga qualquer código de vínculo pendente daquele membro

Depois de desvincular, essa conta do Slack não pode mais comandar agentes até vincular de novo. Espaços, transcrições e tickets existentes mantêm a atribuição original — desvincular não é uma retratação do trabalho passado.

## Solução de problemas

### O bot diz que não sou membro deste espaço de trabalho

Sua conta do Slack está vinculada a um usuário do Control Center, mas esse usuário não tem associação neste espaço de trabalho. Peça a um admin para convidar você; consulte [Multijogador — identidade, associação e presença](/pt-BR/manual/conceitos/multijogador/).

### O bot diz que minha função é somente leitura

As funções `viewer` e `guest` não podem iniciar trabalho. Um admin precisa elevar sua função para `member` ou superior.

### O comando slash não é reconhecido

Verifique se o comando slash existe no Slack e se você está enviando o comando que a caixa de diálogo das configurações mostrou — um admin pode tê-lo renomeado, e nesse caso a caixa de diálogo mostra o nome atual.
