Cada guia resolve **um problema para quem já conhece bem o produto**. Eles pressupõem
que você tem o Control Center instalado e um espaço de trabalho configurado, enunciam um
objetivo no título e terminam quando o objetivo é atingido.

Se você ainda está aprendendo o produto, comece pelos [tutoriais](/pt-BR/manual/tutoriais/).
Se você quer entender _por que_ algo se comporta de determinada maneira, leia os
[conceitos](/pt-BR/manual/conceitos/).
