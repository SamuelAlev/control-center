Cole uma chave de API do Linear no servidor vinculada ao seu usuário, do mesmo
modo que você conecta um forge. Tickets, projetos, vínculos, colaboradores,
delegação e atribuição funcionam com o banco de dados do próprio Control Center,
sem exigir nenhum serviço externo — consulte
[Criar e gerenciar tickets](/pt-BR/manual/guias/gerenciar-tickets/).

## Armazenar sua chave do Linear

A **Chave de API de tickets** fica em **Configurações → Espaço de trabalho →
Geral**, no cartão **Tickets**. Ela armazena a chave no servidor vinculada ao seu
id de usuário. A própria chave do servidor para trabalho que nenhuma pessoa
pediu vem da variável `LINEAR_API_KEY` ou do cartão **Apps do fornecedor**.
Nenhuma chave de tickets é colocada no sandbox de um agente: os agentes escrevem
tickets pelas próprias ferramentas do Control Center, que perguntam primeiro à
regra **Escrever em um rastreador externo**.

## Marcar novos tickets como Linear

O **Provedor de tickets** (primeiro passo do onboarding e
`/workspaces/<workspaceId>/api-keys`) oferece `local` e `linear`. Escolher
`linear` grava `provider: linear` nos tickets que você criar a partir daí.
