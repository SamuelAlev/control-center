As páginas de referência descrevem **o que existe**, de forma exaustiva e sem
comentários. Use-as para consultar algo quando você já sabe o que procura: o nome exato de
uma ferramenta, um tipo de etapa, uma transição de status, uma rota, um atalho.

Elas não foram escritas para serem lidas do início ao fim. Para isso, use os
[conceitos](/pt-BR/manual/conceitos/); para realizar uma tarefa, use os
[guias práticos](/pt-BR/manual/guias/).

## A superfície do produto

- [Ferramentas MCP](/pt-BR/manual/referencia/ferramentas-mcp/) — todas as ferramentas que o servidor MCP registra, por família
- [Ferramentas de agente integradas](/pt-BR/manual/referencia/ferramentas-de-agente/) — ferramentas de harness vinculadas ao servidor (LSP, AST, debug, eval, vibe)
- [Comandos slash](/pt-BR/manual/referencia/comandos-slash/) — builtins do composer, `/skill:` e comandos do usuário
- [Mapa de rotas](/pt-BR/manual/referencia/mapa-de-rotas/) — todas as telas e a URL que leva até elas
- [Atalhos de teclado](/pt-BR/manual/referencia/atalhos-de-teclado/) — o registro completo de keybindings
- [Eventos de domínio](/pt-BR/manual/referencia/eventos-de-dominio/) — todos os eventos publicados no barramento de domínio
- [Rigs](/pt-BR/manual/referencia/rigs/) — todas as superfícies de rig, verbos de ação, estados do ciclo de vida, portas e padrões
