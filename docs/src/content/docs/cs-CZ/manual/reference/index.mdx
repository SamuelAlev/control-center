Referenční stránky popisují, **co tam je**, úplně a bez komentáře. Použij
je k dohledání, když už víš, co hledáš: přesný název nástroje,
druh kroku, přechod stavu, trasu, zkratku.

Nejsou napsané k čtení od začátku do konce. K tomu použij
[koncepty](/cs-CZ/prirucka/koncepty/); když chceš něco udělat, použij
[návody](/cs-CZ/prirucka/navody/).

## Plocha produktu

- [Nástroje MCP](/cs-CZ/prirucka/referencni-prirucka/nastroje-mcp/) — každý nástroj, který server MCP registruje, podle rodiny
- [Vestavěné nástroje agentů](/cs-CZ/prirucka/referencni-prirucka/nastroje-agentu/) — nástroje harnessu vázané na server (LSP, AST, debug, eval, vibe)
- [Slash příkazy](/cs-CZ/prirucka/referencni-prirucka/slash-prikazy/) — vestavěné příkazy composeru, `/skill:` a uživatelské příkazy
- [Mapa tras](/cs-CZ/prirucka/referencni-prirucka/mapa-tras/) — každá obrazovka a URL, která na ni vede
- [Klávesové zkratky](/cs-CZ/prirucka/referencni-prirucka/klavesove-zkratky/) — úplný registr klávesových zkratek
- [Doménové události](/cs-CZ/prirucka/referencni-prirucka/domenove-udalosti/) — každá událost publikovaná na doménové sběrnici
- [Stanice](/cs-CZ/prirucka/referencni-prirucka/stanice/) — každá plocha stanice, sloveso akce, stav životního cyklu, port a výchozí hodnota
