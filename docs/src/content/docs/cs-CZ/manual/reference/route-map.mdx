## Shell aplikace

Shell aplikace (`ControlCenterLayout`) obaluje každou trasu uvnitř pracovního prostoru přes `ShellRoute`. **Každá destinace ve shellu má prefix pracovního prostoru — `/workspaces/:workspaceId/…` — a id pracovního prostoru v URL je jediný zdroj pravdy pro aktivní pracovní prostor.** Prefix nemají jen plochy před kontextem: `/splash`, `/onboarding`, `/signed-out` a holý výběr `/workspaces`, všechny přes celou obrazovku a mimo shell.

Brána je hotová, když je připojená aspoň jedna forge **pro přihlášeného uživatele** a existuje aspoň jeden pracovní prostor.

Chybějící přihlašovací údaj a chybějící nastavení jsou různé obrazovky a rozlišuje je `users.onboarding_finished_at` přečtené z vlastního `identity.me` volajícího — nikdy „pracovní prostory existují“, což je špatně v okamžiku, kdy tě někdo pozve do pracovního prostoru, který jsi nezaložil. Bez připojené forge jde účet, který úvodní nastavení dokončil, na `/signed-out`, aby se znovu ověřil; účet, který ho nedokončil, jde na `/onboarding`. Dokud je příznak pořád neznámý, stráž podrží startovací obrazovku a nehádá, protože z úvodního nastavení se ven nikdy nepřesměrovává.

## Trasy bez prefixu

| Cesta                      | Obrazovka                                                                                                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/splash`                  | Startovací obrazovka, která vyhodnotí bránu úvodního nastavení                                                                                                        |
| `/onboarding`              | Připoj forge, založ pracovní prostor nebo se k němu připoj, sandbox, výchozí adaptér a pak hlas. Krok pracovního prostoru odpadne, když účet už do nějakého patří |
| `/signed-out`              | Nové ověření: stejná karta připojení forge, kterou vykresluje Nastavení, bez lišty kroků a bez tlačítka Pokračovat — router odejde sám, jakmile se forge ohlásí   |
| `/workspaces`              | Seznam a výběr pracovních prostorů                                                                                                                                     |
| `/workspaces/:workspaceId` | Přesměruje na `/workspaces/:workspaceId/inbox`                                                                                                                         |

## Trasy pracovního prostoru

Cesty níže vynechávají prefix `/workspaces/:workspaceId`.

| Cesta                                   | Parametry dotazu                   | Obrazovka                                                                                                                                                                    |
| --------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/inbox`                                | —                                  | Sjednocená doručená pošta: PR roztříděné podle životního cyklu revize a práce mimo PR, která operátora blokuje. Cílová trasa po bráně; holé `/workspaces/:workspaceId` sem přesměruje |
| `/spaces`                               | —                                  | Plocha prostorů, žádný prostor není vybraný                                                                                                                                  |
| `/spaces/:spaceId`                      | `?m=<messageId>`, `?tab=<key>`     | Jeden prostor; `m` vede přímo na zprávu a při otevření se spotřebuje jednou                                                                                                 |
| `/tickets`                              | —                                  | Nástěnka ticketů                                                                                                                                                             |
| `/tickets/:ticketId`                    | —                                  | Ticket v rozložení seznam a detail                                                                                                                                          |
| `/projects/:projectId`                  | —                                  | Přehled projektu                                                                                                                                                             |
| `/pull-requests`                        | `?repo=<owner/name>`               | Seznam PR; `repo` v levé liště vybere ten repozitář                                                                                                                          |
| `/pull-requests/compose`                | `?space=<spaceId>`                 | Sestavení nového pull requestu; `space` určí prostor, jehož izolovaný worktree dodá větev                                                                                   |
| `/pull-requests/:owner/:repo/:prNumber` | `?tab=<key>`, `?comment=<id>`      | Detail PR s prohlížečem diffu; `comment` je číselné REST id jednoho komentáře                                                                                               |
| `/pipelines`                            | —                                  | Seznam běhů pipeline                                                                                                                                                         |
| `/pipelines/run`                        | `?templateId=<id>`                 | Ruční spouštěč běhu                                                                                                                                                          |
| `/pipelines/:runId`                     | —                                  | Detail běhu pipeline (časová osa kroků)                                                                                                                                      |
| `/plans`                                | —                                  | Přehled Plan Studio: aktivní plány, dokumenty plánů, playbooky                                                                                                              |
| `/plans/:kind/:id`                      | —                                  | Plan Studio pro jeden plán; `kind` je `orchestration` nebo `document`                                                                                                       |
| `/meetings`                             | —                                  | Seznam schůzek                                                                                                                                                               |
| `/meetings/record`                      | —                                  | Obrazovka živého nahrávání schůzky                                                                                                                                           |
| `/meetings/:meetingId`                  | —                                  | Detail schůzky: poznámky, přepis, akční položky, rozhodnutí                                                                                                                 |
| `/calendar`                             | —                                  | Kalendář: zobrazení měsíce, týdne a agendy                                                                                                                                   |
| `/calendar/:eventId`                    | —                                  | Detail události kalendáře (sourozenecká trasa; sdílí klíč stránky kalendáře)                                                                                                |
| `/newsfeed`                             | —                                  | Seznam kanálu novinek                                                                                                                                                        |
| `/newsfeed/article/:articleId`          | —                                  | Čtečka článku                                                                                                                                                                |
| `/observability`                        | —                                  | Přehled Observabilita: záložky Využití, Přehledy, Živé a Kvalita nad protokolem běhů pracovního prostoru. Výchozí je záložka Využití                                       |
| `/users/:login`                         | —                                  | Profil uživatele GitHub                                                                                                                                                      |
| `/teams/:organization/:slug`            | —                                  | Profil týmu organizace GitHub                                                                                                                                                |
| `/api-keys`                             | —                                  | Správa API klíčů. **Žádný vstup z navigace** — dostaneš se sem jen přes URL                                                                                                 |
| `/settings/…`                           | —                                  | Obrazovky nastavení (níže)                                                                                                                                                   |

Konverzace a vlákna **nemají vlastní trasu** — vlákno je konverzace uvnitř `/spaces/:spaceId`, otevřená jako karta editoru, bez vlastní adresy v URL.

**Trasa `/dashboard` neexistuje** a neexistuje ani obrazovka dashboardu. Analytická plocha je `/observability`, ze zápatí postranního panelu.

**Položka „Plány“ v postranním panelu není.** Plan Studio se otevře jako karta editoru z řádku plánu v konverzaci, která ho vytvořila; `/plans` a `/plans/:kind/:id` jsou hluboké odkazy.

`/observability` a `/pull-requests/compose` nemají záznam v registru názvů tras ani v registru drobečkové navigace, takže obě v titulku okna ukážou jen holý název aplikace a žádnou drobečkovou navigaci.

## Trasy nastavení

`/settings` přesměruje na `/settings/you/appearance`. Tlačítko nastavení v postranním panelu i `Cmd/Ctrl + ,` vedou na `/settings/you/appearance`.

Cesty nastavení jsou členěné podle **rozsahu** — `you/`, `workspace/`, `server/` — protože segment říká, koho změna zasáhne. Dvě cesty jsou starší než tohle členění a v URL rozsah nemají: `/settings/memory` a `/settings/pipelines`.

### Vy

| Cesta                         | Obrazovka                                                              |
| ----------------------------- | ---------------------------------------------------------------------- |
| `/settings/you/appearance`    | Motiv, jazyk, typografie, motiv editoru (výchozí obrazovka nastavení) |
| `/settings/you/notifications` | Přepínače podle události, tiché hodiny                                |
| `/settings/you/keybindings`   | Přehled klávesových zkratek (jen ke čtení)                             |
| `/settings/you/audio`         | Mikrofon, diktování, zjišťování schůzek a výstup soundscape           |
| `/settings/you/devices`       | Spárované telefony a vzdálené ovládání                                |
| `/settings/you/newsfeed`      | Správa kanálu novinek: zdroje, obnovení, stav přečtení                |

### Pracovní prostor

| Cesta                              | Obrazovka                                                                                                |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `/settings/workspace/profile`      | Profil a identita v tomto pracovním prostoru: jméno, autor Git, hostování kódu, kalendář                |
| `/settings/workspace/general`      | Název, logo, vyloučení cest k tajemstvím, souběh kontrol, pojmenování větví, zdraví synchronizace, mosty chatu, nebezpečná zóna |
| `/settings/workspace/meetings`     | Šablony poznámek ze schůzek a uložené hlasové profily                                                    |
| `/settings/workspace/members`      | Seznam členů, pozvánky, auditní stopa. Auditní stopa se stránkuje volitelným `?cursor=`                  |
| `/settings/workspace/repositories` | Repozitáře zaregistrované v tomto pracovním prostoru                                                     |
| `/settings/workspace/agents`       | Zaregistrované identity agentů                                                                           |
| `/settings/workspace/skills`       | Konfigurace dovedností                                                                                   |
| `/settings/memory`                 | Paměť pracovního prostoru: fakta, politiky, graf znalostí                                                |
| `/settings/workspace/permissions`  | Oprávnění agentů: matice guardrailů a sonda Co kdyby?                                                    |
| `/settings/pipelines`              | Šablony pipeline                                                                                         |
| `/settings/pipelines/:templateId`  | Editor šablony pipeline (plátno s přetahováním)                                                          |

### Server

| Cesta                          | Obrazovka                                                                                          |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| `/settings/server/connection`  | Připojení a stav                                                                                   |
| `/settings/server/sso`         | Jednotné přihlášení (SAML, OIDC, provisioning SCIM)                                                |
| `/settings/server/providers`   | Poskytovatelé modelů a adaptéry                                                                    |
| `/settings/server/mcp`         | Vestavěné a externí servery MCP                                                                    |
| `/settings/server/voice`       | Hlasové a schůzkové modely (ASR, diarizace)                                                        |
| `/settings/server/rigs`        | Stanice: co na tomhle hostiteli může naběhnout, základní obrazy, vlastní obrazy, běžící stroje   |
| `/settings/server/sandbox`     | Povolení spustitelných souborů v sandboxu: programy, které agenti smí spouštět ze své pracovní kopie tvých repozitářů |
| `/settings/server/diagnostics` | Diagnostika a soukromí: sandboxování, embeddingy, synchronizační engine, protokolování, hlášení pádů |
| `/settings/server/backup`      | Záloha a obnovení: snímky instalace, export po pracovních prostorech, import a smazání            |
| `/settings/server/about`       | O aplikaci a aktualizace                                                                           |

`kSettingsNav` v `lib/features/settings/settings_nav.dart` je pro tenhle seznam jediný zdroj pravdy. `settings_nav_test.dart` hlídá jedinečná id, jedinečné trasy, zploštělé pořadí J/K a tři rozsahy. Každou zaregistrovanou `GoRoute` neprochází.
