Zkratky vycházejí z jednoho registru `const`, `KeybindingRegistry` v `lib/core/constants/keybindings.dart`. Je v něm **49 vazeb**. Nastavení → Vy → Klávesové zkratky ten registr vykreslí jako **referenci jen ke čtení**: zkratky nejdou přemapovat a uživatelský soubor zkratek neexistuje.

`Cmd` níže je hlavní modifikátor příkazu — ⌘ na macOS, Ctrl na Windows a Linuxu. Vazba se spustí jen tehdy, když má její příkaz na aktuální obrazovce zaregistrovaný handler a platí její klauzule `when`. `!textInputFocus` znamená, že se klávesa předá zaměřenému textovému poli.

Zkratka pro přechod číslicí neexistuje. K doručené poště, ticketům, pull requestům a ostatním plochám se jde z postranního panelu nebo přes ⌘K. Observabilita zkratku nemá.

## Globální (19)

Rozsah `global`, takže platí kdekoli v shellu aplikace.

## Seznam pull requestů (3)

Rozsah `/pull-requests`. Všechny vyžadují `route == '/pull-requests'` a žádné zaměřené textové pole, takže se nespustí, dokud je nad seznamem otevřená trasa detailu PR.

| Zkratka | Akce                    |
| ------- | ----------------------- |
| `R`     | Obnovit                 |
| `Enter` | Otevřít PR              |
| `F`     | Otevřít nabídku filtrů  |

`Enter` (`pr.list-open`) je v registru a na referenci zkratek se ukáže, ale **obrazovka seznamu pro něj neregistruje handler**, takže se teď nespustí. `F` otevírá nabídku filtrů (`pr.list-open-filter`), hledání ne.

## Detail pull requestu (2)

Rozsah `/pull-requests/`. Obnovení vyžaduje, aby nebylo zaměřené textové pole. Zavření karty nemá pojistku proti textovému vstupu (úhoz s ⌘ nikdy není prostý text) a má regulární výraz trasy, takže se na seznamu nespustí.

| Zkratka        | Akce         | Podmínka                        |
| -------------- | ------------ | ------------------------------- |
| `R`            | Obnovit      | Mimo textové pole               |
| `Cmd/Ctrl + W` | Zavřít kartu | Na trase `/pull-requests/<…>`   |

Přepínání karet (`1`/`2`/`3`), prohlédnutí a sbalení souboru (`V`/`C`), seznam souborů (`T`) a hledání v diffu (`Cmd/Ctrl + F`) obsluhuje vlastní handler prohlížeče diffů — viz [Klávesy prohlížeče diffů mimo registr](#klávesy-prohlížeče-diffů-mimo-registr).

## Profily uživatelů a týmů GitHub (3)

Rozsah `/users/`. Klauzule `when` je regulární výraz na `/users/<login>` **nebo** `/teams/<organization>/<slug>`, plus žádné zaměřené textové pole.

| Zkratka        | Akce             |
| -------------- | ---------------- |
| `R`            | Obnovit          |
| `/`            | Zaměřit hledání  |
| `Cmd/Ctrl + F` | Zaměřit hledání  |

## Prostory (9)

Rozsah `/spaces`. Klauzule `when` používají regulární výraz, takže se spustí jak na seznamu prostorů (`/spaces`), tak ve vybraném prostoru (`/spaces/<id>`).

| Zkratka                | Akce                   | Podmínka          |
| ---------------------- | ---------------------- | ----------------- |
| `Enter`                | Odeslat zprávu         | —                 |
| `Cmd/Ctrl + N`         | Nový prostor           | Na trase `/spaces` |
| `J`                    | Další prostor          | Mimo textové pole |
| `K`                    | Předchozí prostor      | Mimo textové pole |
| `Cmd/Ctrl + Shift + D` | Stisknout a mluvit     | —                 |
| `Cmd/Ctrl + T`         | Otevřít editor         | Na trase `/spaces` |
| `Cmd/Ctrl + W`         | Zavřít kartu           | Na trase `/spaces` |
| `Cmd/Ctrl + B`         | Přepnout postranní panel | Na trase `/spaces` |
| `Cmd/Ctrl + P`         | Přejít na soubor         | Na trase `/spaces` |

Přejít na soubor otevře výběr ze souborů konverzace. Když nic nenapíšeš, zobrazí naposledy otevřené soubory; psaním prohledáš všechny soubory ve worktree konverzace. `Enter` otevře vybraný soubor na nové kartě, `Cmd/Ctrl + Enter` nebo tlačítko rozdělení na řádku ho otevře v podokně vpravo a `×` na řádku nedávného souboru ho ze seznamu odebere.

Odeslání Enterem patří textovému poli composeru. Stisknout a mluvit patří tlačítku mikrofonu v composeru (vlastní handler hardwarové klávesnice). Obojí je v registru kvůli referenci v nastavení.

## Klávesy prohlížeče diffů mimo registr

Prohlížeč diffu PR je obsluhuje sám (`PrDiffKeyboardHandler`). Hledání, prohlédnutí a sbalení jsou v komentářích registru jen kvůli referenci v nastavení — zaregistrovaný handler dispečera není, takže je dispečer nechá prohlížeči diffu. Na referenci zkratek nemají vlastní řádky.

| Zkratka         | Akce                                                      |
| --------------- | --------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Hledat v diffu                                            |
| `J` / `K`       | Další / předchozí soubor                                  |
| `V`             | Přepnout prohlédnutí zaměřeného souboru                   |
| `C`             | Přepnout sbalení zaměřeného souboru                       |
| `T`             | Zobrazit seznam souborů                                   |
| `Enter`         | Další shoda hledání (jen dokud je hledání v diffu otevřené) |
| `Shift + Enter` | Předchozí shoda hledání                                   |
| `Escape`        | Zavřít hledání v diffu, nebo zrušit výběr textu v diffu   |
| `Cmd/Ctrl + C`  | Zkopírovat výběr v diffu                                  |

## Kombinace vyhrazené prohlížeči

Na webovém sestavení prohlížeč některé akcelerátory spotřebuje dřív, než je stránka uvidí, takže odpovídající zkratky se tam nikdy nespustí. Na počítači fungují normálně. Vyhrazené v kombinaci s hlavním modifikátorem příkazu: `T`, `W`, `N` a číslice `1`–`9`.

Tím se pokryje přepínání pracovních prostorů `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nový prostor, nový pracovní prostor, nový agent, přidání repozitáře) a `Cmd/Ctrl + T` / `Cmd/Ctrl + W` v prostorech a v detailu PR.
