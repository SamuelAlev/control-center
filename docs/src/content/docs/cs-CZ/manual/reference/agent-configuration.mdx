Tahle stránka vypisuje všechna pole entity agenta a enumy a příznaky, se kterými pracuje. Jak agenta v aplikaci krok za krokem založit nebo upravit, popisuje [Vytvořte a nakonfigurujte agenta](/cs-CZ/prirucka/navody/vytvoreni-agenta/).

## Pole entity agenta

| Pole                    | Typ                    | Povinné | Popis                                                                                                                                                                      |
| ----------------------- | ---------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ano     | Jedinečný identifikátor agenta                                                                                                                                             |
| `name`                  | `String`               | Ano     | Krátký identifikátor pro zmínky @                                                                                                                                          |
| `title`                 | `String`               | Ano     | Lidsky čitelný název pozice                                                                                                                                                |
| `agentMdPath`           | `String`               | Ano     | Absolutní cesta k definičnímu souboru `.md` agenta                                                                                                                         |
| `workspaceId`           | `String`               | Ano     | Vlastnící pracovní prostor (není null)                                                                                                                                     |
| `reportsTo`             | `String?`              | Ne      | Id nadřízeného agenta                                                                                                                                                      |
| `skills`                | `AgentSkills`          | Ano     | Množina identifikátorů skillů                                                                                                                                              |
| `persona`               | `String?`              | Ne      | Volný text s pokyny k chování                                                                                                                                              |
| `systemPrompt`          | `String?`              | Ne      | Přepis výchozího systémového promptu                                                                                                                                       |
| `adapterId`             | `String?`              | Ne      | Id inferenčního adaptéru                                                                                                                                                   |
| `modelId`               | `String?`              | Ne      | Id modelu v rámci adaptéru                                                                                                                                                 |
| `strictMode`            | `bool`                 | Ne      | Výchozí `false`. Zapisuje se do řádku i do `AGENTS.md` agenta                                                                                                              |
| `effort`                | `String?`              | Ne      | Id úrovně uvažování (např. `'low'`, `'xhigh'`), brané z `thinkingLevels` vybraného modelu                                                                                  |
| `contextSize`           | `int?`                 | Ne      | Maximální velikost kontextového okna                                                                                                                                       |
| `role`                  | `AgentRole?`           | Ne      | Role agenta                                                                                                                                                                |
| `monthlyBudgetCents`    | `int`                  | Ne      | Měsíční strop útraty v centech (výchozí `0`, bez omezení)                                                                                                                  |
| `silenceTimeoutMinutes` | `int?`                 | Ne      | Přepis timeoutu ticha v minutách; musí být null, nebo v rozsahu 1–240 (kontrola v konstruktoru)                                                                           |
| `maxConcurrentTasks`    | `int`                  | Ne      | Výchozí `1`. Kapacita, kterou hlásí model přítomnosti (počty běžících a čekajících běhů se s ní porovnávají)                                                               |
| `visibility`            | `AgentVisibility`      | Ne      | Výchozí `workspace`                                                                                                                                                        |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Ne      | Stav správy (výchozí `active`). Zapisuje ho tvrdé zastavení rozpočtu a zobrazuje se v organizačním schématu i na soupisce přítomnosti. Odeslání od agenta ve stavu `paused` práci pořád bere |
| `budgetPolicyId`        | `String?`              | Ne      | Id sdílené politiky rozpočtu; při null platí přímo `monthlyBudgetCents`                                                                                                    |
| `runtimeProfileId`      | `String?`              | Ne      | Id vlastního profilu běhu                                                                                                                                                  |
| `createdAt`             | `DateTime`             | Ano     | Časové razítko vytvoření                                                                                                                                                   |

`name` i `title` musí být neprázdné (kontrola v konstruktoru). Výchozí
`monthlyBudgetCents` s hodnotou `0` znamená bez omezení. Strop se zapisuje přes `agents.upsert`.

## Oprávnění

Agent nemá žádné příznaky oprávnění. Push, otevírání a zveřejňování pull requestů, zápis do trackeru a odchozí síťový provoz jsou třídy akcí (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`), které [guardraily](/cs-CZ/prirucka/koncepty/guardraily/) vyhodnocují v rozsahu pracovního prostoru, agenta nebo prostoru. Token GitHub běhu má vždycky rozsah jen pro čtení; pushe jdou přes bránu běhů agentů, která se před předáním dál zeptá pravidla `gitPush`.

## AgentSkills

Neměnná množina identifikátorů skillů bez rozlišení velikosti písmen. Při odeslání se tyhle slugy synchronizují jako odkazy na skilly v overlay agenta a harness pak do promptu automaticky načte frontmatter nalinkovaných skillů.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (odvozený)

Neukládá se. Sedm hodnot. Pořadí deklarace je pořadí priority (`sortPriority`, zafixované testem) a podle něj se řadí soupiska:

| Stav        | `sortPriority` | Podmínka                                                                                                            |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Libovolný záznam běhu má stav `running`                                                                             |
| `blocked`   | 1              | Liveness posledního běhu je `blocked`, `stalled` nebo `looping`                                                     |
| `failed`    | 2              | Stav posledního běhu je `error`, nebo je jeho liveness `failed` či `dead`                                           |
| `queued`    | 3              | Běh je odeslaný, ale ještě neběží: čeká za jiným během téhož agenta, nebo je zapsaný a ještě se nespustil           |
| `succeeded` | 4              | Běh úspěšně skončil                                                                                                 |
| `idle`      | 5              | Agent už dřív běžel a nic nemá rozběhnuté                                                                           |
| `neverRun`  | 6              | Neexistuje žádný záznam běhu                                                                                        |

`queued` a `succeeded` platí **jen pro jeden běh**. `deriveAgentLiveState`, které pro agenta počítá stav soupisky, ani jedno z nich nikdy nevrátí: vrací `neverRun`, `running`, `failed`, `blocked` nebo `idle`.
