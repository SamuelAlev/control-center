Každý návod řeší **jeden problém pro toho, kdo se v produktu už vyzná**. Počítá s tím,
že máš nainstalovaný Control Center a založený pracovní prostor, v nadpisu pojmenuje
cíl a skončí, jakmile je cíl splněný.

Pokud produkt teprve poznáváš, začni [tutoriály](/cs-CZ/prirucka/tutorialy/).
Pokud chceš pochopit, _proč_ se něco chová tak, jak se chová, přečti si
[koncepty](/cs-CZ/prirucka/koncepty/).
