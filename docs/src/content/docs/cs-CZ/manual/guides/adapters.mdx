Tento návod ukazuje, jak připojit poskytovatele modelů a vybrat, na čem agent
běží.

Všechno je na jedné stránce: **Nastavení → Server → Poskytovatelé modelů**.
Položka v postranním panelu zní „Poskytovatelé modelů“, nadpis stránky zní
„Adaptéry“.

## Co je adaptér

Adaptér je _runner_, který provede tah agenta. Jsou dva a seznam je pevný:
třetího přidat nejde.

| Adaptér                   | CLI      | Přenos                                              |
| ------------------------- | -------- | --------------------------------------------------- |
| Control Center (built-in) | žádné    | Smyčka agenta v procesu, s poskytovateli mluví po HTTP |
| Claude Code               | `claude` | `claude -p --output-format stream-json`             |

Cursor, Codex, Anthropic, OpenAI a ostatní jsou **poskytovatelé** vestavěného
adaptéru, ne samostatná CLI. Přidat _jde_ dalšího poskytovatele, libovolný
endpoint kompatibilní s OpenAI nebo Anthropic. O tom je další část.

:::note[Detekce se ptá serveru, ne vašeho počítače]
Karta **Zjištění runneři** vypisuje, co `cc_server` našel na `PATH`
_hostitele serveru_. U tenkého nebo webového klienta je to jiný stroj než ten,
na který se díváte. CLI nainstalujte na stroj, na kterém běží `cc_server`.
:::

## Připojte poskytovatele modelu

Vestavěný adaptér potřebuje před spuštěním aspoň jednoho připojeného
poskytovatele. V katalogu jich je čtrnáct.

1. Jděte do **Nastavení → Server → Poskytovatelé modelů**
2. Sjeďte k **Poskytovatelé a modely**
3. Najděte svého poskytovatele a připojte ho:

| Poskytovatel                                                                                            | Jak připojit                                                                                                      |
| ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                               | API klíč. Předplatné Claude Pro/Max není přihlášení k API Anthropic. Pro tenhle tarif použijte adaptér Claude Code |
| OpenAI, Codex, Cursor                                                                                   | Přihlášení OAuth v prohlížeči, nebo API klíč. Codex je ChatGPT Plus/Pro přes backend Codex Responses, ne spuštění CLI |
| Kimi Code                                                                                               | Jen OAuth v prohlížeči, průběh s kódem zařízení. Jde o paušál, takže nemá cenu za token                            |
| OpenRouter, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API)       | API klíč                                                                                                          |

Kontrola: odznak řádku se změní na **Připojeno** a po rozbalení vypíše modely,
které poskytovatel nabízí, každý s cenou za milion tokenů a kontextovým oknem.

Tokeny OAuth se ukládají do vlastního úložiště přihlašovacích údajů serveru
a obnovují se před vypršením. Přihlašovací údaje poskytovatelů jsou
**globální pro hostitele**: sdílí je každý pracovní prostor v instalaci, nejsou
vázané na jeden.

### Přidejte vlastního poskytovatele

Hodí se pro Ollama, LM Studio, vLLM nebo soukromé nasazení.

1. V **Poskytovatelé a modely**, pod **Vlastní poskytovatelé**, stiskněte **Přidat poskytovatele**
2. Vyplňte **Název**, vyberte **Typ API** (**Kompatibilní s OpenAI** nebo
   **Kompatibilní s Anthropic**) a zadejte **Základní URL** (například
   `http://localhost:11434/v1`)
3. Přidejte **API klíč**, pokud ho endpoint vyžaduje, a stiskněte **Přidat poskytovatele**

Vlastní poskytovatel se objeví ve stejném seznamu a má tlačítko pro smazání,
které vestavění nemají.

## Vyberte agentovi model

1. Jděte do **Nastavení → Pracovní prostor → Agenti** a vyberte agenta
2. Na kartě **Nastavení** zvolte **Adaptér**
3. Z rozevíracího seznamu vedle něj vyberte **Model**

U vestavěného adaptéru se rozevírací seznam skládá za běhu z vlastního katalogu
každého připojeného poskytovatele. Poskytovatel bez uloženého přihlašovacího
údaje nepřidá ani jeden model. Prázdný seznam proto skoro vždy znamená „ještě
nic není připojené“, ne „nic není k dispozici“.

:::note[models.dev jen obohacuje, nikdy není zdrojem id]
Přibalený katalog [models.dev](https://models.dev) dodává cenu a kontextové
okno modelu, který už je v živém seznamu. Id modelu nikdy nepřidá. Když model,
který čekáte, chybí, endpoint poskytovatele ho nevrací.
:::

Id modelů vestavěného adaptéru mají tvar `provider/model` a mohou nést řetězec
záloh oddělený `|`. Při záloze se náklady účtují podle modelu, který tah
skutečně obsloužil, ne podle toho, o který jste požádali.

:::note[Agent bez adaptéru běží na vestavěné smyčce]
Každý pracovní prostor založí pět agentů, CEO a `qa`, `architect`, `engineer`
a `librarian`, bez adaptéru a bez modelu. Odeslání spadne zpět na
**Control Center (built-in)**, ne na nastavení **Výchozí runnery** na této
stránce. To je preference klienta, kterou cesta odeslání nikdy nečte. Záznam
běhu u těchto běhů zapíše `cc-harness`, takže přepis pojmenuje, co skutečně
běželo.

Když chybí i model, vestavěná smyčka si od Anthropic vyžádá jeho výchozí model.
Agent ponechaný úplně bez nastavení tedy běží, když máte připojený účet
Anthropic, a jinak spadne s `No credential for provider "anthropic"`.

Dokončení kroku s adaptérem v úvodním nastavení zpětně doplní **každého**
agenta, kterému pořád chybí adaptér nebo model, CEO i specialisty, ve všech
pracovních prostorech, které v tu chvíli existují, dvojicí, kterou jste vybrali.
Pracovní prostory vytvořené později pořád založí všech pět bez nastavení.
Adaptér a model nastavte výslovně u každého agenta, kterého chcete používat.
:::

## Nainstalujte CLI runneru

Vestavěný adaptér se neinstaluje. U Claude Code nainstalujte jeho
CLI **na hostiteli serveru** správcem balíčků toho nástroje, například:

```bash
npm install -g @anthropic-ai/claude-code
```

Pak nahoře na stránce stiskněte **Obnovit**. Každý nalezený řádek ukáže
zjištěnou verzi a cestu a štítky, jestli umí **Režim JSON** a **Výběr modelu**.

Externí CLI si drží vlastní přihlašovací údaje ve vlastní konfiguraci na
hostiteli serveru. Control Center je nespravuje.

:::caution[Další argumenty a proměnné prostředí zůstávají na tomto zařízení]
Každý řádek adaptéru nabízí pole **Další argumenty** a dialog **Proměnné prostředí**.
Tyto hodnoty se ukládají na vašem zařízení. Server čte argv a env při spuštění
z vlastního úložiště nastavení. Klíče poskytovatelů dejte na server (OAuth nebo
pole **API klíč** na stránce Poskytovatelé modelů), ne do těchto dvou polí.
:::

## Omezte, které poskytovatele smí pracovní prostor použít

Řízení poskytovatelů je po pracovních prostorech a rozhoduje poslední shoda.

1. V **Poskytovatelé a modely** vypněte na řádku poskytovatele přepínač **Povolit**

Tím se pro daného poskytovatele v aktivním pracovním prostoru zapíše pravidlo
`deny` a jeho modely z katalogu tohoto pracovního prostoru zmizí. Zapnutí
přepínače zpět pravidlo smaže.

## Řešení problémů

### Runner se ukazuje jako nenalezený

- Zkontrolujte, že CLI je na `PATH` **hostitele serveru**, ne jen na vašem
- Desktopová aplikace spuštěná z grafického rozhraní startuje server s minimálním `PATH`. CLI nainstalované jen na cestě, kterou vidí shell, pro ni může být neviditelné
- Po instalaci stiskněte **Obnovit**

### Rozevírací seznam modelů je prázdný

- Adaptér je vestavěný a žádný poskytovatel není připojený. Připojte ho v
  **Poskytovatelé a modely**
- Nebo je poskytovatel připojený, ale přepínač řízení tohoto pracovního prostoru ho zakazuje

### Model běží, ale cena se ukazuje jako neznámá

Živý seznam modelů nese id. Cenu a kontext dodává models.dev. Zcela nový model,
nebo model od vlastního poskytovatele, v katalogu ještě položku nemá.
