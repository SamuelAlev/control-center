Vlož na server API klíč Linear ke svému uživateli, stejně jako připojuješ
forge. Tickety, projekty, vazby, spolupracovníci, delegování a přiřazení
fungují nad vlastní databází Control Center a žádnou externí službu
nepotřebují. Viz
[Vytvářejte a spravujte tickety](/cs-CZ/prirucka/navody/sprava-ticketu/).

## Ulož klíč Linear

**API klíč ticketingu** je v **Nastavení → Pracovní prostor → Obecné**, na
kartě **Ticketing**. Klíč se uloží na server k tvému id uživatele. Vlastní
klíč serveru pro práci, o kterou nikdo nepožádal, bere `LINEAR_API_KEY` nebo
kartu **Aplikace poskytovatelů** a jako `TICKETING_API_KEY` se vloží jen
tehdy, když má ten agent schopnost **Povolit volání ticketing API**.

## Označ nové tickety jako Linear

**Poskytovatel ticketingu** (první krok onboardingu a
`/workspaces/<workspaceId>/api-keys`) nabízí `local` a `linear`. Když zvolíš
`linear`, na tickety, které od té chvíle vytvoříš, se zapíše `provider: linear`.
