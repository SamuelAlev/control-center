Tutoriály jsou **lekce**. Každá tě jednou cestou provede něčím skutečným od začátku
do konce a po cestě nic nerozhoduješ. Drž se kroků přesně a budou fungovat.

Jsou k orientaci v produktu. Až budeš vědět, jak je uspořádaný,
[návody](/cs-CZ/prirucka/navody/) jsou rychlejší cesta ke konkrétnímu úkolu.

Udělej je v tomhle pořadí — každý počítá s předchozím.

1. [Váš první pracovní prostor](/cs-CZ/prirucka/tutorialy/prvni-pracovni-prostor/) — založ pracovní prostor, přidej repozitář a podívej se na model izolace
2. [Odešlete prvního agenta](/cs-CZ/prirucka/tutorialy/prvni-agent/) — dej agentovi adaptér a model a pusť ho do práce
3. [Zkontrolujte první pull request](/cs-CZ/prirucka/tutorialy/prvni-pr/) — přečti diff, okomentuj ho a slouč
4. [Vytvořte první pipeline](/cs-CZ/prirucka/tutorialy/prvni-pipeline/) — zřetěz kroky do DAGu a spusť ji

Dva další stojí mimo tohle pořadí; kterýkoli z nich udělej, až budeš mít fungující pracovní prostor.

- [Propojte Slack s pracovním prostorem](/cs-CZ/prirucka/tutorialy/prvni-chatovy-most/) — řiď agenty z vlákna Slacku
- [Přihlaste tým přes SSO](/cs-CZ/prirucka/tutorialy/sso/) — připoj poskytovatele identity a projdi přihlášení od začátku do konce

:::note[Než začneš]
Nejdřív nainstaluj Control Center — viz [Instalace](/cs-CZ/prirucka/instalace/). Když chceš jen
nejkratší možnou cestu k běžícímu agentovi, vezmi si místo toho [rychlý start](/cs-CZ/prirucka/rychly-start/)
a sem se vrať potom.
:::
