Tohle je nejkratší úplná cesta od nuly k agentovi, který pracuje na tvém vlastním kódu. Jdi v tomhle pořadí. Každý krok stojí na tom předchozím.

Potřebuješ Git, účet GitHub a buď účet u poskytovatele modelů (Anthropic, OpenAI, Codex, Cursor, Kimi Code nebo libovolný poskytovatel s API klíčem), nebo už nainstalované CLI Claude Code. Zbytek se nastaví cestou.

## Krok 1: Nainstaluj a spusť

Nainstaluj Control Center podle [Instalace](/cs-CZ/prirucka/instalace/) a otevři ho.

Při prvním spuštění se desktop zeptá **„Jak má Control Center běžet?“** Zvol **Spustit v této aplikaci**. Control Center na tomhle stroji spustí headless `cc_server`, který vlastní tvoje data a dělá všechnu práci. Neuvidíš ho. Místo toho se otevře obrazovka úvodního nastavení.

:::note[Nechceš nic instalovat?]
Ta samá aplikace běží v prohlížeči na [app.usectrl.dev](https://app.usectrl.dev) se
stejnými funkcemi. Karta prohlížeče server hostovat neumí, takže ho dodáš ty:
spusť `cc_server` lokálně a připoj se na `ws://localhost:9030`, nebo aplikaci namiř na
server na jiném stroji. Tenhle rychlý start jde cestou desktopu, protože server
nastavovat nemusíš. Cestu prohlížečem popisuje
[Instalace](/cs-CZ/prirucka/instalace/#použij-ho-v-prohlížeči).
:::

## Krok 2: Projdi úvodní nastavení

Úvodní nastavení má pět kroků a jdou po řadě. Dopředu se přeskočit nedá.

1. **Připojit**: přihlas se přes GitHub, nebo vlož osobní přístupový token s oprávněními `repo` a `read:org`. Pověření se uloží na server a připojí se k tvému účtu.
2. **Pracovní prostor**: pojmenuj první pracovní prostor a volitelně vyber logo. Jeho vytvoření založí pět agentů, CEO a `qa`, `architect`, `engineer` a `librarian`, a vestavěné šablony pipeline.
3. **Sandbox**: zapíše preferenci sandboxu. Pokračovat jde po obou volbách.
4. **Adaptér**: vyber adaptér a model, které mají mít agenti jako výchozí. Zvol **Control Center (built-in)** a ve výběru poskytovatele, který se objeví, se přihlas k poskytovateli modelů. Seznam modelů zůstane prázdný, dokud jednoho nepřipojíš. Dokončení tohohle kroku zapíše adaptér a model i agentovi CEO v pracovním prostoru.
5. **Hlas (volitelné)**: nainstaluj řečový model na zařízení pro diktování, nebo krok přeskoč.

Control Center pak otevře doručenou poštu pracovního prostoru.

:::note[Co omezuje běh agenta]
Příkazy agenta se obalí nativním sandboxem operačního systému hostitele, když je k dispozici: Seatbelt na macOS, bubblewrap na Linuxu. Windows backend nemá, takže tam běhy drží jen ostatní vrstvy. Vlastní worktree konverzace (`git worktree` na Windows; copy-on-write tam, kde je `rift`), pověření vydaná při spuštění a odebraná při úklidu a guardraily akcí. Viz [Sandbox a zabezpečení](/cs-CZ/prirucka/koncepty/sandbox-a-zabezpeceni/).
:::

## Krok 3: Přidej repozitář

Jdi do **Nastavení → Pracovní prostor → Repozitáře** a klepni na **Přidat repozitář**.

Dialog prochází složky na stroji, kde běží server, ne na tvém klientovi, a drží se kořenů, které server smí vystavit (ve výchozím stavu domovský adresář jeho uživatele). Zaškrtávací pole dostane jen git checkout. Zaškrtni svůj a zaregistruj ho.

Checkout se přijme, jen když leží v pracovním stromu gitu, má remote `origin` a ten míří na podporovaný forge: github.com, gitlab.com nebo bitbucket.org. Všechno ostatní se odmítne i s důvodem.

Repozitáře patří k pracovnímu prostoru: registrace checkoutu ho vloží do _tohoto_ pracovního prostoru. Samostatný krok propojení není.

## Krok 4: Dej agentovi adaptér a model

Jdi do **Nastavení → Pracovní prostor → Agenti**. V soupisce vyber agenta `engineer`.

Na kartě **Nastavení** nastav:

- **Adaptér**: `Control Center (built-in)`
- **Model**: vyber jeden od poskytovatele, kterého jsi připojil v úvodním nastavení

Stiskni **Uložit změny**.

V praxi tenhle krok vynechat nejde. Adaptér zvolený při úvodním nastavení zdědí jen agent CEO. Čtyři specialisté vzniknou bez něj. Spadnou zpět na **Control Center (built-in)** s výchozím modelem Anthropic, takže běží jen s připojeným účtem Anthropic, a když ho máš, tak na modelu, který sis nevybral.

## Krok 5: Pošli agentovi úkol

1. V postranním panelu najdi sekci **Prostory** a klepni na tlačítko **+**.
2. Pojmenuj prostor, pod **Přidat agenty** přidej agenta `engineer` a vytvoř ho.
3. Napiš konkrétní malý úkol nad repozitářem, který jsi zaregistroval, a stiskni Enter.

Control Center pro tuhle konverzaci připraví copy-on-write worktree repozitářů pracovního prostoru, složí prompt z role, persony a skillů agenta a z kontextu prostoru a odešle běh. Zdrojového checkoutu se nedotkne.

## Krok 6: Sleduj, jak pracuje

Mělo by se stát tohle, v tomhle pořadí:

- Tlačítko odeslání v composeru se změní na **Zastavit**, protože v téhle konverzaci pracuje agent
- Do přepisu se streamuje uvažování agenta, volání nástrojů a text
- Po skončení běhu se tlačítko odeslání vrátí

Pak otevři **Nastavení → Pracovní prostor → Agenti**, vyber agenta a podívej se na kartu **Protokoly**: jeden řádek běhu se stavem, dobou trvání, časy začátku a konce a adaptérem, na kterém běžel.

To je ta smyčka. Všechno ostatní v Control Center, revize pull requestů, pipelines, tickety, schůzky i Slack, z ní vychází.
