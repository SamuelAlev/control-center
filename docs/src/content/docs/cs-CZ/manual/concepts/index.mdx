Tyto stránky vysvětlují, **jak Control Center funguje a proč**. Jsou k pochopení,
ne k provedení: žádná z nich není postup k následování. Až budete chtít splnit
konkrétní úkol, přejděte k [návodům](/cs-CZ/prirucka/navody/); až budete chtít
něco dohledat, přejděte do [referenční příručky](/cs-CZ/prirucka/referencni-prirucka/).

Čtěte je v libovolném pořadí. Pokud jste tu noví, začněte základním modelem.

## Základní model

Čtyři myšlenky, na kterých stojí všechno ostatní.

- [Pracovní prostory a izolace](/cs-CZ/prirucka/koncepty/pracovni-prostory/) — hranice tenanta a proč ji vynucuje uspořádání databáze místo kázně v dotazech
- [Model agentů](/cs-CZ/prirucka/koncepty/model-agentu/) — z čeho se agent skládá: identita, role, skilly, schopnosti, adaptér a model
- [Životní cyklus odeslání agenta](/cs-CZ/prirucka/koncepty/zivotni-cyklus-odeslani/) — co se stane mezi vaší zprávou a prvním tokenem agenta
- [Režimy](/cs-CZ/prirucka/koncepty/rezimy/) — jak `chat`, `plan`, `review` a `orchestrate` mění, co agent smí
- [Kontext nástrojů a cache promptů](/cs-CZ/prirucka/koncepty/kontext-nastroju/) — proč agent vidí jen část svých nástrojů, jak dosáhne na zbytek a co udržuje cache poskytovatele teplou
- [Inteligence kódu](/cs-CZ/prirucka/koncepty/inteligence-kodu/) — graf kódu, language server, strukturální vyhledávání a debugger
- [Historie konverzací](/cs-CZ/prirucka/koncepty/historie-konverzaci/) — ukládání, zhutnění a větvení přepisu

## Bezpečnost a řízení

Čeho se agent smí dotknout a kdo o tom rozhoduje.

- [Sandbox a zabezpečení](/cs-CZ/prirucka/koncepty/sandbox-a-zabezpeceni/) — co běh agenta dnes skutečně omezuje
- [Guardraily](/cs-CZ/prirucka/koncepty/guardraily/) — jeden engine politik pro každou akci měnící stav a jak se pravidlo vyhodnotí
- [Autorizace](/cs-CZ/prirucka/koncepty/autorizace/) — role, katalog oprávnění a auditní stopa
- [Stanice a izolovaná prostředí](/cs-CZ/prirucka/koncepty/stanice/) — proč agenti dostanou jednorázové VM místo vašeho počítače a kde hranice skutečně je

## Řízení práce

Jak se ze záměru stane hotová práce.

- [Tickety a delegování](/cs-CZ/prirucka/koncepty/tickety/) — na dodavateli nezávislá jednotka práce, kterou sdílí celá flotila
- [Pipelines a automatizace](/cs-CZ/prirucka/koncepty/pipelines/) — DAG postupy, spouštěče a běhy, které lze obnovit
- [Orchestace](/cs-CZ/prirucka/koncepty/orchestrace/) — jeden cíl, jedno schválení, vygenerovaná pipeline
- [AI kontrola](/cs-CZ/prirucka/koncepty/ai-kontrola/) — jak se z PR stane zkontrolovaný: prostory kontroly, shoda recenzentů, osy a verdikt Ship/Hold/Block
- [Konverzace v PR](/cs-CZ/prirucka/koncepty/konverzace-v-pr/) — odpověď na zmínku na GitHubu nebo na štítek `ai-review` přímo z hostitele kódu
- [Paměť a znalosti](/cs-CZ/prirucka/koncepty/pamet-a-znalosti/) — fakta, politiky a to, co agent smí vědět
- [Evaly a kvalita](/cs-CZ/prirucka/koncepty/evaly-a-kvalita/) — sady eval a záložka Kvalita
