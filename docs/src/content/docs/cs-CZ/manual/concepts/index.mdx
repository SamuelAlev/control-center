These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/cs-CZ/prirucka/navody/); when you want to look
something up, go to the [reference](/cs-CZ/prirucka/referencni-prirucka/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/cs-CZ/prirucka/koncepty/pracovni-prostory/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/cs-CZ/prirucka/koncepty/model-agentu/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/cs-CZ/prirucka/koncepty/zivotni-cyklus-odeslani/) — what happens between your message and the agent's first token
- [Modes](/cs-CZ/prirucka/koncepty/rezimy/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/cs-CZ/prirucka/koncepty/kontext-nastroju/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/cs-CZ/prirucka/koncepty/inteligence-kodu/) — the code graph, language server, structural search and debugger
- [Conversation history](/cs-CZ/prirucka/koncepty/historie-konverzaci/) — persistence, compaction and forking a transcript
