Referensi ini mencantumkan setiap bidang pada entitas agen, beserta enum dan flag yang digunakannya. Untuk panduan langkah demi langkah dalam membuat atau mengedit agen di aplikasi, lihat [Buat dan konfigurasi agen](/id-ID/panduan-pengguna/panduan-praktis/buat-agen/).

## Bidang entitas agen

| Bidang                  | Tipe                   | Wajib | Deskripsi                                                                                                                                                                                           |
| ----------------------- | ---------------------- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ya    | Pengenal unik agen                                                                                                                                                                                  |
| `name`                  | `String`               | Ya    | Pengenal pendek untuk @-mention                                                                                                                                                                     |
| `title`                 | `String`               | Ya    | Judul peran yang terbaca manusia                                                                                                                                                                    |
| `agentMdPath`           | `String`               | Ya    | Jalur absolut ke file definisi `.md` agen                                                                                                                                                           |
| `workspaceId`           | `String`               | Ya    | Ruang kerja pemilik (tidak boleh null)                                                                                                                                                              |
| `reportsTo`             | `String?`              | Tidak | ID agen induk                                                                                                                                                                                       |
| `skills`                | `AgentSkills`          | Ya    | Kumpulan pengenal skill                                                                                                                                                                             |
| `persona`               | `String?`              | Tidak | Instruksi perilaku berupa teks bebas                                                                                                                                                                |
| `systemPrompt`          | `String?`              | Tidak | Menimpa prompt sistem bawaan                                                                                                                                                                        |
| `adapterId`             | `String?`              | Tidak | ID adapter inferensi                                                                                                                                                                                |
| `modelId`               | `String?`              | Tidak | ID model di dalam adapter                                                                                                                                                                           |
| `strictMode`            | `bool`                 | Tidak | Default `false`. Dituliskan ke baris dan ke `AGENTS.md` agen                                                                                                                                        |
| `effort`                | `String?`              | Tidak | ID tingkat penalaran (mis. `'low'`, `'xhigh'`), bersumber dari `thinkingLevels` model yang dipilih                                                                                                   |
| `contextSize`           | `int?`                 | Tidak | Ukuran maksimum jendela konteks                                                                                                                                                                     |
| `role`                  | `AgentRole?`           | Tidak | Peran agen                                                                                                                                                                                          |
| `capabilities`          | `AgentCapabilities?`   | Tidak | Default kemampuan per agen; saat null default tingkat pengguna berlaku pada saat pengiriman dan percakapan masih dapat menimpanya                                                                   |
| `monthlyBudgetCents`    | `int`                  | Tidak | Batas pengeluaran bulanan dalam sen (default `0`, tak terbatas)                                                                                                                                     |
| `silenceTimeoutMinutes` | `int?`                 | Tidak | Penimpaan batas waktu diam dalam menit; harus null atau dalam rentang 1–240 (ditegaskan oleh konstruktor)                                                                                           |
| `maxConcurrentTasks`    | `int`                  | Tidak | Default `1`. Angka kapasitas yang dilaporkan model kehadiran (jumlah yang berjalan dan yang mengantre dibandingkan dengannya)                                                                        |
| `visibility`            | `AgentVisibility`      | Tidak | Default `workspace`                                                                                                                                                                                 |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Tidak | Status tata kelola (default `active`). Ditulis oleh penghentian paksa anggaran dan ditampilkan pada bagan organisasi serta daftar kehadiran. Pengiriman tetap menerima pekerjaan dari agen `paused` |
| `budgetPolicyId`        | `String?`              | Tidak | ID kebijakan anggaran bersama; saat null `monthlyBudgetCents` berlaku langsung                                                                                                                      |
| `runtimeProfileId`      | `String?`              | Tidak | ID profil runtime kustom                                                                                                                                                                            |
| `createdAt`             | `DateTime`             | Ya    | Stempel waktu pembuatan                                                                                                                                                                             |

`name` dan `title` keduanya harus tidak kosong (ditegaskan oleh konstruktor).
Default `monthlyBudgetCents` bernilai `0` berarti tak terbatas. Tetapkan batas
atas dengan `agents.upsert`.

## Enum AgentLifecycleStatus

| Nilai      | Deskripsi                                                                              |
| ---------- | -------------------------------------------------------------------------------------- |
| `active`   | Default. `isDispatchable` bernilai true hanya untuk nilai ini                          |

## Flag AgentCapabilities

Diselesaikan per pengiriman: default agen, jatuh kembali ke default tingkat pengguna saat null, dengan penimpaan per percakapan di atasnya. Ditegakkan melalui ketiadaan — broker kredensial memang tidak membuat atau menyuntikkan apa yang dicakup oleh kemampuan yang dimatikan.

| Flag               | Tipe   | Default | Deskripsi                                                                                 |
| ------------------ | ------ | ------- | ----------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false` | Push commit ke remote; membatasi injeksi token GitHub bersama `canCallGitHubApi`           |
| `canCallGitHubApi` | `bool` | `false` | Memanggil api.github.com; membatasi injeksi `GH_TOKEN` dan domain egress GitHub            |
| `canCallTicketing` | `bool` | `false` | Memanggil API penyedia ticketing; membatasi injeksi kunci API penyedia dan domain egress-nya |
| `canAccessNetwork` | `bool` | `true`  | Egress keluar sembarang. Juga membatasi alat `web_fetch` dan `web_search` milik harness    |

`AgentCapabilities.safeDefault` adalah keempat default konstruktor. `legacyDefault` (keempatnya true) hanya dipakai oleh migrasi yang mengisi kembali percakapan yang dibuat sebelum kemampuan ada. Blob tersimpan yang rusak atau kosong diuraikan menjadi `safeDefault`; kunci lawas `canCallLinear` dibaca sebagai `canCallTicketing`.

## AgentSkills

Kumpulan pengenal skill yang tidak dapat diubah dan tidak peka huruf besar/kecil. Saat pengiriman, slug-slug tersebut disinkronkan sebagai tautan skill di overlay agen; harness kemudian memuat otomatis frontmatter skill yang ditautkan ke dalam prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (turunan)

Tidak disimpan. Tujuh nilai. Urutan deklarasi adalah urutan prioritas (`sortPriority`, dipatok oleh pengujian), yaitu urutan yang dipakai daftar untuk mengurutkan:

| Status      | `sortPriority` | Kondisi                                                                                                            |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Ada log run yang berstatus `running`                                                                                |
| `blocked`   | 1              | Liveness run terbaru adalah `blocked`, `stalled`, atau `looping`                                                     |
| `failed`    | 2              | Status run terbaru adalah `error`, atau liveness-nya `failed` atau `dead`                                           |
| `queued`    | 3              | Sebuah run dikirim tetapi tidak sedang dieksekusi — tertahan di belakang run lain dari agen yang sama, atau sudah ditulis tetapi belum dimulai |
| `succeeded` | 4              | Run selesai dengan sukses                                                                                           |
| `idle`      | 5              | Agen sudah pernah berjalan dan tidak ada yang sedang diproses                                                        |
| `neverRun`  | 6              | Tidak ada log run                                                                                                   |

`queued` dan `succeeded` hanya **per run**. `deriveAgentLiveState`, yang menghitung status daftar untuk sebuah agen, tidak pernah menghasilkan keduanya — fungsi itu mengembalikan `neverRun`, `running`, `failed`, `blocked`, atau `idle`.
