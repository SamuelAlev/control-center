Halaman referensi menjelaskan **apa yang ada**, secara menyeluruh dan tanpa komentar.
Gunakan halaman ini untuk mencari sesuatu saat Anda sudah tahu apa yang dicari: nama alat
yang persis, jenis langkah, transisi status, rute, atau pintasan.

Halaman-halaman ini tidak ditulis untuk dibaca dari awal sampai akhir. Untuk itu, gunakan
[konsep](/id-ID/panduan-pengguna/konsep/); untuk menyelesaikan suatu tugas, gunakan
[panduan praktis](/id-ID/panduan-pengguna/panduan-praktis/).

## Permukaan produk

- [Alat MCP](/id-ID/panduan-pengguna/referensi/alat-mcp/) — setiap alat yang didaftarkan server MCP, per keluarga
- [Alat agen bawaan](/id-ID/panduan-pengguna/referensi/alat-agen/) — alat harness yang terikat server (LSP, AST, debug, eval, vibe)
- [Perintah slash](/id-ID/panduan-pengguna/referensi/perintah-slash/) — bawaan composer, perintah `/skill:` dan perintah pengguna
- [Peta rute](/id-ID/panduan-pengguna/referensi/peta-rute/) — setiap layar dan URL yang menjangkaunya
- [Pintasan keyboard](/id-ID/panduan-pengguna/referensi/pintasan-keyboard/) — registri pengikatan tombol selengkapnya
- [Peristiwa domain](/id-ID/panduan-pengguna/referensi/peristiwa-domain/) — setiap peristiwa yang diterbitkan di bus domain
- [Rigs](/id-ID/panduan-pengguna/referensi/rigs/) — setiap permukaan rig, verb aksi, status siklus hidup, port dan nilai bawaan

## Konfigurasi

- [Konfigurasi agen](/id-ID/panduan-pengguna/referensi/konfigurasi-agen/) — setiap bidang pada agen dan apa yang membacanya
- [Jenis langkah pipeline](/id-ID/panduan-pengguna/referensi/langkah-pipeline/) — jenis langkah, key body, konfigurasi dan hasil
- [CLI `cc_server`](/id-ID/panduan-pengguna/referensi/cli-cc-server/) — setiap flag, variabel lingkungan, subperintah dan path direktori data
- [Cadangan, ekspor dan impor](/id-ID/panduan-pengguna/referensi/cadangan/) — tata letak snapshot, setiap operasi pencadangan dan rute transfer
- [Backend sandbox](/id-ID/panduan-pengguna/referensi/backend-sandbox/) — backend eksekusi dan ketersediaannya
- [Konfigurasi SSO](/id-ID/panduan-pengguna/referensi/sso/) — endpoint, operasi dan kode kesalahan
- [Jembatan chat](/id-ID/panduan-pengguna/referensi/jembatan-chat/) — penyedia, perintah, kredensial dan operasi
