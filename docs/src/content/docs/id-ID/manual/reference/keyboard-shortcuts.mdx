Pintasan berasal dari satu registri `const`, `KeybindingRegistry` di `lib/core/constants/keybindings.dart`. Registri ini memuat **48 binding**. Pengaturan → Anda → Pintasan keyboard menampilkan registri tersebut sebagai **referensi hanya-baca**: tidak ada UI untuk mengubah binding dan tidak ada berkas binding milik pengguna.

`Cmd` di bawah ini adalah modifikator perintah utama — ⌘ di macOS, Ctrl di Windows dan Linux. Sebuah binding hanya terpicu bila perintahnya memiliki handler terdaftar di layar saat ini dan klausa `when`-nya terpenuhi; `!textInputFocus` berarti tombol tersebut diteruskan ke kolom teks yang sedang difokuskan.

Tidak ada pintasan navigasi dengan tombol angka. Kotak masuk, tiket, pull request, dan sisanya dijangkau dari bilah sisi atau ⌘K. Observabilitas juga tidak punya pintasan.

## Global (19)

Bercakupan `global`, sehingga binding-nya aktif di mana pun di dalam shell.

## Daftar pull request (3)

Cakupan `/pull-requests`. Semuanya mensyaratkan `route == '/pull-requests'` dan tidak ada kolom teks yang difokuskan, jadi pintasannya tidak terpicu selagi rute detail PR terbuka di atas daftar.

| Pintasan | Tindakan         |
| -------- | ---------------- |
| `R`      | Muat ulang       |
| `Enter`  | Buka PR          |
| `F`      | Buka menu filter |

`Enter` (`pr.list-open`) dideklarasikan di registri dan muncul di referensi pintasan keyboard, tetapi **layar daftar tidak mendaftarkan handler untuknya**, jadi saat ini pintasan itu tidak terpicu. `F` membuka menu filter (`pr.list-open-filter`), bukan pencarian.

## Detail pull request (2)

Cakupan `/pull-requests/`. Muat ulang mensyaratkan tidak ada kolom teks yang difokuskan. Tutup tab tidak punya pengaman input teks (kombinasi dengan ⌘ tidak pernah berupa teks biasa) dan memakai regex rute sehingga tidak terpicu di daftar.

| Pintasan       | Tindakan    | Kondisi                            |
| -------------- | ----------- | ---------------------------------- |
| `R`            | Muat ulang  | Tidak sedang mengetik di kolom     |
| `Cmd/Ctrl + W` | Tutup tab   | Di lokasi `/pull-requests/<…>`     |

Peralihan tab (`1`/`2`/`3`), penandaan dilihat/menguncupkan berkas (`V`/`C`), daftar berkas (`T`), dan pencarian dalam diff (`Cmd/Ctrl + F`) ditangani oleh handler penampil diff sendiri — lihat [Tombol penampil diff di luar registri](#tombol-penampil-diff-di-luar-registri).

## Profil pengguna dan tim GitHub (3)

Cakupan `/users/`. Klausa `when`-nya adalah regex terhadap `/users/<login>` **atau** `/teams/<organization>/<slug>`, ditambah tidak ada kolom teks yang difokuskan.

| Pintasan       | Tindakan          |
| -------------- | ----------------- |
| `R`            | Muat ulang        |
| `/`            | Fokus ke pencarian |
| `Cmd/Ctrl + F` | Fokus ke pencarian |

## Space (8)

Cakupan `/spaces`. Klausa `when`-nya memakai regex sehingga terpicu baik di daftar space (`/spaces`) maupun di space yang dipilih (`/spaces/<id>`).

| Pintasan               | Tindakan               | Kondisi               |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | Kirim pesan            | —                     |
| `Cmd/Ctrl + N`         | Space baru             | Di rute `/spaces`     |
| `J`                    | Space berikutnya       | Tidak sedang mengetik di kolom |
| `K`                    | Space sebelumnya       | Tidak sedang mengetik di kolom |
| `Cmd/Ctrl + Shift + D` | Dikte tekan untuk bicara | —                   |
| `Cmd/Ctrl + T`         | Buka tab editor        | Di rute `/spaces`     |
| `Cmd/Ctrl + W`         | Tutup tab editor       | Di rute `/spaces`     |
| `Cmd/Ctrl + B`         | Alihkan bilah sisi editor | Di rute `/spaces`  |

Kirim dengan Enter ditangani oleh kolom teks composer; tekan untuk bicara ditangani oleh tombol mikrofon composer (handler keyboard perangkat kerasnya sendiri). Keduanya tercantum di registri untuk referensi pengaturan.

## Tombol penampil diff di luar registri

Penampil diff PR menangani tombol-tombol ini sendiri (`PrDiffKeyboardHandler`). Pencarian/dilihat/menguncupkan hanya tercantum di komentar registri untuk referensi pengaturan — tidak ada handler dispatcher yang terdaftar, sehingga dispatcher menyerahkannya ke tampilan diff. Tombol-tombol itu tidak muncul sebagai baris tersendiri di referensi pintasan keyboard.

| Pintasan        | Tindakan                                                 |
| --------------- | -------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Cari di dalam diff                                       |
| `J` / `K`       | Berkas berikutnya / sebelumnya                           |
| `V`             | Alihkan status dilihat pada berkas yang difokuskan       |
| `C`             | Alihkan kuncup pada berkas yang difokuskan               |
| `T`             | Tampilkan daftar berkas                                  |
| `Enter`         | Kecocokan pencarian berikutnya (hanya saat pencarian dalam diff terbuka) |
| `Shift + Enter` | Kecocokan pencarian sebelumnya                           |
| `Escape`        | Tutup pencarian dalam diff, atau bersihkan pilihan teks diff |
| `Cmd/Ctrl + C`  | Salin pilihan diff                                       |

## Kombinasi yang dicadangkan browser

Pada build web, browser mengonsumsi sejumlah akselerator sebelum halaman melihatnya, sehingga binding yang bersangkutan tidak akan pernah terpicu di sana. Di desktop, semuanya berfungsi normal. Yang dicadangkan bila digabungkan dengan modifikator perintah utama: `T`, `W`, `N`, dan angka `1`–`9`.

Itu mencakup peralihan ruang kerja `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (space baru, ruang kerja baru, agen baru, tambah repositori), serta `Cmd/Ctrl + T` / `Cmd/Ctrl + W` di space dan detail PR.
