Inilah jalur lengkap terpendek dari nol hingga agen berjalan pada kode Anda sendiri. Ikuti secara berurutan; setiap langkah bergantung pada langkah sebelumnya.

Anda memerlukan Git, akun GitHub, dan salah satu dari ini: akun penyedia model (Anthropic, OpenAI, Codex, Cursor, Kimi Code, atau penyedia mana pun yang memiliki kunci API) atau Claude Code CLI yang sudah terinstal. Selebihnya disiapkan sepanjang proses.

## Langkah 1: Instal dan luncurkan

Instal Control Center seperti dijelaskan di [Instal](/id-ID/panduan-pengguna/instal/), lalu buka.

Saat pertama kali diluncurkan, aplikasi desktop menanyakan **"Bagaimana Control Center harus dijalankan?"** Pilih **Jalankan di aplikasi ini**. Control Center memunculkan `cc_server` headless di mesin ini, yang memiliki data Anda dan mengerjakan semua pekerjaan. Anda tidak pernah melihatnya; layar onboarding yang terbuka sebagai gantinya.

:::note[Tidak ingin menginstal apa pun?]
Aplikasi yang sama berjalan di browser di [app.usectrl.dev](https://app.usectrl.dev) dengan
fitur yang sama. Namun, tab browser tidak dapat menjadi host server, jadi Anda perlu
menyediakan satu server — jalankan `cc_server` secara lokal dan hubungkan ke
`ws://localhost:9030`, atau arahkan ke server di mesin lain. Mulai cepat ini menempuh
jalur desktop karena tidak memerlukan penyiapan server; lihat
[Instal](/id-ID/panduan-pengguna/instal/#use-it-in-your-browser) untuk jalur browser.
:::

## Langkah 2: Selesaikan onboarding

Onboarding memiliki lima langkah dan dijalankan secara berurutan — tidak ada cara melompatinya.

1. **Hubungkan**: masuk dengan GitHub atau tempelkan token akses pribadi dengan `repo` dan `read:org`. Kredensialnya disimpan di server, terlampir pada akun Anda.
2. **Ruang kerja**: beri nama ruang kerja pertama Anda dan secara opsional pilih logo. Membuatnya akan menyemai lima agen — seorang CEO plus `qa`, `architect`, `engineer`, dan `librarian` — serta templat pipeline bawaan.
3. **Sandbox**: mencatat preferensi sandbox. Pilihan mana pun memungkinkan Anda melanjutkan.
4. **Adapter**: pilih adapter dan model yang seharusnya menjadi default agen. Pilih **Control Center (built-in)**, lalu gunakan pemilih penyedia yang muncul untuk masuk ke penyedia model — daftar model tetap kosong sampai ada penyedia yang terhubung. Menyelesaikan langkah ini juga menempelkan adapter dan model ke agen CEO ruang kerja tersebut.
5. **Suara (opsional)**: instal model suara di perangkat untuk dikte, atau lewati saja.

Control Center kemudian membuka kotak masuk ruang kerja Anda.

:::note[Apa yang membatasi sebuah run agen]
Perintah agen dibungkus dalam sandbox native OS host bila tersedia — Seatbelt di macOS, bubblewrap di Linux. Windows tidak memiliki backend, jadi run di sana hanya dibatasi oleh lapisan lainnya: worktree milik percakapan itu sendiri (`git worktree` di Windows; copy-on-write di tempat `rift` tersedia), kredensial yang dijembatani per peluncuran dan dicabut saat teardown, serta pagar pengaman tindakan. Lihat [Sandbox dan keamanan](/id-ID/panduan-pengguna/konsep/sandbox-dan-keamanan/).
:::

## Langkah 3: Tambahkan repositori

Buka **Pengaturan → Ruang kerja → Repositori** dan klik **Tambah repositori**.

Dialognya menelusuri folder di mesin yang menjalankan server, bukan di klien Anda, dan dialog itu tetap berada di dalam root yang dikonfigurasi untuk diekspos oleh server tersebut (secara default, direktori home penggunanya). Hanya checkout git yang mendapat kotak centang. Centang milik Anda lalu daftarkan.

Sebuah checkout hanya diterima jika berada di dalam work tree git, memiliki remote `origin`, dan remote tersebut menunjuk ke forge yang didukung — github.com, gitlab.com, atau bitbucket.org. Selain itu akan ditolak beserta alasannya.

Repo bersifat bercakupan ruang kerja: mendaftarkan checkout di sini menempatkannya di ruang kerja _ini_. Tidak ada langkah penautan terpisah.

## Langkah 4: Beri agen adapter dan model

Buka **Pengaturan → Ruang kerja → Agen**. Pilih agen `engineer` di daftar agen.

Pada tab **Pengaturan**, atur:

- **Adapter**: `Control Center (built-in)`
- **Model**: pilih salah satu dari penyedia yang Anda hubungkan saat onboarding

Tekan **Simpan perubahan**.

Dalam praktiknya, langkah ini bukan opsional. Hanya agen CEO yang mewarisi adapter yang dipilih selama onboarding; keempat spesialis dibuat tanpa adapter. Mereka kembali ke **Control Center (built-in)** dengan model default Anthropic, sehingga hanya berjalan jika Anda telah menghubungkan akun Anthropic — dan pada model yang tidak Anda pilih jika memang sudah terhubung.

## Langkah 5: Kirim tugas ke agen

1. Di bilah sisi, temukan bagian **Ruang** dan klik tombol **+**.
2. Beri nama space tersebut, tambahkan agen `engineer` di bawah **Tambah agen**, lalu buat.
3. Ketik tugas kecil yang konkret terhadap repo yang Anda daftarkan dan tekan Enter.

Control Center menyediakan worktree copy-on-write dari repo ruang kerja untuk percakapan ini, menyusun prompt dari peran, persona, dan skill agen serta konteks space tersebut, lalu mengirimkan run-nya. Checkout sumber Anda tidak pernah tersentuh.

## Langkah 6: Saksikan agen bekerja

Anda akan melihat, secara berurutan:

- Tombol kirim composer berubah menjadi tombol berhenti, karena ada agen yang bekerja di percakapan ini
- Penalaran agen, panggilan alat, dan teks mengalir ke transkrip
- Tombol kirim kembali muncul saat run berakhir

Lalu buka **Pengaturan → Ruang kerja → Agen**, pilih agen tersebut, dan periksa tab **Log**: satu baris run, beserta status, durasi, waktu mulai dan selesai, serta adapter yang digunakannya.

Itulah loop-nya. Semua hal lain di Control Center — tinjauan pull request, pipeline, tiket, rapat, Slack — bergantung padanya.
