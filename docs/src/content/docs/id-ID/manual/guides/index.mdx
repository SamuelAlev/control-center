Setiap panduan menyelesaikan **satu masalah bagi orang yang sudah terbiasa dengan produk
ini**. Panduan ini mengasumsikan Control Center sudah terinstal dan ruang kerja sudah
disiapkan, menyatakan tujuannya di judul, dan berhenti saat tujuan itu tercapai.

Jika Anda masih mempelajari produk ini, mulailah dari
[tutorial](/id-ID/panduan-pengguna/tutorial/). Jika Anda ingin memahami _mengapa_ sesuatu
berperilaku seperti itu, baca [konsep](/id-ID/panduan-pengguna/konsep/).
