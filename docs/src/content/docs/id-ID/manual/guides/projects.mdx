Proyek adalah pengelompokan tiket bercakupan ruang kerja menuju tujuan bersama.
Proyek hanya ada di Control Center — proyek tidak pernah disinkronkan ke penyedia
eksternal seperti Linear.

## Buat proyek

1. Perluas grup **Tiket** di sidebar ruang kerja. Grup itu mencantumkan
   **Semua tiket**, satu baris per proyek yang tidak diarsipkan, lalu
   **Proyek baru**.
2. Klik **Proyek baru**.
3. Isi **Nama proyek**, **Deskripsi** opsional, dan pilih **Warna**.
4. Tekan **Buat proyek**.

Anda akan dibawa ke ringkasan proyek baru, dan proyek tersebut muncul sebagai
baris sidebar di bawah **Tiket**.

## Tambahkan tiket ke proyek

Proyek adalah bidang per tiket tunggal yang diatur di salah satu dari dua
tempat:

- Buka tiket dan atur **Proyek** di panel propertinya.
- Klik kanan tiket di daftar dan gunakan submenu **Proyek**.

Pemilih di panel properti juga menawarkan **Proyek baru**, sehingga Anda dapat
memasukkan tiket ke proyek yang Anda buat saat itu juga. **Tidak ada proyek**
mengosongkan bidang tersebut.

Sebuah tiket paling banyak menjadi bagian dari satu proyek.

:::note[Proyek bukan tindakan massal]
Bilah mengambang yang muncul saat Anda memilih beberapa tiket mencakup status,
prioritas, penerima tugas, label, dan hapus. Bilah itu tidak memiliki chip
proyek, jadi memasukkan banyak tiket berarti melakukannya satu per satu.
:::

Anda juga dapat memulai dari proyek: **Tiket baru** di ringkasan proyek membuat
tiket dan memasukkannya ke sana.

## Baca progres proyek

Buka proyek dari baris sidebarnya, atau buka
`/workspaces/<workspace-id>/projects/<project-id>`.

Ringkasan menampilkan glif dan nama proyek, lencana status, deskripsi, serta
bilah progres selesai-dari-total. Di bawahnya, tiket proyek dikelompokkan
berdasarkan status.

Ringkasan tidak mengagregasi hal lain — tidak ada rincian penerima tugas dan
tidak ada distribusi prioritas. Untuk itu, filter daftar tiket utama.

## Ubah status proyek

Proyek memiliki tiga status:

| Status        | Arti                 |
| ------------- | -------------------- |
| **Aktif**     | Pekerjaan berjalan   |
| **Selesai**   | Semua pekerjaan tuntas |
| **Diarsipkan** | Referensi historis  |

Gunakan menu **⋯** pada header proyek. Menu itu menawarkan **Edit proyek**,
**Tandai selesai** / **Tandai aktif**, **Arsipkan** / **Pulihkan**, dan
**Hapus proyek**.

Mengarsipkan menyembunyikan proyek dari daftar sidebar dan dari pemilih tiket.
Tindakan ini dapat dibalik — **Pulihkan** mengembalikan proyek ke aktif — tetapi
selagi diarsipkan, proyek hanya dapat dijangkau lewat URL.

## Proyek yang dibuat untuk Anda

Menyetujui orkestrasi akan membuat proyek dan memasukkan tiket induk ke
dalamnya, bersama apa pun yang Anda masukkan secara manual. Item pekerjaan yang
dihasilkan adalah langkah pipeline, bukan baris tiket, sehingga tidak muncul di
papan proyek. Itulah satu-satunya jalur otomatis: tidak ada node pipeline yang
membuat tiket, jadi pipeline tidak dapat mengisi proyek. Lihat
[Jalankan orkestrasi](/id-ID/panduan-pengguna/panduan-praktis/jalankan-orkestrasi/).

:::note[Proyek adalah permukaan operator]
Buat, daftar, perbarui, dan hapus proyek di aplikasi. Agen tidak memiliki alat
proyek.
