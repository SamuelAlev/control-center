Tempelkan kunci API Linear di server yang dikaitkan dengan pengguna Anda, sama
seperti saat Anda menghubungkan host kode. Tiket, proyek, tautan, kolaborator,
delegasi, dan penugasan semuanya bekerja pada basis data Control Center sendiri
tanpa memerlukan layanan eksternal — lihat
[Buat dan kelola tiket](/id-ID/panduan-pengguna/panduan-praktis/kelola-tiket/).

## Simpan kunci Linear Anda

**Kunci API ticketing** berada di **Pengaturan → Ruang kerja → Umum**, pada
kartu **Tiket**. Kunci ini disimpan di server dan dikaitkan dengan id pengguna
Anda. Kunci milik server untuk pekerjaan tanpa pengawasan berasal dari
`LINEAR_API_KEY` atau kartu **Aplikasi penyedia**, dan hanya disuntikkan sebagai
`TICKETING_API_KEY` ketika agen tersebut memiliki kemampuan **Izinkan panggilan
API ticketing**.

## Tandai tiket baru sebagai Linear

**Penyedia ticketing** (langkah pertama onboarding, dan
`/workspaces/<workspaceId>/api-keys`) menawarkan `local` dan `linear`. Memilih
`linear` menandai tiket yang Anda buat sejak saat itu dengan `provider: linear`.
