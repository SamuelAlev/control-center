Panduan ini menunjukkan cara menghubungkan penyedia model dan memilih apa yang
dijalankan agen.

Semua yang ada di sini terletak di satu halaman: **Pengaturan → Server → Penyedia
model**. Entri sub-sidebar berbunyi "Penyedia model"; judul halamannya berbunyi
"Adapter".

## Apa itu adapter

Adapter adalah _runner_ yang menjalankan giliran agen. Hanya ada dua dan daftarnya
tetap — Anda tidak dapat menambahkan yang ketiga.

| Adapter                   | CLI      | Transport                                              |
| ------------------------- | -------- | ------------------------------------------------------ |
| Control Center (built-in) | tidak ada | Loop agen dalam proses, berbicara dengan penyedia melalui HTTP |
| Claude Code               | `claude` | `claude -p --output-format stream-json`                |

Cursor, Codex, Anthropic, OpenAI, dan lainnya adalah **penyedia** pada adapter
bawaan, bukan CLI terpisah. Yang _dapat_ Anda tambahkan adalah penyedia lain —
endpoint apa pun yang kompatibel dengan OpenAI atau Anthropic. Itulah bagian
berikutnya.

:::note[Deteksi memeriksa server, bukan mesin Anda]
Kartu **Runner terdeteksi** mencantumkan apa yang ditemukan `cc_server` di `PATH`
_host server_. Pada klien tipis atau klien web, itu adalah mesin yang berbeda dari
yang sedang Anda lihat. Instal CLI di mesin yang menjalankan `cc_server`.
:::

## Hubungkan penyedia model

Adapter bawaan memerlukan setidaknya satu penyedia yang terhubung sebelum dapat
berjalan. Empat belas sudah tersedia di katalog.

1. Buka **Pengaturan → Server → Penyedia model**
2. Gulir ke **Penyedia & model**
3. Temukan penyedia Anda dan hubungkan:

| Penyedia                                                                                                 | Cara menghubungkan                                                                                                            |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | Kunci API. Langganan Claude Pro/Max bukanlah login API Anthropic — gunakan adapter Claude Code untuk paket itu                 |
| OpenAI, Codex, Cursor                                                                                    | Login OAuth lewat browser, atau kunci API. Codex adalah ChatGPT Plus/Pro melalui backend Codex Responses, bukan spawn CLI      |
| Kimi Code                                                                                                | Hanya OAuth browser — alur kode perangkat. Ini paket tarif tetap, jadi tidak ada harga per token                              |
| OpenRouter, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API)       | Kunci API                                                                                                                     |

Titik pemeriksaan: badge baris berubah menjadi terhubung dan saat diperluas akan
mencantumkan model yang dilayani penyedia tersebut, masing-masing dengan harga per
juta token dan jendela konteksnya.

Token OAuth disimpan di penyimpanan kredensial milik server dan disegarkan sebelum
kedaluwarsa. Kredensial penyedia bersifat **global host** — dibagikan oleh setiap
ruang kerja pada instalasi, bukan dibatasi untuk satu ruang kerja.

### Tambahkan penyedia kustom

Gunakan ini untuk Ollama, LM Studio, vLLM, atau deployment pribadi.

1. Di **Penyedia & model**, pada **Penyedia kustom**, tekan **Tambah penyedia**
2. Isi **nama**, pilih **Jenis API** (kompatibel OpenAI atau kompatibel
   Anthropic), dan berikan **Base URL** (misalnya
   `http://localhost:11434/v1`)
3. Tambahkan **Kunci API** jika endpoint memerlukannya, lalu tekan **Tambah
   penyedia**

Penyedia kustom muncul di daftar yang sama, dengan tombol hapus yang tidak dimiliki
penyedia bawaan lainnya.

## Pilih model untuk agen

1. Buka **Pengaturan → Ruang kerja → Agen** dan pilih agen
2. Di tab **Pengaturan**, pilih **adapter**
3. Pilih **model** dari dropdown di sebelahnya

Untuk adapter bawaan, dropdown disusun secara langsung dari katalog
masing-masing penyedia yang terhubung. Penyedia tanpa kredensial tersimpan tidak
menyumbang model sama sekali, itulah sebabnya dropdown yang kosong hampir selalu
berarti "belum ada yang terhubung", bukan "tidak ada yang tersedia".

:::note[models.dev adalah pengayaan, bukan sumber id]
Katalog [models.dev](https://models.dev) yang disertakan menyediakan harga dan
jendela konteks untuk model yang sudah ada di daftar aktif. Katalog ini tidak
pernah menambahkan id model. Jika model yang Anda harapkan tidak ada, endpoint
penyedia tidak mengembalikannya.
:::

Id model untuk adapter bawaan memakai bentuk berkualifikasi `provider/model` dan
dapat membawa rantai fallback yang dipisahkan `|`. Dalam kondisi fallback, biaya
dihitung berdasarkan model yang benar-benar melayani giliran tersebut, bukan model
yang Anda minta.

:::note[Agen tanpa adapter berjalan pada loop bawaan]
Setiap ruang kerja menyemai lima agen — seorang CEO plus `qa`, `architect`,
`engineer`, dan `librarian` — tanpa adapter dan tanpa model. Pengiriman jatuh
kembali ke **Control Center (built-in)**, bukan ke setelan **Runner default** di
halaman ini, yang merupakan preferensi sisi klien yang tidak pernah dibaca jalur
pengiriman. Log run mencatat `cc-harness` untuk run tersebut, sehingga transkrip
menyebutkan apa yang benar-benar berjalan.

Karena juga tanpa model, loop bawaan meminta Anthropic memakai model defaultnya.
Agen yang sama sekali tidak disetel karena itu berjalan jika Anda telah
menghubungkan akun Anthropic, dan jika tidak, gagal dengan `No credential for
provider "anthropic"`.

Menyelesaikan langkah adapter pada onboarding akan menambal balik **setiap** agen
yang masih belum memiliki adapter atau model — CEO dan para spesialis, di semua
ruang kerja yang ada saat itu — dengan pasangan yang Anda pilih. Ruang kerja yang
dibuat kemudian tetap menyemai kelimanya tanpa setelan. Setel adapter dan model
secara eksplisit pada setiap agen yang ingin Anda gunakan.
:::

## Instal CLI runner

Adapter bawaan tidak perlu instalasi. Untuk Claude Code, instal CLI-nya **di host
server** dengan pengelola paket milik alat tersebut, misalnya:

```bash
npm install -g @anthropic-ai/claude-code
```

Lalu tekan **Segarkan** di bagian atas halaman. Setiap baris yang terdeteksi
menampilkan versi dan jalur yang diselesaikan, plus chip yang menunjukkan apakah
mendukung mode JSON dan pemilihan model.

CLI eksternal menyimpan kredensialnya sendiri, dalam konfigurasinya sendiri, di
host server. Control Center tidak mengelolanya.

:::caution[Argumen adapter dan Variabel lingkungan tetap di perangkat ini]
Setiap baris adapter menawarkan kolom **Argumen** dan dialog **Variabel
lingkungan**. Nilai-nilai itu disimpan di perangkat Anda. Server membaca argv dan
env peluncuran dari penyimpanan setelannya sendiri. Letakkan kunci penyedia di
server (OAuth atau kolom kunci di halaman Penyedia model), bukan di kedua kolom
tersebut.
:::

## Batasi penyedia yang boleh digunakan ruang kerja

Tata kelola penyedia bersifat per ruang kerja dan dievaluasi dengan aturan
kecocokan terakhir yang menang.

1. Di **Penyedia & model**, matikan sakelar **Izinkan** pada baris penyedia

Tindakan itu menulis pernyataan `deny` untuk penyedia tersebut di ruang kerja aktif
dan modelnya keluar dari katalog untuk ruang kerja itu. Menyalakan kembali sakelar
tersebut akan menghapus pernyataan itu.

## Pemecahan masalah

### Runner ditampilkan sebagai tidak ditemukan

- Pastikan CLI ada di `PATH` **host server**, bukan hanya di `PATH` Anda
- Aplikasi desktop yang diluncurkan melalui GUI menjalankan servernya dengan
  `PATH` minimal; CLI yang diinstal pada jalur yang hanya tersedia di shell
  mungkin tidak terlihat olehnya
- Tekan **Segarkan** setelah menginstal

### Dropdown model kosong

- Adapter yang dipakai adalah adapter bawaan dan tidak ada penyedia yang
  terhubung — hubungkan satu di **Penyedia & model**
- Atau penyedia sudah terhubung tetapi ditolak oleh sakelar tata kelola ruang
  kerja ini

### Model berjalan tetapi harga ditampilkan sebagai tidak diketahui

Daftar model aktif memuat id-nya; harga dan konteks berasal dari models.dev. Model
yang sangat baru, atau model dari penyedia kustom, belum memiliki entri katalog.
