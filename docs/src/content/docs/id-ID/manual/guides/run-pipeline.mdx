Panduan ini membahas cara memulai eksekusi secara manual. Untuk memantau
eksekusi, membaca keluaran langkah, dan memulihkan diri setelah kegagalan, lihat
[Pantau eksekusi pipeline](/id-ID/panduan-pengguna/panduan-praktis/pantau-pipeline/).

## Memulai eksekusi

1. Klik **Pipeline** di bilah sisi ruang kerja.
2. Tekan **Jalankan pipeline** di header. Anda masuk ke peluncur
   (`/workspaces/<workspace-id>/pipelines/run`).
3. Pilih templat dari bilah kiri. Setiap kartu menampilkan nama templat,
   deskripsinya, dan apakah templat itu menerima input.
4. Isi formulir input di sebelah kanan. Kolom wajib memblokir tombolnya sampai
   terisi; templat tanpa input akan mengatakan demikian.
5. Tekan **Jalankan pipeline**.

Anda masuk ke halaman detail eksekusi, dengan waterfall waktu dan kanvas graf
yang aktif.

## Jika bilah kiri kosong

Peluncur hanya menampilkan templat bila **keduanya** benar:

- Sakelar templat menyala di **Pengaturan → Ruang kerja → Template pipeline**.
- **Izinkan eksekusi manual** menyala di dialog **Eksekusi manual** pada editor
  templat — sakelar itulah yang membuat pemicu `manual` yang dibaca peluncur.

Delapan dari tiga belas templat bawaan dikirim dalam keadaan nonaktif:
`external_pr_welcome`, `cross_review`, `ticket_to_pr`, `pr_triage`,
`pre_merge_gate`, `release_notes`, `dep_audit`, dan `pr_digest`. Mesin menolak
memulai templat yang nonaktif, jadi nyalakan sakelarnya sebelum mencarinya di
sini.

Tidak ada tindakan **Jalankan** per templat di daftar templat dan tidak ada
tombol eksekusi di dalam editor — peluncur adalah satu-satunya titik masuk
manual.

## Mengisi input repositori

Input bertipe **Repositori** menampilkan pemilih atas repo yang terdaftar di
ruang kerja. Memilih salah satunya mengisi `repo_id`, `repo_local_path`,
`repo_full_name`, dan — saat repo punya remote GitHub — `repo_owner` serta
`repo_name` ke dalam payload eksekusi, sehingga langkah di hilir dapat membaca
nilai mana pun yang dibutuhkannya.

## Mengamati eksekusinya

Halaman detail eksekusi terdiri atas tiga bagian: strip meta (waktu mulai,
durasi aktif, kemajuan langkah, banner kegagalan, **Coba lagi** dan **Hapus**),
waterfall waktu yang dapat dilipat dengan durasi serta biaya per langkah, dan
kanvas graf. Memilih sebuah node akan membuka panel detail langkah tersebut.

[Pantau eksekusi pipeline](/id-ID/panduan-pengguna/panduan-praktis/pantau-pipeline/)
membahas semua itu, termasuk cara membaca langkah yang ditangguhkan dan apa yang
harus dilakukan saat langkah itu gagal.

Setiap eksekusi yang Anda mulai dari aplikasi adalah eksekusi nyata.
