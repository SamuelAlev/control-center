Panduan ini menunjukkan cara memasangkan ponsel dengan Control Center, sehingga
Anda dapat membaca pesan dan tiket serta membalas dari mana saja. Alur yang sama
juga memasangkan peramban atau aplikasi desktop kedua. Lihat
[Kontrol jarak jauh dan seluler](/id-ID/panduan-pengguna/konsep/kontrol-jarak-jauh/) untuk cara tautan ini
bekerja dan model keamanannya.

## Prasyarat

- Klien desktop atau web yang terhubung ke server Anda dan ruang kerja yang sudah disiapkan. Operasi pemasangan memerlukan klien lengkap, jadi ponsel yang sudah dipasangkan tidak akan pernah dapat memasangkan — atau mencabut — perangkat lain.
- Server dapat dijangkau dari perangkat yang Anda pasangkan. Pada jaringan yang sama ini langsung berfungsi; dari jarak yang lebih jauh, relay dengan perantara yang membawa lalu lintasnya. Jika panel menjawab **Tidak dapat dijangkau**, bukan menampilkan QR atau kredensial, publikasikan jalur terlebih dahulu — opsi ikut-serta tunnel di **Pengaturan → Server → Koneksi & status** (**Bagikan server ini**), atau `--public-url` milik server (lihat [Jalankan server headless](/id-ID/panduan-pengguna/panduan-praktis/jalankan-server-headless/)).
- Untuk ponsel: tidak ada yang perlu diinstal. QR membuka aplikasi web **Remote** (secara bawaan [remote.usectrl.dev](https://remote.usectrl.dev/)).

**Menghosting sendiri.** Remote dan broker relay bersifat open source di repo
ini: aplikasi ponsel (`apps/cc_remote`, PWA web Flutter yang dapat Anda deploy ke
Cloudflare Pages melalui `wrangler.jsonc`-nya, ke image nginx `docker/cc_remote`,
atau ke host statis mana pun dengan HTTPS — service worker dan IndexedDB
dibatasi oleh konteks aman) dan relay (`apps/cc_signaling_server`, biner Dart
stateless tunggal yang tidak menyimpan data aplikasi apa pun dan tidak pernah
melihat rahasia pemasangan — ia hanya meneruskan frame yang tersegel ujung ke
ujung). Lihat README masing-masing untuk langkah build dan menjalankannya.

## Langkah 1: Buka panel pemasangan

Buka **Pengaturan → Anda → Perangkat Anda**. Bagian **Perangkat Anda**
mencantumkan klien yang dipasangkan ke akun Anda di server ini. (Pemilik server
melihat setiap perangkat di server; semua orang lain hanya melihat perangkatnya
sendiri.)

## Langkah 2: Pasangkan klien baru

Klik **Pasangkan klien baru** di header halaman, beri label (mis. "Ponsel
saya"), pilih jenisnya — **Peramban web**, **Aplikasi desktop**, atau
**Ponsel** — lalu klik **Pasangkan**.

- Untuk **ponsel**, kode QR akan muncul. Pindai dengan kamera ponsel, atau salin tautannya dan buka di peramban mana pun. Tautan ini mengarahkan aplikasi Remote ke server Anda dan membawa kredensialnya.
- Untuk **peramban** atau **desktop**, salin tautan yang ditampilkan (atau id perangkat dan kunci pemasangan) ke klien baru. Tautan sekali ketuk hanya ditawarkan saat Anda memasangkan dari klien web, karena biner desktop tidak memiliki origin web untuk membangunnya.

QR ponsel dan tautan yang dicetak `cc_server pair --client-url` di CLI adalah
**muatan yang berbeda dan tidak dapat dipertukarkan**: tautan CLI mengisi
formulir koneksi klien web, sedangkan QR ini membawa deskriptor koneksi lengkap
server dan sidik jari identitas untuk PWA Remote.

Di sisi ponsel, membuka tautan pemasangan tidak memasangkan secara diam-diam.
Remote menampilkan nama yang diumumkan server dan meminta Anda mengonfirmasi
sebelum menyimpan apa pun, sehingga tautan palsu tidak dapat membajak aplikasi
ke server orang lain.

:::caution[QR yang dipindai langsung memberikan akses]
Tidak ada langkah menunggu-lalu-menyetujui: perangkat yang dibuat langsung aktif
sejak saat dibuat dan gerbang koneksi hanya memeriksa bahwa kredensialnya aktif
dan belum kedaluwarsa. Perlakukan QR dan kunci pemasangan seperti kata sandi,
lalu cabut apa pun yang tidak ingin Anda berikan.
:::

## Kelola perangkat yang dipasangkan

Dari **Pengaturan → Anda → Perangkat Anda**, Anda dapat:

- **Ganti nama** perangkat
- **Cabut** perangkat yang tidak lagi Anda percayai. Pencabutan menghancurkan kredensialnya dan memutus sesi aktifnya dalam hitungan detik, sehingga perangkat gagal secara tertutup saat menyambung kembali

Mencabut adalah langkah yang tepat untuk ponsel yang hilang atau diganti. Dari
sudut pandang perangkat, tindakan ini langsung berlaku dan tidak dapat
dibatalkan.

Kredensial yang dibuat dari panel ini dibatasi waktu: kredensial kedaluwarsa 30
hari setelah diterbitkan dan gerbang koneksi menolaknya secara tertutup setelah
itu. Kredensial yang dibuat dengan `cc_server pair` di baris perintah **sama
sekali tidak memiliki masa kedaluwarsa** — cabut secara manual saat mesin yang
dituju sudah tidak digunakan lagi.

## Beralih ruang kerja dari ponsel

Ponsel yang dipasangkan dapat beralih antar-ruang kerja secara independen dari
desktop. Ponsel mengirimkan ruang kerja pada setiap panggilan dan server
memeriksa keanggotaan serta peran Anda di ruang kerja tersebut pada setiap
panggilan — sehingga ponsel hanya menjangkau ruang kerja yang Anda ikuti dan
beralih di sana tidak pernah mengubah apa yang ditampilkan desktop.

Sesi ponsel juga dibatasi pada daftar izin kecil berisi alat yang banyak
membaca: ponsel dapat menampilkan daftar dan membaca tiket, agen, space, pesan,
dan artikel umpan berita, serta dapat memperbarui atau menetapkan tiket,
mengirim pesan di sebuah space, dan menandai artikel sebagai sudah dibaca atau
disimpan. Apa pun di luar kumpulan itu ditolak sebelum mencapai dispatcher
server.
