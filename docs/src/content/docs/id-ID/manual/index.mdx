Control Center memberi Anda kendali atas fleet agen pengodean AI. Jalankan agen, saksikan mereka bekerja secara real time, tinjau PR mereka, dan kelola repo, ruang kerja, serta integrasi — dari aplikasi desktop native, browser, atau ponsel Anda.

## Yang dapat Anda lakukan

- **Kirimi agen pesan**: space adalah cara utama untuk mengemudikan fleet. @-mention sebuah agen dan agen itu dikirim ke worktree copy-on-write miliknya sendiri, sehingga beberapa agen dapat menulis kode dan meninjau secara paralel tanpa menyentuh checkout Anda
- **Orkestrasi permintaan besar**: beri orkestrator sebuah tujuan, setujui sekali rencana seluruh tim yang dia usulkan, dan [pipeline](/id-ID/panduan-pengguna/konsep/pipeline/) yang dihasilkan akan menjalankannya
- **Tinjau dan gabungkan PR** dengan penampil diff bawaan, komentar inline, dan tinjauan bertenaga AI
- **Berikan agen mesin sekali pakai**: [rig](/id-ID/panduan-pengguna/panduan-praktis/gunakan-rigs/) adalah VM sekali pakai — browser, desktop, ponsel, atau terminal tertutup — yang dikemudikan agen sementara Anda menonton langsung dan dapat mengambil alih; server dev di dalamnya diteruskan ke `localhost`, browser agen, dan `https://myapp.test`
- **Otomatiskan alur kerja** dengan pipeline berbasis DAG yang dipicu oleh peristiwa atau jadwal
- **Kelola pengetahuan** dengan memori, fakta, dan kebijakan yang dicakup ruang kerja
- **Lacak pekerjaan** dengan tiket, proyek, dan delegasi yang netral vendor
- **Rekam rapat** dengan pengambilan, transkripsi, dan diarisasi di perangkat, lalu diringkas menjadi catatan, item tindakan, dan keputusan
- **Lihat hari Anda** dengan sinkronisasi Google Calendar, RSVP, peringatan rapat, dan rekam-dan-tautkan
- **Ikuti fleet dari ponsel Anda**: pasangkan perangkat dengan server Anda, lalu baca pesan, balas, dan lakukan triase tiket. Ponsel mengambil jalur terbaik yang dapat dijangkau — loopback, LAN, tailnet, atau TLS — dan beralih ke relay tersegel end-to-end yang meneruskan frame yang tidak dapat dibacanya
- **Kemudikan agen dari Slack**: jembatani ruang kerja ke aplikasi chat dan sebut bot, balas di thread Slack, atau buat tiket dengan perintah slash — melalui koneksi keluar, sehingga tidak perlu endpoint publik
- **Integrasikan** dengan GitHub, Linear, Slack, Google Calendar, dan lebih dari 100 alat MCP

## Anda tidak perlu menginstalnya

Aplikasi yang sama berjalan di browser Anda di
[app.usectrl.dev](https://app.usectrl.dev), dengan fitur yang sama.

Setiap klien — desktop, web, dan ponsel — adalah perender tipis di atas server headless yang
memiliki data Anda dan melakukan pekerjaannya. Desktop dapat menjalankan server itu untuk Anda; tab browser
tidak bisa, sehingga aplikasi web terhubung ke server yang Anda jalankan. Server itu dapat berada di mesin Anda
sendiri (`ws://localhost:9030`, tidak perlu sertifikat) atau di host jarak jauh yang dapat dijangkau melalui
TLS, VPN, atau tunnel.

Lihat [Instal](/id-ID/panduan-pengguna/instal/#use-it-in-your-browser) untuk jalur browser dan
[Deployment dan klien](/id-ID/panduan-pengguna/konsep/deployment/) untuk memahami hubungan ketiga klien.
