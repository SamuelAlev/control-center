Tutorial adalah **pelajaran**. Setiap pelajaran menuntun Anda dari awal sampai akhir melalui
sesuatu yang nyata, dalam satu jalur, tanpa keputusan yang perlu diambil di sepanjang jalan.
Ikuti langkah-langkahnya dengan tepat dan semuanya berhasil.

Pelajaran ini untuk mengenali seluk-beluk produk. Setelah Anda memahami bentuk produknya,
[panduan praktis](/id-ID/panduan-pengguna/panduan-praktis/) adalah jalur yang lebih cepat menuju tugas tertentu.

Kerjakan dengan urutan ini — setiap pelajaran mengasumsikan pelajaran sebelumnya.

1. [Ruang kerja pertama Anda](/id-ID/panduan-pengguna/tutorial/ruang-kerja-pertama/) — buat ruang kerja, tambahkan repo, dan lihat model isolasinya
2. [Kirim agen pertama Anda](/id-ID/panduan-pengguna/tutorial/agen-pertama/) — beri agen sebuah adapter dan sebuah model, lalu suruh agen itu bekerja
3. [Tinjau pull request pertama Anda](/id-ID/panduan-pengguna/tutorial/pr-pertama/) — baca diff, beri komentar, dan gabungkan
4. [Bangun pipeline pertama Anda](/id-ID/panduan-pengguna/tutorial/pipeline-pertama/) — rangkai langkah-langkah menjadi DAG dan jalankan

Dua pelajaran berikut berdiri sendiri; kerjakan salah satunya setelah Anda memiliki ruang kerja yang berfungsi.

- [Jembatani Slack ke ruang kerja Anda](/id-ID/panduan-pengguna/tutorial/jembatan-chat-pertama/) — kemudikan agen dari thread Slack
- [Masukkan tim Anda dengan SSO](/id-ID/panduan-pengguna/tutorial/sso/) — hubungkan penyedia identitas dan jalani proses login dari awal sampai akhir

:::note[Sebelum memulai]
Instal Control Center terlebih dahulu — lihat [Instal](/id-ID/panduan-pengguna/instal/). Jika Anda hanya ingin
jalur terpendek menuju agen yang berjalan, ikuti [mulai cepat](/id-ID/panduan-pengguna/mulai-cepat/)
dan kembali ke sini setelahnya.
:::
