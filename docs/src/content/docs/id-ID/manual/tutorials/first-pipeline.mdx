## Apa yang akan Anda bangun

Pada akhir tutorial ini, Anda akan memiliki:

- Templat pipeline tersimpan yang mengirim agen dengan sebuah prompt
- Eksekusi manual yang aktif padanya, sehingga templat itu dapat dijalankan dengan tangan
- Satu eksekusi yang selesai, dengan input dan output langkahnya terlihat

Prasyarat: [Kirim agen pertama Anda](/id-ID/panduan-pengguna/tutorial/agen-pertama/) sudah selesai, sehingga Anda memiliki agen dengan adapter dan model.

Pipeline adalah DAG berisi langkah-langkah. Templat mendefinisikan grafnya; eksekusi adalah pelaksanaannya. Untuk model di baliknya, baca [Pipeline dan otomatisasi](/id-ID/panduan-pengguna/konsep/pipeline/); untuk kosakata langkah selengkapnya, [Jenis langkah pipeline](/id-ID/panduan-pengguna/referensi/langkah-pipeline/).

## Langkah 1: Buat templat

1. Buka **Pengaturan → Ruang kerja → Template pipeline**
2. Klik **Template baru**

Editor terbuka pada kerangka yang telah disemai bernama **Pipeline baru** (id `pipeline_N`).
Klik judul di header dan ganti namanya — untuk tutorial ini,
`code_quality_check` adalah nama yang bagus. Tidak ada dialog id dan tidak ada
kolom deskripsi.

Kanvasnya tidak kosong. Templat baru sudah terkabel sebelumnya sebagai **Trigger → Step →
terminal**, di mana "Step" adalah node agen prompt dan terminal adalah
sentinel tak terlihat yang disambungkan ulang oleh editor ke setiap sink yang
dapat dijangkau.

Anda mengonfigurasi Step yang sudah ada di sana.

## Langkah 2: Konfigurasikan langkah

1. Klik node **Step** di kanvas
2. Di panel **Konfigurasi node** di sebelah kanan, setel:
   - **Agen**: agen Anda dari tutorial sebelumnya
   - **Template prompt**: "Tinjau kode di branch saat ini untuk masalah kualitas. Daftarkan apa yang Anda temukan."
3. Biarkan **Pemicu dari** apa adanya — node sudah terkabel untuk terpicu setelah Trigger

## Langkah 3: Simpan

Tekan **Simpan** di header editor.

**Titik pemeriksaan.** Keterangan "Perubahan belum disimpan" menghilang.

## Langkah 4: Izinkan eksekusi manual

1. Klik ubin bergaris putus-putus **Tambah trigger** di kanvas (atau seret **Run manual**
   dari bagian **Trigger** di pustaka node) lalu pilih **Run manual**.
2. Pilih node itu. Di inspector di sebelah kanan, nyalakan **Aktif** —
   "Tampilkan di halaman run dan mulai secara manual."

Ini bukan opsional dan mudah terlewat. Templat baru dibuat **tanpa baris pemicu sama sekali**, jadi sampai Anda menyalakannya, halaman eksekusi tidak akan mencantumkannya dan tidak ada yang bisa dijalankan. Sakelar itu langsung menulis pemicunya; ia tidak menunggu penyimpanan berikutnya.

Sakelar yang sama ada di balik **Eksekusi manual** di header editor, tempatnya berdampingan dengan input yang dideklarasikan templat.

## Langkah 5: Jalankan

1. Klik **Pipeline** di bilah sisi
2. Klik **Jalankan pipeline** di header
3. Pilih `code_quality_check` di bilah kiri
4. Klik **Jalankan pipeline** di formulir — templat Anda tidak mendeklarasikan input, jadi tidak ada yang perlu diisi

**Titik pemeriksaan.** Toast mengonfirmasi bahwa eksekusi dimulai dan Control Center membuka detail eksekusi.

Mesin membuat catatan eksekusi, menyelesaikan pemicunya, menjadwalkan langkahnya, mengirim agen, lalu menyelesaikan eksekusi saat cabang hulu terminal selesai.

## Langkah 6: Periksa hasilnya

Klik langkah di dalam eksekusi itu untuk membuka panel detailnya:

- Stempel waktu **Dimulai** dan **Selesai** serta **Durasi**
- **Input**: state yang diteruskan ke langkah itu
- **Output**: apa yang dihasilkannya — di sini, respons agen
- **Aktivitas agen**, dengan tautan menuju percakapan yang dijalankan langkah itu

**Titik pemeriksaan.** Langkah itu berstatus selesai dan outputnya memuat tinjauan dari agen.

## Menambahkan lebih banyak langkah

Node ditambahkan dengan menyeret entri dari pustaka node di sebelah kiri ke
kanvas, atau dengan menekan **Tambah langkah** (`+`) tepat setelah sebuah node.
Seret dari port output sebuah node ke node lain untuk menghubungkannya, atau
pilih node baru itu dan centang langkah hulunya di bawah **Pemicu dari**.

Node terminal tidak digambar dan tidak dapat dipilih. Editor menyambungkannya
ulang ke setiap sink yang dapat dijangkau, sehingga node yang Anda tambahkan
setelah Step yang telah disemai tetap berjalan.

## Rekap

Anda membuat templat, mengonfigurasi node agen prompt yang disemai bersamanya, menyimpannya, membuatnya dapat dijalankan secara manual, memulai eksekusi, lalu membaca input dan output langkahnya.

Pipeline bisa jauh lebih besar dari ini — router bersyarat, cabang paralel, node join, fan-out for-each, gerbang manusia — tetapi bentuknya tidak pernah berubah: langkah-langkah dalam sebuah DAG, yang meneruskan state.
