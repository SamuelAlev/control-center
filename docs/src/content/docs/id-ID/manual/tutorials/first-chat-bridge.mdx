## Yang akan Anda bangun

Pada akhir tutorial ini, Anda akan memiliki:

- Aplikasi Slack yang dibuat untuk ruang kerja Anda, dengan izin dan peristiwa yang sudah diatur dengan benar
- Koneksi aktif antara Slack dan Control Center
- Akun Slack Anda sendiri yang tertaut ke pengguna Control Center Anda
- Agen yang menjawab Anda di thread Slack dan tiket yang dibuat dari perintah slash

Prasyarat:

- [Ruang kerja pertama Anda](/id-ID/panduan-pengguna/tutorial/ruang-kerja-pertama/) dan [Kirim agen pertama Anda](/id-ID/panduan-pengguna/tutorial/agen-pertama/) sudah selesai — ruang kerja tanpa agen dapat menerima pesan Slack tetapi tidak punya siapa pun untuk menjawabnya
- **Agen CEO** ruang kerja sudah memiliki adapter dan model yang diatur di **Pengaturan → Ruang kerja → Agen**. Jembatan membangunkan CEO, bukan agen yang Anda konfigurasikan di tutorial sebelumnya, dan agen tanpa adapter berjalan pada loop bawaan dengan model default Anthropic.
- Peran `owner` atau `admin` di ruang kerja Control Center (menghubungkan aplikasi chat berbicara atas nama seluruh ruang kerja)
- Izin untuk membuat dan menginstal aplikasi di ruang kerja Slack Anda

Tidak ada yang di sini memerlukan alamat publik, tunnel, atau port masuk. Control Center menghubungi _keluar_ ke Slack melalui Socket Mode, sehingga ini berfungsi dari laptop di belakang NAT.

## Langkah 1: Dapatkan token konfigurasi aplikasi Slack

Ini satu-satunya kredensial yang harus Anda ambil sendiri. Token ini memungkinkan Control Center membuat dan nanti mengedit aplikasi untuk Anda.

1. Buka [api.slack.com/apps](https://api.slack.com/apps)
2. Gulir ke bagian token konfigurasi aplikasi di bagian bawah halaman
3. Buat pasangan token untuk ruang kerja Slack Anda
4. Salin token **refresh** — diawali dengan `xoxe-`

## Langkah 2: Biarkan Control Center membuat aplikasinya

1. Di Control Center, buka **Pengaturan → Ruang kerja → Umum** dan temukan kartu **Jembatan chat**
2. Pada blok **Slack**, klik **Buatkan aplikasi**
3. Tempel token konfigurasi aplikasi
4. Tinjau bagaimana bot akan terlihat:
   - **Nama aplikasi**: bagaimana Slack mencantumkan aplikasi, misalnya `Control Center · Acme`
   - **Nama bot (yang diketik anggota setelah @)**: misalnya `control-center`
   - **Deskripsi singkat** dan **Yang dikatakan bot dapat dilakukannya**
   - **Perintah slash**: `cc` secara default, sehingga perintahnya adalah `/cc`
   - **Pesan langsung**: biarkan aktif agar anggota dapat mengirim DM ke bot
5. Klik **Buat aplikasi**

Control Center menyusun seluruh definisi aplikasi — Socket Mode aktif, scope bot dan langganan peristiwa yang dibutuhkan, perintah slash, tab Messages — lalu membuatnya di Slack.

## Langkah 3: Selesaikan dua langkah yang hanya bisa dilakukan Slack

Slack tidak punya API untuk membuat token tingkat aplikasi atau menginstal aplikasi, jadi dialog menyerahkan keduanya kepada Anda sebagai tautan:

1. **Buat token tingkat aplikasi** — membuka **Basic Information → App-Level Tokens**. Buat token dengan scope `connections:write` dan salin token itu. Diawali dengan `xapp-`
2. **Instal aplikasi** — membuka **Install App**. Instal ke ruang kerja Anda, lalu salin **Bot User OAuth Token**. Diawali dengan `xoxb-`

Simpan kedua nilai itu untuk langkah berikutnya.

## Langkah 4: Hubungkan

1. Kembali di dialog, klik **Tempel kredensial**
2. Isi **Token bot** (`xoxb-…`) dan **Token tingkat aplikasi** (`xapp-…`)
3. Biarkan **Token konfigurasi aplikasi** kosong — token dari langkah 1 sudah tersimpan (Slack merotasinya dan Control Center menyimpan yang baru)
4. Klik **Hubungkan**

Control Center memverifikasi token bot dengan Slack sebelum menyimpan apa pun, lalu membuka socket. Baris itu kini menampilkan nama bot dan nama ruang kerja Slack Anda dengan tag **Aktif**.

## Langkah 5: Tautkan akun Slack Anda sendiri

Koneksi membuat bot dapat dijangkau; penautan membuat _Anda_ dikenali. Sampai identitas Slack Anda tertaut, bot tidak akan menindaklanjuti pesan Anda — bot tidak pernah mengatribusikan pesan kepada siapa pun yang menginstal aplikasi.

Penautan bersifat personal, jadi letaknya di halaman yang berbeda dari koneksi seluruh ruang kerja.

1. Buka **Pengaturan → Ruang kerja → Profil & identitas** dan temukan kartu **Akun chat tertaut**
2. Klik **Hubungkan akun Slack saya**
3. Salin perintah yang ditampilkan, misalnya `/cc link K7M2QP`
4. Di Slack, kirim perintah itu ke bot lewat DM
5. Bot menjawab "Linked — you are …"

Kode ini hanya dapat dipakai sekali dan kedaluwarsa dalam 15 menit. Jika email Slack Anda cocok dengan pengguna Control Center yang sudah menjadi anggota ruang kerja ini, jembatan menautkan Anda secara otomatis pada pertama kali Anda berbicara dengannya dan Anda dapat melewati langkah ini.

Jika Anda menyebut bot sebelum ini selesai, bot menolak dan menjelaskan alasannya. Ketiga penolakan itu berbeda, jadi baca yang mana yang Anda terima:

- **Pengirim belum tertaut**: bot memberi tahu cara menautkan. Kembali ke langkah ini.
- **Tertaut, tetapi bukan anggota ruang kerja ini**: minta admin mengundang Anda.
- **Anggota dengan peran hanya baca** (viewer atau guest): bot tidak akan memulai pekerjaan atas nama Anda.

## Langkah 6: Beri agen sesuatu untuk dikerjakan

1. Di Slack, undang bot ke sebuah kanal: `/invite @control-center`
2. Sebut botnya dengan permintaan nyata:

   > @control-center ringkas PR yang terbuka di repo api

Jembatan:

1. Membuat space Control Center untuk thread Slack itu, dinamai menurut kanal Slack dan permintaan Anda
2. Membangunkan agen pintu depan ruang kerja (agen CEO bila ada, jika tidak agen pertama)
3. Mengalirkan jawaban agen kembali ke thread Slack saat jawaban itu ditulis

Balas di thread Slack yang sama untuk melanjutkan — tidak perlu menyebut lagi, karena thread Slack itu kini sudah dijembatani. Atau kirim DM ke bot alih-alih memakai kanal; setiap percakapan DM menjalankan space Control Center-nya sendiri, dengan judul dan baris status "is thinking…" selama agen bekerja.

Streaming memerlukan API streaming milik Slack, yang tidak dimiliki setiap paket. Jika aplikasi Anda ditolak, jembatan berhenti mencobanya selama sisa masa hidup koneksi itu dan mengirim setiap balasan sebagai satu pesan, dan kartu Jembatan chat menampilkan "Streaming langsung nonaktif untuk aplikasi Slack ini — balasan tiba sebagai satu pesan." Segala hal lainnya berfungsi sama.

## Langkah 7: Buat tiket tanpa meninggalkan Slack

```text
/cc ticket Fix the flaky login test | It fails on CI about once a day.
```

Bot menjawab dengan kunci tiket yang dibuatnya. Tiket itu adalah tiket lokal Control Center biasa, dilaporkan oleh Anda, siap ditugaskan ke agen. `/cc help` mencantumkan semua yang dapat dilakukan perintah itu.

## Rekap

Anda membuat aplikasi Slack dari Control Center, menghubungkannya lewat socket keluar, menautkan identitas Slack Anda ke pengguna Control Center Anda, dan mengendalikan agen dari thread Slack. Semua yang terjadi di Slack juga ada di Control Center: thread Slack adalah space, balasannya adalah transkrip, tiketnya adalah tiket.
