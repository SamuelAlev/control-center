کلید API مربوط به Linear را روی سرور و در برابر کاربر خودتان بچسبانید، درست همان
شکلی که یک میزبان کد را وصل می‌کنید. تیکت‌ها، پروژه‌ها، پیوندها، همکاران، واگذاری و
تخصیص همگی روی پایگاه‌دادهٔ خودِ Control Center کار می‌کنند و هیچ سرویس بیرونی
لازم نیست — [ایجاد و مدیریت
تیکت‌ها](/fa-IR/راهنمای-کاربر/راهنماهای-عملی/مدیریت-تیکتها/) را ببینید.

## کلید Linear خود را ذخیره کنید

**کلید API تیکتینگ** در **تنظیمات → فضای کاری → عمومی**، روی کارت تیکتینگ قرار
دارد. کلید را روی سرور و در برابر شناسهٔ کاربری شما ذخیره می‌کند. کلید خودِ سرور
برای کارهایی که انسانی پشتشان نیست از `LINEAR_API_KEY` یا کارت **برنامه‌های
ارائه‌دهنده** می‌آید و تنها وقتی به‌عنوان `TICKETING_API_KEY` تزریق می‌شود که آن
عامل قابلیت **اجازهٔ فراخوانی‌های API تیکتینگ** را داشته باشد.

## مهر Linear را روی تیکت‌های جدید بزنید

**ارائه‌دهندهٔ تیکتینگ** (نخستین گام راه‌اندازی اولیه، و
`/workspaces/<workspaceId>/api-keys`) گزینه‌های `local` و `linear` را ارائه می‌دهد.
با انتخاب `linear`، از آن پس روی تیکت‌هایی که می‌سازید `provider: linear` مهر
می‌خورد.
