Linear دو هویت در Control Center دارد و هر دو ورود مرورگری هستند: هویت شما، برای کارهایی که انجام می‌دهید، و برنامهٔ Control Center فضای کاری، برای کارهایی که عامل‌ها و پایپ‌لاین‌ها انجام می‌دهند. تیکت‌ها، پروژه‌ها، پیوندها، همکاران، واگذاری و تخصیص همگی روی پایگاه‌دادهٔ خود Control Center کار می‌کنند و هیچ سرویس بیرونی لازم نیست — ببینید [ایجاد و مدیریت تیکت‌ها](/fa-IR/راهنمای-کاربر/راهنماهای-عملی/مدیریت-تیکتها/).

## پیش‌نیازها

- سرور بتواند افراد را به Linear وارد کند: از طریق Control Center Connect، یا با برنامهٔ Linear خود سرور ([ثبت برنامهٔ Linear خودتان](#ثبت-برنامهٔ-linear-خودتان)). مالک سرور در **تنظیمات ← سرور ← ورود یکپارچه** انتخاب می‌کند
- یک مدیر فضای کاری، برای انتخاب Linear به‌عنوان ارائه‌دهندهٔ تیکتینگ و اتصال خودکارسازی Linear

## انتخاب Linear برای فضای کاری

۱. به **تنظیمات ← فضای کاری ← یکپارچه‌سازی‌ها** بروید و کارت **تیکتینگ** را پیدا کنید
۲. **ارائه‌دهندهٔ تیکتینگ** را روی **Linear** تنظیم کنید

تیکت‌هایی که از این به بعد می‌سازید با `provider: linear` مهر می‌خورند. **محلی** تیکت‌ها را در پایگاه‌دادهٔ همین سرور نگه می‌دارد و ردیف‌های Linear را پنهان می‌کند: چیزی برای احراز هویت وجود ندارد.

## ورود به Linear

ورود شخصی شما به Linear در **تنظیمات ← شما ← نمایه**، در کارت **تیکتینگ** است:

۱. روی **ورود به Linear** کلیک کنید
۲. در مرورگر تأیید کنید
۳. با برنامهٔ خود سرور، گفتگو خودش این را تشخیص می‌دهد. از طریق Connect، کد ۸ کاراکتری را که مرورگر نشان می‌دهد تایپ کنید، یا اجازه دهید از طریق پیوند `control-center://` در Control Center باز شود

هر کاری که از Control Center در Linear انجام می‌دهید روی همین ورود و هیچ چیز دیگری اجرا می‌شود. اگر وارد نشده باشید، برنامه از شما می‌خواهد وارد شوید، نه اینکه به جای شخص دیگری عمل کند.

این ورود در همهٔ فضاهای کاری این سرور کار می‌کند، مگر اینکه فضای کاری‌ای برنامه‌های ورود خودش را داشته باشد: آن فضای کاری ورود Linear جدا خودش را نگه می‌دارد. کارت نشان می‌دهد کدام صادق است.

## اتصال خودکارسازی Linear

ردیف **خودکارسازی Linear**، روی کارت **تیکتینگ** در **تنظیمات ← فضای کاری ← یکپارچه‌سازی‌ها**، همان برنامهٔ Control Center فضای کاری در Linear است. همگام‌سازی تیکت، پایپ‌لاین‌ها و عامل‌ها با آن می‌نویسند، پس موضوع‌ها و نظرهای خودکار به‌عنوان Control Center ظاهر می‌شوند نه به‌عنوان یک فرد.

۱. یک مدیر فضای کاری روی **اتصال Linear برای خودکارسازی** کلیک می‌کند
۲. او برنامه را برای فضای کاری Linear در مرورگر تأیید می‌کند، مانند بالا

ردیف آنگاه "متصل به _فضای کاری Linear شما_" را نشان می‌دهد. فقط مدیران فضای کاری می‌توانند آن را متصل یا قطع کنند.

هیچ اعتبارنامهٔ Linear‌ای در سندباکس عامل گذاشته نمی‌شود: عامل‌ها تیکت‌ها را از طریق ابزارهای خود Control Center می‌نویسند، که ابتدا از قاعدهٔ **نوشتن در یک ردیاب خارجی** می‌پرسند.

## ثبت برنامهٔ Linear خودتان

وقتی **استفاده از برنامه‌های خودم** را انتخاب کرده‌اید، از برنامهٔ خودتان استفاده کنید. برنامهٔ سرور تنها در این حالت اعمال می‌شود: با Control Center یا Connect سفارشی، Connect هر مسیری از جمله Linear را اجرا می‌کند و برنامهٔ سرور و کلید API سرویس آن ذخیره‌شده اما بدون استفاده می‌مانند. برنامهٔ اختصاصی فضای کاری ([در ادامه](#دادن-برنامهٔ-linear-اختصاصی-به-یک-فضای-کاری)) به‌جای برنامهٔ سرور، از برنامهٔ خودش استفاده می‌کند، هرطور که حالت سرور باشد.

۱. یک برنامهٔ OAuth در [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new) بسازید
۲. هر دو نشانی callback را که **تنظیمات ← سرور ← ورود یکپارچه ← برنامه‌های ارائه‌دهنده ← Linear** زیر **Callback URLs** نشان می‌دهد، عیناً اضافه کنید:
   `<server origin>/oauth/linear/callback` و `<server origin>/oauth/linear_app/callback`
۳. **Client id** را در بلوک Linear بچسبانید

client secret وجود ندارد: سرور با PKCE وارد می‌شود. توکن‌های تازه‌سازی Linear پس از ۳۰ روز بی‌استفاده منقضی می‌شوند، پس سرور هر ورود Linear را که بیش از ۲۰ روز قدمت دارد، روزی یک بار تازه می‌کند.

همان بلوک یک **کلید API سرویس** اختیاری هم دارد. این اعتبارنامهٔ خود سرور برای Linear است و برای خودکارسازی در فضای کاری‌هایی که خودکارسازی Linear را متصل نکرده‌اند به کار می‌رود. آن را در **تنظیمات** یا در فایل `.env` سرور به‌صورت `LINEAR_API_KEY` نگه دارید: وقتی `LINEAR_API_KEY` در محیط فرایند سرور صادر شده باشد، سرور از راه‌اندازی خودداری می‌کند.

## دادن برنامهٔ Linear اختصاصی به یک فضای کاری

یک فضای کاری می‌تواند با برنامهٔ اختصاصی خودش به Linear وارد شود، به جای برنامهٔ سرور. فقط مدیر یا مالک فضای کاری می‌تواند آن را راه‌اندازی کند.

۱. یک برنامهٔ OAuth در Linear بسازید، همان‌طور که در بالا توضیح داده شد
۲. به **تنظیمات ← فضای کاری ← یکپارچه‌سازی‌ها** بروید. در کارت **Control Center Connect**، **استفاده از برنامه‌های خودم** را انتخاب کنید و روی **اعمال** بزنید
۳. زیر **تیکت‌ها**، کارت **برنامهٔ Linear** ظاهر می‌شود. هر دو نشانی callback را که زیر **نشانی‌های URL بازگشت** نشان می‌دهد، عیناً به برنامهٔ Linear اضافه کنید
۵. **شناسهٔ کلاینت** آن را بچسبانید و در صورت تمایل **کلید API سرویس** را برای خودکارسازی این فضای کاری

برنامهٔ فضای کاری از این پس به هر درخواست ورود و خودکارسازی Linear در این فضای کاری پاسخ می‌دهد، هرطور که سرور افراد را وارد کند. هرگز به برنامهٔ سرور یا Connect برنمی‌گردد: تا وقتی client id تنظیم نشده، Linear در این فضای کاری خاموش است و کارت می‌گوید چه چیزی کم است. کلید API سرویس آن فقط همین‌جا استفاده می‌شود؛ بدون آن، همگام‌سازی به **اتصال خودکارسازی Linear** نیاز دارد.

**استفاده از برنامه‌های خودم** برای همه‌چیز با هم اعمال می‌شود: GitHub، Google Calendar و جست‌وجوی GIF هم فقط با برنامه‌های خود فضای کاری کار می‌کنند، هرکدام کنار ارائه‌دهندهٔ خودش در همین صفحه. تغییر برنامه‌های ورود فضای کاری، یا تغییر client id فضای کاری، همه را در این فضای کاری از Linear خارج می‌کند و خودکارسازی آن را قطع می‌کند. آن‌ها دوباره از طریق برنامهٔ جدید وارد می‌شوند. فیلدهای ذخیره‌شده با انتخاب دیگری برای فضای کاری حذف نمی‌شوند، اما فقط زیر **استفاده از برنامه‌های خودم** به کار می‌روند. رازها فقط نوشتنی هستند: کارت فقط نشان می‌دهد که آیا یکی ذخیره شده یا نه. فضاهای کاری دیگر سرور تحت تأثیر قرار نمی‌گیرند.

## عیب‌یابی

### ردیف Linear می‌گوید ورود تنظیم نشده است

سرور نه برنامهٔ Linear خودش را دارد و نه Connect را. مالک سرور یکی از آن‌ها را در **تنظیمات ← سرور ← ورود یکپارچه** انتخاب می‌کند. وقتی فضای کاری از برنامه‌های خودش استفاده می‌کند، کارت به‌جای آن می‌گوید راه‌اندازی‌اش تمام نشده است: مدیر فضای کاری client id را در **تنظیمات ← فضای کاری ← یکپارچه‌سازی‌ها** (کارت **برنامهٔ Linear**) وارد می‌کند.

### همگام‌سازی تیکت با خطای احراز هویت شکست می‌خورد

فضای کاری خودکارسازی Linear متصل ندارد و سرور کلید API سرویس ندارد، پس همگام‌سازی هیچ اعتبارنامه‌ای ندارد. یک مدیر فضای کاری روی **اتصال Linear برای خودکارسازی** کلیک می‌کند.

### اتصال خودکارسازی می‌گوید فضای کاری Linear جای دیگری متصل است

برنامهٔ Control Center آن فضای کاری Linear از قبل به سرور Control Center دیگری متصل است.
