میان‌برها از یک رجیستری `const` می‌آیند: `KeybindingRegistry` در `lib/core/constants/keybindings.dart`. این رجیستری **۴۹ کلیدبندی** دارد. مسیر **تنظیمات → شما → میان‌برهای صفحه‌کلید** آن رجیستری را به‌صورت یک **مرجع فقط‌خواندنی** نمایش می‌دهد: هیچ رابطی برای تخصیص مجدد و هیچ فایل کلیدبندی کاربری وجود ندارد.

`Cmd` که در ادامه می‌آید، تغییردهندهٔ اصلی فرمان است — ⌘ روی macOS و Ctrl روی Windows و Linux. یک کلیدبندی تنها زمانی فعال می‌شود که فرمانش روی صفحهٔ فعلی یک گردانندهٔ ثبت‌شده داشته باشد و بند `when` آن برقرار باشد؛ `!textInputFocus` یعنی اگر فیلد متنی فعال باشد، کلید در عوض به همان فیلد سپرده می‌شود.

هیچ میان‌بر پیمایشی با کلیدهای عددی وجود ندارد. صندوق ورودی، تیکت‌ها، pull requestها و بقیه از نوار کناری یا با ⌘K باز می‌شوند. مشاهده‌پذیری هم هیچ میان‌بری ندارد.

## سراسری (۱۹)

دامنهٔ آن‌ها `global` است، پس در هر نقطه از پوسته فعال‌اند.

### سیستم

| میانبر | کنش | شرط |
| ------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | پالت فرمان                                      | —                                                          |
| `Shift + /` (`?`)                           | برگهٔ میان‌برهای صفحه‌کلید                       | وقتی در فیلدی تایپ نمی‌کنید                                |
| `Cmd/Ctrl + Z`                              | واگرد                                            | وقتی در فیلدی تایپ نمی‌کنید (فیلد فعال واگرد خودش را دارد) |
| `Cmd/Ctrl + Shift + Z`                      | ازنو                                             | وقتی در فیلدی تایپ نمی‌کنید                                |
| `Cmd/Ctrl + Shift + T`                      | تغییر تم                                         | —                                                          |
| `Cmd/Ctrl + ,`                              | باز کردن تنظیمات (روی `/settings/you/appearance` فرود می‌آید) | —                                                          |
| `Cmd/Ctrl + Shift + Alt + F`                | تغییر وضعیت حالت تمرکز                           | —                                                          |
| `Cmd/Ctrl + Shift + W`                      | تغییر وضعیت تعویض‌گر فضای کاری                   | —                                                          |
| `Cmd/Ctrl + ]`                              | فضای کاری بعدی                                   | —                                                          |
| `Cmd/Ctrl + [`                              | فضای کاری قبلی                                   | —                                                          |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | رفتن به فضای کاری ۱–۹                            | —                                                          |

## فهرست pull request (۳)

دامنه: `/pull-requests`. همه به `route == '/pull-requests'` و نبود فیلد متنی فعال نیاز دارند، بنابراین وقتی مسیر جزئیات PR روی فهرست باز است فعال نمی‌شوند.

| میانبر | کنش |
| -------- | ---------------- |
| `R`      | تازه‌سازی        |
| `Enter`  | باز کردن PR      |
| `F`      | باز کردن منوی فیلتر |

`Enter` (`pr.list-open`) در رجیستری اعلام شده و در مرجع کلیدبندی هم دیده می‌شود، اما **صفحهٔ فهرست هیچ گرداننده‌ای برایش ثبت نکرده است**، پس فعلاً فعال نمی‌شود. `F` منوی فیلتر (`pr.list-open-filter`) را باز می‌کند، نه جستجو.

## جزئیات pull request (۲)

دامنه: `/pull-requests/`. تازه‌سازی به نبود فیلد متنی فعال نیاز دارد. بستن زبانه هیچ محافظ ورودی متنی ندارد (فشرده‌ای که با ⌘ اصلاح شده باشد هرگز متن ساده به شمار نمی‌آید) و یک عبارت باقاعده برای مسیر دارد تا روی فهرست فعال نشود.

| میانبر | کنش | شرط |
| -------------- | --------- | ---------------------------------- |
| `R`            | تازه‌سازی | وقتی در فیلدی تایپ نمی‌کنید        |
| `Cmd/Ctrl + W` | بستن زبانه | روی یک نشانی `/pull-requests/<…>` |

جابه‌جایی زبانه (`1`/`2`/`3`)، دیده‌شده/جمع‌کردن فایل (`V`/`C`)، فهرست فایل (`T`) و یافتن در دیف (`Cmd/Ctrl + F`) در اختیار گردانندهٔ خودِ نمایشگر دیف‌اند — [کلیدهای نمایشگر دیف بیرون از رجیستری](#کلیدهای-نمایشگر-دیف-بیرون-از-رجیستری) را ببینید.

## صندوق ورودی (۱)

| میانبر | کنش |
| -------- | ---------------- |
| `F`      | باز کردن منوی فیلتر |

به `route == '/inbox'` و نبود فیلد متنی فعال نیاز دارد.

## نمایه‌های کاربر و تیم GitHub (۳)

دامنه: `/users/`. شرط `when` یک عبارت باقاعده در برابر `/users/<login>` **یا** `/teams/<organization>/<slug>` است، به‌علاوهٔ نبود فیلد متنی فعال.

| میانبر | کنش |
| -------------- | ------------ |
| `R`            | تازه‌سازی    |
| `/`            | تمرکز روی جستجو |
| `Cmd/Ctrl + F` | تمرکز روی جستجو |

## فضاها (۹)

دامنه: `/spaces`. شرط‌های `when` از یک عبارت باقاعده استفاده می‌کنند تا هم روی فهرست فضاها (`/spaces`) و هم روی فضای انتخاب‌شده (`/spaces/<id>`) فعال شوند.

| میانبر | کنش | شرط |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | ارسال پیام             | —                     |
| `Cmd/Ctrl + N`         | فضای جدید              | روی یک مسیر `/spaces` |
| `J`                    | فضای بعدی              | وقتی در فیلدی تایپ نمی‌کنید |
| `K`                    | فضای قبلی              | وقتی در فیلدی تایپ نمی‌کنید |
| `Cmd/Ctrl + Shift + D` | دیکتهٔ فشار دهید تا صحبت کنید | —                     |
| `Cmd/Ctrl + T`         | باز کردن زبانهٔ ویرایشگر | روی یک مسیر `/spaces` |
| `Cmd/Ctrl + W`         | بستن زبانهٔ ویرایشگر   | روی یک مسیر `/spaces` |
| `Cmd/Ctrl + B`         | تغییر وضعیت نوار کناری ویرایشگر | روی یک مسیر `/spaces` |
| `Cmd/Ctrl + P`         | رفتن به فایل                    | روی یک مسیر `/spaces` |

«رفتن به فایل» انتخابگری روی فایل‌های گفتگو باز می‌کند. وقتی چیزی تایپ نکرده‌اید، فایل‌هایی را که اخیراً باز کرده‌اید فهرست می‌کند؛ با تایپ کردن، همهٔ فایل‌های worktreeهای گفتگو جست‌وجو می‌شوند. `Enter` فایل انتخاب‌شده را در یک زبانهٔ جدید باز می‌کند، `Cmd/Ctrl + Enter` یا دکمهٔ تقسیم روی ردیف آن را در یک پنل در سمت راست باز می‌کند، و `×` روی ردیفِ یک فایل اخیر آن را از فهرست حذف می‌کند.

ارسال با Enter در اختیار فیلد متنی ویرایشگر پیام است؛ فشار دهید تا صحبت کنید هم در اختیار دکمهٔ میکروفون ویرایشگر پیام است (گردانندهٔ صفحه‌کلید سخت‌افزاری خودش). هر دو فقط برای مرجع تنظیمات در رجیستری فهرست شده‌اند.

## انتخاب‌گر فضای کاری (۲)

دامنه: `/workspaces`، فقط روی خود انتخاب‌گر فعال‌اند.

| میانبر | کنش |
| -------------- | ----------------------- |
| `Cmd/Ctrl + N` | فضای کاری جدید          |
| `Enter`        | باز کردن فضای کاری انتخاب‌شده |

`Enter` به نبود فیلد متنی فعال نیاز دارد.

## کلیدهای نمایشگر دیف بیرون از رجیستری

نمایشگر دیف PR خودش این‌ها را مدیریت می‌کند (`PrDiffKeyboardHandler`). جستجو/دیده‌شده/جمع‌کردن فقط در توضیحات رجیستری و تنها برای مرجع تنظیمات فهرست شده‌اند — هیچ گرداننده‌ای در توزیع‌کننده ثبت نشده، بنابراین توزیع‌کننده آن‌ها را به نمای دیف وا می‌گذارد. این‌ها به‌صورت ردیف مستقل در مرجع کلیدبندی ظاهر نمی‌شوند.

| میانبر | کنش |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | جستجو در دیف                                         |
| `J` / `K`       | فایل بعدی / قبلی                                     |
| `V`             | تغییر وضعیت دیده‌شده روی فایل فعال                   |
| `C`             | تغییر وضعیت جمع‌کردن روی فایل فعال                   |
| `T`             | نمایش فهرست فایل                                     |
| `Enter`         | نتیجهٔ بعدی جستجو (تنها وقتی یافتن در دیف باز است)   |
| `Shift + Enter` | نتیجهٔ قبلی جستجو                                    |
| `Escape`        | بستن یافتن در دیف، یا پاک کردن انتخاب متن دیف        |
| `Cmd/Ctrl + C`  | کپی انتخاب دیف                                       |

## ترکیب‌های رزروشده برای مرورگر

در نسخهٔ وب، مرورگر برخی شتاب‌دهنده‌ها را پیش از آن‌که صفحه آن‌ها را ببیند مصرف می‌کند، پس کلیدبندی‌های متناظر هرگز آنجا فعال نمی‌شوند. روی دسکتاپ به‌طور عادی کار می‌کنند. این‌ها وقتی با تغییردهندهٔ اصلی فرمان ترکیب شوند رزرو می‌شوند: `T`، `W`، `N` و ارقام `1`–`9`.

این شامل جابه‌جایی فضای کاری با `Cmd/Ctrl + Alt + 1`–`9`، `Cmd/Ctrl + N` (فضای جدید، فضای کاری جدید، عامل جدید، افزودن مخزن) و `Cmd/Ctrl + T` / `Cmd/Ctrl + W` در فضاها و جزئیات PR می‌شود.
