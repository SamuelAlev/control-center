صفحه‌های مرجع توضیح می‌دهند **چه چیزی وجود دارد**، به‌صورت جامع و بدون تفسیر. از آن‌ها
برای یافتن چیزی استفاده کنید که پیش‌تر می‌دانید دنبال چه هستید: نام دقیق یک ابزار،
نوع یک گام، گذار یک وضعیت، یک مسیر، یک میان‌بر.

این صفحه‌ها برای خواندن از ابتدا تا انتها نوشته نشده‌اند. برای مطالعهٔ پیوسته از
[مفهوم‌ها](/fa-IR/راهنمای-کاربر/مفهومها/) استفاده کنید؛ برای انجام یک کار، به
[راهنماهای عملی](/fa-IR/راهنمای-کاربر/راهنماهای-عملی/) مراجعه کنید.
