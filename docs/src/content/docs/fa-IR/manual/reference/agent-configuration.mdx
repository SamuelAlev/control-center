این مرجع هر فیلد روی موجودیت عامل را به‌همراه enumها و پرچم‌هایی که به کار می‌برد فهرست می‌کند. برای یک راهنمای گام‌به‌گام از ساخت یا ویرایش یک عامل در برنامه، [ایجاد و پیکربندی یک عامل](/fa-IR/راهنمای-کاربر/راهنماهای-عملی/ایجاد-عامل/) را ببینید.

## فیلدهای موجودیت عامل

| فیلد                    | نوع                    | الزامی | توضیح                                                                                                                                                                                               |
| ----------------------- | ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | بله    | شناسهٔ یکتای عامل                                                                                                                                                                                   |
| `name`                  | `String`               | بله    | شناسهٔ کوتاه برای منشن‌های @                                                                                                                                                                         |
| `title`                 | `String`               | بله    | عنوان نقش خوانا برای انسان                                                                                                                                                                          |
| `agentMdPath`           | `String`               | بله    | مسیر مطلق فایل تعریف `.md` عامل                                                                                                                                                                     |
| `workspaceId`           | `String`               | بله    | فضای کاری مالک (نه null)                                                                                                                                                                            |
| `reportsTo`             | `String?`              | خیر    | شناسهٔ عامل والد                                                                                                                                                                                    |
| `skills`                | `AgentSkills`          | بله    | مجموعهٔ شناسه‌های مهارت                                                                                                                                                                             |
| `persona`               | `String?`              | خیر    | دستورالعمل‌های رفتاری متنی آزاد                                                                                                                                                                      |
| `systemPrompt`          | `String?`              | خیر    | جایگزینی پرامپت سیستمی پیش‌فرض                                                                                                                                                                      |
| `adapterId`             | `String?`              | خیر    | شناسهٔ آداپتور استنتاج                                                                                                                                                                              |
| `modelId`               | `String?`              | خیر    | شناسهٔ مدل در آن آداپتور                                                                                                                                                                            |
| `strictMode`            | `bool`                 | خیر    | پیش‌فرض `false`. در ردیف و در `AGENTS.md` عامل نوشته می‌شود                                                                                                                |
| `effort`                | `String?`              | خیر    | شناسهٔ سطح استدلال (مثلاً `'low'`، `'xhigh'`)، برگرفته از `thinkingLevels` مدل انتخاب‌شده                                                                                    |
| `contextSize`           | `int?`                 | خیر    | بیشترین اندازهٔ پنجرهٔ زمینه                                                                                                                                                                         |
| `role`                  | `AgentRole?`           | خیر    | نقش عامل                                                                                                                                                                                            |
| `capabilities`          | `AgentCapabilities?`   | خیر    | پیش‌فرض قابلیت هر عامل؛ وقتی null باشد، پیش‌فرض سطح کاربر هنگام اعزام اعمال می‌شود و یک گفتگو هنوز می‌تواند آن را نادیده بگیرد                                                                        |
| `monthlyBudgetCents`    | `int`                  | خیر    | سقف هزینهٔ ماهانه به سنت (پیش‌فرض `0`، بی‌نهایت)                                                                                                                                                     |
| `silenceTimeoutMinutes` | `int?`                 | خیر    | جایگزین مهلت سکوت به دقیقه؛ باید null باشد یا در بازهٔ 1–240 (با assert در سازنده)                                                                                                                   |
| `maxConcurrentTasks`    | `int`                  | خیر    | پیش‌فرض `1`. رقم ظرفیتی که مدل حضور گزارش می‌کند (شمارهای در حال اجرا و در صف با آن مقایسه می‌شوند)                                                                                                  |
| `visibility`            | `AgentVisibility`      | خیر    | پیش‌فرض `workspace`                                                                                                                                                                                 |
| `lifecycleStatus`       | `AgentLifecycleStatus` | خیر    | وضعیت حاکمیتی (پیش‌فرض `active`). با توقف سخت بودجه نوشته می‌شود و روی نمودار سازمانی و فهرست حضور رندر می‌شود. اعزام هنوز کار را از یک عامل `paused` می‌پذیرد                                          |
| `budgetPolicyId`        | `String?`              | خیر    | شناسهٔ سیاست بودجهٔ اشتراکی؛ وقتی null باشد `monthlyBudgetCents` مستقیم اعمال می‌شود                                                                                                                |
| `runtimeProfileId`      | `String?`              | خیر    | شناسهٔ پروفایل زمان اجرای سفارشی                                                                                                                                                                    |
| `createdAt`             | `DateTime`             | بله    | مُهر زمانی ساخت                                                                                                                                                                                     |

`name` و `title` هر دو باید ناتهی باشند (با assert در سازنده). پیش‌فرض `0` برای
`monthlyBudgetCents` یعنی بی‌نهایت. سقف را با `agents.upsert` بنویسید.

## پرچم‌های AgentCapabilities

در هر اعزام حل می‌شوند: پیش‌فرض خود عامل، با بازگشت به پیش‌فرض سطح کاربر وقتی null باشد، و با یک نادیده‌گرفتن در سطح گفتگو روی آن. با نبودِ آن اعمال می‌شوند — کارگزار اعتبارنامه به‌سادگی چیزی را که یک قابلیت خاموش پوشش می‌دهد نمی‌سازد و تزریق نمی‌کند.

| پرچم               | نوع    | پیش‌فرض | توضیح                                                                                     |
| ------------------ | ------ | ------- | ---------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false` | پوش دادن کامیت‌ها به ریموت؛ تزریق توکن GitHub را در کنار `canCallGitHubApi` کنترل می‌کند   |
| `canCallGitHubApi` | `bool` | `false` | فراخوانی api.github.com؛ تزریق `GH_TOKEN` و دامنه‌های خروج GitHub را کنترل می‌کند           |
| `canCallTicketing` | `bool` | `false` | فراخوانی API ارائه‌دهندهٔ تیکتینگ؛ تزریق کلید API ارائه‌دهنده و دامنه‌های خروج آن را کنترل می‌کند |
| `canAccessNetwork` | `bool` | `true`  | خروج بیرونی دلخواه. ابزارهای `web_fetch` و `web_search` هارنس را هم کنترل می‌کند           |

`AgentCapabilities.safeDefault` همان هر چهار پیش‌فرض سازنده است. `legacyDefault` (هر چهار مورد true) فقط توسط مهاجرتی استفاده می‌شود که گفتگوهای ساخته‌شده پیش از وجود قابلیت‌ها را پر کرد. یک بلاب ذخیره‌شدهٔ بدشکل یا تهی به `safeDefault` تجزیه می‌شود؛ کلید قدیمی `canCallLinear` به‌عنوان `canCallTicketing` خوانده می‌شود.

## AgentSkills

مجموعه‌ای تغییرناپذیر و بدون حساسیت به بزرگی و کوچکی حروف از شناسه‌های مهارت. هنگام اعزام، آن اسلاگ‌ها به‌صورت پیوندهای مهارت در overlay عامل همگام می‌شوند؛ سپس هارنس فرانت‌متر مهارت‌های پیوندشده را به‌طور خودکار در پرامپت بارگذاری می‌کند.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (مشتق‌شده)

ذخیره نمی‌شود. هفت مقدار. ترتیب اعلان همان ترتیب اولویت است (`sortPriority`، با یک تست سنجاق شده)، و همان ترتیبی است که فهرست حضور بر پایهٔ آن مرتب می‌شود:

| وضعیت       | `sortPriority` | شرط                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | هر گزارش اجرایی وضعیت `running` داشته باشد                                                                          |
| `blocked`   | 1              | زنده‌بودن آخرین اجرا `blocked`، `stalled` یا `looping` باشد                                                         |
| `failed`    | 2              | وضعیت آخرین اجرا `error` باشد، یا زنده‌بودنش `failed` یا `dead`                                                     |
| `queued`    | 3              | اجرایی اعزام شده اما در حال اجرا نیست — پشت اجرایی دیگر از همان عامل پارک شده، یا نوشته شده اما هنوز آغاز نشده است |
| `succeeded` | 4              | اجرا با موفقیت تمام شده است                                                                                         |
| `idle`      | 5              | عامل قبلاً اجرا شده و کاری در پرواز ندارد                                                                           |
| `neverRun`  | 6              | هیچ گزارش اجرایی وجود ندارد                                                                                         |

`queued` و `succeeded` **فقط برای هر اجرا** هستند. `deriveAgentLiveState` که وضعیت فهرست حضور یک عامل را محاسبه می‌کند هرگز هیچ‌یک از این دو را تولید نمی‌کند — `neverRun`، `running`، `failed`، `blocked` یا `idle` را برمی‌گرداند.
