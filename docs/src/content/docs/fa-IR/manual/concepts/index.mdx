These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/fa-IR/راهنمای-کاربر/راهنماهای-عملی/); when you want to look
something up, go to the [reference](/fa-IR/راهنمای-کاربر/مرجع/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/fa-IR/راهنمای-کاربر/مفهومها/فضاهای-کاری/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/fa-IR/راهنمای-کاربر/مفهومها/مدل-عامل/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/fa-IR/راهنمای-کاربر/مفهومها/چرخه-عمر-اعزام/) — what happens between your message and the agent's first token
- [Modes](/fa-IR/راهنمای-کاربر/مفهومها/حالتها/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/fa-IR/راهنمای-کاربر/مفهومها/بافت-ابزار/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/fa-IR/راهنمای-کاربر/مفهومها/هوش-کد/) — the code graph, language server, structural search and debugger
- [Conversation history](/fa-IR/راهنمای-کاربر/مفهومها/تاریخچه-گفتگو/) — persistence, compaction and forking a transcript
