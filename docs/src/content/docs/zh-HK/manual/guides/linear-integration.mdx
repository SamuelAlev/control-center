把 Linear API 金鑰貼到伺服器上並繫結到你的用戶，就像連接程式碼託管一樣。
工單、項目、連結、協作者、委派與指派全都對着 Control Center 自己的資料庫運作，
無需任何外部服務——參見[建立與管理工單](/zh-HK/手冊/操作指南/管理工單/)。

## 儲存你的 Linear 金鑰

**工單 API 金鑰**位於 **設定 → 工作區 → 一般**，就在**工單系統**卡片上。它會以你的
用戶 id 為鍵，把金鑰存放在伺服器上。伺服器為無人操作的工作所用的自有金鑰，來自
`LINEAR_API_KEY` 或**供應商應用**卡片，而且只有在該代理具備**允許工單 API 呼叫**
能力時，才會以 `TICKETING_API_KEY` 注入。

## 將新工單標記為 Linear

**工單供應商**（新手導引的第一步，以及
`/workspaces/<workspaceId>/api-keys`）提供 `local` 和 `linear`。選擇
`linear` 之後，你往後建立的工單都會蓋上 `provider: linear`。
