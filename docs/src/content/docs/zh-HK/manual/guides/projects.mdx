項目是以工作區為範圍的工單分組，用來朝著共同目標邁進。項目只存在於
Control Center——永遠不會同步到 Linear 之類的外部供應商。

## 建立項目

1. 展開工作區側邊欄中的**工單**群組。它會依序列出**所有工單**、每個未歸檔項目
   各佔一列，然後是**新增項目**。
2. 點擊**新增項目**。
3. 填寫**項目名稱**、可選的**描述**，並選擇一種**顏色**。
4. 按下**建立項目**。

你會進到新項目的概覽，而該項目會以側邊欄資料列的形式出現在**工單**之下。

## 將工單加入項目

項目是單張工單上的欄位，可在以下兩個位置之一設定：

- 開啟工單，並在其屬性欄中設定**項目**。
- 在清單中以右鍵點擊該工單，然後使用**項目**子選單。

屬性欄的選擇器也提供**新增項目**，讓你即時建立項目並把工單歸入其中。
**無項目**會清除此欄位。

一張工單最多只屬於一個項目。

:::note[項目不是批次操作]
選取多張工單時出現的浮動列，涵蓋狀態、優先級、負責人、標籤與刪除。它沒有
項目晶片，因此要歸入大量工單時，只能逐一處理。
:::

你也可以從項目著手：項目概覽上的**新增工單**會建立一張工單並歸入該項目。

## 查看項目進度

從側邊欄資料列開啟項目，或前往
`/workspaces/<workspace-id>/projects/<project-id>`。

概覽會顯示項目的圖示與名稱、狀態徽章、描述，以及「已完成／總數」的進度條。
其下方會按狀態把項目的工單分組。

它不會彙總其他內容——沒有負責人分佈，也沒有優先級分佈。如要查看這些，請改為
篩選主工單清單。

## 變更項目狀態

項目有三種狀態：

| 狀態       | 含義         |
| ---------- | ------------ |
| **進行中** | 工作仍在進行 |
| **已完成** | 所有工作均已完成 |
| **已歸檔** | 僅作歷史參考 |

使用項目頁首上的 **⋯** 選單。它提供**編輯項目**、
**標示為已完成**／**標示為進行中**、**歸檔**／**還原**，以及
**刪除項目**。

歸檔會把項目從側邊欄清單與工單選擇器中隱藏。此操作可以還原——**還原**會把項目
回復為進行中——但在已歸檔期間，項目只能透過網址存取。

## 為你建立的項目

核准一次編排會建立一個項目，並把父工單歸入其中，與你手動歸入的內容並列。
產出的工作項目是管線步驟，而不是工單資料列，因此不會出現在項目板上。
這是唯一的自動路徑：沒有任何管線節點會建立工單，所以管線無法為項目填入內容。參見
[執行編排](/zh-HK/手冊/操作指南/執行編排/)。

:::note[項目是操作者專用的介面]
請在應用程式中建立、列出、更新與刪除項目。代理沒有
項目工具。
