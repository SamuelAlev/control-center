每篇指南都為**已經熟悉操作方式的讀者解決一個問題**。這些指南假設你已安裝
Control Center，並已設定好工作區；它們在標題中訂明目標，並在達成目標後結束。

如果你仍在學習這套產品，請先閱讀[教學](/zh-HK/手冊/教學/)。
如果你想了解某項行為_為何_會這樣，請閱讀[概念](/zh-HK/手冊/概念/)。
