本指南說明如何把你的聊天身分連結到你的 Control Center 使用者，以及如何取消連結。

每位成員都要為每個聊天提供方做一次。這件事與連接應用程式是分開的：連接讓整個工作區都能觸達機械人，連結則讓_你_在當中可被辨識。

## 為何必須連結

對於無法解析到工作區成員的聊天帳戶，橋接會拒絕代它行事。這是刻意的——沒有連結的話，每一則來自 Slack 的訊息都只能歸到安裝應用程式的那個人，稽核紀錄、按主體計算的速率限制和工單報告人都會指向錯誤的人。

未連結的成員提及機械人時，會在該 Slack 討論串中收到一則回覆，說明如何連結。不會派發任何工作。

## 以代碼連結

連結需要兩邊配合：從 Slack 傳送代碼證明了那個 Slack 帳戶，而在 Control Center 中確認則證明那個帳戶是你的。

1. 前往 **設定 → 你 → 個人資料**，找到**已連結的聊天帳戶**卡片
2. 在 Slack 區塊上，按一下**連結我的 Slack 帳戶**。對話框會顯示一個一次性代碼，例如：

```text
K7M2QP
```

3. 在 Slack 中以**私訊**把該代碼傳送給機械人：只傳代碼，不要加其他內容
4. 機械人會回覆「Got it. Confirm this Slack account in Control Center to finish linking.」，而你一直開着的對話框會顯示傳送該代碼的 Slack 個人資料：名稱和 Slack 成員 id
5. 如果那是你的帳戶，按一下**確認**。連結隨即建立，對話框會說明此事，機械人也會在同一則私訊中確認
6. 如果那不是你的帳戶，按一下**拒絕**。不會建立任何連結，代碼亦會失效；按一下**取得新代碼**再試一次

關閉對話框不會令認領遺失。稍後才送達的代碼會在該卡片的**連結我的 Slack 帳戶**那一列等候，同樣提供**確認**和**拒絕**。

為甚麼需要確認這一步：有人從你身後偷看到代碼，再從別人的 Slack 帳戶傳送出去，否則便能令那個帳戶以你的身分行事。只有你能確認，而且只能確認傳送該代碼的那個確切個人資料。

該代碼：

- 只能使用一次，並在產生後 **15 分鐘**過期
- 永遠是為_你_產生，不會為隊友產生
- 只在傳給機械人的私訊中有效。在頻道中它只是一則普通訊息
- 只能由機械人所安裝的 Slack 工作區的正式成員認領，訪客或來自其他組織的人都不行
- 會取代你已持有的任何代碼，因此再按一次按鈕會令先前那個失效
- 只存在於記憶體中，因此伺服器重新啟動會令尚未使用的代碼失效——請再按一次按鈕

未知、已過期、已被拒絕，或為其他工作區產生的代碼，都會以同樣無法分辨的方式失敗：「That code is not valid (or has expired).」

## 以電郵自動連結

如果你的 Slack 個人資料帶有已確認的電郵，而該電郵對應到一位**已是本工作區成員**的 Control Center 使用者的已驗證電郵，橋接會在你第一次與它對話時把你連結起來。無需代碼。

Control Center 一方的電郵會被視為已驗證，條件是單一登入或 SCIM 設定了該地址，或伺服器擁有者已在**設定 → 伺服器 → 人員**中確認它。你在自己的個人資料中輸入的地址並未經過驗證，因此在擁有者確認之前不會連結任何東西；在此之前請改用代碼流程。

兩邊都重要：電郵匹配證明身分，但只有成員身分才授予存取權，所以一個地址恰好在伺服器上存在的陌生人，什麼也連結不到。名冊會顯示每個連結是如何建立的（「以電郵匹配」或「以代碼連結」）。

自動連結需要 `users:read.email` 權限範圍。沒有它，Slack 不會披露該地址，代碼流程就是唯一途徑。

## 查看誰已連結

名冊屬於工作區管理，所以位於管理員卡片中：**設定 → 工作區 → 整合 → 聊天橋接 → 已連結帳戶**。它會列出工作區中每位已連結的成員、各自對應的 Slack 帳戶，以及連結是如何建立的。

你自己的狀態則在 **設定 → 你 → 個人資料**：**連結我的 Slack 帳戶**那一列在你已連結後會顯示「已連結至 _your-slack-id_」，未連結時則提示你去連結。

名冊和認領都是即時訂閱，因為變更發生在另一邊：你是在 Slack 中傳送代碼，所以從應用程式發出的任何請求都無法把結果帶回來。

## 取消連結

在工作區名冊的其中一列上按一下**取消連結**。

- 任何人都可以取消連結自己
- 只有管理員可以取消連結其他成員
- 取消連結也會撤銷該成員任何尚未使用的連結代碼

取消連結後，該 Slack 帳戶在重新連結之前都無法再驅動代理。現有的空間、轉錄和工單會保留原本的歸屬——取消連結並不是撤回過去的工作。

## 疑難排解

### 機械人說我不是本工作區的成員

你的 Slack 帳戶已連結到某位 Control Center 使用者，但該使用者並未持有本工作區的成員身分。請管理員邀請你；參見[多人協作與線上狀態](/zh-HK/手冊/概念/多人協作/)。

### 機械人說我的角色是唯讀

`viewer` 和 `guest` 角色無法開始工作。管理員必須把你的角色提升到 `member` 或以上。

### 機械人說代碼無效

代碼已過期、已被使用、已被拒絕，或已被較新的代碼取代。請再按一次**連結我的 Slack 帳戶**並傳送新的代碼。

### 機械人把我的代碼當作請求

你是在頻道中傳送的，或你的 Slack 帳戶已經連結。代碼只在私訊中被接受，而來自已連結帳戶、看似代碼的訊息會被當作一般請求。
