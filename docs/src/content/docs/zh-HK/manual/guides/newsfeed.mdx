本指南說明如何塑造資訊動態：它會抓取哪些來源、文章如何被閱讀，以及內容封鎖有甚麼作用。

:::caution[資訊動態以每位使用者為單位，而非以工作區為範圍]
訂閱源與文章屬於登入中的使用者：你的訂閱源清單、已讀狀態與書籤會跟隨你進入每個工作區，以及你登入的每一部裝置，其他使用者都看不到。訂閱源存放在伺服器的全域資料庫中，因此 `/newsfeed` URL 帶有工作區 id，只因為應用程式內每條路由都如此。
:::

## 閱讀文章

1. 在側邊欄按一下 **資訊動態**
2. 用工具列的區段在 **全部**、**未讀** 與 **已儲存** 之間切換
3. 用搜尋框或來源選擇器收窄清單
4. 用版面按鈕在雜誌式格狀與密集清單之間切換

開啟文章即會將它標為已讀。使用頁面標題的 **全部標為已讀**（它只在有未讀項目時出現）一次清空積壓的文章，並使用卡片上的書籤控制項把文章儲存起來稍後閱讀。

版面選擇會在每次啟動後保留。

## 新增訂閱源

1. 開啟 **設定 → 你 → 資訊動態**（資訊動態標題列的設定圖示可直接前往該處）
2. 按 **新增訂閱源**
3. 填寫**名稱**與**訂閱源 URL**（RSS 或 Atom）
4. 可選擇展開**進階**並設定自訂的 **User-Agent**——部分發佈者對預設用戶端會回傳不同的回應
5. 按 **新增訂閱源**

檢查點：該訂閱源會出現在**訂閱源**清單中，其文章會在首次抓取後送達。已訂閱的 URL 會被拒絕，並顯示「此 URL 的訂閱源已存在。」

首次使用時，每位使用者都會預先植入十四個訂閱源：Control Center、The Verge、TechCrunch、Hacker News、ByteByteGo、Product Hunt、TLDR AI、Import AI、The Pragmatic Engineer、Martin Fowler、Will Larson's Irrational Exuberance、The Engineering Manager、Lea Verou 與 CSS-Tricks。

## 管理訂閱源

**訂閱源**清單中的每一列都提供三個控制項：

| 控制項       | 效果                                                     |
| ------------ | -------------------------------------------------------- |
| 開關         | 停用該訂閱源。已停用的一列會變暗，且不再被抓取           |
| 重新整理圖示 | 立即抓取這一個訂閱源                                     |
| 垃圾桶圖示   | 經確認後刪除該訂閱源                                     |

清單頂部的**全部重新整理**會抓取每個已啟用的訂閱源。

訂閱源的副標題會顯示其描述，以及上次抓取是多久之前；抓取失敗的訂閱源會在其位置以警告顏色顯示錯誤。

沒有提供編輯功能——如要更改訂閱源的名稱、URL 或使用者代理，請刪除它再重新新增。

抓取完全在伺服器上執行：每位使用者在開機時一次（其後建立的帳戶則在首次使用時），之後每 30 分鐘一次。

## 在閱讀器中封鎖廣告與追蹤器

1. 在「設定 → 你 → 資訊動態」中，找到**閱讀器偏好**
2. 保持**在應用程式內開啟文章**為開啟，以使用內建閱讀器；或關閉它，把文章交給系統瀏覽器
3. 保持**封鎖廣告、追蹤器與 Cookie 橫幅**為開啟

封鎖預設為開啟。內嵌閱讀器僅支援 macOS 與 Windows：在網頁組建與 Linux 上，系統瀏覽器_就是_閱讀器，文章會在那裏開啟（網頁上為新分頁）。在網頁上，封鎖開關、**篩選清單**卡片與**受信任網站**卡片都會隱藏。

應用程式內閱讀器不會重新排版文章。它會把發佈者的頁面渲染在內嵌 webview 中，並使用快取的篩選清單抑制廣告、追蹤器與 Cookie 橫幅。

### 檢查或更新篩選清單

**篩選清單**卡片會顯示已載入多少條隱藏 Cookie、隱藏廣告與封鎖網絡的規則，以及它會移除的追蹤參數，還有清單上次更新的時間。按 **檢查更新** 即可重新整理它們。

來源包括 EasyList、i-dont-care-about-cookies、Fanboy Cookiemonster、多份 uBlock Origin 清單，以及 uBO 的追蹤參數清單。在下載成功之前，卡片會把清單標示為從未更新過的內建預設值——廣告、Cookie 與網絡規則的數量會維持為零；追蹤參數的移除仍然使用一組內建預設值。

### 把網站加入允許清單

有些網站在封鎖下會故障。

1. 在「設定 → 你 → 資訊動態」中，前往**受信任網站**
2. 按 **新增受信任網站** 並輸入網域

該網域會略過封鎖。

## 疑難排解

### 我新增的訂閱源出現在另一個工作區

這是預期行為。資訊動態以每位使用者為單位，而非以每個工作區為單位——你的訂閱源會跟隨你到所有已登入的地方。請參閱最上方的注意事項。

### 訂閱源的一列顯示錯誤而非描述

上次抓取失敗，該列會逐字顯示原因。按重新整理圖示重試，並檢查該 URL 是否仍提供 RSS 或 Atom。拒絕未知用戶端的發佈者可能需要自訂使用者代理，這意味着要刪除該訂閱源再重新新增。

### 文章頁面顯示異常

透過**受信任網站**為該網域關閉**封鎖廣告、追蹤器與 Cookie 橫幅**，或關閉**在應用程式內開啟文章**，改在瀏覽器中閱讀。
