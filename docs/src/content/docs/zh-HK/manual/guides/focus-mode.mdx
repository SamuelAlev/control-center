本指南說明如何運行一個專注時段：一段計時的時間，期間 Control Center 會封鎖非緊急通知，並在你的其他視窗上方懸浮顯示一個倒數膠囊。本指南亦會介紹在其下（預設）播放的聲景——一段由你的伺服器即時合成的無盡環境音軌，並由你所選的情境、室外的天氣以及一天中的時段共同塑造。

專注時段是 shell 層面的功能。它不綁定任何支柱——它不會改變版面、隱藏側邊欄，也不會改動 PR 審查介面。

:::note[僅限桌面版]
懸浮膠囊與聲景的彈出迷你播放器都是原生同級視窗，只由桌面版啟動程序掛載。`app.usectrl.dev` 的 Web 版本兩者皆無，也沒有作業系統通知管道，因此專注時段在那裡既沒有可顯示的內容，也沒有可封鎖的內容。聲景面板及其播放功能，在你連線到伺服器的任何地方都能運作。
:::

## 開始專注時段

1. 點擊標題欄右側的專注圖示（工具提示 **開始專注時段**）
2. 在對話框中輸入選填的**目標**——你正在做什麼
3. 選擇**時長**：25m、50m、1h、1h 30m 或 2h。預設為 50m，並會記住你上次的選擇
4. 按下**開始**

檢查點：標題欄按鈕會被一個顯示剩餘分鐘數的強調色標籤取代，懸浮膠囊會出現在你的其他視窗上方，而且在**隨專注模式啟動**開啟時，聲景會開始播放。

另外兩個入口也能到達同一個時段：

- **⌘K → 開始專注時段**會開啟同一個對話框。
- **⌘⇧⌥F** 會以你記住的時長、不設目標立即開始一個時段——它會略過對話框。再次按下則會結束該時段。

## 讀懂懸浮膠囊

膠囊是一個無邊框的小視窗，你可以把它拖到任何位置。它會顯示：

- 一個即時的線上狀態圓點，以及以 `mm:ss` 顯示的剩餘時間
- 你的目標；未設定目標時顯示「專注時段」
- 沿著底邊的細進度條

將游標懸停在上面，會顯示兩個操作：

- **暫停** / **繼續** — 停止倒數。暫停只作用於膠囊本身；時段本身仍保持運作。
- **完成** — 結束該時段。

無論主視窗使用什麼主題，膠囊都固定採用深色配色，因為它懸浮在任意的桌面內容之上。

如果你從標題欄關閉膠囊，時段仍會繼續運行。按下專注標籤旁邊的子母畫面按鈕（工具提示 **最小化為浮動列**）即可把它叫回來。

## 了解哪些內容會被封鎖

當時段運作中時，Control Center 會捨棄除兩類以外的所有通知，而這兩類一律會送達：

- **會議即將開始** — 事後才看到的會議提醒毫無價值
- **PR 已發布**

其餘一切在整個時段內都會被靜默封鎖——沒有聲音，也沒有作業系統提示。被封鎖的通知不會排隊留待稍後送達。

## 播放聲景

1. 點擊標題欄右側的揚聲器圖示（工具提示 **聲景**）以開啟面板
2. 選擇一個**情境**——**專注**、**上升**、**放鬆**或**睡眠**
3. 按下**播放**

檢查點：**正在播放**卡片會顯示目前場景的名稱——你工作區所在位置的天氣、以 °C 表示的溫度，以及位置標籤。當它顯示「正在調整環境音…」時，場景仍在解析中。

這段音軌不是循環播放。你的伺服器會根據情境、工作區所在位置的即時天氣以及一天中的時段，持續合成它。雨聽起來明亮而繁忙，暴風雨響亮而多陣風，霧則低沉發悶；夜晚比正午更暗、殘響更重。情境決定了它的詞彙：

| 情境   | 聲音                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 專注   | 柔和而警覺的環境音，帶有低沉的脈衝——意在襯托工作                                       |
| 上升   | 輕快的旋律，帶有柔和的脈衝——適合工作令人感到沉重時                                     |
| 放鬆   | 更溫暖、更和諧的和聲襯底，沒有節拍                                                     |
| 睡眠   | 幾乎沒有事件的低沉持續音，殘響深沉                                                     |

播放期間切換情境，會把播放交給新的情境，而不會停止。

也可以從 ⌘K 的**專注**類別下開啟該面板，它就在專注時段旁邊。

## 塑造聲音

- **調性**（專注、上升與放鬆）— 一個帶有可拖曳圓點的方形調性板。水平方向是**柔和**到**活力**（發生的事情有多少），垂直方向是**空靈**到**明亮**（聽起來有多開闊）。在調性板上點兩下可重設至中性中心；方向鍵可微調圓點。你的調性設定會按情境分別記住，而調整會平滑地融入正在運行的混音——音訊流永不重新開始。睡眠情境按設計不可調音。
- **音量** — 一個從 0 到 100% 的滑桿，預設為 60%。它獨立於系統音量，並且會被記住。
- **位置** — 從工作區自動偵測。按下**重新整理天氣**可重新取得場景。

## 彈出迷你播放器

音訊播放時，標題欄會多出第二個按鈕（工具提示 **彈出播放器**）。它會懸浮出一個小型、永遠置頂的 HUD，包含播放／暫停、天氣圖示、場景名稱，以及一個**返回應用程式**按鈕——當專注時段讓你完全投入另一個應用程式時，這非常方便。

從迷你播放器暫停並不會關閉它；只有它的關閉按鈕（或結束應用程式）才會把它移除。

## 同時運行兩者

這兩個功能由聲景面板中的一個開關互相連結：**隨專注模式啟動**，預設為開啟。

- 如果目前沒有正在播放的內容，開始一個專注時段會同時啟動聲景。
- 結束該時段——無論以何種方式結束，包括計時器耗盡——都會停止它，即使聲景是你手動啟動的。

關閉該開關即可讓兩者保持獨立。

## 結束時段

以下任一操作都會結束它：

- 點擊標題欄中的專注標籤（工具提示 **專注模式作用中—點擊以結束**）
- 在膠囊上按下**完成**
- 按下 **⌘⇧⌥F**
- 在 ⌘K 中選擇**結束專注模式**
- 讓計時器耗盡——時段會在歸零時自動完成

膠囊會關閉，通知立即恢復，聲景停止。

## 了解哪些內容不會持久保留

一個時段只在一次應用程式運行期間存在。結束並重新開啟 Control Center 後，你會從未啟用狀態與已重設的計時器開始，即使是在時段中途亦然——沒有當機復原，也沒有時段記錄。

只有兩樣東西會保留：你偏好的時長與封鎖通知標誌。目標、已過的時間以及膠囊的開啟狀態都不會保留。

播放同樣短暫——聲景在啟動時一律處於停止狀態。你的情境、音量與各情境的調性設定會持久保留；音訊流本身永遠不會自行恢復。

## 故障排查

### 調性板不見了

你目前處於睡眠情境，它按設計不可調音。切換到專注或放鬆即可找回調性板。

### 重新啟動應用程式後沒有任何聲音

這是刻意設計——播放一律會在應用程式啟動時停止。開啟面板並再次按下**播放**。如果仍然沒有聲音，請檢查面板的音量滑桿，它獨立於系統音量。

### 天氣或溫度看起來不對

場景會跟隨目前使用中工作區的位置。在面板中按下**重新整理天氣**即可重新取得它。
