本指南說明如何親手啟動一次執行。要觀察一次執行的過程、讀取步驟輸出，以及從失敗中
復原，請參閱[監察管線執行](/zh-HK/手冊/操作指南/監察管線/)。

## 啟動一次執行

1. 在工作區側邊欄中點擊 **管線**。
2. 在頁首按下 **執行管線**。你會落到執行選擇器
   （`/workspaces/<workspace-id>/pipelines/run`）。
3. 在左側欄挑選一個範本。每張卡片會顯示範本的名稱、描述，以及它是否接受輸入。
4. 在右邊填寫輸入表單。必填欄位在有值之前會一直停用按鈕；沒有輸入的範本會
   明確說明這一點。
5. 按下 **執行管線**。

你會落到該次執行的詳情頁，並即時看到時序瀑布圖與圖畫布。

## 如果左側欄是空的

只有當以下**兩項**條件同時成立時，執行選擇器才會顯示某個範本：

- 該範本的開關已在 **設定 → 工作區 → 管線範本** 中打開。
- 範本編輯器的 **手動執行** 對話框中的 **允許手動執行** 已打開 —— 正是這個開關
  建立了執行選擇器所讀取的 `manual` 觸發器。

十三個內建範本中有八個出廠時處於停用狀態：`external_pr_welcome`、
`cross_review`、`ticket_to_pr`、`pr_triage`、`pre_merge_gate`、`release_notes`、
`dep_audit` 與 `pr_digest`。引擎會拒絕啟動已停用的範本，因此請先打開它的開關，
再到這裡尋找它。

範本清單上沒有針對個別範本的 **執行** 操作，編輯器內也沒有執行按鈕 —— 執行選擇器
是唯一的手動入口。

## 填寫程式庫輸入

類型為 **程式庫** 的輸入，會在該工作區已註冊的程式庫之上渲染一個選擇器。選定一個
程式庫，會把 `repo_id`、`repo_local_path`、`repo_full_name`，以及 —— 當該程式庫
有 GitHub 遠端時 —— `repo_owner` 與 `repo_name` 填入執行載荷，讓下游步驟可以讀取
各自所需的欄位。

## 觀察它執行

執行詳情頁由三個部分組成：元資訊條（開始時間、有效時長、步驟進度、失敗橫幅、
**重試** 與 **刪除**）、可摺疊的時序瀑布圖（附每個步驟的時長與成本），以及圖畫布。
選取某個節點會打開該步驟的詳情面板。

[監察管線執行](/zh-HK/手冊/操作指南/監察管線/)涵蓋了這一切，包括如何讀取已暫停的
步驟，以及某個步驟失敗時該怎樣做。

你從應用程式啟動的每一次執行，都是真實的執行。
