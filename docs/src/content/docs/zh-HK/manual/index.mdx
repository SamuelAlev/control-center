## 你可以做甚麼

- **向代理發訊息**：空間是驅動整隊代理的主要方式。@ 提及代理，它就會派發到自己的寫入時複製 worktree，讓多個代理可以同時編寫和審查程式碼，而不會干擾你的 checkout
- **編排大型任務**：給編排器一個目標，一次過核准它提出的全隊計劃，然後由自動產生的[管線](/zh-HK/手冊/概念/管線/)執行
- **審查並合併 PR**：內建差異檢視器、行內註解與 AI 輔助審查
- **給代理用完即棄的機器**：[測試機](/zh-HK/手冊/操作指南/使用測試機/)是一部用完即棄的虛擬機——可以是瀏覽器、桌面、手機或隔離終端——由代理操作，你可以即時觀看並接手；當中的開發伺服器會轉送到 `localhost`、代理的瀏覽器及 `https://myapp.test`
- **自動化工作流程**：以事件或排程觸發的 DAG 管線
- **管理知識**：工作區範圍的記憶、事實與政策
- **追蹤工作**：不綁定特定供應商的工單、項目與委派
- **錄製會議**：在裝置上擷取、轉寫並區分發言人，然後摘要為筆記、行動項目與決定
- **掌握你的一天**：Google Calendar 同步、回覆邀請、會議提醒與錄製並連結
- **用手機追蹤整隊代理**：將裝置與你的伺服器配對，然後閱讀訊息、回覆及整理工單。手機會選用可達的最佳路徑——loopback、LAN、tailnet 或 TLS——並在必要時退回端對端密封的中繼，只轉送它無法解讀的訊框
- **從 Slack 驅動代理**：將工作區橋接到聊天應用程式，然後提及機械人、在 Slack 討論串中回覆，或以斜線指令開立工單——經由對外連線進行，因此無需公開端點
- **整合** GitHub、Linear、Slack、Google Calendar 及超過 100 個 MCP 工具

## 你不一定要安裝它

同一個應用程式也可在瀏覽器上於
[app.usectrl.dev](https://app.usectrl.dev) 執行，功能完全相同。

每個用戶端——桌面、網頁與手機——都只是無介面伺服器上的精簡轉譯層，
伺服器擁有你的資料並實際執行工作。桌面應用程式可以代你啟動該伺服器；
瀏覽器分頁無法做到，因此網頁應用程式會連接到由你自行執行的伺服器。
該伺服器可以位於你自己的電腦上（`ws://localhost:9030`，無需憑證），
也可以位於可經 TLS、VPN 或隧道連線的遠端主機上。

瀏覽器途徑請參閱[安裝](/zh-HK/手冊/安裝/#use-it-in-your-browser)，
三個用戶端之間的關係請參閱[部署與用戶端](/zh-HK/手冊/概念/部署/)。
