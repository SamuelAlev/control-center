**可觀測性 → 品質**同時包含針對單一任務的評估套件，以及成對進行的技能評估活動。技能評估活動所量度的是某個封裝在某個特定模型與 harness 下被使用時的表現，而不是它自身的 Markdown 質素。

## 評估套件

**評估套件**是一種以工作區為界的任務定義，用來針對某個代理執行：一段提示詞、一個目標代理與模式、可選的預備步驟、一個帶有固定 SHA 的可選夾具，以及一組評分器。評分器以確定性檢查為先；確定性檢查無法表達的部分，則交由按 LLM 評分標準判斷的評審處理。

建立工作區時會預置五個入門套件。它們涵蓋編排提案、能找出預置錯誤的審查、計劃模式維持唯讀、計劃模式產出計劃，以及工單往返。預置程序會監聽 `WorkspaceCreated`（`workspace.upsert` 或 `workspace.create`），略過已存在的名稱，亦不會回填較早的工作區。

### 它們出現的位置

**可觀測性 → 品質**（`/workspaces/<id>/observability`）會列出工作區內的每個套件。

透過 `evals.upsertSuite`、`evals.deleteSuite` 和 `evals.watchSuites` 來建立、列出、編輯和刪除套件。品質分頁就是這份清單，而這些操作就是編輯器。

## 技能評估活動

一次活動會在相同的任務與執行設定下比較兩個組別。候選技能可以是不存在、以正常方式可用、被明確載入，或與較早的修訂版本或固定的環境技能清單比較。這些方式回答的是不同的問題；強制載入是一種診斷手段，而不是正常探索過程的得分。[技能指南](/zh-HK/手冊/操作指南/管理技能/#評估技能)說明如何選擇比較方式，以及如何授權一次帶預算的執行。

證據屬於一個精確的**整包雜湊**：`SKILL.md`、中繼資料、指令碼、參照與資產。伺服器會擷取已掃描的不可變封裝，並固定任務集、配接器、提供者／原生模型標識、協定、工具結構描述與環境技能清單。原生 Claude 活動亦會固定受管理帳戶與觀測到的 CLI 版本。修改某個參照會使目前的證據失效，即使 `SKILL.md` 沒有變動也一樣。模型別名記錄的是所要求的內容，而不是提供者不可變的權重。

每次嘗試都會取得全新的上下文、主目錄與夾具狀態。成對組別除所宣告的技能介入外，使用相同的政策與任務條件。目標不存在意味着候選技能的中繼資料與檔案無法取得，而不是所有背景指令或技能都被移除。在正常探索的比較中，任務提示詞不得點名候選技能。

授權、執行、預算與工作區持久化都由伺服器負責。用戶端選擇設定並呈現證據。進度在重新連線後依然保留；取消會保留部分結果，而重新啟動會把未完成的工作標示為已中斷，而不是靜默重跑付費呼叫。這些活動並不提供針對任意評估套件的獨立執行器契約。

## 審慎解讀證據

- **正確性由結果決定。** 獨立的帶型別驗證器檢查產物與最終行為，而不是代理自稱成功。預期答案保留在候選技能的隔離邊界之外；產生的程式碼會在另外隔離的副本中評分。
- **載入與實用是兩回事。** 可用性、內文／參照的載入，以及觀察到的指令碼使用情況說明了執行過程。讀取某個檔案並不證明模型遵循了它的指令；無法觀察的存取仍然未知。
- **保留相配的基準。** 單憑候選技能一次成功的執行，並不能確立收益。請納入可用技能被忽略的嘗試、失敗的嘗試及其成本；不要只保留最好的那次重試。
- **重複執行並不是新任務。** 報告會按任務聚類不確定性。樣本太小、覆蓋不足、身分漂移與未知開支都不足以支持採用建議。一次已完成的活動仍可能無法判定；未能顯示改善，並不等於證明了等效或回歸。
- **檢查個別的回歸。** 整體收益不得掩蓋某個受損的任務或未經授權的副作用。安全掃描、執行期間的安全觀察與實用性保持互相獨立；更便宜的執行無法彌補質素或安全證據的缺失。
- **不要混合不相容的結果。** 另一個模型、harness、政策、夾具或技能組合就是另一種設定。請把留出集上的遷移與組合證據，與開發用例分開保留。

本地撰寫的九個試點任務集包含 108 個任務項目，涵蓋實用性、按家族劃分的路由／安全，以及留出集上的遷移／組合。請選擇與技能用途相配的家族。參照解答與已知的不良輸出用於檢驗驗證器；這些夾具並不是對某個公開基準的複現，也不構成任何已安裝技能實用的證據。以指令碼化提供者回應進行的實作煙霧測試，並不是在真實模型上量度技能質素。

## 執行與證據限制

受控的**內建 harness** 與 **Claude Code** 兩種配接器都受支援。隔離與有效的憑證必須在執行前通過檢查。內建提供者要求有成文的工具支援、權杖限制與定價；Codex OAuth 驗證自己的帳戶，而不要求另外的 OpenAI API 金鑰。Claude Code 使用預設的受管理帳戶、具體的模型 ID 及其原生的 API 等價成本報告。

Claude Code 與 Codex OAuth 使用**用量停止臨界值**：進行中的呼叫可能超出預算，隨後後續呼叫即停止。這既不是計費的訂閱開支，也不是硬性帳單上限。使用 API 金鑰的提供者保留保守的呼叫前預留。觀察到的未知開支會為每種配接器停止後續呼叫；不完整的覆蓋仍屬部分或無法判定。

Claude 在私有的控制器目錄中執行其原生模型迴圈，內建工具與環境技能均已停用。它唯一的工具是經過驗證、歸伺服器所有的 MCP 橋接，通往內建 harness 所用的同一個受約束客體。憑證留在該客體之外。CLI 身分或工具介面的變化會使該次嘗試失效，而不是悄然更換執行器。不支援機群評估與 Windows；工作程序的 Git 探測成功或提示詞回顯都不算作評估。

macOS 上的隔離會拒絕客體網絡與外部檔案系統存取、阻止處理程序脫離、限制 CPU／檔案／輸出，並清理其擁有的後續處理程序，但**不會強制執行硬性記憶體配額**。Linux 需要 bubblewrap，並施加位址空間限制。最初的隔離驗證測試的是 macOS，而不是 Linux。缺少隔離時絕不會退回宿主 shell。提供者憑證留在伺服器上，位於客體工具之外。

嘗試證據會被遮蔽，並限制為 256 KiB；一次匯出限制為 16 MiB。大型匯出會為所有獲准入的嘗試保留精簡的結果／成本摘要，並明確報告被省略或已彙總的軌跡內容。匯出與報告都不包含完整的私有來源重播封裝。合成的安全檢查並不能確立實際的防外洩能力，不會覆寫隔離，也不會證明某個技能安全。
