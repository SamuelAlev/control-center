本參考列出代理實體上的每個欄位，以及它所用的列舉與旗標。若要在應用程式中逐步了解如何建立或編輯代理，請參見[建立並設定代理](/zh-HK/手冊/操作指南/建立代理/)。

## 代理實體欄位

| 欄位                    | 類型                   | 必填 | 說明                                                                                                                                                                                                |
| ----------------------- | ---------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | 是   | 唯一的代理識別碼                                                                                                                                                                                    |
| `name`                  | `String`               | 是   | 用於 @ 提及的簡短識別碼                                                                                                                                                                             |
| `title`                 | `String`               | 是   | 人類可讀的職位名稱                                                                                                                                                                                  |
| `agentMdPath`           | `String`               | 是   | 代理 `.md` 定義檔案的絕對路徑                                                                                                                                                                       |
| `workspaceId`           | `String`               | 是   | 所屬工作區（不可為 null）                                                                                                                                                                           |
| `reportsTo`             | `String?`              | 否   | 上級代理 id                                                                                                                                                                                         |
| `skills`                | `AgentSkills`          | 是   | 技能識別碼的集合                                                                                                                                                                                    |
| `persona`               | `String?`              | 否   | 自由文字的行為指示                                                                                                                                                                                  |
| `systemPrompt`          | `String?`              | 否   | 覆寫預設的系統提示                                                                                                                                                                                  |
| `adapterId`             | `String?`              | 否   | 推理配接器 id                                                                                                                                                                                       |
| `modelId`               | `String?`              | 否   | 該配接器內的模型 id                                                                                                                                                                                 |
| `strictMode`            | `bool`                 | 否   | 預設 `false`。會寫入該資料列，以及代理的 `AGENTS.md`                                                                                                                                                |
| `effort`                | `String?`              | 否   | 推理等級 id（例如 `'low'`、`'xhigh'`），取自所選模型的 `thinkingLevels`                                                                                                                             |
| `contextSize`           | `int?`                 | 否   | 上下文窗口的大小上限                                                                                                                                                                                |
| `role`                  | `AgentRole?`           | 否   | 代理的角色                                                                                                                                                                                          |
| `monthlyBudgetMicros`    | `int`                  | 否   | 以微美元為單位的每月支出上限（預設 `0`，即不限）                                                                                                                                                        |
| `silenceTimeoutMinutes` | `int?`                 | 否   | 靜默逾時的覆寫值，以分鐘計；必須為 null 或落於 1–240 之間（由建構函式斷言）                                                                                                                         |
| `maxConcurrentTasks`    | `int`                  | 否   | 預設 `1`。線上狀態模型所報告的容量數值（執行中與已排隊的計數都會與它比較）                                                                                                                          |
| `visibility`            | `AgentVisibility`      | 否   | 預設 `workspace`                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | 否   | 治理狀態（預設 `active`）。由預算硬性停止寫入，並渲染在組織圖與線上狀態名冊上。派發仍會接受來自 `paused` 代理的工作                                                                                 |
| `budgetPolicyId`        | `String?`              | 否   | 共享預算政策 id；為 null 時直接套用 `monthlyBudgetMicros`                                                                                                                                            |
| `runtimeProfileId`      | `String?`              | 否   | 自訂執行階段設定檔 id                                                                                                                                                                               |
| `createdAt`             | `DateTime`             | 是   | 建立時間戳                                                                                                                                                                                          |

`name` 與 `title` 都必須非空（由建構函式斷言）。`monthlyBudgetMicros` 的預設值
`0` 代表不限。要寫入上限，請使用 `agents.upsert`。

| 值         | 說明                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| `active`   | 預設值。`isDispatchable` 只有在此值下才為 true                             |

## 權限

代理不帶任何權限旗標。推送、開啟與發佈 pull request、寫入追蹤器以及網絡對外連線都是動作類別（`gitPush`、`prCreate`、`prPublish`、`vendorSyncWrite`、`networkEgress`），由[護欄](/zh-HK/手冊/概念/護欄/)在工作區、代理或空間範圍內解析。執行的 GitHub 權杖一律是唯讀範圍；推送經過代理執行閘道，閘道在轉送前會詢問 `gitPush` 規則。

## AgentSkills

一個不可變、不區分大小寫的技能識別碼集合。派發時，這些 slug 會同步為代理覆蓋層中的技能連結；隨後執行框架會把已連結技能的前置資料自動載入提示中。

```
{'flutter', 'dart', 'rest-api'}
```

## Shell 掛鉤

Shell 掛鉤讓伺服器擁有者在內建 harness 執行的前後執行自己的腳本：工作階段開始時一次、每次工具呼叫之前，以及每次工具呼叫之後。掛鉤是任意程式碼，因此它們屬於主機設定。只有伺服器擁有者可以親手在伺服器的機器上設定它們。應用程式中沒有任何設定，也沒有任何操作會寫入它們。

對於代理，掛鉤位於伺服器資料目錄下它自己的資料夾中：

```text
<data dir>/_agent_hooks/<workspace id>/<agent slug>/hooks.json
```

`<agent slug>` 是代理在工作區中資料夾的名稱（`agents/<slug>/`）。該資料夾位於每個工作區儲存空間之外，而每個沙箱都會隱藏資料目錄，因此沒有任何成員、執行或終端機能夠寫入它。

`hooks.json` 會以相對於掛鉤資料夾的路徑，把以下三個鍵中的任何一個對應到一個腳本：

| 鍵             | 何時執行                  | 結束碼的含義                                                   |
| -------------- | ------------------------- | -------------------------------------------------------------- |
| `sessionStart` | 執行開始時執行一次        | 無；掛鉤只作觀察                                               |
| `preTool`      | 每次工具呼叫之前          | `0` 允許該呼叫；其他任何值都會拒絕它                           |
| `postTool`     | 每次工具呼叫之後          | 無；掛鉤只作觀察                                               |

- 每個腳本都會作為其自身的可執行檔啟動，不經 shell、也不帶任何參數，因此它必須可執行，並以 shebang 行開頭。它會以 JSON 從 stdin 接收事件：事件名稱，以及工具掛鉤的工具名稱與其引數（`preTool`）或其結果（`postTool`）。
- 掛鉤會作為該次執行的其中一個工具行程執行，位於該次執行的代理資料夾中。當伺服器為代理加上沙箱時，它在該次執行的沙箱內執行。它只會取得最小化的環境，且沒有該次執行的任何憑證：沒有程式碼代管平台或供應商權杖，也沒有閘道存取權。
- 每個掛鉤有 30 秒。它的輸出會被讀取後丟棄。
- `preTool` 採失敗即關閉原則。非零結束、逾時，或腳本無法啟動，都會拒絕該工具呼叫。
- 絕對路徑、不存在的路徑，或離開掛鉤資料夾的路徑（解析連結後）都會被拒絕，該次執行的日誌會說明哪個掛鉤被拒絕以及原因。被拒絕或無法讀取的 `preTool` 掛鉤會拒絕每一次工具呼叫，直到它被修正為止。
- 位於存放庫或代理自己資料夾中的 `.agents/harness.json`，其中的 `hooks` 區塊都會被忽略。存放庫常常是他人的程式碼，而代理的資料夾可由成員和執行寫入。該次執行的日誌會說明該區塊已被忽略，以及掛鉤實際從何處讀取。

Shell 掛鉤只適用於內建的 harness。一個已設定的 `preTool` 或 `postTool` 掛鉤會令該次執行逐一呼叫其工具。

## AgentLiveState（衍生）

不會儲存。共七個值。宣告順序即優先順序（`sortPriority`，由測試固定），也就是名冊排序所依據的順序：

| 狀態        | `sortPriority` | 條件                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | 任何執行日誌的狀態為 `running`                                                                                      |
| `blocked`   | 1              | 最近一次執行的存活狀態為 `blocked`、`stalled` 或 `looping`                                                         |
| `failed`    | 2              | 最近一次執行的狀態為 `error`，或其存活狀態為 `failed` 或 `dead`                                                    |
| `queued`    | 3              | 一次執行已被派發但尚未執行——停在同一代理的另一次執行之後，或已寫入但尚未開始                                       |
| `succeeded` | 4              | 該次執行成功完成                                                                                                     |
| `idle`      | 5              | 該代理曾經執行過，且目前沒有進行中的工作                                                                             |
| `neverRun`  | 6              | 不存在任何執行日誌                                                                                                   |

`queued` 與 `succeeded` **僅存在於單次執行上**。為代理計算名冊狀態的 `deriveAgentLiveState` 永遠不會產生這兩者——它只會傳回 `neverRun`、`running`、`failed`、`blocked` 或 `idle`。
