參考頁面詳盡而不加評述地描述**實際存在哪些內容**。當你已經知道自己要找甚麼時，
可用它們來查閱：某個確切的工具名稱、某種步驟類型、某次狀態轉換、某條路由、某個
快捷鍵。

它們並非為了從頭讀到尾而寫。若要通讀，請使用
[概念](/zh-HK/手冊/概念/)；若要完成某項工作，請使用
[操作指南](/zh-HK/手冊/操作指南/)。

## 產品面

- [MCP 工具](/zh-HK/手冊/參考/mcp-工具/) — MCP 伺服器註冊的每一項工具，按工具族劃分
- [內建代理工具](/zh-HK/手冊/參考/代理工具/) — 綁定伺服器的 harness 工具（LSP、AST、debug、eval、vibe）
- [斜線指令](/zh-HK/手冊/參考/斜線指令/) — 輸入框內建指令、`/skill:` 與用戶指令
- [路由圖](/zh-HK/手冊/參考/路由圖/) — 每一個畫面及其對應的 URL
- [鍵盤快捷鍵](/zh-HK/手冊/參考/鍵盤快捷鍵/) — 完整的按鍵綁定註冊表
- [領域事件](/zh-HK/手冊/參考/領域事件/) — 領域匯流排上發布的每一個事件
- [測試機](/zh-HK/手冊/參考/測試機/) — 測試機的每一個介面、動作動詞、生命週期狀態、連接埠與預設值

## 設定

- [代理設定](/zh-HK/手冊/參考/代理設定/) — 代理的每一個欄位，以及哪些部分會讀取它
- [管線步驟類型](/zh-HK/手冊/參考/管線步驟/) — 步驟類型、body 鍵、設定與結果
- [`cc_server` CLI](/zh-HK/手冊/參考/cc-server-cli/) — 每一個旗標、環境變數、子命令與資料目錄路徑
- [備份、匯出與匯入](/zh-HK/手冊/參考/備份/) — 快照的佈局、每一項備份操作與傳輸路由
- [沙箱後端](/zh-HK/手冊/參考/沙箱後端/) — 各種執行後端及其可用性
- [SSO 設定](/zh-HK/手冊/參考/sso/) — 端點、操作與錯誤碼
- [聊天橋接](/zh-HK/手冊/參考/聊天橋接/) — 提供方、指令、憑證與操作

## 模型
