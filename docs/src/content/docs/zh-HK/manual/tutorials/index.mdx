教學是**課程**。每一課都由頭到尾帶你完成一件真實的事，只有一條路徑，沿途沒有
需要你作的決定。只要照着步驟做，就會成功。

它們的用途是讓你熟悉環境。當你摸清產品的輪廓之後，[操作指南](/zh-HK/手冊/操作指南/)
就是更快完成特定任務的途徑。

請按以下順序進行——每一課都以對上一課為前提。

1. [你的第一個工作區](/zh-HK/手冊/教學/第一個工作區/) —— 建立工作區、加入程式庫，並了解隔離模型
2. [派發你的第一個代理](/zh-HK/手冊/教學/第一個代理/) —— 為代理設定配接器與模型，然後讓它開始工作
3. [審查你的第一個 pull request](/zh-HK/手冊/教學/第一個-pr/) —— 閱讀差異、留下註解，然後合併
4. [建立你的第一條管線](/zh-HK/手冊/教學/第一條管線/) —— 將步驟串成 DAG 並執行

另外兩課各自獨立；當你有一個可用的工作區之後，做其中任何一課都可以。

- [將 Slack 橋接到工作區](/zh-HK/手冊/教學/第一個聊天橋接/) —— 在 Slack 討論串中驅動代理
- [以 SSO 讓團隊登入](/zh-HK/手冊/教學/sso/) —— 連接身分提供者，並完整走一次登入流程

:::note[開始之前]
先安裝 Control Center——參見[安裝](/zh-HK/手冊/安裝/)。如果你只想要最快讓代理
跑起來的途徑，請改為先看[快速入門](/zh-HK/手冊/快速入門/)，
之後再回到這裡。
:::
