Учебники — это **уроки**. Каждый из них проводит вас от начала до конца через что-то
настоящее, по одному пути, без необходимости принимать решения по дороге. Выполняйте
шаги в точности — и они сработают.

Они нужны, чтобы освоиться в продукте. Когда вы поймёте, как устроен продукт,
[практические руководства](/ru-RU/руководство/практические-руководства/) станут более
быстрым путём к конкретной задаче.

Проходите их в этом порядке — каждый предполагает, что предыдущий уже пройден.

1. [Ваше первое рабочее пространство](/ru-RU/руководство/учебники/первое-рабочее-пространство/) — создайте рабочее пространство, добавьте репозиторий и посмотрите на модель изоляции
2. [Запустите первого агента](/ru-RU/руководство/учебники/первый-агент/) — дайте агенту адаптер и модель, а затем пустите его в работу
3. [Проверьте свой первый pull request](/ru-RU/руководство/учебники/первый-pr/) — прочитайте diff, оставьте комментарий и смержите
4. [Соберите свой первый конвейер](/ru-RU/руководство/учебники/первый-конвейер/) — свяжите шаги в DAG и запустите его

Ещё два руководства самостоятельны; любое из них можно пройти, когда рабочее
пространство уже работает.

- [Подключите Slack к рабочему пространству](/ru-RU/руководство/учебники/первый-чат-мост/) — управляйте агентами прямо из треда Slack
- [Войдите с командой через SSO](/ru-RU/руководство/учебники/sso/) — подключите провайдера идентификации и пройдите вход от начала до конца

:::note[Прежде чем начать]
Сначала установите Control Center — см. [Установка](/ru-RU/руководство/установка/). Если вам
нужен только самый короткий путь к работающему агенту, выберите вместо этого
[быстрый старт](/ru-RU/руководство/быстрый-старт/) и вернитесь сюда после него.
:::
