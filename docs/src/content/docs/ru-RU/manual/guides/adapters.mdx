Это руководство показывает, как подключить провайдеров моделей и выбрать, на
чём работает агент.

Всё это находится на одной странице: **Настройки → Сервер → Провайдеры моделей**.
В подменю боковой панели этот пункт называется «Провайдеры моделей», а заголовок
страницы — «Адаптеры».

## Что такое адаптер

Адаптер — это _раннер_, который выполняет ход агента. Их два, и список
фиксирован — третий добавить нельзя.

| Адаптер                   | CLI      | Транспорт                                                    |
| ------------------------- | -------- | ------------------------------------------------------------ |
| Control Center (built-in) | нет      | Внутрипроцессный цикл агента, обращается к провайдерам по HTTP |
| Claude Code               | `claude` | `claude -p --output-format stream-json`                      |

Cursor, Codex, Anthropic, OpenAI и остальные — это **провайдеры** встроенного
адаптера, а не отдельные CLI. Добавить же можно другого провайдера — любую
конечную точку, совместимую с OpenAI или с Anthropic. Об этом — следующий раздел.

:::note[Обнаружение проверяет сервер, а не вашу машину]
Карточка **Обнаруженные раннеры** перечисляет то, что `cc_server` нашёл в `PATH`
_хоста сервера_. На тонком или веб-клиенте это другая машина, не та, на которую
вы смотрите. Установите CLI на машине, где запущен `cc_server`.
:::

## Подключить провайдера моделей

Встроенному адаптеру для работы нужен хотя бы один подключённый провайдер. В
каталоге их поставляется четырнадцать.

1. Перейдите в **Настройки → Сервер → Провайдеры моделей**
2. Прокрутите до **Провайдеры и модели**
3. Найдите своего провайдера и подключите его:

| Провайдер                                                                                                | Как подключить                                                                                                                |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | API-ключ. Подписка Claude Pro/Max — это не вход в API Anthropic; для такого тарифа используйте адаптер Claude Code            |
| OpenAI, Codex, Cursor                                                                                    | Вход по OAuth в браузере или API-ключ. Codex — это ChatGPT Plus/Pro через бэкенд Codex Responses, а не запуск CLI             |
| Kimi Code                                                                                                | Только OAuth в браузере — поток с кодом устройства. Это тариф с фиксированной оплатой, поэтому цены за токен у него нет       |
| OpenRouter, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API)       | API-ключ                                                                                                                      |

Проверка: значок в строке меняется на «Подключено», а при разворачивании строка
перечисляет модели, которые обслуживает этот провайдер, — каждую с ценой за
миллион токенов и окном контекста.

Токены OAuth попадают в собственное хранилище учётных данных сервера и
обновляются до истечения срока. Учётные данные провайдеров **глобальны для
хоста** — они общие для всех рабочих пространств установки, а не привязаны к
одному.

### Добавить своего провайдера

Используйте это для Ollama, LM Studio, vLLM или частного развёртывания.

1. В разделе **Провайдеры и модели**, под **Свои провайдеры**, нажмите
   **Добавить провайдера**
2. Укажите **имя**, выберите **тип API** (совместимый с OpenAI или с Anthropic)
   и задайте **базовый URL** (например, `http://localhost:11434/v1`)
3. Добавьте **API-ключ**, если он нужен конечной точке, затем нажмите
   **Добавить провайдера**

Свой провайдер появляется в том же списке, с кнопкой удаления, которой нет у его
встроенных собратьев.

## Выбрать модель для агента

1. Перейдите в **Настройки → Рабочее пространство → Агенты** и выберите агента
2. На вкладке **Настройки** выберите **адаптер**
3. Выберите **модель** в раскрывающемся списке рядом

Для встроенного адаптера этот список собирается на лету из собственного каталога
каждого подключённого провайдера. Провайдер без сохранённых учётных данных не
даёт ни одной модели, поэтому пустой список почти всегда означает «пока ничего
не подключено», а не «ничего не доступно».

:::note[models.dev — это обогащение, а не источник идентификаторов]
Поставляемый каталог [models.dev](https://models.dev) даёт цену и окно контекста
для модели, которая уже есть в живом списке. Он никогда не добавляет
идентификатор модели. Если ожидаемой модели нет, значит, конечная точка
провайдера её не возвращает.
:::

Идентификаторы моделей встроенного адаптера имеют вид `provider/model` и могут
нести цепочку резервных вариантов, разделённых `|`. При срабатывании резервного
варианта стоимость считается по модели, которая фактически обслужила ход, а не
по той, которую вы запросили.

:::note[Агент без адаптера работает на встроенном цикле]
Каждое рабочее пространство создаёт пять агентов — CEO плюс `qa`, `architect`,
`engineer` и `librarian` — без адаптера и без модели. Запуск откатывается к
**Control Center (built-in)**, а не к настройке **Раннеры по умолчанию** на этой
странице, которая является клиентской настройкой и никогда не читается путём
запуска. Журнал запуска записывает `cc-harness` для таких запусков, поэтому
транскрипт указывает, что именно выполнялось.

Если и модели нет, встроенный цикл запрашивает у Anthropic модель по умолчанию.
Поэтому полностью не настроенный агент работает, если вы подключили аккаунт
Anthropic, и в противном случае завершается ошибкой
`No credential for provider "anthropic"`.

Завершение шага адаптера первоначальной настройки задним числом проставляет
**каждому** агенту, которому всё ещё не хватает адаптера или модели, — CEO и
специалистам, во всех рабочих пространствах, существующих на тот момент, —
выбранную вами пару. Рабочие пространства, созданные позже, всё равно создают
всех пятерых ненастроенными. Задайте адаптер и модель явно для каждого агента,
который собираетесь использовать.
:::

## Установить CLI раннера

Встроенный адаптер не требует установки. Для Claude Code установите его
CLI **на хосте сервера** собственным менеджером пакетов этого инструмента,
например:

```bash
npm install -g @anthropic-ai/claude-code
```

Затем нажмите **Обновить** в верхней части страницы. В каждой обнаруженной строке
указаны найденные версия и путь, а также метки о том, поддерживаются ли режим
JSON и выбор модели.

Внешний CLI хранит свои собственные учётные данные в собственной конфигурации на
хосте сервера. Control Center ими не управляет.

:::caution[Аргументы адаптера и переменные окружения остаются на этом устройстве]
Каждая строка адаптера предлагает поле **Аргументы** и диалог **Переменные
окружения**. Эти значения хранятся на вашем устройстве. Сервер читает argv
запуска и переменные окружения из собственного хранилища настроек. Размещайте
ключи провайдеров на сервере (OAuth или поле ключа на странице «Провайдеры
моделей»), а не в этих двух полях.
:::

## Ограничить, каких провайдеров может использовать рабочее пространство

Управление провайдерами задаётся для каждого рабочего пространства, и применяется
правило «последнее совпадение выигрывает».

1. В разделе **Провайдеры и модели** выключите переключатель **Разрешить** в
   строке провайдера

Так для этого провайдера записывается инструкция `deny` в активном рабочем
пространстве, и его модели выпадают из каталога этого рабочего пространства.
Повторное включение переключателя удаляет инструкцию.

## Устранение неполадок

### Раннер отображается как ненайденный

- Проверьте, что CLI находится в `PATH` **хоста сервера**, а не только в вашем
- Настольное приложение, запущенное из графического интерфейса, порождает свой
  сервер с минимальным `PATH`; CLI, установленный по пути, доступному только
  оболочке, может быть ему не виден
- Нажмите **Обновить** после установки

### Раскрывающийся список моделей пуст

- Адаптер — встроенный, и ни один провайдер не подключён — подключите его в
  разделе **Провайдеры и модели**
- Либо провайдер подключён, но запрещён переключателем управления в этом рабочем
  пространстве

### Модель работает, но цена отображается как неизвестная

Живой список моделей содержит идентификатор; цена и контекст берутся из
models.dev. У совсем новой модели или модели от своего провайдера ещё нет записи
в каталоге.
