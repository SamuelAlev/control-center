Проект — это группировка тикетов в рамках рабочего пространства ради общей
цели. Проекты существуют только в Control Center и никогда не синхронизируются с
внешним провайдером, таким как Linear.

## Создать проект

1. Разверните группу **Тикеты** на боковой панели рабочего пространства. В ней
   перечислены **Все тикеты**, по одной строке на каждый неархивированный проект,
   а затем **Новый проект**.
2. Нажмите **Новый проект**.
3. Укажите **Название проекта**, при необходимости — **Описание** и выберите
   **Цвет**.
4. Нажмите **Создать проект**.

Вы попадаете на обзор нового проекта, и проект появляется строкой на боковой
панели в группе **Тикеты**.

## Добавить тикеты в проект

Проект — поле отдельного тикета, и задать его можно в одном из двух мест:

- Откройте тикет и укажите **Проект** в панели свойств.
- Щёлкните по тикету правой кнопкой мыши в списке и воспользуйтесь подменю
  **Проект**.

Средство выбора в панели свойств также предлагает **Новый проект**, так что
тикет можно сразу отнести в проект, созданный на месте. **Без проекта** очищает
поле.

Тикет принадлежит не более чем одному проекту.

:::note[Проект не входит в массовые действия]
Плавающая панель, которая появляется при выборе нескольких тикетов, охватывает
статус, приоритет, исполнителя, метки и удаление. Чипа проекта в ней нет, поэтому
проставлять проект многим тикетам приходится по одному.
:::

Начать можно и с проекта: **Новый тикет** на обзоре проекта создаёт тикет и
сразу относит его туда.

## Смотреть прогресс проекта

Откройте проект из его строки на боковой панели или перейдите по адресу
`/workspaces/<workspace-id>/projects/<project-id>`.

На обзоре показаны значок и название проекта, бейдж статуса, описание и
индикатор прогресса «выполнено из общего числа». Ниже тикеты проекта
сгруппированы по статусу.

Больше он ничего не агрегирует — ни разбивки по исполнителям, ни распределения
по приоритетам здесь нет. Для этого фильтруйте основной список тикетов.

## Изменить статус проекта

У проектов три состояния:

| Статус        | Значение            |
| ------------- | ------------------- |
| **Активный**  | Работа продолжается |
| **Завершён**  | Вся работа сделана  |
| **В архиве**  | Историческая справка |

Используйте меню **⋯** в заголовке проекта. В нём есть **Изменить проект**,
**Отметить завершённым** / **Отметить активным**, **Архивировать** /
**Восстановить** и **Удалить проект**.

Архивация скрывает проект из списка на боковой панели и из средств выбора
тикетов. Её можно отменить — **Восстановить** возвращает проект в активное
состояние, — но, пока проект в архиве, попасть в него можно только по URL.

## Проекты, создаваемые за вас

Утверждение оркестрации создаёт проект и относит в него родительский тикет
вместе со всем, что вы отнесли туда вручную. Сгенерированные рабочие элементы —
это шаги конвейера, а не строки тикетов, поэтому на доске проекта они не
появляются. Это единственный автоматический путь: ни один узел конвейера не
создаёт тикеты, поэтому конвейер не может наполнить проект. См.
[Запустить оркестрацию](/ru-RU/руководство/практические-руководства/запустить-оркестрацию/).

:::note[Проекты — это поверхность оператора]
Создавайте проекты, просматривайте их список, обновляйте и удаляйте их в
приложении. У агентов нет инструментов для работы с проектами.
