Вставьте API-ключ Linear на сервере для своего пользователя — так же, как вы
подключаете хост кода. Тикеты, проекты, связи, соисполнители, делегирование и
назначение работают на собственной базе данных Control Center, и внешний сервис
не нужен — см. [Создавать и управлять
тикетами](/ru-RU/руководство/практические-руководства/управлять-тикетами/).

## Сохранить ключ Linear

**API-ключ тикетов** находится в разделе **Настройки → Рабочее пространство →
Основные**, на карточке **Тикеты**. Он хранит ключ на сервере с привязкой к id
вашего пользователя. Собственный ключ сервера для работы без участия человека
берётся из `LINEAR_API_KEY` или с карточки **Приложения провайдера** и
подставляется как `TICKETING_API_KEY` только тогда, когда у этого агента есть
возможность **Разрешить вызовы API тикетов**.

## Помечать новые тикеты как Linear

**Провайдер тикетов** (первый шаг первоначальной настройки и
`/workspaces/<workspaceId>/api-keys`) предлагает `local` и `linear`. Выбор
`linear` проставляет `provider: linear` на тикетах, которые вы создаёте с этого
момента.
