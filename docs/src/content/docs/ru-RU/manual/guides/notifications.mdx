В этом руководстве описано, как настраивать уведомления и что на самом деле
контролирует каждая настройка.

Уведомления приходят на две поверхности. **Центр уведомлений** — колокольчик в
строке заголовка — читает постоянную ленту уведомлений для каждого рабочего
пространства на сервере. **Тосты ОС** — отдельный путь, доступный только на
десктопе; их питают живые кадры, которые присылает сервер.

:::note[В веб-сборке уведомления ОС не показываются]
Конвейер тостов создаёт только загрузчик десктопного приложения. На
`app.usectrl.dev` нет ни тостов ОС, ни звуков уведомлений, ни фоновых баннеров —
колокольчик и его история по-прежнему работают, потому что читают серверную
ленту. У телефонного клиента поверхности уведомлений нет вообще.
:::

## Включение и отключение категорий

1. Откройте **Настройки → Вы → Уведомления**
2. Оставьте **Включить уведомления** включённым
3. Включите нужные категории. Всего их ровно шестнадцать:

| Категория                       | Срабатывает, когда                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| Агент завершил работу           | Агент ответил в запуске, который начали вы, или запуск завершился ошибкой           |
| PR опубликован                  | Агент опубликовал PR                                                                |
| PR объединён                    | PR был объединён                                                                    |
| Новые сообщения                 | Вас упомянули в пространстве                                                        |
| Упоминание в pull request       | Опрос уведомлений GitHub увидел, что вас упомянули в PR                             |
| Запрошено ревью                 | Ревью действительно запросили для PR, который не является черновиком                |
| Ревью устарело                  | В pull request, который вы уже проверили, появились новые коммиты                   |
| Готово к слиянию                | Pull request, автором которого вы являетесь, стал готов к слиянию или перестал быть |
| Решения по ревью                | Ревьюер одобрил, запросил изменения или его одобрение было отменено                 |
| Проверки                       | CI упал на pull request, автором которого вы являетесь, или восстановился            |
| Ветки обсуждения                | Кто-то ответил в ветке обсуждения, где вы участвуете, или закрыл её                 |
| Тикет назначен                  | Тикет был назначен                                                                  |
| Статус тикета изменён           | Тикет сменил статус                                                                 |
| Встреча скоро начнётся          | Календарная встреча попала в ваше окно опережения                                   |
| Календарь отключён              | Истёк OAuth-токен подключённого календаря                                           |
| Обновления стенда               | Стенд был перехвачен, возвращён или вышел из строя                                  |

Всё, что не входит в этот список, нельзя ни уведомить, ни отфильтровать —
категории «всё остальное» не существует.

Эти настройки следуют за вашим пользователем на всех устройствах, поэтому
телефон и ноутбук остаются синхронными. Громкость — намеренное исключение: она
задаётся отдельно для каждого устройства.

## Настроить тихие часы

1. На той же странице включите **Quiet hours**
2. Введите время начала и окончания в формате `HH:MM` (по умолчанию окно
   22:00–08:00)

В тихие часы несрочные уведомления отбрасываются — они не ставятся в очередь и
не воспроизводятся позже.

Две категории считаются **срочными** и доставляются всегда, обходя тихие часы _и_
режим фокуса: **Встреча скоро начнётся** и **PR опубликован**. Предупреждение о
встрече, которое вы увидите только после неё, бесполезно — именно поэтому.

## Выбрать звук

1. Прокрутите до **Звук уведомления**
2. Выберите один из одиннадцати встроенных звуков или **Нет**
3. Нажмите кнопку **Тест**, чтобы услышать звук, и задайте громкость ползунком

Звук воспроизводит само приложение, а уведомление ОС приходит без звука, чтобы
вы не услышали его дважды.

## Настроить время предупреждения о встречах

1. Прокрутите до **За сколько предупреждать**
2. Выберите **5**, **10**, **15** или **30** минут

Столько времени проходит до события календаря, когда срабатывает уведомление
**Встреча скоро начнётся**. По умолчанию — 5 минут.

## Когда уведомление подавляется

Уведомление молча отбрасывается, если верно хотя бы одно из условий:

- Уведомления отключены глобально или отключена его категория
- Вы уже находитесь на маршруте, куда оно вас привело бы, — а для сообщения ещё
  и в том самом пространстве
- Активен режим фокуса, а категория не срочная
- Включены тихие часы, а категория не срочная

Эти проверки касаются тостов ОС. Постоянный колокольчик всё равно фиксирует
событие.

Ещё два механизма подавления работают выше по потоку — в том, что сервер вообще
отправляет:

- Сообщение от другого **человека** без упоминания вас никогда не становится
  уведомлением
- В общем пространстве ответ агента уведомляет того, кто начал этот запуск,
  а не всех участников
- Пространства «агент — агент» заглушены в боковой панели, поэтому они никогда
  не увеличивают счётчик непрочитанного у людей

Внутри пространства тихого уголка нет: каждый разговор уведомляет одинаково,
включая ветки обсуждения. Состояние прочтения привязано к пространству, поэтому
непрочитанное суммируется по всем разговорам пространства, а не отслеживается
отдельно по каждому разговору.

## Просмотр и очистка центра уведомлений

1. Нажмите на колокольчик в строке заголовка

Всплывающее окно показывает недавнюю активность, снабжая каждую запись прямой
ссылкой на то, о чём она. Открытие окна **не** помечает всё прочитанным —
используйте **Отметить все как прочитанные** в заголовке или отметьте отдельную
строку. Состояние прочтения следует за вашим пользователем на всех устройствах.

:::note[«Очистить всё» — это водяной знак, а не удаление]
**Очистить всё** ставит пользовательский водяной знак, который скрывает всё
более старое; сами строки остаются. Отдельно от этого каждое рабочее
пространство хранит только **200** последних строк ленты, которые вытесняются по
мере поступления новых, колокольчик подписан на **50** самых свежих, а
всплывающее окно показывает до **15** из них. Всё, что старше, исчезает
независимо от состояния прочтения.
:::

## Решение проблем

### Нет уведомлений ОС в macOS

Разрешение запрашивается нативно при запуске приложения. Если вы его отклонили,
снова включите Control Center в разделе «Системные настройки → Уведомления»;
внутри приложения нет запроса, который запустил бы его повторно.

### В веб-сборке ничего не приходит

Так и задумано: в веб-сборке нет конвейера уведомлений ОС. Пользуйтесь
колокольчиком.

### Бейдж колокольчика показывает ноль, хотя новая активность явно есть

Пока после подключения не разрешится поток отметок о прочтении, записи
отображаются как прочитанные, чтобы бейдж не мигал и не пустел. Как только
отметка загрузится, всё придёт в норму.

### Запуск агента завершился, но мне ничего не пришло

Проверьте, не находились ли вы уже в пространстве, где это произошло: активный
маршрут подавляет собственный тост ОС. В общем пространстве о запуске, который
начал кто-то другой, уведомляют его, а не вас. Ход, завершившийся без ответа и
без ошибки, ничего не отправляет.
