Az oktatóanyagok **leckék**. Mindegyik végigvezet egy valós feladaton, egyetlen
útvonalon, anélkül hogy közben döntéseket kellene hoznia. Ha pontosan követi a
lépéseket, működni fognak.

Arra valók, hogy kiismerje magát a termékben. Ha már átlátja a termék felépítését,
egy adott feladathoz a [gyakorlati útmutatók](/hu-HU/kezikonyv/gyakorlati-utmutatok/)
vezetnek gyorsabban.

Ebben a sorrendben haladjon velük — mindegyik az előzőt feltételezi.

1. [Az első munkaterületed](/hu-HU/kezikonyv/oktatoanyagok/elso-munkaterulet/) — hozzon létre egy munkaterületet, adjon hozzá egy repót, és nézze meg az elszigetelési modellt
2. [Az első ügynök indítása](/hu-HU/kezikonyv/oktatoanyagok/elso-ugynok/) — adjon egy ügynöknek adaptert és modellt, majd állítsa munkába
3. [Az első pull request átnézése](/hu-HU/kezikonyv/oktatoanyagok/elso-pr/) — olvassa el a diffet, kommenteljen és fésülje össze
4. [Az első pipeline felépítése](/hu-HU/kezikonyv/oktatoanyagok/elso-pipeline/) — fűzze a lépéseket DAG-gá, és futtassa le

Kettő különálló; bármelyiket elvégezheti, ha már van működő munkaterülete.

- [Slack összekötése a munkaterülettel](/hu-HU/kezikonyv/oktatoanyagok/elso-csevegohid/) — irányítsa az ügynököket egy Slack-szálból
- [Csapat bejelentkeztetése SSO-val](/hu-HU/kezikonyv/oktatoanyagok/sso/) — kapcsoljon össze egy identitásszolgáltatót, és vigyen végig egy bejelentkezést

:::note[Mielőtt elkezdi]
Először telepítse a Control Centert — lásd: [Telepítés](/hu-HU/kezikonyv/telepites/). Ha
csak a lehető legrövidebb utat szeretné egy futó ügynökig, válassza helyette a
[gyors kezdést](/hu-HU/kezikonyv/gyors-kezdes/), és utána térjen vissza ide.
:::
