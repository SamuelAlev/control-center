A billentyűparancsok egyetlen `const` nyilvántartásból származnak: a `KeybindingRegistry`-ből a `lib/core/constants/keybindings.dart` fájlban. Ez **49 kötést** tartalmaz. A Beállítások → Ön → Gyorsbillentyűk ezt a nyilvántartást **írásvédett referenciaként** jeleníti meg: nincs átkötési felület, és nincs felhasználói gyorsbillentyű-fájl sem.

Az alábbiakban a `Cmd` az elsődleges parancsmódosító — ⌘ macOS-en, Ctrl Windowson és Linuxon. Egy kötés csak akkor aktiválódik, ha a parancsához az aktuális képernyőn regisztrált kezelő tartozik, és teljesül a `when` feltétele; a `!textInputFocus` azt jelenti, hogy a lenyomás inkább egy fókuszált szövegmezőbe jut tovább.

Nincs számjegyekkel működő navigációs billentyűparancs. A Beérkezett, a jegyek, a pull requestek és a többi rész az oldalsávból vagy a ⌘K használatával érhető el. A megfigyelhetőségnek sincs billentyűparancsa.

## Pull requestek listája (3)

`/pull-requests` hatókör. Mindegyikhez `route == '/pull-requests'` és fókusz nélküli szövegmező kell, ezért nem aktiválódnak, amikor a PR részleteinek útvonala nyitva van a lista fölött.

| Billentyűparancs | Művelet              |
| ---------------- | -------------------- |
| `R`              | Frissítés            |
| `Enter`          | PR megnyitása        |
| `F`              | Szűrőmenü megnyitása |

Az `Enter` (`pr.list-open`) szerepel a nyilvántartásban, és megjelenik a gyorsbillentyűk referenciáján, de **a listaképernyő nem regisztrál hozzá kezelőt**, ezért jelenleg nem aktiválódik. Az `F` a szűrőmenüt nyitja meg (`pr.list-open-filter`), nem a keresést.

## Pull request részletei (2)

`/pull-requests/` hatókör. A frissítéshez nem lehet fókuszált szövegmező. A lap bezárásának nincs szövegbeviteli őre (a ⌘-vel módosított leütés soha nem sima szöveg), viszont van útvonal-regexe, így nem aktiválódik a listán.

| Billentyűparancs | Művelet       | Feltétel                           |
| ---------------- | ------------- | ---------------------------------- |
| `R`              | Frissítés     | Nem gépel egy mezőbe               |
| `Cmd/Ctrl + W`   | Lap bezárása  | `/pull-requests/<…>` helyen        |

A lapváltást (`1`/`2`/`3`), a fájl megtekintettként jelölését és összecsukását (`V`/`C`), a fájllistát (`T`) és a diffben keresést (`Cmd/Ctrl + F`) a diff-megjelenítő saját kezelője birtokolja — lásd [A nyilvántartáson kívüli diff-megjelenítő-billentyűk](#a-nyilvántartáson-kívüli-diff-megjelenítő-billentyűk).

## Terek (9)

`/spaces` hatókör. A `when` feltételek regexet használnak, így a térlistán (`/spaces`) és egy kijelölt téren (`/spaces/<id>`) is aktiválódnak.

| Billentyűparancs       | Művelet                        | Feltétel              |
| ---------------------- | ------------------------------ | --------------------- |
| `Enter`                | Üzenet küldése                 | —                     |
| `Cmd/Ctrl + N`         | Új tér                         | `/spaces` útvonalon   |
| `J`                    | Következő tér                  | Nem gépel egy mezőbe  |
| `K`                    | Előző tér                      | Nem gépel egy mezőbe  |
| `Cmd/Ctrl + Shift + D` | Nyomva beszélhet diktálás      | —                     |
| `Cmd/Ctrl + T`         | Szerkesztőlap megnyitása       | `/spaces` útvonalon   |
| `Cmd/Ctrl + W`         | Szerkesztőlap bezárása         | `/spaces` útvonalon   |
| `Cmd/Ctrl + B`         | Szerkesztő oldalsávjának váltása | `/spaces` útvonalon |
| `Cmd/Ctrl + P`         | Ugrás fájlra                     | `/spaces` útvonalon |

Az „Ugrás fájlra” választót nyit a beszélgetés fájljaival. Ha nem gépel semmit, a legutóbb megnyitott fájlokat listázza; gépeléskor a beszélgetés worktree-jeinek összes fájljában keres. Az `Enter` új lapon nyitja meg a kijelölt fájlt, a `Cmd/Ctrl + Enter` vagy a sor felosztás gombja egy jobb oldali panelen nyitja meg, a nemrég megnyitott fájl sorában lévő `×` pedig eltávolítja a listából.

Az Enterrel küldést a szerkesztő szövegmezője birtokolja; a nyomva beszélhet módot a szerkesztő mikrofon gombja (a saját hardveres billentyűzetkezelője). Mindkettő a beállítások referenciája kedvéért szerepel a nyilvántartásban.

## A nyilvántartáson kívüli diff-megjelenítő-billentyűk

A PR diff-megjelenítő ezeket maga kezeli (`PrDiffKeyboardHandler`). A keresés/megtekintett/összecsukás csak a beállítások referenciája kedvéért szerepel a nyilvántartás megjegyzéseiben — nincs regisztrált diszpécserkezelő, ezért a diszpécser a diff-nézetre hagyja őket. A gyorsbillentyűk referenciáján nem jelennek meg saját sorokként.

| Billentyűparancs | Művelet                                               |
| ---------------- | ----------------------------------------------------- |
| `Cmd/Ctrl + F`   | Keresés a diffben                                     |
| `J` / `K`        | Következő / előző fájl                                |
| `V`              | A fókuszált fájl megtekintett jelölésének váltása     |
| `C`              | A fókuszált fájl összecsukásának váltása              |
| `T`              | Fájllista megjelenítése                               |
| `Enter`          | Következő találat (csak amíg a diffben keresés nyitva van) |
| `Shift + Enter`  | Előző találat                                         |
| `Escape`         | A diffben keresés bezárása vagy a diff szövegkijelölésének törlése |
| `Cmd/Ctrl + C`   | A diff kijelölésének másolása                         |

## A böngésző által lefoglalt kombinációk

A webes buildben a böngésző néhány gyorsítóbillentyűt még azelőtt elfogyaszt, hogy az oldal észlelné őket, így a megfelelő kötések ott soha nem aktiválódhatnak. Asztali környezetben normálisan működnek. Az elsődleges parancsmódosítóval kombinálva ezek vannak lefoglalva: `T`, `W`, `N` és az `1`–`9` számjegyek.

Ez érinti a `Cmd/Ctrl + Alt + 1`–`9` munkaterület-váltást, a `Cmd/Ctrl + N` kombinációt (új tér, új munkaterület, új ügynök, tároló hozzáadása), valamint a `Cmd/Ctrl + T` / `Cmd/Ctrl + W` kombinációt a terekben és a PR részleteinél.
