Los atajos proceden de un único registro `const`, `KeybindingRegistry` en `lib/core/constants/keybindings.dart`. Contiene **48 asignaciones**. Ajustes → Tú → Atajos de teclado muestra ese registro como una **referencia de solo lectura**: no hay ninguna interfaz para reasignar atajos ni ningún archivo de atajos de teclado del usuario.

`Cmd`, a continuación, es el modificador de comando principal: ⌘ en macOS y Ctrl en Windows y Linux. Una asignación solo se activa cuando su comando tiene un manejador registrado en la pantalla actual y su cláusula `when` se cumple; `!textInputFocus` significa que la tecla se deja pasar al campo de texto que tenga el foco.

No hay ningún atajo de navegación con teclas numéricas. A la bandeja de entrada, los tickets, las pull requests y todo lo demás se llega desde la barra lateral o con ⌘K. Observabilidad tampoco tiene atajo.

## Global (19)

Ámbito `global`, así que están activos en cualquier punto del shell.

### Sistema

| Atajo                                       | Acción                                              | Condición                                                  |
| ------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Paleta de comandos                                  | —                                                          |
| `Shift + /` (`?`)                           | Hoja de referencia de atajos de teclado             | Sin escribir en un campo                                   |
| `Cmd/Ctrl + Z`                              | Deshacer                                            | Sin escribir en un campo (un campo con el foco conserva su propio deshacer) |
| `Cmd/Ctrl + Shift + Z`                      | Rehacer                                             | Sin escribir en un campo                                   |
| `Cmd/Ctrl + Shift + T`                      | Cambiar tema                                        | —                                                          |
| `Cmd/Ctrl + ,`                              | Abrir ajustes (lleva a `/settings/you/appearance`)  | —                                                          |
| `Cmd/Ctrl + Shift + Alt + F`                | Toggle focus mode                                   | —                                                          |
| `Cmd/Ctrl + Shift + W`                      | Cambiar selector de espacio                         | —                                                          |
| `Cmd/Ctrl + ]`                              | Espacio de trabajo siguiente                        | —                                                          |
| `Cmd/Ctrl + [`                              | Espacio de trabajo anterior                         | —                                                          |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | Cambiar al espacio de trabajo 1–9                   | —                                                          |

## Lista de pull requests (3)

Ámbito `/pull-requests`. Todas exigen `route == '/pull-requests'` y que no haya ningún campo de texto con el foco, así que no se activan mientras la ruta de detalle de la PR está abierta sobre la lista.

| Atajo   | Acción                 |
| ------- | ---------------------- |
| `R`     | Actualizar             |
| `Enter` | Abrir PR               |
| `F`     | Abrir el menú de filtros |

`Enter` (`pr.list-open`) está declarado en el registro y aparece en la referencia de atajos de teclado, pero **la pantalla de lista no registra ningún manejador para él**, así que de momento no se activa. `F` abre el menú de filtros (`pr.list-open-filter`), no la búsqueda.

## Detalle de pull request (2)

Ámbito `/pull-requests/`. Actualizar exige que no haya ningún campo de texto con el foco. Cerrar pestaña no tiene protección de entrada de texto (una pulsación modificada con ⌘ nunca es texto plano) y cuenta con una regex de ruta, de modo que no se activa en la lista.

| Atajo          | Acción         | Condición                          |
| -------------- | -------------- | ---------------------------------- |
| `R`            | Actualizar     | Sin escribir en un campo           |
| `Cmd/Ctrl + W` | Cerrar pestaña | En una ubicación `/pull-requests/<…>` |

El cambio de pestañas (`1`/`2`/`3`), marcar un archivo como visto o contraerlo (`V`/`C`), la lista de archivos (`T`) y buscar en el diff (`Cmd/Ctrl + F`) los gestiona el propio manejador del visor de diferencias; consulta [Teclas del visor de diferencias fuera del registro](#teclas-del-visor-de-diferencias-fuera-del-registro).

## Bandeja de entrada (1)

| Atajo | Acción                 |
| ----- | ---------------------- |
| `F`   | Abrir el menú de filtros |

Exige `route == '/inbox'` y que no haya ningún campo de texto con el foco.

## Perfiles de usuario y equipo de GitHub (3)

Ámbito `/users/`. La cláusula `when` es una regex sobre `/users/<login>` **o** `/teams/<organization>/<slug>`, además de exigir que no haya ningún campo de texto con el foco.

| Atajo          | Acción            |
| -------------- | ----------------- |
| `R`            | Actualizar        |
| `/`            | Enfocar búsqueda  |
| `Cmd/Ctrl + F` | Enfocar búsqueda  |

## Espacios (8)

Ámbito `/spaces`. Las cláusulas `when` usan una regex, de modo que se activan tanto en la lista de espacios (`/spaces`) como en un espacio seleccionado (`/spaces/<id>`).

| Atajo                  | Acción                              | Condición              |
| ---------------------- | ----------------------------------- | ---------------------- |
| `Enter`                | Enviar mensaje                      | —                      |
| `Cmd/Ctrl + N`         | Nuevo espacio                       | En una ruta `/spaces`  |
| `J`                    | Espacio siguiente                   | Sin escribir en un campo |
| `K`                    | Espacio anterior                    | Sin escribir en un campo |
| `Cmd/Ctrl + Shift + D` | Dictado con pulsar para hablar      | —                      |
| `Cmd/Ctrl + T`         | Abrir pestaña del editor            | En una ruta `/spaces`  |
| `Cmd/Ctrl + W`         | Cerrar pestaña del editor           | En una ruta `/spaces`  |
| `Cmd/Ctrl + B`         | Mostrar/ocultar la barra lateral del editor | En una ruta `/spaces` |

El envío con Enter lo gestiona el campo de texto del compositor; «pulsar para hablar» lo gestiona el botón de micrófono del compositor (con su propio manejador de teclado de hardware). Ambos figuran en el registro para la referencia de ajustes.

## Selector de espacio de trabajo (2)

Ámbito `/workspaces`, solo están activos en el propio selector.

| Atajo          | Acción                                 |
| -------------- | -------------------------------------- |
| `Cmd/Ctrl + N` | Nuevo espacio de trabajo               |
| `Enter`        | Abrir el espacio de trabajo seleccionado |

`Enter` exige que no haya ningún campo de texto con el foco.

## Teclas del visor de diferencias fuera del registro

El visor de diferencias de PR gestiona estas teclas por su cuenta (`PrDiffKeyboardHandler`). La búsqueda, el visto y el contraer solo figuran en los comentarios del registro para la referencia de ajustes: no hay ningún manejador registrado en el despachador, así que este se las deja a la vista de diferencias. No aparecen como filas propias en la referencia de atajos de teclado.

| Atajo           | Acción                                                         |
| --------------- | -------------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Buscar en el diff                                              |
| `J` / `K`       | Archivo siguiente / anterior                                   |
| `V`             | Marcar como visto el archivo con el foco                       |
| `C`             | Contraer o desplegar el archivo con el foco                    |
| `T`             | Mostrar la lista de archivos                                   |
| `Enter`         | Siguiente coincidencia de búsqueda (solo mientras está abierta la búsqueda en el diff) |
| `Shift + Enter` | Coincidencia de búsqueda anterior                              |
| `Escape`        | Cerrar la búsqueda en el diff o limpiar la selección de texto del diff |
| `Cmd/Ctrl + C`  | Copiar la selección del diff                                   |

## Combinaciones reservadas por el navegador

En la compilación web, el navegador consume algunos aceleradores antes de que la página los vea, así que las asignaciones correspondientes nunca pueden activarse ahí. En el escritorio funcionan con normalidad. Están reservados al combinarse con el modificador de comando principal: `T`, `W`, `N` y los dígitos `1`–`9`.

Eso afecta al cambio de espacio de trabajo con `Cmd/Ctrl + Alt + 1`–`9`, a `Cmd/Ctrl + N` (nuevo espacio, nuevo espacio de trabajo, nuevo agente, añadir repositorio) y a `Cmd/Ctrl + T` / `Cmd/Ctrl + W` en espacios y en el detalle de PR.
