Esta referencia enumera todos los campos de la entidad de agente, además de las enumeraciones e indicadores que usa. Para ver el procedimiento paso a paso para crear o editar un agente en la aplicación, consulta [Crear y configurar un agente](/es-ES/manual/guias/crear-agente/).

## Campos de la entidad de agente

| Campo                   | Tipo                   | Obligatorio | Descripción                                                                                                                                                                                          |
| ----------------------- | ---------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Sí          | Identificador único del agente                                                                                                                                                                       |
| `name`                  | `String`               | Sí          | Identificador corto para menciones con @                                                                                                                                                             |
| `title`                 | `String`               | Sí          | Título del rol legible por personas                                                                                                                                                                  |
| `agentMdPath`           | `String`               | Sí          | Ruta absoluta al archivo de definición `.md` del agente                                                                                                                                              |
| `workspaceId`           | `String`               | Sí          | Espacio de trabajo propietario (no null)                                                                                                                                                             |
| `reportsTo`             | `String?`              | No          | Identificador del agente superior                                                                                                                                                                    |
| `skills`                | `AgentSkills`          | Sí          | Conjunto de identificadores de skills                                                                                                                                                                |
| `persona`               | `String?`              | No          | Instrucciones de comportamiento en texto libre                                                                                                                                                       |
| `systemPrompt`          | `String?`              | No          | Anula el prompt de sistema predeterminado                                                                                                                                                            |
| `adapterId`             | `String?`              | No          | Identificador del adaptador de inferencia                                                                                                                                                            |
| `modelId`               | `String?`              | No          | Identificador del modelo dentro del adaptador                                                                                                                                                        |
| `strictMode`            | `bool`                 | No          | Predeterminado `false`. Se escribe en la fila y en el `AGENTS.md` del agente                                                                                                                         |
| `effort`                | `String?`              | No          | Identificador del nivel de razonamiento (p. ej. `'low'`, `'xhigh'`), tomado de `thinkingLevels` del modelo seleccionado                                                                             |
| `contextSize`           | `int?`                 | No          | Tamaño máximo de la ventana de contexto                                                                                                                                                              |
| `role`                  | `AgentRole?`           | No          | Rol del agente                                                                                                                                                                                       |
| `capabilities`          | `AgentCapabilities?`   | No          | Valor predeterminado de capacidades por agente; cuando es null se aplica el predeterminado del usuario al despachar, y una conversación aún puede anularlo                                          |
| `monthlyBudgetCents`    | `int`                  | No          | Límite de gasto mensual en céntimos (predeterminado `0`, ilimitado)                                                                                                                                  |
| `silenceTimeoutMinutes` | `int?`                 | No          | Anulación del tiempo de silencio en minutos; debe ser null o estar entre 1 y 240 (verificado en el constructor)                                                                                      |
| `maxConcurrentTasks`    | `int`                  | No          | Predeterminado `1`. Cifra de capacidad que comunica el modelo de presencia (los recuentos en ejecución y en cola se comparan con ella)                                                              |
| `visibility`            | `AgentVisibility`      | No          | Predeterminado `workspace`                                                                                                                                                                           |
| `lifecycleStatus`       | `AgentLifecycleStatus` | No          | Estado de gobernanza (predeterminado `active`). Lo escribe la parada dura del presupuesto y se representa en el organigrama y en la lista de presencia. El despacho sigue aceptando trabajo de un agente `paused` |
| `budgetPolicyId`        | `String?`              | No          | Identificador de la política de presupuesto compartida; cuando es null se aplica directamente `monthlyBudgetCents`                                                                                   |
| `runtimeProfileId`      | `String?`              | No          | Identificador del perfil de tiempo de ejecución personalizado                                                                                                                                        |
| `createdAt`             | `DateTime`             | Sí          | Marca de tiempo de creación                                                                                                                                                                          |

`name` y `title` deben ser ambos no vacíos (verificado en el constructor). Un
`monthlyBudgetCents` predeterminado de `0` significa ilimitado. Escribe un techo con `agents.upsert`.

## Enumeración AgentVisibility

| Valor       | Descripción                                                      |
| ----------- | ---------------------------------------------------------------- |
| `workspace` | El valor predeterminado; los valores almacenados desconocidos y null se resuelven a él |
| `private`   | Privado para el usuario que lo creó                              |

## Enumeración AgentLifecycleStatus

| Valor      | Descripción                                                                                     |
| ---------- | ----------------------------------------------------------------------------------------------- |
| `active`   | El valor predeterminado. `isDispatchable` solo es true para este valor                          |
| `paused`   | Lo establece la parada dura del presupuesto. Se muestra en la lista de presencia; el despacho sigue aceptando trabajo |
| `archived` | Retirado y oculto de las listas de presencia activas                                            |

## Indicadores de AgentCapabilities

Se resuelven en cada despacho: el valor predeterminado del agente, recurriendo al predeterminado del usuario cuando es null, con una anulación por conversación por encima. Se aplican por ausencia: el bróker de credenciales sencillamente no emite ni inyecta aquello que cubre una capacidad desactivada.

| Indicador          | Tipo   | Predeterminado | Descripción                                                                                      |
| ------------------ | ------ | -------------- | ------------------------------------------------------------------------------------------------ |
| `canPushToRepo`    | `bool` | `false`        | Sube commits al remoto; condiciona la inyección del token de GitHub junto con `canCallGitHubApi`  |
| `canCallGitHubApi` | `bool` | `false`        | Llama a api.github.com; condiciona la inyección de `GH_TOKEN` y los dominios de salida a la red de GitHub |
| `canCallTicketing` | `bool` | `false`        | Llama a la API del proveedor de tickets; condiciona la inyección de la clave API del proveedor y sus dominios de salida a la red |
| `canAccessNetwork` | `bool` | `true`         | Salida a la red arbitraria hacia el exterior. También condiciona las herramientas `web_fetch` y `web_search` del arnés |

`AgentCapabilities.safeDefault` es el valor predeterminado del constructor para las cuatro capacidades. `legacyDefault` (las cuatro en true) solo lo usa la migración que rellenó conversaciones creadas antes de que existieran las capacidades. Un blob almacenado mal formado o vacío se resuelve a `safeDefault`; la clave heredada `canCallLinear` se interpreta como `canCallTicketing`.

## AgentSkills

Un conjunto inmutable y que no distingue mayúsculas de minúsculas de identificadores de skills. Al despachar, esos slugs se sincronizan como enlaces de skills en el overlay del agente; el arnés carga entonces automáticamente el frontmatter de las skills enlazadas en el prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (derivado)

No se almacena. Siete valores. El orden de declaración es el orden de prioridad (`sortPriority`, fijado por un test), que es el orden por el que ordena la lista de presencia:

| Estado      | `sortPriority` | Condición                                                                                                            |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Algún registro de ejecución tiene el estado `running`                                                                |
| `blocked`   | 1              | La vitalidad de la última ejecución es `blocked`, `stalled` o `looping`                                              |
| `failed`    | 2              | El estado de la última ejecución es `error`, o su vitalidad es `failed` o `dead`                                     |
| `queued`    | 3              | Una ejecución se ha despachado pero no se está ejecutando: aparcada detrás de otra ejecución del mismo agente, o escrita pero aún sin iniciar |
| `succeeded` | 4              | La ejecución terminó correctamente                                                                                    |
| `idle`      | 5              | El agente ya se ha ejecutado antes y no tiene nada en curso                                                           |
| `neverRun`  | 6              | No existe ningún registro de ejecución                                                                               |

`queued` y `succeeded` son **solo por ejecución**. `deriveAgentLiveState`, que calcula el estado de la lista de presencia de un agente, nunca produce ninguno de los dos: devuelve `neverRun`, `running`, `failed`, `blocked` o `idle`.
