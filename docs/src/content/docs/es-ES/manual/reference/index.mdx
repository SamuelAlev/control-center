Las páginas de referencia describen **lo que hay**, de forma exhaustiva y sin
comentarios. Úsalas para consultar algo cuando ya sabes lo que buscas: el nombre
exacto de una herramienta, un tipo de paso, una transición de estado, una ruta, un
atajo.

No están escritas para leerse de principio a fin. Para eso, usa los
[conceptos](/es-ES/manual/conceptos/); para llevar a cabo una tarea, usa las
[guías prácticas](/es-ES/manual/guias/).

## La superficie del producto

- [Herramientas MCP](/es-ES/manual/referencia/herramientas-mcp/) — todas las herramientas que registra el servidor MCP, por familia
- [Herramientas de agente integradas](/es-ES/manual/referencia/herramientas-de-agente/) — herramientas del harness vinculadas al servidor (LSP, AST, debug, eval, vibe)
- [Comandos slash](/es-ES/manual/referencia/comandos-slash/) — integradas del compositor, `/skill:` y comandos de usuario
- [Mapa de rutas](/es-ES/manual/referencia/mapa-de-rutas/) — cada pantalla y la URL que lleva hasta ella
- [Atajos de teclado](/es-ES/manual/referencia/atajos-de-teclado/) — el registro completo de atajos de teclado
- [Eventos de dominio](/es-ES/manual/referencia/eventos-de-dominio/) — cada evento publicado en el bus de dominio
- [Rigs](/es-ES/manual/referencia/rigs/) — cada superficie de rig, verbo de acción, estado del ciclo de vida, puerto y valor predeterminado
