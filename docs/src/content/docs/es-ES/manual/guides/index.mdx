Cada guía resuelve **un problema para quien ya se maneja bien con el producto**. Dan por
hecho que tienes Control Center instalado y un espacio de trabajo configurado, enuncian un
objetivo en el título y terminan cuando se alcanza ese objetivo.

Si todavía estás conociendo el producto, empieza por los
[tutoriales](/es-ES/manual/tutoriales/). Si quieres entender _por qué_ algo se comporta
como se comporta, lee los [conceptos](/es-ES/manual/conceptos/).
