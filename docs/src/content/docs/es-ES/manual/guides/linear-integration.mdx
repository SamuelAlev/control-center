Pega una clave de API de Linear en el servidor asociada a tu usuario, igual que
conectas un host de código. Los tickets, los proyectos, los vínculos, los
colaboradores, la delegación y la asignación funcionan todos contra la base de
datos propia de Control Center, sin necesidad de ningún servicio externo —
consulta [Crear y gestionar tickets](/es-ES/manual/guias/gestionar-tickets/).

## Guardar tu clave de Linear

**Clave de API de tickets** está en **Ajustes → Espacio de trabajo → General**,
en la tarjeta **Tickets**. Guarda la clave en el servidor asociada a tu id de
usuario. La clave propia del servidor para el trabajo sin supervisión procede de
`LINEAR_API_KEY` o de la tarjeta **Aplicaciones de proveedor**. En el entorno
aislado de un agente no se coloca ninguna clave de tickets: los agentes escriben
tickets con las herramientas propias de Control Center, que primero preguntan a
la regla **Escribir en un rastreador externo**.

## Marcar los tickets nuevos como Linear

**Proveedor de tickets** (el primer paso de la puesta en marcha, y
`/workspaces/<workspaceId>/api-keys`) ofrece `local` y `linear`. Si eliges
`linear`, se marca `provider: linear` en los tickets que crees a partir de ese
momento.
