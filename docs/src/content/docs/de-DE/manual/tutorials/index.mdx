Tutorials sind **Lektionen**. Jede führt dich von Anfang bis Ende durch etwas Echtes,
auf einem einzigen Weg und ohne Entscheidungen unterwegs. Folge den Schritten genau,
dann funktionieren sie.

Damit findest du dich zurecht. Sobald du weißt, wie das Produkt aufgebaut ist, sind die
[Anleitungen](/de-DE/handbuch/anleitungen/) der schnellere Weg zu einer bestimmten Aufgabe.

Geh sie in dieser Reihenfolge — jede setzt die vorherige voraus.

1. [Dein erster Arbeitsbereich](/de-DE/handbuch/tutorials/erster-arbeitsbereich/) — leg einen Arbeitsbereich an, füge ein Repo hinzu und sieh dir das Isolationsmodell an
2. [Deinen ersten Agenten starten](/de-DE/handbuch/tutorials/erster-agent/) — gib einem Agenten einen Adapter und ein Modell und setz ihn dann an die Arbeit
3. [Deinen ersten Pull Request prüfen](/de-DE/handbuch/tutorials/erster-pr/) — lies den Diff, kommentiere und merge
4. [Deine erste Pipeline bauen](/de-DE/handbuch/tutorials/erste-pipeline/) — verkette Schritte zu einem DAG und führe ihn aus

Zwei weitere stehen für sich; mach eine davon, sobald du einen funktionierenden Arbeitsbereich hast.

- [Slack mit deinem Arbeitsbereich verbinden](/de-DE/handbuch/tutorials/erste-chat-bruecke/) — steuere Agenten aus einem Slack-Thread
- [Dein Team mit SSO anmelden](/de-DE/handbuch/tutorials/sso/) — verbinde einen Identitätsanbieter und geh eine Anmeldung von Anfang bis Ende durch

:::note[Bevor du anfängst]
Installiere zuerst Control Center — siehe [Installation](/de-DE/handbuch/installation/). Wenn du nur den
kürzestmöglichen Weg zu einem laufenden Agenten willst, nimm stattdessen den [Schnellstart](/de-DE/handbuch/schnellstart/)
und komm danach hierher zurück.
:::
