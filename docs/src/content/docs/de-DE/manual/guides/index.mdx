Jede Anleitung löst **ein Problem für jemanden, der sich schon auskennt**. Sie
setzen voraus, dass du Control Center installiert und einen Arbeitsbereich
eingerichtet hast, nennen das Ziel im Titel und hören auf, sobald das Ziel erreicht ist.

Wenn du das Produkt noch lernst, fang mit den [Tutorials](/de-DE/handbuch/tutorials/)
an. Wenn du verstehen willst, _warum_ sich etwas so verhält, lies die
[Konzepte](/de-DE/handbuch/konzepte/).
