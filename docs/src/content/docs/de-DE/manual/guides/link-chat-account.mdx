Diese Anleitung zeigt dir, wie du deine Chat-Identität mit deinem Nutzer in Control Center verknüpfst und wie du eine Verknüpfung wieder löst.

Jedes Mitglied macht das einmal pro Chat-Anbieter. Das ist etwas anderes, als die App zu verbinden: Die Verbindung macht den Bot für den ganzen Arbeitsbereich erreichbar, die Verknüpfung macht _dich_ darin erkennbar.

## Warum die Verknüpfung nötig ist

Die Brücke weigert sich, für ein Chat-Konto zu handeln, das sie keinem Mitglied des Arbeitsbereichs zuordnen kann. Das ist Absicht — ohne Verknüpfung müsste jede Nachricht aus Slack der Person zugerechnet werden, die die App installiert hat, und Prüfpfad, Rate-Limits pro Prinzipal und die Melder der Tickets würden alle die falsche Person nennen.

Ein nicht verknüpftes Mitglied, das den Bot erwähnt, bekommt in diesem Slack-Thread eine Antwort, die erklärt, wie die Verknüpfung geht. Es wird nichts ausgeführt.

## Mit einem Code verknüpfen

Zum Verknüpfen gehören beide Seiten: Einen Code aus Slack zu schicken beweist das Slack-Konto, und ihn in Control Center zu bestätigen beweist, dass dieses Konto dir gehört.

1. Geh zu **Einstellungen → Du → Profil** und such die Karte **Verknüpfte Chat-Konten**
2. Klicke im Slack-Block auf **Mein Slack-Konto verknüpfen**. Der Dialog zeigt einen Einmalcode, zum Beispiel:

```text
K7M2QP
```

3. Schick diesen Code in Slack in einer **Direktnachricht** an den Bot: nur den Code, sonst nichts
4. Der Bot antwortet „Got it. Confirm this Slack account in Control Center to finish linking.“, und der Dialog, den du offen gelassen hast, zeigt das Slack-Profil, das den Code geschickt hat: seinen Namen und seine Slack-Mitglieds-ID
5. Ist es dein Konto, klicke auf **Bestätigen**. Die Verknüpfung entsteht, der Dialog meldet das, und der Bot bestätigt in derselben Direktnachricht
6. Ist es nicht deins, klicke auf **Ablehnen**. Nichts wird verknüpft, und der Code funktioniert nicht mehr; klicke auf **Neuen Code holen**, um es noch einmal zu versuchen

Schließt du den Dialog, geht ein Anspruch nicht verloren. Ein Code, der später ankommt, wartet in der Zeile **Mein Slack-Konto verknüpfen** auf dieser Karte, mit denselben Schaltflächen **Bestätigen** und **Ablehnen**.

Warum es den Bestätigungsschritt gibt: Ein Code, den jemand über deine Schulter liest und von einem anderen Slack-Konto schickt, würde dieses Konto sonst als dich handeln lassen. Nur du kannst bestätigen, und nur genau das Profil, das den Code geschickt hat.

Der Code:

- Ist einmalig und läuft **15 Minuten** nach dem Erzeugen ab
- Wird immer für _dich_ erzeugt, nie für ein Teammitglied
- Funktioniert nur in einer Direktnachricht an den Bot. In einem Kanal ist er nur eine Nachricht
- Kann nur von einem Vollmitglied des Slack-Workspace eingelöst werden, in dem der Bot installiert ist, nicht von einem Gast oder jemandem aus einer anderen Organisation
- Ersetzt jeden Code, den du schon hältst, sodass ein erneuter Klick auf die Schaltfläche den vorherigen ungültig macht
- Liegt nur im Speicher, sodass ein Neustart des Servers noch offene Codes ungültig macht — tippe erneut auf die Schaltfläche

Ein Code, der unbekannt, abgelaufen, abgelehnt oder für einen anderen Arbeitsbereich erzeugt wurde, scheitert jedes Mal auf dieselbe, nicht unterscheidbare Weise: „That code is not valid (or has expired).“

## Automatisch per E-Mail verknüpfen

Trägt dein Slack-Profil eine bestätigte E-Mail, die zur verifizierten E-Mail eines Nutzers in Control Center passt, der **bereits Mitglied dieses Arbeitsbereichs** ist, verknüpft die Brücke dich beim ersten Gespräch. Kein Code nötig.

Die Control-Center-Seite gilt als verifiziert, wenn Single sign-on oder SCIM die Adresse gesetzt haben oder der Serverinhaber sie unter **Einstellungen → Server → Personen** bestätigt hat. Eine Adresse, die du in deinem eigenen Profil eingetragen hast, ist nicht verifiziert und verknüpft daher nichts, bis der Serverinhaber sie bestätigt. Nutze bis dahin den Code-Ablauf.

Beide Hälften zählen: Der E-Mail-Abgleich beweist die Identität, aber nur die Mitgliedschaft gewährt Zugang, sodass ein Fremder, dessen E-Mail zufällig auf dem Server liegt, mit nichts verknüpft wird. Die Liste zeigt, wie jede Verknüpfung entstanden ist („per E-Mail zugeordnet“ oder „mit einem Code verknüpft“).

Die automatische Verknüpfung braucht den Scope `users:read.email`. Ohne ihn gibt Slack die Adresse nicht preis, und der Weg über den Code ist der einzige.

## Sehen, wer verknüpft ist

Die Liste gehört zur Verwaltung des Arbeitsbereichs, sie steht also auf der Verwaltungskarte: **Einstellungen → Arbeitsbereich → Integrationen → Chat-Brücken → Verknüpfte Konten**. Sie führt jedes verknüpfte Mitglied des Arbeitsbereichs auf, mit dem Slack-Konto, auf das es abbildet, und damit, wie die Verknüpfung entstanden ist.

Deinen eigenen Stand siehst du unter **Einstellungen → Du → Profil**: Die Zeile **Mein Slack-Konto verknüpfen** liest „Verknüpft mit _your-slack-id_“, sobald du verknüpft bist, und fordert dich zum Verknüpfen auf, solange du es nicht bist.

Die Liste und der Anspruch sind Live-Abonnements, weil die Änderung auf der anderen Seite geschieht: Du schickst den Code in Slack, also kann keine Anfrage aus der App die Antwort zurücktragen.

## Verknüpfung lösen

Klicke in einer Zeile der Liste des Arbeitsbereichs auf **Verknüpfung lösen**.

- Jede Person kann die eigene Verknüpfung lösen
- Nur ein Admin kann die Verknüpfung eines anderen Mitglieds lösen
- Das Lösen widerruft auch jeden noch offenen Verknüpfungscode dieses Mitglieds

Danach kann dieses Slack-Konto keine Agenten mehr steuern, bis es erneut verknüpft wird. Vorhandene Bereiche, Transkripte und Tickets behalten ihre ursprüngliche Zuordnung — das Lösen nimmt vergangene Arbeit nicht zurück.

## Fehlersuche

### Der Bot sagt, ich sei kein Mitglied dieses Arbeitsbereichs

Dein Slack-Konto ist mit einem Nutzer in Control Center verknüpft, aber dieser Nutzer hat in diesem Arbeitsbereich keine Mitgliedschaft. Bitte einen Admin, dich einzuladen; siehe [Multiplayer — Identität, Mitgliedschaft und Präsenz](/de-DE/handbuch/konzepte/multiplayer/).

### Der Bot sagt, meine Rolle sei nur lesend

Die Rollen `viewer` und `guest` können keine Arbeit starten. Ein Admin muss deine Rolle auf `member` oder höher setzen.

### Der Bot sagt, der Code sei nicht gültig

Der Code ist abgelaufen, wurde schon benutzt, wurde abgelehnt oder durch einen neueren ersetzt. Klicke erneut auf **Mein Slack-Konto verknüpfen** und schick den neuen Code.

### Der Bot behandelt meinen Code als Anfrage

Du hast ihn in einem Kanal geschickt, oder dein Slack-Konto ist schon verknüpft. Codes werden nur in einer Direktnachricht angenommen, und eine Nachricht in Codeform von einem verknüpften Konto ist eine gewöhnliche Anfrage.
