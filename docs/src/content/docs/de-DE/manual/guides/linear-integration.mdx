Füge einen Linear-API-Schlüssel auf dem Server unter deinem Nutzer ein, so wie du
eine Forge verbindest. Tickets, Projekte, Verknüpfungen, Mitwirkende, Delegation
und Zuweisung funktionieren alle über die eigene Datenbank von Control Center,
ohne dass ein externer Dienst nötig ist — siehe
[Tickets erstellen und verwalten](/de-DE/handbuch/anleitungen/tickets-verwalten/).

## Deinen Linear-Schlüssel speichern

**Ticketing-API-Schlüssel** liegt unter **Einstellungen → Arbeitsbereich → Allgemein**, auf der
Karte **Tickets**. Er speichert den Schlüssel auf dem Server unter deiner Nutzer-ID. Den
eigenen Schlüssel des Servers für Arbeit ohne Aufrufer liefert `LINEAR_API_KEY` oder die
Karte **Anbieter-Apps**, und er wird nur dann als `TICKETING_API_KEY` injiziert, wenn
dieser Agent die Befugnis **Ticketing-API-Aufrufe zulassen** hat.

## Neue Tickets als Linear stempeln

**Ticketing-Anbieter** (der erste Schritt des Onboardings und
`/workspaces/<workspaceId>/api-keys`) bietet `local` und `linear`. Wählst du
`linear`, stempelt das `provider: linear` auf Tickets, die du von da an anlegst.
