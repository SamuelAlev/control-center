## App-Shell

Die App-Shell (`ControlCenterLayout`) umschließt jede Route im Arbeitsbereich über eine `ShellRoute`. **Jedes Ziel in der Shell trägt den Arbeitsbereich als Präfix — `/workspaces/:workspaceId/…` — und die Arbeitsbereichs-ID in der URL ist die einzige Quelle der Wahrheit für den aktiven Arbeitsbereich.** Nur die Flächen vor dem Kontext haben kein Präfix: `/splash`, `/onboarding` und die nackte Auswahl `/workspaces`, alle im Vollbild und außerhalb der Shell.

Das Gate ist vollständig, wenn mindestens eine Forge **für den angemeldeten User** verbunden ist und mindestens ein Arbeitsbereich existiert.

Fehlende Zugangsdaten und ein fehlendes Setup werden unterschiedlich behandelt, und das Unterscheidungsmerkmal ist `users.onboarding_finished_at`, gelesen vom eigenen `identity.me` des Aufrufers — nie „Arbeitsbereiche existieren“, was in dem Moment falsch ist, in dem jemand in einen Arbeitsbereich eingeladen wird, den diese Person nie angelegt hat. Ohne verbundene Forge bleibt ein Konto, das das Onboarding abgeschlossen hat, in der App: Die Shell des Arbeitsbereichs zeigt eine Warnung mit einem Link zu Einstellungen → Du → Profil, wo die Anmeldung liegt. Eines, das es nicht abgeschlossen hat, geht nach `/onboarding`. Solange das Flag noch unbekannt ist, hält der Guard den Splash, statt zu raten, weil er nie aus dem Onboarding wieder herausleitet.

## Routen ohne Präfix

| Pfad                       | Bildschirm                                           |
| -------------------------- | ---------------------------------------------------- |
| `/splash`                  | Start-Splash, der das Onboarding-Gate auflöst |
| `/onboarding`              | Forge verbinden, einen Arbeitsbereich anlegen oder beitreten, Sandbox, Standard-Adapter, dann Stimme. Der Schritt zum Arbeitsbereich entfällt, wenn das Konto schon zu einem gehört |
| `/workspaces`              | Liste und Auswahl der Arbeitsbereiche                        |
| `/workspaces/:workspaceId` | Leitet um nach `/workspaces/:workspaceId/inbox`    |

Unterhaltungen und Threads haben **keine eigene Route** — ein Thread ist eine Unterhaltung in `/spaces/:spaceId`, geöffnet als Editor-Tab statt über die URL adressiert.

Es gibt **keine Route `/dashboard`** und keinen Dashboard-Bildschirm. Die Analysefläche ist `/observability`, erreichbar aus der Fußzeile der Seitenleiste.

Es gibt **keinen Seitenleisteneintrag „Pläne“**. Plan Studio öffnet sich als Editor-Tab aus der Planzeile der Unterhaltung, die ihn erzeugt hat; `/plans` und `/plans/:kind/:id` sind Direktlinks.

`/observability` und `/pull-requests/compose` stehen weder in der Registry der Routentitel noch in der der Breadcrumbs, deshalb zeigen beide nur den App-Namen im Fenstertitel und keine Breadcrumb-Spur.

## Einstellungsrouten

`/settings` leitet auf `/settings/you/profile` um. Die Schaltfläche Einstellungen in der Seitenleiste und `Cmd/Ctrl + ,` führen beide nach `/settings/you/profile`.

Einstellungspfade sind nach **Geltungsbereich** benannt — `you/`, `workspace/`, `server/` — weil das Segment sagt, wen eine Änderung betrifft. Zwei Pfade sind älter als diese Benennung und in der URL keinem Geltungsbereich zugeordnet: `/settings/memory` und `/settings/pipelines`.

### Du

| Pfad                          | Bildschirm                                                                     |
| ----------------------------- | -------------------------------------------------------------------------- |
| `/settings/you/profile`       | Dein Konto auf diesem Server: Name, Benutzername, Bild und Anmeldung (die Einstiegsseite der Einstellungen) |
| `/settings/you/profile?section=accounts` | Verbundene Konten: deine eigenen Anmeldungen für Code-Hosting, Tickets, Kalender und Chat sowie Ticketentwürfe aus dem Chat |
| `/settings/you/appearance`    | Thema, Sprache, Typografie, Editor-Thema |
| `/settings/you/audio`         | Mikrofon, Diktat, Besprechungserkennung und Klanglandschafts-Ausgabe             |
| `/settings/you/notifications` | Schalter je Ereignis, Quiet hours                                             |
| `/settings/you/commits`       | Wer bei Commits aus Arbeit, die du startest, als Autor geführt wird, und dein Commit-Signaturschlüssel |
| `/settings/you/desktop`       | Nur Desktop-App: das Tray-Symbol, Schließen des Fensters und Öffnen beim Anmelden   |
| `/settings/you/devices`       | Gekoppelte Telefone und Fernsteuerung                                           |
| `/settings/you/newsfeed`      | Feed-Verwaltung: Quellen, Aktualisierung, Lesestatus                              |
| `/settings/you/links`         | Wohin Links von außerhalb von Control Center geöffnet werden                               |

| `/settings/workspace/integrations` | Connect-Wahl, die GitHub App und Automatisierungstoken, Ticket-Anbieter und Automatisierung, Sync-Status, die eigenen Provider-Apps des Arbeitsbereichs, Chat-Brücken, GIFs. Jede Anbietergruppe nennt dein eigenes Konto und verlinkt auf Verbundene Konten |
| `/settings/workspace/meetings`     | Vorlagen für Besprechungsnotizen und gespeicherte Stimmprofile                                                     |
| `/settings/workspace/members`      | Mitgliederliste und Einladungen                    |
| `/settings/workspace/repositories` | In diesem Arbeitsbereich registrierte Repositorys                                                           |

| `/settings/workspace/agents`       | Registrierte Agentenidentitäten                                                                         |
| `/settings/workspace/skills`       | Konfiguration der Fähigkeiten                                                                                 |
| `/settings/memory`                 | Arbeitsbereichs-Gedächtnis: Fakten, Richtlinien, Wissensgraph                                                  |

| ------------------------------ | ------------------------------------------------------------------------------------- |

`kSettingsNav` in `lib/features/settings/settings_nav.dart` ist die einzige Quelle der Wahrheit für diese Liste. `settings_nav_test.dart` hält eindeutige Ids, eindeutige Routen, die flache J/K-Reihenfolge und die drei Geltungsbereiche fest. Er geht nicht jede registrierte `GoRoute` ab.
