## App-Shell

Die App-Shell (`ControlCenterLayout`) umschließt jede Route im Arbeitsbereich über eine `ShellRoute`. **Jedes Ziel in der Shell trägt den Arbeitsbereich als Präfix — `/workspaces/:workspaceId/…` — und die Arbeitsbereichs-ID in der URL ist die einzige Quelle der Wahrheit für den aktiven Arbeitsbereich.** Nur die Flächen vor dem Kontext haben kein Präfix: `/splash`, `/onboarding`, `/signed-out` und die nackte Auswahl `/workspaces`, alle im Vollbild und außerhalb der Shell.

Das Gate ist vollständig, wenn mindestens eine Forge **für den angemeldeten User** verbunden ist und mindestens ein Arbeitsbereich existiert.

Fehlende Zugangsdaten und ein fehlendes Setup sind verschiedene Bildschirme, und das Unterscheidungsmerkmal ist `users.onboarding_finished_at`, gelesen vom eigenen `identity.me` des Aufrufers — nie „Arbeitsbereiche existieren“, was in dem Moment falsch ist, in dem jemand in einen Arbeitsbereich eingeladen wird, den diese Person nie angelegt hat. Ohne verbundene Forge geht ein Konto, das das Onboarding abgeschlossen hat, nach `/signed-out`, um sich neu zu authentifizieren; eines, das es nicht abgeschlossen hat, nach `/onboarding`. Solange das Flag noch unbekannt ist, hält der Guard den Splash, statt zu raten, weil er nie aus dem Onboarding wieder herausleitet.

## Routen ohne Präfix

| Pfad                       | Bildschirm                                           |
| -------------------------- | ---------------------------------------------------- |
| `/splash`                  | Start-Splash, der das Onboarding-Gate auflöst |
| `/onboarding`              | Forge verbinden, einen Arbeitsbereich anlegen oder beitreten, Sandbox, Standard-Adapter, dann Stimme. Der Schritt zum Arbeitsbereich entfällt, wenn das Konto schon zu einem gehört |
| `/signed-out`              | Neu authentifizieren: dieselbe Karte Code-Hosting, die die Einstellungen zeigen, ohne Schrittleiste und ohne Schaltfläche Weiter — der Router verlässt die Seite von selbst, sobald eine Forge sich meldet |
| `/workspaces`              | Liste und Auswahl der Arbeitsbereiche                        |
| `/workspaces/:workspaceId` | Leitet um nach `/workspaces/:workspaceId/inbox`    |

Unterhaltungen und Threads haben **keine eigene Route** — ein Thread ist eine Unterhaltung in `/spaces/:spaceId`, geöffnet als Editor-Tab statt über die URL adressiert.

Es gibt **keine Route `/dashboard`** und keinen Dashboard-Bildschirm. Die Analysefläche ist `/observability`, erreichbar aus der Fußzeile der Seitenleiste.

Es gibt **keinen Seitenleisteneintrag „Pläne“**. Plan Studio öffnet sich als Editor-Tab aus der Planzeile der Unterhaltung, die ihn erzeugt hat; `/plans` und `/plans/:kind/:id` sind Direktlinks.

`/observability` und `/pull-requests/compose` stehen weder in der Registry der Routentitel noch in der der Breadcrumbs, deshalb zeigen beide nur den App-Namen im Fenstertitel und keine Breadcrumb-Spur.

## Einstellungsrouten

`/settings` leitet auf `/settings/you/appearance` um. Die Schaltfläche Einstellungen in der Seitenleiste und `Cmd/Ctrl + ,` führen beide nach `/settings/you/appearance`.

Einstellungspfade sind nach **Geltungsbereich** benannt — `you/`, `workspace/`, `server/` — weil das Segment sagt, wen eine Änderung betrifft. Zwei Pfade sind älter als diese Benennung und in der URL keinem Geltungsbereich zugeordnet: `/settings/memory` und `/settings/pipelines`.

### Du

| Pfad                          | Bildschirm                                                                     |
| ----------------------------- | -------------------------------------------------------------------------- |
| `/settings/you/appearance`    | Thema, Sprache, Typografie, Editor-Thema (die Einstiegsseite der Einstellungen)          |
| `/settings/you/notifications` | Schalter je Ereignis, Quiet hours                                             |
| `/settings/you/keybindings`   | Referenz der Tastaturkürzel (nur lesbar)                                    |
| `/settings/you/audio`         | Mikrofon, Diktat, Besprechungserkennung und Klanglandschafts-Ausgabe             |
| `/settings/you/devices`       | Gekoppelte Telefone und Fernsteuerung                                           |
| `/settings/you/newsfeed`      | Feed-Verwaltung: Quellen, Aktualisierung, Lesestatus                              |

### Arbeitsbereich

| Pfad                               | Bildschirm                                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- |
| `/settings/workspace/profile`      | Profil und Identität in diesem Arbeitsbereich: Name, Git-Autor, Code-Hosting, Kalender |
| `/settings/workspace/general`      | Name, Logo, ausgeschlossene Geheimnispfade, parallele Prüfer, Vorlage für Branch-Namen, Sync-Status, Chat-Brücken, Gefahrenzone |
| `/settings/workspace/meetings`     | Vorlagen für Besprechungsnotizen und gespeicherte Stimmprofile                                                     |
| `/settings/workspace/members`      | Mitgliederliste, Einladungen, Prüfprotokoll. Das Prüfprotokoll paginiert optional mit `?cursor=`                    |
| `/settings/workspace/repositories` | In diesem Arbeitsbereich registrierte Repositorys                                                           |
| `/settings/workspace/agents`       | Registrierte Agentenidentitäten                                                                         |
| `/settings/workspace/skills`       | Konfiguration der Fähigkeiten                                                                                 |
| `/settings/memory`                 | Arbeitsbereichs-Gedächtnis: Fakten, Richtlinien, Wissensgraph                                                  |
| `/settings/workspace/permissions`  | Agent-Berechtigungen: Schutzregel-Matrix und Prüfung „Was wäre wenn?“                                               |
| `/settings/pipelines`              | Pipeline-Vorlagen                                                                                  |
| `/settings/pipelines/:templateId`  | Editor für Pipeline-Vorlagen (Drag-and-Drop-Leinwand)                                                     |

### Server

| Pfad                           | Bildschirm                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------- |

| `/settings/server/providers`   | Modellanbieter und Adapter                                                          |
| `/settings/server/mcp`         | Eingebaute und externe MCP-Server                                                     |

`kSettingsNav` in `lib/features/settings/settings_nav.dart` ist die einzige Quelle der Wahrheit für diese Liste. `settings_nav_test.dart` hält eindeutige Ids, eindeutige Routen, die flache J/K-Reihenfolge und die drei Geltungsbereiche fest. Er geht nicht jede registrierte `GoRoute` ab.
