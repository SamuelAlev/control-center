Die Kürzel kommen aus einer `const`-Registry, `KeybindingRegistry` in `lib/core/constants/keybindings.dart`. Sie enthält **48 Bindungen**. Einstellungen → Du → Tastaturkürzel zeigt diese Registry als **schreibgeschützte Referenz**: Es gibt keine Oberfläche zum Umbelegen und keine Datei für eigene Tastenkürzel.

`Cmd` unten ist der primäre Befehlsmodifikator — ⌘ auf macOS, Ctrl unter Windows und Linux. Eine Bindung löst nur aus, wenn ihr Befehl auf dem aktuellen Bildschirm einen registrierten Handler hat und ihre `when`-Klausel zutrifft; `!textInputFocus` heißt, die Taste wird an ein fokussiertes Textfeld durchgereicht.

Eine Navigation per Zifferntaste gibt es nicht. Posteingang, Tickets, Pull Requests und den Rest erreichst du über die Seitenleiste oder mit ⌘K. Observability hat auch keins.

Geltungsbereich `global`, sie gelten also überall in der App-Shell.

## Pull-Request-Liste (3)

Geltungsbereich `/pull-requests`. Alle verlangen `route == '/pull-requests'` und kein fokussiertes Textfeld, sie lösen also nicht aus, solange die PR-Detailroute über der Liste offen ist.

| Tastenkürzel | Aktion            |
| ------------ | ----------------- |
| `R`          | Aktualisieren     |
| `Enter`      | PR öffnen         |
| `F`          | Filtermenü öffnen |

`Enter` (`pr.list-open`) ist in der Registry deklariert und erscheint in der Tastaturkürzel-Referenz, aber **der Listenbildschirm registriert keinen Handler dafür**, deshalb löst es derzeit nicht aus. `F` öffnet das Filtermenü (`pr.list-open-filter`), nicht die Suche.

## Pull-Request-Detail (2)

Geltungsbereich `/pull-requests/`. Aktualisieren verlangt kein fokussiertes Textfeld. Tab schließen hat keine Sperre für die Texteingabe (ein mit ⌘ modifizierter Anschlag ist nie Klartext) und einen Routen-Regex, damit es auf der Liste nicht auslöst.

| Tastenkürzel   | Aktion         | Bedingung                          |
| -------------- | -------------- | ---------------------------------- |
| `R`            | Aktualisieren  | Nicht in einem Feld tippen         |
| `Cmd/Ctrl + W` | Tab schließen  | Auf einer `/pull-requests/<…>`-Adresse |

Tabwechsel (`1`/`2`/`3`), Gesehen und Einklappen einer Datei (`V`/`C`), die Dateiliste (`T`) und die Suche im Diff (`Cmd/Ctrl + F`) gehören zum eigenen Handler des Diff-Viewers — siehe [Diff-Viewer-Tasten außerhalb der Registry](#diff-viewer-tasten-außerhalb-der-registry).

## GitHub-Benutzer- und Teamprofile (3)

Geltungsbereich `/users/`. Die `when`-Klausel ist ein Regex gegen `/users/<login>` **oder** `/teams/<organization>/<slug>`, dazu kein fokussiertes Textfeld.

| Tastenkürzel   | Aktion             |
| -------------- | ------------------ |
| `R`            | Aktualisieren      |
| `/`            | Suche fokussieren  |
| `Cmd/Ctrl + F` | Suche fokussieren  |

## Bereiche (8)

Geltungsbereich `/spaces`. Die `when`-Klauseln nutzen einen Regex, damit sie sowohl auf der Bereichsliste (`/spaces`) als auch in einem ausgewählten Bereich (`/spaces/<id>`) auslösen.

| Tastenkürzel           | Aktion                         | Bedingung                  |
| ---------------------- | ------------------------------ | -------------------------- |
| `Enter`                | Nachricht senden               | —                          |
| `Cmd/Ctrl + N`         | Neuer Bereich                  | Auf einer `/spaces`-Route  |
| `J`                    | Nächster Bereich               | Nicht in einem Feld tippen |
| `K`                    | Vorheriger Bereich             | Nicht in einem Feld tippen |
| `Cmd/Ctrl + Shift + D` | Zum Sprechen drücken           | —                          |
| `Cmd/Ctrl + T`         | Editor öffnen                  | Auf einer `/spaces`-Route  |
| `Cmd/Ctrl + W`         | Tab schließen                  | Auf einer `/spaces`-Route  |
| `Cmd/Ctrl + B`         | Seitenleiste ein/ausblenden    | Auf einer `/spaces`-Route  |

Senden mit Enter gehört zum Textfeld des Composers. Zum Sprechen drücken gehört zur Mikrofontaste des Composers, mit eigenem Handler für die Hardware-Tastatur. Beide stehen in der Registry, damit die Einstellungsreferenz sie aufführt.

## Diff-Viewer-Tasten außerhalb der Registry

Der PR-Diff-Viewer verarbeitet diese Tasten selbst (`PrDiffKeyboardHandler`). Suche, Gesehen und Einklappen stehen nur in den Kommentaren der Registry für die Einstellungsreferenz — ein Dispatcher-Handler ist nicht registriert, der Dispatcher überlässt sie der Diff-Ansicht. In der Tastaturkürzel-Referenz haben sie keine eigenen Zeilen.

| Tastenkürzel    | Aktion                                                          |
| --------------- | --------------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Im Diff suchen                                                  |
| `J` / `K`       | Nächste / vorherige Datei                                       |
| `V`             | Gesehen für die fokussierte Datei umschalten                    |
| `C`             | Einklappen für die fokussierte Datei umschalten                 |
| `T`             | Dateiliste anzeigen                                             |
| `Enter`         | Nächste Übereinstimmung (nur solange die Suche im Diff offen ist) |
| `Shift + Enter` | Vorherige Übereinstimmung                                       |
| `Escape`        | Suche im Diff schließen oder die Textauswahl im Diff aufheben   |
| `Cmd/Ctrl + C`  | Diff-Auswahl kopieren                                           |

## Vom Browser reservierte Kombinationen

Im Web-Build verbraucht der Browser einige Tastenkürzel, bevor die Seite sie sieht, deshalb können die passenden Bindungen dort nie auslösen. Auf dem Desktop funktionieren sie normal. Reserviert in Kombination mit dem primären Befehlsmodifikator: `T`, `W`, `N` und die Ziffern `1`–`9`.

Das umfasst den Arbeitsbereichswechsel mit `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (neuer Bereich, neuer Arbeitsbereich, neuer Agent, Repository hinzufügen) sowie `Cmd/Ctrl + T` und `Cmd/Ctrl + W` in Bereichen und im PR-Detail.
