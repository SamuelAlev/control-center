Diese Referenz listet jedes Feld der Agenten-Entität auf, dazu die Enums und Flags, die sie verwendet. Wie du einen Agenten in der App anlegst oder bearbeitest, steht Schritt für Schritt unter [Einen Agenten erstellen und konfigurieren](/de-DE/handbuch/anleitungen/agent-erstellen/).

## Felder der Agenten-Entität

| Feld                    | Typ                    | Erforderlich | Beschreibung                                                                                                                                                                                          |
| ----------------------- | ---------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ja           | Eindeutige Kennung des Agenten                                                                                                                                                                        |
| `name`                  | `String`               | Ja           | Kurze Kennung für @-Erwähnungen                                                                                                                                                                       |
| `title`                 | `String`               | Ja           | Lesbare Berufsbezeichnung                                                                                                                                                                             |
| `agentMdPath`           | `String`               | Ja           | Absoluter Pfad zur `.md`-Definitionsdatei des Agenten                                                                                                                                                 |
| `workspaceId`           | `String`               | Ja           | Arbeitsbereich, dem der Agent gehört (nicht null)                                                                                                                                                     |
| `reportsTo`             | `String?`              | Nein         | ID des übergeordneten Agenten                                                                                                                                                                         |
| `skills`                | `AgentSkills`          | Ja           | Menge von Skill-Kennungen                                                                                                                                                                             |
| `persona`               | `String?`              | Nein         | Freitext mit Verhaltensanweisungen                                                                                                                                                                    |
| `systemPrompt`          | `String?`              | Nein         | Überschreibt den Standard-System-Prompt                                                                                                                                                               |
| `adapterId`             | `String?`              | Nein         | ID des Inferenzadapters                                                                                                                                                                               |
| `modelId`               | `String?`              | Nein         | Modell-ID innerhalb des Adapters                                                                                                                                                                      |
| `strictMode`            | `bool`                 | Nein         | Standard `false`. Wird in die Zeile und in die `AGENTS.md` des Agenten geschrieben                                                                                                                    |
| `effort`                | `String?`              | Nein         | ID der Denkstufe (z. B. `'low'`, `'xhigh'`), aus den `thinkingLevels` des gewählten Modells                                                                                                           |
| `contextSize`           | `int?`                 | Nein         | Maximale Größe des Kontextfensters                                                                                                                                                                    |
| `role`                  | `AgentRole?`           | Nein         | Agentenrolle                                                                                                                                                                                          |
| `capabilities`          | `AgentCapabilities?`   | Nein         | Standard der Befugnisse je Agent; ist der Wert null, gilt beim Dispatch der Standard auf Benutzerebene, und eine Unterhaltung kann ihn weiterhin überschreiben                                       |
| `monthlyBudgetCents`    | `int`                  | Nein         | Monatliche Ausgabenobergrenze in Cent (Standard `0`, unbegrenzt)                                                                                                                                      |
| `silenceTimeoutMinutes` | `int?`                 | Nein         | Überschreibung des Stille-Timeouts in Minuten; null oder ein Wert von 1–240 (per Assertion im Konstruktor)                                                                                            |
| `maxConcurrentTasks`    | `int`                  | Nein         | Standard `1`. Kapazitätszahl, die das Präsenzmodell meldet (laufende und wartende Anzahlen werden damit verglichen)                                                                            |
| `visibility`            | `AgentVisibility`      | Nein         | Standard `workspace`                                                                                                                                                                                  |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Nein         | Governance-Status (Standard `active`). Geschrieben vom harten Budgetstopp, angezeigt im Organigramm und in der Präsenzliste. Die Ausführung nimmt von einem Agenten mit `paused` weiter Arbeit an    |
| `budgetPolicyId`        | `String?`              | Nein         | ID einer gemeinsamen Budgetrichtlinie; ist der Wert null, gilt `monthlyBudgetCents` direkt                                                                                                            |
| `runtimeProfileId`      | `String?`              | Nein         | ID eines eigenen Laufzeitprofils                                                                                                                                                                      |
| `createdAt`             | `DateTime`             | Ja           | Zeitpunkt der Erstellung                                                                                                                                                                              |

`name` und `title` dürfen nicht leer sein (per Assertion im Konstruktor). Ein
`monthlyBudgetCents` von `0` heißt unbegrenzt. Eine Obergrenze schreibst du mit
`agents.upsert`.

## Enum AgentVisibility

| Wert        | Beschreibung                                                        |
| ----------- | ------------------------------------------------------------------- |
| `workspace` | Der Standard; unbekannte und als null gespeicherte Werte werden darauf geparst |
| `private`   | Privat für die Person, die den Agenten angelegt hat                |

## Enum AgentLifecycleStatus

| Wert       | Beschreibung                                                                                |
| ---------- | ------------------------------------------------------------------------------------------- |
| `active`   | Der Standard. `isDispatchable` ist nur für diesen Wert wahr                                |
| `paused`   | Gesetzt vom harten Budgetstopp. Sichtbar in der Präsenzliste; die Ausführung nimmt weiter Arbeit an |
| `archived` | Stillgelegt und aus den aktiven Listen ausgeblendet                                        |

## Flags von AgentCapabilities

Je Dispatch aufgelöst: der Standard des Agenten, bei null der Standard auf Benutzerebene, und darüber eine Überschreibung je Unterhaltung. Durchgesetzt durch Abwesenheit: Der Zugangsdaten-Broker stellt schlicht nichts aus und injiziert nichts, was eine abgeschaltete Befugnis abdeckt.

| Flag               | Typ    | Standard | Beschreibung                                                                                                |
| ------------------ | ------ | -------- | ----------------------------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false`  | Pusht Commits auf das Remote; gibt zusammen mit `canCallGitHubApi` die Injektion des GitHub-Tokens frei    |
| `canCallGitHubApi` | `bool` | `false`  | Ruft api.github.com auf; gibt die Injektion von `GH_TOKEN` und die GitHub-Domains für ausgehenden Verkehr frei |
| `canCallTicketing` | `bool` | `false`  | Ruft die API des Ticketing-Anbieters auf; gibt die Injektion des API-Schlüssels und dessen Domains für ausgehenden Verkehr frei |
| `canAccessNetwork` | `bool` | `true`   | Beliebiger ausgehender Verkehr. Gibt außerdem die Werkzeuge `web_fetch` und `web_search` des Harness frei   |

`AgentCapabilities.safeDefault` sind die vier Konstruktorstandards. `legacyDefault` (alle vier true) nutzt nur die Migration, die Unterhaltungen nachgetragen hat, die angelegt wurden, bevor es Befugnisse gab. Ein fehlerhafter oder leerer gespeicherter Blob wird auf `safeDefault` geparst; der alte Schlüssel `canCallLinear` wird als `canCallTicketing` gelesen.

## AgentSkills

Eine unveränderliche Menge von Skill-Kennungen, ohne Unterscheidung der Groß- und Kleinschreibung. Beim Dispatch werden diese Slugs als Skill-Links im Overlay des Agenten synchronisiert; der Harness lädt danach das Frontmatter der verlinkten Skills automatisch in den Prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (abgeleitet)

Nicht gespeichert. Sieben Werte. Die Deklarationsreihenfolge ist die Prioritätsreihenfolge (`sortPriority`, von einem Test festgeschrieben) und damit die Reihenfolge, nach der die Liste sortiert:

| Zustand     | `sortPriority` | Bedingung                                                                                                            |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Mindestens ein Laufprotokoll hat den Status `running`                                                                |
| `blocked`   | 1              | Die Liveness des jüngsten Laufs ist `blocked`, `stalled` oder `looping`                                              |
| `failed`    | 2              | Der Status des jüngsten Laufs ist `error`, oder seine Liveness ist `failed` oder `dead`                              |
| `queued`    | 3              | Ein Lauf ist dispatched, wird aber nicht ausgeführt: Er wartet hinter einem anderen Lauf desselben Agenten, oder er ist geschrieben, aber noch nicht gestartet |
| `succeeded` | 4              | Der Lauf wurde erfolgreich abgeschlossen                                                                             |
| `idle`      | 5              | Der Agent ist schon gelaufen und hat nichts unterwegs                                                                |
| `neverRun`  | 6              | Es gibt keine Laufprotokolle                                                                                         |

`queued` und `succeeded` gelten **nur je Lauf**. `deriveAgentLiveState`, das den Listenzustand eines Agenten berechnet, liefert keines von beiden: Zurück kommen `neverRun`, `running`, `failed`, `blocked` oder `idle`.
