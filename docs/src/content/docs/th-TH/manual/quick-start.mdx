นี่คือเส้นทางที่สั้นที่สุดและครบถ้วนที่สุดจากศูนย์ไปจนถึงเอเจนต์ที่รันกับโค้ดของคุณเอง ทำตามลำดับ ทุกขั้นตอนต้องอาศัยขั้นตอนก่อนหน้า

คุณต้องมี Git บัญชี GitHub และไม่ว่าจะเป็นบัญชีผู้ให้บริการโมเดล (Anthropic, OpenAI, Codex, Cursor, Kimi Code หรือผู้ให้บริการใดก็ตามที่มีคีย์ API) หรือ Claude Code CLI ที่ติดตั้งไว้แล้ว ส่วนที่เหลือจะถูกตั้งค่าไปตามทาง

## ขั้นตอนที่ 1: ติดตั้งและเปิดใช้งาน

ติดตั้ง Control Center ตามที่อธิบายไว้ใน[ติดตั้ง](/th-TH/คู่มือ/ติดตั้ง/) แล้วเปิดมันขึ้นมา

ในการเปิดครั้งแรก เดสก์ท็อปจะถามว่า **“Control Center ควรรันอย่างไร?”** ให้เลือก **รันในแอปนี้** Control Center จะสปอว์น `cc_server` แบบไม่มีส่วนติดต่อบนเครื่องนี้ ซึ่งเป็นเจ้าของข้อมูลของคุณและทำงานทั้งหมด คุณจะไม่เห็นมัน แต่หน้าจอการเริ่มต้นใช้งานจะเปิดขึ้นแทน

:::note[ไม่อยากติดตั้งอะไรเลยใช่ไหม?]
แอปเดียวกันรันในเบราว์เซอร์ได้ที่ [app.usectrl.dev](https://app.usectrl.dev) ด้วย
คุณสมบัติเดียวกัน อย่างไรก็ตาม แท็บเบราว์เซอร์ไม่สามารถโฮสต์เซิร์ฟเวอร์ได้ คุณจึงต้อง
เตรียมเซิร์ฟเวอร์เอง — รัน `cc_server` ในเครื่องแล้วเชื่อมต่อกับ `ws://localhost:9030`
หรือชี้ไปที่เซิร์ฟเวอร์บนเครื่องอื่น เริ่มอย่างรวดเร็วนี้ใช้เส้นทางเดสก์ท็อปเพราะไม่ต้อง
ตั้งค่าเซิร์ฟเวอร์ ดู[ติดตั้ง](/th-TH/คู่มือ/ติดตั้ง/#use-it-in-your-browser)สำหรับเส้นทางผ่านเบราว์เซอร์
:::

## ขั้นตอนที่ 2: ทำขั้นตอนการเริ่มต้นใช้งานให้ครบ

การเริ่มต้นใช้งานมีห้าขั้นตอนและรันตามลำดับ — ข้ามไปข้างหน้าไม่ได้

1. **เชื่อมต่อ**: ลงชื่อเข้าใช้ด้วย GitHub หรือวางโทเค็นการเข้าถึงส่วนบุคคลที่มี `repo` และ `read:org` ข้อมูลรับรองจะถูกเก็บไว้บนเซิร์ฟเวอร์ ผูกกับบัญชีของคุณ
2. **เวิร์กสเปซ**: ตั้งชื่อเวิร์กสเปซแรกของคุณและเลือกโลโก้ได้ตามต้องการ การสร้างมันจะซีดเอเจนต์ห้าตัว — CEO หนึ่งตัว บวก `qa`, `architect`, `engineer` และ `librarian` — พร้อมเทมเพลตไปป์ไลน์ที่มีมาให้ในตัว
3. **แซนด์บ็อกซ์**: บันทึกค่ากำหนดเรื่องการทำแซนด์บ็อกซ์ ไม่ว่าจะเลือกแบบใดก็ไปต่อได้
4. **อะแดปเตอร์**: เลือกอะแดปเตอร์และโมเดลที่เอเจนต์ควรใช้เป็นค่าเริ่มต้น เลือก **Control Center (built-in)** จากนั้นใช้ตัวเลือกผู้ให้บริการที่ปรากฏขึ้นเพื่อลงชื่อเข้าใช้ผู้ให้บริการโมเดล — รายการโมเดลจะว่างอยู่จนกว่าจะเชื่อมต่อผู้ให้บริการสักราย การทำขั้นตอนนี้ให้เสร็จจะประทับอะแดปเตอร์และโมเดลลงบนเอเจนต์ CEO ของเวิร์กสเปซด้วย
5. **เสียง (ไม่บังคับ)**: ติดตั้งโมเดลเสียงพูดบนอุปกรณ์สำหรับการป้อนข้อความด้วยเสียง หรือข้ามขั้นตอนนี้

จากนั้น Control Center จะเปิดกล่องขาเข้าของเวิร์กสเปซคุณ

:::note[อะไรเป็นตัวจำกัดการรันของเอเจนต์]
คำสั่งของเอเจนต์ถูกห่อหุ้มด้วยแซนด์บ็อกซ์เนทีฟของระบบปฏิบัติการโฮสต์เมื่อมีให้ใช้ — Seatbelt บน macOS, bubblewrap บน Linux Windows ไม่มีแบ็กเอนด์ การรันที่นั่นจึงถูกจำกัดด้วยชั้นอื่น ๆ เท่านั้น: worktree ของการสนทนาเอง (`git worktree` บน Windows; copy-on-write เมื่อ `rift` มีให้ใช้) ข้อมูลรับรองที่ผ่านนายหน้าต่อการเปิดใช้แต่ละครั้งและถูกเพิกถอนตอนรื้อถอน และกฎคุมการกระทำ ดู[แซนด์บ็อกซ์และความปลอดภัย](/th-TH/คู่มือ/แนวคิด/แซนด์บ็อกซ์และความปลอดภัย/)
:::

## ขั้นตอนที่ 3: เพิ่มรีโพสิทอรี

ไปที่ **การตั้งค่า → เวิร์กสเปซ → รีโพสิทอรี** แล้วคลิก **เพิ่มรีโพสิทอรี**

ไดอะล็อกจะเรียกดูโฟลเดอร์บนเครื่องที่รันเซิร์ฟเวอร์ ไม่ใช่เครื่องไคลเอนต์ของคุณ และมันจะอยู่ภายในราก (root) ที่เซิร์ฟเวอร์ถูกกำหนดค่าให้เปิดเผยเท่านั้น (โดยค่าเริ่มต้นคือโฮมไดเรกทอรีของผู้ใช้ของเซิร์ฟเวอร์) มีเฉพาะเช็กเอาต์ git เท่านั้นที่ได้ช่องทำเครื่องหมาย ติ๊กของคุณแล้วลงทะเบียนมัน

เช็กเอาต์จะถูกยอมรับก็ต่อเมื่อมันอยู่ภายใน git work tree มี remote `origin` และ remote นั้นชี้ไปที่โฮสต์โค้ดที่รองรับ — github.com, gitlab.com หรือ bitbucket.org สิ่งอื่นจะถูกปฏิเสธพร้อมระบุเหตุผล

รีโพถูกจำกัดขอบเขตตามเวิร์กสเปซ: การลงทะเบียนเช็กเอาต์ที่นี่จะใส่ไว้ในเวิร์กสเปซ_นี้_ ไม่มีขั้นตอนการเชื่อมโยงแยกต่างหาก

## ขั้นตอนที่ 4: กำหนดอะแดปเตอร์และโมเดลให้เอเจนต์

ไปที่ **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** เลือกเอเจนต์ `engineer` ในรายการเอเจนต์

ในแท็บ **การตั้งค่า** กำหนด:

- **อะแดปเตอร์**: `Control Center (built-in)`
- **โมเดล**: เลือกหนึ่งตัวจากผู้ให้บริการที่คุณเชื่อมต่อไว้ในการเริ่มต้นใช้งาน

กด **บันทึกการเปลี่ยนแปลง**

ในทางปฏิบัติ ขั้นตอนนี้ไม่ใช่ตัวเลือกเสริม เฉพาะเอเจนต์ CEO เท่านั้นที่สืบทอดอะแดปเตอร์ที่เลือกไว้ระหว่างการเริ่มต้นใช้งาน ผู้เชี่ยวชาญอีกสี่ตัวถูกสร้างขึ้นโดยไม่มีอะแดปเตอร์ พวกมันจะถอยกลับไปใช้ **Control Center (built-in)** พร้อมโมเดลเริ่มต้นของ Anthropic จึงรันได้เฉพาะเมื่อคุณเชื่อมต่อบัญชี Anthropic ไว้แล้ว — และจะรันบนโมเดลที่คุณไม่ได้เลือกหากคุณเชื่อมต่อไว้

## ขั้นตอนที่ 5: ส่งงานให้เอเจนต์

1. ในแถบด้านข้าง หาส่วน **สเปซ** แล้วคลิกปุ่ม **+**
2. ตั้งชื่อสเปซ เพิ่มเอเจนต์ `engineer` ใต้ **เพิ่มเอเจนต์** แล้วสร้างมัน
3. พิมพ์งานเล็ก ๆ ที่เป็นรูปธรรมโดยอิงกับรีโพที่คุณลงทะเบียนไว้ แล้วกด Enter

Control Center จัดเตรียม worktree แบบ copy-on-write ของรีโพในเวิร์กสเปซสำหรับการสนทนานี้ ประกอบพรอมต์จากบทบาท เพอร์โซนา สกิลของเอเจนต์และบริบทของสเปซ แล้วส่งงานรัน เช็กเอาต์ต้นทางของคุณจะไม่ถูกแตะต้อง

## ขั้นตอนที่ 6: ดูมันทำงาน

คุณควรเห็นตามลำดับ:

- ปุ่มส่งของคอมโพเซอร์เปลี่ยนเป็นปุ่มหยุด เพราะมีเอเจนต์กำลังทำงานอยู่ในการสนทนานี้
- การให้เหตุผล การเรียกเครื่องมือ และข้อความของเอเจนต์ที่สตรีมเข้าสู่ทรานสคริปต์
- ปุ่มส่งกลับมาอีกครั้งเมื่อการรันจบลง

จากนั้นเปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** เลือกเอเจนต์ แล้วดูแท็บ **บันทึก**: จะมีแถวการรันหนึ่งแถว พร้อมสถานะ ระยะเวลา เวลาเริ่มและเวลาสิ้นสุด และอะแดปเตอร์ที่ใช้รัน

นั่นคือวงจรหลัก ทุกสิ่งอื่นใน Control Center — การรีวิว pull request, ไปป์ไลน์, ตั๋วงาน, การประชุม, Slack — ล้วนต่อยอดจากมัน
