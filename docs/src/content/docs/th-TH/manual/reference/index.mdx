หน้าอ้างอิงอธิบาย **สิ่งที่มีอยู่** อย่างครบถ้วนโดยไม่มีความเห็นประกอบ ใช้หน้านี้เพื่อค้นหาสิ่งต่าง ๆ เมื่อคุณรู้อยู่แล้วว่าตนต้องการอะไร เช่น ชื่อเครื่องมือที่แน่นอน ชนิดของขั้นตอน การเปลี่ยนสถานะ เส้นทาง หรือทางลัด

หน้าเหล่านี้ไม่ได้เขียนขึ้นเพื่ออ่านตั้งแต่ต้นจนจบ หากต้องการอ่านแบบนั้นให้ใช้
[แนวคิด](/th-TH/คู่มือ/แนวคิด/) และหากต้องการลงมือทำงานให้ใช้
[คู่มือวิธีทำ](/th-TH/คู่มือ/วิธีทำ/)

## พื้นผิวของผลิตภัณฑ์

- [เครื่องมือ MCP](/th-TH/คู่มือ/อ้างอิง/เครื่องมือ-mcp/) — เครื่องมือทุกตัวที่เซิร์ฟเวอร์ MCP ลงทะเบียน จำแนกตามตระกูล
- [เครื่องมือเอเจนต์ในตัว](/th-TH/คู่มือ/อ้างอิง/เครื่องมือเอเจนต์/) — เครื่องมือฮาร์เนสที่ผูกกับเซิร์ฟเวอร์ (LSP, AST, debug, eval, vibe)
- [คำสั่งสแลช](/th-TH/คู่มือ/อ้างอิง/คำสั่งสแลช/) — บิลต์อินของคอมโพเซอร์, `/skill:` และคำสั่งของผู้ใช้
- [แผนที่เส้นทาง](/th-TH/คู่มือ/อ้างอิง/แผนที่เส้นทาง/) — ทุกหน้าจอและ URL ที่นำไปถึงหน้าจอนั้น
- [ทางลัดแป้นพิมพ์](/th-TH/คู่มือ/อ้างอิง/ทางลัดแป้นพิมพ์/) — ทะเบียนการผูกปุ่มทั้งหมด
- [เหตุการณ์โดเมน](/th-TH/คู่มือ/อ้างอิง/เหตุการณ์โดเมน/) — ทุกเหตุการณ์ที่เผยแพร่บนบัสโดเมน
- [ริก](/th-TH/คู่มือ/อ้างอิง/ริก/) — พื้นผิวของริก กริยาการกระทำ สถานะวงจรชีวิต พอร์ต และค่าเริ่มต้นทั้งหมด

## การตั้งค่า

- [การตั้งค่าเอเจนต์](/th-TH/คู่มือ/อ้างอิง/การตั้งค่าเอเจนต์/) — ทุกฟิลด์บนเอเจนต์และสิ่งที่อ่านฟิลด์นั้น
- [ชนิดขั้นตอนไปป์ไลน์](/th-TH/คู่มือ/อ้างอิง/ขั้นตอนไปป์ไลน์/) — ชนิดของขั้นตอน คีย์ในบอดี การตั้งค่า และผลลัพธ์
- [`cc_server` CLI](/th-TH/คู่มือ/อ้างอิง/cc-server-cli/) — ทุกแฟล็ก ตัวแปรสภาพแวดล้อม ซับคอมมานด์ และพาธของไดเรกทอรีข้อมูล
- [สำรอง นำออก และนำเข้า](/th-TH/คู่มือ/อ้างอิง/สำรองข้อมูล/) — โครงสร้างของสแนปช็อต การดำเนินการสำรองข้อมูลทุกแบบ และเส้นทางการโอนย้าย
- [แบ็กเอนด์แซนด์บ็อกซ์](/th-TH/คู่มือ/อ้างอิง/แบ็กเอนด์แซนด์บ็อกซ์/) — แบ็กเอนด์ที่ใช้รันโค้ดและความพร้อมใช้งานของแต่ละตัว
- [การตั้งค่า SSO](/th-TH/คู่มือ/อ้างอิง/sso/) — เอนด์พอยต์ การดำเนินการ และรหัสข้อผิดพลาด
- [สะพานแชท](/th-TH/คู่มือ/อ้างอิง/สะพานแชท/) — ผู้ให้บริการ คำสั่ง ข้อมูลรับรอง และการดำเนินการ

## โมเดล

- [วงจรชีวิตตั๋วงาน](/th-TH/คู่มือ/อ้างอิง/วงจรชีวิตตั๋วงาน/) — สถานะ การเปลี่ยนสถานะ และเอนจินเวิร์กโฟลว์
- [อภิธานศัพท์](/th-TH/คู่มือ/อ้างอิง/อภิธานศัพท์/) — คำศัพท์เฉพาะโดเมนที่ใช้ทั่วทั้งคู่มือ
