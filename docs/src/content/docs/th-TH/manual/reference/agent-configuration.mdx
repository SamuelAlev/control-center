เอกสารอ้างอิงนี้แสดงรายการทุกฟิลด์บนเอนทิตีเอเจนต์ พร้อมทั้งอีนัมและแฟล็กที่มันใช้ สำหรับคำแนะนำแบบทีละขั้นตอนในการสร้างหรือแก้ไขเอเจนต์ในแอป ดู [สร้างและกำหนดค่าเอเจนต์](/th-TH/คู่มือ/วิธีทำ/สร้างเอเจนต์/)

## ฟิลด์ของเอนทิตีเอเจนต์

| ฟิลด์ | ชนิด | จำเป็น | คำอธิบาย |
| ----- | ---- | ------ | -------- |
| `id` | `String` | ใช่ | ตัวระบุเอเจนต์ที่ไม่ซ้ำกัน |
| `name` | `String` | ใช่ | ตัวระบุสั้นสำหรับ @-mention |
| `title` | `String` | ใช่ | ตำแหน่งงานที่มนุษย์อ่านได้ |
| `agentMdPath` | `String` | ใช่ | พาธแบบสัมบูรณ์ไปยังไฟล์นิยาม `.md` ของเอเจนต์ |
| `workspaceId` | `String` | ใช่ | เวิร์กสเปซเจ้าของ (ไม่เป็นค่าว่าง) |
| `reportsTo` | `String?` | ไม่ใช่ | รหัสเอเจนต์แม่ |
| `skills` | `AgentSkills` | ใช่ | ชุดตัวระบุสกิล |
| `persona` | `String?` | ไม่ใช่ | คำแนะนำด้านพฤติกรรมแบบข้อความอิสระ |
| `systemPrompt` | `String?` | ไม่ใช่ | แทนที่พรอมต์ระบบเริ่มต้น |
| `adapterId` | `String?` | ไม่ใช่ | รหัสอะแดปเตอร์การอนุมาน |
| `modelId` | `String?` | ไม่ใช่ | รหัสโมเดลภายในอะแดปเตอร์ |
| `strictMode` | `bool` | ไม่ใช่ | ค่าเริ่มต้น `false` เขียนลงแถวข้อมูลและลง `AGENTS.md` ของเอเจนต์ |
| `effort` | `String?` | ไม่ใช่ | รหัสระดับการใช้เหตุผล (เช่น `'low'`, `'xhigh'`) ซึ่งดึงมาจาก `thinkingLevels` ของโมเดลที่เลือก |
| `contextSize` | `int?` | ไม่ใช่ | ขนาดหน้าต่างบริบทสูงสุด |
| `role` | `AgentRole?` | ไม่ใช่ | บทบาทของเอเจนต์ |
| `monthlyBudgetCents` | `int` | ไม่ใช่ | เพดานการใช้จ่ายรายเดือนเป็นเซนต์ (ค่าเริ่มต้น `0` ไม่จำกัด) |
| `silenceTimeoutMinutes` | `int?` | ไม่ใช่ | การแทนที่การหมดเวลาเงียบเป็นนาที ต้องเป็น null หรืออยู่ในช่วง 1–240 (ตรวจสอบโดยคอนสตรักเตอร์) |
| `maxConcurrentTasks` | `int` | ไม่ใช่ | ค่าเริ่มต้น `1` ตัวเลขความจุที่โมเดลสถานะออนไลน์รายงาน (จำนวนที่กำลังรันและที่อยู่ในคิวจะถูกนำมาเทียบกับค่านี้) |
| `visibility` | `AgentVisibility` | ไม่ใช่ | ค่าเริ่มต้น `workspace` |
| `lifecycleStatus` | `AgentLifecycleStatus` | ไม่ใช่ | สถานะการกำกับดูแล (ค่าเริ่มต้น `active`) ถูกเขียนโดยการหยุดแข็งของงบประมาณ และแสดงบนผังองค์กรและรายชื่อสถานะออนไลน์ การสั่งงานยังคงรับงานจากเอเจนต์ที่ `paused` |
| `budgetPolicyId` | `String?` | ไม่ใช่ | รหัสนโยบายงบประมาณที่ใช้ร่วมกัน เมื่อเป็น null `monthlyBudgetCents` จะมีผลโดยตรง |
| `runtimeProfileId` | `String?` | ไม่ใช่ | รหัสโปรไฟล์รันไทม์ที่กำหนดเอง |
| `createdAt` | `DateTime` | ใช่ | เวลาที่สร้าง |

`name` และ `title` ต้องไม่ว่างทั้งคู่ (ตรวจสอบโดยคอนสตรักเตอร์) `monthlyBudgetCents`
ค่าเริ่มต้นที่เป็น `0` หมายถึงไม่จำกัด การกำหนดเพดานทำได้ด้วย `agents.upsert`

## อีนัม AgentRole

| บทบาท | ป้าย | คำอธิบาย |
| ----- | ---- | -------- |
| `ceo` | CEO | การประสานงานและการมอบหมาย |
| `coder` | Coder | การลงมือเขียนโค้ด |
| `reviewer` | Reviewer | การรีวิวและวิเคราะห์ PR |
| `qa` | QA | การทดสอบและประกันคุณภาพ |
| `designer` | Designer | การลงมือทำ UI/UX |
| `security` | Security | การรีวิวและตรวจสอบด้านความปลอดภัย |
| `devops` | DevOps | โครงสร้างพื้นฐานและการปรับใช้ |
| `pm` | PM | การจัดการผลิตภัณฑ์ |
| `general` | General | ยืดหยุ่น ใช้ได้หลากหลาย |

## อีนัม AgentVisibility

| ค่า | คำอธิบาย |
| --- | -------- |
| `workspace` | ค่าเริ่มต้น ค่าที่จัดเก็บแบบไม่รู้จักและค่า null จะถูกแปลงมาเป็นค่านี้ |
| `private` | เป็นส่วนตัวสำหรับผู้ใช้ที่สร้าง |

## อีนัม AgentLifecycleStatus

| ค่า | คำอธิบาย |
| --- | -------- |
| `active` | ค่าเริ่มต้น `isDispatchable` เป็นจริงเฉพาะค่านี้ |
| `paused` | ถูกตั้งโดยการหยุดแข็งของงบประมาณ แสดงบนรายชื่อสถานะออนไลน์ การสั่งงานยังคงรับงาน |
| `archived` | ปลดระวางและซ่อนจากรายชื่อที่ใช้งานอยู่ |

## สิทธิ์

เอเจนต์ไม่ได้พกแฟล็กสิทธิ์ใด ๆ การพุช การเปิดและเผยแพร่ pull request การเขียนไปยังตัวติดตาม และการส่งออกเครือข่าย เป็นคลาสการกระทำ (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) ที่[กฎคุม](/th-TH/คู่มือ/แนวคิด/กฎคุม/)ตัดสินในขอบเขตเวิร์กสเปซ เอเจนต์ หรือสเปซ โทเคน GitHub ของการรันมีขอบเขตแบบอ่านอย่างเดียวเสมอ การพุชผ่านเกตเวย์การรันเอเจนต์ ซึ่งถามกฎ `gitPush` ก่อนส่งต่อ

## AgentSkills

ชุดตัวระบุสกิลที่ไม่เปลี่ยนรูปและไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่ ตอนสั่งงาน slug เหล่านั้นจะถูกซิงค์เป็นลิงก์สกิลในโอเวอร์เลย์ของเอเจนต์ จากนั้นฮาร์เนสจะโหลดฟรอนต์แมตเทอร์ของสกิลที่ลิงก์ไว้เข้าสู่พรอมต์โดยอัตโนมัติ

```

```

## AgentLiveState (อนุมานได้)

ไม่ถูกจัดเก็บ มีเจ็ดค่า ลำดับการประกาศคือลำดับความสำคัญ (`sortPriority` ซึ่งถูกตรึงไว้ด้วยเทสต์) และเป็นลำดับที่รายชื่อใช้เรียง:

| สถานะ | `sortPriority` | เงื่อนไข |
| ----- | -------------- | -------- |
| `running` | 0 | บันทึกการรันใด ๆ มีสถานะ `running` |
| `blocked` | 1 | สถานะความมีชีวิตของการรันล่าสุดคือ `blocked`, `stalled` หรือ `looping` |
| `failed` | 2 | สถานะของการรันล่าสุดคือ `error` หรือสถานะความมีชีวิตของมันคือ `failed` หรือ `dead` |
| `queued` | 3 | การรันถูกสั่งงานแล้วแต่ยังไม่ทำงาน — จอดรออยู่หลังการรันอีกรายการของเอเจนต์ตัวเดียวกัน หรือถูกเขียนแล้วแต่ยังไม่เริ่ม |
| `succeeded` | 4 | การรันเสร็จสิ้นอย่างสำเร็จ |
| `idle` | 5 | เอเจนต์เคยรันมาก่อนและไม่มีอะไรกำลังดำเนินอยู่ |
| `neverRun` | 6 | ไม่มีบันทึกการรันอยู่เลย |

`queued` และ `succeeded` ใช้ **เฉพาะต่อการรันแต่ละรายการเท่านั้น** `deriveAgentLiveState` ซึ่งคำนวณสถานะรายชื่อของเอเจนต์ ไม่เคยสร้างค่าใดในสองค่านี้เลย — มันคืนค่า `neverRun`, `running`, `failed`, `blocked` หรือ `idle`
