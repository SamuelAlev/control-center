ทางลัดทั้งหมดมาจากทะเบียน `const` ตัวเดียว ชื่อ `KeybindingRegistry` ใน `lib/core/constants/keybindings.dart` โดยมี **49 รายการผูก** หน้า การตั้งค่า → คุณ → ทางลัดคีย์บอร์ด แสดงทะเบียนนี้เป็น **เอกสารอ้างอิงแบบอ่านอย่างเดียว**: ไม่มี UI สำหรับกำหนดปุ่มใหม่ และไม่มีไฟล์ทางลัดของผู้ใช้

`Cmd` ข้างล่างคือปุ่มคำสั่งหลัก — ⌘ บน macOS, Ctrl บน Windows และ Linux รายการผูกจะทำงานก็ต่อเมื่อคำสั่งนั้นมีตัวจัดการที่ลงทะเบียนไว้บนหน้าจอปัจจุบัน และเงื่อนไข `when` ของมันเป็นจริง; `!textInputFocus` หมายความว่าปุ่มจะถูกส่งต่อไปยังช่องกรอกข้อความที่โฟกัสอยู่แทน

ไม่มีทางลัดสำหรับนำทางด้วยปุ่มตัวเลข กล่องขาเข้า ตั๋วงาน Pull request และอื่น ๆ เข้าถึงได้จากแถบข้างหรือ ⌘K ส่วนการสังเกตการณ์ก็ไม่มีทางลัดเช่นกัน

## ทั่วไป (19)

ขอบเขต `global` จึงทำงานได้ทุกที่ในเชลล์

### ระบบ

| ทางลัด                                      | การทำงาน                                          | เงื่อนไข                                                     |
| ------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------ |
| `Cmd/Ctrl + K`                              | จานคำสั่ง                                          | —                                                            |
| `Shift + /` (`?`)                           | สรุปทางลัดแป้นพิมพ์                                 | ไม่ได้กำลังพิมพ์ในช่อง                                        |
| `Cmd/Ctrl + Z`                              | เลิกทำ                                             | ไม่ได้กำลังพิมพ์ในช่อง (ช่องที่โฟกัสอยู่มีเลิกทำของตัวเอง)      |
| `Cmd/Ctrl + Shift + Z`                      | ทำซ้ำ                                              | ไม่ได้กำลังพิมพ์ในช่อง                                        |
| `Cmd/Ctrl + Shift + T`                      | สลับธีม                                            | —                                                            |
| `Cmd/Ctrl + ,`                              | เปิดการตั้งค่า (ไปที่ `/settings/you/appearance`)    | —                                                            |
| `Cmd/Ctrl + Shift + Alt + F`                | สลับโหมดโฟกัส                                      | —                                                            |
| `Cmd/Ctrl + Shift + W`                      | สลับตัวสลับเวิร์กสเปซ                               | —                                                            |
| `Cmd/Ctrl + ]`                              | เวิร์กสเปซถัดไป                                     | —                                                            |
| `Cmd/Ctrl + [`                              | เวิร์กสเปซก่อนหน้า                                  | —                                                            |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | สลับไปเวิร์กสเปซ 1–9                                | —                                                            |

## รายการ Pull request (3)

ขอบเขต `/pull-requests` ทั้งหมดต้องมี `route == '/pull-requests'` และไม่มีช่องข้อความที่โฟกัสอยู่ จึงไม่ทำงานขณะที่เส้นทางรายละเอียด PR เปิดทับรายการอยู่

| ทางลัด  | การทำงาน           |
| -------- | ------------------ |
| `R`      | รีเฟรช             |
| `Enter`  | เปิด PR            |
| `F`      | เปิดเมนูตัวกรอง     |

`Enter` (`pr.list-open`) ถูกประกาศไว้ในทะเบียนและปรากฏบนเอกสารอ้างอิงทางลัดคีย์บอร์ด แต่ **หน้าจอรายการไม่ได้ลงทะเบียนตัวจัดการสำหรับมัน** จึงยังไม่ทำงานในตอนนี้ `F` เปิดเมนูตัวกรอง (`pr.list-open-filter`) ไม่ใช่ค้นหา

## รายละเอียด Pull request (2)

ขอบเขต `/pull-requests/` รีเฟรชต้องไม่มีช่องข้อความที่โฟกัสอยู่ การปิดแท็บไม่มีตัวกันการป้อนข้อความ (คีย์ผสมที่ใช้ ⌘ ไม่ใช่ข้อความธรรมดาอยู่แล้ว) และมี regex ของเส้นทางจึงไม่ทำงานบนรายการ

| ทางลัด          | การทำงาน   | เงื่อนไข                            |
| ---------------- | ---------- | ----------------------------------- |
| `R`              | รีเฟรช     | ไม่ได้กำลังพิมพ์ในช่อง               |
| `Cmd/Ctrl + W`   | ปิดแท็บ    | บนตำแหน่ง `/pull-requests/<…>`       |

การสลับแท็บ (`1`/`2`/`3`), การทำเครื่องหมายว่าดูแล้ว/ยุบ (`V`/`C`), รายการไฟล์ (`T`) และค้นหาในดิฟ (`Cmd/Ctrl + F`) เป็นของตัวจัดการของตัวแสดงดิฟเอง — ดู[ปุ่มของตัวแสดงดิฟนอกทะเบียน](#ปุ่มของตัวแสดงดิฟนอกทะเบียน)

## กล่องขาเข้า (1)

| ทางลัด  | การทำงาน           |
| -------- | ------------------ |
| `F`      | เปิดเมนูตัวกรอง     |

ต้องมี `route == '/inbox'` และไม่มีช่องข้อความที่โฟกัสอยู่

## โปรไฟล์ผู้ใช้และทีม GitHub (3)

ขอบเขต `/users/` เงื่อนไข `when` เป็น regex เทียบกับ `/users/<login>` **หรือ** `/teams/<organization>/<slug>` บวกกับไม่มีช่องข้อความที่โฟกัสอยู่

| ทางลัด          | การทำงาน       |
| ---------------- | -------------- |
| `R`              | รีเฟรช         |
| `/`              | โฟกัสการค้นหา  |
| `Cmd/Ctrl + F`   | โฟกัสการค้นหา  |

## สเปซ (9)

ขอบเขต `/spaces` เงื่อนไข `when` ใช้ regex จึงทำงานทั้งบนรายการสเปซ (`/spaces`) และสเปซที่เลือกไว้ (`/spaces/<id>`)

| ทางลัด                  | การทำงาน                 | เงื่อนไข                 |
| ----------------------- | ------------------------ | ------------------------ |
| `Enter`                 | ส่งข้อความ                | —                        |
| `Cmd/Ctrl + N`          | สเปซใหม่                  | บนเส้นทาง `/spaces`       |
| `J`                     | สเปซถัดไป                 | ไม่ได้กำลังพิมพ์ในช่อง    |
| `K`                     | สเปซก่อนหน้า              | ไม่ได้กำลังพิมพ์ในช่อง    |
| `Cmd/Ctrl + Shift + D`  | การสั่งด้วยเสียงแบบกดเพื่อพูด | —                        |
| `Cmd/Ctrl + T`          | เปิดแท็บตัวแก้ไข           | บนเส้นทาง `/spaces`       |
| `Cmd/Ctrl + W`          | ปิดแท็บตัวแก้ไข            | บนเส้นทาง `/spaces`       |
| `Cmd/Ctrl + B`          | สลับแถบข้างของตัวแก้ไข     | บนเส้นทาง `/spaces`       |
| `Cmd/Ctrl + P`          | ไปที่ไฟล์                  | บนเส้นทาง `/spaces`       |

ไปที่ไฟล์จะเปิดตัวเลือกไฟล์ของการสนทนา เมื่อยังไม่พิมพ์อะไร จะแสดงไฟล์ที่คุณเปิดล่าสุด เมื่อพิมพ์จะค้นหาทุกไฟล์ใน worktree ของการสนทนา `Enter` เปิดไฟล์ที่เลือกในแท็บใหม่ `Cmd/Ctrl + Enter` หรือปุ่มแบ่งบนแถวจะเปิดไฟล์ในบานหน้าต่างทางขวา และ `×` บนแถวของไฟล์ล่าสุดจะนำไฟล์นั้นออกจากรายการ

การกด Enter เพื่อส่งเป็นของช่องข้อความของช่องเขียนข้อความ ส่วนกดเพื่อพูดเป็นของปุ่มไมค์ของช่องเขียนข้อความ (ตัวจัดการฮาร์ดแวร์คีย์บอร์ดของมันเอง) ทั้งคู่ถูกระบุไว้ในทะเบียนเพื่อใช้เป็นเอกสารอ้างอิงในการตั้งค่า

## ตัวเลือกเวิร์กสเปซ (2)

ขอบเขต `/workspaces` ทำงานเฉพาะบนตัวเลือกเอง

| ทางลัด          | การทำงาน                  |
| ---------------- | ------------------------- |
| `Cmd/Ctrl + N`   | เวิร์กสเปซใหม่             |
| `Enter`          | เปิดเวิร์กสเปซที่เลือกไว้   |

`Enter` ต้องไม่มีช่องข้อความที่โฟกัสอยู่

## การตั้งค่า (5)

| ทางลัด          | การทำงาน                 | หน้าจอ                                 |
| ---------------- | ------------------------ | --------------------------------------- |
| `J`              | หน้าตั้งค่าถัดไป           | เส้นทาง `/settings` ใด ๆ ที่ไม่ได้กำลังพิมพ์ |
| `K`              | หน้าตั้งค่าก่อนหน้า        | เส้นทาง `/settings` ใด ๆ ที่ไม่ได้กำลังพิมพ์ |
| `Cmd/Ctrl + N`   | เอเจนต์ใหม่               | การตั้งค่า → เวิร์กสเปซ → เอเจนต์        |
| `Cmd/Ctrl + N`   | เพิ่มรีโพสิทอรี            | การตั้งค่า → เวิร์กสเปซ → รีโพสิทอรี      |
| `R`              | สแกนอะแดปเตอร์อีกครั้ง     | การตั้งค่า → เซิร์ฟเวอร์ → ผู้ให้บริการโมเดล |

## ฟีดข่าว (5)

ขอบเขต `/newsfeed` ทั้งหมดต้องมี `route == '/newsfeed'` และไม่มีช่องข้อความที่โฟกัสอยู่

| ทางลัด  | การทำงาน           |
| -------- | ------------------ |
| `J`      | บทความถัดไป        |
| `K`      | บทความก่อนหน้า     |
| `Enter`  | เปิดบทความ         |
| `S`      | สลับบุ๊กมาร์ก      |
| `R`      | รีเฟรชฟีด          |

## ปุ่มของตัวแสดงดิฟนอกทะเบียน

ตัวแสดงดิฟของ PR จัดการปุ่มเหล่านี้เอง (`PrDiffKeyboardHandler`) ค้นหา/ดูแล้ว/ยุบ ถูกระบุไว้ในคอมเมนต์ของทะเบียนเพื่อใช้เป็นเอกสารอ้างอิงในการตั้งค่าเท่านั้น — ไม่มีตัวจัดการของตัวกระจายที่ลงทะเบียนไว้ ตัวกระจายจึงปล่อยปุ่มเหล่านี้ให้มุมมองดิฟจัดการเอง ปุ่มเหล่านี้จึงไม่ปรากฏเป็นแถวของตัวเองบนเอกสารอ้างอิงทางลัดคีย์บอร์ด

| ทางลัด          | การทำงาน                                             |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | ค้นหาในดิฟ                                           |
| `J` / `K`       | ไฟล์ถัดไป / ก่อนหน้า                                  |
| `V`             | สลับสถานะดูแล้วบนไฟล์ที่โฟกัส                          |
| `C`             | สลับการยุบบนไฟล์ที่โฟกัส                               |
| `T`             | แสดงรายการไฟล์                                        |
| `Enter`         | ผลการค้นหาถัดไป (เฉพาะขณะที่ค้นหาในดิฟเปิดอยู่)         |
| `Shift + Enter` | ผลการค้นหาก่อนหน้า                                    |
| `Escape`        | ปิดค้นหาในดิฟ หรือล้างข้อความที่เลือกในดิฟ              |
| `Cmd/Ctrl + C`  | คัดลอกส่วนที่เลือกในดิฟ                               |

## คีย์ผสมที่เบราว์เซอร์สงวนไว้

ในบิลด์เว็บ เบราว์เซอร์จะกินคีย์ลัดบางตัวไปก่อนที่หน้าจะได้รับ จึงทำให้รายการผูกที่ตรงกันไม่สามารถทำงานได้เลยที่นั่น แต่ทำงานได้ตามปกติบนเดสก์ท็อป คีย์ที่ถูกสงวนเมื่อใช้ร่วมกับปุ่มคำสั่งหลักคือ `T`, `W`, `N` และตัวเลข `1`–`9`

นั่นครอบคลุมการสลับเวิร์กสเปซด้วย `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (สเปซใหม่, เวิร์กสเปซใหม่, เอเจนต์ใหม่, เพิ่มรีโพสิทอรี) และ `Cmd/Ctrl + T` / `Cmd/Ctrl + W` ในสเปซและรายละเอียด PR
