## สิ่งที่คุณจะสร้าง

เมื่อจบบทสอนนี้ คุณจะมี:

- เวิร์กสเปซที่ตั้งชื่อตามโปรเจกต์ของคุณ
- รีโพสิทอรี Git ที่ลงทะเบียนเข้าไปแล้ว
- เอเจนต์ที่ถูก seed ห้าตัว โดยตัวหนึ่งคุณตั้งค่าไว้จนรันได้
- เวิร์กสเปซที่สองที่ว่างเปล่า ซึ่งพิสูจน์ขอบเขตการแยก

การเริ่มต้นใช้งานได้สร้างเวิร์กสเปซให้คุณแล้ว บทสอนนี้สร้างเวิร์กสเปซใหม่ขึ้นมาโดยเจตนา เพื่อให้คุณเห็นทุกส่วนของกระบวนการ

ก่อนเริ่ม เลือกเช็กเอาต์ Git ที่เข้าเงื่อนไขทั้งสามข้อนี้ — ขั้นตอนการลงทะเบียนจะปฏิเสธสิ่งอื่นใด:

- มันอยู่ภายใน git work tree
- มันมี remote `origin`
- remote นั้นชี้ไปที่ github.com, gitlab.com หรือ bitbucket.org

## ขั้นตอนที่ 1: สร้างเวิร์กสเปซ

1. คลิกชิปเวิร์กสเปซบนแถบชื่อเรื่อง
2. เลือก **เพิ่มเวิร์กสเปซ…**
3. ใส่ชื่อที่ระบุโปรเจกต์ เช่น "api-service" หรือ "frontend-v2"
4. เลือกโลโก้ได้ตามต้องการ
5. คลิก **เพิ่มเวิร์กสเปซ**

Control Center สลับไปยังเวิร์กสเปซใหม่และพาคุณไปยังกล่องขาเข้าของมัน (`/workspaces/<id>/inbox`)

เบื้องหลังนั้น เซิร์ฟเวอร์เผยแพร่เหตุการณ์ `WorkspaceCreated` และ seed เวิร์กสเปซด้วย:

- **เอเจนต์ CEO** หนึ่งตัว ซึ่งมีเพอร์โซนาเป็นการประสานงานและการมอบหมาย
- ผู้เชี่ยวชาญสี่ตัว — `qa`, `architect`, `engineer` และ `librarian` — แต่ละตัวมีคำสั่งและสกิลของตัวเอง
- เทมเพลตไปป์ไลน์ในตัวและแถวทริกเกอร์ของมัน

ทุกเวิร์กสเปซที่คุณสร้างจะได้ทั้งหมดนี้ ไม่ใช่แค่เวิร์กสเปซแรก

ยืนยันได้ว่า: เปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** ในรายชื่อมีเอเจนต์ห้าตัว แต่ละตัวมีวงแหวนสถานะกลวง

## ขั้นตอนที่ 2: ลงทะเบียนรีโพสิทอรี

1. ไปที่ **การตั้งค่า → เวิร์กสเปซ → รีโพสิทอรี**
2. คลิก **เพิ่มรีโพสิทอรี**
3. เรียกดูไปยังเช็กเอาต์ของคุณ ไดอะล็อกจะไล่ดูโฟลเดอร์บนเครื่องที่รัน `cc_server` — ไม่ใช่ไคลเอนต์ของคุณ — และอยู่ภายในรากที่เซิร์ฟเวอร์นั้นเปิดเผย (โฮมไดเรกทอรีของผู้ใช้เป็นค่าเริ่มต้น) เช็กเอาต์ git จะได้ไอคอนโฟลเดอร์ที่แตกต่างพร้อมกล่องทำเครื่องหมาย ส่วนโฟลเดอร์ธรรมดาไม่ได้ทั้งสองอย่าง จึงเลือกได้เฉพาะเช็กเอาต์
4. ทำเครื่องหมายเช็กเอาต์หนึ่งรายการขึ้นไปแล้วลงทะเบียนทั้งชุด การเลือกจะคงอยู่ขณะที่คุณเรียกดูต่อไป คุณจึงรวบรวมได้หลายรายการในคราวเดียว และการเลือกที่ผิดหนึ่งรายการไม่เคยทำให้ส่วนที่เหลือหลุดไป

Control Center อ่าน remote `origin` ของแต่ละเช็กเอาต์ หา owner และรีโป แล้วสร้างแถวรีโป **ภายในเวิร์กสเปซนี้** ไม่มีขั้นตอนที่สองในการเชื่อมโยงมัน การลงทะเบียนคือสิ่งที่กำหนดขอบเขตของมัน

การลงทะเบียนเช็กเอาต์เดียวกันในเวิร์กสเปซอื่นในภายหลังจะสร้างแถวรีโปที่สองที่เป็นอิสระและมี id ของตัวเอง เมื่อข้ามเวิร์กสเปซ ตัวตนของเช็กเอาต์คือพาธในระบบไฟล์ของมัน ไม่ใช่ id ของมันเลย

ยืนยันได้ว่า: รีโปปรากฏในรายการพร้อม `owner/repo` และแบรนช์ปัจจุบันของมัน

## ขั้นตอนที่ 3: ทำให้เอเจนต์ตัวหนึ่งรันได้

เอเจนต์ห้าตัวที่เวิร์กสเปซนี้เพิ่ง seed ไปนั้นไม่มีอะแดปเตอร์และไม่มีโมเดล การสั่งงานจะรันพวกมันบน **Control Center (built-in)** และเมื่อไม่ได้ตั้งโมเดล ก็จะขอค่าเริ่มต้นจาก Anthropic — พวกมันจึงทำงานได้เฉพาะเมื่อคุณเชื่อมต่อบัญชี Anthropic ไว้แล้ว และจะรันบนโมเดลที่คุณไม่ได้เลือกหากคุณเชื่อมต่อไว้ การเริ่มต้นใช้งานครั้งแรกจะประทับตัวเลือกของมันลงบนเอเจนต์ทุกตัวในเวิร์กสเปซแรกเพียงครั้งเดียว ส่วนเวิร์กสเปซที่คุณสร้างในภายหลังจะเริ่มต้นโดยที่ทั้งห้าตัวยังไม่ได้ตั้งค่า ตั้งสักตัวเดี๋ยวนี้

1. เปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์**
2. เลือก `engineer` ในรายชื่อ
3. บนแท็บ **การตั้งค่า** ตั้ง **อะแดปเตอร์** เป็น `Control Center (built-in)` และเลือก **โมเดล** จากผู้ให้บริการที่คุณเชื่อมต่อไว้ภายใต้ การตั้งค่า → เซิร์ฟเวอร์ → ผู้ให้บริการโมเดล
4. กด **บันทึกการเปลี่ยนแปลง**

ยืนยันได้ว่า: เปิดเอเจนต์อีกครั้งแล้วทั้งสองฟิลด์ยังคงเก็บตัวเลือกของคุณไว้

เอเจนต์แต่ละตัวมีอะแดปเตอร์และโมเดลของตัวเอง ดังนั้นทำซ้ำกับเอเจนต์ตัวอื่นที่คุณตั้งใจจะใช้ [สร้างและกำหนดค่าเอเจนต์](/th-TH/คู่มือ/วิธีทำ/สร้างเอเจนต์/) ครอบคลุมส่วนที่เหลือของฟอร์ม

## ขั้นตอนที่ 4: ดูขอบเขตการแยก

สร้างเวิร์กสเปซที่สองจากชิปบนแถบชื่อเรื่อง เช่นเดียวกับในขั้นตอนที่ 1 จากนั้นลองดูที่มัน:

- **การตั้งค่า → เวิร์กสเปซ → รีโพสิทอรี** ว่างเปล่า รีโปที่คุณลงทะเบียนเมื่อสักครู่ไม่อยู่ที่นั่น
- **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** มีเอเจนต์ห้าตัว แต่เป็นแถวคนละชุด — อะแดปเตอร์ที่คุณตั้งในขั้นตอนที่ 3 หายไป
- รายการสเปซ ตั๋วงาน และหน่วยความจำว่างเปล่าทั้งหมด

ไม่มีอะไรรั่วไหล เพราะไม่มีอะไรให้รั่วไหลจาก: แถวข้อมูลของแต่ละเวิร์กสเปซอยู่ในไฟล์ฐานข้อมูลของเวิร์กสเปซนั้นเอง การอ่านข้ามเวิร์กสเปซไม่ใช่คิวรีที่ถูกกรอง แต่เป็นคิวรีที่ไม่มีที่ให้รัน การลบเวิร์กสเปซคือการยกเลิกการเชื่อมโยงไฟล์หนึ่งไฟล์

สลับกลับได้ด้วยชิปบนแถบชื่อเรื่อง หรือเปิด **จัดการเวิร์กสเปซ** เพื่อดูพวกมันเคียงข้างกัน

## สรุป

คุณสร้างเวิร์กสเปซ เห็นมัน seed เอเจนต์ CEO หนึ่งตัวและผู้เชี่ยวชาญอีกสี่ตัว ลงทะเบียนรีโปเข้าไป ให้เอเจนต์ตัวหนึ่งมีอะแดปเตอร์และโมเดล และยืนยันว่าเวิร์กสเปซที่สองไม่ได้ใช้ร่วมกับอะไรเลย
