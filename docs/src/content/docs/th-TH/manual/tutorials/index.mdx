บทสอนคือ**บทเรียน** แต่ละบทพาคุณจากต้นจนจบผ่านงานจริงในเส้นทางเดียว โดยไม่มีอะไรต้องตัดสินใจระหว่างทาง ทำตามขั้นตอนอย่างตรงไปตรงมาแล้วมันจะได้ผล

บทสอนมีไว้เพื่อทำความรู้จักผลิตภัณฑ์โดยรวม เมื่อคุณเข้าใจรูปร่างหน้าตาของผลิตภัณฑ์แล้ว [คู่มือวิธีทำ](/th-TH/คู่มือ/วิธีทำ/) จะเป็นเส้นทางที่เร็วกว่าไปสู่งานใดงานหนึ่งโดยเฉพาะ

ทำตามลำดับนี้ แต่ละบทจะถือว่าคุณทำบทก่อนหน้าแล้ว

1. [เวิร์กสเปซแรกของคุณ](/th-TH/คู่มือ/บทสอน/เวิร์กสเปซแรก/) — สร้างเวิร์กสเปซ เพิ่มรีโป และดูโมเดลการแยกโดเมน
2. [สั่งงานเอเจนต์ตัวแรก](/th-TH/คู่มือ/บทสอน/เอเจนต์ตัวแรก/) — ให้อะแดปเตอร์และโมเดลกับเอเจนต์ จากนั้นให้มันลงมือทำงาน
3. [รีวิว Pull request แรกของคุณ](/th-TH/คู่มือ/บทสอน/pr-แรก/) — อ่านดิฟ แสดงความคิดเห็น และรวม
4. [สร้างไปป์ไลน์แรกของคุณ](/th-TH/คู่มือ/บทสอน/ไปป์ไลน์แรก/) — เชื่อมขั้นตอนเป็น DAG แล้วรัน

อีกสองบทเป็นบทเดี่ยว ทำบทใดก็ได้เมื่อคุณมีเวิร์กสเปซที่ใช้งานได้แล้ว

- [เชื่อม Slack เข้ากับเวิร์กสเปซ](/th-TH/คู่มือ/บทสอน/สะพานแชทแรก/) — ขับเคลื่อนเอเจนต์จากเธรด Slack
- [ให้ทีมเข้าสู่ระบบด้วย SSO](/th-TH/คู่มือ/บทสอน/sso/) — เชื่อมต่อผู้ให้บริการระบุตัวตนและทำการเข้าสู่ระบบให้ครบวงจร

:::note[ก่อนเริ่มต้น]
ติดตั้ง Control Center ก่อน — ดู [ติดตั้ง](/th-TH/คู่มือ/ติดตั้ง/) ถ้าคุณต้องการเพียงเส้นทางที่สั้นที่สุดไปสู่เอเจนต์ที่รันได้ ให้ใช้ [เริ่มอย่างรวดเร็ว](/th-TH/คู่มือ/เริ่มอย่างรวดเร็ว/) แทน แล้วค่อยกลับมาที่นี่ในภายหลัง
:::
