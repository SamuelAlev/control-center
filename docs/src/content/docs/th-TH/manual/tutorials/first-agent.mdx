## สิ่งที่คุณจะสร้าง

เมื่อจบบทสอนนี้ คุณจะมี:

- เอเจนต์ที่คุณสร้างและกำหนดค่าเอง
- สเปซที่คุณกับเอเจนต์ตัวนั้นคุยกัน
- การรันที่เสร็จสมบูรณ์หนึ่งครั้ง พร้อมงานที่คอมมิตไว้ใน worktree ที่แยกโดดเดี่ยว และหนึ่งแถวในบันทึกการรันของเอเจนต์

สิ่งที่ต้องมีก่อน: ทำ[เวิร์กสเปซแรกของคุณ](/th-TH/คู่มือ/บทสอน/เวิร์กสเปซแรก/) ให้เสร็จก่อน เพื่อให้เวิร์กสเปซนี้มีรีโปที่ลงทะเบียนไว้และมีผู้ให้บริการโมเดลอย่างน้อยหนึ่งรายเชื่อมต่ออยู่

## ขั้นตอนที่ 1: สร้างเอเจนต์

1. ไปที่ **การตั้งค่า → เวิร์กสเปซ → เอเจนต์**
2. คลิก **เอเจนต์ใหม่** เอเจนต์ที่ชื่อ “เอเจนต์ไม่มีชื่อ” จะถูกสร้างขึ้นทันทีและถูกเลือกไว้ในรายชื่อ — ไม่มีไดอะล็อกการสร้างและไม่มีอะไรต้องยืนยัน คุณกำหนดค่ามันได้ทันทีในหน้านั้น
3. บนแท็บ **การตั้งค่า** กรอก:
   - **ชื่อ**: อะไรสั้น ๆ ที่จำง่าย เช่น `alice` นี่คือสิ่งที่คุณพิมพ์หลัง `@`
   - **ชื่อ**: สิ่งที่มันทำ เช่น “วิศวกรแบ็กเอนด์”
   - **อะแดปเตอร์**: `Control Center (built-in)` เลือกตัวนี้อย่างตั้งใจ — มีเพียงฮาร์เนสในตัวเท่านั้นที่ชี้นำระหว่างการรันได้ หยุดชั่วคราวที่ขอบเขตเทิร์นได้ และไม่ต้องติดตั้ง CLI ใด ๆ บนโฮสต์ของเซิร์ฟเวอร์
   - **โมเดล**: เลือกจากรายการที่ผู้ให้บริการที่เชื่อมต่อไว้ให้บริการ
   - **สกิล**: แนบสกิลใดก็ได้ที่เหมาะสม เช่น `testing` หรือ `architecture`
4. กด **บันทึกการเปลี่ยนแปลง**

:::note[เอเจนต์ที่ไม่มีอะแดปเตอร์จะรันบนลูปในตัว]
เมื่อไม่ได้ตั้งค่าฟิลด์อะแดปเตอร์ การสั่งงานจะถอยกลับไปใช้ **Control Center (built-in)** — ลูปเอเจนต์ที่อยู่ภายในเซิร์ฟเวอร์ จึงไม่มีอะไรต้องติดตั้งบนโฮสต์ มันยังต้องมีโมเดล: หากไม่ได้ตั้งไว้เลย มันจะขอค่าเริ่มต้นจาก Anthropic ซึ่งใช้ได้หากคุณเชื่อมต่อบัญชี Anthropic ไว้ และจะล้มเหลวเป็นอย่างอื่นด้วย `No credential for provider "anthropic"` ตั้งค่าทั้งสองอย่างให้ชัดเจนไว้ดีกว่า ไม่อย่างนั้นคุณจะรันบนโมเดลที่คุณไม่ได้เลือก
:::

**จุดตรวจสอบ** แถวในรายชื่อแสดงชื่อเอเจนต์ของคุณและวงแหวนสถานะกลวง

## ขั้นตอนที่ 2: เริ่มสเปซ

1. ในแถบข้าง หาส่วน **สเปซ** แล้วคลิกปุ่ม **+**
2. ตั้งชื่อให้สเปซ
3. ใต้ **เพิ่มเอเจนต์** เลือกเอเจนต์ที่คุณเพิ่งสร้าง
4. หากเวิร์กสเปซมีรีโปอยู่ ให้เลือกรีโปที่สเปซนี้ควรทำงานด้วย
5. คลิก **สร้าง**

สเปซจะเปิดขึ้น เบื้องหลัง Control Center จัดเตรียม worktree แบบ copy-on-write ของรีโปที่เลือกไว้สำหรับบทสนทนานี้ บนแบรนช์ของมันเอง เช็กเอาต์ต้นทางของคุณจะไม่ถูกแก้ไขเลย

## ขั้นตอนที่ 3: ส่งงาน

พิมพ์งานเล็ก ๆ ที่เป็นรูปธรรมหนึ่งงานกับรีโปที่คุณลงทะเบียนไว้ งานที่มีผลลัพธ์ตรวจสอบได้จะได้ผลดีที่สุด — เพิ่มเทสต์ แก้ lint เปลี่ยนชื่อสัญลักษณ์

กด Enter คุณไม่จำเป็นต้อง `@`-mention ใครเลย: เมื่อมีเอเจนต์ตัวเดียวในสเปซ ข้อความธรรมดาก็ปลุกมันได้ ในสเปซที่มีเอเจนต์หลายตัว `@name` ใช้เลือกตัวหนึ่ง

Control Center ประกอบพรอมต์จากคำสั่งของเอเจนต์ เพอร์โซนา สกิล และบริบทของสเปซ แล้วจึงสั่งงานการรัน

**จุดตรวจสอบ** ปุ่มส่งของช่องเขียนข้อความกลายเป็นปุ่มหยุด — มีเอเจนต์กำลังทำงานอยู่ในบทสนทนานี้ — และข้อความเริ่มเข้ามา

## ขั้นตอนที่ 4: ดูมันทำงาน

บทสนทนาเรนเดอร์การรันขณะที่มันเกิดขึ้น:

- **การให้เหตุผล** แสดงแบบอินไลน์ขณะที่เอเจนต์คิด
- **การเรียกเครื่องมือ**: การอ่านและเขียนไฟล์ การค้นหา คำสั่งเชลล์ แต่ละอย่างพร้อมผลลัพธ์ของมัน
- **ข้อความ**: สรุป คำอธิบาย และคำถามถึงคุณ

หากเอเจนต์ถามอะไร ให้ตอบในบทสนทนา แล้วมันจะทำต่อ

สำหรับเมตริกของการรันหนึ่ง ๆ และตัวควบคุมหยุดชั่วคราว ทำต่อ และหยุดของมัน ให้หาเอเจนต์ที่กำลังรันอยู่ในส่วน **เอเจนต์** ของแผงทั่วไปของสเปซ แล้วเลือก **เปิดกิจกรรม**

ในแผงกิจกรรม แบดจ์สถานะจะอ่านว่า **กำลังรัน** จากนั้นเป็น **สำเร็จ** เมื่อการรันจบลง การรันที่ชะงักหรือวนซ้ำจะอ่านว่า **ถูกบล็อก** ส่วนการรันที่เกิดข้อผิดพลาดจะอ่านว่า **ล้มเหลว** ในทะเบียนเอเจนต์ วงแหวนในรายชื่อจะเป็นวงกลวงก่อนการรันครั้งแรก และเป็นวงทึบเมื่อเอเจนต์ว่างอีกครั้ง

สิ่งที่จำกัดการรัน: worktree แบบ copy-on-write ของมันเอง ข้อมูลรับรองที่จัดหาให้ผ่านโบรกเกอร์ตอนเปิดตัวและถูกเพิกถอนตอนรื้อถอน สภาพแวดล้อมที่ถูกทำให้สะอาด พื้นผิวเครื่องมือที่โหมดของมันอนุญาต และกฎคุมการกระทำ ผลกระทบอย่างการพุชแบรนช์หรือการเปิด pull request จะถูกกั้นแยกต่างหาก — ดู[กฎคุม](/th-TH/คู่มือ/แนวคิด/กฎคุม/)

## ขั้นตอนที่ 5: ตรวจสอบผลลัพธ์

1. เปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** แล้วเลือกเอเจนต์ของคุณ
2. เปิดแท็บ **บันทึก**

**จุดตรวจสอบ** หนึ่งแถวการรัน แสดงสถานะ ระยะเวลา เวลาเริ่มและเวลาสิ้นสุด และอะแดปเตอร์ที่มันรันอยู่

การเปลี่ยนแปลงของเอเจนต์ถูกคอมมิตบนแบรนช์ของบทสนทนา ใน worktree ของมัน คอมมิตถูกเขียนในนามของเอเจนต์ โดยให้เครดิตคุณไว้ในส่วนท้าย `Co-Authored-By:`

## ขอ pull request

ไม่มีอะไรเปิด pull request เอง หากคุณต้องการ ให้ขอในบทสนทนาเดียวกัน:

> พุชแบรนช์นี้แล้วเปิด pull request เทียบกับแบรนช์เริ่มต้น

การพุช (`gitPush`) และการสร้าง PR (`prCreate`) ต่างมีค่าเริ่มต้นเป็นการขออนุมัติจากคุณ จึงควรคาดว่าจะมีการยืนยันก่อนแต่ละอย่าง หากไม่มีผู้อนุมัติเชื่อมต่ออยู่ตอนที่คำขอเกิดขึ้น การกระทำจะถูกปฏิเสธแทนที่จะถูกอนุญาต — กฎคุมจะล้มเหลวแบบปิด

PR จะถูกเปิดภายใต้ตัวตน GitHub ที่การรันนั้นใช้โทเคนของตัวตนนั้น — ของคุณ หากคุณเก็บโทเคนส่วนตัวไว้ — ไม่ใช่ภายใต้ชื่อของเอเจนต์ ความเป็นผู้เขียนของเอเจนต์จะปรากฏบนคอมมิต

คุณเปิดมันเองได้เช่นกัน: แผง **การควบคุมซอร์ส** ของสเปซมีปุ่ม **สร้าง pull request** ที่พาแบรนช์ของบทสนทนาเข้าสู่หน้าจอเขียน และ **Pull request → PR ใหม่** เปิดหน้าจอเดียวกันแบบว่างเปล่า นั่นคือจุดที่บทสอนถัดไปเริ่มต้น
