Control Center ให้คุณควบคุมฟลีตของเอเจนต์เขียนโค้ด AI สปอว์นเอเจนต์ เฝ้าดูมันทำงานแบบเรียลไทม์ รีวิว PR ของมัน และจัดการรีโป เวิร์กสเปซ และการผสานระบบ — จากแอปเดสก์ท็อปแบบเนทีฟ เบราว์เซอร์ หรือโทรศัพท์ของคุณ

## สิ่งที่คุณทำได้

- **ส่งข้อความหาเอเจนต์**: สเปซเป็นวิธีหลักในการขับเคลื่อนฟลีต @-mention เอเจนต์ตัวหนึ่ง แล้วมันจะถูกส่งเข้าสู่ worktree แบบ copy-on-write ของตัวเอง หลายตัวจึงเขียนโค้ดและรีวิวขนานกันได้โดยไม่แตะเช็กเอาต์ของคุณ
- **ประสานงานคำขอใหญ่**: บอกเป้าหมายให้ตัวประสานงาน อนุมัติแผนของทั้งทีมที่มันเสนอเพียงครั้งเดียว แล้ว[ไปป์ไลน์](/th-TH/คู่มือ/แนวคิด/ไปป์ไลน์/)ที่สร้างขึ้นจะรันแผนนั้น
- **รีวิวและรวม PR** ด้วยตัวดู diff ในตัว ความคิดเห็นแบบอินไลน์ และรีวิวที่ขับเคลื่อนด้วย AI
- **มอบเครื่องใช้แล้วทิ้งให้เอเจนต์**: [ริก](/th-TH/คู่มือ/วิธีทำ/ใช้ริก/) คือ VM แบบใช้แล้วทิ้ง — เบราว์เซอร์ เดสก์ท็อป โทรศัพท์ หรือเทอร์มินัลในเอนโคลเจอร์ — ที่เอเจนต์ขับเคลื่อนขณะคุณดูสด ๆ และเข้ายึดต่อได้ เซิร์ฟเวอร์ dev ข้างในถูกส่งต่อไปยัง `localhost` เบราว์เซอร์ของเอเจนต์ และ `https://myapp.test`
- **ทำให้เวิร์กโฟลว์เป็นอัตโนมัติ** ด้วยไปป์ไลน์แบบ DAG ที่ทริกเกอร์ด้วยเหตุการณ์หรือกำหนดเวลา
- **จัดการความรู้** ด้วยหน่วยความจำ ข้อเท็จจริง และนโยบายที่จำกัดขอบเขตไว้ที่เวิร์กสเปซ
- **ติดตามงาน** ด้วยตั๋วงาน โปรเจกต์ และการมอบหมายที่ไม่ผูกกับผู้ขายรายใด
- **บันทึกการประชุม** ด้วยการเก็บเสียง ถอดเสียง และแยกผู้พูดบนอุปกรณ์ แล้วสรุปเป็นโน้ต รายการสิ่งที่ต้องทำ และการตัดสินใจ
- **ดูวันของคุณ** ด้วยการซิงค์ Google Calendar การตอบรับ (RSVP) การแจ้งเตือนการประชุม และการบันทึกแล้วเชื่อมโยง
- **ติดตามฟลีตจากโทรศัพท์**: จับคู่อุปกรณ์กับเซิร์ฟเวอร์ของคุณ แล้วอ่านข้อความ ตอบกลับ และคัดแยกตั๋วงาน โทรศัพท์เลือกเส้นทางที่ดีที่สุดเท่าที่เข้าถึงได้ — ลูปแบ็ก LAN tailnet หรือ TLS — และถอยไปใช้รีเลย์ที่ปิดผนึกแบบต้นทางถึงปลายทางซึ่งส่งต่อเฟรมที่มันอ่านไม่ได้
- **ขับเคลื่อนเอเจนต์จาก Slack**: เชื่อมเวิร์กสเปซเข้ากับแอปแชทแล้ว mention บอต ตอบกลับในเธรด Slack หรือเปิดตั๋วงานด้วยคำสั่งสแลช — ผ่านการเชื่อมต่อขาออก จึงไม่ต้องมีปลายทางสาธารณะ
- **ผสานระบบ** กับ GitHub, Linear, Slack, Google Calendar และเครื่องมือ MCP กว่า 100 รายการ

## คุณไม่จำเป็นต้องติดตั้ง

แอปเดียวกันนี้ทำงานในเบราว์เซอร์ของคุณที่
[app.usectrl.dev](https://app.usectrl.dev) พร้อมฟีเจอร์เดียวกัน

ทุกไคลเอนต์ — เดสก์ท็อป เว็บ และโทรศัพท์ — เป็นตัวเรนเดอร์แบบบางบนเซิร์ฟเวอร์แบบไม่มีส่วนติดต่อ
ที่เป็นเจ้าของข้อมูลของคุณและลงมือทำงาน เดสก์ท็อปสปอว์นเซิร์ฟเวอร์นั้นให้คุณได้ แต่แท็บ
เบราว์เซอร์ทำไม่ได้ แอปเว็บจึงเชื่อมต่อกับเซิร์ฟเวอร์ที่คุณรันเอง เซิร์ฟเวอร์นั้นจะวางอยู่บน
เครื่องของคุณเอง (`ws://localhost:9030` ไม่ต้องใช้ใบรับรอง) หรือบนโฮสต์ระยะไกลที่เข้าถึงได้ผ่าน
TLS, VPN หรือทันเนลก็ได้

ดู[ติดตั้ง](/th-TH/คู่มือ/ติดตั้ง/#use-it-in-your-browser) สำหรับเส้นทางเบราว์เซอร์ และ
[การปรับใช้และไคลเอนต์](/th-TH/คู่มือ/แนวคิด/การปรับใช้/) สำหรับความสัมพันธ์ของไคลเอนต์ทั้งสาม
