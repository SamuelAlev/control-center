คู่มือนี้แสดงวิธีใช้สเปซ **สเปซ** คือพื้นผิวการรับส่งข้อความใน Control Center:
ห้องที่จำกัดขอบเขตตามเวิร์กสเปซ มีผู้เข้าร่วมหนึ่งคนขึ้นไป (คุณและ/หรือเอเจนต์)
และถือครอง worktree แบบ copy-on-write หนึ่งชุดต่อหนึ่งรีโปที่มันถูกสร้างขึ้นมา

ห้องคุยตัวต่อตัวและห้องที่มีเอเจนต์หลายตัวก็เป็นแค่สเปซทั้งคู่ ต่างกันเพียงจำนวน
ผู้เข้าร่วมที่มี ข้อยกเว้นเดียวคือสเปซที่เอเจนต์เปิดขึ้นเพื่อคุยกันเอง — ดู
[สเปซระหว่างเอเจนต์](#สเปซระหว่างเอเจนต์) ด้านล่าง

## สร้างสเปซ

1. ไปที่ **สเปซ**
2. คลิกปุ่ม **+** ข้างหัวข้อสเปซ
3. ตั้ง **ชื่อ** ให้มัน — จำเป็นต้องระบุ หากปล่อยชื่อว่างจะถูกปฏิเสธ
   ไดอะล็อกจะยังเปิดอยู่
4. เพิ่มเอเจนต์จากเวิร์กสเปซก็ได้ตามต้องการ
5. เมื่อเวิร์กสเปซมีรีโปอยู่ เลือกว่าสเปซนี้จะจัดเตรียม worktree ให้รีโปใดบ้าง
   เริ่มต้นจะเลือกทั้งหมด การยกเลิกการเลือกรีโปทุกตัวจะสร้างสเปซที่ไม่มีอะไร
   เช็กเอาต์ไว้
6. ยืนยัน

สเปซจำกัดขอบเขตตามเวิร์กสเปซ: คุณจะเห็นเฉพาะเอเจนต์จากเวิร์กสเปซปัจจุบัน และ
สเปซจะไม่แสดงข้อมูลจากเวิร์กสเปซอื่นเลย

รีโปแต่ละตัวจะถูกเช็กเอาต์ไว้ที่ `repos/<name>/` ภายในสเปซ รีโปที่มาพร้อมสกิล
เอเจนต์ของตัวเองจะมอบสกิลเหล่านั้นให้เอเจนต์ที่ทำงานอยู่ในรีโปนั้น — ทีละชุดของ
รีโปเดียว สลับไปตามที่เอเจนต์ย้ายไปมา จากช่องเขียนข้อความคุณเข้าถึงสกิลใดก็ได้ด้วย
`/skill:<repo>:<name>` ดู
[สกิลที่จำกัดตามรีโป](/th-TH/คู่มือ/แนวคิด/โมเดลเอเจนต์/#repo-scoped-skills)

พื้นผิวนี้อยู่ที่ `/workspaces/<id>/spaces` และสเปซเดี่ยวอยู่ที่
`/workspaces/<id>/spaces/<spaceId>`

## กำหนดโหมดของสเปซ

สเปซใหม่จะเริ่มต้นในโหมดเริ่มต้น เปลี่ยนได้จาก **ดรอปดาวน์โหมด** ที่ซ้ายสุดของ
แถบเครื่องมือช่องเขียนข้อความ — ไม่ใช่จากไดอะล็อกสร้างสเปซ (ซึ่งไม่มีช่องโหมด)
และไม่ใช่จากส่วนหัวของสเปซ

| โหมด          | ผลที่ได้                                                                                       |
| ------------- | ---------------------------------------------------------------------------------------------- |
| **เอเจนต์**   | เข้าถึงเต็มรูปแบบ ค่าเริ่มต้น; `chat` ภายใน ใช้ป้าย “เอเจนต์” ในดรอปดาวน์                        |
| **แผน**       | อ่านและค้นคว้าเท่านั้น; สิ่งที่ส่งมอบคือแผนที่มีชนิดข้อมูลกำกับ                                  |
| **ประสานงาน** | อ่านและค้นคว้า บวกคำกริยา `propose_orchestration` เพียงคำเดียว; แผนจะรันหลังคุณอนุมัติแล้วเท่านั้น |

Shift+Tab สลับระหว่างโหมดแผนกับโหมดเอเจนต์โดยไม่ต้องเปิดดรอปดาวน์

มีโหมดที่สี่คือ **รีวิว** อยู่ด้วย แต่ไม่ถูกเสนอในดรอปดาวน์ — มันถูกนำไปใช้โดย
อัตโนมัติกับสเปซรีวิว PR

โหมดถูกจัดเก็บไว้ที่สเปซ เอเจนต์ตัวเดียวกันจึงอยู่ในโหมดแผนในสเปซหนึ่งและโหมด
เอเจนต์ในอีกสเปซหนึ่งได้พร้อมกัน การสนทนาทุกอันภายในสเปซใช้โหมดของสเปซนั้นร่วมกัน

:::caution[ระวังป้ายการบังคับใช้]
ป้ายจะปรากฏข้างดรอปดาวน์โหมดเมื่อเอเจนต์ของสเปซรันบนอะแดปเตอร์ที่บังคับใช้โหมดที่
คุณเลือกไม่ได้ มีเพียงฮาร์เนสในตัวของ Control Center เท่านั้นที่กรองพื้นผิวเครื่องมือ
และกั้นการเรียกทุกครั้ง; อะแดปเตอร์ Claude Code และ ACP ได้รับโหมดไปในฐานะคำขอที่
ตัวรันของมันอาจทำตามหรือไม่ก็ได้ การไม่มีป้ายหมายถึง “ไม่มีการอ้างสิ่งใด” ไม่ใช่
“ยืนยันแล้วว่าปลอดภัย”
:::

ดู [โหมด](/th-TH/คู่มือ/แนวคิด/โหมด/) สำหรับโมเดลฉบับเต็ม

## จัดการผู้เข้าร่วมและความเป็นอิสระรายเอเจนต์

คลิกไอคอนรูปคนในส่วนหัวของสเปซเพื่อเปิด **จัดการผู้เข้าร่วม** สำหรับเอเจนต์แต่ละตัว
ที่มีอยู่ในสเปซแล้ว คุณสามารถ:

- นำมันออกจากสเปซ
- ตั้ง **ความเป็นอิสระ** ของมันสำหรับสเปซนี้: **ค่าเริ่มต้น**, **เสนออย่างเดียว**,
  **ทำเมื่อได้รับอนุมัติ** หรือ **ทำได้อย่างอิสระ**

ปุ่มความเป็นอิสระเป็นราย (สเปซ, เอเจนต์) เอเจนต์ที่คุณไว้ใจในห้องหนึ่งจึงอาจถูก
จำกัดให้เสนออย่างเดียวในอีกห้องหนึ่งได้

## ตอบกลับข้อความด้วยปฏิกิริยา

วางเมาส์บนข้อความแล้วคลิกไอคอนรอยยิ้มเพื่อเปิดพาเลตต์ปฏิกิริยา มันเป็นชุดตายตัว
หกแบบ: 👍 👎 🎉 ❤️ 👀 ✅ ไม่มีตัวเลือกอีโมจิแบบอิสระ — การแตะหนึ่งครั้งจะสลับ
ปฏิกิริยานั้นให้คุณ และชิปที่รวมแล้วจะปรากฏใต้ข้อความ

## เปิดการสนทนา

สเปซหนึ่งรองรับการสนทนาหลายอันพร้อมกัน และทั้งหมดเท่าเทียมกันแบบแบนราบ — ไม่มี
อันใดเป็นอันหลัก สเปซจะเก็บการสนทนาที่ยังมีชีวิตอยู่ไว้อย่างน้อยหนึ่งอันเสมอ: คุณ
เก็บถาวรอันสุดท้ายที่ยังใช้งานอยู่ไม่ได้ และการเปิดสเปซที่ยังไม่มีการสนทนาเลยจะ
สร้างการสนทนาประจำที่ไม่มีชื่อขึ้นมา

การสนทนาจะปรากฏเป็นแท็บของตัวแก้ไข และเป็นแถวซ้อนอยู่ใต้สเปซในแถบข้างเมื่อมี
มากกว่าหนึ่งอัน **การสนทนาใหม่** อยู่ในเมนูแท็บใหม่ของตัวแก้ไข และสร้างการสนทนาที่
ไม่มีชื่อโดยไม่มีการถามชื่อ — โมเดลชื่อจะตั้งชื่อให้ตามข้อความแรก ใช้มันเพื่อทำงาน
ขนานกับเอเจนต์และ worktree ชุดเดียวกัน

การสนทนาแต่ละอันเก็บประวัติข้อความและเซสชันเอเจนต์ของตัวเองไว้ ขณะที่ใช้ worktree
ของสเปซและโหมดของสเปซร่วมกัน การปิดแท็บจะซ่อนมันไว้; **เก็บถาวรการสนทนา** (แถวใน
แถบข้างหรือเมนูบริบทของแท็บแชท) จะเก็บถาวรเฉพาะการสนทนานั้น

## เริ่มเธรด

วางเมาส์บนข้อความใดก็ได้แล้วเลือก **เริ่มเธรด** มันจะเปิดการสนทนาที่ผูกยึดกับ
ข้อความนั้น: จุดยึดจะป้อนบริบทเอเจนต์ของการสนทนาใหม่ด้วยหนึ่งบรรทัด และประวัติของ
บทสนทนาต้นทางจะ **ไม่** ถูกคัดลอกมา

เมื่อเธรดมีคำตอบแล้ว ข้อความที่มันเกาะอยู่จะมีแถวงอกขึ้นมาใต้มัน — ใบหน้าของผู้ที่ได้
พูด จำนวนคำตอบ และเวลาที่คำตอบล่าสุดมาถึง แถวนั้นคือทางกลับเข้าไป: การคลิกมันจะเปิด
(หรือโฟกัส) แท็บของเธรด มันเป็นร่องรอยเดียวที่เธรดทิ้งไว้ในสตรีมที่มันแยกออกมา
จึงเป็นเหตุผลว่าทำไมมันถึงอยู่ตรงนั้นตั้งแต่แรก

แท็บของเธรดมีชื่อว่า `Thread: <name>` และมีสัญลักษณ์สาขาติดอยู่ จึงไม่มีทางที่แท็บ
สองอันบนสเปซเดียวกันจะถูกเข้าใจผิดว่าเป็นอันเดียวกัน

เธรดไม่ซ้อนกันเด็ดขาด — การผูกยึดกับข้อความที่อยู่ในเธรดอยู่แล้วจะถูกปฏิเสธ ส่วนหัว
ของการสนทนาจะลิงก์กลับไปยังข้อความจุดยึด การลบข้อความจุดยึดจะลบเธรดนั้น และการ
เก็บถาวรบทสนทนาต้นทางไม่ขัดขวางเธรดที่มีอยู่แล้วของมัน

## สถานะการอ่าน

เครื่องหมายว่าอ่านแล้วถูกจำกัดขอบเขตที่สเปซ ไม่ใช่ที่การสนทนา: การเปิดการสนทนาใดก็
ได้ในสเปซจะล้างทั้งห้อง สถานะยังไม่อ่านยังคงรวมจากการสนทนาทุกอันของสเปซ รวมทั้ง
เธรดด้วย เมื่อมีการแสดงรายการการสนทนาใต้สเปซ จุดยังไม่อ่านจะอยู่ที่การสนทนาที่ยัง
มีงานที่ยังไม่เห็น ไม่ใช่ที่แถวแม่

## สเปซระหว่างเอเจนต์

สเปซที่เอเจนต์เปิดขึ้นเพื่อคุยกันเองจะถูกแยกเป็นส่วนต่างหากในแถบข้างใต้ **เอเจนต์**
ยุบไว้เป็นค่าเริ่มต้นและแสดงแบบจาง มันไม่เพิ่มป้ายยังไม่อ่านของคุณเลย — เสียงคุยของ
เอเจนต์เงียบโดยตัวมันเอง ไม่ใช่เพราะการตั้งค่าที่คุณต้องไปหามาเปิด

ชนิดของสเปซมีได้ห้าค่า: `topic` (ค่าเริ่มต้นสำหรับทุกอย่างที่คุณสร้าง), `agentPeer`,
`system` (จัดการโดยไปป์ไลน์), `pr` (สร้างเมื่อพื้นผิว PR ต้องมีจุดยึด worktree และ
ถูกซ่อนจากแถบข้างจนกว่าจะมีข้อความ) และ `slack` (สร้างโดยสะพานแชทสำหรับเธรด Slack
หรือ DM กับบอต และถูกปฏิบัติเหมือนการสนทนาของมนุษย์ทั่วไป)
