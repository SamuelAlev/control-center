คู่มือนี้แสดงวิธีจัดรูปฟีดข่าว: ดึงข้อมูลจากแหล่งใด อ่านบทความอย่างไร และการ
บล็อกเนื้อหาทำอะไรบ้าง

:::caution[ฟีดข่าวเป็นระดับผู้ใช้ ไม่ได้ผูกกับเวิร์กสเปซ]
ฟีดและบทความเป็นของผู้ใช้ที่ลงชื่อเข้าใช้: รายการฟีด สถานะการอ่าน และบุ๊กมาร์ก
ของคุณติดตามคุณไปทุกเวิร์กสเปซและทุกอุปกรณ์ที่คุณลงชื่อเข้าใช้ และไม่มีผู้ใช้อื่น
เห็นข้อมูลเหล่านี้ ฟีดถูกเก็บในฐานข้อมูลส่วนกลางของเซิร์ฟเวอร์ URL `/newsfeed`
จึงมี id ของเวิร์กสเปซเพียงเพราะทุกเส้นทางในแอปมีเหมือนกัน
:::

## อ่านบทความ

1. คลิก **ฟีดข่าว** ในแถบด้านข้าง
2. สลับระหว่าง **ทั้งหมด** **ยังไม่อ่าน** และ **ที่บันทึก** ด้วยปุ่มแบ่งส่วนบนแถบเครื่องมือ
3. กรองรายการให้แคบลงด้วยช่องค้นหาหรือตัวเลือกแหล่งข่าว
4. สลับระหว่างตารางแบบนิตยสารและรายการแบบกะทัดรัดด้วยปุ่มเลย์เอาต์

การเปิดบทความจะทำเครื่องหมายว่าอ่านแล้ว ใช้ **ทำเครื่องหมายทั้งหมดว่าอ่านแล้ว**
ในส่วนหัวของหน้า — ซึ่งจะปรากฏเฉพาะเมื่อยังมีรายการที่ยังไม่อ่าน — เพื่อเคลียร์
รายการค้างทั้งหมดในคราวเดียว และใช้ปุ่มบุ๊กมาร์กบนการ์ดเพื่อบันทึกบทความไว้ดู
ภายหลัง

การเลือกเลย์เอาต์จะคงอยู่ข้ามการเปิดโปรแกรมแต่ละครั้ง

## เพิ่มฟีด

1. เปิด **การตั้งค่า → คุณ → ฟีดข่าว** (ไอคอนการตั้งค่าในส่วนหัวของฟีดข่าว
   จะพาไปที่นั่นโดยตรง)
2. กด **เพิ่มฟีด**
3. กรอก **ชื่อ** และ **URL ของฟีด** (RSS หรือ Atom)
4. หากต้องการ ขยาย **ขั้นสูง** แล้วกำหนด **User-Agent** แบบกำหนดเอง — ผู้เผยแพร่
   บางรายส่งคำตอบที่ต่างออกไปให้ไคลเอนต์เริ่มต้น
5. กด **เพิ่มฟีด**

จุดตรวจสอบ: ฟีดจะปรากฏในรายการ **ฟีด** และบทความจะเข้ามาหลังการดึงครั้งแรก
URL ที่ติดตามอยู่แล้วจะถูกปฏิเสธด้วยข้อความ “มีฟีดที่ใช้ URL นี้อยู่แล้ว”

ระบบจะติดตั้งฟีดเริ่มต้น 14 รายการให้ผู้ใช้ทุกคนเมื่อใช้งานครั้งแรก: Control Center,
The Verge, TechCrunch, Hacker News, ByteByteGo, Product Hunt, TLDR AI, Import AI,
The Pragmatic Engineer, Martin Fowler, Irrational Exuberance ของ Will Larson,
The Engineering Manager, Lea Verou และ CSS-Tricks

## จัดการฟีด

แต่ละแถวในรายการ **ฟีด** มีปุ่มควบคุมสามปุ่ม:

| ตัวควบคุม    | ผลลัพธ์                                                             |
| ------------ | ------------------------------------------------------------------- |
| สวิตช์       | ปิดใช้งานฟีด แถวที่ถูกปิดใช้งานจะถูกหรี่สีและไม่ถูกดึงข้อมูลอีก      |
| ไอคอนรีเฟรช  | ดึงฟีดนี้ทันที                                                       |
| ไอคอนถังขยะ  | ลบฟีด หลังการยืนยัน                                                  |

**รีเฟรชทั้งหมด** ที่ด้านบนของรายการจะดึงฟีดที่เปิดใช้งานทุกรายการ

คำบรรยายใต้ชื่อฟีดจะแสดงคำอธิบายและเวลาที่ผ่านมาหลังการดึงล่าสุด ฟีดที่ล้มเหลว
จะแสดงข้อผิดพลาดแทนคำอธิบายนั้น โดยใช้สีเตือน

ไม่มีปุ่มแก้ไข — หากต้องการเปลี่ยนชื่อ URL หรือ user agent ของฟีด ให้ลบแล้ว
เพิ่มใหม่

การดึงข้อมูลทำงานบนเซิร์ฟเวอร์ทั้งหมด: หนึ่งครั้งต่อผู้ใช้เมื่อเริ่มระบบ (และเมื่อ
ใช้งานครั้งแรกสำหรับบัญชีที่สร้างขึ้นภายหลัง) จากนั้นทุก 30 นาที

## บล็อกโฆษณาและตัวติดตามในตัวอ่าน

1. ใน การตั้งค่า → คุณ → ฟีดข่าว ให้หา **ค่ากำหนดตัวอ่าน**
2. เปิด **เปิดบทความในแอป** ไว้เพื่อใช้ตัวอ่านในตัว หรือปิดเพื่อส่งบทความให้
   เบราว์เซอร์ของระบบ
3. เปิด **บล็อกโฆษณา ตัวติดตาม และแบนเนอร์คุกกี้** ไว้

การบล็อกเปิดอยู่โดยค่าเริ่มต้น ตัวอ่านแบบฝังมีเฉพาะ macOS และ Windows: บนบิลด์
เว็บและบน Linux เบราว์เซอร์ของระบบ _คือ_ ตัวอ่าน และบทความจะเปิดที่นั่น (เป็น
แท็บใหม่บนเว็บ) บนเว็บ สวิตช์บล็อก การ์ด **รายการตัวกรอง** และการ์ด
**ไซต์ที่เชื่อถือ** จะถูกซ่อนไว้

ตัวอ่านในแอปไม่ได้จัดรูปแบบบทความใหม่ แต่แสดงหน้าของผู้เผยแพร่ในเว็บวิวแบบฝัง
และระงับโฆษณา ตัวติดตาม และแบนเนอร์คุกกี้โดยใช้รายการตัวกรองที่แคชไว้

### ตรวจสอบหรืออัปเดตรายการตัวกรอง

การ์ด **รายการตัวกรอง** แสดงจำนวนกฎซ่อนคุกกี้ ซ่อนโฆษณา และบล็อกเครือข่ายที่
โหลดอยู่ รวมทั้งพารามิเตอร์ติดตามที่ถูกตัดออก และเวลาที่อัปเดตรายการล่าสุด
กด **ตรวจหาอัปเดต** เพื่อรีเฟรชรายการเหล่านี้

แหล่งที่มาได้แก่ EasyList, i-dont-care-about-cookies, Fanboy Cookiemonster,
รายการ uBlock Origin หลายรายการ และรายการพารามิเตอร์ติดตามของ uBO จนกว่าการ
ดาวน์โหลดจะสำเร็จ การ์ดจะระบุว่ารายการเหล่านี้เป็นค่าเริ่มต้นที่มาพร้อมแอปและ
ยังไม่เคยอัปเดต — จำนวนกฎโฆษณา คุกกี้ และเครือข่ายจะยังเป็นศูนย์ ส่วนการตัด
พารามิเตอร์ติดตามยังคงใช้ชุดค่าเริ่มต้นในตัว

### อนุญาตไซต์

บางไซต์ทำงานผิดพลาดเมื่อเปิดการบล็อก

1. ใน การตั้งค่า → คุณ → ฟีดข่าว ไปที่ **ไซต์ที่เชื่อถือ**
2. กด **เพิ่มไซต์ที่เชื่อถือ** แล้วกรอกโดเมน

ไซต์นั้นจะถูกข้ามการบล็อก

## การแก้ปัญหา

### ฟีดที่ฉันเพิ่มไปปรากฏในเวิร์กสเปซอื่น

เป็นพฤติกรรมที่คาดไว้ ฟีดข่าวเป็นระดับผู้ใช้ ไม่ได้แยกระดับเวิร์กสเปซ — ฟีดของ
คุณติดตามคุณไปทุกที่ที่คุณลงชื่อเข้าใช้ ดูคำเตือนที่ด้านบน

### แถวของฟีดแสดงข้อผิดพลาดแทนคำอธิบาย

การดึงข้อมูลครั้งล่าสุดล้มเหลว และแถวนั้นแสดงสาเหตุตามจริง กดไอคอนรีเฟรชเพื่อ
ลองใหม่ และตรวจสอบว่า URL ยังให้บริการ RSS หรือ Atom อยู่ ผู้เผยแพร่ที่ปฏิเสธ
ไคลเอนต์ที่ไม่รู้จักอาจต้องใช้ user agent แบบกำหนดเอง ซึ่งหมายถึงต้องลบฟีดแล้ว
เพิ่มใหม่

### หน้าบทความแสดงผลผิดปกติ

ปิด **บล็อกโฆษณา ตัวติดตาม และแบนเนอร์คุกกี้** สำหรับโดเมนนั้นผ่าน
**ไซต์ที่เชื่อถือ** หรือปิด **เปิดบทความในแอป** แล้วอ่านในเบราว์เซอร์ของคุณ
