โปรเจกต์คือการจัดกลุ่มตั๋วงานภายในขอบเขตของเวิร์กสเปซเพื่อไปสู่วัตถุประสงค์ร่วม โปรเจกต์มีอยู่เฉพาะใน Control Center เท่านั้น — มันไม่เคยซิงก์ไปยังผู้ให้บริการภายนอกอย่าง
Linear

## สร้างโปรเจกต์

1. ขยายกลุ่ม **ตั๋วงาน** ในแถบด้านข้างของเวิร์กสเปซ กลุ่มนี้แสดง
   **ตั๋วงานทั้งหมด** หนึ่งแถวต่อโปรเจกต์ที่ยังไม่ถูกเก็บถาวร แล้วตามด้วย **โปรเจกต์ใหม่**
2. คลิก **โปรเจกต์ใหม่**
3. กรอก **ชื่อโปรเจกต์**, **คำอธิบาย** (ซึ่งไม่บังคับ) และเลือก **สี**
4. กด **สร้างโปรเจกต์**

คุณจะเข้าสู่ภาพรวมของโปรเจกต์ใหม่ และโปรเจกต์จะปรากฏเป็นแถวในแถบด้านข้าง
ใต้ **ตั๋วงาน**

## เพิ่มตั๋วงานเข้าโปรเจกต์

โปรเจกต์เป็นฟิลด์ของตั๋วงานแต่ละใบ ตั้งค่าได้จากสองตำแหน่งต่อไปนี้:

- เปิดตั๋วงานแล้วตั้งค่า **โปรเจกต์** ในแถบคุณสมบัติของมัน
- คลิกขวาที่ตั๋วงานในรายการ แล้วใช้เมนูย่อย **โปรเจกต์**

ตัวเลือกในแถบคุณสมบัติยังมี **โปรเจกต์ใหม่** ด้วย ดังนั้นคุณจึงจัดเก็บตั๋วงาน
เข้าโปรเจกต์ที่สร้างขึ้นตรงนั้นได้เลย **ไม่มีโปรเจกต์** จะล้างฟิลด์นี้

ตั๋วงานหนึ่งใบเป็นสมาชิกของโปรเจกต์ได้ไม่เกินหนึ่งโปรเจกต์

:::note[โปรเจกต์ไม่ใช่การดำเนินการแบบกลุ่ม]
แถบลอยที่ปรากฏเมื่อคุณเลือกตั๋วงานหลายใบครอบคลุมสถานะ ลำดับความสำคัญ
ผู้รับมอบหมาย ป้ายกำกับ และการลบ แต่ไม่มีชิปโปรเจกต์ ดังนั้นการจัดเก็บตั๋วงาน
หลายใบจึงหมายถึงต้องทำทีละใบ
:::

คุณยังเริ่มจากโปรเจกต์ได้เช่นกัน: **ตั๋วงานใหม่** บนภาพรวมของโปรเจกต์
จะสร้างตั๋วงานและจัดเก็บไว้ที่นั่น

## อ่านความคืบหน้าของโปรเจกต์

เปิดโปรเจกต์จากแถวในแถบด้านข้าง หรือไปที่
`/workspaces/<workspace-id>/projects/<project-id>`

ภาพรวมแสดงสัญลักษณ์และชื่อของโปรเจกต์ ป้ายสถานะ คำอธิบาย และแถบความคืบหน้า
ที่บอกจำนวนที่เสร็จเทียบกับทั้งหมด ด้านล่างนั้น ตั๋วงานของโปรเจกต์ถูกจัดกลุ่ม
ตามสถานะ

มันไม่สรุปข้อมูลอย่างอื่นเลย — ไม่มีการแจกแจงตามผู้รับมอบหมาย และไม่มี
การกระจายตามลำดับความสำคัญ หากต้องการข้อมูลเหล่านั้น ให้กรองรายการตั๋วงาน
หลักแทน

## เปลี่ยนสถานะโปรเจกต์

โปรเจกต์มีสามสถานะ:

| สถานะ           | ความหมาย             |
| --------------- | -------------------- |
| **ใช้งานอยู่**   | งานกำลังดำเนินอยู่     |
| **เสร็จแล้ว**    | งานทั้งหมดเสร็จสิ้น   |
| **เก็บถาวรแล้ว** | เอกสารอ้างอิงเชิงประวัติ |

ใช้เมนู **⋯** บนส่วนหัวของโปรเจกต์ เมนูนี้มี **แก้ไขโปรเจกต์**,
**ทำเครื่องหมายว่าเสร็จ** / **ทำเครื่องหมายว่าใช้งาน**, **เก็บถาวร** / **กู้คืน**
และ **ลบโปรเจกต์**

การเก็บถาวรจะซ่อนโปรเจกต์จากรายการในแถบด้านข้างและจากตัวเลือกตั๋วงาน
มันย้อนกลับได้ — **กู้คืน** จะทำให้โปรเจกต์กลับมาใช้งานอยู่ — แต่ระหว่างที่
ถูกเก็บถาวร โปรเจกต์จะเข้าถึงได้ผ่าน URL เท่านั้น

## โปรเจกต์ที่สร้างให้คุณ

การอนุมัติการประสานงานจะสร้างโปรเจกต์และจัดเก็บตั๋วงานแม่ไว้ใต้โปรเจกต์นั้น
พร้อมกับสิ่งที่คุณจัดเก็บด้วยตัวเอง รายการงานที่สร้างขึ้นเป็นขั้นตอนของ
ไปป์ไลน์ ไม่ใช่แถวของตั๋วงาน จึงไม่ปรากฏบนบอร์ดของโปรเจกต์ นั่นคือเส้นทาง
อัตโนมัติเพียงเส้นทางเดียว: ไม่มีโหนดของไปป์ไลน์ใดสร้างตั๋วงาน ไปป์ไลน์จึง
เพิ่มข้อมูลเข้าโปรเจกต์ไม่ได้ ดู
[รันการประสานงาน](/th-TH/คู่มือ/วิธีทำ/รันการประสานงาน/)

:::note[โปรเจกต์เป็นพื้นผิวของผู้ดำเนินการ]
สร้าง แสดงรายการ อัปเดต และลบโปรเจกต์ได้ในแอป เอเจนต์ไม่มีเครื่องมือสำหรับ
โปรเจกต์
