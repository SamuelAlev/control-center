คู่มือนี้แสดงวิธีเติมสกิลจาก GitHub ให้เวิร์กสเปซ: เพิ่มรีโพสิทอรีเป็นแหล่ง
ติดตั้งสกิลที่คุณต้องการจากมัน และทำให้มันเป็นปัจจุบันอยู่เสมอ

สิ่งสำคัญที่ควรรู้ก่อนเริ่ม: **รีโพสิทอรีต้นทางไม่น่าเชื่อถือ** ชื่อ คำอธิบาย
และจำนวนดาวของมันเขียนขึ้นโดยเจ้าของของมัน สัญญาณความปลอดภัยเดียวที่ Control
Center เชื่อถือได้คือคำตัดสินจากการสแกนแอนติไวรัส ซึ่งการติดตั้งทุกครั้งต้องผ่าน
ก่อนที่สิ่งใดจะไปถึงดิสก์หรือพรอมต์ของเอเจนต์ หากต้องการเหตุผล อ่าน
[ส่วนว่าด้วยสกิลของโมเดลเอเจนต์](/th-TH/คู่มือ/แนวคิด/โมเดลเอเจนต์/) หน้านี้มุ่งอยู่
ที่การลงมือทำ

สกิลอยู่ที่ **การตั้งค่า → เวิร์กสเปซ → สกิล**
(`/workspaces/<id>/settings/workspace/skills`) สกิลมีขอบเขตอยู่ที่เวิร์กสเปซ:
สกิลที่คุณติดตั้งที่นี่เป็นของเวิร์กสเปซนี้เท่านั้น หน้านี้มีสองแท็บ:
**ติดตั้งแล้ว** (สกิลในเครื่อง รวมถึงตัวแก้ไข **สกิลใหม่**) และ **แหล่ง**
(แค็ตตาล็อก GitHub) การเขียนทั้งสองแบบผ่านด่านสแกนเดียวกัน

## เพิ่มรีโพสิทอรีสกิล

1. เปิด **การตั้งค่า → เวิร์กสเปซ → สกิล** แล้วสลับไปที่แท็บ **แหล่ง**
2. กด **เพิ่มรีโพสิทอรี**
3. วาง URL ของรีโพสิทอรี GitHub เช่น `https://github.com/anthropics/skills`
   แล้วยืนยัน

เซิร์ฟเวอร์ตรวจว่ารีโพสิทอรีมีอยู่จริงและมองเห็นได้ด้วยข้อมูลรับรองของมัน
จากนั้นเพิ่มมันลงในแถบด้านซ้าย ไม่มีที่เก็บที่คัดสรรอยู่ตรงกลาง: รีโพสิทอรี GitHub
ใดก็ได้ ซึ่งหมายความว่าชื่อเสียงเป็นสิ่งที่คุณต้องตัดสินเอง — จำนวนดาวเป็นหลักฐาน
ไม่ใช่สิ่งรับประกัน

สกิลของรีโพสิทอรีคือไดเรกทอรีที่มี `SKILL.md` (ลึกได้ถึงสามระดับ บวกกับเลย์เอาต์
Claude plugin-marketplace `plugins/<plugin>/skills/<skill>` โดยข้ามทรีของ
dependency และ vendor) หากภายหลังตารางการ์ดบอกว่ารีโพสิทอรีไม่มีสกิล
นั่นคือความหมายของมัน: ไม่มีไดเรกทอรีใดในนั้นตรงกับธรรมเนียมของสกิล

## ตรวจดูสกิลก่อนติดตั้ง

เลือกรีโพสิทอรีในแถบด้านซ้าย สกิลของมันจะปรากฏเป็นตารางการ์ดทางขวา
พร้อมช่องตัวกรองด้านบนที่จำกัดแค็ตตาล็อกตามชื่อ คำอธิบาย หรือ slug คลิกการ์ด
เพื่อเปิดมุมมองรายละเอียด ซึ่งแสดงสามอย่าง:

- **README** ที่เรนเดอร์เป็น markdown — `README.md` ของไดเรกทอรีสกิล หรือ
  เนื้อหา `SKILL.md` เมื่อไม่มี README
- **ตัวอย่างการสแกน** — คำตัดสิน (`pass`, `warn` หรือ `quarantine`)
  ความสามารถที่เนื้อหาของสกิลประกาศไว้ (รันเชลล์ เขียนไฟล์ เข้าถึงเครือข่าย…)
  และข้อค้นพบทุกข้อที่ตัวสแกนบันทึกไว้
- **จำนวนไฟล์** — การติดตั้งจะเขียนไดเรกทอรีทั้งหมดของสกิล ไม่ใช่แค่
  `SKILL.md` ของมัน

ตัวอย่างนี้สแกนไบต์ชุดเดียวกับที่การติดตั้งจะเขียน ดังนั้นคำตัดสินที่คุณเห็นคือ
คำตัดสินที่การติดตั้งจะได้รับ ไม่มีสิ่งใดถูกตัดสินใหม่ลับหลังคุณ

## ติดตั้งสกิล

1. เปิดมุมมองรายละเอียดของสกิล
2. อ่านคำตัดสินการสแกน สำหรับคำตัดสิน `warn` หรือ `pass` ให้กด **ติดตั้ง**
3. สำหรับคำตัดสิน `quarantine` ปุ่มติดตั้งจะยังใช้ไม่ได้จนกว่าคุณจะติ๊ก
   **เข้าใจความเสี่ยง — ติดตั้งต่อไป** การข้ามนี้ถูกบันทึกไว้ ไม่ใช่สันนิษฐาน

การติดตั้งจะเขียนไดเรกทอรีของสกิลลงในเวิร์กสเปซ บันทึกหมุดใน
`skills-lock.json` (รีโพสิทอรีต้นทาง พาธ คอมมิตที่มันมาจาก และแฮชเนื้อหา)
และสกิลจะพร้อมใช้กับเอเจนต์ในเวิร์กสเปซ การ์ดที่ทำเครื่องหมาย **ชื่อนี้ถูกใช้แล้ว**
หมายความว่าสกิลอื่นเป็นเจ้าของชื่อนั้นในเครื่องอยู่แล้ว — ถอนการติดตั้งตัวนั้นก่อน

## อัปเดตสกิลเมื่อเวลาผ่านไป

การ์ดของสกิลที่ติดตั้งแล้วมีป้าย: **ติดตั้งแล้ว** หรือ **มีอัปเดต**
เมื่อรีโพสิทอรีเดินหน้าไปไกลกว่าคอมมิตที่คุณปักหมุดไว้ เปิดมุมมองรายละเอียด
แล้วกด **อัปเดต** เพื่อดึงใหม่ที่คอมมิตใหม่ การอัปเดตผ่านด่านสแกนเดียวกับการติดตั้ง
— สกิลที่เวอร์ชันใหม่ถูกกักกันจะถูกปฏิเสธ และเวอร์ชันที่คุณมีอยู่จะคงเดิม
แฮชของเวอร์ชันเก่าถูกเก็บไว้เป็นข้อมูลอ้างอิงสำหรับย้อนกลับในไฟล์ล็อก

## ถอนการติดตั้งสกิล ลบรีโพสิทอรีออก

**ถอนการติดตั้ง** (บนมุมมองรายละเอียดของสกิลที่ติดตั้งแล้ว หรือลบในแท็บ
ติดตั้งแล้ว) จะลบไดเรกทอรีของสกิลและหมุดในไฟล์ล็อกไปพร้อมกัน — สกิลที่ถอน
การติดตั้งแล้วไม่เหลืออะไรไว้ข้างหลัง

**การลบรีโพสิทอรี** ออกจากแถบด้านซ้ายลบเฉพาะแค็ตตาล็อก: สกิลที่คุณติดตั้งจากมัน
ยังคงติดตั้งอยู่และยังอัปเดตได้ เพราะหมุดบันทึกรีโพสิทอรีด้วยชื่อ ไม่ใช่ด้วย
การอ้างอิงถึงรายการต้นทาง เพิ่มรีโพสิทอรีกลับหากคุณต้องการเรียกดูมันอีกครั้ง

## เรียกใช้สกิล

สกิลถูกเรียกใช้ภายใต้เนมสเปซของตัวเอง จึงไม่ชนกับคำสั่งสแลชในตัว
(`/plan`, `/goal`, `/loop`, `/compact`):

- `/skill:<name>` — สกิลที่ติดตั้งในเวิร์กสเปซนี้ หรือที่แนบกับเอเจนต์
- `/skill:<repo>:<name>` — สกิลที่รีโปซึ่งเช็กเอาต์ในสเปซนี้จัดส่งมา

ชื่อเปล่า ๆ ที่ไม่ใช่คำสั่งในตัวยังคงแปลงได้ สำหรับข้อความที่เขียนไว้ก่อนที่
เนมสเปซจะมีอยู่ `/skill:plan` คือสิ่งที่ไปถึงสกิลชื่อ `plan`; `/plan`
เป็นคำสั่งในตัวเสมอ

## สกิลที่จำกัดขอบเขตตามรีโป

รีโปที่เช็กเอาต์มาสามารถจัดส่งสกิลของตัวเองได้ ใน `.agents/skills/`,
`.agent/skills/`, `.claude/skills/`, `.opencode/skills/` หรือ `skills/` เหล่านั้น
**ไม่**ได้ติดตั้งผ่านหน้านี้ เอเจนต์ถือเฉพาะสกิลของรีโปที่มันกำลังทำงานอยู่เท่านั้น
พวกมันจะสลับไปเมื่อมันย้าย ช่องเขียนข้อความไม่ได้จำกัดขอบเขตแบบนั้น:
`/skill:<repo>:<name>` ไปถึงรีโปใดก็ได้ในสเปซ

สกิลของรีโปผ่านการสแกนแบบปิดเมื่อล้มเหลวเช่นเดียวกัน
(`pass` / `warn` / `quarantine`) ก่อนที่ฟรอนต์แมตเทอร์ของมันจะไปถึงพรอมต์
`warn` ผ่านเข้าได้ ส่วน `quarantine` ถูกระงับไว้ โดยไม่มีทางข้ามของผู้ปฏิบัติการ
บนเส้นทางนั้น
