คู่มือนี้แสดงวิธีกลับไปยังจุดก่อนหน้าในการสนทนาแล้วพาไปอีกทางหนึ่ง — โดยที่เส้นทางที่คุณจากมายังอยู่ครบ

## เรื่องเดียวที่ควรรู้

**การแยกสาขาไม่เขียนอะไรเลย** บทสนทนาคือต้นไม้ของข้อความที่มีตัวชี้อยู่ที่ปลาย การย้อนกลับจึงเป็นการเลื่อนตัวชี้ ไม่มีอะไรถูกลบ ไม่มีอะไรถูกซ่อน และการสลับกลับก็คือการเลื่อนตัวชี้อีกครั้ง

นั่นคือเหตุผลที่การแก้พรอมต์แล้วรันใหม่ปลอดภัยตรงนี้: คำตอบที่คุณกำลังเทียบอยู่ยังอยู่ตรงนั้น

## ดูสาขาทั้งหมด

```
/tree
```

ตัวนำทางจะแสดงข้อความทุกข้อความ โดยเยื้องในแต่ละจุดที่แยก และทำเครื่องหมายเส้นทางปัจจุบันว่า **อยู่บนสาขานี้** บทสนทนาที่ไม่เคยแยกจะแสดงเป็นรายการแบนอย่างที่มันเคยเป็น — ตัวนำทางไม่มีต้นทุนอะไรในการมอง จนกว่าจะมีอะไรให้สำรวจ

แต่ละแถวเสนอการกระทำสองอย่าง

| การกระทำ                        | ผลลัพธ์                                                      |
| ------------------------------- | --------------------------------------------------------- |
| **ทำต่อจากที่นี่**               | เลื่อนตัวชี้ ข้อความถัดไปของคุณจะทำต่อจากข้อความนั้น             |
| **แยกเป็นการสนทนาใหม่**          | คัดลอกเส้นทางจนถึงข้อความนั้นไปยังบทสนทนาใหม่                   |

## แยกสาขา: ลองแนวทางอื่น

1. `/tree`
2. หาข้อความที่คุณอยากเริ่มต้นใหม่อีกครั้งจากมัน — ปกติคือข้อความสุดท้ายที่คุณพอใจ
3. **ทำต่อจากที่นี่**
4. พิมพ์พรอมต์ใหม่

ส่วนต่อของเดิมยังอยู่ในต้นไม้ ตอนนี้ `/tree` จะแสดงสองเส้นทางจากจุดนั้น และคุณสลับไปมาระหว่างทั้งสองได้อย่างอิสระ

:::note[เส้นทางที่คุณจากมายังอยู่ตรงนั้น]
การแยกสาขาไม่ได้ซ่อนหรือลบอะไรเลย `/tree` แสดงทุกเส้นทาง ทำเครื่องหมายเส้นทางปัจจุบันว่า **อยู่บนสาขานี้** และเป็นวิธีที่คุณใช้สลับ
:::

## แยก: พาไปที่อื่น

การแยกจะคัดลอกเส้นทางไปยัง **บทสนทนาใหม่** ในสเปซเดียวกัน ใช้เมื่อทิศทางทั้งสองจะแยกออกจากกันไปเรื่อย ๆ และคุณอยากให้มันอยู่เคียงข้างกันมากกว่าจะสลับไปมา

สำเนามี id ข้อความใหม่ บทสนทนาสองอันที่ใช้แถวร่วมกันจะแสดงข้อความถัด ๆ ไปของกันและกัน ซึ่งเป็นสิ่งที่การแยกมีขึ้นมาเพื่อป้องกันพอดี

## การย้อนกลับกับการแยกสาขา

มันเป็นเครื่องมือคนละอย่าง และความต่างนั้นสำคัญ

|                     | การย้อนกลับ                                        | การแยกสาขา                      |
| ------------------- | -------------------------------------------------- | ------------------------------- |
| ข้อความหลังจากนั้น  | ถูกซ่อนจากทรานสคริปต์                                | ยังมองเห็นได้ใน `/tree`           |
| **worktree**        | ย้อนกลับไปยังสแนปช็อตของเทิร์นนั้น                     | ไม่ถูกแตะต้อง                    |
| เลิกทำ              | **เลิกย้อน** คืนชุดการเปลี่ยนแปลงนั้น                 | เลื่อนตัวชี้กลับ                  |

การย้อนกลับคือสิ่งที่คุณต้องการเมื่อเอเจนต์แก้ *ไฟล์* ที่คุณอยากได้คืน การแยกสาขาคือสิ่งที่คุณต้องการเมื่อการสนทนาไปผิดทางแต่ไฟล์ยังดีอยู่

การย้อนกลับยังเลื่อนปลายสาขาด้วย ข้อความถัดไปของคุณจึงทำต่อจากจุดที่ถูกต้อง แทนที่จะทำต่อจากหางที่ไม่มีใครมองเห็นอีกแล้ว

## นำออกจากแอป

### `/export`

เขียน **ไฟล์ HTML ที่ครบในตัวเอง**: บทสนทนาทั้งหมดพร้อมการ์ดเครื่องมือที่พับได้ ซึ่งแสดงว่าแต่ละการเรียกได้รับอะไรมาบ้างและคืนอะไรกลับไป ไม่มีสไตล์ชีต ไม่มีสคริปต์ ไม่มีโฮสต์รูปภาพ — มันใช้งานได้จากแฟลชไดรฟ์ USB และใช้ได้แม้อีกห้าปีข้างหน้า

- **เดสก์ท็อป:** `Documents/ControlCenter/exports/` ประทับเวลากำกับ การนำออกครั้งที่สองจึงไม่ทับครั้งแรก
- **เว็บ:** ดาวน์โหลดผ่านเบราว์เซอร์

### `/dump`

คัดลอกทรานสคริปต์ไปยังคลิปบอร์ดในรูปแบบมาร์กดาวน์ โดยการเรียกเครื่องมืออยู่ในบล็อกที่พับได้ อันนี้คืออันที่ควรเอาไปแปะใน issue

การให้เหตุผลถูกตัดออกโดยเจตนา: มันเป็นพื้นที่ทดของโมเดล และรายงานบั๊กมีไว้ให้คนอ่าน
