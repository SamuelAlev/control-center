คู่มือนี้แสดงวิธีสร้างทีม กำหนดหัวหน้าให้ทีม และส่งงานไปยังทีม

ทีมคือกลุ่มเอเจนต์ที่มีชื่ออยู่ในเวิร์กสเปซเดียว โดยมีเอเจนต์หนึ่งตัวที่ถูกกำหนดเป็น **หัวหน้า** เมื่อมอบตั๋วงานให้ทีม หัวหน้าจะถูกปลุกให้ตื่น แล้วแยกงานออกเป็นส่วนย่อยและมอบหมายให้สมาชิก เมื่อการรันของสมาชิกเสร็จสิ้น หัวหน้าจะถูกปลุกอีกครั้งเพื่อตัดสินใจว่าจะทำอะไรต่อไป

สร้าง เปลี่ยนชื่อ และกำหนดสมาชิกของทีมได้ที่ **การตั้งค่า → เวิร์กสเปซ → เอเจนต์ → ทีม** ส่งงานไปยังทีมได้สองวิธี: เอเจนต์เรียก `assign_ticket` พร้อม `team_id` ของทีมนั้น หรือโหนด **Team dispatch** ของไปป์ไลน์จัดส่งทีม (โดยไม่มอบตั๋วงาน) ตัวเลือกผู้รับมอบหมายของตั๋วงานจะแสดงคุณและเอเจนต์แต่ละตัว

## สร้างทีม

1. เปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** (`/settings/workspace/agents`)
2. คลิก **ทีม** ที่ส่วนหัวของหน้า
3. คลิก **เพิ่มทีม**
4. ป้อน **ชื่อ** (ตัวอย่างเช่น "backend" หรือ "review squad") และ **คำอธิบาย** ซึ่งไม่บังคับ แล้วคลิก **สร้าง**

ทีมจะถูกสร้างและเลือกไว้ และตัวแก้ไขของทีมจะเปิดขึ้นในบานหน้าต่างด้านขวา

## กำหนดหัวหน้า

นี่คือขั้นตอนที่ฟีเจอร์ทั้งหมดนี้พึ่งพา ในตัวแก้ไขของทีม:

1. ใต้ **หัวหน้า** เลือกเอเจนต์หนึ่งตัว ข้อความช่วยเหลืออธิบายไว้อย่างชัดเจนว่า "ผู้ประสานที่รับงานของทีมและมอบหมายให้สมาชิกที่เหมาะสมที่สุด"
2. เติม **คำสั่งการทำงาน** ตามต้องการ — ข้อความอิสระที่ส่งให้หัวหน้าพร้อมกับตั๋วงานทุกใบที่ถูกส่งมา

การเลื่อนเอเจนต์ขึ้นเป็นหัวหน้าจะทำให้มันกลายเป็นสมาชิกด้วยหากยังไม่ได้เป็นอยู่แล้ว ทีมที่ตั้งค่าไว้ที่ **ไม่มีหัวหน้า** จะไม่ทำงาน: ไม่มีอะไรถูกจัดส่งเมื่อมีงานส่งมาที่ทีม และการถอดหัวหน้าคนปัจจุบันออกจากรายชื่อสมาชิกจะทำให้ทีมกลับไปไม่มีหัวหน้าอีกครั้ง

## เพิ่มสมาชิก

ในตัวแก้ไขเดียวกัน ใช้การ์ดสมาชิกเพื่อเพิ่มเอเจนต์จากเวิร์กสเปซและถอดเอเจนต์ออก สมาชิกคือรายชื่อที่หัวหน้าใช้ในการมอบหมายงาน

ทีมมีขอบเขตอยู่ที่เวิร์กสเปซ: เฉพาะเอเจนต์ในเวิร์กสเปซนี้เท่านั้นที่เข้าร่วมได้

## ให้สเปซกับทีม

ไม่มีสเปซของทีมโดยอัตโนมัติ หากคุณต้องการสเปซ ให้สร้างสเปซธรรมดาจาก **สเปซ** แล้วเพิ่มเอเจนต์ของทีมเข้าไปในนั้น `Team` เก็บชื่อ คำอธิบาย หัวหน้า คำสั่ง และสมาชิก — ไม่มีความเชื่อมโยงกับสเปซ

## สายการรายงานเป็นเรื่องแยกต่างหาก

เอเจนต์แต่ละตัวยังมีฟิลด์ **รายงานต่อ** ซึ่งตั้งค่าได้ใน **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** ฟิลด์นี้สร้างโครงสร้างต้นไม้การรายงานของเวิร์กสเปซ ซึ่งดูได้จากปุ่ม **ผังองค์กร** บนหน้าเอเจนต์

ฟิลด์นี้ไม่ได้ขับเคลื่อนการส่งงานของทีม หัวหน้าเลือกผู้รับมอบหมายจากรายชื่อสมาชิกของทีมตามทักษะและบทบาท ไม่ใช่จากสายการรายงาน สิทธิ์การเข้าถึงหน่วยความจำผูกกับบทบาทของเอเจนต์ ไม่ใช่สายการรายงาน และไม่มีพื้นผิวการวิเคราะห์ใดรวมข้อมูลตามทีมหรือลำดับชั้น ตัวป้องกันการมอบหมายจำกัดความลึกและตรวจจับวงจร แต่ไม่เคยกำหนดให้เป้าหมายต้องเป็นผู้ใต้บังคับบัญชา

## สิ่งที่ตั๋วงานที่ถูกส่งมาทำ

เมื่อตั๋วงานมีการมอบหมายให้ทีมจริง:

1. หัวหน้าของทีมถูกจัดส่งพร้อมกับตั๋วงาน คำสั่งการทำงาน และรายชื่อสมาชิก
2. หัวหน้ามอบหมายงานให้สมาชิกและบันทึกการประเมินด้วยเครื่องมือ `record_team_activity` — `action` (มอบหมายแล้ว), `no_action` (ไม่มีอะไรต้องทำต่อ ซึ่งจะหยุดการทริกเกอร์ซ้ำต่อไป) หรือ `failed`
3. การรันของสมาชิกแต่ละครั้งที่เสร็จสิ้นจะปลุกหัวหน้าอีกครั้ง โดยมีตัวป้องกัน no-action เป็นขอบเขต

โหนด **Team dispatch** ของไปป์ไลน์เป็นจุดเข้าอีกทางหนึ่ง โหนดนี้รับ ID ทีม พรอมต์ และโหมดการจัดส่ง:

- `allParallel` — หนึ่งงานต่อสมาชิกหนึ่งคน เข้าสู่บทสนทนาที่ซ่อนอยู่ร่วมกัน โดยระงับไว้จนกว่าทุกการรันจะเสร็จสิ้น และเอาต์พุตของสมาชิกแต่ละคนถูกเก็บไว้ใต้คีย์เอาต์พุตของโหนด
- `manager` — จัดส่งเฉพาะหัวหน้า ซึ่งประสานงานอยู่ในบทสนทนา
