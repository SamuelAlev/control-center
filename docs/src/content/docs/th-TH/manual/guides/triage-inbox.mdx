คู่มือนี้แสดงวิธีทำงานกับกล่องขาเข้า: พื้นผิวเดียวที่รวมทุกอย่างที่บล็อกคุณหรือ
ร้องขอคุณอย่างชัดเจน — การอนุมัติของเอเจนต์ที่ค้างอยู่ การซิงค์ตั๋วงานที่ล้มเหลว
และ pull request ทุกใบที่เกี่ยวข้องกับคุณในฐานะผู้รีวิวหรือผู้เขียน

## เปิดกล่องขาเข้า

1. คลิก **กล่องขาเข้า** ในแถบข้าง ป้ายตัวเลขของมันนับการอนุมัติของเอเจนต์ที่
   ค้างอยู่ การซิงค์ที่ล้มเหลว และ PR ที่เปิดอยู่ซึ่งรอการรีวิวของคุณ
2. หรือกด <kbd>⌘K</kbd> แล้วรันคำสั่งนำทาง **กล่องขาเข้า**
3. หรือลิงก์ตรงไปที่ `/workspaces/<workspace-id>/inbox`

รายการในแถบข้างแสดงจำนวนสดเสมอ คุณจึงเห็นงานคัดแยกสะสมได้โดยไม่ต้องเปิดหน้า

## อ่านความรุนแรงได้ในพริบตา

ไล่จากบนลงล่าง กล่องขาเข้าเรียงตามความเร่งด่วนอยู่แล้ว:

1. แถบ **ต้องการความสนใจของคุณ** ที่ปักหมุดไว้อยู่เหนือส่วนต่าง ๆ ของ PR
   ทุกการ์ดมีชิปความรุนแรง แหล่งที่ลงทะเบียนไว้ (เอเจนต์ที่ติดอยู่ที่พรอมป์ต์
   ยืนยัน การซิงค์ตั๋วงานที่มีมิเรอร์จากผู้ให้บริการล้าสมัย) จะส่ง **ถูกบล็อก**
2. ภายในแถบ ความรุนแรงที่เร่งด่วนที่สุดมาก่อน เสมอกันให้รายการที่รอนานที่สุด
3. ใต้แถบลงมา PR ถูกจัดกลุ่มเป็นส่วนตามวงจรชีวิตการรีวิวแบบตายตัว —
   **ต้องการการรีวิวของคุณ**, **คืนมาให้คุณ**, **อนุมัติแล้ว**, **ฉบับร่าง**,
   **รอผู้รีวิว**, **กำลังรวมและรวมล่าสุด**, **รอผู้เขียน** ส่วนบนคือสิ่งที่ต้อง
   การ _คุณ_ ส่วนที่เหลือคือสถานะของ PR _ของคุณ_ **ต้องการการรีวิวของคุณ** รวม
   PR ที่ยังร้องขอทีมที่คุณสังกัดอยู่บน forge ที่รองรับทีม (GitHub จะตัดทีมทิ้ง
   เมื่อสมาชิกทีมคนใดรีวิว)

รายการจะตกเข้ากล่องขาเข้าเมื่อมันบล็อกอะไรบางอย่างหรือร้องขอคุณอย่างชัดเจนเท่านั้น
แถบว่างบวกรายการส่วนที่ว่างจะแสดง **คุณตามทันหมดแล้ว** เฉพาะเมื่อความว่างนั้น
เชื่อถือได้

## กล่องขาเข้าเดียวครอบทุก forge

หากเวิร์กสเปซมีรีโปอยู่บนโฮสต์โค้ดมากกว่าหนึ่ง กล่องขาเข้าจะรวมมันเป็นสตรีมเดียว —
pull request จาก GitHub กับ pull request จาก Bitbucket อยู่ในส่วนเดียวกัน เรียง
ตามเวลา มิได้จัดกลุ่มตามผู้ให้บริการ เมตา `repo #number` ของแถวคือสิ่งที่แยก
สองอันนั้นออกจากกัน

"ของคุณ" ถูกตัดสิน **ต่อ forge** เพราะคุณเป็นบัญชีที่ต่างกันในแต่ละแห่ง
pull request จะนับเป็นของคุณ หรือนับว่าร้องขอการรีวิวของคุณ เฉพาะเมื่อมันตรงกับ
ตัวตนของคุณบน forge ที่รีโปนั้นอยู่จริง

forge ที่ล่มหรือยังไม่เชื่อมต่อจะไม่ส่งอะไรเข้ามา และปล่อยให้ส่วนอื่นของ
กล่องขาเข้าไม่เสียหาย — การเชื่อมต่อที่พังจุดเดียวไม่เคยทำให้ทั้งลิสต์ว่างเปล่า
สถานะว่างจะบอกข้อแม้แทน **คุณตามทันหมดแล้ว** เมื่อการลงชื่อเข้าใช้ forge ทุกแห่ง
ยังแก้ไม่สำเร็จ (**ยืนยันบัญชี GitHub ของคุณไม่ได้** — ข้อความยังคงระบุชื่อ GitHub)
เมื่อ githubstatus.com รายงานเหตุขัดข้อง หรือเมื่อการติดตั้ง GitHub App ที่
ครอบคลุมรีโปที่เชื่อมไว้ถูกระงับ

## เคลียร์แถบความสนใจ

การ์ดในแถบแต่ละใบมีการกระทำถัดไปหนึ่งอย่าง:

1. หากการ์ดเป็นการยืนยันของเอเจนต์ที่ค้างอยู่ ให้คลิก **รีวิว** — คุณจะไปที่
   สเปซของเอเจนต์นั้นพร้อมการยืนยันที่ค้างอยู่ อนุมัติหรือปฏิเสธที่นั่น
   (ดู [แชทกับเอเจนต์](/th-TH/คู่มือ/วิธีทำ/แชทกับเอเจนต์/))
2. หากการ์ดเขียนว่า **ซิงค์ไม่สำเร็จ** สำหรับผู้ให้บริการรายหนึ่ง ให้คลิก **เปิด**
   — คุณจะไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** ซึ่งการ์ด
   **สุขภาพการซิงค์** แสดงการซิงค์ล่าสุดของแต่ละการเชื่อมต่อ จำนวนครั้งที่
   ล้มเหลวติดต่อกัน และผลลัพธ์ล่าสุด มีเพียงความล้มเหลวล่าสุดต่อผู้ให้บริการ
   หนึ่งรายเท่านั้นที่ปรากฏในกล่องขาเข้า การซิงค์ที่ฟื้นตัวจึงเคลียร์การ์ดไป
3. การ์ดหายไปเองเมื่อสถานะเบื้องหลังคลี่คลาย (เอเจนต์ได้รับคำตอบ การซิงค์ฟื้นตัว)
   — ไม่มีอะไรให้ปิดทิ้งด้วยมือ

:::note[นี่คือการยืนยันต่อเทิร์น ไม่ใช่การอนุมัติเชิงธรรมาภิบาล]
การ์ด "การอนุมัติของเอเจนต์" คือเอเจนต์ที่กำลังรันอยู่หยุดชั่วคราวเพื่อขออนุญาต
สำหรับการกระทำหนึ่งอย่าง ในบทสนทนาของมันเอง มันเป็นคนละเรื่องกับเรกคอร์ด
`Approval` เชิงธรรมาภิบาลที่เอเจนต์สร้างด้วยเครื่องมือ MCP การอนุมัติ — พวกนั้น
ไม่มีหน้าจอสำหรับมนุษย์ที่ไหนในแอปเลย และไม่เคยปรากฏที่นี่
:::

:::caution[สุขภาพการซิงค์เป็นแบบอ่านอย่างเดียว]
การ์ดรายงานเกี่ยวกับการเชื่อมต่อการซิงค์ตั๋วงาน นอกจากปุ่ม **ซิงค์ตอนนี้** แล้ว
มันสร้าง แก้ไข หรือเชื่อมต่อใหม่ไม่ได้ และไม่มีหน้าจออื่นที่ทำได้เช่นกัน เมื่อยัง
ไม่ได้ตั้งค่าการเชื่อมต่อใด ๆ มันก็แค่อ่านว่า "ยังไม่มีการเชื่อมต่อซิงค์" ซึ่งเป็น
สิ่งที่เวิร์กสเปซใหม่แสดง
:::

## กรองให้เหลือเฉพาะสิ่งที่บล็อกอยู่

1. กด <kbd>f</kbd> (โดยไม่มีช่องข้อความใดถูกโฟกัส) เพื่อเปิดเมนูตัวกรอง หรือ
   คลิกปุ่มตัวกรองในแถบเครื่องมือ
2. เลือกผสมใด ๆ ของสถานะ ผู้เขียน ผู้รีวิว เนื้อหา เจ้าของ/ชื่อรีโป ช่วงวันที่
   หรือรีวิวเร็ว จำนวนแง่มุมในเมนูแสดงว่าตัวเลือกแต่ละอย่างตรงกับรายการใน
   กล่องขาเข้ากี่รายการ
3. ตัวกรองที่ใช้งานอยู่จะปรากฏเป็นชิปในแถบเหนือรายการ คลิก ✕ ของชิปเพื่อยกเลิก
   เกณฑ์นั้น
4. ใช้แถบด้านซ้ายเพื่อกระโดดระหว่างส่วน — แต่ละรายการแสดงจำนวนสด และไฮไลต์
   ติดตามตำแหน่งเลื่อนของคุณ คลิกหัวข้อส่วนเพื่อยุบส่วนที่คุณไม่ได้คัดแยก
   (เช่น **ฉบับร่าง** ขณะเคลียร์รีวิว)
5. คลิกหัวคอลัมน์ (ชื่อเรื่อง การเปลี่ยนแปลง หรืออัปเดตแล้ว) เพื่อเรียงทุกส่วน
   คลิกคอลัมน์ที่ใช้งานอยู่อีกครั้งเพื่อสลับทิศทาง ปุ่มตัวเลือกการแสดงผลควบคุม
   การมองเห็นฉบับร่าง หน้าต่างที่รวมล่าสุด คุณสมบัติของแถว การเรียงลำดับ และ
   การจัดกลุ่ม (มีเพียงการจัดกลุ่มตามผู้เขียนที่เปลี่ยนเลย์เอาต์ของกล่องขาเข้า)

ตัวกรองที่นี่เป็นอิสระจากคิว PR — การจำกัดขอบเขตกล่องขาเข้าไม่เคยเปลี่ยนตัวกรอง
ของคิว และในทางกลับกันก็เช่นกัน

## ลงมือกับรายการ PR

1. คลิกแถวใดก็ได้เพื่อเปิดหน้ารายละเอียด PR
2. หาก PR อยู่ใน **ต้องการการรีวิวของคุณ** ให้รีวิวและส่งคำตัดสินของคุณ — ดู
   [รีวิวและรวม PR](/th-TH/คู่มือ/วิธีทำ/รีวิวและรวม-pr/)
3. หาก PR อยู่ใน **คืนมาให้คุณ** (ขอให้แก้ไขหรือ CI ล้มเหลว) ให้พุชการแก้ไขจาก
   เช็คเอาท์ของคุณ หรือยกงานต่อให้เอเจนต์
4. หาก PR อยู่ใน **อนุมัติแล้ว** ให้รวมมันจากหน้ารายละเอียด
5. หากคุณอยากมอบหมายการรีวิวมากกว่าทำเอง ดู
   [สั่งงานเอเจนต์รีวิวเวอร์](/th-TH/คู่มือ/วิธีทำ/สั่งงานรีวิวเวอร์/) และ
   [วงจรชีวิตการสั่งงาน](/th-TH/คู่มือ/แนวคิด/วงจรชีวิตการสั่งงาน/)

เมื่อสถานะเบื้องหลังเปลี่ยน (รีวิวของคุณเข้าที่ PR ถูกรวม) ตัวจำแนกจะจัด PR
เข้าส่วนใหม่โดยอัตโนมัติ

## เลิกทำการกระทำที่พลาดไป

1. กด <kbd>⌘Z</kbd> เพื่อเลิกทำการกระทำล่าสุด กด <kbd>⌘⇧Z</kbd> เพื่อทำซ้ำ
2. หากช่องข้อความถูกโฟกัส ⌘Z จะแก้ข้อความในช่องแทน — คลิกออกจากช่องก่อนเพื่อ
   เลิกทำการกระทำระดับแอป

## ดูทางลัดในที่

กด <kbd>?</kbd> (โดยไม่มีช่องข้อความใดถูกโฟกัส) เพื่อเปิดแผ่นสรุปทางลัดแป้นพิมพ์
มันแสดงทุกการผูกปุ่มที่ใช้งานบนเส้นทางปัจจุบัน รวมถึงทางลัดตัวกรอง <kbd>f</kbd>
ของกล่องขาเข้า แผนที่เต็มอยู่ใน
[เอกสารอ้างอิงทางลัดแป้นพิมพ์](/th-TH/คู่มือ/อ้างอิง/ทางลัดแป้นพิมพ์/)

## ขับเคลื่อนด้วยจานคำสั่ง

1. กด <kbd>⌘K</kbd> ที่ไหนก็ได้เพื่อเปิดจานคำสั่ง
2. พิมพ์ **กล่องขาเข้า** เพื่อกระโดดไปที่หน้า หรือพิมพ์ชื่อเรื่อง PR —
   จานคำสั่งจะแสดง pull request ที่ตรงกันและเปิดอันที่คุณเลือก
3. ขณะกล่องขาเข้าเปิดอยู่ รัน **คัดลอกลิงก์ไปหน้านี้** เพื่อคัดลอก URL นั้นไว้
   แชร์ คำสั่งนี้คัดลอกเส้นทางปัจจุบัน จึงเป็น URL ของกล่องขาเข้าเฉพาะเมื่อคุณอยู่
   บนหน้านี้

## รีเฟรชเมื่อต้องการ

กล่องขาเข้าอัปเดตสด แต่หากคุณสงสัยว่าข้อมูลล้าสมัย ให้คลิกตัวควบคุมรีเฟรชใน
แถบเครื่องมือ — มันบังคับให้เซิร์ฟเวอร์กวาดทุก forge ที่เชื่อมต่อทันที และดึง
โอเวอร์เลย์ที่รวม/รีวิวแล้วมาใหม่ ไอคอนจะหมุนจนทุกการดึงข้อมูลเสร็จสิ้น
