คู่มือนี้แสดงวิธีบันทึกการประชุมและรับบันทึกสรุปที่สร้างโดย AI
ดู [การประชุมและการถอดเสียง](/th-TH/คู่มือ/แนวคิด/การประชุม/) เพื่อทำความเข้าใจกลไกการทำงาน

## ก่อนเริ่ม

- **รอบลโมเดลเสียง แล้วรีสตาร์ตเซิร์ฟเวอร์** การบูตตามปกติจะบังคับติดตั้งโมเดล
  ASR ที่เลือกไว้ (Parakeet TDT 0.6B v3 ซึ่งเป็นค่าเริ่มต้นแบบหลายภาษา
  ขนาดประมาณ 600 MB) ในเบื้องหลัง เซิร์ฟเวอร์แปลงพาธของโมเดล
  **ครั้งเดียวตอนบูต** การรันครั้งแรกจึงยังบันทึกไม่ได้จนกว่าคุณจะรีสตาร์ต
  หากไม่มีโมเดลอยู่บนดิสก์ การบันทึกจะล้มเหลวโดยขึ้นข้อความ `Could not start
  recording on the host: …` หากต้องการเลือกบิลด์อื่น ให้ไปที่ **การตั้งค่า →
  เซิร์ฟเวอร์ → โมเดลเสียงและการประชุม** ซึ่งก็ต้องรีสตาร์ตเช่นกัน
- อนุญาตสิทธิ์ **ไมโครโฟน** เมื่อระบบปฏิบัติการขอตอนบันทึกครั้งแรก
- บน **macOS 14.4+** เสียงระบบถูกเก็บด้วย Core Audio process taps — ไม่ต้องติดตั้งไดรเวอร์ แต่ระบบปฏิบัติการจะขอสิทธิ์ _การเก็บเสียง_ เป็นครั้งที่สอง ซึ่งไม่ใช่ Screen Recording และไม่ทำให้ไฟแสดงการบันทึกหน้าจอติดเลย หากปฏิเสธ การเริ่มบันทึกจะล้มเหลวโดยขึ้นข้อความ `System-audio capture permission denied.` ส่วน macOS ที่ต่ำกว่า 14.4 ไม่มีการเก็บเสียงระบบ
- บน **Linux** ต้องมี `parecord` (pulseaudio-utils) หรือ `pw-record` (pipewire) อยู่ใน `PATH` — การเก็บเสียงจะเรียกใช้ตัวใดตัวหนึ่งกับมอนิเตอร์ซอร์สของ PipeWire/PulseAudio หากไม่มีทั้งสอง การเริ่มบันทึกจะล้มเหลวโดยขึ้นข้อความ `No system-audio capture tool found`

:::caution[เสียงการประชุมของคุณไปที่ไหน]
การเก็บเสียง การถอดเสียง การตัดเสียงสะท้อน และการแยกผู้พูด ล้วนทำงาน
บนอุปกรณ์ โดยไม่มีการเรียกผ่านคลาวด์ — แต่คำว่า "อุปกรณ์" หมายถึง **โฮสต์ cc_server**
ซึ่งเป็นคนละเครื่องเมื่อคุณรันเซิร์ฟเวอร์ระยะไกล และบันทึกสรุปสุดท้ายก็คือ
การรันเอเจนต์ตามปกติ: ไปป์ไลน์ `meeting_summary` ส่งทรานสคริปต์ทั้งหมด
และโน้ตคร่าวๆ ของคุณไปยังผู้ให้บริการโมเดลที่เอเจนต์นั้นใช้อยู่ หากทรานสคริปต์
ต้องไม่ออกจากเครื่อง ให้ชี้เอเจนต์นั้นไปยังผู้ให้บริการภายในเครื่อง

หน้าจอบันทึกจะแจ้งเรื่องนี้ขณะคุณบันทึก การตัดสินใจจึงอยู่ตรงหน้าคุณก่อน
ที่จะมีทรานสคริปต์ให้ส่ง
:::

## เริ่มบันทึก

1. เปิด **การประชุม** ในแถบด้านข้าง
2. คลิก **บันทึกการประชุม** ระบบจะเปิด HUD การบันทึกสดที่ `/meetings/record`

การบันทึกเริ่มทันทีและเก็บเสียงไมโครโฟนของคุณบวกกับเสียงเอาต์พุตของระบบ —
นั่นคือผู้เข้าร่วมคนอื่นๆ ไม่มีหน้าจอให้เลือกโหมดและไม่มีตัวเลือกแหล่งเสียง:
โหมดไมค์เดียวแบบนั่งประชุมต่อหน้ามีอยู่ใน API แต่ยังไม่มี UI ในตอนนี้

ในเบราว์เซอร์ ขั้นตอนเดียวกันใช้ได้ แต่มีข้อต่างอยู่หนึ่งอย่าง: "เสียงระบบ" คือ
การแชร์หน้าจอที่ต้องมีแทร็กเสียงด้วย ให้แชร์แท็บของเบราว์เซอร์ (หรือทั้งหน้าจอ)
แล้วเปิด "Share tab audio" / "Share system audio" ในตัวเลือก Safari กับ Firefox
และการแชร์เต็มจอบน macOS มักให้แทร็กเสียงไม่ได้

HUD แสดงมาตรวัดระดับ เวลาที่ผ่านไป และทรานสคริปต์สดที่ค่อยๆ ต่อขึ้นทางด้านหนึ่ง

## ระหว่างการประชุม

- **จดโน้ตคร่าวๆ** ในบานหน้าต่างโน้ต โน้ตจะถูกบันทึกขณะคุณพิมพ์และส่งให้เอเจนต์สรุปในภายหลัง จึงควรจดทุกอย่างที่ทรานสคริปต์อาจพลาดไป
- **เลือกเทมเพลตบันทึก** ในแถว **เทมเพลตที่ใช้งาน** เทมเพลตนี้กำหนดรูปร่างของสรุปการประชุมครั้งนี้และถูกบันทึกไว้พร้อมกับการบันทึก การรันสรุปใหม่ในภายหลังจึงได้เทมเพลตเดียวกับที่คุณเลือกไว้ที่นี่
- **หยุดชั่วคราวและทำต่อ** ด้วยปุ่มหยุดชั่วคราว การถอดเสียงจะหยุดขณะพัก และตัวจับเวลาจะหยุดชั่วคราว
- ทรานสคริปต์สตรีมเข้ามาพร้อมแท็กผู้พูด: คำของคุณเป็น **คุณ** ทุกคนในสายเป็น **คนอื่น** — จนกว่าการแยกผู้พูดจะแบ่งคนอื่นออกเป็น `Person 1`, `Person 2`, … ซึ่งคุณเปลี่ยนชื่อได้

:::note[ผู้พูดที่เบามากอาจไม่ถูกถอดเสียง]
การถอดเสียงจะข้ามหน้าต่างเสียงใดก็ตามที่ไม่เคยสูงเกินเกณฑ์ความเงียบ
โดยไม่ถอดรหัสเลย วิธีนี้กันไม่ให้ช่องสัญญาณที่เบาไปเผา CPU
กับโทเคนที่ไม่ใช่คำพูดซึ่งโมเดลหลอนขึ้นมา แต่ก็หมายความว่าผู้พูดที่เบาหรือ
อยู่ไกลอาจไม่เกิดทรานสคริปต์เลย ควรตรวจมาตรวัดระดับตั้งแต่เนิ่นๆ ดีกว่าไปตรวจตอนท้าย
:::

## หยุดและสรุป

1. คลิก **หยุดและสรุป**
2. Control Center จะพาคุณไปที่มุมมองรายละเอียดของการประชุมทันที ซึ่งทำเครื่องหมายว่า **กำลังประมวลผล**: การแยกผู้พูดจะแบ่งช่องสัญญาณระยะไกลออกเป็นผู้พูดแต่ละคน และไปป์ไลน์ `meeting_summary` จะสร้างบันทึกสรุป
3. การประชุมจะเปลี่ยนเป็น **เสร็จแล้ว** เมื่อไปป์ไลน์นั้นทำงานเสร็จ คุณไม่จำเป็นต้องรอ — มุมมองรายละเอียดอัปเดตตัวเอง

## ตรวจทานบันทึกสรุป

รายละเอียดการประชุม (`/meetings/:meetingId`) มีสี่แท็บ:

| แท็บ             | มีอะไรอยู่                                                                       |
| ---------------- | ------------------------------------------------------------------------------- |
| **โน้ต**         | สรุปจาก AI และโน้ตที่เสริมแล้ว ซึ่งสร้างจากโน้ตคร่าวๆ ของคุณ + ทรานสคริปต์       |
| **ทรานสคริปต์**  | ทรานสคริปต์ทั้งหมดที่ติดแท็กผู้พูดพร้อมการประทับเวลา                              |
| **รายการดำเนินการ** | งานที่ต้องทำซึ่งถูกสกัดออกมา แต่ละรายการมีเจ้าของซึ่งไม่บังคับ                 |
| **การตัดสินใจ**  | การตัดสินใจที่บันทึกไว้ระหว่างการสนทนา                                           |

จากตรงนี้คุณสามารถ:

- **เปลี่ยนชื่อผู้พูด**: เปลี่ยน `Person 1` เป็นชื่อจริง การเปลี่ยนจะมีผลทั้งทรานสคริปต์
- **ติ๊กทำเครื่องหมายรายการดำเนินการ** เมื่อทำเสร็จ
- **สร้างตั๋วงาน** จากรายการดำเนินการ: ระบบจะสร้างตั๋วงานใหม่ที่ยังไม่มอบหมาย โดยใช้ชื่อรายการดำเนินการเป็นชื่อเรื่อง และลิงก์กลับมาที่แถวนั้น มอบหมายให้เอเจนต์ได้จากตัวตั๋วงานเอง (ดู [มอบงานให้เอเจนต์](/th-TH/คู่มือ/วิธีทำ/มอบหมายตั๋วงาน/))
- **รันสรุปใหม่** เพื่อสรุปอีกรอบ (เช่น หลังเปลี่ยนชื่อผู้พูด) ระบบจะใช้เทมเพลตที่บันทึกไว้ตอนบันทึกการประชุม เลือกเทมเพลตที่ใช้งานได้ที่ **การตั้งค่า → เวิร์กสเปซ → การประชุม**

การแก้ไขโน้ต ชื่อเรื่อง รายการดำเนินการ และการตัดสินใจ ทำได้ทุกที่
ส่วน **รันสรุปใหม่** และการยกเลิกการประชุมที่กำลังประมวลผลเป็น **เฉพาะเดสก์ท็อป** — ใน
เบราว์เซอร์ปุ่มทั้งสองไม่ทำงาน

## บันทึกจากเหตุการณ์ในปฏิทินโดยตรง

หากคุณ[เชื่อมต่อปฏิทิน](/th-TH/คู่มือ/วิธีทำ/เชื่อมต่อปฏิทิน/)แล้ว คุณข้าม
การเริ่มด้วยตนเองได้ ฟีเจอร์นี้ **เฉพาะเดสก์ท็อป** เท่านั้น ไคลเอนต์เว็บจะปฏิเสธ

1. เปิดเหตุการณ์จาก **ปฏิทิน**
2. คลิก **เริ่มบันทึกและลิงก์**

การบันทึกจะถูกตั้งชื่อเริ่มต้นตามชื่อเหตุการณ์และลิงก์กลับไปยังเหตุการณ์นั้น
โน้ตกับรายการในปฏิทินจึงยังเชื่อมโยงกันอยู่

:::note[การลบการประชุมไม่ได้ลบไฟล์เสียง]
การลบการประชุมจะลบเฉพาะแถวข้อมูล แต่ไฟล์ WAV ที่บันทึกไว้ใต้
`<dataDir>/meetings/<meetingId>/` ยังคงอยู่บนดิสก์ — ไม่มีนโยบายเก็บรักษา
ไม่มีเพดานขนาด และไม่มีการกวาดล้าง หากเสียงสำคัญ ให้ลบไดเรกทอรีนั้นด้วยตนเอง
:::
