คู่มือนี้แสดงวิธีให้เซิร์ฟเวอร์ของคุณมี GitHub App เป็นของตัวเอง ใช้เวลาประมาณสองนาที ให้เจ้าของเซิร์ฟเวอร์ทำเท่านั้น และทำเพียงครั้งเดียวต่อเซิร์ฟเวอร์

:::note[คุณอาจไม่จำเป็นต้องทำ]
เมื่อเปิด Control Center Connect ไว้ ผู้คนจะลงชื่อเข้าใช้ GitHub ผ่านแอปที่ใช้ร่วมกันของ Control Center หรือผ่านแอปที่องค์กรของคุณใช้กับ Connect ลงทะเบียนของคุณเองเมื่อคุณเลือก **ใช้แอปของฉันเอง**: แอปของเซิร์ฟเวอร์เองถูกใช้เฉพาะตอนนั้น ดู [Control Center Connect](/th-TH/คู่มือ/อ้างอิง/connect/)
:::

หากต้องการลงชื่อเข้าใช้บัญชีของคุณเองภายหลัง ดู[ตั้งค่าการผสาน GitHub](/th-TH/คู่มือ/วิธีทำ/การผสาน-github/)

## แอปนี้ทำอะไร

การลงทะเบียนครั้งเดียวตอบงานสองอย่างที่ต่างกัน:

| งาน                    | สิ่งที่ตอบ                                              | เหตุใดจึงสำคัญ                                                              |
| ---------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------- |
| **ให้คนลงชื่อเข้าใช้** | client id และ client secret ของแอป                      | ทุกคนได้ข้อมูลรับรอง GitHub ของตัวเองบนเซิร์ฟเวอร์ ในทุกอุปกรณ์           |
| **ให้เซิร์ฟเวอร์ทำงาน** | app id และ private key ของแอป                          | เอเจนต์ ไปป์ไลน์ ตัวโพลล์ และการตอบกลับของบอตได้โทเค็นสำหรับรีโปเดียวในแต่ละครั้ง |

งานที่สองไม่เคยยืมข้อมูลรับรองทั้งชุดของคนใดคนหนึ่ง โทเค็นแต่ละตัวที่เซิร์ฟเวอร์ออกครอบคลุมรีโปเดียว และจำกัดให้อยู่ในขอบเขตของสิ่งที่สมาชิกที่รับผิดชอบทำได้บนรีโปนั้น การอ่านรีโปที่เชื่อมแล้วต้องใช้แอปเท่านั้น ส่วนการเขียนใด ๆ ต้องมีสมาชิกที่มีสิทธิ์พุช การอนุมัติโดยระบบอัตโนมัติจะไม่เกิดขึ้นเด็ดขาด

แอปของเซิร์ฟเวอร์เองใช้ได้เฉพาะภายใต้ **ใช้แอปของฉันเอง** เมื่อใช้ Control Center Connect หรือ Connect แบบกำหนดเอง Connect จะให้บริการทุกช่องทาง รวมถึง GitHub และแอปของเซิร์ฟเวอร์จะยังถูกบันทึกไว้แต่ไม่ได้ใช้งานจนกว่าคุณจะสลับกลับ แอปของเวิร์กสเปซ ([ใช้แอปอื่นสำหรับเวิร์กสเปซหนึ่ง](#ใช้แอปอื่นสำหรับเวิร์กสเปซหนึ่ง)) ยังคงใช้ได้ในทุกโหมด แอปที่มีบางฟิลด์หายไปถือเป็นข้อผิดพลาด ไม่ใช่การถอยไปใช้ค่าอื่น: การลงชื่อเข้าใช้ GitHub จะถูกปฏิเสธจนกว่าทุกฟิลด์จะถูกตั้งค่า

## สิ่งที่ต้องมีก่อน

- คุณเป็น**เจ้าของเซิร์ฟเวอร์** การ์ด **แอปผู้ให้บริการ** จะมองไม่เห็นสำหรับคนอื่น
- บัญชี GitHub แอปจะถูกสร้างภายใต้บัญชีนี้
- ที่อยู่เซิร์ฟเวอร์ที่เบราว์เซอร์เข้าถึงได้ URL สาธารณะของเซิร์ฟเวอร์ (หรือ loopback สำหรับเซิร์ฟเวอร์ของเดสก์ท็อปเอง) คือที่ที่ GitHub จะส่งคุณกลับมา

## สร้างด้วยการคลิกครั้งเดียว

1. ไปที่ **การตั้งค่า → เซิร์ฟเวอร์ → ลงชื่อเข้าใช้ครั้งเดียว** แล้วเลื่อนลงไปยังการ์ด **แอปผู้ให้บริการ**
2. ในบล็อก **GitHub** ตัวเลือกคือพิมพ์องค์กร GitHub ที่ควรเป็นเจ้าของแอปใน **องค์กร (ไม่บังคับ)** เว้นว่างไว้เพื่อสร้างแอปภายใต้บัญชีของคุณเอง การสร้างภายใต้องค์กรต้องใช้เจ้าของขององค์กรนั้น
3. คลิก **สร้างแอป GitHub ของฉัน**
4. เบราว์เซอร์ของคุณจะเปิด GitHub โดยกรอกข้อมูลแอปไว้แล้ว คลิก **สร้าง GitHub App**
5. GitHub จะส่งคุณกลับมายังเซิร์ฟเวอร์ ซึ่งจัดเก็บ app id, private key, client id และ client secret จากนั้นเปิดหน้าการติดตั้งของแอป

ไม่มีการคัดลอกสิ่งใดด้วยมือ และโค้ดการแปลงจะส่งจาก GitHub ตรงไปยังเซิร์ฟเวอร์ของคุณ ลิงก์ใช้ได้เพียงครั้งเดียวและหมดอายุหลังสิบนาที หากหมดอายุแล้ว ให้คลิก **สร้างแอป GitHub ของฉัน** อีกครั้ง

แอปจะมีชื่อว่า `Control Center <รหัส>` และขอสิทธิ์เฉพาะที่ Control Center ใช้จริง:

| สิทธิ์                                     | การเข้าถึง     |
| ------------------------------------------ | -------------- |
| Metadata                                   | อ่าน           |
| Contents                                   | อ่านและเขียน   |
| Pull requests                              | อ่านและเขียน   |
| Issues                                     | อ่านและเขียน   |
| Checks, Actions, Commit statuses           | อ่าน           |
| Organization members                       | อ่าน           |

Webhook ปิดอยู่: เซิร์ฟเวอร์จะโพลล์ หากภายหลังต้องการย้ายแอปที่สร้างภายใต้บัญชีของคุณไปยังองค์กร ให้ใช้ **โอนความเป็นเจ้าของ** ในการตั้งค่าขั้นสูงของแอปบน GitHub

จุดตรวจสอบ: บล็อก GitHub แสดงข้อความ “เซิร์ฟเวอร์สามารถทำงานในฐานะตัวเองได้ และผู้คนสามารถลงชื่อเข้าใช้ได้”

## ติดตั้งในที่ที่รีโพของคุณอยู่

แอปที่ลงทะเบียนแล้วแต่ยังไม่ได้ติดตั้งจะลงชื่อเข้าใช้ให้คนได้ แต่อ่านอะไรไม่ได้

1. บนหน้าการติดตั้งที่ GitHub เปิดไว้ ให้เลือกบัญชีหรือองค์กรที่เป็นเจ้าของรีโพของคุณ
2. เลือก **ทุกรีโพ** หรือเลือกเฉพาะรีโพที่เซิร์ฟเวอร์นี้ควรมองเห็น

หากภายหลังต้องการติดตั้งบนบัญชีอื่น ผู้ดูแลเวิร์กสเปซไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** ค้นหา **การติดตั้งแอป GitHub** ในการ์ดตัวตน GitHub แล้วคลิก **ติดตั้งแอป GitHub** รายการจะแสดงทุกบัญชีที่แอปถูกติดตั้งไว้ และระบุการติดตั้งที่ถูกระงับ

## อนุญาตเซิร์ฟเวอร์นี้สำหรับองค์กร

บนแอปที่ใช้ร่วมกันของ Control Center การติดตั้งขององค์กรจะให้บริการเฉพาะเซิร์ฟเวอร์ที่ผู้ดูแลได้อนุญาตไว้เท่านั้น การติดตั้งผ่าน **ติดตั้งแอป GitHub** จะอนุญาตเซิร์ฟเวอร์ที่เริ่มการติดตั้ง สำหรับการติดตั้งที่มีอยู่แล้ว:

1. ผู้ดูแลขององค์กรนั้นลงชื่อเข้าใช้ GitHub บนเซิร์ฟเวอร์นี้
2. เปิด **การตั้งค่า → เวิร์กสเปซ → ทั่วไป → การติดตั้งแอป GitHub**
3. แถวขององค์กรจะแสดง **ยังไม่ได้รับอนุญาต** พวกเขาคลิก **อนุญาตเซิร์ฟเวอร์นี้**

จากนั้นแถวจะแสดง **ได้รับอนุญาตแล้ว** แอปของคุณเองไม่ต้องทำขั้นตอนนี้: การติดตั้งทุกครั้งของแอปเป็นของเซิร์ฟเวอร์คุณ

## ลงทะเบียนด้วยตนเองแทน

การ์ด **แอปผู้ให้บริการ** ยังรับค่าโดยตรงได้ สำหรับแอปที่คุณลงทะเบียนเอง:

| กลุ่ม                          | ฟิลด์                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------- |
| **ทำหน้าที่แทนเซิร์ฟเวอร์**    | **App id** และ **Private key** (ไฟล์ `.pem` ทั้งหมด รวมบรรทัด `BEGIN` และ `END`)                       |
| **ให้คนลงชื่อเข้าใช้**         | **Client id** และ **Client secret** **Callback URLs** แสดง URL ที่ต้องลงทะเบียน ให้ใช้ตามที่แสดงทุกตัวอักษร |
| **การสนทนาใน PR**              | **ล็อกอินบอท** ซึ่งจะถูกหาค่าเมื่อคุณทดสอบการเชื่อมต่อ                                                |

ลงทะเบียน callback URL `<server origin>/oauth/github/callback` ตามที่การ์ดแสดง เปิด **Expire user authorization tokens** ไว้ และให้สิทธิ์ตามตารางด้านบน จากนั้นคลิก **ทดสอบ**: ระบบจะถาม GitHub ว่าแอปติดตั้งอยู่บนบัญชีใดบ้าง เพื่อไม่ให้ “บันทึกแล้ว” กับ “ใช้งานได้” ถูกนับปนกัน

## ตั้งค่าจากไฟล์ `.env` ของเซิร์ฟเวอร์

สำหรับการติดตั้งแบบไม่มีส่วนติดต่อหรือแบบสคริปต์ เซิร์ฟเวอร์จะกำหนดค่าแต่ละฟิลด์จากไฟล์ `.env` ในครั้งแรกที่ยังไม่มีค่าที่บันทึกไว้:

```bash
GITHUB_APP_ID=123456
GITHUB_CLIENT_ID=Iv23li0123456789abcd
GITHUB_CLIENT_SECRET=<secret>
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEow…\n-----END RSA PRIVATE KEY-----"
```

ให้ใส่คีย์ส่วนตัวในบรรทัดเดียว: ค่าใน `.env` มีได้หนึ่งบรรทัด และ `\n` ภายในเครื่องหมายคำพูดคู่จะถูกถอดรหัสเป็นการขึ้นบรรทัดใหม่ เซิร์ฟเวอร์จะปฏิเสธการเริ่มทำงานเมื่อ `GITHUB_APP_PRIVATE_KEY` หรือ `GITHUB_CLIENT_SECRET` ถูกส่งออกไปยังสภาพแวดล้อมของโปรเซส ซึ่งทุกโปรเซสลูกอ่านได้ ให้เก็บไว้ในไฟล์ `.env` (ใน Docker ให้ mount ไว้ที่ `/app/bin/.env`) การกำหนดค่าจะเกิดขึ้น**หนึ่งครั้งต่อฟิลด์** ดังนั้นการแก้ไขในการตั้งค่าจะไม่ถูกยกเลิกโดยการรีสตาร์ตครั้งถัดไป

## ใช้แอปอื่นสำหรับเวิร์กสเปซหนึ่ง

เวิร์กสเปซสามารถใช้แอปของตัวเองแทนของเซิร์ฟเวอร์ได้ ผู้ดูแลเวิร์กสเปซไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** เลือก **ใช้แอป GitHub อื่น** ในการ์ด **ตัวตน GitHub** แล้วกรอก app id, private key, client id และ client secret ของแอปนั้น จากนั้นสมาชิกจะลงชื่อเข้าใช้แอปนั้นสำหรับเวิร์กสเปซนี้ เวิร์กสเปซที่ใช้แอปของตัวเองจะไม่ถอยกลับไปใช้แอปของเซิร์ฟเวอร์หรือ Connect: จนกว่าฟิลด์จะครบ งานของ GitHub จะถูกปฏิเสธ ซึ่งใช้ได้ไม่ว่าเซิร์ฟเวอร์จะลงชื่อเข้าใช้ผู้คนด้วยวิธีใด รวมถึง Connect

การ์ด **แอปผู้ให้บริการ** บนหน้าเดียวกันทำสิ่งเดียวกันให้ Google Calendar, Linear และการค้นหา GIF ดู [มอบแอป Linear ของตัวเองให้เวิร์กสเปซหนึ่งแห่ง](/th-TH/คู่มือ/วิธีทำ/การผสาน-linear/#มอบแอป-linear-ของตัวเองให้เวิร์กสเปซหนึ่งแห่ง) และ[มอบไคลเอนต์ Google ของตัวเองแก่เวิร์กสเปซหนึ่งแห่ง](/th-TH/คู่มือ/วิธีทำ/เชื่อมต่อปฏิทิน/#มอบไคลเอนต์-google-ของตัวเองแก่เวิร์กสเปซหนึ่งแห่ง)

## การแก้ปัญหา

### สร้างแอป GitHub ของฉันแจ้งว่าเซิร์ฟเวอร์ไม่มีที่อยู่

เซิร์ฟเวอร์ไม่มี URL สาธารณะที่เบราว์เซอร์จะกลับไปได้ ตั้งค่า `CC_SERVER_PUBLIC_URL` (หรือ `--public-url`) แล้วลองอีกครั้ง

### GitHub บอกว่าลิงก์หมดอายุแล้ว

หน้าใช้ครั้งเดียวนี้ถูกใช้ไปแล้ว หรือผ่านไปสิบนาทีแล้ว เริ่มใหม่จากการตั้งค่า

### ทดสอบแล้วข้อมูลรับรองใช้ได้ แต่แอปยังไม่ได้ติดตั้งที่ไหนเลย

การลงทะเบียนกับการติดตั้งเป็นสองขั้นตอนที่แยกกัน เปิดหน้าการติดตั้งของแอป หรือใช้ **ติดตั้งแอป GitHub** ใน เวิร์กสเปซ → ทั่วไป

### ทดสอบแล้วบอกว่าอ่านคีย์ส่วนตัวไม่ได้

วางไฟล์ `.pem` ทั้งหมด รวมบรรทัด `-----BEGIN` และ `-----END` คีย์ `ed25519` หรือ EC ใช้ไม่ได้: GitHub App ลงนามด้วย RSA

### สมาชิกลงชื่อเข้าใช้แล้วแต่ไม่เห็นรีโพใดเลย

แอปไม่ได้ติดตั้งบนบัญชีที่เป็นเจ้าของรีโพเหล่านั้น หรือการติดตั้งเลือกรีโปต่างกัน การลงชื่อเข้าใช้จะให้สิทธิ์เฉพาะสิ่งที่แอปได้รับอนุญาตให้เห็นเท่านั้น

### เอเจนต์แจ้งว่าการติดตั้ง GitHub App ถูกระงับ

มีคนระงับการติดตั้งบน GitHub ให้ยกเลิกการระงับในบัญชีที่ **Settings → Applications → Installed GitHub Apps**
