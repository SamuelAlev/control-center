คู่มือนี้แสดงวิธีจับคู่โทรศัพท์กับ Control Center เพื่อให้คุณอ่านข้อความและตั๋วงาน
และตอบกลับได้จากทุกที่ ขั้นตอนเดียวกันนี้ใช้จับคู่เบราว์เซอร์หรือแอปเดสก์ท็อป
เครื่องที่สอง ดู[ควบคุมระยะไกลและมือถือ](/th-TH/คู่มือ/แนวคิด/ควบคุมระยะไกล/)
ว่าการเชื่อมต่อนี้ทำงานอย่างไรและมีโมเดลความปลอดภัยแบบใด

## ก่อนเริ่ม

- ไคลเอนต์เดสก์ท็อปหรือเว็บที่เชื่อมต่อกับเซิร์ฟเวอร์ของคุณ และเวิร์กสเปซที่ตั้งค่าไว้แล้ว การดำเนินการจับคู่ต้องใช้ไคลเอนต์เต็มรูปแบบ โทรศัพท์ที่จับคู่แล้วจึงจับคู่ — หรือเพิกถอน — อุปกรณ์อื่นไม่ได้เลย
- เซิร์ฟเวอร์ต้องเข้าถึงได้จากอุปกรณ์ที่คุณกำลังจับคู่ ในเครือข่ายเดียวกันก็ทำงานได้ทันที จากที่ไกลออกไปกว่านั้นรีเลย์ที่มีตัวกลางเป็นตัวขนส่งทราฟฟิก หากแผงตอบว่า **เข้าถึงไม่ได้** แทนที่จะแสดง QR หรือข้อมูลรับรอง ให้เผยแพร่เส้นทางก่อน — การเลือกใช้ทันเนลที่ **การตั้งค่า → เซิร์ฟเวอร์ → การเชื่อมต่อและสถานะ** (**แชร์เซิร์ฟเวอร์นี้**) หรือ `--public-url` ของเซิร์ฟเวอร์ (ดู[รันเซิร์ฟเวอร์แบบไม่มีส่วนติดต่อ](/th-TH/คู่มือ/วิธีทำ/รันเซิร์ฟเวอร์แบบไม่มีส่วนติดต่อ/))
- สำหรับโทรศัพท์: ไม่ต้องติดตั้งอะไร QR จะเปิดเว็บแอป **Remote** ([remote.usectrl.dev](https://remote.usectrl.dev/) โดยค่าเริ่มต้น)

**การโฮสต์เอง** Remote และรีเลย์โบรกเกอร์เป็นโอเพนซอร์สในรีโปนี้: แอปโทรศัพท์
(`apps/cc_remote` เป็น PWA เว็บ Flutter ที่คุณนำไปปรับใช้บน Cloudflare Pages ผ่าน
`wrangler.jsonc` ของมัน บนอิมเมจ nginx `docker/cc_remote` หรือบนโฮสต์สแตติกใดก็ได้
ที่ใช้ HTTPS — service worker และ IndexedDB ใช้ได้เฉพาะในบริบทที่ปลอดภัยเท่านั้น)
และรีเลย์ (`apps/cc_signaling_server` ไบนารี Dart แบบไร้สถานะตัวเดียวที่เก็บข้อมูล
แอปไม่ได้เลยและไม่เคยเห็นความลับการจับคู่ — มันส่งต่อเฉพาะเฟรมที่ปิดผนึกแบบต้นทาง
ถึงปลายทาง) ดู README ของทั้งสองตัวสำหรับขั้นตอนบิลด์และรัน

## ขั้นตอนที่ 1: เปิดแผงการจับคู่

เปิด **การตั้งค่า → คุณ → อุปกรณ์ของคุณ** ส่วน **อุปกรณ์ของคุณ** แสดงรายการ
ไคลเอนต์ที่จับคู่กับบัญชีของคุณบนเซิร์ฟเวอร์นี้ (เจ้าของเซิร์ฟเวอร์เห็นทุกอุปกรณ์
บนเซิร์ฟเวอร์ คนอื่นเห็นเฉพาะของตัวเอง)

## ขั้นตอนที่ 2: จับคู่ไคลเอนต์ใหม่

คลิก **จับคู่ไคลเอนต์ใหม่** ที่ส่วนหัวของหน้า ตั้งป้ายชื่อให้มัน (เช่น
"โทรศัพท์ของฉัน") เลือกชนิด — **เว็บเบราว์เซอร์** **แอปเดสก์ท็อป** หรือ
**โทรศัพท์** — แล้วคลิก **จับคู่**

- สำหรับ **โทรศัพท์** จะมี QR โค้ดปรากฏขึ้น สแกนมันด้วยกล้องของโทรศัพท์ หรือคัดลอกลิงก์แล้วเปิดในเบราว์เซอร์ใดก็ได้ ลิงก์นี้ชี้แอป Remote ไปที่เซิร์ฟเวอร์ของคุณและพาข้อมูลรับรองไปด้วย
- สำหรับ **เบราว์เซอร์** หรือ **เดสก์ท็อป** ให้คัดลอกลิงก์ที่แสดง (หรือ ID อุปกรณ์กับคีย์จับคู่) ไปใส่ในไคลเอนต์ใหม่แทน ลิงก์แบบแตะครั้งเดียวจะเสนอให้เฉพาะเมื่อคุณจับคู่จากไคลเอนต์เว็บ เนื่องจากไบนารีเดสก์ท็อปไม่มีเว็บออริจินให้สร้างลิงก์ดังกล่าว

QR ของโทรศัพท์กับลิงก์ที่ `cc_server pair --client-url` พิมพ์บน CLI เป็น
**เพย์โหลดที่ต่างกันและใช้แทนกันไม่ได้**: ลิงก์จาก CLI กรอกแบบฟอร์มเชื่อมต่อของ
ไคลเอนต์เว็บ ขณะที่ QR นี้พาตัวพรรณาการเชื่อมต่อทั้งหมดของเซิร์ฟเวอร์และ
ลายนิ้วมือตัวตนไปให้ Remote PWA

ฝั่งโทรศัพท์ การเปิดลิงก์จับคู่ไม่ได้จับคู่อย่างเงียบ ๆ Remote จะแสดงชื่อที่
เซิร์ฟเวอร์ประกาศไว้และขอให้คุณยืนยันก่อนจัดเก็บสิ่งใด ลิงก์ปลอมจึงลักพาแอปไป
ยังเซิร์ฟเวอร์ของคนอื่นไม่ได้

:::caution[QR ที่สแกนแล้วให้สิทธิ์เข้าถึงทันที]
ไม่มีขั้นตอนค้างรอแล้วอนุมัติ: อุปกรณ์ที่สร้างขึ้นใช้งานได้ทันทีที่ถูกสร้าง และเกต
การเชื่อมต่อตรวจสอบเพียงว่าข้อมูลรับรองยังใช้งานได้และยังไม่หมดอายุ ให้ปฏิบัติกับ
QR และคีย์จับคู่เหมือนรหัสผ่าน และเพิกถอนทุกสิ่งที่คุณไม่ได้ตั้งใจมอบออกไป
:::

## จัดการอุปกรณ์ที่จับคู่แล้ว

จาก **การตั้งค่า → คุณ → อุปกรณ์ของคุณ** คุณสามารถ:

- **เปลี่ยนชื่อ** อุปกรณ์
- **เพิกถอน** อุปกรณ์ที่คุณไม่ไว้วางใจอีกต่อไป การเพิกถอนจะทำลายข้อมูลรับรองของมันและตัดเซสชันที่ใช้งานอยู่ภายในไม่กี่วินาที เมื่อเชื่อมต่อใหม่จึงล้มเหลวแบบปิด

การเพิกถอนเป็นการกระทำที่ถูกต้องสำหรับโทรศัพท์ที่หายหรือถูกเปลี่ยนเครื่อง
มันมีผลทันทีและย้อนกลับไม่ได้จากมุมมองของอุปกรณ์

ข้อมูลรับรองที่สร้างจากแผงนี้มีเวลาจำกัด: มันหมดอายุ 30 วันหลังออกให้ และเกต
การเชื่อมต่อจะทำให้มันล้มเหลวแบบปิดหลังจากนั้น ข้อมูลรับรองที่สร้างด้วย
`cc_server pair` บนบรรทัดคำสั่ง **ไม่มีวันหมดอายุเลย** — ให้เพิกถอนด้วยมือ
เมื่อเครื่องที่มันมีไว้เพื่อนั้นปลดระวาง

## สลับเวิร์กสเปซจากโทรศัพท์

โทรศัพท์ที่จับคู่แล้วสลับเวิร์กสเปซได้อย่างอิสระจากเดสก์ท็อป โทรศัพท์ส่ง
เวิร์กสเปซไปกับการเรียกทุกครั้ง และเซิร์ฟเวอร์ตรวจสอบสมาชิกภาพและบทบาทของคุณ
ในเวิร์กสเปซนั้นทุกครั้ง — โทรศัพท์จึงเข้าถึงเฉพาะเวิร์กสเปซที่คุณเป็นสมาชิก
และการสลับที่นั่นไม่เคยเปลี่ยนสิ่งที่เดสก์ท็อปแสดง

เซสชันของโทรศัพท์ยังถูกจำกัดเพิ่มเติมให้ใช้ได้เฉพาะรายการอนุญาตสั้น ๆ ของ
เครื่องมือที่เน้นการอ่านเป็นหลัก: มันแสดงรายการและอ่านตั๋วงาน เอเจนต์ สเปซ
ข้อความ และบทความในฟีดได้ และอัปเดตหรือมอบหมายตั๋วงาน ส่งข้อความในสเปซ และ
ทำเครื่องหมายว่าบทความอ่านแล้วหรือบันทึกไว้ได้ สิ่งใดนอกเหนือจากชุดนั้นจะถูก
ปฏิเสธก่อนถึงตัวจัดส่งของเซิร์ฟเวอร์
