คู่มือนี้ครอบคลุมการเริ่มรันด้วยมือ หากต้องการเฝ้าดูการรัน อ่านเอาต์พุตของขั้นตอน
และกู้คืนจากความล้มเหลว ดู[ติดตามรันไปป์ไลน์](/th-TH/คู่มือ/วิธีทำ/ติดตามไปป์ไลน์/)

## เริ่มการรัน

1. คลิก **ไปป์ไลน์** ในแถบข้างของเวิร์กสเปซ
2. กด **รันไปป์ไลน์** ในส่วนหัว คุณจะไปอยู่ที่หน้าจอเริ่มรัน
   (`/workspaces/<workspace-id>/pipelines/run`)
3. เลือกเทมเพลตจากรางด้านซ้าย การ์ดแต่ละใบแสดงชื่อเทมเพลต คำอธิบาย
   และว่ารับอินพุตหรือไม่
4. กรอกฟอร์มอินพุตทางด้านขวา ฟิลด์ที่จำเป็นจะปิดกั้นปุ่มจนกว่าจะมีค่า
   ส่วนเทมเพลตที่ไม่มีอินพุตจะบอกไว้เช่นนั้น
5. กด **รันไปป์ไลน์**

คุณจะไปอยู่ที่หน้ารายละเอียดการรัน โดยไทม์ไลน์การจับเวลาและแคนวาสกราฟพร้อมใช้งาน

## ถ้ารางว่างเปล่า

หน้าจอเริ่มรันจะแสดงเทมเพลตก็ต่อเมื่อเป็นจริง**ทั้งสองข้อ**:

- สวิตช์ของเทมเพลตเปิดอยู่ที่ **การตั้งค่า → เวิร์กสเปซ → เทมเพลตไปป์ไลน์**
- **อนุญาตการรันด้วยตนเอง** เปิดอยู่ในกล่องโต้ตอบ **รันด้วยตนเอง** ของตัวแก้ไข
  เทมเพลต — สวิตช์นั้นคือสิ่งที่สร้างทริกเกอร์ `manual` ที่หน้าจอเริ่มรันอ่าน

เทมเพลตในตัวแปดจากสิบสามรายการมาพร้อมสถานะปิดใช้งาน: `external_pr_welcome`,
`cross_review`, `ticket_to_pr`, `pr_triage`, `pre_merge_gate`, `release_notes`,
`dep_audit` และ `pr_digest` เอนจินจะปฏิเสธไม่เริ่มเทมเพลตที่ปิดใช้งาน ดังนั้น
จงเปิดสวิตช์ของมันก่อนจะหาเทมเพลตนั้นที่นี่

ไม่มีปุ่ม **รัน** ต่อเทมเพลตในรายการเทมเพลต และไม่มีปุ่มรันในตัวแก้ไข —
หน้าจอเริ่มรันคือทางเข้าเดียวสำหรับการรันด้วยตนเอง

## กรอกอินพุตรีโพสิทอรี

อินพุตชนิด **รีโพสิทอรี** จะแสดงตัวเลือกเหนือรีโพที่ลงทะเบียนไว้ในเวิร์กสเปซ
การเลือกรีโพหนึ่งจะเติม `repo_id`, `repo_local_path`, `repo_full_name` และ —
เมื่อรีโพมีรีโมต GitHub — `repo_owner` และ `repo_name` ลงในเพย์โหลดการรัน
เพื่อให้ขั้นตอนปลายน้ำอ่านค่าใดก็ได้ที่ต้องการ

## เฝ้าดูการรัน

หน้ารายละเอียดการรันมีสามส่วน: แถบเมตา (เวลาเริ่ม ระยะเวลาที่ใช้งานจริง
ความคืบหน้าของขั้นตอน แบนเนอร์ความล้มเหลว **ลองใหม่** และ **ลบ**)
ไทม์ไลน์การจับเวลาแบบพับเก็บได้ที่แสดงระยะเวลาและต้นทุนต่อขั้นตอน และแคนวาสกราฟ
การเลือกโหนดหนึ่งจะเปิดแผงรายละเอียดของขั้นตอนนั้น

[ติดตามรันไปป์ไลน์](/th-TH/คู่มือ/วิธีทำ/ติดตามไปป์ไลน์/) ครอบคลุมทั้งหมด
รวมถึงวิธีอ่านขั้นตอนที่ถูกระงับและสิ่งที่ต้องทำเมื่อขั้นตอนหนึ่งล้มเหลว

ทุกการรันที่คุณเริ่มจากแอปเป็นการรันจริง
