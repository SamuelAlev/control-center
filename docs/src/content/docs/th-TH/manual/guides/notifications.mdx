คู่มือนี้แสดงวิธีตั้งค่าการแจ้งเตือน และการตั้งค่าแต่ละอย่างควบคุมอะไรจริง ๆ

การแจ้งเตือนมาถึงบนสองพื้นผิว **ศูนย์การแจ้งเตือน** — ระฆังบนแถบชื่อเรื่อง — อ่าน
ฟีดถาวรต่อเวิร์กสเปซจากเซิร์ฟเวอร์ ส่วน **ทอสต์ของระบบปฏิบัติการ** เป็นเส้นทางแยก
ที่ใช้เฉพาะเดสก์ท็อป ป้อนด้วยเฟรมสดที่เซิร์ฟเวอร์ผลักมา

:::note[บิลด์เว็บไม่แสดงการแจ้งเตือนของระบบปฏิบัติการ]
ไปป์ไลน์ทอสต์ถูกสร้างขึ้นโดยเดสก์ท็อปบูตสแตรปเท่านั้น บน `app.usectrl.dev` ไม่มี
ทอสต์ของระบบปฏิบัติการ ไม่มีเสียงแจ้งเตือน และไม่มีแบนเนอร์แวดล้อม — ระฆังและ
ประวัติของมันยังทำงานได้ เพราะอ่านฟีดจากเซิร์ฟเวอร์ ไคลเอนต์บนมือถือไม่มีการ
แจ้งเตือนใด ๆ เลย
:::

## เปิดหรือปิดหมวดหมู่

1. ไปที่ **การตั้งค่า → คุณ → การแจ้งเตือน**
2. ปล่อยให้ **เปิดการแจ้งเตือน** เปิดอยู่
3. สลับหมวดหมู่ที่คุณต้องการ มีทั้งหมดสิบหกหมวดหมู่พอดี:

| หมวดหมู่                     | แจ้งเตือนเมื่อ                                                                |
| ---------------------------- | --------------------------------------------------------------------------- |
| เอเจนต์เสร็จแล้ว             | เอเจนต์ตอบกลับในการรันที่คุณเริ่ม หรือการรันล้มเหลว                          |
| PR ถูกเผยแพร่แล้ว            | เอเจนต์เผยแพร่ PR                                                            |
| PR ถูกรวมแล้ว                | PR ถูกรวม                                                                   |
| ข้อความใหม่                  | มีคนกล่าวถึงคุณในสเปซ                                                          |
| ถูกกล่าวถึงใน pull request   | การตรวจสอบการแจ้งเตือนของ GitHub พบว่าคุณถูกกล่าวถึงบน PR                     |
| ขอรีวิว                      | มีการขอรีวิวจากคุณจริง ๆ บน PR ที่ไม่ใช่ฉบับร่าง                               |
| รีวิวล้าสมัย                  | มีคอมมิตใหม่เข้ามาใน pull request ที่คุณรีวิวไปแล้ว                          |
| พร้อมรวม                     | pull request ที่คุณเป็นผู้เขียนกลายเป็นรวมได้ หรือเลิกเป็นเช่นนั้น             |
| ผลการรีวิว                   | ผู้รีวิวอนุมัติ ขอให้แก้ไข หรือการอนุมัติถูกเพิกถอน                            |
| การตรวจ                      | CI ล้มเหลวบน pull request ที่คุณเป็นผู้เขียน หรือกลับมาผ่าน                   |
| เธรดรีวิว                    | มีคนตอบกลับในเธรดที่คุณอยู่หรือปิดเธรดนั้น                                     |
| มอบหมายตั๋วงานแล้ว           | มีการมอบหมายตั๋วงาน                                                          |
| สถานะตั๋วงานเปลี่ยน          | ตั๋วงานเปลี่ยนสถานะ                                                          |
| การประชุมกำลังจะเริ่ม        | การประชุมในปฏิทินอยู่ในช่วงเวลาล่วงหน้าที่คุณตั้งไว้                           |
| ปฏิทินถูกตัดการเชื่อมต่อ     | โทเค็น OAuth ของปฏิทินที่เชื่อมต่อหมดอายุ                                     |
| อัปเดตเอนโคลเจอร์             | เอนโคลเจอร์ถูกเข้ายึด ถูกเรียกคืน หรือล้มเหลว                                  |

สิ่งที่อยู่นอกเหนือรายการนี้ไม่สามารถแจ้งเตือนหรือกรองได้ — ไม่มีหมวดหมู่
“ทุกอย่างอื่น”

การตั้งค่าเหล่านี้ติดตามผู้ใช้ของคุณข้ามอุปกรณ์ โทรศัพท์กับแล็ปท็อปจึงสอดคล้องกัน
ส่วนระดับเสียงเป็นข้อยกเว้นโดยเจตนา และแยกตามอุปกรณ์

## ตั้งค่า Quiet hours

1. บนหน้าเดียวกัน เปิด **Quiet hours**
2. พิมพ์เวลาเริ่มและเวลาสิ้นสุดในรูปแบบ `HH:MM` (ช่วงเริ่มต้นคือ 22:00–08:00)

ในช่วง Quiet hours การแจ้งเตือนที่ไม่เร่งด่วนจะถูกทิ้ง — ไม่ถูกจัดคิวแล้วเล่นซ้ำ
ภายหลัง

มีสองหมวดหมู่ที่เป็น **เรื่องด่วน** และส่งถึงเสมอ โดยข้าม Quiet hours _และ_
โหมดโฟกัส: **การประชุมกำลังจะเริ่ม** และ **PR ถูกเผยแพร่แล้ว** การเตือนการประชุมที่
คุณเห็นหลังจากนั้นไปแล้วก็ไร้ค่า นี่คือเหตุผล

## เลือกเสียง

1. เลื่อนไปที่ **เสียงแจ้งเตือน**
2. เลือกหนึ่งในสิบเอ็ดเสียงที่มาพร้อมแอป หรือ **ไม่มี**
3. กดปุ่มทดสอบเพื่อฟังเสียง แล้วตั้งระดับเสียงด้วยแถบเลื่อน

แอปเล่นเสียงเอง ส่วนการแจ้งเตือนของระบบปฏิบัติการถูกส่งแบบเงียบ คุณจึงไม่ต้องได้ยิน
ซ้ำสองครั้ง

## ตั้งเวลาล่วงหน้าก่อนการประชุม

1. เลื่อนไปที่ **เวลาก่อนแจ้งเตือน**
2. เลือก **5**, **10**, **15** หรือ **30** นาที

นี่คือระยะเวลาล่วงหน้าก่อนเหตุการณ์ในปฏิทินที่การแจ้งเตือน **การประชุมกำลังจะเริ่ม**
จะทำงาน ค่าเริ่มต้นคือ 5 นาที

## รู้ว่าเมื่อใดการแจ้งเตือนถูกระงับ

การแจ้งเตือนจะถูกทิ้งอย่างเงียบ ๆ เมื่อข้อใดข้อหนึ่งต่อไปนี้เป็นจริง:

- การแจ้งเตือนถูกปิดทั้งหมด หรือหมวดหมู่ของมันถูกปิด
- คุณอยู่ในเส้นทางที่มันจะพาคุณไปอยู่แล้ว — และสำหรับข้อความ คุณอยู่ในสเปซนั้นอยู่แล้ว
- โหมดโฟกัสทำงานอยู่และหมวดหมู่นั้นไม่ใช่เรื่องด่วน
- Quiet hours ทำงานอยู่และหมวดหมู่นั้นไม่ใช่เรื่องด่วน

การตรวจสอบเหล่านั้นใช้กับทอสต์ของระบบปฏิบัติการ ส่วนระฆังแบบถาวรยังคงบันทึก
เหตุการณ์ไว้

มีการระงับอีกสองกรณีที่อยู่ต้นทางยิ่งกว่า ในสิ่งที่เซิร์ฟเวอร์ส่งมาเลย:

- ข้อความที่ไม่ได้กล่าวถึงคุณจาก **มนุษย์** คนอื่นจะไม่กลายเป็นการแจ้งเตือน
- ในสเปซที่ใช้ร่วมกัน คำตอบของเอเจนต์จะแจ้งเตือนคนที่เริ่มการรันนั้น ไม่ใช่สมาชิก
  ทุกคน
- สเปซระหว่างเอเจนต์กับเอเจนต์ถูกปิดเสียงในแถบข้าง จึงไม่ทำให้ป้ายข้อความยังไม่ได้
  อ่านเพิ่มขึ้นเลย

ภายในสเปซไม่มีมุมที่เงียบ: ทุกการสนทนาแจ้งเตือนเท่ากัน รวมถึงเธรดด้วย สถานะการอ่าน
ผูกกับสเปซ ความยังไม่ได้อ่านจึงรวมกันข้ามการสนทนาต่าง ๆ ในสเปซ แทนที่จะติดตามแยก
ทีละการสนทนา

## อ่านและล้างศูนย์การแจ้งเตือน

1. คลิกระฆังบนแถบชื่อเรื่อง

ป๊อปโอเวอร์แสดงกิจกรรมล่าสุด โดยลิงก์เจาะลึกแต่ละรายการไปยังสิ่งที่รายการนั้น
เกี่ยวกับ การเปิดมัน **ไม่** ทำเครื่องหมายว่าอ่านแล้วทั้งหมด — ใช้ **ทำเครื่องหมาย
ทั้งหมดว่าอ่านแล้ว** ในส่วนหัว หรือทำเครื่องหมายทีละแถว สถานะการอ่านติดตามผู้ใช้ของ
คุณข้ามอุปกรณ์

:::note[ล้างทั้งหมดเป็นการประทับลายน้ำ ไม่ใช่การลบ]
**ล้างทั้งหมด** ประทับลายน้ำต่อผู้ใช้ที่ซ่อนทุกอย่างที่เก่ากว่า ส่วนแถวยังคงอยู่
แยกจากกัน แต่ละเวิร์กสเปซเก็บเฉพาะ **200** แถวล่าสุดของฟีด โดยตัดทิ้งเมื่อมีแถวใหม่
เข้ามา ขณะที่ระฆังสมัครรับ **50** แถวใหม่สุด และป๊อปโอเวอร์แสดงได้ถึง **15** แถวจาก
เหล่านั้น ประวัติที่เกินกว่านั้นหายไปแล้วไม่ว่าสถานะการอ่านจะเป็นอย่างไร
:::

## การแก้ไขปัญหา

### ไม่มีการแจ้งเตือนของระบบปฏิบัติการบน macOS

ระบบขอสิทธิ์โดยตรงเมื่อแอปเปิดขึ้น หากคุณปฏิเสธไปแล้ว ให้เปิดใช้งาน Control Center
อีกครั้งที่ การตั้งค่าระบบ → การแจ้งเตือน ไม่มีพรอมป์ต์ในแอปให้เรียกขอใหม่

### บนบิลด์เว็บไม่มีอะไรมาถึง

เป็นไปตามที่คาดไว้ — บิลด์เว็บไม่มีไปป์ไลน์การแจ้งเตือนของระบบปฏิบัติการ ให้ใช้ระฆัง

### ป้ายบนระฆังแสดงศูนย์แต่มีกิจกรรมใหม่ชัดเจน

จนกว่าสตรีมเครื่องหมายการอ่านจะพร้อมหลังเชื่อมต่อ รายการจะแสดงเป็นอ่านแล้วเพื่อ
หลีกเลี่ยงป้ายที่กะพริบแล้วว่างเปล่า มันจะเข้าที่เมื่อโหลดเครื่องหมายเสร็จ

### การรันของเอเจนต์เสร็จแล้วแต่ไม่มีอะไรแจ้งเตือนฉัน

ตรวจสอบว่าคุณไม่ได้อยู่ในสเปซที่มันเกิดขึ้นอยู่แล้ว — เส้นทางที่ใช้งานอยู่จะระงับ
ทอสต์ของระบบปฏิบัติการของตัวเอง ในสเปซที่ใช้ร่วมกัน การรันที่คนอื่นเริ่มจะแจ้งเตือน
คนนั้น ไม่ใช่คุณ เทิร์นที่จบลงโดยไม่มีคำตอบและไม่มีข้อผิดพลาดจะไม่ส่งอะไรเลย
