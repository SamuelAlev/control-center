คู่มือนี้อธิบายวิธีเชื่อมตัวตนแชทของคุณเข้ากับผู้ใช้ Control Center และวิธียกเลิกการเชื่อม

ทุกสมาชิกต้องทำขั้นตอนนี้หนึ่งครั้งต่อผลิตภัณฑ์แชทแต่ละตัว ไม่เกี่ยวข้องกับการเชื่อมต่อแอป: การเชื่อมต่อทำให้บอตเข้าถึงได้สำหรับทั้งเวิร์กสเปซ ส่วนการลิงก์ทำให้บอตจำ_คุณ_ได้

## ทำไมต้องลิงก์

สำหรับบัญชีแชทที่ไม่สามารถระบุให้เป็นสมาชิกของเวิร์กสเปซได้ สะพานจะปฏิเสธการทำงานแทน นี่เป็นการตั้งใจ: หากไม่มีการลิงก์ ข้อความทุกข้อความจาก Slack จะถูกระบุให้เป็นคนที่ติดตั้งแอปเท่านั้น บันทึกการตรวจสอบ ขีดจำกัดอัตราตามผู้รับผิดชอบ และผู้ขอตั๋วงานจะชี้ไปยังคนผิด

สมาชิกที่ยังไม่ได้ลิงก์และกล่าวถึงบอตจะได้รับคำตอบในเธรด Slack นั้นที่อธิบายวิธีลิงก์ จะไม่มีงานใดถูกส่งออกไป

## ลิงก์ด้วยรหัส

การลิงก์ต้องใช้ทั้งสองฝั่ง: การส่งรหัสจาก Slack พิสูจน์บัญชี Slack และการยืนยันใน Control Center พิสูจน์ว่าบัญชีนั้นเป็นของคุณ

1. ไปที่ **การตั้งค่า → คุณ → โปรไฟล์** แล้วหาการ์ด **บัญชีแชทที่ลิงก์**
2. ในบล็อก Slack คลิก **ลิงก์บัญชี Slack ของฉัน** ไดอะล็อกจะแสดงรหัสครั้งเดียว เช่น:

```text
K7M2QP
```

3. ใน Slack ส่งเฉพาะรหัสนี้ให้บอตใน**ข้อความส่วนตัว** โดยไม่ต้องมีข้อความอื่น
4. บอตจะตอบว่า “Got it. Confirm this Slack account in Control Center to finish linking.” และไดอะล็อกที่คุณเปิดค้างไว้จะแสดงโปรไฟล์ Slack ที่ส่งรหัสมา ได้แก่ชื่อและ Slack member id
5. หากเป็นบัญชีของคุณ ให้คลิก **ยืนยัน** การลิงก์จะเสร็จสมบูรณ์ ไดอะล็อกจะแจ้งผล และบอตจะยืนยันในข้อความส่วนตัวเดียวกัน
6. หากไม่ใช่บัญชีของคุณ ให้คลิก **ปฏิเสธ** จะไม่มีการลิงก์อะไรเลย และรหัสนั้นจะใช้ไม่ได้อีก คลิก **ขอรหัสใหม่** หากยังต้องการลิงก์ แล้วลองอีกครั้ง

การปิดไดอะล็อกไม่ทำให้คำขอหาย รหัสที่มาถึงภายหลังจะรออยู่ในแถว **ลิงก์บัญชี Slack ของฉัน** ของการ์ดนั้น พร้อมปุ่ม **ยืนยัน** และ **ปฏิเสธ** เช่นเดิม

เหตุผลของขั้นตอนยืนยัน: หากมีคนแอบเห็นรหัสของคุณแล้วส่งจากบัญชี Slack ของคนอื่น บัญชีนั้นจะกระทำการในนามของคุณได้ มีเพียงคุณเท่านั้นที่ยืนยันได้ และยืนยันได้เฉพาะโปรไฟล์ที่ส่งรหัสนั้นมาเท่านั้น

รหัสนี้:

- ใช้ได้ครั้งเดียว และหมดอายุ **15 นาที** หลังจากสร้าง
- สร้างขึ้นเพื่อ_คุณ_เสมอ ไม่เคยสร้างให้เพื่อนร่วมงาน
- ใช้ได้เฉพาะในข้อความส่วนตัวกับบอต ในช่องสนทนาจะเป็นเพียงข้อความธรรมดา
- รับได้เฉพาะสมาชิกเต็มตัวของเวิร์กสเปซ Slack ที่บอตติดตั้งอยู่ ไม่ใช่แขกหรือคนจากองค์กรอื่น
- แทนที่รหัสใด ๆ ที่คุณถืออยู่ ดังนั้นการกดปุ่มอีกครั้งจะทำให้รหัสก่อนหน้าใช้ไม่ได้
- อยู่ในหน่วยความจำเท่านั้น ดังนั้นการรีสตาร์ตเซิร์ฟเวอร์จะทำให้รหัสที่ยังค้างอยู่ใช้ไม่ได้ — กดปุ่มอีกครั้ง

รหัสที่ไม่รู้จัก หมดอายุ ถูกปฏิเสธ หรือสร้างขึ้นสำหรับเวิร์กสเปซอื่น จะล้มเหลวในลักษณะเดียวกันจนแยกไม่ออก: “That code is not valid (or has expired).”

## ลิงก์อัตโนมัติด้วยอีเมล

หากโปรไฟล์ Slack ของคุณมีอีเมลที่ได้รับการยืนยัน และอีเมลนั้นตรงกับอีเมลที่ได้รับการยืนยันของผู้ใช้ Control Center ที่**เป็นสมาชิกของเวิร์กสเปซนี้อยู่แล้ว** สะพานจะลิงก์คุณให้ในครั้งแรกที่คุณคุยกับมัน โดยไม่ต้องใช้รหัส

ฝั่ง Control Center จะถือว่าอีเมลได้รับการยืนยันเมื่อการลงชื่อเข้าใช้ครั้งเดียวหรือ SCIM เป็นผู้ตั้งที่อยู่นั้น หรือเมื่อเจ้าของเซิร์ฟเวอร์ยืนยันที่อยู่นั้นใน **การตั้งค่า → เซิร์ฟเวอร์ → บุคคล** ที่อยู่ที่คุณพิมพ์ในโปรไฟล์ของตัวเองจะไม่ถือว่าได้รับการยืนยัน จึงไม่ลิงก์อะไรเลยจนกว่าเจ้าของจะยืนยัน ระหว่างนั้นให้ใช้ขั้นตอนรหัสแทน

ทั้งสองส่วนสำคัญ: การจับคู่อีเมลพิสูจน์ตัวตน แต่มีเพียงการเป็นสมาชิกเท่านั้นที่ให้สิทธิ์เข้าถึง ดังนั้นคนแปลกหน้าที่อีเมลของเขาตรงกับบัญชีบนเซิร์ฟเวอร์จะไม่ถูกลิงก์กับอะไรเลย รายชื่อจะแสดงว่าแต่ละการลิงก์ถูกสร้างขึ้นอย่างไร (“จับคู่ตามอีเมล” หรือ “ลิงก์ด้วยรหัส”)

การลิงก์อัตโนมัติต้องใช้สโคป `users:read.email` หากไม่มีสโคปนี้ Slack จะไม่ให้ที่อยู่อีเมล และต้องใช้ขั้นตอนรหัสแทน

## ดูว่าใครถูกลิงก์ไว้

รายชื่อเป็นของการจัดการเวิร์กสเปซ จึงอยู่ในการ์ดของแอดมิน: **การตั้งค่า → เวิร์กสเปซ → การผสานรวม → สะพานแชท → บัญชีที่ลิงก์** รายชื่อแสดงสมาชิกทุกคนในเวิร์กสเปซที่ลิงก์แล้ว พร้อมบัญชี Slack และวิธีการลิงก์ของแต่ละคน

สถานะของคุณเองอยู่ที่ **การตั้งค่า → คุณ → โปรไฟล์**: เมื่อคุณลิงก์แล้ว แถว **ลิงก์บัญชี Slack ของฉัน** จะแสดง “ลิงก์กับ _your-slack-id_” แล้ว และเมื่อยังไม่ได้ลิงก์ จะบอกให้คุณลิงก์

ทั้งรายชื่อและการลิงก์ที่รอการยืนยันเป็นการสมัครรับข้อมูลแบบเรียลไทม์ เพราะการเปลี่ยนแปลงเกิดขึ้นอีกฝั่งหนึ่ง: คุณส่งรหัสใน Slack ดังนั้นไม่มีคำขอใดจากแอปที่สามารถส่งคำตอบกลับมาได้

## เลิกลิงก์

ในรายชื่อของเวิร์กสเปซ คลิก **เลิกลิงก์** ที่แถวหนึ่ง ๆ

- ทุกคนเลิกลิงก์บัญชีของตัวเองได้
- เฉพาะผู้ดูแลเท่านั้นที่เลิกลิงก์สมาชิกคนอื่นได้
- การเลิกลิงก์ยังเพิกถอนรหัสลิงก์ที่สมาชิกคนนั้นยังไม่ได้ใช้

หลังเลิกลิงก์ บัญชี Slack นั้นจะไม่สามารถสั่งการเอเจนต์ได้อีกจนกว่าจะลิงก์ใหม่ สเปซ บันทึก และตั๋วงานที่มีอยู่จะยังคงความเป็นเจ้าของเดิมไว้ — การเลิกลิงก์ไม่ได้ถอนงานที่ผ่านมา

## การแก้ปัญหา

### บอตบอกว่าฉันไม่ใช่สมาชิกของเวิร์กสเปซนี้

บัญชี Slack ของคุณลิงก์กับผู้ใช้ Control Center คนหนึ่งอยู่ แต่ผู้ใช้นั้นไม่มีสถานะสมาชิกในเวิร์กสเปซนี้ ให้ผู้ดูแลเชิญคุณ ดู[การทำงานร่วมกันแบบหลายคน — ตัวตน สมาชิกภาพ และการแสดงสถานะออนไลน์](/th-TH/คู่มือ/แนวคิด/การทำงานร่วมกันแบบหลายคน/)

### บอตบอกว่าบทบาทของฉันเป็นแบบอ่านอย่างเดียว

บทบาท `viewer` และ `guest` ไม่สามารถเริ่มงานได้ ผู้ดูแลต้องเพิ่มบทบาทของคุณเป็น `member` หรือสูงกว่า

### บอตบอกว่ารหัสไม่ถูกต้อง

รหัสหมดอายุ ถูกใช้ไปแล้ว ถูกปฏิเสธ หรือถูกแทนที่ด้วยรหัสที่ใหม่กว่า คลิก **ลิงก์บัญชี Slack ของฉัน** อีกครั้ง แล้วส่งรหัสใหม่

### บอตถือว่ารหัสของฉันเป็นคำขอ

คุณส่งในช่องสนทนา หรือบัญชี Slack ของคุณลิงก์ไว้แล้ว รหัสจะรับเฉพาะในข้อความส่วนตัว และข้อความที่มีรูปแบบเหมือนรหัสจากบัญชีที่ลิงก์แล้วถือเป็นคำขอปกติ
