คู่มือนี้แสดงวิธีลิงก์ตัวตนแชทของคุณเข้ากับผู้ใช้ Control Center ของคุณ และวิธี
เลิกลิงก์

สมาชิกทุกคนทำขั้นตอนนี้ครั้งเดียวต่อผู้ให้บริการแชทหนึ่งราย มันแยกจากการเชื่อมแอป:
การเชื่อมทำให้บอทเข้าถึงได้สำหรับทั้งเวิร์กสเปซ ส่วนการลิงก์ทำให้ _คุณ_ ถูกจดจำได้
ภายในเวิร์กสเปซนั้น

## เหตุใดจึงต้องลิงก์

สะพานจะปฏิเสธที่จะลงมือแทนบัญชีแชทที่มันแปลงเป็นสมาชิกของเวิร์กสเปซไม่ได้ นั่นเป็น
ความตั้งใจ — หากไม่มีการลิงก์ ข้อความทุกฉบับจาก Slack จะต้องถูกระบุที่มาให้กับคนที่
ติดตั้งแอป และร่องรอยการตรวจสอบ ขีดจำกัดอัตราต่อ Principal และผู้รายงานตั๋วงาน
ก็จะระบุชื่อผิดคนทั้งหมด

สมาชิกที่ยังไม่ได้ลิงก์ซึ่งกล่าวถึงบอทจะได้รับคำตอบในเธรด Slack นั้นที่อธิบายวิธี
ลิงก์ ไม่มีการส่งงานใด ๆ

## ลิงก์ด้วยรหัส

1. ไปที่ **การตั้งค่า → เวิร์กสเปซ → โปรไฟล์และตัวตน** แล้วเลื่อนไปที่การ์ด
   **บัญชีแชทที่ลิงก์**
2. ในบล็อก Slack คลิก **ลิงก์บัญชี Slack ของฉัน**
3. คัดลอกคำสั่งที่มันแสดง ตัวอย่างเช่น:

```text
/cc link K7M2QP
```

4. ใน Slack ส่งคำสั่งนั้นถึงบอท — ข้อความส่วนตัวเป็นที่ที่ง่ายที่สุด
5. บอทจะยืนยันผู้ใช้ Control Center ที่คุณลิงก์อยู่ด้วยในตอนนี้ และกล่องโต้ตอบ
   ที่คุณเปิดค้างไว้จะอัปเดตบอกเรื่องนี้ในจังหวะเดียวกัน — คุณไม่ต้องปิดมันแล้ว
   ไปดูเอง

รหัสนี้:

- ใช้ได้ครั้งเดียวและหมดอายุ **15 นาที** หลังถูกสร้าง
- ถูกสร้างสำหรับ _คุณ_ เสมอ ไม่เคยสร้างให้เพื่อนร่วมทีม
- แทนที่รหัสใด ๆ ที่คุณถืออยู่แล้ว การกดปุ่มอีกครั้งจึงทำให้รหัสก่อนหน้าใช้ไม่ได้
- ถูกเก็บไว้ในหน่วยความจำเท่านั้น การรีสตาร์ตเซิร์ฟเวอร์จึงทำให้รหัสที่ค้างอยู่
  ใช้ไม่ได้ — กดปุ่มอีกครั้ง

รหัสที่ไม่รู้จัก หมดอายุ หรือถูกสร้างสำหรับเวิร์กสเปซอื่น จะล้มเหลวด้วยวิธีที่แยก
ไม่ออกจากกันแบบเดียวกัน: "that code is not valid (or has expired)"

## ลิงก์อัตโนมัติด้วยอีเมล

หากโปรไฟล์ Slack ของคุณมีอีเมลที่ผ่านการยืนยันซึ่งตรงกับผู้ใช้ Control Center
ที่ **เป็นสมาชิกของเวิร์กสเปซนี้อยู่แล้ว** สะพานจะลิงก์คุณในครั้งแรกที่คุณคุยกับมัน
ไม่ต้องใช้รหัส

ทั้งสองส่วนสำคัญเท่ากัน: การตรงกันของอีเมลพิสูจน์ตัวตน แต่มีเพียงสมาชิกภาพเท่านั้น
ที่ให้สิทธิ์เข้าถึง คนแปลกหน้าที่อีเมลของเขาบังเอิญมีอยู่บนเซิร์ฟเวอร์จึงลิงก์กับ
อะไรไม่ได้ รายชื่อจะแสดงว่าลิงก์แต่ละอันเกิดขึ้นได้อย่างไร ("จับคู่ด้วยอีเมล" หรือ
"ลิงก์ด้วยรหัส")

การลิงก์อัตโนมัติต้องใช้สโคป `users:read.email` หากไม่มี Slack จะไม่เปิดเผยที่อยู่
และเส้นทางผ่านรหัสคือเส้นทางเดียว

## ดูว่าใครถูกลิงก์ไว้

รายชื่อเป็นงานดูแลเวิร์กสเปซ มันจึงอยู่บนอีกครึ่งของพื้นผิว:
**การตั้งค่า → เวิร์กสเปซ → ทั่วไป → สะพานแชท → บัญชีที่ลิงก์** มันแสดงรายชื่อ
สมาชิกทุกคนที่ลิงก์ไว้ในเวิร์กสเปซ พร้อมบัญชี Slack ที่แต่ละคนแปลงไปถึง และวิธี
ที่ลิงก์นั้นถูกสร้างขึ้น

สถานะของคุณเองอยู่บนหน้าโปรไฟล์ของคุณ: แถว **ลิงก์บัญชี Slack ของฉัน** จะอ่านว่า
"ลิงก์กับ _your-slack-id_" เมื่อคุณลิงก์แล้ว และบอกให้คุณลิงก์เมื่อยังไม่ได้ลิงก์

รายชื่อเป็นการสมัครรับแบบสด เพราะการเปลี่ยนแปลงเกิดขึ้นที่อีกฝั่ง — คุณพิมพ์รหัส
ใน Slack ดังนั้นไม่มีคำขอใดจากแอปที่พาคำตอบกลับมาได้

## เลิกลิงก์

คลิก **เลิกลิงก์** บนแถวใดแถวหนึ่งในรายชื่อของเวิร์กสเปซ

- ใครก็เลิกลิงก์ตัวเองได้
- เฉพาะแอดมินเท่านั้นที่เลิกลิงก์สมาชิกคนอื่นได้
- การเลิกลิงก์ยังเพิกถอนรหัสลิงก์ที่ค้างอยู่ทั้งหมดของสมาชิกคนนั้นด้วย

หลังเลิกลิงก์ บัญชี Slack นั้นจะขับเคลื่อนเอเจนต์ไม่ได้อีกจนกว่าจะลิงก์ใหม่ สเปซ
ทรานสคริปต์ และตั๋วงานที่มีอยู่เดิมยังคงการระบุที่มาเดิมไว้ — การเลิกลิงก์ไม่ใช่
การถอนงานที่ผ่านมา

## การแก้ปัญหา

### บอทบอกว่าฉันไม่ใช่สมาชิกของเวิร์กสเปซนี้

บัญชี Slack ของคุณลิงก์กับผู้ใช้ Control Center แต่ผู้ใช้คนนั้นไม่มีความเป็นสมาชิก
ในเวิร์กสเปซนี้ ขอให้แอดมินเชิญคุณ ดู[การทำงานร่วมกันแบบหลายคน — ตัวตน สมาชิกภาพ และการปรากฏตัว](/th-TH/คู่มือ/แนวคิด/การทำงานร่วมกันแบบหลายคน/)

### บอทบอกว่าบทบาทของฉันเป็นแบบอ่านอย่างเดียว

บทบาท `viewer` และ `guest` เริ่มงานไม่ได้ แอดมินต้องยกระดับบทบาทของคุณเป็น
`member` หรือสูงกว่า

### คำสั่งสแลชไม่ถูกจดจำ

ตรวจสอบว่าคำสั่งสแลชนั้นมีอยู่ใน Slack และคุณกำลังส่งคำสั่งที่กล่องโต้ตอบการตั้งค่า
แสดงให้คุณ — แอดมินอาจเปลี่ยนชื่อมัน ซึ่งในกรณีนั้นกล่องโต้ตอบจะแสดงชื่อปัจจุบัน
