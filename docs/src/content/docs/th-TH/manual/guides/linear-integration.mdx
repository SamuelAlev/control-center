Linear ใน Control Center มีตัวตนสองแบบ ทั้งคู่เป็นการลงชื่อเข้าใช้ผ่านเบราว์เซอร์: ตัวตนของคุณเองสำหรับสิ่งที่คุณทำ และแอป Control Center ของเวิร์กสเปซสำหรับสิ่งที่เอเจนต์และไปป์ไลน์ทำ ตั๋วงาน โปรเจกต์ ลิงก์ ผู้ร่วมงาน การมอบหมาย และการกำหนดผู้รับผิดชอบทั้งหมดทำงานบนฐานข้อมูลของ Control Center เอง โดยไม่ต้องใช้บริการภายนอกใด ๆ — ดู[สร้างและจัดการตั๋วงาน](/th-TH/คู่มือ/วิธีทำ/จัดการตั๋วงาน/)

## ข้อกำหนดเบื้องต้น

- เซิร์ฟเวอร์สามารถทำให้คนลงชื่อเข้าใช้ Linear ได้: ผ่าน Control Center Connect หรือด้วยแอป Linear ของเซิร์ฟเวอร์เอง ([ลงทะเบียนแอป Linear ของคุณเอง](#ลงทะเบียนแอป-linear-ของคุณเอง)) เจ้าของเซิร์ฟเวอร์เป็นผู้เลือกใน **การตั้งค่า → เซิร์ฟเวอร์ → ลงชื่อเข้าใช้ครั้งเดียว**
- ผู้ดูแลเวิร์กสเปซ เพื่อเลือก Linear เป็นผู้ให้บริการตั๋วงาน และเชื่อมต่อระบบอัตโนมัติของ Linear

## เลือก Linear สำหรับเวิร์กสเปซ

1. ไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** แล้วหาการ์ด **ระบบตั๋วงาน**
2. ตั้ง **ผู้ให้บริการตั๋วงาน** เป็น **Linear**

ตั๋วงานที่คุณสร้างตั้งแต่นั้นจะถูกประทับ `provider: linear` **ในเครื่อง** จะเก็บตั๋วไว้ในฐานข้อมูลของเซิร์ฟเวอร์นี้ และซ่อนแถว Linear: ไม่มีอะไรต้องยืนยันตัวตน

## ลงชื่อเข้าใช้ Linear

บนการ์ดเดียวกัน แถว **Linear** เป็นของคุณ:

1. คลิก **ลงชื่อเข้าใช้ Linear**
2. อนุมัติในเบราว์เซอร์ของคุณ
3. เมื่อใช้แอปของเซิร์ฟเวอร์เอง ไดอะล็อกจะตรวจพบเองว่าการลงชื่อเข้าใช้เสร็จแล้ว เมื่อผ่าน Connect ให้พิมพ์รหัสแปดตัวอักษรที่เบราว์เซอร์แสดง หรือให้เบราว์เซอร์เปิด Control Center ผ่านลิงก์ `control-center://`

สิ่งที่คุณทำใน Linear จาก Control Center จะใช้การลงชื่อเข้าใช้นี้เท่านั้น และไม่มีอย่างอื่น หากคุณยังไม่ได้ลงชื่อเข้าใช้ แอปจะขอให้คุณลงชื่อเข้าใช้ แทนที่จะทำในฐานะคนอื่น

## เชื่อมต่อระบบอัตโนมัติของ Linear

แถว **ระบบอัตโนมัติของ Linear** แทนแอป Control Center ของเวิร์กสเปซใน Linear การซิงค์ตั๋ว ไปป์ไลน์ และเอเจนต์ใช้แอปนี้เขียนข้อมูล ดังนั้นประเด็นและความคิดเห็นที่ระบบอัตโนมัติสร้างจะปรากฏในชื่อ Control Center ไม่ใช่ชื่อของบุคคล

1. ผู้ดูแลเวิร์กสเปซคลิก **เชื่อมต่อ Linear เพื่อใช้ระบบอัตโนมัติ**
2. เขาอนุมัติแอปสำหรับเวิร์กสเปซ Linear ในเบราว์เซอร์ ตามที่กล่าวข้างต้น

หลังจากนั้นแถวจะแสดง “เชื่อมต่อกับ _เวิร์กสเปซ Linear ของคุณ_” เฉพาะผู้ดูแลเวิร์กสเปซเท่านั้นที่เชื่อมต่อหรือยกเลิกการเชื่อมต่อได้

ไม่มีข้อมูลรับรอง Linear ใดถูกวางไว้ในแซนด์บ็อกซ์ของเอเจนต์: เอเจนต์เขียนตั๋วผ่านเครื่องมือของ Control Center เอง ซึ่งจะถามกฎ **เขียนไปยังตัวติดตามภายนอก** ก่อน

## ลงทะเบียนแอป Linear ของคุณเอง

ใช้แอปของคุณเองเมื่อคุณเลือก **ใช้แอปของฉันเอง** แอปของเซิร์ฟเวอร์เองใช้ได้เฉพาะตอนนั้น: เมื่อใช้ Control Center Connect หรือ Connect แบบกำหนดเอง Connect จะให้บริการทุกช่องทาง รวมถึง Linear และแอปของเซิร์ฟเวอร์กับคีย์ API ของบริการจะยังถูกบันทึกไว้แต่ไม่ได้ใช้งาน แอปของเวิร์กสเปซ ([ด้านล่าง](#มอบแอป-linear-ของตัวเองให้เวิร์กสเปซหนึ่งแห่ง)) ยังคงใช้ได้ในทุกโหมด

1. สร้างแอป OAuth ที่ [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new)
2. เพิ่ม callback URL ทั้งสองที่ **การตั้งค่า → เซิร์ฟเวอร์ → ลงชื่อเข้าใช้ครั้งเดียว → แอปผู้ให้บริการ → Linear** แสดงภายใต้ **URL เรียกกลับ** ให้ใช้ตามที่แสดงทุกตัวอักษร: `<server origin>/oauth/linear/callback` และ `<server origin>/oauth/linear_app/callback`
3. วาง **Client id** ลงในบล็อก Linear

ไม่มี client secret: เซิร์ฟเวอร์ลงชื่อเข้าใช้ด้วย PKCE โทเค็นรีเฟรชของ Linear จะหมดอายุหลังไม่ได้ใช้งาน 30 วัน เซิร์ฟเวอร์จึงต่ออายุการลงชื่อเข้าใช้ Linear ทุกรายการที่เก่ากว่า 20 วัน วันละครั้ง

บล็อกเดียวกันยังรับ **คีย์ API ของบริการ** ที่เป็นทางเลือกได้ นั่นคือข้อมูลรับรอง Linear ของเซิร์ฟเวอร์เอง สำหรับระบบอัตโนมัติในเวิร์กสเปซที่ยังไม่ได้เชื่อมต่อระบบอัตโนมัติของ Linear เก็บไว้ใน **การตั้งค่า** หรือในไฟล์ `.env` ของเซิร์ฟเวอร์เป็น `LINEAR_API_KEY`: เซิร์ฟเวอร์จะปฏิเสธการเริ่มทำงานเมื่อ `LINEAR_API_KEY` ถูกส่งออกไปยังสภาพแวดล้อมของโปรเซส

## มอบแอป Linear ของตัวเองให้เวิร์กสเปซหนึ่งแห่ง

เวิร์กสเปซสามารถลงชื่อเข้าใช้ Linear ผ่านแอปของตัวเองแทนแอปของเซิร์ฟเวอร์ได้ มีเพียงผู้ดูแลเวิร์กสเปซหรือเจ้าของเท่านั้นที่ตั้งค่าได้

1. สร้างแอป OAuth ของ Linear ตามขั้นตอนข้างต้น
2. ไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป → แอปผู้ให้บริการ** แล้วเปิด **Linear**
3. เลือก **ใช้แอปของเวิร์กสเปซนี้**
4. เพิ่ม callback URL ทั้งสองที่แถวแสดงภายใต้ **URL เรียกกลับ** ลงในแอป Linear ให้ตรงทุกตัวอักษร
5. วาง **Client id** ของแอป และใส่ **คีย์ API ของบริการ** ได้ตามต้องการสำหรับระบบอัตโนมัติของเวิร์กสเปซนี้

แอปของเวิร์กสเปซจะตอบทุกการลงชื่อเข้าใช้และคำขอระบบอัตโนมัติของ Linear ในเวิร์กสเปซนี้ ไม่ว่าเซิร์ฟเวอร์จะลงชื่อเข้าใช้ผู้คนด้วยวิธีใด มันจะไม่ถอยกลับไปใช้แอปของเซิร์ฟเวอร์หรือ Connect: จนกว่าจะตั้งค่า client id Linear จะปิดอยู่ในเวิร์กสเปซนี้ และแถวจะแจ้งว่าขาดอะไร คีย์ API ของบริการใช้เฉพาะที่นี่ หากไม่มี การซิงค์ต้องใช้ **เชื่อมต่อ Linear สำหรับระบบอัตโนมัติ**

การสลับระหว่างแอปของเซิร์ฟเวอร์กับแอปของเวิร์กสเปซ หรือเปลี่ยน client id ของเวิร์กสเปซ จะทำให้ทุกคนในเวิร์กสเปซนี้ออกจากระบบ Linear และยกเลิกการเชื่อมต่อระบบอัตโนมัติ พวกเขาจะลงชื่อเข้าใช้อีกครั้งผ่านแอปใหม่ **ใช้แอปของเซิร์ฟเวอร์นี้** จะลบฟิลด์ที่บันทึกไว้ของเวิร์กสเปซ ความลับเป็นแบบเขียนอย่างเดียว: แถวจะแสดงเพียงว่ามีค่าที่บันทึกไว้หรือไม่ เวิร์กสเปซอื่นบนเซิร์ฟเวอร์ไม่ได้รับผลกระทบ

## การแก้ปัญหา

### แถว Linear แจ้งว่ายังไม่ได้ตั้งค่าการลงชื่อเข้าใช้

เซิร์ฟเวอร์ไม่มีทั้งแอป Linear ของตัวเองและ Connect เจ้าของเซิร์ฟเวอร์เลือกหนึ่งอย่างได้ใน **การตั้งค่า → เซิร์ฟเวอร์ → ลงชื่อเข้าใช้ครั้งเดียว** เมื่อเวิร์กสเปซใช้แอปของตัวเอง แถวจะแจ้งแทนว่าการตั้งค่ายังไม่เสร็จ: ผู้ดูแลเวิร์กสเปซเพิ่ม client id ได้ที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป → แอปผู้ให้บริการ**

### การซิงค์ตั๋วงานล้มเหลวด้วยข้อผิดพลาดการยืนยันตัวตน

เวิร์กสเปซยังไม่ได้เชื่อมต่อระบบอัตโนมัติของ Linear และเซิร์ฟเวอร์ไม่มีคีย์ API ของบริการ ทำให้การซิงค์ไม่มีข้อมูลรับรองที่ใช้ได้ ผู้ดูแลเวิร์กสเปซคลิก **เชื่อมต่อ Linear เพื่อใช้ระบบอัตโนมัติ** เพื่อแก้ไข

### การเชื่อมต่อระบบอัตโนมัติแจ้งว่าเวิร์กสเปซ Linear นั้นเชื่อมต่ออยู่ที่อื่นแล้ว

แอป Control Center ของเวิร์กสเปซ Linear นั้นเชื่อมต่ออยู่กับเซิร์ฟเวอร์ Control Center เครื่องอื่นแล้ว
