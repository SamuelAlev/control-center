วางคีย์ API ของ Linear ลงบนเซิร์ฟเวอร์โดยผูกกับผู้ใช้ของคุณ เหมือนกับวิธีที่คุณ
เชื่อมต่อโฮสต์โค้ด ตั๋วงาน โปรเจกต์ ลิงก์ ผู้ร่วมงาน การมอบหมายงาน และการกำหนด
ผู้รับผิดชอบ ทำงานกับฐานข้อมูลของ Control Center เองทั้งหมด โดยไม่ต้องพึ่งบริการ
ภายนอก — ดูที่ [สร้างและจัดการตั๋วงาน](/th-TH/คู่มือ/วิธีทำ/จัดการตั๋วงาน/)

## จัดเก็บคีย์ Linear ของคุณ

**คีย์ API ของตั๋วงาน** อยู่ที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** บนการ์ดตั๋วงาน
โดยเก็บคีย์ไว้บนเซิร์ฟเวอร์ผูกกับ id ผู้ใช้ของคุณ คีย์ของเซิร์ฟเวอร์เองสำหรับงานที่
ไม่มีคนเฝ้า มาจาก `LINEAR_API_KEY` หรือการ์ด **แอปผู้ให้บริการ** และจะถูกฉีดเป็น
`TICKETING_API_KEY` เฉพาะเมื่อเอเจนต์นั้นมีความสามารถ **อนุญาตการเรียก ticketing API**

## ประทับตั๋วงานใหม่เป็น Linear

**ผู้ให้บริการตั๋วงาน** (ขั้นตอนแรกของการตั้งค่าเริ่มต้น และ
`/workspaces/<workspaceId>/api-keys`) มีให้เลือก `local` และ `linear` การเลือก
`linear` จะประทับ `provider: linear` ลงบนตั๋วงานที่คุณสร้างต่อจากนั้น
