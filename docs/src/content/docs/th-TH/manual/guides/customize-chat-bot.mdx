คู่มือนี้แสดงวิธีปรับรูปร่างแอปบอทฝั่งผู้ให้บริการ โดยไม่ต้องออกจาก Control Center

## สิ่งที่ต้องมีก่อน

- บทบาท `owner` หรือ `admin` ในเวิร์กสเปซ
- ผู้ให้บริการที่ **เชื่อมต่อแล้ว** แถว **ปรับแต่งบอท** จะปรากฏก็ต่อเมื่อเวิร์กสเปซเชื่อมต่อแล้วเท่านั้น
- แอปที่ Control Center จัดการได้ สำหรับ Slack นั่นหมายความว่าการเชื่อมต่อเก็บรีเฟรชโทเค็นของการตั้งค่าแอป (`xoxe-…`) ไว้ หากไม่มี แถวนั้นจะบอกเช่นนั้นและยังคงถูกปิดใช้งาน

## สิ่งที่คุณเปลี่ยนได้

| ฟิลด์                 | ความหมาย                                         | ขีดจำกัด                                                      |
| --------------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| **ชื่อแอป**          | ผู้ให้บริการแสดงแอปในรายการอย่างไร                  | 1–35 ตัวอักษร                                            |
| **ชื่อบอท (สิ่งที่สมาชิกพิมพ์หลัง @)**  | สิ่งที่สมาชิกพิมพ์หลัง `@`                     | 1–80 ตัวอักษร                                            |
| **คำอธิบายสั้น**       | หนึ่งบรรทัดที่ผู้ให้บริการแสดง                     | ไม่เกิน 140 ตัวอักษร                                    |
| **สิ่งที่บอทบอกว่าทำได้** | แสดงเหนือ DM ที่คุยกับบอท                   | ไม่เกิน 300 ตัวอักษร                                    |
| **คำสั่งสแลช**     | คำสั่งที่สมาชิกเรียกใช้ โดยไม่มีเครื่องหมายสแลช   | ตัวพิมพ์เล็ก เฉพาะ `a–z 0–9 _ -` และตัดที่ 32 ตัวอักษร |
| **ข้อความตรง**   | บอทเปิดประสบการณ์ DM/เอเจนต์หรือไม่ | เปิดหรือปิด                                                  |

Control Center ตรวจสอบฟิลด์ข้อความทั้งสี่ก่อนเรียกผู้ให้บริการ คุณจึงได้ข้อความ "the app name must be between 1 and 35 characters" แทนที่จะเป็น `invalid_manifest` ที่อ่านไม่ออกจากเซิร์ฟเวอร์ที่คุณมองไม่เห็น คำสั่งไม่ถูกปฏิเสธ แต่ถูกปรับให้เป็นรูปแบบมาตรฐาน: เครื่องหมายสแลชนำหน้าถูกตัดออก ส่วนที่เหลือถูกแปลงเป็นตัวพิมพ์เล็ก อักขระใดที่อยู่นอก `a–z 0–9 _ -` จะถูกทิ้ง และผลลัพธ์ที่ว่างเปล่าจะกลับไปใช้ `cc`

## แก้ไขบอท

1. ไปที่ **การตั้งค่า → เวิร์กสเปซ → ทั่วไป** แล้วเลื่อนไปที่การ์ด **สะพานแชท**
2. ในบล็อกของผู้ให้บริการ คลิก **ปรับแต่งบอท**
3. กล่องโต้ตอบจะเปิดด้วยค่า _สด_ ของแอปที่อ่านกลับมาจากผู้ให้บริการ — สิ่งที่คุณเริ่มต้นจึงเป็นการเปลี่ยนแปลงที่ใครบางคนทำไว้ใน UI ของ Slack เอง
4. แก้ไขสิ่งที่คุณต้องการแล้วบันทึก

การอ่านค่าสดเหล่านั้นทำให้เกิดการหมุนโทเค็นฝั่ง Slack จึงเป็นเหตุผลว่าทำไมแถวจึงต้องคลิกอย่างตั้งใจ ไม่ใช่สิ่งที่หน้าเว็บทำเองเมื่อโหลด

การเขียนจะซ้อนทับการเปลี่ยนแปลงของคุณลงบนคำจำกัดความปัจจุบันของแอป สิ่งใดก็ตามที่ Control Center ไม่ได้จำลองไว้ — คำสั่งสแลชคำที่สองที่คุณเพิ่มใน Slack ขั้นตอนของเวิร์กโฟลว์ การตั้งค่าที่ไม่เกี่ยวข้อง — จะคงอยู่โดยไม่ถูกแตะต้อง สโคปและเหตุการณ์จะถูกผสานเข้าไป ไม่เคยถูกหักออก

หลังจากบันทึก Control Center จะอ่านตัวตนของบอทใหม่ เพื่อให้ชื่อในการตั้งค่าตรงกับชื่อในแอปแชท

## ติดตั้งใหม่เมื่อสิทธิ์เปลี่ยน

:::caution[ติดตั้งใหม่หลังการเปลี่ยนสิทธิ์]
Slack นำคำจำกัดความใหม่ของแอปไปใช้ทันที แต่ยังคงการอนุญาตที่ติดตั้งไว้
ตามเดิม ติดตั้งแอปใหม่เพื่อให้การเปลี่ยนสิทธิ์มีผล สะพานจะทำงานต่อไป
ด้วยการอนุญาตเดิมจนกว่าคุณจะติดตั้งใหม่
:::

เมื่อการบันทึกเปลี่ยนสิทธิ์ กล่องโต้ตอบจะยังเปิดอยู่และแสดงข้อความ
"Slack เปลี่ยนสิทธิ์ของแอป ติดตั้งแอปใหม่เพื่อให้มีผล" พร้อมปุ่ม
**ติดตั้งแอปใหม่** ที่เปิดหน้าติดตั้งแอปในทีมของ Slack สำหรับแอปนั้น
ใน Slack นั่นคือ **Install App → Reinstall to Workspace**

## เปลี่ยนชื่อคำสั่งสแลช

เปลี่ยน **คำสั่งสแลช** แล้วบันทึก จากนั้นสะพานจะเขียนคำแนะนำโดยใช้คำสั่งใดก็ตามที่มันถูกเรียกใช้ครั้งล่าสุด ข้อความช่วยเหลือและคำแนะนำการลิงก์จึงเปลี่ยนตามชื่อใหม่ แทนที่จะระบุชื่อคำสั่งที่ไม่มีอยู่แล้ว

การเปลี่ยนชื่อไม่ทำให้เธรดที่เชื่อมไว้แล้วเสียหาย เพราะเธรดถูกคีย์ด้วยบทสนทนา ไม่ใช่ด้วยคำสั่ง

## สิ่งที่ Control Center จะไม่เปลี่ยน

- **การตั้งค่าเชิงโครงสร้าง** ทรานสปอร์ต (Socket Mode) สโคปที่จำเป็น และการสมัครรับเหตุการณ์ เป็นสิ่งที่ถูกกำหนดตายตัว ไม่ใช่สิ่งที่ให้เลือก แอปที่ตั้งค่าให้เงียบได้จากหน้าจอตั้งค่าคือตั๋วซัพพอร์ต ไม่ใช่ฟีเจอร์
- **ไอคอนของบอท** มีเพียงการตั้งค่าแอปของผู้ให้บริการเองเท่านั้นที่เปลี่ยนได้ และกล่องโต้ตอบก็บอกไว้เช่นนั้น
- **การย้ายฟีเจอร์ของผู้ให้บริการเอง** แอปที่อยู่ในรูปแบบผู้ช่วยรุ่นเก่าของ Slack แล้วจะคงรูปแบบนั้นไว้ กล่องโต้ตอบนี้แก้ไขคำอธิบาย ไม่ได้ย้ายแอป

## การแก้ปัญหา

### ไม่มีแถว "ปรับแต่งบอท" เลย

เวิร์กสเปซยังไม่ได้เชื่อมต่อ แถวนี้จะปรากฏก็ต่อเมื่อบล็อกของผู้ให้บริการ
แสดงการเชื่อมต่อที่ใช้งานอยู่ ดู [ตั้งค่าการผสาน Slack](/th-TH/คู่มือ/วิธีทำ/การผสาน-slack/)

### แถว "ปรับแต่งบอท" ถูกปิดใช้งาน

การเชื่อมต่อไม่มีข้อมูลรับรองสำหรับจัดการแอป — คำบรรยายใต้แถวระบุว่า
"Control Center ต้องมีโทเค็นการตั้งค่าแอปเพื่อแก้ไขบอท เชื่อมต่อใหม่และ
ใส่หนึ่งอัน" สำหรับ Slack ให้สร้างคู่โทเค็นการตั้งค่าแอปที่
[api.slack.com/apps](https://api.slack.com/apps) แล้วเชื่อมต่อใหม่โดยกรอก
รีเฟรชโทเค็นไว้ นี่เป็นเรื่องคาดหมายสำหรับแอปที่สร้างด้วยมือหรือสร้างผ่าน
**สร้างใน Slack** เพราะ Slack ไม่เคยรายงานว่าแอปใดที่มันสร้างขึ้น

### "Control Center does not know which app to edit"

การเชื่อมต่อที่จัดเก็บไว้ไม่มี app id — โดยทั่วไปคือแอปที่เชื่อมต่อด้วยมือก่อนที่จะมีการบันทึก id ให้เชื่อมต่อเวิร์กสเปซใหม่ หรือสร้างแอปจาก Control Center

### ชื่อใหม่ของบอทยังไม่ปรากฏในแชท

ผู้ให้บริการแคชเมทาดาทาของแอปไว้ชั่วคราว หากชื่อยังเป็นค่าเก่าอยู่หลังจากผ่านไปหนึ่งนาที ให้ตรวจสอบว่าการบันทึกขอให้คุณติดตั้งแอปใหม่หรือไม่
