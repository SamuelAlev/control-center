คู่มือนี้แสดงวิธีทำงานกับที่จัดเก็บความรู้ของเวิร์กสเปซ

สิ่งสำคัญที่ควรรู้ก่อนเริ่ม: **UI ของหน่วยความจำนั้นเป็นพื้นที่สำหรับตรวจทาน ไม่ใช่พื้นที่สำหรับสร้างเนื้อหา** ข้อเท็จจริงและนโยบายเขียนโดยเอเจนต์ — ผ่าน `propose_fact` และ `propose_policy` โดยมี `supersede_fact` และ `supersede_policy` ใช้แทนที่ `remember` เขียนรายการ hot-tier ที่ผูกกับเซสชัน ซึ่ง `consolidate_memory` อาจยกระดับเป็นข้อเท็จจริงในภายหลัง ข้อตัดสินใจจากการประชุมจะถูกเก็บเข้าสู่โดเมน `decisions`; ไม่มีการเก็บจากการรันเอเจนต์ที่เสร็จสิ้น สิ่งที่คุณทำที่นี่คืออ่านสิ่งที่เอเจนต์เขียน แก้ไข ปิดใช้ หรือลบมัน

หน่วยความจำอยู่ที่ **การตั้งค่า → เวิร์กสเปซ → หน่วยความจำ** (`/workspaces/<id>/settings/memory`) ไม่ใช่จุดหมายระดับบนสุดในแถบข้าง

## แท็บทั้งสาม

หน้านี้มีสามแท็บพอดี ข้อเท็จจริงและนโยบายแสดงจำนวนแบบเรียลไทม์ ส่วนกราฟไม่แสดง:

- **ข้อเท็จจริง** — ข้อเท็จจริงทุกตัวในเวิร์กสเปซ พร้อมจำนวนของตัวที่ยังไม่ถูกแทนที่
- **นโยบาย** — กฎเชิงบรรทัดฐานที่จัดกลุ่มตามโดเมน พร้อมจำนวนของตัวที่ active
- **กราฟความรู้** — แคนวาสแบบโต้ตอบของโดเมน หัวข้อ ข้อเท็จจริง และนโยบาย

โดเมนไม่ใช่สิ่งที่คุณสร้างขึ้น โดเมนจะถือกำเนิดเมื่อเอเจนต์เขียนข้อเท็จจริงหรือนโยบายตัวแรกเข้าไป; ไม่มีตัวควบคุมสำหรับสร้างโดเมนที่ไหนใน UI เลย

## ตรวจทานและแก้ไขข้อเท็จจริง

1. เปิดแท็บ **ข้อเท็จจริง**
2. ใช้กล่องค้นหาเพื่อกรองรายการให้แคบลง มันเป็นตัวกรองสตริงย่อยธรรมดาบนโดเมน หัวข้อ และเนื้อหาของข้อเท็จจริงแต่ละตัว — ไม่มีดัชนีคำค้น ไม่มีการจัดอันดับ
3. ใช้ตัวกรองขอบเขตเพื่อแสดงทุกขอบเขต เฉพาะข้อเท็จจริงระดับทั้งเวิร์กสเปซ หรือข้อเท็จจริงของรีโพสิทอรีเดียว
4. ใช้ตัวสลับการเรียงลำดับเพื่อจัดเรียงตามล่าสุดหรือตามความมั่นใจ
5. คลิกตัวควบคุมแก้ไขของข้อเท็จจริง

กล่องโต้ตอบแก้ไขให้คุณเปลี่ยน:

- **โดเมน** — ย้ายข้อเท็จจริงระหว่างโดเมน
- **หัวข้อ** — ป้ายสั้น ๆ ของมัน
- **เนื้อหา** — ข้อความความรู้
- **ความมั่นใจ** — สไลเดอร์ที่เพิ่มทีละ 5%

บันทึกเพื่อเขียนกลับ ไม่มีปุ่ม **เพิ่มข้อเท็จจริง**; กล่องโต้ตอบเปิดได้เฉพาะบนแถวที่มีอยู่แล้ว

## ดูข้อเท็จจริงที่ถูกแทนที่

แท็บข้อเท็จจริงมีสวิตช์ **แสดงที่ถูกแทนที่** ข้อเท็จจริงที่ถูกแทนที่จะถูกซ่อนไว้โดยค่าเริ่มต้นและถูกเปิดเผยด้วยสวิตช์นั้น ซึ่งเป็นที่อยู่ของร่องรอยการตรวจสอบ — การแทนที่ไม่มีวันลบ

## ลบข้อเท็จจริง

ใช้ตัวควบคุมลบของข้อเท็จจริงแล้วยืนยัน นี่เป็นการลบจริง ไม่ใช่การแทนที่: ใช้มันกับข้อเท็จจริงที่บันทึกไว้ผิดตั้งแต่แรก และปล่อยให้เอเจนต์แทนที่ข้อเท็จจริงที่_เนื้อหา_เปลี่ยนไปแล้ว

## จัดการนโยบาย

แท็บ **นโยบาย** จัดกลุ่มนโยบายที่ active ตามโดเมน และลดตัวที่ไม่ active ลงไปไว้ในส่วนท้าย ต่อนโยบายหนึ่งตัวคุณสามารถ:

- **แก้ไข** มัน
- **ลบ** มัน
- **ปิดใช้** / **เปิดใช้** มัน — ตัวเลือกที่ย้อนกลับได้และมักเป็นตัวที่ถูกต้อง มีเพียงนโยบายที่ active เท่านั้นที่ไปถึงพรอมต์ของเอเจนต์

เช่นเดียวกับข้อเท็จจริง ไม่มีตัวควบคุมสำหรับสร้าง

## สำรวจกราฟความรู้

แท็บ **กราฟความรู้** จัดวางโดเมน หัวข้อ ข้อเท็จจริง และนโยบายเป็นแคนวาสโหนดที่นำทางได้ — เลื่อน ซูม ลากโหนด แตะโหนดหนึ่งจะเปิดแผ่นรายละเอียดของมัน ซึ่งเข้าถึงกล่องโต้ตอบแก้ไขชุดเดียวกันได้ มันเป็นวิธีที่เร็วที่สุดในการดูว่าโดเมนใดมีข้อมูลอยู่จริง

## แก้ไขหน่วยความจำทำงานของเอเจนต์

หน่วยความจำทำงานเป็นสมุดจดชั่วคราวส่วนตัวของเอเจนต์แต่ละตัว ถูกฉีดเข้าไปในพรอมต์ของมันตอนสั่งงาน เอเจนต์เขียนมันเองด้วย `record_observation` และ `update_my_notes` แต่คุณสามารถอ่านและแก้ไขมันได้โดยตรง:

**การตั้งค่า → เวิร์กสเปซ → เอเจนต์** → เลือกเอเจนต์ → แท็บ **หน่วยความจำ**

## การให้สิทธิ์เข้าถึง

การให้สิทธิ์เข้าถึงหน่วยความจำจับคู่บทบาทของเอเจนต์เข้ากับสิทธิ์ (`none`, `read`, `write`) ต่อโดเมน เขียนมันด้วยการดำเนินการ `memory_access_grant.*`

มีสองเรื่องที่ต้องเข้าใจเกี่ยวกับวิธีที่สิทธิ์มีผลจริง:

- **การอ่านเป็นแบบ fail-open** เมื่อไม่มีแถวการให้สิทธิ์สำหรับคู่ (role, domain) สิทธิ์ที่มีผลจริงคือ `read` การเขียนเดียวที่โยนข้อผิดพลาดเมื่อไม่มี `write` คือ `propose_policy` การเขียนข้อเท็จจริงไม่ได้ถูกควบคุมด้วยการให้สิทธิ์
- **การให้สิทธิ์ผูกกับบทบาทของเอเจนต์** เครื่องมือที่ใช้เสนอจะตั้งค่า `agent_role` ที่หายไปเป็น `general` โดยค่าเริ่มต้น การให้สิทธิ์ที่เขียนสำหรับบทบาทอื่นไม่ผูกมัดเอเจนต์เหล่านั้น; แต่การให้สิทธิ์ `general` ผูกมัด

## การค้นหาไม่เหมือนกันทุกที่

มีสามสิ่งที่ต่างกันถูกเรียกว่า “การค้นหาหน่วยความจำ” และพวกมันไม่ตรงกัน:

| ที่ไหน                              | ทำอะไร                                                                                                                     |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| กล่องค้นหาของแท็บข้อเท็จจริง         | ตัวกรองสตริงย่อยบนข้อเท็จจริงที่โหลดไว้ในไคลเอนต์แล้ว                                                                       |
| op ของ RPC `memory_fact.search`     | การค้นหาคำค้นแบบ FTS5 เท่านั้น — ไคลเอนต์แบบบางไม่สามารถส่ง embedding ของคำค้นไปด้วยได้ การค้นหาแบบ hybrid จึงอยู่ภายในโฮสต์ |
| เครื่องมือ `search_memory` ฝั่งเอเจนต์ | `keyword`, `semantic` หรือ `hybrid` (ค่าเริ่มต้น) Hybrid หลอมรวมสี่เสียง: lexical, semantic, temporal และ graph              |

ดังนั้นเอเจนต์กับหน้าหน่วยความจำจะไม่จัดอันดับคำค้นเดียวกันในแบบเดียวกัน เมื่อคุณกำลังตรวจสอบว่าเอเจนต์เรียกคืนอะไรได้จริง ๆ ให้ถามเอเจนต์

## Embedding

ข้อเท็จจริงจะถูกสร้าง embedding **ตอนเขียน** และเฉพาะเมื่อโมเดล embedding บนอุปกรณ์ถูกติดตั้งไว้แล้วเท่านั้น ตรวจสอบสถานะของมันที่ **การตั้งค่า → เซิร์ฟเวอร์ → การวินิจฉัยและความเป็นส่วนตัว → ค้นหาเชิงความหมาย** ติดตั้งโมเดลก่อนที่เอเจนต์จะเริ่มเขียนหน่วยความจำ หากคุณต้องการการเรียกคืนเชิงความหมาย
