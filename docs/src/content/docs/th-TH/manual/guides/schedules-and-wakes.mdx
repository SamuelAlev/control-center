เอเจนต์ไม่ได้หลับหรือคอยตรวจซ้ำๆ ระหว่างรอ เอเจนต์หรือคุณเป็นผู้ตั้ง **การปลุก** ซึ่งเป็นคำขอที่คงทนให้เริ่มหรือทำการรันของเอเจนต์ต่อในการสนทนา ในเวลาที่กำหนดหรือเมื่อมีบางอย่างเกิดขึ้น ทุกการรันที่เซิร์ฟเวอร์เริ่มโดยไม่มีใครพิมพ์จะเริ่มต้นเป็นการปลุก ได้แก่ ช่วงถัดไปของเป้าหมาย ตารางเวลา การเฝ้าดู ข้อความตอบกลับจากเอเจนต์อื่น งานที่มอบหมายและเสร็จแล้ว การสิ้นสุดของขีดจำกัดการใช้งาน และงานที่ค้างอยู่หลังการรีสตาร์ต การปลุกถูกเก็บไว้ในฐานข้อมูลของเวิร์กสเปซ จึงอยู่รอดจากการรีสตาร์ต

## ตั้งตารางเวลาให้เอเจนต์ด้วยตัวคุณเอง

พิมพ์หนึ่งในคำสั่งเหล่านี้ในช่องเขียนข้อความของการสนทนา:

```text
/loop every 30m --days 3 check the deploy and fix what broke
/loop keep the flaky tests green
/schedule in 2h look at the overnight benchmark
/schedule at 09:00 summarize what changed overnight
/schedule cron "0 9 * * 1-5" --max 20 triage new tickets
```

| คำสั่ง | สิ่งที่ทำ |
| --- | --- |
| `/loop every <interval> <prompt>` | ปลุกเอเจนต์ด้วยพรอมต์ทันที และซ้ำทุกช่วงเวลาที่กำหนด (ห่างกันอย่างน้อย 60 วินาที) |
| `/loop <prompt>` | ลูปที่เลือกจังหวะเอง: ปลุกเอเจนต์ทันที และหลังแต่ละการรัน เอเจนต์จะเลือกดีเลย์ถัดไปที่ 1 ถึง 60 นาที (ค่าเริ่มต้นคือ 20 นาที) |
| `/schedule in <duration> <prompt>` | ปลุกเอเจนต์หนึ่งครั้งหลังจากดีเลย์ |
| `/schedule at <HH:MM or ISO time> <prompt>` | ปลุกเอเจนต์หนึ่งครั้ง `HH:MM` คือเวลานั้นครั้งถัดไปในเขตเวลาของเวิร์กสเปซ เวลาแบบ ISO ที่ไม่มีออฟเซ็ตคือ UTC |
| `/schedule cron "<expression>" <prompt>` | ปลุกเอเจนต์ตามครอนห้าฟิลด์ อ่านในเขตเวลาของเวิร์กสเปซ เครื่องหมายคำพูดเป็นทางเลือก |

- `--max <N>` จำกัดจำนวนการรัน `--days <N>` ทำให้ตารางเวลาสิ้นสุดหลังจากจำนวนวันนั้น (ค่าเริ่มต้น 30 วัน สูงสุด 365 วัน) และ `--budget <dollars>` จำกัดว่าตารางเวลาใช้จ่ายได้รวมทั้งหมดเท่าไร (มิฉะนั้นใช้ค่าเริ่มต้นของเวิร์กสเปซ เริ่มต้นที่ 50 ดอลลาร์)
- `/loop` ทำการรันแรกทันที ส่วน `/schedule` รอจนถึงเวลาของมัน
- ระยะเวลาใช้ `s`, `m`, `h` และ `d` เช่น `90s`, `20m` หรือ `1h30m`
- คำสั่งเหล่านี้อ่านเฉพาะในข้อความที่คุณพิมพ์เองเท่านั้น

ช่องเขียนข้อความช่วยคุณเขียนคำสั่งเหล่านี้ หลัง `/loop` หรือ `/schedule` และเว้นวรรค รายการแนะนำจะเสนอเวลาที่มันจะทำงาน และจะแคบลงเมื่อคุณพิมพ์ พิมพ์ `--` หลังเวลาเพื่อดูขีดจำกัด Enter หรือ Tab เลือกแถวและไม่ส่งอะไรเลย จากนั้นบรรทัดเหนือข้อความของคุณจะอ่านคำสั่งกลับมา: จะทำงานเมื่อไร จะจบเมื่อไร และยังขาดอะไรอยู่ หากคุณกด Enter ที่คำสั่งที่อ่านไม่ได้ บรรทัดนั้นจะบอกว่าผิดตรงไหน และฉบับร่างของคุณจะยังอยู่

คุณยังสร้างตารางเวลาภายใต้ **การตั้งค่า → เวิร์กสเปซ → ตารางเวลา** ได้ด้วย **ตารางเวลาใหม่**: เลือกสเปซ การสนทนา และเอเจนต์ เวลาที่จะทำงาน สิ่งที่แต่ละการรันเริ่มจาก วันสิ้นสุด เพดานจำนวนการรัน และเพดานค่าใช้จ่าย **หากเอเจนต์ไม่ว่าง** ใช้เลือกระหว่างข้ามการทำงานครั้งนั้นกับรอจนกว่าเอเจนต์จะว่าง **แต่ละครั้งที่ทำงาน** ใช้เลือกระหว่างเริ่มการรันกับเพียงแจ้งให้คุณทราบพร้อมโน้ต

## สิ่งที่เอเจนต์ตั้งไว้

เอเจนต์ใช้เครื่องมือ `wake_me` สำหรับสิ่งเดียวกัน และสำหรับการเฝ้าดู:

| การเฝ้าดู | ทำงานเมื่อ |
| --- | --- |
| `on:pr_checks` | การตรวจของ pull request ของสเปซเสร็จสิ้น |
| `on:pr_review` | pull request ของสเปซได้รับการรีวิวหรือการตอบกลับ |
| `on:pr_merged` | pull request ของสเปซถูกผสาน |
| `on:environment` | งานหนึ่งของสภาพแวดล้อมของสเปซออกจากการทำงาน หรือสภาพแวดล้อมพร้อมใช้งาน |
| `on:ticket:<id>` | ตั๋วงานถึงสถานะสุดท้าย |
| `on:pipeline_run:<id>` | การรันไปป์ไลน์สิ้นสุด |

- การเฝ้าดู pull request จะได้ยินเฉพาะ pull request ของสเปซเอง หรือ pull request หนึ่งรายการที่ระบุ (`on:pr_checks:acme/shop-ui#12`) การเฝ้าดูสิ่งที่บุคคลของมันอ่านไม่ได้จะถูกปฏิเสธ
- การกระทำของเอเจนต์เองไม่ทำให้การเฝ้าดูของมันทำงาน เหตุการณ์ที่มาถึงระหว่างที่เอเจนต์กำลังทำงานจะไม่หายไป มันจะรอจนการรันจบ และเหตุการณ์ที่มาทีหลังจะถูกรวมเข้าในการปลุกเดียวกัน
- ตารางเวลาของเอเจนต์ต้องมีเพดานจำนวนการรันหรือวันสิ้นสุด ตารางเวลาจะสิ้นสุดหลัง 7 วันตามค่าเริ่มต้น และสูงสุด 30 วัน การเฝ้าดูทำงาน 10 ครั้งตามค่าเริ่มต้น
- ตารางเวลาที่เอเจนต์ตั้งในการรันซึ่งตารางเวลาหนึ่งของมันเป็นผู้เริ่ม จะใช้วันสิ้นสุด เพดานจำนวนการรัน และเพดานค่าใช้จ่ายร่วมกับตารางเวลาแรก ทำให้สายโซ่ของตารางเวลาของเอเจนต์ไม่อาจอยู่นานกว่าตารางแรก การลบตารางเวลาแรกจะสิ้นสุดสายโซ่ทั้งหมด ส่วนการหยุดชั่วคราวหยุดเฉพาะตารางเวลานั้น การรันที่สายโซ่เริ่มผ่านเอเจนต์อื่นนับรวมในเพดานค่าใช้จ่ายเดียวกัน ตารางเวลาที่คุณตั้งเองไม่เริ่มสายโซ่ใดๆ สิ่งที่เอเจนต์ตั้งในการรันของมันจะถูกจำกัดเหมือนสิ่งอื่นที่มันตั้งหลังข้อความของคุณ
- เอเจนต์ดูรายการสิ่งที่รออยู่ด้วย `list_wakes` และยกเลิกสิ่งที่ตั้งเองด้วย `cancel_wake` มันยกเลิกสิ่งที่คุณตั้งไม่ได้

## ดูสิ่งที่กำลังรอ

**เหนือช่องเขียนข้อความ** เมื่อมีการปลุกรอเอเจนต์ในการสนทนา แถบจะแสดง: **การปลุก N รายการกำลังรอ** ซึ่งแต่ละรายการมาจากไหน (**เป้าหมาย** **ตารางเวลา** **การเฝ้าดู** **ตอบกลับจาก** เอเจนต์ **ขีดจำกัดการใช้งานรีเซ็ต** **การกู้คืน** และอื่นๆ) จะถึงกำหนดเมื่อใด และเหตุใดจึงถูกพักไว้

| ปุ่ม | สิ่งที่ทำ | ใครทำได้ |
| --- | --- | --- |
| **ส่งตอนนี้** | ส่งการปลุกที่รออยู่ทันที | เฉพาะบุคคลที่การปลุกนั้นทำแทน |
| **ทำต่อ** | ปล่อยการปลุกที่ถูกพักไว้ | เฉพาะบุคคลที่การปลุกนั้นทำแทน |
| **ยกเลิกการปลุก** | ยกเลิกการปลุกนั้น | ทุกคนที่มีสิทธิ์เข้าถึงสเปซ |

การปลุกที่ไม่ได้ถูกส่งจะทิ้งแถวหนึ่งไว้ในการสนทนาเพื่อบอกเหตุผล เช่น **เอเจนต์หยุดชั่วคราวอยู่** หรือ **งบประมาณกำลังบล็อกการรัน**

**หน้าตารางเวลา** **การตั้งค่า → เวิร์กสเปซ → ตารางเวลา** แสดงทุกตารางเวลาและการเฝ้าดูที่คุณเห็น จัดกลุ่มตามสถานะ ตารางเวลาแบบครอนจะแสดงเวลาถัดไปสามเวลาในเขตเวลาของคุณ เปิดรายการเพื่อดูโน้ต เจ้าของ การทำงานถัดไป การรัน การข้าม การใช้จ่าย และวันสิ้นสุด รวมถึง **การปลุกและการรันล่าสุด** แต่ละตารางเวลามีที่อยู่ของตัวเอง (`/workspaces/<workspace>/settings/workspace/schedules/<id>`)

| การกระทำ | ใครทำได้ |
| --- | --- |
| **หยุดชั่วคราว**, **ลบ** | ทุกคนที่มีสิทธิ์เข้าถึงสเปซ |
| **ทำต่อ**, **ขยาย** | เฉพาะเจ้าของ (ผู้ดูแลเวิร์กสเปซสำหรับตารางเวลาที่เอเจนต์สร้างโดยไม่มีบุคคล) |

เมื่อคนอื่นที่ไม่ใช่เจ้าของตารางเวลาหยุดมันชั่วคราว การสนทนาจะแสดงแถวที่ระบุชื่อคนนั้น

บนโทรศัพท์ **ซ้ำ** ในหน้าจอเป้าหมายจะเริ่มพรอมต์ที่ซ้ำ (ทุกกี่นาทีหรือกี่ชั่วโมง หรือเลือกจังหวะเอง) พร้อมเพดานค่าใช้จ่ายและวันสิ้นสุด ส่วนหน้าจอ **ตารางเวลา** หยุดชั่วคราว ทำต่อ และลบตารางเวลาได้ มุมมองความคืบหน้าของการสนทนาแสดงสิ่งที่รออยู่ รวมถึงการหยุดชั่วคราวที่ขีดจำกัดการใช้งาน (**ทำต่อตอนนี้**, **ยกเลิก**) และงานที่ค้างหลังเซิร์ฟเวอร์หยุด

## ตารางเวลาทำงานอย่างไร

- การรันของตารางเวลาหรือการเฝ้าดูแต่ละครั้งถูกจำกัดที่ 5 ดอลลาร์ หรือที่ตารางเวลาเหลืออยู่ เมื่อค่านั้นน้อยกว่า และตารางเวลาจะหยุดเมื่อถึงเพดานค่าใช้จ่าย
- เวลาครอนในชั่วโมงที่ถูกข้ามเมื่อนาฬิกาเดินหน้า จะทำงานหนึ่งชั่วโมงให้หลังในวันนั้น (02:30 ทำงานเวลา 03:30) เวลาในชั่วโมงที่ซ้ำเมื่อนาฬิกาถอยหลังจะทำงานเพียงครั้งเดียว
- การรันของตารางเวลาจะไม่เข้าร่วมการรันที่กำลังทำงานอยู่แล้ว หากเอเจนต์ไม่ว่างเมื่อตารางเวลาที่กำหนดเวลาทำงาน การทำงานครั้งนั้นจะถูกข้ามอย่างเงียบๆ เว้นแต่ตารางเวลาจะรอจนกว่าเอเจนต์จะว่าง
- การรันที่ตารางเวลาหรือการเฝ้าดูเริ่มไว้และจบโดยไม่มีปัญหาจะไม่แจ้งคุณ เว้นแต่จะกล่าวถึงใครบางคน เมื่อตารางเวลาสิ้นสุด กระดิ่งจะบอกเหตุผล (**ใช้จำนวนรันครบแล้ว**, **ถึงวันสิ้นสุดแล้ว**, และอื่นๆ) โดยไม่มีเสียง
- การรันสูงสุด 30 ครั้งต่อชั่วโมงจะเริ่มจากการปลุกในการสนทนาหนึ่ง และ 300 ครั้งในเวิร์กสเปซ
- เมื่อบุคคลที่ตารางเวลาทำแทนออกจากเวิร์กสเปซ ตารางเวลานั้นจะสิ้นสุด สิ่งอื่นทั้งหมดที่ทำแทนบุคคลนั้นก็จะหยุดด้วย: การปลุกที่รออยู่จะถูกยกเลิก ข้อความที่เข้าคิวและข้อความที่พักไว้จะถูกลบ และเอเจนต์ที่กำลังรันจะถูกหยุด

## หยุด รีสตาร์ต และขีดจำกัดการใช้งาน

- **หยุด** การกด **หยุด** ที่การรันของเอเจนต์จะพักการปลุกที่รออยู่ (ที่ไม่ได้เป็นของเป้าหมาย) และข้อความที่คุณเข้าคิวไว้ให้มัน ทั้งหมดจะรอ **ทำต่อ** หรือ **ส่งข้อความที่พักไว้** แต่ละคนส่งข้อความที่พักไว้ของตัวเอง ไม่มีใครส่งของคนอื่น
- **รีสตาร์ตเซิร์ฟเวอร์** การปลุกและตารางเวลายังอยู่รอด การรันที่การปลุกเริ่มไว้จะทำต่อหลังรีสตาร์ต โดยพยายามได้ไม่เกิน 3 ครั้ง การรันที่คุณเริ่มเองจะไม่ถูกรันซ้ำโดยอัตโนมัติ แต่จะทิ้งการปลุก **การกู้คืน** ที่ถูกพักไว้ และจะทำต่อเมื่อคุณกด **ทำต่อ** ตารางเวลาแบบกำหนดเวลาที่พลาดช่วงเวลาที่ควรทำงานขณะเซิร์ฟเวอร์ปิดอยู่ จะทำงานช้าได้เฉพาะภายในระยะผ่อนผันสั้นๆ (ครึ่งหนึ่งของช่วงเวลา สูงสุด 10 นาที หรือ 24 ชั่วโมงสำหรับงานครั้งเดียว) มิฉะนั้นจะบันทึกการข้ามเพียงครั้งเดียว: **พลาดไปขณะเซิร์ฟเวอร์ปิดอยู่**
- **ขีดจำกัดการใช้งานของผู้ให้บริการ** เมื่อการรันหยุดที่ขีดจำกัดการใช้งานของผู้ให้บริการ และผู้ให้บริการบอกเวลารีเซ็ต (ภายใน 7 วัน) การรันจะถูกหยุดชั่วคราว การรันที่เซิร์ฟเวอร์เริ่มเอง เช่นช่วงของเป้าหมายหรือการรันของตารางเวลา จะทำต่อเองหลังรีเซ็ต 30 วินาที สำหรับการรันที่คุณเริ่ม การรันจะรอคุณ: การสนทนาจะแสดง **หยุดชั่วคราวที่** **ขีดจำกัดการใช้งานของผู้ให้บริการ ขีดจำกัดจะรีเซ็ตเวลา** เวลาหนึ่ง พร้อม **ทำต่อ** (เฉพาะคุณ) และ **ยกเลิก** (ทุกคนในสเปซ) เมื่อกด **ทำต่อ** การรันจะทำต่อเมื่อขีดจำกัดรีเซ็ตแล้ว การหยุดชั่วคราวที่คุณไม่ทำต่อจะหมดอายุ 7 วันหลังรีเซ็ต ข้อความที่คุณเข้าคิวไว้ตอนถึงขีดจำกัดจะถูกส่งเข้าการรันที่ทำต่อ หากการรันไม่รอการรีเซ็ต หรือการหยุดชั่วคราวถูกยกเลิกหรือหมดอายุ ข้อความเหล่านั้นจะถูกพักไว้ให้คุณภายใต้ **ส่งข้อความที่พักไว้** แทน ข้อความที่บุคคลอื่นเข้าคิวจะถูกพักไว้ให้บุคคลนั้นทันที การทำงานครั้งถัดไปของตารางเวลาจะรอจนกว่าการรันที่หยุดไว้จะทำต่อ เอเจนต์ ACP ไม่รายงานเวลารีเซ็ต การรันของมันจึงไม่รอ

## ขีดจำกัดของเวิร์กสเปซ

ผู้ดูแลเวิร์กสเปซตั้งขีดจำกัดในหน้าเดียวกันนี้ ใต้รายการ:

- **ขีดจำกัดตารางเวลา**: จำนวนตารางเวลาที่ใช้งานหรือถูกพักที่เอเจนต์หนึ่งตัวถือได้ในการสนทนาหนึ่ง (10) ทั่วทั้งเวิร์กสเปซ (50) และทั้งเวิร์กสเปซ (500) เพดานค่าใช้จ่ายเริ่มต้นของตารางเวลา (50 ดอลลาร์) และเขตเวลาที่ตารางเวลาแบบครอนและสรุปรายวันใช้ (เริ่มต้นที่ UTC)
- **เมื่อไม่มีใครตอบ**: การรันที่เซิร์ฟเวอร์เริ่มจะรอคำตอบหรือการอนุมัติจากบุคคลนานเท่าใด (72 ชั่วโมงตามค่าเริ่มต้น ตั้งได้ตั้งแต่ 1 ชั่วโมงถึง 7 วัน) ก่อนที่การอนุมัติจะนับว่าถูกปฏิเสธ และคำถามจะนับว่าไม่ได้รับคำตอบ (หลังจากนั้น คำถามอื่นใดของการรันเดียวกันจะถูกปฏิเสธทันที) รวมถึงชั่วโมงของสรุปรายวันสิ่งที่รอคุณในเป้าหมาย ตารางเวลา และการรันอื่นที่เซิร์ฟเวอร์เริ่ม

สมาชิกดูหน้านี้ได้แบบอ่านอย่างเดียว
