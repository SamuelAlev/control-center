คู่มือนี้แสดงวิธีเพิ่มเอเจนต์ลงในเวิร์กสเปซและกำหนดค่ามันจนกว่าจะรันได้จริง

ทุกเวิร์กสเปซถูกซีดมาพร้อมเอเจนต์ห้าตัว — CEO หนึ่งตัว บวกกับ `qa`, `architect`, `engineer` และ `librarian` — คุณจึงมักมีเอเจนต์อยู่ก่อนที่จะกำหนดค่าใด ๆ ขั้นตอนด้านล่างใช้ได้เหมือนกันทั้งกับเอเจนต์ที่ซีดมาและเอเจนต์ใหม่

## ก่อนเริ่ม

- คุณอยู่ในเวิร์กสเปซหนึ่งแห่ง หน้าจอทั้งหมดอยู่ที่ **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** (`/settings/workspace/agents`)
- เอเจนต์จะต้องมีแบ็กเอนด์ ให้เชื่อมต่อผู้ให้บริการสำหรับฮาร์เนสในตัวใต้ **การตั้งค่า → เซิร์ฟเวอร์ → ผู้ให้บริการโมเดล** หรือติดตั้ง Claude Code CLI บนเครื่องที่โฮสต์ `cc_server`
- ถ้าคุณต้องการให้เอเจนต์ถือสกิล ให้ติดตั้งสกิลเหล่านั้นก่อนใต้ **การตั้งค่า → เวิร์กสเปซ → สกิล** ฟอร์มเอเจนต์เปิดให้สลับสกิลที่มีอยู่ในเวิร์กสเปซอยู่แล้วเท่านั้น

## เพิ่มเอเจนต์

1. เปิด **การตั้งค่า → เวิร์กสเปซ → เอเจนต์**
2. คลิก **เอเจนต์ใหม่**

ไม่มีไดอะล็อกและไม่มีตัวเลือกบทบาท เอเจนต์ชื่อ "เอเจนต์ไม่มีชื่อ" ถูกสร้างขึ้นทันทีและถูกเลือกไว้ในบานหน้าต่างรายละเอียดทางขวา

ตอนนี้คุณควรเห็น "เอเจนต์ไม่มีชื่อ" ในรายชื่อทางซ้าย โดยแท็บ **การตั้งค่า** ของบานหน้าต่างรายละเอียดเปิดอยู่ และฟิลด์ **ชื่อ** มีข้อความ "เอเจนต์ไม่มีชื่อ"

## ตั้งชื่อให้มัน

- **ชื่อ** — ตัวระบุสั้นที่ใช้ในการ @-mention เช่น `alice` การแยกวิเคราะห์การกล่าวถึงจะจับคู่ `@` ตามด้วยอักขระคำ ดังนั้นชื่อที่มีขีดกลาง จุด หรือช่องว่างจึงไม่มีทางถูกกล่าวถึงได้
- **ชื่อ** — ป้ายที่มนุษย์อ่านได้ เช่น "นักพัฒนาอาวุโส"
- **พรอมต์ระบบ** — คำแนะนำเพิ่มเติมแบบไม่บังคับ ถูกฉีดเป็นส่วน Agent instructions พวกมันไม่ได้แทนที่ส่วนที่เหลือของพรอมต์ที่ประกอบขึ้น

คลิก **บันทึกการเปลี่ยนแปลง** ที่ด้านล่างของฟอร์ม ทุกฟิลด์ในหน้านี้ถูกบันทึกด้วยปุ่มเดียวนี้

## กำหนดอะแดปเตอร์และโมเดลให้มัน

ดรอปดาวน์ **อะแดปเตอร์** แสดงรายการตัวรันที่โฮสต์ของเซิร์ฟเวอร์มีอยู่จริง อะแดปเตอร์ในตัวจะพบเสมอ (มันคือเซิร์ฟเวอร์) Claude Code จะปรากฏเฉพาะเมื่อตรวจพบ CLI ของมันบนโฮสต์นั้น

| อะแดปเตอร์               | แบ็กเอนด์                                   |
| ------------------------ | ------------------------------------------- |
| Control Center (built-in) | ลูปเอเจนต์ที่อยู่ในโปรเซส — ไม่มี CLI ภายนอก |
| Claude Code               | `claude -p --output-format stream-json`     |

มีเพียงอะแดปเตอร์ในตัวเท่านั้นที่บังคับใช้โหมด การกำกับ การหยุดชั่วคราว/รันต่อ สัญญาการเสร็จงาน และเอเจนต์ย่อย Claude Code ไม่ให้สิ่งใดในนั้นเลย Cursor, Codex และผู้ให้บริการโมเดลอื่น ๆ เกาะกับอะแดปเตอร์ในตัว ไม่ใช่ในฐานะตัวรันแยกต่างหาก

:::note[อะแดปเตอร์ว่างเปล่าหมายถึงลูปในตัว]
เอเจนต์ที่ไม่ได้ตั้งอะแดปเตอร์จะถูกส่งไปที่ **Control Center (built-in)** ซึ่งเป็นลูปที่อยู่ในเซิร์ฟเวอร์ จึงไม่ต้องติดตั้งสิ่งใดบนโฮสต์ เมื่อไม่ได้ตั้งโมเดลด้วย มันจะถามค่าเริ่มต้นจาก Anthropic เอเจนต์ที่ไม่ได้ตั้งค่าอะไรเลยจึงรันได้เฉพาะเมื่อคุณเชื่อมต่อบัญชี Anthropic ไว้แล้ว เอเจนต์ผู้เชี่ยวชาญที่ซีดมานั้นไม่ได้ตั้งทั้งสองอย่างไว้ ให้ตั้งทั้งคู่บนเอเจนต์ทุกตัวที่คุณตั้งใจจะใช้
:::

ดรอปดาวน์ **โมเดล** ถูกขับเคลื่อนด้วยอะแดปเตอร์ที่คุณเลือก สำหรับอะแดปเตอร์ในตัว รายการจะมาจากผู้ให้บริการที่คุณเชื่อมต่อไว้ใต้ **การตั้งค่า → เซิร์ฟเวอร์ → ผู้ให้บริการโมเดล** แบบสด ๆ ดังนั้นผู้ให้บริการที่ไม่มีข้อมูลรับรองที่จัดเก็บไว้จะเสนอโมเดลเป็นศูนย์

## เพิ่มสกิล

**สกิล** เป็นตัวเลือกแบบชิปสำหรับชุดสกิลที่ติดตั้งไว้ในเวิร์กสเปซนี้ แตะชิปเพื่อสลับ สัญลักษณ์เครื่องหมายถูกจะทำเครื่องหมายสกิลที่เลือกไว้ ถ้าเวิร์กสเปซไม่มีสกิล ฟิลด์นี้จะแสดงข้อความ "No skills available. Create skills in Settings → Skills first."

คุณไม่เลือกสกิลของรีโปเองที่นี่ รีโปที่มาพร้อมสกิลเหล่านี้ (ใน `.agents/skills/`, `.claude/skills/` หรือ `.opencode/skills/`) จะส่งสกิลให้เอเจนต์ที่ทำงานอยู่ในรีโปนั้นโดยอัตโนมัติ และสกิลจะสลับออกเมื่อมันย้ายไปรีโปอื่น — ดู [สกิลที่จำกัดขอบเขตตามรีโป](/th-TH/คู่มือ/แนวคิด/โมเดลเอเจนต์/#repo-scoped-skills)

## กำหนดสายการรายงานและเพอร์โซนา

- **รายงานต่อ** — เลือกเอเจนต์ตัวอื่นตามชื่อ การเลือกนี้สร้างต้นไม้การรายงานที่ปุ่ม **ผังองค์กร** ในส่วนหัวของหน้าแสดงขึ้น มันไม่ใช่รายชื่อที่หัวหน้าทีมใช้ตอนมอบงาน — รายชื่อนั้นมาจากสมาชิกของทีมและสกิลของพวกเขา
- **เพอร์โซนา** — ข้อความอิสระที่หล่อหลอมน้ำเสียงและพฤติกรรม เช่น: "ชอบวิธีแก้ที่เรียบง่ายและอ่านออก เขียนเทสต์ให้โค้ดใหม่ทุกชิ้น"

## ปรับแต่งการรัน

- **ความพยายามในการคิด** — ตัวเลือกมาจากระดับที่โมเดลที่เลือกประกาศไว้เอง: Low / Medium / High บวกกับ Extra High บนโมเดลสไตล์ OpenAI และ Extra High + Max บนโมเดลสไตล์ Claude ฟิลด์นี้ถูกซ่อนทั้งหมดเมื่อโมเดลที่เลือกไม่ได้ประกาศระดับการคิด และมันจะใช้ค่าเริ่มต้นของโมเดลเอง
- **ขนาดหน้าต่างบริบท** — ถูกเติมล่วงหน้าจากหน้าต่างบริบทของโมเดลทุกครั้งที่คุณเปลี่ยนโมเดล พร้อมชิปแตะครั้งเดียวสำหรับค่าเริ่มต้นของโมเดล, 200k, 500k และ 1M ค่าที่คุณพิมพ์หลังจากเลือกโมเดลแล้วจะมีผลจนกว่าจะเปลี่ยนโมเดลครั้งถัดไป
- **หมดเวลาเงียบ (นาที)** — ยุติการรันเมื่อผ่านไปนานเท่านี้โดยไม่มีเอาต์พุต เว้นว่างไว้เพื่อใช้ค่าเริ่มต้นของแต่ละโหมด

## ให้สิทธิ์

**สิทธิ์แซนด์บ็อกซ์** เริ่มต้นที่ "ใช้ค่าเริ่มต้นของเวิร์กสเปซ" เปิดสวิตช์เพื่อตั้งค่าให้เอเจนต์ตัวนี้ แล้วสลับ:

- **อนุญาต git push** — ฉีดโทเคน GitHub ที่เอเจนต์ต้องใช้ในการพุช
- **อนุญาตการเรียก GitHub API** — ให้เอเจนต์อ่าน PR, issue และเมตาดาต้าของรีโป
- **อนุญาตการเรียก ticketing API** — ฉีดคีย์ของผู้ให้บริการตั๋วงาน
- **อนุญาตการเข้าถึงเครือข่ายทั่วไป** — ยังเปิดใช้เครื่องมือ `web_fetch` และ `web_search` ของฮาร์เนสในตัวด้วย

สวิตช์แต่ละตัวจะถูกตรวจโดยตัวกลางจัดการข้อมูลรับรองตอนที่การรันเริ่ม: ความสามารถที่ปิดอยู่หมายความง่าย ๆ ว่าโทเคนที่ตรงกันจะไม่ถูกสร้างเข้าไปในสภาพแวดล้อมของการรันเลย

:::caution[ค่าเริ่มต้นของเวิร์กสเปซหมายถึงชุดอนุรักษนิยมของเซิร์ฟเวอร์]
เอเจนต์ที่ถูกปล่อยไว้ที่ "ใช้ค่าเริ่มต้นของเวิร์กสเปซ" จะรันโดยที่ git push, GitHub API และตั๋วงาน **ปิด** ทั้งหมด และเครือข่าย **เปิด** ค่าเริ่มต้นของความสามารถที่แสดงใต้ การตั้งค่า → เซิร์ฟเวอร์ → การวินิจฉัยและความเป็นส่วนตัว เป็นค่ากำหนดฝั่งไคลเอนต์ ถ้าคุณต้องการให้เอเจนต์พุชหรือเปิด PR ให้เปิดสวิตช์และให้ความสามารถอย่างชัดเจน

ความสามารถเหล่านี้ควบคุมข้อมูลรับรองและเครื่องมือของฮาร์เนส ซึ่งเป็นชั้นที่แยกจากแซนด์บ็อกซ์ของระบบปฏิบัติการ `cc_server` ห่อการรันของเอเจนต์ไว้ในแซนด์บ็อกซ์ของโฮสต์เมื่อมี — Windows ไม่มีแบ็กเอนด์เนทีฟ และ Linux กับ WSL2 ต้องมี `bwrap` และ `socat` ดู [แซนด์บ็อกซ์และความปลอดภัย](/th-TH/คู่มือ/แนวคิด/แซนด์บ็อกซ์และความปลอดภัย/) สำหรับขอบเขตทั้งหมด
:::

## ยืนยันว่ามันรันได้

1. เปิด **การตั้งค่า → เซิร์ฟเวอร์ → ผู้ให้บริการโมเดล** และยืนยันว่าอะแดปเตอร์ที่คุณเลือกรายงานเวอร์ชันที่ติดตั้งแล้ว ไม่ใช่ "ไม่พบ" คลิก **รีเฟรช** เพื่อตรวจใหม่ — การตรวจนี้ทำงานบนเครื่องที่โฮสต์ `cc_server` ไม่ใช่เครื่องที่คุณกำลังดูอยู่
2. เปิดสเปซที่มีเอเจนต์ตัวนั้นแล้วส่งข้อความถึงมัน หรือ @-mention มันในสเปซที่มีอยู่แล้ว
3. กลับมาที่ **การตั้งค่า → เวิร์กสเปซ → เอเจนต์** เลือกเอเจนต์แล้วเปิดแท็บ **บันทึก** ของมัน การรันหนึ่งครั้งควรปรากฏขึ้นพร้อมป้ายสถานะ ระยะเวลา เวลาเริ่ม และอะแดปเตอร์ที่มันใช้ **ดู** จะเปิดสตรีมเหตุการณ์ของการรันนั้น

ถ้าไม่มีการรันปรากฏขึ้นเลย ให้ทำตามขั้นตอนใน [วินิจฉัยเอเจนต์](/th-TH/คู่มือ/วิธีทำ/วินิจฉัยเอเจนต์/)

## ลบเอเจนต์

เลือกมันในรายชื่อ บนแท็บ **การตั้งค่า** เลื่อนลงไปที่ **โซนอันตราย** ที่ด้านล่างของฟอร์มแล้วคลิก **ลบ**
