หน้าเหล่านี้อธิบาย **ว่า Control Center ทำงานอย่างไรและทำไมจึงเป็นเช่นนั้น** หน้าเหล่านี้
มีไว้เพื่อทำความเข้าใจ ไม่ใช่เพื่อลงมือทำ เพราะไม่มีหน้าใดเลยที่เป็นขั้นตอนให้ปฏิบัติตาม
เมื่อคุณต้องการทำงานใดงานหนึ่งให้สำเร็จ ให้ไปที่[คู่มือวิธีทำ](/th-TH/คู่มือ/วิธีทำ/)
และเมื่อต้องการค้นดูข้อมูลอ้างอิง ให้ไปที่[อ้างอิง](/th-TH/คู่มือ/อ้างอิง/)

อ่านตามลำดับใดก็ได้ หากคุณเพิ่งเริ่มต้น โมเดลหลักคือจุดที่ควรเริ่ม

## โมเดลหลัก

สี่แนวคิดที่ทุกอย่างอื่นสร้างขึ้นบนนั้น

- [เวิร์กสเปซและการแยกโดเมน](/th-TH/คู่มือ/แนวคิด/เวิร์กสเปซ/) — ขอบเขตของผู้เช่า และเหตุใดจึงบังคับใช้ผ่านโครงสร้างฐานข้อมูลแทนที่จะอาศัยวินัยในการเขียนคิวรี
- [โมเดลเอเจนต์](/th-TH/คู่มือ/แนวคิด/โมเดลเอเจนต์/) — เอเจนต์ประกอบขึ้นจากอะไร: ตัวตน บทบาท สกิล ความสามารถ อะแดปเตอร์ และโมเดล
- [วงจรชีวิตการสั่งงานเอเจนต์](/th-TH/คู่มือ/แนวคิด/วงจรชีวิตการสั่งงาน/) — เกิดอะไรขึ้นระหว่างข้อความของคุณกับโทเค็นแรกของเอเจนต์
- [โหมด](/th-TH/คู่มือ/แนวคิด/โหมด/) — `chat`, `plan`, `review` และ `orchestrate` เปลี่ยนสิ่งที่เอเจนต์ทำได้อย่างไร
- [บริบทเครื่องมือและการแคชพรอมต์](/th-TH/คู่มือ/แนวคิด/บริบทเครื่องมือ/) — เหตุใดเอเจนต์จึงเห็นเครื่องมือเพียงบางส่วน เข้าถึงเครื่องมือที่เหลือได้อย่างไร และอะไรทำให้แคชของผู้ให้บริการอุ่นอยู่
- [ความฉลาดของโค้ด](/th-TH/คู่มือ/แนวคิด/ความฉลาดของโค้ด/) — กราฟโค้ด เซิร์ฟเวอร์ภาษา การค้นหาเชิงโครงสร้าง และดีบักเกอร์
- [ประวัติการสนทนา](/th-TH/คู่มือ/แนวคิด/ประวัติการสนทนา/) — การเก็บถาวร การบีบอัด และการแยกสายของบันทึกการสนทนา

## ความปลอดภัยและการควบคุม

สิ่งที่เอเจนต์ได้รับอนุญาตให้แตะต้อง และใครเป็นผู้ตัดสิน

- [แซนด์บ็อกซ์และความปลอดภัย](/th-TH/คู่มือ/แนวคิด/แซนด์บ็อกซ์และความปลอดภัย/) — สิ่งที่จำกัดการรันของเอเจนต์จริง ๆ ในปัจจุบัน
- [กฎคุม](/th-TH/คู่มือ/แนวคิด/กฎคุม/) — เอนจินนโยบายเดียวสำหรับทุกการกระทำที่เปลี่ยนแปลงข้อมูล และวิธีตัดสินกฎหนึ่งข้อ
- [การอนุญาต](/th-TH/คู่มือ/แนวคิด/การอนุญาต/) — บทบาท แคตตาล็อกสิทธิ์ และร่องรอยการตรวจสอบ
- [ริกและเอนโคลเจอร์](/th-TH/คู่มือ/แนวคิด/ริก/) — เหตุใดเอเจนต์จึงได้ VM แบบใช้แล้วทิ้งแทนเครื่องของคุณ และขอบเขตที่แท้จริงคืออะไร

## กำกับงาน

การเปลี่ยนเจตนาให้เป็นงานที่ลงมือทำจนสำเร็จ

- [ตั๋วงานและการมอบหมาย](/th-TH/คู่มือ/แนวคิด/ตั๋วงาน/) — หน่วยของงานที่ไม่ผูกกับผู้ขายรายใด ซึ่งทั้งฟลีตใช้ร่วมกัน
- [ไปป์ไลน์และระบบอัตโนมัติ](/th-TH/คู่มือ/แนวคิด/ไปป์ไลน์/) — เวิร์กโฟลว์แบบ DAG ตัวกระตุ้น และการรันที่กลับมาทำต่อได้
- [การประสานงาน](/th-TH/คู่มือ/แนวคิด/การประสานงาน/) — เป้าหมายเดียว การอนุมัติครั้งเดียว ไปป์ไลน์ที่สร้างขึ้น
- [รีวิวด้วย AI](/th-TH/คู่มือ/แนวคิด/รีวิวด้วย-ai/) — PR กลายเป็น PR ที่ผ่านการรีวิวได้อย่างไร: สเปซรีวิว ความเห็นพ้องของเพื่อนร่วมงาน แกน และคำตัดสิน Ship/Hold/Block
- [การสนทนาบน PR](/th-TH/คู่มือ/แนวคิด/การสนทนาบน-pr/) — การตอบกลับเมื่อมีคนกล่าวถึงบน GitHub หรือป้าย `ai-review` จาก forge เอง
- [หน่วยความจำและความรู้](/th-TH/คู่มือ/แนวคิด/หน่วยความจำและความรู้/) — ข้อเท็จจริง นโยบาย และสิ่งที่เอเจนต์ได้รับอนุญาตให้รู้
- [การประเมินและคุณภาพ](/th-TH/คู่มือ/แนวคิด/การประเมินและคุณภาพ/) — ชุดการประเมินและแท็บคุณภาพ

## คนและการเข้าถึง

การทำงานร่วมกับมนุษย์คนอื่น และการเข้าถึงฟลีตจากที่อื่น

- [การทำงานร่วมกันแบบหลายคนและสถานะออนไลน์](/th-TH/คู่มือ/แนวคิด/การทำงานร่วมกันแบบหลายคน/) — มนุษย์และเอเจนต์ในฐานะผู้เข้าร่วมที่เท่าเทียมกัน และอะไรที่ควบคุมการเข้าถึง
- [การลงชื่อเข้าใช้ครั้งเดียว](/th-TH/คู่มือ/แนวคิด/การลงชื่อเข้าใช้ครั้งเดียว/) — การเข้าสู่ระบบด้วย SAML และ OIDC
- [สะพานแชท](/th-TH/คู่มือ/แนวคิด/สะพานแชท/) — เหตุใดสะพาน Slack จึงเชื่อมต่อออก และอะไรอนุญาตข้อความจากแชท
- [ควบคุมระยะไกลและมือถือ](/th-TH/คู่มือ/แนวคิด/ควบคุมระยะไกล/) — โทรศัพท์เข้าถึงเซิร์ฟเวอร์ของคุณได้อย่างไร และโมเดลความปลอดภัยที่ล้อมรอบอยู่
- [การประชุมและการถอดเสียง](/th-TH/คู่มือ/แนวคิด/การประชุม/) — การบันทึก การถอดความ และการสรุปบนอุปกรณ์
- [ปฏิทินและการจัดตาราง](/th-TH/คู่มือ/แนวคิด/ปฏิทิน/) — การซิงก์ Google Calendar และการแจ้งเตือนการประชุม

## เบื้องหลังระบบ

รูปร่างของระบบเอง

- [สถาปัตยกรรม](/th-TH/คู่มือ/แนวคิด/สถาปัตยกรรม/) — การแบ่งชั้น เคอร์เนลที่ใช้ร่วมกัน พอร์ตและอะแดปเตอร์
- [การปรับใช้และไคลเอนต์](/th-TH/คู่มือ/แนวคิด/การปรับใช้/) — ไคลเอนต์เดสก์ท็อป เว็บ และโทรศัพท์เกี่ยวข้องกับเซิร์ฟเวอร์เดียวอย่างไร
- [เหตุการณ์โดเมน](/th-TH/คู่มือ/แนวคิด/เหตุการณ์โดเมน/) — บัสภายในโปรเซสที่ฟีเจอร์ต่าง ๆ ใช้สื่อสารกัน
