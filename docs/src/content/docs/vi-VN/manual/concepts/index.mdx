These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/vi-VN/so-tay/huong-dan-thuc-hanh/); when you want to look
something up, go to the [reference](/vi-VN/so-tay/tham-chieu/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/vi-VN/so-tay/khai-niem/khong-gian-lam-viec/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/vi-VN/so-tay/khai-niem/mo-hinh-agent/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/vi-VN/so-tay/khai-niem/vong-doi-dieu-phoi-agent/) — what happens between your message and the agent's first token
- [Modes](/vi-VN/so-tay/khai-niem/che-do/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/vi-VN/so-tay/khai-niem/ngu-canh-cong-cu/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/vi-VN/so-tay/khai-niem/tri-tue-ma-nguon/) — the code graph, language server, structural search and debugger
- [Conversation history](/vi-VN/so-tay/khai-niem/lich-su-hoi-thoai/) — persistence, compaction and forking a transcript

## Safety and control

What an agent is allowed to touch and who decides.

- [Sandbox and security](/vi-VN/so-tay/khai-niem/sandbox-va-bao-mat/) — what actually constrains an agent run today
- [Guardrails](/vi-VN/so-tay/khai-niem/rao-chan/) — one policy engine for every mutating action and how a rule is resolved
- [Authorization](/vi-VN/so-tay/khai-niem/uy-quyen/) — roles, the permission catalog and the audit trail
- [Rigs and enclosures](/vi-VN/so-tay/khai-niem/rigs/) — why agents get disposable VMs instead of your machine, and what the boundary actually is
