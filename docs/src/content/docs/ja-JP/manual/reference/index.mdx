リファレンスページは、**何が存在するか**を網羅的に、解説を挟まずに記述します。探している
ものをすでに把握しているときの調べ物に使ってください。たとえば、正確なツール名、ステップ
の種類、ステータスの遷移、ルート、ショートカットです。

これらは最初から最後まで読み通すためのものではありません。通読には
[コンセプト](/ja-JP/マニュアル/コンセプト/)を、実際に作業を進めるには
[ハウツーガイド](/ja-JP/マニュアル/ハウツーガイド/)を使ってください。

## 製品サーフェス

- [MCP ツール](/ja-JP/マニュアル/リファレンス/mcp-ツール/) — MCP サーバーが登録するすべてのツールをファミリー別に
- [内蔵エージェントツール](/ja-JP/マニュアル/リファレンス/エージェントツール/) — サーバーにバインドされたハーネスツール（LSP、AST、debug、eval、vibe）
- [スラッシュコマンド](/ja-JP/マニュアル/リファレンス/スラッシュコマンド/) — コンポーザーの組み込みコマンド、`/skill:`、ユーザーコマンド
- [ルートマップ](/ja-JP/マニュアル/リファレンス/ルートマップ/) — すべての画面と、そこに到達する URL
- [キーボードショートカット](/ja-JP/マニュアル/リファレンス/キーボードショートカット/) — キーバインドの完全なレジストリ
- [ドメインイベント](/ja-JP/マニュアル/リファレンス/ドメインイベント/) — ドメインバスに発行されるすべてのイベント
- [リグ](/ja-JP/マニュアル/リファレンス/リグ/) — すべてのリグサーフェス、アクション動詞、ライフサイクル状態、ポート、既定値

## 設定

- [エージェント設定](/ja-JP/マニュアル/リファレンス/エージェント設定/) — エージェントのすべてのフィールドと、それを読み取るもの
- [パイプラインステップの種類](/ja-JP/マニュアル/リファレンス/パイプラインステップ/) — ステップの種類、ボディキー、設定、結果
- [`cc_server` CLI](/ja-JP/マニュアル/リファレンス/cc-server-cli/) — すべてのフラグ、環境変数、サブコマンド、データディレクトリのパス
- [バックアップ、エクスポート、インポート](/ja-JP/マニュアル/リファレンス/バックアップ/) — スナップショットのレイアウト、すべてのバックアップ操作と転送ルート
- [サンドボックスバックエンド](/ja-JP/マニュアル/リファレンス/サンドボックスバックエンド/) — 実行バックエンドとその可用性
- [SSO 設定](/ja-JP/マニュアル/リファレンス/sso/) — エンドポイント、操作、エラーコード
- [チャットブリッジ](/ja-JP/マニュアル/リファレンス/チャットブリッジ/) — プロバイダー、コマンド、資格情報、操作

## モデル

- [チケットのライフサイクル](/ja-JP/マニュアル/リファレンス/チケットライフサイクル/) — ステータス、遷移、ワークフローエンジン
- [用語集](/ja-JP/マニュアル/リファレンス/用語集/) — マニュアル全体で使われるドメイン語彙
