このリファレンスでは、エージェントエンティティのすべてのフィールドと、それが使用する列挙型およびフラグを一覧します。アプリでエージェントを作成または編集する手順を追った説明については、[エージェントの作成と設定](/ja-JP/マニュアル/ハウツーガイド/エージェント作成/)を参照してください。

## エージェントエンティティのフィールド

| フィールド              | 型                     | 必須   | 説明                                                                                                                                                                                                                        |
| ----------------------- | ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | はい   | エージェントの一意な識別子                                                                                                                                                                                                  |
| `name`                  | `String`               | はい   | @メンション用の短い識別子                                                                                                                                                                                                   |
| `title`                 | `String`               | はい   | 人が読める職種名                                                                                                                                                                                                            |
| `agentMdPath`           | `String`               | はい   | エージェントの `.md` 定義ファイルへの絶対パス                                                                                                                                                                                |
| `workspaceId`           | `String`               | はい   | 所有ワークスペース（null 以外）                                                                                                                                                                                             |
| `reportsTo`             | `String?`              | いいえ | 親エージェントの ID                                                                                                                                                                                                         |
| `skills`                | `AgentSkills`          | はい   | スキル識別子の集合                                                                                                                                                                                                          |
| `persona`               | `String?`              | いいえ | 自由記述の振る舞いに関する指示                                                                                                                                                                                              |
| `systemPrompt`          | `String?`              | いいえ | デフォルトのシステムプロンプトを上書きする                                                                                                                                                                                  |
| `adapterId`             | `String?`              | いいえ | 推論アダプターの id                                                                                                                                                                                                         |
| `modelId`               | `String?`              | いいえ | アダプター内のモデル id                                                                                                                                                                                                     |
| `strictMode`            | `bool`                 | いいえ | デフォルトは `false`。行とエージェントの `AGENTS.md` に書き込まれる                                                                                                                                                         |
| `effort`                | `String?`              | いいえ | 推論レベルの id（例: `'low'`、`'xhigh'`）。選択したモデルの `thinkingLevels` から取得される                                                                                                                                    |
| `contextSize`           | `int?`                 | いいえ | コンテキストウィンドウの最大サイズ                                                                                                                                                                                          |
| `role`                  | `AgentRole?`           | いいえ | エージェントのロール                                                                                                                                                                                                        |
| `monthlyBudgetMicros`    | `int`                  | いいえ | 月間の支出上限（マイクロドル単位。デフォルト `0` で無制限）                                                                                                                                                                        |
| `silenceTimeoutMinutes` | `int?`                 | いいえ | 無応答タイムアウトの上書き（分単位）。null または 1–240 のいずれかでなければならない（コンストラクターでアサート）                                                                                                           |
| `maxConcurrentTasks`    | `int`                  | いいえ | デフォルトは `1`。プレゼンスモデルが報告するキャパシティ値（実行中とキューの件数がこれと比較される）                                                                                                                        |
| `visibility`            | `AgentVisibility`      | いいえ | デフォルトは `workspace`                                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | いいえ | ガバナンスステータス（デフォルトは `active`）。予算のハードストップによって書き込まれ、組織図とプレゼンス名簿に表示される。ディスパッチは `paused` のエージェントからの作業も引き続き受け入れる                              |
| `budgetPolicyId`        | `String?`              | いいえ | 共有予算ポリシーの id。null の場合は `monthlyBudgetMicros` が直接適用される                                                                                                                                                   |
| `runtimeProfileId`      | `String?`              | いいえ | カスタムランタイムプロファイルの id                                                                                                                                                                                          |
| `createdAt`             | `DateTime`             | はい   | 作成タイムスタンプ                                                                                                                                                                                                          |

`name` と `title` はどちらも空であってはならない（コンストラクターでアサート）。`monthlyBudgetMicros` のデフォルトである `0` は無制限を意味する。上限を書き込むには `agents.upsert` を使う。

## AgentRole 列挙型

| ロール     | ラベル   | 説明                             |
| ---------- | -------- | -------------------------------- |
| `ceo`      | CEO      | 調整と委任                       |
| `coder`    | Coder    | コードの実装                     |
| `reviewer` | Reviewer | PR レビューと分析                |
| `qa`       | QA       | テストと品質保証                 |
| `designer` | Designer | UI/UX の実装                     |
| `security` | Security | セキュリティレビューと監査       |
| `devops`   | DevOps   | インフラストラクチャとデプロイメント |
| `pm`       | PM       | プロダクトマネジメント           |
| `general`  | General  | 柔軟な汎用                       |

## AgentVisibility 列挙型

| 値          | 説明                                                           |
| ----------- | -------------------------------------------------------------- |
| `workspace` | デフォルト。不明な値と null の保存値はこれにパースされる        |
| `private`   | 作成したユーザーだけが利用できる                                |

## AgentLifecycleStatus 列挙型

| 値         | 説明                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| `active`   | デフォルト。`isDispatchable` が true になるのはこの値のときだけ                              |
| `paused`   | 予算のハードストップによって設定される。プレゼンス名簿に表示されるが、ディスパッチは引き続き作業を受け入れる |
| `archived` | 引退扱いとなり、アクティブな名簿からは非表示になる                                          |

## 権限

エージェントは権限フラグを持たない。プッシュ、プルリクエストの作成と公開、トラッカーへの書き込み、ネットワークエグレスはアクションクラス（`gitPush`、`prCreate`、`prPublish`、`vendorSyncWrite`、`networkEgress`）であり、[ガードレール](/ja-JP/マニュアル/コンセプト/ガードレール/)がワークスペース、エージェント、スペースのスコープで解決する。実行の GitHub トークンは常に読み取りスコープであり、プッシュはエージェント実行ゲートウェイを通り、ゲートウェイは転送前に `gitPush` のルールに問い合わせる。

## AgentSkills

スキル識別子の不変で大文字小文字を区別しない集合。ディスパッチ時にそれらのスラッグはエージェントのオーバーレイ内のスキルリンクとして同期され、その後ハーネスがリンクされたスキルのフロントマターをプロンプトに自動読み込みする。

```
{'flutter', 'dart', 'rest-api'}
```

## シェルフック

シェルフックを使うと、サーバーオーナーは組み込みのハーネス実行の前後に、自分のスクリプトを実行できます。実行される場所は、セッション開始時に 1 回、各ツール呼び出しの前、各ツール呼び出しの後です。フックは任意のコードなので、フックはホストの設定です。設定するのはサーバーオーナーだけで、サーバーのマシン上で手作業で行います。アプリに設定項目はなく、フックを書き込む操作もありません。

エージェントの場合、フックはサーバーのデータディレクトリ配下にある、そのエージェント自身のフォルダーに置かれます:

```text
<data dir>/_agent_hooks/<workspace id>/<agent slug>/hooks.json
```

`<agent slug>` はワークスペース内のエージェントのフォルダー名（`agents/<slug>/`）です。このフォルダーはどのワークスペースのストレージの外にもあり、どのサンドボックスもデータディレクトリを隠すため、メンバー、実行、ターミナルのいずれもこれを書き込めません。

`hooks.json` は、3 つのキーのいずれかをスクリプトに対応付けます。スクリプトはフックフォルダーからの相対パスで指定します:

| キー           | 実行されるタイミング           | 終了コードの意味                                               |
| -------------- | ------------------------------ | -------------------------------------------------------------- |
| `sessionStart` | 実行の開始時に 1 回            | なし。フックは観察するだけです                                 |
| `preTool`      | ツール呼び出しの前ごと         | `0` は呼び出しを許可し、それ以外は拒否します                   |
| `postTool`     | ツール呼び出しの後ごと         | なし。フックは観察するだけです                                 |

- 各スクリプトは、シェルも引数もなしに、独立した実行可能ファイルとして起動されます。そのため、実行権限を持ち、シバン行で始まっている必要があります。イベントは stdin 上の JSON として渡されます。イベント名と、ツールフックの場合はツール名とその引数（`preTool`）または結果（`postTool`）が含まれます。
- フックは、その実行のツールプロセスの 1 つとして、その実行のエージェントのディレクトリで動作します。サーバーがエージェントをサンドボックス化している場合、フックは実行のサンドボックス内で動きます。最小限の環境変数を受け取り、実行の資格情報は一切受け取りません。フォージやプロバイダーのトークンも、ゲートウェイへのアクセスもありません。
- 各フックには 30 秒の制限があります。その出力は読み取られ、破棄されます。
- `preTool` はフェイルクローズです。0 以外の終了、タイムアウト、またはスクリプトを起動できない場合は、そのツール呼び出しを拒否します。
- 絶対パス、存在しないパス、またはフックフォルダーの外に出るパス（リンクを解決した後で判定）は拒否されます。実行のログには、どのフックが拒否されたか、その理由が記録されます。拒否された、または読み取れない `preTool` フックは、修正されるまですべてのツール呼び出しを拒否します。
- リポジトリにあっても、エージェント自身のフォルダーにあっても、`.agents/harness.json` の `hooks` ブロックは無視されます。リポジトリは他人のコードであることが多く、エージェントのフォルダーはメンバーや実行によって書き込まれ得るためです。実行のログには、そのブロックが無視されたこと、代わりにフックがどこから読み込まれるかが記録されます。

シェルフックは組み込みのハーネスにのみ適用されます。設定された `preTool` または `postTool` フックがあると、その実行はツールを 1 つずつ呼び出します。

## AgentLiveState（派生）

保存されない。7 つの値がある。宣言順が優先順位（`sortPriority`、テストで固定されている）であり、名簿が並べ替えに使う順序でもある:

| 状態        | `sortPriority` | 条件                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | いずれかの実行ログのステータスが `running`                                                                          |
| `blocked`   | 1              | 最新の実行の生存状態が `blocked`、`stalled`、または `looping`                                                       |
| `failed`    | 2              | 最新の実行のステータスが `error`、またはその生存状態が `failed` か `dead`                                           |
| `queued`    | 3              | 実行はディスパッチ済みだが実行中ではない — 同じエージェントの別の実行の後ろで待機しているか、書き込まれたがまだ開始されていない |
| `succeeded` | 4              | 実行が正常に完了した                                                                                                |
| `idle`      | 5              | エージェントは以前に実行されたことがあり、進行中のものは何もない                                                    |
| `neverRun`  | 6              | 実行ログが存在しない                                                                                                |

`queued` と `succeeded` は**実行単位にのみ**存在する。エージェントの名簿状態を計算する `deriveAgentLiveState` がこれらを生成することはない — 返すのは `neverRun`、`running`、`failed`、`blocked`、または `idle` である。
