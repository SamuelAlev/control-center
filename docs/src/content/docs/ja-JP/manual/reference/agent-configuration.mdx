このリファレンスでは、エージェントエンティティのすべてのフィールドと、それが使用する列挙型およびフラグを一覧します。アプリでエージェントを作成または編集する手順を追った説明については、[エージェントの作成と設定](/ja-JP/マニュアル/ハウツーガイド/エージェント作成/)を参照してください。

## エージェントエンティティのフィールド

| フィールド              | 型                     | 必須   | 説明                                                                                                                                                                                                                        |
| ----------------------- | ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | はい   | エージェントの一意な識別子                                                                                                                                                                                                  |
| `name`                  | `String`               | はい   | @メンション用の短い識別子                                                                                                                                                                                                   |
| `title`                 | `String`               | はい   | 人が読める職種名                                                                                                                                                                                                            |
| `agentMdPath`           | `String`               | はい   | エージェントの `.md` 定義ファイルへの絶対パス                                                                                                                                                                                |
| `workspaceId`           | `String`               | はい   | 所有ワークスペース（null 以外）                                                                                                                                                                                             |
| `reportsTo`             | `String?`              | いいえ | 親エージェントの ID                                                                                                                                                                                                         |
| `skills`                | `AgentSkills`          | はい   | スキル識別子の集合                                                                                                                                                                                                          |
| `persona`               | `String?`              | いいえ | 自由記述の振る舞いに関する指示                                                                                                                                                                                              |
| `systemPrompt`          | `String?`              | いいえ | デフォルトのシステムプロンプトを上書きする                                                                                                                                                                                  |
| `adapterId`             | `String?`              | いいえ | 推論アダプターの id                                                                                                                                                                                                         |
| `modelId`               | `String?`              | いいえ | アダプター内のモデル id                                                                                                                                                                                                     |
| `strictMode`            | `bool`                 | いいえ | デフォルトは `false`。行とエージェントの `AGENTS.md` に書き込まれる                                                                                                                                                         |
| `effort`                | `String?`              | いいえ | 推論レベルの id（例: `'low'`、`'xhigh'`）。選択したモデルの `thinkingLevels` から取得される                                                                                                                                    |
| `contextSize`           | `int?`                 | いいえ | コンテキストウィンドウの最大サイズ                                                                                                                                                                                          |
| `role`                  | `AgentRole?`           | いいえ | エージェントのロール                                                                                                                                                                                                        |
| `capabilities`          | `AgentCapabilities?`   | いいえ | エージェント単位のケイパビリティのデフォルト。null の場合はディスパッチ時にユーザーレベルのデフォルトが適用され、会話による上書きも可能                                                                                     |
| `monthlyBudgetCents`    | `int`                  | いいえ | 月間の支出上限（セント単位。デフォルト `0` で無制限）                                                                                                                                                                        |
| `silenceTimeoutMinutes` | `int?`                 | いいえ | 無応答タイムアウトの上書き（分単位）。null または 1–240 のいずれかでなければならない（コンストラクターでアサート）                                                                                                           |
| `maxConcurrentTasks`    | `int`                  | いいえ | デフォルトは `1`。プレゼンスモデルが報告するキャパシティ値（実行中とキューの件数がこれと比較される）                                                                                                                        |
| `visibility`            | `AgentVisibility`      | いいえ | デフォルトは `workspace`                                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | いいえ | ガバナンスステータス（デフォルトは `active`）。予算のハードストップによって書き込まれ、組織図とプレゼンス名簿に表示される。ディスパッチは `paused` のエージェントからの作業も引き続き受け入れる                              |
| `budgetPolicyId`        | `String?`              | いいえ | 共有予算ポリシーの id。null の場合は `monthlyBudgetCents` が直接適用される                                                                                                                                                   |
| `runtimeProfileId`      | `String?`              | いいえ | カスタムランタイムプロファイルの id                                                                                                                                                                                          |
| `createdAt`             | `DateTime`             | はい   | 作成タイムスタンプ                                                                                                                                                                                                          |

`name` と `title` はどちらも空であってはならない（コンストラクターでアサート）。`monthlyBudgetCents` のデフォルトである `0` は無制限を意味する。上限を書き込むには `agents.upsert` を使う。

## AgentRole 列挙型

| ロール     | ラベル   | 説明                             |
| ---------- | -------- | -------------------------------- |
| `ceo`      | CEO      | 調整と委任                       |
| `coder`    | Coder    | コードの実装                     |
| `reviewer` | Reviewer | PR レビューと分析                |
| `qa`       | QA       | テストと品質保証                 |
| `designer` | Designer | UI/UX の実装                     |
| `security` | Security | セキュリティレビューと監査       |
| `devops`   | DevOps   | インフラストラクチャとデプロイメント |
| `pm`       | PM       | プロダクトマネジメント           |
| `general`  | General  | 柔軟な汎用                       |

## AgentVisibility 列挙型

| 値          | 説明                                                           |
| ----------- | -------------------------------------------------------------- |
| `workspace` | デフォルト。不明な値と null の保存値はこれにパースされる        |
| `private`   | 作成したユーザーだけが利用できる                                |

## AgentLifecycleStatus 列挙型

| 値         | 説明                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------- |
| `active`   | デフォルト。`isDispatchable` が true になるのはこの値のときだけ                              |
| `paused`   | 予算のハードストップによって設定される。プレゼンス名簿に表示されるが、ディスパッチは引き続き作業を受け入れる |
| `archived` | 引退扱いとなり、アクティブな名簿からは非表示になる                                          |

## AgentCapabilities のフラグ

ディスパッチごとに解決される。エージェントのデフォルトを使い、null の場合はユーザーレベルのデフォルトにフォールバックし、その上に会話単位の上書きが重なる。強制は「存在しないこと」によって行われる — 無効なケイパビリティが対象とするものを、資格情報ブローカーが発行も注入もしないだけである。

| フラグ             | 型     | デフォルト | 説明                                                                                     |
| ------------------ | ------ | ---------- | ---------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false`    | リモートへのコミットのプッシュ。`canCallGitHubApi` とともに GitHub トークンの注入を制御する |
| `canCallGitHubApi` | `bool` | `false`    | api.github.com の呼び出し。`GH_TOKEN` の注入と GitHub のエグレスドメインを制御する        |
| `canCallTicketing` | `bool` | `false`    | チケットプロバイダーの API の呼び出し。プロバイダーの API キーの注入とそのエグレスドメインを制御する |
| `canAccessNetwork` | `bool` | `true`     | 任意の外向きエグレス。ハーネスの `web_fetch` と `web_search` ツールも制御する             |

`AgentCapabilities.safeDefault` は 4 つすべてについてコンストラクターのデフォルトである。`legacyDefault`（4 つすべてが true）は、ケイパビリティが存在する前に作成された会話を遡って埋めたマイグレーションだけが使用する。形式が不正な、または空の保存ブロブは `safeDefault` にパースされる。レガシーキー `canCallLinear` は `canCallTicketing` として読み取られる。

## AgentSkills

スキル識別子の不変で大文字小文字を区別しない集合。ディスパッチ時にそれらのスラッグはエージェントのオーバーレイ内のスキルリンクとして同期され、その後ハーネスがリンクされたスキルのフロントマターをプロンプトに自動読み込みする。

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState（派生）

保存されない。7 つの値がある。宣言順が優先順位（`sortPriority`、テストで固定されている）であり、名簿が並べ替えに使う順序でもある:

| 状態        | `sortPriority` | 条件                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | いずれかの実行ログのステータスが `running`                                                                          |
| `blocked`   | 1              | 最新の実行の生存状態が `blocked`、`stalled`、または `looping`                                                       |
| `failed`    | 2              | 最新の実行のステータスが `error`、またはその生存状態が `failed` か `dead`                                           |
| `queued`    | 3              | 実行はディスパッチ済みだが実行中ではない — 同じエージェントの別の実行の後ろで待機しているか、書き込まれたがまだ開始されていない |
| `succeeded` | 4              | 実行が正常に完了した                                                                                                |
| `idle`      | 5              | エージェントは以前に実行されたことがあり、進行中のものは何もない                                                    |
| `neverRun`  | 6              | 実行ログが存在しない                                                                                                |

`queued` と `succeeded` は**実行単位にのみ**存在する。エージェントの名簿状態を計算する `deriveAgentLiveState` がこれらを生成することはない — 返すのは `neverRun`、`running`、`failed`、`blocked`、または `idle` である。
