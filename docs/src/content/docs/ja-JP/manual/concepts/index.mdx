これらのページでは、**Control Center がどのように機能し、なぜそうなっているのか**を説明します。理解のための読み物であり、実際に何かを行うためのものではありません。ここにあるページは、従うべき手順ではありません。特定のタスクを達成したいときは[ハウツーガイド](/ja-JP/マニュアル/ハウツーガイド/)へ、何かを調べたいときは[リファレンス](/ja-JP/マニュアル/リファレンス/)へ進んでください。

どの順番で読んでもかまいません。初めての方は、コアモデルから始めてください。

## コアモデル

ほかのすべてがその上に成り立つ 4 つの考え方です。

- [ワークスペースと分離](/ja-JP/マニュアル/コンセプト/ワークスペース/) — テナント境界と、それがクエリの書き方ではなくデータベースのレイアウトによって強制される理由
- [エージェントモデル](/ja-JP/マニュアル/コンセプト/エージェントモデル/) — エージェントを構成するもの。アイデンティティ、ロール、スキル、アダプター、モデル
- [エージェントのディスパッチライフサイクル](/ja-JP/マニュアル/コンセプト/ディスパッチライフサイクル/) — あなたのメッセージからエージェントが最初のトークンを返すまでの間に何が起きるか
- [モード](/ja-JP/マニュアル/コンセプト/モード/) — `chat`、`plan`、`review`、`orchestrate` がエージェントにできることをどう変えるか
- [ツールコンテキストとプロンプトキャッシュ](/ja-JP/マニュアル/コンセプト/ツールコンテキスト/) — エージェントがツールの一部しか見えない理由、残りにどう到達するか、プロバイダーのキャッシュを温かく保つもの
- [コードインテリジェンス](/ja-JP/マニュアル/コンセプト/コードインテリジェンス/) — コードグラフ、言語サーバー、構造検索、デバッガー
- [会話履歴](/ja-JP/マニュアル/コンセプト/会話履歴/) — 永続化、圧縮、トランスクリプトのフォーク

## 安全性と制御

エージェントが触れることを許されるものと、それを決めるのは誰か。

- [サンドボックスとセキュリティ](/ja-JP/マニュアル/コンセプト/サンドボックスとセキュリティ/) — 現在、エージェントの実行を実際に制約しているもの
- [ガードレール](/ja-JP/マニュアル/コンセプト/ガードレール/) — すべての変更操作に対する 1 つのポリシーエンジンと、ルールがどのように解決されるか
- [認可](/ja-JP/マニュアル/コンセプト/認可/) — ロール、権限カタログ、監査証跡
- [リグとエンクロージャー](/ja-JP/マニュアル/コンセプト/リグ/) — エージェントがあなたのマシンではなく使い捨ての VM を受け取る理由と、境界が実際に何であるか

## 作業の指示

意図を、実際に片づく作業に変えること。

- [チケットと委任](/ja-JP/マニュアル/コンセプト/チケット/) — フリート全体が共有する、ベンダー中立の作業単位
- [パイプラインと自動化](/ja-JP/マニュアル/コンセプト/パイプライン/) — DAG ワークフロー、トリガー、再開可能な実行
- [オーケストレーション](/ja-JP/マニュアル/コンセプト/オーケストレーション/) — 1 つのゴール、1 つの承認、生成されるパイプライン
- [AI レビュー](/ja-JP/マニュアル/コンセプト/ai-レビュー/) — PR がレビュー済みになるまで。レビュースペース、ピアのコンセンサス、軸、Ship/Hold/Block の判定
- [PR 会話](/ja-JP/マニュアル/コンセプト/pr-会話/) — forge 自体から GitHub のメンションや `ai-review` ラベルに応答する
- [メモリとナレッジ](/ja-JP/マニュアル/コンセプト/メモリとナレッジ/) — ファクト、ポリシー、エージェントが知ることを許されるもの
- [評価と品質](/ja-JP/マニュアル/コンセプト/評価と品質/) — 評価スイートと品質タブ

## 人と到達範囲

ほかの人間と一緒に働き、別の場所からフリートに到達すること。

- [マルチプレイヤーとプレゼンス](/ja-JP/マニュアル/コンセプト/マルチプレイヤー/) — 人間とエージェントが対等な参加者であること、そしてアクセスを制限するもの
- [シングルサインオン](/ja-JP/マニュアル/コンセプト/シングルサインオン/) — SAML と OIDC のログイン
- [チャットブリッジ](/ja-JP/マニュアル/コンセプト/チャットブリッジ/) — Slack ブリッジが外向きに接続する理由と、チャットからのメッセージを認可するもの
- [リモートコントロールとモバイル](/ja-JP/マニュアル/コンセプト/リモートコントロール/) — スマートフォンがあなたのサーバーに到達する方法と、その周囲のセキュリティモデル
- [ミーティングと文字起こし](/ja-JP/マニュアル/コンセプト/ミーティング/) — オンデバイスでの録音、文字起こし、要約
- [カレンダーとスケジュール](/ja-JP/マニュアル/コンセプト/カレンダー/) — Google Calendar の同期とミーティングのアラート
