**オブザーバビリティ → 品質**には、単一タスクの評価スイートと、ペアで比較する
スキルキャンペーンの両方が含まれます。スキルキャンペーンが測るのは、特定のモデルと
ハーネスが使ったときのパッケージであり、Markdown 単体の品質ではありません。

## 評価スイート

**評価スイート**とは、エージェントに対して実行するタスクをワークスペーススコープで定義したものです。プロンプト、対象のエージェントとモード、省略可能なセットアップ、固定された SHA を持つ省略可能なフィクスチャ、そしてグレーダーの一覧から構成されます。グレーダーはまず決定論的で、そうしたチェックでは表現できない部分を LLM ルーブリックによる判定が補います。

ワークスペースの作成時に 5 つのスタータースイートがシードされます。これらは、オーケストレーションの提案、シードされたバグを検出するレビュー、プランモードが読み取り専用にとどまること、プランモードがプランを生成すること、チケットのラウンドトリップをカバーします。シードは `WorkspaceCreated`（`workspace.upsert` または `workspace.create`）をリッスンし、既に存在する名前はスキップし、古いワークスペースをバックフィルしません。

### 表示される場所

**オブザーバビリティ → 品質**（`/workspaces/<id>/observability`）に、ワークスペース内の各スイートが一覧表示されます。

スイートの作成、一覧表示、編集、削除は `evals.upsertSuite`、`evals.deleteSuite`、`evals.watchSuites` で行います。品質タブが一覧であり、これらの操作がエディターです。

## スキルキャンペーン

キャンペーンは、同じタスクと同じ実行構成のもとで 2 つのアームを比較します。候補は、
存在しない状態、通常どおり利用可能な状態、明示的に読み込んだ状態、あるいは以前の
リビジョンや固定された常時利用可能なスキル一覧と比較した状態のいずれかです。これらは
それぞれ別の問いに答えるもので、強制読み込みは診断であり、通常の検出に対する
スコアではありません。[スキルガイド](/ja-JP/マニュアル/ハウツーガイド/スキル管理/#スキルを評価する)
では、比較の選び方と、予算付きの実行を承認する方法を説明しています。

証拠は、正確な**パッケージ全体のハッシュ**に紐づきます: `SKILL.md`、メタデータ、
スクリプト、参照、アセットです。サーバーは、スキャン済みの不変パッケージを取得し、
タスク集、アダプター、プロバイダー/ネイティブモデルの識別子、プロトコル、
ツールスキーマ、常時利用可能な一覧を固定します。ネイティブ Claude のキャンペーンでは、
管理対象アカウントと観測された CLI バージョンも固定します。`SKILL.md` が変わって
いなくても、参照を編集すると現在の証拠は無効になります。モデルエイリアスが記録するのは要求された内容であり、
プロバイダーの不変の重みではありません。

各試行には、新しいコンテキスト、ホーム、フィクスチャの状態が与えられます。ペアの
アームは、宣言されたスキルの介入を除いて、同じポリシーとタスク条件を使います。
ターゲット不在とは、候補のメタデータとファイルが利用できないという意味であり、
すべてのバックグラウンド指示やスキルが取り除かれたという意味ではありません。
通常の検出の比較では、タスクのプロンプトに候補の名前を書いてはいけません。

サーバーが認可、実行、予算、ワークスペースの永続化を担います。クライアントは設定を
選び、証拠を表示します。進捗は再接続をまたいで維持され、キャンセルは部分的な結果を
保持し、再起動は未完了の作業を、有料の呼び出しを黙って繰り返すのではなく中断済み
として印を付けます。これらのキャンペーンは、任意の評価スイート向けの別個の実行者
コントラクトを提供するものではありません。

## 証拠を慎重に読む

- **正しさを決めるのは結果です。** 独立した型付きの検証者が、エージェントが成功
  したという主張ではなく、成果物とそこから生じる動作を確認します。期待される
  答えは候補の囲いの外に置かれ、生成されたコードは別に分離したコピーで採点
  されます。
- **読み込みと有用性は別物です。** 利用可能性、本文や参照の読み込み、観測された
  スクリプトの使用が実行を説明します。ファイルが読まれたことは、モデルがその
  指示に従った証拠にはなりません。観測できないアクセスは不明のままです。
- **対応するベースラインを保ちます。** 候補を 1 回実行して成功しただけでは、
  利点を立証できません。利用可能なスキルが無視された試行、失敗した試行とその
  費用も含めてください。最良の再試行だけを残してはいけません。
- **繰り返しは新しいタスクではありません。** レポートはタスクごとに不確実性を
  まとめます。少ないサンプル、欠けたカバレッジ、識別情報のずれ、不明な支出は、
  採用の勧告を正当化できません。完了したキャンペーンでも結論が出ないことがあり、
  改善を示せないことは同等性やリグレッションの証明ではありません。
- **個々のリグレッションを確認します。** 集計された改善が、損なわれたタスクや
  不正な副作用を覆い隠してはいけません。セキュリティスキャン、実行時の安全性の
  観測、有用性は別々のままであり、安価な実行は欠けた品質や安全性の証拠を
  埋め合わせられません。
- **互換性のない結果をまとめないでください。** 別のモデル、ハーネス、ポリシー、
  フィクスチャ、スキルの組み合わせは別の構成です。保留した転移と構成の証拠は、
  開発用のケースとは分けておきます。

ローカルで作成した 9 つのパイロットコーパスには、有用性、ファミリー固有の
ルーティング/安全性、保留した転移/構成にわたる 108 件のタスクエントリが含まれます。
スキルの目的に合うファミリーを選んでください。参照ソリューションと既知の不良出力が
検証者を検査します。これらのフィクスチャは公開ベンチマークの再現ではなく、
インストールされたスキルが有用である証拠でもありません。スクリプト化した
プロバイダー応答による実装スモーク実行は、実モデルでのスキル品質の測定では
ありません。

## 実行と証拠の限界

制御された**組み込みハーネス**と **Claude Code** アダプターがサポートされます。
実行前に、サンドボックスと有効な資格情報の確認を通過する必要があります。組み込み
プロバイダーには、文書化されたツール対応、トークン上限、価格設定が必要です。
**Codex OAuth** は、別途 OpenAI API キーを必要とせず、自身のアカウントを
認証します。**Claude Code** は、既定の管理対象アカウント、具体的なモデル ID、
およびネイティブの API 換算コストレポートを使います。

**Claude Code** と **Codex OAuth** は**使用量による停止しきい値**を使います。
実行中の呼び出しが予算を超えることがあり、その後は以降の呼び出しが停止します。
これは請求されるサブスクリプション支出でも、厳密な請求上限でもありません。
API キーのプロバイダーは、呼び出し前の保守的な予約を維持します。観測された支出が
不明な場合は、すべてのアダプターで以降の呼び出しが停止します。不完全なカバレッジは
一部のみまたは結論なしのままです。

**Claude** は、組み込みツールと常時利用可能なスキルを無効にした状態で、プライベートな
コントローラーディレクトリ内でネイティブのモデルループを実行します。その唯一の
ツールは、組み込みハーネスが使うのと同じ隔離されたゲストへの、認証済みで
サーバーが所有する MCP ブリッジです。資格情報はそのゲストの外にとどまります。
CLI の識別情報やツールの表面が変わると、実行者を黙って切り替えるのではなく、その試行が
無効になります。フリート評価と Windows はサポートされません。ワーカーの Git プローブや
プロンプトのエコーが成功しても、評価として数えられません。

macOS のサンドボックスは、ゲストのネットワークと外部ファイルシステムへのアクセスを拒否
し、プロセスの切り離しをブロックし、CPU、ファイル、出力を制限し、所有する子孫
プロセスをクリーンアップしますが、**厳密なメモリ割り当て量を強制しません**。Linux
には bubblewrap が必要で、アドレス空間の上限を適用します。サンドボックスの初期検証で
実際に確認したのは macOS であり、Linux ではありません。サンドボックスがない場合、
ホストのシェルにフォールバックすることは決してありません。プロバイダーの資格情報は
サーバー上にとどまり、ゲストのツールの外にあります。

試行の証拠は編集（秘匿化）され、256 KiB に制限されます。エクスポートは 16 MiB に
制限されます。大きなエクスポートでは、受け入れられたすべての試行について簡潔な
結果/費用の要約が保持され、省略または要約されたトレース内容が明示的に報告されます。
エクスポートにもレポートにも、プライベートソースの完全なリプレイ用バンドルは
含まれません。合成による安全性チェックは、実際の持ち出し耐性を立証せず、隔離を
覆さず、スキルを安全だと認定するものでもありません。
