Control Center を使えば、AI コーディングエージェントのフリートを自在に指揮できます。エージェントを起動し、リアルタイムで作業の様子を眺め、その PR をレビューし、リポジトリ、ワークスペース、インテグレーションを管理できます — ネイティブのデスクトップアプリ、ブラウザー、スマートフォンのどこからでも。

## できること

- **エージェントにメッセージを送る**: スペースはフリートを動かす主要な手段です。エージェントを @メンションすると、そのエージェントは専用のコピーオンライト worktree にディスパッチされるため、複数のエージェントがあなたのチェックアウトに触れることなく、並行してコードを書き、レビューできます
- **大きな依頼をオーケストレーション**: オーケストレーターにゴールを与え、提案されたチーム全体のプランを一度承認すれば、生成された[パイプライン](/ja-JP/マニュアル/コンセプト/パイプライン/)がそれを実行します
- **PR のレビューとマージ**: 内蔵の差分ビューアー、インラインコメント、AI を活用したレビューで行えます
- **エージェントに使い捨てのマシンを渡す**: [リグ](/ja-JP/マニュアル/ハウツーガイド/リグの利用/)は使い捨ての VM です — ブラウザー、デスクトップ、スマートフォン、またはエンクロージャー内のターミナル — エージェントがこれを操作し、あなたはライブで見守りながら引き継ぐこともできます。内部の開発サーバーは `localhost`、エージェントのブラウザー、`https://myapp.test` に転送されます
- **ワークフローを自動化**: イベントやスケジュールでトリガーされる DAG ベースのパイプラインで
- **ナレッジを管理**: ワークスペーススコープのメモリ、ファクト、ポリシーで
- **作業を追跡**: ベンダー中立のチケット、プロジェクト、委任で
- **ミーティングを録画**: オンデバイスでの録音、文字起こし、話者分離を行い、ノート、アクションアイテム、決定事項に要約します
- **1 日を見渡す**: Google Calendar の同期、RSVP、ミーティングのアラート、録画とリンク付け
- **スマートフォンからフリートを追う**: デバイスをサーバーとペアリングすれば、メッセージを読み、返信し、チケットをトリアージできます。スマートフォンは到達できる最良の経路 — ループバック、LAN、tailnet、TLS — を使い、どれも使えなければ、読めないフレームを転送するエンドツーエンドで密封されたリレーにフォールバックします
- **Slack からエージェントを操作**: ワークスペースをチャットアプリにブリッジし、ボットにメンションする、Slack スレッドで返信する、スラッシュコマンドでチケットを起票する — いずれも外向きの接続を経由するため、公開エンドポイントは不要です
- **連携**: GitHub、Linear、Slack、Google Calendar、および 100 を超える MCP ツールに対応します

## インストールは必須ではありません

同じアプリケーションが、同じ機能を備えたまま
[app.usectrl.dev](https://app.usectrl.dev) のブラウザーで動作します。

デスクトップ、Web、スマートフォンのどのクライアントも、あなたのデータを所有し実際の処理を行う
ヘッドレスサーバーの上で画面を描画する薄いレンダラーにすぎません。デスクトップはそのサーバーを
代わりに起動できますが、ブラウザーのタブにはそれができないため、Web アプリは自分で動かす
サーバーに接続します。そのサーバーは自分のマシン上（`ws://localhost:9030`、証明書は不要）に
置くことも、TLS、VPN、トンネル経由で到達できるリモートホストに置くこともできます。

ブラウザーで使う方法は[インストール](/ja-JP/マニュアル/インストール/#use-it-in-your-browser)を、
3 つのクライアントの関係は[デプロイメントとクライアント](/ja-JP/マニュアル/コンセプト/デプロイメント/)を参照してください。
