各ガイドは、**すでに製品の扱いに慣れている人のための 1 つの問題**を解決します。Control Center
がインストールされ、ワークスペースがセットアップ済みであることを前提とし、タイトルで目的を掲げ、
目的を達成したところで終わります。

製品をこれから学ぶ場合は、[チュートリアル](/ja-JP/マニュアル/チュートリアル/) から始めてください。
ある挙動が _なぜ_ そうなるのかを理解したい場合は、[コンセプト](/ja-JP/マニュアル/コンセプト/)
を読んでください。
