このガイドでは、ニュースフィードをどう形作るかを説明します: どのソースから取得するか、記事をどう読むか、コンテンツブロックが何をするかです。

:::caution[ニュースフィードはユーザー単位で、ワークスペース単位ではありません]
フィードと記事はサインインしているユーザーに属します。フィード一覧、既読状態、ブックマークは、どのワークスペースに移動しても、サインインしたどのデバイスでもついてきて、ほかのユーザーには見えません。フィードはサーバーのグローバルデータベースに保存されるため、`/newsfeed` URL にワークスペース ID が付くのは、すべてのアプリ内ルートがそうなっているからにすぎません。
:::

## 記事を読む

1. サイドバーの**ニュースフィード**をクリックします
2. ツールバーのセグメントで**すべて**、**未読**、**保存済み**を切り替えます
3. 検索ボックスまたはソースの絞り込みで一覧を絞り込みます
4. レイアウトボタンでマガジングリッドと高密度リストを切り替えます

記事を開くと既読になります。たまっている記事を一度に片付けるには、ページヘッダーの**すべて既読にする**（未読の記事がある間だけ表示されます）を使います。あとで読むために 1 件保存するには、カードのブックマークコントロールを使います。

レイアウトの選択は起動をまたいで保持されます。

## フィードを追加する

1. **設定 → 自分 → ニュースフィード**を開きます（ニュースフィードのヘッダーにある設定アイコンから直接移動できます）
2. **フィードを追加**を押します
3. **名前**と**フィードURL**（RSS または Atom）を入力します
4. 必要に応じて**詳細**を展開し、カスタムの **User-Agent** を設定します — デフォルトのクライアントには別の応答を返すパブリッシャーもあります
5. **フィードを追加**を押します

チェックポイント: フィードは**フィード**一覧に表示され、最初の取得後にその記事が届きます。すでに購読している URL は「このURLのフィードはすでに存在します。」で拒否されます。

初回利用時に、すべてのユーザーへ 14 件のフィードが用意されます: Control Center、The Verge、TechCrunch、Hacker News、ByteByteGo、Product Hunt、TLDR AI、Import AI、The Pragmatic Engineer、Martin Fowler、Will Larson の Irrational Exuberance、The Engineering Manager、Lea Verou、CSS-Tricks。

## フィードを管理する

**フィード**一覧の各行には 3 つのコントロールがあります:

| コントロール | 効果 |
| --- | --- |
| スイッチ | フィードを無効にします。無効な行は淡色表示になり、取得されなくなります |
| 更新アイコン | このフィードだけを今すぐ更新します |
| ゴミ箱アイコン | 確認のうえ、フィードを削除します |

一覧の上部にある**すべて更新**は、有効なすべてのフィードを更新します。

フィードのサブタイトルには、その説明と最後に更新してからの経過時間が表示されます。取得に失敗したフィードでは、その代わりにエラーが警告色で表示されます。

編集の手段はありません。フィードの名前、URL、ユーザーエージェントを変更するには、削除してからもう一度追加してください。

取得は完全にサーバー上で実行されます: 起動時にユーザーごとに 1 回（あとから作成されたアカウントでは初回利用時に）、その後は 30 分ごとです。

## リーダーで広告とトラッカーをブロックする

1. 設定 → 自分 → ニュースフィードで、**リーダー設定**を探します
2. 内蔵リーダーを使うには**アプリで記事を開く**をオンのままにし、記事をシステムのブラウザーに渡すにはオフにします
3. **広告、トラッカー、Cookieバナーをブロック**をオンのままにします

ブロックはデフォルトでオンです。埋め込みリーダーは macOS と Windows のみです: Web ビルドと Linux では、システムのブラウザーが_リーダーそのもの_で、記事はそこで開きます（Web では新しいタブ）。Web では、ブロックのトグル、**リストを絞り込む**カード、**信頼済みサイト**カードは非表示になります。

アプリ内リーダーは記事を再整形しません。パブリッシャーのページを埋め込み WebView でレンダリングし、キャッシュされたフィルターリストを使って広告、トラッカー、Cookie バナーを抑止します。

### フィルターリストを確認または更新する

**リストを絞り込む**カードには、Cookie 非表示、広告非表示、ネットワークブロックのルールがいくつ読み込まれているかに加えて、削除するトラッキングパラメータと、リストが最後に更新された日時が表示されます。更新するには**更新を確認**を押します。

ソースは EasyList、i-dont-care-about-cookies、Fanboy Cookiemonster、いくつかの uBlock Origin リスト、uBO のトラッキングパラメータリストです。ダウンロードが成功するまで、カードはリストを「同梱のデフォルト — 更新されません」と表示します — 広告、Cookie、ネットワークのルール数は 0 のままで、トラッキングパラメータの削除には引き続き内蔵のデフォルトセットが使われます。

### サイトを許可リストに追加する

ブロックによって壊れてしまうサイトもあります。

1. 設定 → 自分 → ニュースフィードで、**信頼済みサイト**に移動します
2. **信頼済みサイトを追加**を押し、ドメインを入力します

そのサイトではブロックがスキップされます。

## トラブルシューティング

### 追加したフィードが別のワークスペースに表示される

想定どおりです。ニュースフィードはユーザー単位であり、ワークスペース単位ではありません — フィードは、サインインしているすべての場所についてきます。冒頭の注意を参照してください。

### フィードの行に説明ではなくエラーが表示される

最後の取得が失敗し、行にはその理由がそのまま表示されています。更新アイコンを押して再試行し、URL が今も RSS または Atom を配信しているか確認してください。未知のクライアントを拒否するパブリッシャーではカスタムのユーザーエージェントが必要なことがあり、その場合はフィードを削除して追加し直すことになります。

### 記事ページが正しく表示されない

**信頼済みサイト**でそのドメインの**広告、トラッカー、Cookieバナーをブロック**をオフにするか、**アプリで記事を開く**をオフにしてブラウザーで読んでください。
