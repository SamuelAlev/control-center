ワークスペース内のエージェントは、互いに質問したり、専門家に相談したり、レビューを依頼したり、メッセージを送ったり、チケットを委任したりできます。これらのどれも、エージェントが待ち続ける必要はありません。質問したエージェントは作業を続けることも、ターンを終えることもでき、回答が届くと自分の会話の中で起動されます。

## 別のエージェントに質問する

エージェントは `ask_agent` を使って、次の2つの方法のいずれかで質問します:

- **待つ**（既定）: 回答が届くまでエージェントはブロックされます。既定では600秒まで、最大1,800秒です。
- **依頼元は回答を待っていません**: 呼び出しはすぐに戻り、エージェントは作業を続けます。

どちらの場合も、質問は配信される前に記録されます。呼び出しの中で回答が返ってこなかった場合、質問したエージェントは、相手のエージェントの実行が終わると、回答とともにちょうど1回起動されます。終わり方は、回答あり、失敗、または24時間たっても回答がなく期限切れのいずれかです。その途中で、相手のエージェントが回答を約束したこと、担当者を待っていること、利用上限で停止したことを、それぞれ1回ずつ聞くことがあります。これらのどれも回答には数えられません。

`consult_agent`（最も合う専門家を呼び出す）、`request_peer_review`（レビューの指摘に対する第二の目）、`send_to_agent`（一方向のメッセージ）は、同じキューを通して動作します。`send_to_agent` は、相手のエージェントが起動されたか、メッセージが現在の実行の後ろで待つか、拒否された理由を伝えます。

相手のエージェントは、その質問を別のエージェントからの情報として読みます。従わなければならない命令としては扱わず、スラッシュコマンドを実行することもできません。

## 作業を引き渡す

- **委任したチケット**（`delegate_task`）は、チケットが確定すると、委任元のエージェントを、委任元の会話の中で起動します。
- リーダーが `@mention` またはメッセージで開始した**チームメンバーの実行**は、終了するとリーダーを、リーダーがそのメンバーを起動した会話の中で起動します。（質問は返信によって、委任されたチケットはそのチケットによって回答されます。）
- **バックグラウンドワーカー**は、ディレクターモード（`/vibe`）で、ディレクターが作業を続けている間にその結果をディレクターに渡します。
- エージェントへの **`@mention`** と、スペースのチェッカーは、どちらも起動として同じ方法で配信されます。

質問せずに、別のエージェントが何をしているかを見ることもできます。`agent_activity` は、相手のエージェントの状態、現在のツール、直近のメッセージを表示し、誰も起動しません。

## 制限

エージェントが何と言おうと、サーバーは次の制限を適用します:

| 制限 | 値 |
| --- | --- |
| 質問と引き渡しの連鎖がどこまで深くなりうるか | 3 |
| 循環（あるエージェントが、ほかを経由して自分を待っているエージェントに質問すること） | 拒否 |
| 質問するエージェントごとの保留中の質問 | 10 |
| 質問されるエージェントごとの保留中の質問 | 20 |
| 同じエージェントへの同じ質問の再送 | 10分以内は拒否 |
| 1組のエージェント間のメッセージ | 1分あたり10件 |
| メッセージまたは回答の長さ | 16,384文字 |

委任もまた、質問するエージェントの自律性と予算を尊重します。エージェントは、自分より多くの自律性や資金を持つ相手に作業を渡すことはできません。あなた自身が送ったメッセージは、この方法では制限されません。

質問されたエージェントがプロバイダーの利用上限で停止した場合、リセットが質問の期限より前に来るなら、その実行はリセットを待ちます。そうでなければ、質問はすぐに失敗し、質問したエージェントにその理由が伝えられます。

## エージェントが何を待っているかを確認する

会話では、**一般**パネルの**依頼**セクションに、エージェントがそこから行った質問が一覧表示されます。宛先、種類（**質問**、**相談**、**レビュー**）、時刻、状態（**待機中**、**回答済み**、**失敗**、**期限切れ**、または**キャンセル済み**）が示され、該当する場合は**後で回答すると約束しました**または**依頼元は回答を待っていません**が表示されます。失敗した依頼には理由が表示されます。例えば **実行がプロバイダーの利用上限で停止しました。** と表示されます。

スペースへのアクセス権を持つ人は、**依頼をキャンセル**できます。その場合、質問したエージェントは起動されず、相手のエージェントの実行も停止されません。

エージェントが待っている返信、メッセージ、完了した作業も、入力欄の上のストリップに、それが待っている他のものとともに表示されます（[スケジュールと起動予約](/ja-JP/マニュアル/ハウツーガイド/スケジュール-起動予約/#待機中のものを確認する)を参照）。
