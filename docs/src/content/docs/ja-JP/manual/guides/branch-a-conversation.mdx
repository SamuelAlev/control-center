このガイドでは、会話の以前の地点に戻り、そこから別の方向へ進める方法を説明します — 離れたパスはそのまま残したままです。

## 知っておくべきこと 1 つ

**ブランチしても何も書き込まれません。** 会話はメッセージのツリーで、その先端にポインターがあります。戻るという操作は、このポインターを動かすだけです。何も削除されず、何も隠されず、元に戻るのもまたポインターを動かすだけです。

だからこそ、ここではプロンプトを編集して再実行しても安全です。比較していた回答はそのまま残っています。

## ブランチを見る

```
/tree
```

ナビゲーターはすべてのメッセージを一覧表示し、フォークごとにインデントし、現在のパスには**このブランチ上**というマークを付けます。一度もフォークしていない会話は、これまでどおりの平坦なリストとして表示されます — ナビゲートする対象ができるまで、ナビゲーターを見るのに何のコストもかかりません。

各行には 2 つの操作があります。

| 操作                          | 効果                                                    |
| ------------------------------- | --------------------------------------------------------- |
| **ここから続ける**          | ポインターを移動します。次のメッセージはそのメッセージから続きます。 |
| **新しい会話へフォーク** | そのメッセージまでのパスを新しい会話にコピーします。 |

## ブランチ: 別のやり方を試す

1. `/tree`
2. やり直したい起点のメッセージを探します — たいていは、最後に納得していたメッセージです。
3. **ここから続ける**を選びます。
4. 新しいプロンプトを入力します。

以前の続きもツリーに残っています。`/tree` はその地点から 2 つのパスを表示し、自由に切り替えられます。

:::note[離れたパスはそのまま残っています]
ブランチしても、何も隠されず削除されません。`/tree` はすべてのパスを一覧表示し、現在のパスに**このブランチ上**のマークを付け、切り替えの手段になります。
:::

## フォーク: 別の場所へ持っていく

フォークは、同じスペース内の**新しい会話**にパスをコピーします。2 つの方向が今後も分かれ続ける見込みで、切り替えるのではなく並べて扱いたいときに使います。

コピーは新しいメッセージ id を持ちます。2 つの会話が行を共有すると、互いの以降のメッセージが見えてしまい、それはまさにフォークが防ぐべきことです。

## 戻すとブランチの違い

この 2 つは別の道具であり、その違いは重要です。

|                     | 戻す                                             | ブランチ                          |
| ------------------- | -------------------------------------------------- | ------------------------------- |
| 以降のメッセージ  | トランスクリプトから非表示                          | `/tree` では表示されたまま         |
| **ワークツリー**    | そのターンのスナップショットまでロールバック                 | 変更なし                        |
| 取り消し                | **戻すを取り消す**で一括して元に戻る                  | ポインターを戻す            |

エージェントが変更した*ファイル*を取り戻したいときは戻すを使います。会話が間違った方向に進んだものの、ファイルは問題ないときはブランチを使います。

戻すもブランチの先端を移動させるため、次のメッセージは、もう誰にも見えない末尾からではなく、正しい場所から続きます。

## アプリの外に持ち出す

### `/export`

**自己完結した HTML ファイル**を書き出します。会話全体が含まれ、折りたたみ可能なツールカードが、各呼び出しに渡されたものと返されたものを示します。スタイルシートもスクリプトも画像ホストも不要です — USB メモリーからでも動作し、5 年後でも開けます。

- **デスクトップ:** `Documents/ControlCenter/exports/` に、タイムスタンプ付きで保存されるため、2 回目のエクスポートが 1 回目を上書きしません。
- **Web:** ブラウザーのダウンロードになります。

### `/dump`

トランスクリプトを markdown としてクリップボードにコピーします。ツール呼び出しは折りたたみ可能なブロックになります。issue に貼り付けるならこれです。

推論は意図的に省かれています。それはモデルの作業メモであり、バグレポートは人が読むものだからです。
