このガイドでは、フォーカスセッションの実行方法を説明します。フォーカスセッションとは、その間 Control Center が緊急でない通知を抑制し、ほかのウィンドウの上にカウントダウンピルを浮かべる、時間制の区切りです。あわせて、その下で（既定で）再生されるサウンドスケープも扱います — サーバーがライブで合成する、終わりのない環境音のトラックで、選んだムード、外の天気、時刻によって形作られます。

フォーカスセッションはシェルレベルの機能です。どのピラーにも結び付いておらず、レイアウトを変更したり、サイドバーを隠したり、PR レビュー画面を変えたりしません。

:::note[デスクトップ版のみ]
フローティングのピルとサウンドスケープのポップアウトミニプレーヤーはネイティブの兄弟ウィンドウで、デスクトップのブートストラップだけがマウントします。`app.usectrl.dev` の Web ビルドにはどちらもなく、OS 通知のパイプラインもないため、そこではフォーカスセッションに表示するものも抑制するものもありません。サウンドスケープのパネルとその再生は、サーバーに接続できる場所ならどこでも動作します。
:::

## フォーカスセッションを開始する

1. タイトルバーの右側にあるフォーカスアイコンをクリックします（ツールチップ **フォーカスセッションを開始**）
2. ダイアログで任意の **目標** を入力します — 何に取り組んでいるか
3. **時間** を選びます: 25m、50m、1h、1h 30m、2h のいずれか。既定は 50m で、前回の選択が記憶されます
4. **開始** を押します

チェックポイント: タイトルバーのボタンは残り時間を示すアクセントカラーのチップに置き換わり、ほかのウィンドウの上にフローティングのピルが表示され、**集中モードと一緒に開始** がオンの場合はサウンドスケープの再生が始まります。

同じセッションに到達できる入口は、ほかにも 2 つあります:

- **⌘K → Start focus session** で同じダイアログが開きます。
- **⌘⇧⌥F** は、記憶された時間と目標なしでセッションを即座に開始します — ダイアログをスキップします。もう一度押すとセッションが終了します。

## フローティングのピルを読む

ピルは、どこにでもドラッグできる小さな枠なしのウィンドウです。次のものを表示します:

- ライブのプレゼンスドットと、`mm:ss` 形式の残り時間
- 設定した目標。設定していない場合は「Focus session」
- 下端に沿った細いプログレスバー

ポインタを合わせると、2 つのアクションが表示されます:

- **Pause** / **Resume** — カウントダウンを停止します。一時停止はピルにだけ作用し、セッション自体はアクティブのままです。
- **Complete** — セッションを終了します。

ピルは、メインウィンドウがどのテーマを使っていてもダークパレットのままです。任意のデスクトップコンテンツの上に浮かぶためです。

タイトルバーからピルを閉じても、セッションは動き続けます。元に戻すには、フォーカスチップの隣にあるピクチャーインピクチャーボタン（ツールチップ **バーに最小化**）を押します。

## 抑制される通知を知る

セッションがアクティブな間、Control Center は 2 つのカテゴリを除くすべての通知を破棄します。その 2 つは常に配信されます:

- **まもなく会議開始** — 後から気付く会議アラートには価値がありません
- **PR公開**

それ以外はすべて、セッションの間ずっと静かに抑制されます — 音も、OS のトーストもありません。抑制された通知は、後で配信するためにキューに入れられることはありません。

## サウンドスケープを再生する

1. タイトルバーの右側にあるスピーカーアイコンをクリックして（ツールチップ **サウンドスケープ**）パネルを開きます
2. **ムード** を選びます — **集中**、**上昇**、**リラックス**、**睡眠**
3. **再生** を押します

チェックポイント: **再生中** カードに現在のシーンが示されます — ワークスペースの場所の天気、°C 単位の気温、場所のラベルです。「環境音を調整中…」と表示されている間は、シーンはまだ解決中です。

トラックはループではありません。サーバーが、ムード、ワークスペースの場所のライブの天気、時刻から継続的に合成します。雨は明るく忙しく、嵐は大きく突風が吹き、霧はこもった響きになります。夜は日中より暗く、残響が多くなります。ムードが語彙を決めます:

| ムード | サウンド |
| ------ | -------- |
| 集中 | 低いパルスを伴う穏やかで覚醒的な環境音 — 作業の下に流すためのもの |
| 上昇 | 柔らかなパルスを伴う軽快なメロディー — 作業が重く感じるときに |
| リラックス | より温かく協和したパッド、ビートなし |
| 睡眠 | ほとんどイベントのない低いドローン、深いリバーブ |

再生中にムードを切り替えると、再生を止めることなく新しいムードに引き継がれます。

パネルは ⌘K の **Focus** カテゴリからも、フォーカスセッションのすぐ隣で開けます。

## サウンドを形作る

- **音色**（集中、上昇、リラックス）— ドラッグできるパックを備えた正方形のパッドです。横軸は **まろやか** から **エネルギッシュ**（どれだけ出来事が起きるか）、縦軸は **スペーシー** から **明るい**（どれだけ開いて聞こえるか）です。パッドをダブルタップすると中立の中央に戻り、矢印キーでパックを少し動かせます。音色はムードごとに記憶され、調整は再生中のミックスに滑らかに溶け込みます — ストリームが再起動することはありません。睡眠ムードは設計上、調整できません。
- **音量** — 0 から 100% のスライダーで、既定は 60% です。システムの音量とは別で、記憶されます。
- **場所** — ワークスペースから自動的に検出されます。シーンを再取得するには **天気を更新** を押します。

## ミニプレーヤーをポップアウトする

音声を再生している間、タイトルバーに 2 つ目のボタンが現れます（ツールチップ **プレーヤーをポップアウト**）。これは再生/一時停止、天気のグリフ、シーン名、**アプリに戻る** ボタンを備えた、常に最前面の小さな HUD を浮かべます — フォーカスセッションでまったく別のアプリを使っているときに便利です。

ミニプレーヤーから一時停止しても、ミニプレーヤーは閉じません。閉じるボタン（またはアプリの終了）だけがミニプレーヤーを消します。

## 一緒に使う

この 2 つの機能は、サウンドスケープパネルの 1 つのスイッチで連動します: **集中モードと一緒に開始**（既定でオン）。

- フォーカスセッションを開始すると、まだ何も再生されていなければサウンドスケープが始まります。
- セッションを終了すると — タイマー切れも含め、どのように終わっても — 手動でサウンドスケープを開始した場合でも停止します。

スイッチをオフにすると、2 つは独立したままになります。

## セッションを終了する

次のいずれかで終了します:

- タイトルバーのフォーカスチップをクリックする（ツールチップ **フォーカスモードが有効です — タップして終了**）
- ピルで **Complete** を押す
- **⌘⇧⌥F** を押す
- ⌘K で **Exit focus mode** を選ぶ
- タイマーを切らす — セッションはゼロで自動完了します

ピルが閉じ、通知がすぐに再開し、サウンドスケープが停止します。

## 永続しないものを理解する

セッションは、ちょうど 1 回のアプリ実行の間だけ存在します。Control Center を終了して開き直すと、セッションの途中であっても、タイマーがリセットされた非アクティブの状態で始まります — クラッシュ復旧もセッション履歴もありません。

引き継がれるのは次の 2 つだけです: 優先する時間と、通知をブロックするフラグです。目標、経過時間、ピルの開閉状態は引き継がれません。

再生も同じように一時的です — サウンドスケープは起動時に必ず停止しています。ムード、音量、ムードごとの音色は保持されますが、ストリーム自体が勝手に再開することはありません。

## トラブルシューティング

### 音色パッドが表示されない

睡眠ムードでは、意図的に調整できません。パッドを元に戻すには、集中またはリラックスに切り替えます。

### アプリを再起動すると何も再生されない

仕様です — 再生はアプリの起動時に必ず停止します。パネルを開いて **再生** を押し直します。それでも無音の場合は、システムの音量とは別の、パネルの音量スライダーを確認します。

### 天気や気温が正しくない

シーンはアクティブなワークスペースの場所に従います。再取得するには、パネルの **天気を更新** を押します。
