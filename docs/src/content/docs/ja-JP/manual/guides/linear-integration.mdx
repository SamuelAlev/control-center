コードホストを接続するときと同じように、Linear API キーをサーバー上で自分の
ユーザーに紐づけて貼り付けます。チケット、プロジェクト、リンク、コラボレーター、
委任、割り当てはすべて Control Center 自身のデータベースに対して動作し、外部
サービスは不要です — [チケットの作成と管理](/ja-JP/マニュアル/ハウツーガイド/チケット管理/)
を参照してください。

## Linear キーを保存する

**チケット API キー**は **設定 → ワークスペース → 全般** のチケット管理カードに
あります。キーはサーバー上で自分のユーザー id に紐づけて保存されます。無人で
動作するためのサーバー自身のキーは `LINEAR_API_KEY` または**プロバイダーアプリ**
カードから供給され、そのエージェントが**チケット API の呼び出しを許可**の
ケイパビリティを持つ場合にのみ `TICKETING_API_KEY` として注入されます。

## 新しいチケットを Linear として刻印する

**チケットプロバイダー**（オンボーディングの最初のステップ、および
`/workspaces/<workspaceId>/api-keys`）は `local` と `linear` を提供します。
`linear` を選ぶと、それ以降に作成するチケットに `provider: linear` が刻印されます。
