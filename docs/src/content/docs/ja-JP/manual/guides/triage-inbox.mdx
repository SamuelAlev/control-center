このガイドでは、受信トレイの活用方法を説明します。受信トレイは、あなたを
ブロックしているもの、または明示的にあなたを求めるものをすべて集約する唯一の
画面です — 保留中のエージェント承認、失敗したチケット同期、そしてレビュアー
または作成者としてあなたが関わるすべてのプルリクエストです。

## 受信トレイを開く

1. サイドバーの**受信トレイ**をクリックします。バッジには、保留中のエージェント
   承認、失敗した同期、あなたのレビューを待っているオープンな PR が数えられます。
2. または <kbd>⌘K</kbd> を押して、**受信トレイ**のナビゲーションコマンドを実行
   します。
3. または `/workspaces/<workspace-id>/inbox` に直接ディープリンクします。

サイドバーの項目には常に最新の件数が表示されるため、ページを開かなくても
トリアージの作業がたまっていくのがわかります。

## 重大度をひと目で読み取る

上から下へと目を通してください。受信トレイはすでに緊急度順に並んでいます。

1. 固定された**要対応**ストリップは、PR セクションの上に表示されます。各カード
   には重大度チップが付いています。登録済みのソース（確認プロンプトで止まって
   いるエージェント、ベンダーミラーが古いチケット同期）は**ブロック中**を発行
   します。
2. ストリップ内では、最も緊急度の高い重大度が最初に来ます。同じ場合は、最も
   長く待っている項目が先になります。
3. ストリップの下では、PR は固定のレビューライフサイクルセクションにグループ
   化されます — **レビュー待ち**、**差し戻し**、**承認済み**、**ドラフト**、
   **レビュアー待ち**、**マージ中・マージ済み**、**作成者待ち**。上部のセクション
   は_あなた_を必要とするもので、残りは_あなたの_ PR がどこにあるかを示します。
   **レビュー待ち**には、チーム機能を持つコードホスト上で、あなたが所属する
   チームをまだリクエストしている PR も含まれます（GitHub では、チームメイトの
   誰かがレビューするとチームが外れます）。

項目が受信トレイに入るのは、何かをブロックしているか、明示的にあなたを
リクエストしている場合だけです。ストリップが空でセクションリストも空のとき、
**すべて対応済みです**と表示されるのは、その空が信頼できる場合だけです。

## すべてのコードホストにまたがる 1 つの受信トレイ

ワークスペースが複数のコードホストにリポジトリを持つ場合、受信トレイはそれらを
1 つのストリームに統合します — GitHub のプルリクエストと Bitbucket の
プルリクエストは、ベンダーごとにまとめられるのではなく時間順に並び、同じ
セクションに表示されます。それらを見分けるのは、行の `repo #number` メタ情報
です。

「あなたのもの」は**コードホストごと**に解決されます。コードホストごとにあなたは
別のアカウントだからです。プルリクエストがあなたのものとして、またはあなたの
レビューをリクエストしているものとして数えられるのは、そのリポジトリが実際に
あるコードホスト上でのあなたのアイデンティティと一致する場合だけです。

ダウンしている、または接続されていないコードホストは何も寄与せず、受信トレイの
残りはそのまま保たれます — 1 つの壊れた接続がリスト全体を空にすることは
ありません。すべてのコードホストのログインがまだ解決されていない場合
（**GitHubアカウントを確認できませんでした** — この文言は引き続き GitHub を名指し
します）、githubstatus.com がインシデントを報告している場合、またはリンクされた
リポジトリをカバーする GitHub App のインストールが停止されている場合は、空の
状態に**すべて対応済みです**ではなく注意事項が表示されます。

## 要対応ストリップを解消する

ストリップの各カードには、次のアクションが 1 つだけあります。

1. カードが保留中のエージェント確認である場合は、**レビュー**をクリックします —
   その保留中の確認とともに、そのエージェントのスペースに移動します。そこで
   承認または却下します（[エージェントとチャット](/ja-JP/マニュアル/ハウツーガイド/エージェントとチャット/)を参照）。
2. カードにベンダーの**同期に失敗しました**と表示されている場合は、**開く**を
   クリックします — **設定 → ワークスペース → 全般**に移動し、その**同期の
   健全性**カードに、各接続の最終同期、連続失敗回数、最新の結果が表示されます。
   受信トレイに表示されるのはベンダーごとの最新の失敗だけなので、同期が復旧
   するとカードは消えます。
3. カードは、根本の状態が解決すると（エージェントに回答した、同期が復旧した）、
   自動的に消えます — 手動で閉じるものはありません。

:::note[これはターンごとの確認であり、ガバナンス承認ではありません]
「エージェント承認」カードは、実行中のエージェントが自分の会話の中で、1 つの
アクションの許可を求めて一時停止しているものです。エージェントが承認 MCP ツールで
作成するガバナンスの `Approval` レコードとは別物です — それらにはアプリのどこにも
人間が操作する画面がなく、ここに表示されることもありません。
:::

:::caution[同期の健全性は読み取り専用です]
このカードはチケット同期接続について報告します。**今すぐ同期**ボタンを除けば、
接続の作成、編集、再接続はできず、それを行う他の画面もありません。接続が構成
されていない場合は、単に「同期接続はまだありません」と表示されます。これは新しい
ワークスペースで表示される内容です。
:::

## ブロックしているものに絞り込む

1. （テキストフィールドにフォーカスがない状態で）<kbd>f</kbd> を押してフィルター
   メニューを開くか、ツールバーのフィルターボタンをクリックします。
2. ステータス、作成者、レビュアー、内容、リポジトリのオーナー/名前、期間、
   レビューが簡単なもの、の任意の組み合わせを選びます。メニューのファセット
   件数には、各オプションが一致する受信トレイ項目の数が表示されます。
3. 有効なフィルターはリストの上のバーにチップとして表示されます。チップの ✕ を
   クリックすると、その条件が解除されます。
4. 左のレールを使ってセクション間を移動します — 各項目には最新の件数が表示され、
   ハイライトはスクロール位置に追従します。セクションヘッダーをクリックすると、
   トリアージしないセクションを折りたたむことができます（たとえば、レビューを
   片付けている間の**ドラフト**）。
5. 列ヘッダー（タイトル、変更、更新）をクリックすると、すべてのセクションが
   並べ替えられます。有効な列をもう一度クリックすると、並び順が反転します。
   表示オプションのボタンでは、ドラフトの表示、最近マージされた期間、行の
   プロパティ、並び順、グループ化を制御できます（受信トレイのレイアウトが
   変わるのは、作成者によるグループ化だけです）。

ここでのフィルターは PR キューとは独立しています — 受信トレイを絞り込んでも
キューのフィルターは変わりませんし、その逆も同様です。

## PR 項目に対応する

1. 任意の行をクリックして、PR 詳細ページを開きます。
2. PR が**レビュー待ち**にある場合は、レビューして判断を送信します —
   [PR のレビューとマージ](/ja-JP/マニュアル/ハウツーガイド/pr-レビューとマージ/)を参照してください。
3. PR が**差し戻し**にある場合（変更リクエストまたは CI の失敗）、自分の
   チェックアウトから修正をプッシュするか、フォローアップをエージェントに任せます。
4. PR が**承認済み**にある場合は、詳細ページからマージします。
5. 自分でレビューするよりも委任したい場合は、
   [レビュアーエージェントをディスパッチ](/ja-JP/マニュアル/ハウツーガイド/レビュアーのディスパッチ/)と
   [エージェントのディスパッチライフサイクル](/ja-JP/マニュアル/コンセプト/ディスパッチライフサイクル/)を参照してください。

根本の状態が変わると（あなたのレビューが反映された、PR がマージされた）、分類器が
PR を自動的に新しいセクションへ移動します。

## 誤った操作を取り消す

1. <kbd>⌘Z</kbd> を押すと最後の操作を取り消し、<kbd>⌘⇧Z</kbd> を押すとやり直し
   ます。
2. テキストフィールドにフォーカスがある場合、⌘Z は代わりにそのフィールドの
   テキストを編集します — アプリレベルの操作を取り消すには、まずフィールドの外を
   クリックしてください。

## その場でショートカットを調べる

（テキストフィールドにフォーカスがない状態で）<kbd>?</kbd> を押すと、キーボード
ショートカットのチートシートが開きます。現在のルートで有効なすべてのバインドが
一覧表示され、受信トレイの <kbd>f</kbd> フィルターショートカットも含まれます。
全体のマップは[キーボードショートカット](/ja-JP/マニュアル/リファレンス/キーボードショートカット/)にあります。

## コマンドパレットから操作する

1. どこでも <kbd>⌘K</kbd> を押すと、コマンドパレットが開きます。
2. **受信トレイ**と入力してページにジャンプするか、PR のタイトルを入力します —
   パレットは一致するプルリクエストを一覧表示し、選んだものを開きます。
3. 受信トレイを開いている間に、**このページへのリンクをコピー**を実行すると、
   共有用にその URL がコピーされます。このコマンドは現在のルートをコピーする
   ため、受信トレイの URL になるのは、このページにいるときだけです。

## オンデマンドで更新する

受信トレイはライブで更新されますが、データが古い疑いがある場合は、ツールバーの
更新コントロールをクリックします — 接続されているすべてのコードホストに対して
サーバー側の即時スイープが実行され、マージ済み/レビュー済みのオーバーレイが
再取得されます。アイコンは、すべての取得が終わるまで回転します。
