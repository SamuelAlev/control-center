このガイドでは、モデルプロバイダーを接続し、エージェントが何で実行されるかを選ぶ方法を説明します。

ここで扱う内容はすべて 1 つのページにあります: **設定 → サーバー → モデルプロバイダー**。サブサイドバーの項目は「モデルプロバイダー」、ページの見出しは「アダプター」です。

## アダプターとは

アダプターとは、エージェントの 1 ターンを実行する_ランナー_です。2 つだけであり、この一覧は固定です。3 つ目を追加することはできません。

| アダプター                | CLI      | トランスポート                                      |
| ------------------------- | -------- | --------------------------------------------------- |
| Control Center (built-in) | なし     | インプロセスのエージェントループで、プロバイダーとは HTTP で通信する |
| Claude Code               | `claude` | `claude -p --output-format stream-json`             |

Cursor、Codex、Anthropic、OpenAI などは、別個の CLI ではなく、組み込みアダプター上の**プロバイダー**です。追加_できる_のは別のプロバイダー、つまり OpenAI または Anthropic 互換の任意のエンドポイントです。それは次のセクションで扱います。

:::note[検出が調べるのはあなたのマシンではなくサーバーです]
**検出されたランナー**カードには、_サーバーホストの_ `PATH` で `cc_server` が見つけたものが一覧されます。シンクライアントや Web クライアントでは、それは今見ているマシンとは別のマシンです。CLI は `cc_server` を実行するマシンにインストールしてください。
:::

## モデルプロバイダーを接続

組み込みアダプターは、実行する前に少なくとも 1 つの接続済みプロバイダーが必要です。カタログには 14 個が同梱されています。

1. **設定 → サーバー → モデルプロバイダー**に移動します
2. **プロバイダーとモデル**までスクロールします
3. 使うプロバイダーを見つけて接続します:

| プロバイダー                                                                                             | 接続方法                                                                                                                      |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | API キー。Claude Pro/Max サブスクリプションは Anthropic API のログインではないため、そのプランでは Claude Code アダプターを使用してください |
| OpenAI、Codex、Cursor                                                                                    | ブラウザーでの OAuth ログイン、または API キー。Codex は CLI の起動ではなく、Codex Responses バックエンド経由の ChatGPT Plus/Pro です |
| Kimi Code                                                                                                | ブラウザー OAuth のみ（デバイスコードフロー）。定額プランなので、トークン単位の料金はありません                              |
| OpenRouter、Groq、Google Gemini、DeepSeek、Mistral、xAI、z.ai、z.ai GLM Coding Plan、Moonshot (Kimi API) | API キー                                                                                                                      |

確認ポイント: 行のバッジが接続済みに変わり、展開するとそのプロバイダーが提供するモデルが一覧されます。各モデルには 100 万トークンあたりの料金とコンテキストウィンドウが表示されます。

OAuth トークンはサーバー自身の資格情報ストアに保存され、期限切れになる前に更新されます。プロバイダーの資格情報は**ホストグローバル**であり、1 つのワークスペースに限定されず、インストール上のすべてのワークスペースで共有されます。

### カスタムプロバイダーを追加

Ollama、LM Studio、vLLM、またはプライベートデプロイメントに使用します。

1. **プロバイダーとモデル**の**カスタムプロバイダー**で、**プロバイダーを追加**を押します
2. **名前**を入力し、**API の種類**（OpenAI 互換または Anthropic 互換）を選び、**ベース URL** を指定します（例: `http://localhost:11434/v1`）
3. エンドポイントに必要な場合は **API キー**を追加し、**プロバイダーを追加**を押します

カスタムプロバイダーは同じ一覧に表示され、組み込みの兄弟にはない削除ボタンが付きます。

## エージェントで使うモデルを選ぶ

1. **設定 → ワークスペース → エージェント**に移動し、エージェントを選択します
2. **設定**タブで**アダプター**を選びます
3. その隣のドロップダウンから**モデル**を選びます

組み込みアダプターでは、ドロップダウンは接続済みの各プロバイダー自身のカタログからリアルタイムに組み立てられます。資格情報が保存されていないプロバイダーはモデルを 1 つも提供しないため、ドロップダウンが空のときはほぼ常に「利用可能なものがない」ではなく「まだ何も接続していない」という意味になります。

:::note[models.dev は補完情報であり、ID の供給元ではありません]
同梱の [models.dev](https://models.dev) カタログは、すでにライブ一覧にあるモデルに料金とコンテキストウィンドウを補います。モデル ID を追加することはありません。期待するモデルが見当たらない場合、そのプロバイダーのエンドポイントがそれを返していません。
:::

組み込みアダプターのモデル ID は `provider/model` という修飾形式で、`|` で区切られたフォールバックチェーンを持てます。フォールバック時は、要求したモデルではなく、実際にそのターンを処理したモデルに対してコストが計算されます。

:::note[アダプターのないエージェントは組み込みループで実行されます]
すべてのワークスペースには 5 体のエージェント（CEO と、`qa`、`architect`、`engineer`、`librarian`）がアダプターもモデルもなしでシードされます。ディスパッチは **Control Center (built-in)** にフォールバックし、このページの**デフォルトランナー**設定にはフォールバックしません。後者はクライアントの設定であり、ディスパッチ経路が読むことはありません。これらの実行のログには `cc-harness` が記録されるため、トランスクリプトには実際に実行されたものが示されます。

モデルもない場合、組み込みループは Anthropic にデフォルトモデルを問い合わせます。したがって、完全に未設定のエージェントは、Anthropic アカウントを接続していれば実行され、そうでなければ `No credential for provider "anthropic"` で失敗します。

オンボーディングのアダプター手順を終えると、その時点で存在するすべてのワークスペースにわたり、アダプターまたはモデルがまだ不足している**すべての**エージェント（CEO とスペシャリスト）が、選んだ組み合わせで後からまとめて更新されます。後から作成されたワークスペースでは、5 体すべてが引き続き未設定でシードされます。使用する予定のすべてのエージェントで、アダプターとモデルを明示的に設定してください。
:::

## ランナー CLI をインストール

組み込みアダプターにはインストールは不要です。Claude Code の場合は、そのツール自身のパッケージマネージャーで CLI を**サーバーホストに**インストールします。例:

```bash
npm install -g @anthropic-ai/claude-code
```

その後、ページ上部の**更新**を押します。検出された各行には、解決されたバージョンとパス、および JSON モードとモデル選択に対応しているかどうかを示すチップが表示されます。

外部 CLI は、サーバーホスト上の自身の設定に、自身の資格情報を保持します。Control Center はそれらを管理しません。

:::caution[アダプターの追加引数と環境変数はこのデバイスに保存されます]
各アダプターの行には**追加引数**フィールドと**環境変数**ダイアログがあります。これらの値はお使いのデバイスに保存されます。サーバーは起動時の argv と env を自身の設定ストアから読み取ります。プロバイダーのキーは（OAuth またはモデルプロバイダーページのキーフィールドを使って）サーバーに置き、これら 2 つのフィールドには入れないでください。
:::

## ワークスペースが使用できるプロバイダーを制限

プロバイダーのガバナンスはワークスペース単位で、最後に一致したものが勝つ方式で評価されます。

1. **プロバイダーとモデル**で、プロバイダーの行の**許可**スイッチをオフにします

これにより、アクティブなワークスペースにそのプロバイダーの `deny` ステートメントが書き込まれ、そのワークスペースのカタログからそのモデルが外れます。スイッチを再びオンにすると、ステートメントが削除されます。

## トラブルシューティング

### ランナーが見つからないと表示される

- CLI が自分のマシンだけでなく**サーバーホストの** `PATH` にあることを確認します
- GUI から起動したデスクトップアプリは最小限の `PATH` でサーバーを起動するため、シェル専用のパスにインストールされた CLI はそれから見えないことがあります
- インストール後に**更新**を押します

### モデルのドロップダウンが空である

- アダプターが組み込みのもので、プロバイダーが 1 つも接続されていない — **プロバイダーとモデル**で接続します
- または、プロバイダーは接続済みだが、このワークスペースのガバナンススイッチで拒否されている

### モデルは実行されるが料金が不明と表示される

ライブのモデル一覧には ID が含まれます。料金とコンテキストは models.dev から取得します。まったく新しいモデルやカスタムプロバイダーのモデルには、まだカタログのエントリがありません。
