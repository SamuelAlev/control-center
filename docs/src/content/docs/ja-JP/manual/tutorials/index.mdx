チュートリアルは **レッスン** です。どれも、実際の作業をひとつの道筋で最初から最後まで
通します。途中で判断を求められることはありません。手順どおりに進めれば、きちんと動きます。

これは製品の全体像をつかむためのものです。製品の姿が見えてきたら、特定のタスクをこなすには
[ハウツーガイド](/ja-JP/マニュアル/ハウツーガイド/)のほうが速い道です。

次の順番で進めてください — どれも前のチュートリアルを前提にしています。

1. [初めてのワークスペース](/ja-JP/マニュアル/チュートリアル/初めてのワークスペース/) — ワークスペースを作成し、リポジトリを追加して、分離モデルを確認します
2. [初めてのエージェントをディスパッチ](/ja-JP/マニュアル/チュートリアル/初めてのエージェント/) — エージェントにアダプターとモデルを与えて、実際に働かせます
3. [初めてのプルリクエストをレビュー](/ja-JP/マニュアル/チュートリアル/初めてのプルリクエスト/) — 差分を読み、コメントしてマージします
4. [初めてのパイプラインを構築](/ja-JP/マニュアル/チュートリアル/初めてのパイプライン/) — ステップをつないで DAG にし、実行します

残りの 2 つは独立しています。動くワークスペースができたら、どちらかを進めてください。

- [Slack をワークスペースにブリッジ](/ja-JP/マニュアル/チュートリアル/初めてのチャットブリッジ/) — Slack スレッドからエージェントを操作します
- [SSO でチームをサインイン](/ja-JP/マニュアル/チュートリアル/sso/) — ID プロバイダーを接続し、ログインを最初から最後まで通します

:::note[始める前に]
まず Control Center をインストールしてください — [インストール](/ja-JP/マニュアル/インストール/)を参照してください。動くエージェントまでの
最短の道筋だけを知りたい場合は、代わりに[クイックスタート](/ja-JP/マニュアル/クイックスタート/)を進め、あとでここに戻ってきてください。
:::
