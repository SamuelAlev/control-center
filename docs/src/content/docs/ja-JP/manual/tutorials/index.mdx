Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/ja-JP/マニュアル/ハウツーガイド/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/ja-JP/マニュアル/チュートリアル/初めてのワークスペース/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/ja-JP/マニュアル/チュートリアル/初めてのエージェント/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/ja-JP/マニュアル/チュートリアル/初めてのプルリクエスト/) — read the diff, comment and merge
4. [Build your first pipeline](/ja-JP/マニュアル/チュートリアル/初めてのパイプライン/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/ja-JP/マニュアル/チュートリアル/初めてのチャットブリッジ/) — drive agents from a Slack thread
- [Sign your team in with SSO](/ja-JP/マニュアル/チュートリアル/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/ja-JP/マニュアル/インストール/). If you only want the
shortest possible path to a running agent, take the [quick start](/ja-JP/マニュアル/クイックスタート/)
instead and come back here afterwards.
:::
