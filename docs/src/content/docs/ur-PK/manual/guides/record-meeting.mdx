یہ گائیڈ بتاتی ہے کہ میٹنگ کیسے ریکارڈ کریں اور AI سے تیار شدہ تحریر کیسے حاصل کریں۔
یہ کیسے کام کرتا ہے، اِس کے لیے [میٹنگز اور ٹرانسکرپشن](/ur-PK/ہدایت-نامہ/تصورات/میٹنگز/) دیکھیں۔

## شروع کرنے سے پہلے

- **اسپیچ ماڈل کا انتظار کریں، پھر سرور ری اسٹارٹ کریں۔** ایک عام بوٹ پس منظر میں
  منتخب ASR ماڈل (Parakeet TDT 0.6B v3، کثیراللسانی ڈیفالٹ، تقریباً 600 MB) زبردستی
  انسٹال کرتا ہے۔ سرور ماڈل کو **بوٹ پر صرف ایک بار** حل کرتا ہے، اس لیے ری اسٹارٹ تک
  پہلے رن میں اب بھی کوئی ریکارڈنگ آپریشن نہیں ہوتا۔ ڈسک پر کوئی ماڈل نہ ہونے پر
  ریکارڈنگ `Could not start recording on the host: …` کے ساتھ ناکام ہو جاتی ہے۔ کوئی
  مختلف بلڈ چننے کے لیے **ترتیبات → سرور → آواز اور میٹنگ ماڈلز** پر جائیں — اُس کے
  لیے بھی ری اسٹارٹ درکار ہے۔
- پہلی ریکارڈنگ پر جب آپ کا OS پوچھے تو **مائیکروفون** کی اجازت دیں۔
- **macOS 14.4+** پر سسٹم آڈیو Core Audio process taps کے ذریعے کیپچر ہوتی ہے — کوئی ڈرائیور انسٹال کرنے کی ضرورت نہیں، مگر OS دوسری بار _آڈیو کیپچر_ کی اجازت مانگتا ہے۔ یہ Screen Recording نہیں ہے اور یہ کبھی اسکرین ریکارڈنگ انڈیکیٹر روشن نہیں کرتا۔ اِس سے انکار کرنے پر آغاز `System-audio capture permission denied.` کے ساتھ ناکام ہو جاتا ہے۔ macOS 14.4 سے نیچے سسٹم آڈیو کیپچر نہیں ہوتی۔
- **Linux** پر `parecord` (pulseaudio-utils) یا `pw-record` (pipewire) کا `PATH` پر ہونا لازمی ہے — کیپچر اِن میں سے ایک کو PipeWire/PulseAudio مانیٹر سورس کے خلاف چلاتی ہے۔ اِن میں سے کوئی ایک نہ ہونے پر آغاز `No system-audio capture tool found` کے ساتھ ناکام ہو جاتا ہے۔

:::caution[آپ کی میٹنگ کی آڈیو کہاں جاتی ہے]
کیپچر، ٹرانسکرپشن، ایکو کی منسوخی اور اسپیکر ڈائرائزیشن سب کچھ آن ڈیوائس چلتا ہے،
بغیر کسی کلاؤڈ کال کے — مگر ”ڈیوائس“ سے مراد **cc_server میزبان** ہے، جو سرور ریموٹ
چلانے پر ایک مختلف مشین ہوتا ہے۔ اور حتمی تحریر ایک عام ایجنٹ رن ہے: `meeting_summary`
پائپ لائن پوری ٹرانسکرپٹ اور آپ کے موٹے نوٹس اُس ماڈل فراہم کنندہ کو بھیجتی ہے جو وہ
ایجنٹ استعمال کرتا ہے۔ اگر ٹرانسکرپٹ کو مشین سے باہر نہیں جانا چاہیے تو اُس ایجنٹ کو
کسی مقامی فراہم کنندہ کی طرف اشارہ کریں۔

ریکارڈنگ اسکرین آپ کے ریکارڈ کرتے وقت یہ بتاتی رہتی ہے، اس لیے بھیجنے کے لیے کوئی
ٹرانسکرپٹ بننے سے پہلے ہی فیصلہ آپ کے سامنے ہوتا ہے۔
:::

## ریکارڈنگ شروع کریں

1. سائیڈبار میں **میٹنگز** کھولیں۔
2. **میٹنگ ریکارڈ کریں** پر کلک کریں۔ لائیو ریکارڈنگ HUD `/meetings/record` پر کھلتا ہے۔

ریکارڈنگ فوراً شروع ہو جاتی ہے اور آپ کا مائیکروفون نیز سسٹم آؤٹ پٹ آڈیو — یعنی باقی
شرکاء — کیپچر کرتی ہے۔ کوئی موڈ پرامپٹ اور کوئی آڈیو سورس پکر نہیں ہے: اِن پرسن
سنگل مائیک موڈ API میں موجود ہے مگر آج اُس کا کوئی UI نہیں۔

براؤزر میں یہی فلو کام کرتا ہے، البتہ ایک فرق کے ساتھ: ”سسٹم آڈیو“ ایک اسکرین شیئر ہے
جس میں آڈیو ٹریک شامل ہونا لازمی ہے۔ کوئی براؤزر ٹیب (یا پوری اسکرین) شیئر کریں اور
پکر میں ”ٹیب کی آڈیو شیئر کریں“ / ”سسٹم آڈیو شیئر کریں“ فعال کریں۔ Safari اور Firefox
نیز macOS پر فل اسکرین شیئرنگ اکثر ایسا ٹریک فراہم نہیں کر سکتے۔

HUD ایک لیول میٹر، گزرا ہوا وقت اور ایک طرف بنتی ہوئی لائیو ٹرانسکرپٹ دکھاتا ہے۔

## میٹنگ کے دوران

- نوٹس پین میں **موٹے نوٹس لیں**۔ یہ ٹائپ کرتے ہی محفوظ ہوتے جاتے ہیں اور بعد میں خلاصے والے ایجنٹ کو دیے جاتے ہیں، اس لیے جو کچھ ٹرانسکرپٹ سے رہ جائے وہ لکھ لیا کریں۔
- **فعال ٹیمپلیٹ** والی قطار میں **نوٹ ٹیمپلیٹ منتخب کریں**۔ یہ اِس میٹنگ کے خلاصے کی تشکیل کرتا ہے اور ریکارڈنگ کے ساتھ محفوظ ہو جاتا ہے، اس لیے بعد میں دوبارہ چلانے پر وہی ٹیمپلیٹ دوبارہ استعمال ہوتا ہے جو آپ نے یہاں چنا تھا۔
- توقف کنٹرول سے **توقف اور جاری رکھیں**۔ توقف کے دوران ٹرانسکرپشن رک جاتی ہے اور ٹائمر جم جاتا ہے۔
- ٹرانسکرپٹ اسپیکر کے ٹیگ کے ساتھ اسٹریم ہوتی ہے: آپ کے الفاظ **آپ** کے طور پر، کال میں موجود ہر شخص **دیگر** کے طور پر — یہاں تک کہ ڈائرائزیشن دیگر کو `Person 1`، `Person 2`، … میں تقسیم کر دیتی ہے، جنہیں آپ دوبارہ نام دے سکتے ہیں۔

:::note[بہت مدھم بولنے والا اسپیکر شاید ٹرانسکرائب نہ ہو]
ٹرانسکرپشن ہر اُس آڈیو ونڈو کو چھوڑ دیتی ہے جو کبھی خاموشی کی حد سے اوپر نہ اٹھی ہو،
اور اُسے بالکل بھی ڈی کوڈ نہیں کرتی۔ یہ کسی خاموش چینل کو من گھڑت غیر اسپیچ ٹوکنز پر
CPU جلانے سے روکتا ہے، مگر اِس کا یہ مطلب بھی ہے کہ کوئی مدھم یا دور کا اسپیکر کوئی
ٹرانسکرپٹ نہ دے سکے۔ لیول میٹر آخر میں دیکھنے کے بجائے شروع میں ہی چیک کریں۔
:::

## روکیں اور خلاصہ کریں

1. **روکیں اور خلاصہ** پر کلک کریں۔
2. Control Center آپ کو سیدھا میٹنگ کے تفصیلی ویو پر لے جاتا ہے، جو **پروسیس ہو رہا ہے** کے طور پر نشان زد ہوتا ہے: ڈائرائزیشن ریموٹ چینل کو الگ الگ اسپیکرز میں تقسیم کرتی ہے اور `meeting_summary` پائپ لائن تحریر تیار کرتی ہے۔
3. وہ پائپ لائن مکمل ہوتے ہی میٹنگ **مکمل** پر پلٹ جاتی ہے۔ آپ کو اُس کا انتظار کرنے کی ضرورت نہیں — تفصیلی ویو خود کو اپ ڈیٹ کرتا رہتا ہے۔

## تحریر کا جائزہ لیں

میٹنگ کی تفصیل (`/meetings/:meetingId`) میں چار ٹیبز ہوتے ہیں:

| ٹیب             | وہاں کیا ہے                                                                      |
| ---------------- | ------------------------------------------------------------------------------- |
| **نوٹس**         | AI خلاصہ اور بہتر شدہ نوٹس، جو آپ کے موٹے نوٹس + ٹرانسکرپٹ سے بنائے جاتے ہیں    |
| **ٹرانسکرپٹ**    | ٹائم اسٹیمپ کے ساتھ مکمل اسپیکر ٹیگ والی ٹرانسکرپٹ                              |
| **ایکشن آئٹمز**  | نکالے گئے کام، ہر ایک کے ساتھ اختیاری ذمہ دار                                   |
| **فیصلے**        | کال کے دوران درج کیے گئے فیصلے                                                  |

یہاں سے آپ یہ کر سکتے ہیں:

- **اسپیکرز کے نام بدلیں**: `Person 1` کو کسی اصل نام سے بدلیں؛ یہ پوری ٹرانسکرپٹ پر لاگو ہوتا ہے۔
- جیسے جیسے ایکشن آئٹمز مکمل ہوں، **اُن پر نشان لگائیں**۔
- کسی ایکشن آئٹم سے **ٹکٹ بنائیں**: یہ ایک نیا، غیر تفویض شدہ ٹکٹ بناتا ہے جس کا عنوان ایکشن آئٹم ہوتا ہے اور اُسے واپس اُس قطار سے لنک کرتا ہے۔ اسے خود ٹکٹ سے کسی ایجنٹ کو تفویض کریں (دیکھیں [ایجنٹس کو کام تفویض کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/ٹکٹس-تفویض-کریں/))۔
- ایک نئی گزر کے لیے **خلاصہ دوبارہ چلائیں** (مثلاً اسپیکرز کے نام بدلنے کے بعد)۔ یہ میٹنگ ریکارڈ ہوتے وقت محفوظ ہوا ٹیمپلیٹ دوبارہ استعمال کرتا ہے۔ فعال ٹیمپلیٹ **ترتیبات → ورک اسپیس → میٹنگز** پر منتخب کریں۔

نوٹس، عنوان، ایکشن آئٹمز اور فیصلوں کی ترمیم ہر جگہ کام کرتی ہے۔
**خلاصہ دوبارہ چلائیں** اور پروسیس ہو رہی میٹنگ منسوخ کرنا **صرف ڈیسک ٹاپ** پر ہے — براؤزر
میں دونوں بٹن کچھ نہیں کرتے۔

## سیدھا کیلنڈر ایونٹ سے ریکارڈ کریں

اگر آپ نے [کیلنڈر جوڑ رکھا ہے](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/کیلنڈر-جوڑیں/)، تو آپ
دستی آغاز چھوڑ سکتے ہیں۔ یہ **صرف ڈیسک ٹاپ** پر ہے؛ ویب کلائنٹ اِس سے انکار کر دیتا ہے۔

1. ایونٹ کو **کیلنڈر** سے کھولیں۔
2. **ریکارڈنگ شروع کریں اور لنک کریں** پر کلک کریں۔

ریکارڈنگ ایونٹ کے عنوان کے ساتھ شروع کی جاتی ہے اور واپس اُس سے لنک ہو جاتی ہے، تاکہ
نوٹس اور کیلنڈر اندراج جڑے رہیں۔

:::note[میٹنگ حذف کرنے سے اُس کی آڈیو حذف نہیں ہوتی]
میٹنگ حذف کرنا اُس کی قطاریں ہٹاتا ہے، مگر `<dataDir>/meetings/<meetingId>/` کے تحت
محفوظ WAV فائلیں ڈسک پر رہ جاتی ہیں — کوئی برقراری پالیسی، حجم کی حد یا صفائی نہیں
ہوتی۔ اگر آڈیو اہم ہے تو وہ ڈائریکٹری خود ہٹائیں۔
:::
