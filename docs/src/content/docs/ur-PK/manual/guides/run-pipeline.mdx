یہ گائیڈ ہاتھ سے رن شروع کرنے کا احاطہ کرتی ہے۔ کسی رن کی نگرانی، قدم کے آؤٹ پٹ
پڑھنے اور ناکامی سے بحالی کے لیے
[پائپ لائن رنز کی نگرانی کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/پائپ-لائنز-کی-نگرانی/)
دیکھیں۔

## رن شروع کریں

1. ورک اسپیس سائیڈ بار میں **پائپ لائنز** پر کلک کریں۔
2. ہیڈر میں **پائپ لائن چلائیں** دبائیں۔ آپ لانچر
   (`/workspaces/<workspace-id>/pipelines/run`) پر پہنچ جاتے ہیں۔
3. بائیں ریل سے ایک ٹیمپلیٹ منتخب کریں۔ ہر کارڈ ٹیمپلیٹ کا نام، اُس کی تفصیل
   اور یہ دکھاتا ہے کہ وہ ان پٹس لیتا ہے یا نہیں۔
4. دائیں طرف ان پٹ فارم بھریں۔ لازمی فیلڈز قدر آنے تک بٹن روکے رکھتی ہیں؛ جس
   ٹیمپلیٹ میں کوئی ان پٹ نہ ہو، وہ یہی بتاتا ہے۔
5. **پائپ لائن چلائیں** دبائیں۔

آپ رن کے تفصیلی صفحے پر پہنچ جاتے ہیں، جہاں ٹائمنگ واٹرفال اور گراف کینوس لائیو
ہوتے ہیں۔

## اگر ریل خالی ہو

لانچر کوئی ٹیمپلیٹ صرف اُس وقت دکھاتا ہے جب **دونوں** باتیں درست ہوں:

- ٹیمپلیٹ کا سوئچ **ترتیبات → ورک اسپیس → پائپ لائن ٹیمپلیٹس** میں آن ہو۔
- ٹیمپلیٹ ایڈیٹر کے **دستی رن** ڈائیلاگ میں **دستی رن کی اجازت دیں** آن ہو —
  یہی سوئچ وہ `manual` ٹریگر بناتا ہے جسے لانچر پڑھتا ہے۔

تیرہ بلٹ اِن ٹیمپلیٹس میں سے آٹھ غیر فعال آتے ہیں: `external_pr_welcome`،
`cross_review`، `ticket_to_pr`، `pr_triage`، `pre_merge_gate`، `release_notes`،
`dep_audit` اور `pr_digest`۔ انجن غیر فعال ٹیمپلیٹ شروع کرنے سے انکار کرتا ہے،
اس لیے یہاں اسے ڈھونڈنے سے پہلے اس کا سوئچ آن کریں۔

ٹیمپلیٹس کی فہرست میں فی ٹیمپلیٹ کوئی **چلائیں** ایکشن نہیں اور ایڈیٹر کے اندر
بھی کوئی رن بٹن نہیں — لانچر ہی واحد دستی داخلہ نقطہ ہے۔

## ریپوزٹری ان پٹ بھریں

**ریپوزٹری** قسم کا ان پٹ ورک اسپیس کے رجسٹرڈ ریپوز پر ایک پکر بناتا ہے۔ کسی
ایک کو چننے سے `repo_id`، `repo_local_path`، `repo_full_name` اور — جب ریپو کا
GitHub ریموٹ ہو — `repo_owner` اور `repo_name` رن پے لوڈ میں بھر جاتے ہیں، تاکہ
نیچے کے قدم جو چاہیں پڑھ سکیں۔

## اسے چلتے دیکھیں

رن کے تفصیلی صفحے کے تین حصے ہیں: ایک میٹا اسٹرپ (شروع کا وقت، فعال دورانیہ،
قدم کی پیش رفت، ناکامی کا بینر، **دوبارہ کوشش** اور **حذف کریں**)، ایک سکیڑے
جا سکنے والا ٹائمنگ واٹرفال جس میں فی قدم دورانیہ اور لاگت شامل ہے، اور گراف
کینوس۔ کسی نوڈ کو منتخب کرنے سے اُس قدم کی تفصیل کا پینل کھل جاتا ہے۔

[پائپ لائن رنز کی نگرانی کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/پائپ-لائنز-کی-نگرانی/)
اِن سب کا احاطہ کرتا ہے، بشمول یہ کہ معطل قدم کو کیسے پڑھا جائے اور جب کوئی
ناکام ہو تو کیا کرنا ہے۔

ایپ سے آپ جو بھی رن شروع کرتے ہیں وہ حقیقی ہوتا ہے۔
