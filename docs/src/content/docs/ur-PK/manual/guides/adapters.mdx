یہ گائیڈ دکھاتی ہے کہ ماڈل فراہم کنندگان کیسے جوڑیں اور چنیں کہ ایجنٹ کس پر
چلے۔

یہ سب کچھ ایک ہی صفحے پر ہے: **ترتیبات → سرور → ماڈل فراہم کنندگان**۔ ذیلی
سائیڈ بار کا اندراج "ماڈل فراہم کنندگان" پڑھا جاتا ہے؛ صفحے کا عنوان "اڈاپٹرز"
پڑھا جاتا ہے۔

## اڈاپٹر کیا ہے

اڈاپٹر وہ _رنر_ ہے جو ایک ایجنٹ باری چلاتا ہے۔ یہ دو ہیں اور فہرست مقرر ہے —
تیسرا شامل نہیں کیا جا سکتا۔

| اڈاپٹر                    | CLI      | ٹرانسپورٹ                                          |
| ------------------------- | -------- | --------------------------------------------------- |
| Control Center (built-in) | کوئی نہیں | پراسیس کے اندر ایجنٹ لوپ، فراہم کنندگان سے HTTP کے ذریعے بات کرتا ہے |
| Claude Code               | `claude` | `claude -p --output-format stream-json`             |

Cursor، Codex، Anthropic، OpenAI اور باقی سب بلٹ اِن اڈاپٹر پر **فراہم کنندگان**
ہیں، الگ CLIs نہیں۔ جو آپ _شامل_ کر سکتے ہیں وہ ایک اور فراہم کنندہ ہے — کوئی بھی
OpenAI- یا Anthropic-مطابق اینڈ پوائنٹ۔ یہی اگلا حصہ ہے۔

:::note[دریافت آپ کی مشین نہیں، سرور کی جانچ کرتی ہے]
**دریافت شدہ رنرز** کارڈ وہ فہرست دکھاتا ہے جو `cc_server` نے _سرور ہوسٹ کے_
`PATH` پر پایا۔ تھن یا ویب کلائنٹ پر یہ اُس مشین سے مختلف ہوتی ہے جسے آپ دیکھ
رہے ہیں۔ CLI اُس مشین پر انسٹال کریں جو `cc_server` چلاتی ہے۔
:::

## ماڈل فراہم کنندہ جوڑیں

بلٹ اِن اڈاپٹر کو چلنے سے پہلے کم از کم ایک منسلک فراہم کنندہ درکار ہے۔ کیٹلاگ
میں چودہ شامل ہیں۔

1. **ترتیبات → سرور → ماڈل فراہم کنندگان** پر جائیں
2. **فراہم کنندگان اور ماڈلز** تک اسکرول کریں
3. اپنا فراہم کنندہ ڈھونڈیں اور اسے جوڑیں:

| فراہم کنندہ                                                                                              | کیسے جوڑیں                                                                                                                    |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | API کلید۔ Claude Pro/Max سبسکرپشن Anthropic API لاگ اِن نہیں ہے — اُس پلان کے لیے Claude Code اڈاپٹر استعمال کریں              |
| OpenAI, Codex, Cursor                                                                                    | براؤزر OAuth لاگ اِن، یا API کلید۔ Codex، Codex Responses بیک اینڈ کے ذریعے ChatGPT Plus/Pro ہے، CLI اسپان نہیں                |
| Kimi Code                                                                                                | صرف براؤزر OAuth — ڈیوائس کوڈ فلو۔ یہ فلیٹ ریٹ پلان ہے، اس لیے اس کی فی ٹوکن کوئی قیمت نہیں                                  |
| OpenRouter, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API)       | API کلید                                                                                                                       |

تصدیق: قطار کا بیج منسلک میں بدل جاتا ہے اور اسے پھیلانے پر اُس فراہم کنندہ کے پیش
کردہ ماڈلز کی فہرست آتی ہے، ہر ایک کے ساتھ فی ملین ٹوکن قیمت اور کانٹیکسٹ ونڈو۔

OAuth ٹوکن سرور کے اپنے اسناد کے ذخیرے میں جاتے ہیں اور میعاد ختم ہونے سے پہلے
تازہ کر دیے جاتے ہیں۔ فراہم کنندہ کے اسناد **ہوسٹ گلوبل** ہوتے ہیں — انسٹال کی
ہر ورک اسپیس انہیں شیئر کرتی ہے، کسی ایک تک محدود نہیں۔

### حسبِ ضرورت فراہم کنندہ شامل کریں

یہ Ollama، LM Studio، vLLM یا کسی نجی ڈیپلائمنٹ کے لیے استعمال کریں۔

1. **فراہم کنندگان اور ماڈلز** میں، **حسبِ ضرورت فراہم کنندگان** کے تحت،
   **فراہم کنندہ شامل کریں** دبائیں
2. ایک **نام** بھریں، **API قسم** چنیں (OpenAI-مطابق یا
   Anthropic-مطابق) اور **بیس URL** دیں (مثلاً
   `http://localhost:11434/v1`)
3. اگر اینڈ پوائنٹ کو ضرورت ہو تو ایک **API کلید** شامل کریں، پھر **فراہم کنندہ شامل کریں** دبائیں

حسبِ ضرورت فراہم کنندہ اُسی فہرست میں ظاہر ہوتا ہے، ایک حذف بٹن کے ساتھ جو اس کے
بلٹ اِن ہم منصبوں کے پاس نہیں ہوتا۔

## ایجنٹ کے لیے ماڈل منتخب کریں

1. **ترتیبات → ورک اسپیس → ایجنٹس** پر جائیں اور ایجنٹ منتخب کریں
2. **ترتیبات** ٹیب پر، **اڈاپٹر** چنیں
3. اس کے ساتھ والے ڈراپ ڈاؤن سے **ماڈل** چنیں

بلٹ اِن اڈاپٹر کے لیے ڈراپ ڈاؤن ہر منسلک فراہم کنندہ کے اپنے کیٹلاگ سے لائیو تیار
ہوتا ہے۔ جس فراہم کنندہ کا کوئی محفوظ اسناد نہ ہو وہ صفر ماڈلز ڈالتا ہے، اسی لیے
خالی ڈراپ ڈاؤن کا مطلب تقریباً ہمیشہ "ابھی کچھ منسلک نہیں" ہوتا ہے، نہ کہ "کچھ
دستیاب نہیں"۔

:::note[models.dev صرف افزودگی ہے، ids کا ماخذ ہرگز نہیں]
بنڈل شدہ [models.dev](https://models.dev) کیٹلاگ اُس ماڈل کے لیے قیمت اور
کانٹیکسٹ ونڈو فراہم کرتا ہے جو پہلے سے لائیو فہرست میں موجود ہو۔ یہ کبھی کوئی
ماڈل id شامل نہیں کرتا۔ اگر کوئی متوقع ماڈل غائب ہو تو فراہم کنندہ کا اینڈ پوائنٹ
اسے واپس نہیں کر رہا۔
:::

بلٹ اِن اڈاپٹر کے ماڈل ids اہل `provider/model` ہوتے ہیں اور `|` سے الگ فال بیک
زنجیر رکھ سکتے ہیں۔ فال بیک کی صورت میں لاگت اُس ماڈل کے حساب سے لگائی جاتی ہے
جس نے واقعی باری سر کی، نہ کہ اُس کے جس کی آپ نے مانگ کی۔

:::note[بغیر اڈاپٹر والا ایجنٹ بلٹ اِن لوپ پر چلتا ہے]
ہر ورک اسپیس پانچ ایجنٹ سیڈ کرتی ہے — ایک CEO کے ساتھ `qa`، `architect`، `engineer` اور
`librarian` — بغیر اڈاپٹر اور بغیر ماڈل کے۔ ڈسپیچ
**Control Center (built-in)** پر واپس آتا ہے، اس صفحے کی **ڈیفالٹ رنرز** ترتیب پر
نہیں، جو ایک کلائنٹ طرفہ ترجیح ہے جسے ڈسپیچ راستہ کبھی نہیں پڑھتا۔ رن لاگ اُن
رنز کے لیے `cc-harness` درج کرتا ہے، چنانچہ ٹرانسکرپٹ بتاتا ہے کہ واقعی کیا چلا۔

ماڈل بھی نہ ہونے پر بلٹ اِن لوپ Anthropic سے اس کا ڈیفالٹ ماڈل مانگتا ہے۔ اس لیے
مکمل طور پر غیر سیٹ چھوڑا گیا ایجنٹ تب چلتا ہے جب آپ نے Anthropic اکاؤنٹ جوڑا ہو،
ورنہ `No credential for provider "anthropic"` کے ساتھ ناکام ہوتا ہے۔

آن بورڈنگ کا اڈاپٹر قدم مکمل کرنے پر آپ کا چنا ہوا جوڑا **ہر** اُس ایجنٹ پر بعد
ازاں لاگو ہوتا ہے جس میں ابھی تک اڈاپٹر یا ماڈل نہ ہو — CEO اور ماہرین، اُس وقت
موجود ہر ورک اسپیس میں۔ بعد میں بننے والی ورک اسپیسز پھر بھی پانچوں کو غیر سیٹ سیڈ
کرتی ہیں۔ جس بھی ایجنٹ کو آپ استعمال کرنے کا ارادہ رکھتے ہیں، اس پر اڈاپٹر اور
ماڈل واضح طور پر سیٹ کریں۔
:::

## رنر CLI انسٹال کریں

بلٹ اِن اڈاپٹر کو کسی انسٹالیشن کی ضرورت نہیں۔ Claude Code کے لیے اس کا
CLI **سرور ہوسٹ پر** اُس ٹول کے اپنے پیکیج مینیجر سے انسٹال کریں، مثلاً:

```bash
npm install -g @anthropic-ai/claude-code
```

پھر صفحے کے اوپری حصے میں **تازہ کریں** دبائیں۔ ہر دریافت شدہ قطار حل شدہ ورژن
اور پاتھ دکھاتی ہے، نیز چپس کہ آیا یہ JSON موڈ اور ماڈل انتخاب کی حمایت کرتا ہے۔

بیرونی CLI اپنے اسناد اپنی کنفیگریشن میں، سرور ہوسٹ پر رکھتا ہے۔ Control Center
انہیں منظم نہیں کرتا۔

:::caution[اڈاپٹر کے آرگومنٹس اور ماحول کے ویری ایبلز اسی ڈیوائس پر رہتے ہیں]
ہر اڈاپٹر قطار ایک **آرگومنٹس** فیلڈ اور ایک **ماحول کے ویری ایبلز** ڈائیلاگ پیش
کرتی ہے۔ وہ اقدار آپ کے ڈیوائس پر محفوظ ہوتی ہیں۔ سرور لانچ argv
اور env اپنے سیٹنگز اسٹور سے پڑھتا ہے۔ فراہم کنندہ کی کلیدیں سرور پر رکھیں (OAuth یا
ماڈل فراہم کنندگان صفحے کا کلید فیلڈ)، اُن دو فیلڈز میں نہیں۔
:::

## محدود کریں کہ ورک اسپیس کون سے فراہم کنندگان استعمال کر سکتی ہے

فراہم کنندہ گورننس فی ورک اسپیس ہے اور آخری مطابقت غالب آنے کے اصول پر لاگو ہوتی
ہے۔

1. **فراہم کنندگان اور ماڈلز** میں، کسی فراہم کنندہ قطار کا **اجازت دیں** سوئچ بند کریں

یہ فعال ورک اسپیس میں اُس فراہم کنندہ کے لیے ایک `deny` بیان لکھتا ہے اور اس کے
ماڈلز اُس ورک اسپیس کے کیٹلاگ سے نکل جاتے ہیں۔ سوئچ دوبارہ آن کرنے سے بیان ہٹ
جاتا ہے۔

## خرابیوں کا ازالہ

### کوئی رنر نہیں ملا دکھاتا ہے

- جانچیں کہ CLI **سرور ہوسٹ کے** `PATH` پر ہے، صرف آپ کے نہیں
- GUI سے لانچ ہونے والی ڈیسک ٹاپ ایپ اپنا سرور کم سے کم `PATH` کے ساتھ اسپان کرتی
  ہے؛ صرف شیل والے پاتھ میں انسٹال CLI اسے نظر نہ آئے
- انسٹال کرنے کے بعد **تازہ کریں** دبائیں

### ماڈل ڈراپ ڈاؤن خالی ہے

- اڈاپٹر بلٹ اِن والا ہے اور کوئی فراہم کنندہ منسلک نہیں — **فراہم کنندگان اور ماڈلز**
  میں ایک جوڑیں
- یا فراہم کنندہ منسلک ہے مگر اِس ورک اسپیس کا گورننس سوئچ اسے منع کرتا ہے

### ماڈل چلتا ہے مگر قیمت نامعلوم دکھتی ہے

لائیو ماڈل فہرست id رکھتی ہے؛ قیمت اور کانٹیکسٹ models.dev سے آتے ہیں۔ بالکل نئے
ماڈل، یا حسبِ ضرورت فراہم کنندہ والے ماڈل کا ابھی کوئی کیٹلاگ اندراج نہیں ہوتا۔
