ہر گائیڈ **ایسے شخص کے لیے ایک مسئلہ حل کرتی ہے جو پہلے ہی راہ و رسم رکھتا ہو**۔ ان میں
یہ فرض کیا جاتا ہے کہ آپ کے پاس Control Center انسٹال ہے اور ورک اسپیس سیٹ اپ ہے، یہ عنوان
میں ایک مقصد بیان کرتی ہیں اور مقصد پورا ہونے پر رک جاتی ہیں۔

اگر آپ ابھی پروڈکٹ سیکھ رہے ہیں تو [ٹیوٹوریلز](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/) سے آغاز کریں۔
اگر آپ سمجھنا چاہتے ہیں کہ _کوئی چیز ایسا رویہ کیوں اختیار کرتی ہے_، تو
[تصورات](/ur-PK/ہدایت-نامہ/تصورات/) پڑھیں۔
