یہ گائیڈ دکھاتی ہے کہ ٹکٹس کیسے بنائے اور منظم کیے جائیں۔

## ٹکٹ بنائیں

### UI سے

1. ورک اسپیس سائیڈ بار میں **ٹکٹس** پر کلک کریں۔
2. **نیا ٹکٹ** دبائیں۔
3. یہ بھریں:
   - **عنوان** — مختصر خلاصہ۔ یہ واحد لازمی فیلڈ ہے۔
   - **تفصیل** — markdown، فارمیٹنگ ٹول بار کے ساتھ۔
   - **اسٹیٹس** — **کرنا ہے** (ڈیفالٹ) یا **بیک لاگ**۔ شروع شدہ اور ٹرمینل
     حالتیں لائف سائیکل کے ذریعے پہنچتی ہیں، تخلیق کے وقت نہیں۔
   - **ترجیح** — کوئی نہیں، فوری، زیادہ، درمیانہ یا کم۔
   - **تفویض شدہ** — خود آپ یا ورک اسپیس کا کوئی بھی ایجنٹ۔
   - **پروجیکٹ** — اختیاری گروہ بندی۔
4. **بنائیں** دبائیں، یا تیز اندراج کے لیے پہلے **مزید بنائیں** آن کریں تاکہ
   ڈائیلاگ کھلا رہے۔

ڈائیلاگ میں کوئی فراہم کنندہ پکر نہیں ہوتا۔ ٹکٹ ورک اسپیس کے فعال ٹکٹ فراہم
کنندہ کے خلاف بنایا جاتا ہے۔

### ایجنٹ کی طرف سے

کسی اسپیس میں کسی ایجنٹ سے کہیں:

> سست کنکشنوں پر لاگ اِن ٹائم آؤٹ کے مسئلے کو ٹھیک کرنے کے لیے ایک ٹکٹ بنائیں۔

یہ `create_ticket` MCP ٹول کال کرتا ہے۔ اُس ٹول پر ترجیح **عدد** ہوتی ہے، نام
نہیں:

```
create_ticket(
  workspace_id: "...",
  title: "Fix login timeout on slow connections",
  description: "...",
  priority: 2
)
```

| قدر   | ترجیح      |
| ----- | ---------- |
| `0`   | کوئی نہیں  |
| `1`   | فوری       |
| `2`   | زیادہ      |
| `3`   | درمیانہ    |
| `4`   | کم         |

صرف `workspace_id` اور `title` لازمی ہیں؛ `description`، `priority`، `assignee`
(ایک ایجنٹ id) اور `team_id` اختیاری ہیں۔ یہ ٹول وینڈر سنک رائٹ کے طور پر درجہ
بند ہے اور چلنے سے پہلے آپ کی منظوری مانگتا ہے۔

## ٹکٹ اسٹیٹس اپ ڈیٹ کریں

ٹکٹس اس لائف سائیکل کی پیروی کرتے ہیں:

```
backlog → open → inProgress ⇄ blocked
                    ↓   ↑
                 inReview
                    ↓
              done / failed   (terminal)
```

`done`، `failed` اور `cancelled` ٹرمینل ہیں۔ `cancelled` کسی بھی غیر ٹرمینل
اسٹیٹس سے پہنچا جا سکتا ہے۔ `done` اور `failed` `inProgress` یا `inReview` سے
پہنچائے جا سکتے ہیں؛ `open` براہِ راست `blocked` میں بھی جا سکتا ہے۔ UI اسٹیٹس
پکر `failed` کے سوا ہر اسٹیٹس کی فہرست دیتا ہے — ایجنٹس اُسے `fail_ticket` سے
نشان زد کرتے ہیں۔

اسے تبدیل کرنے کے لیے ان میں سے کوئی بھی استعمال کریں:

- ٹکٹ کے پراپرٹیز ریل میں **اسٹیٹس** قطار،
- فہرست میں ٹکٹ کے رائٹ کلک مینو پر **اسٹیٹس** ذیلی مینو،
- کئی ٹکٹس منتخب کرنے کے بعد فلوٹنگ بار پر **اسٹیٹس** چپ۔

:::note[لائف سائیکل گراف ایجنٹس کو باندھتا ہے، آپ کو نہیں]
UI سے کی گئی ہر اسٹیٹس تبدیلی زبردستی نافذ ہوتی ہے اور گراف کو مکمل طور پر نظر
انداز کر دیتی ہے — آپ ٹکٹ کو پکر کی فہرست میں موجود کسی بھی اسٹیٹس پر منتقل کر
سکتے ہیں، بشمول کسی `done`، `failed` یا `cancelled` والے ٹکٹ کو دوبارہ کھولنا۔
پکر `failed` کو بطور ہدف پیش نہیں کرتا۔ اوپر کا خاکہ ایجنٹس اور آٹومیشن پر لاگو
ہوتا ہے: MCP ٹول یا ری کنسائلر کی کوشش کردہ کوئی غیر قانونی منتقلی لاگ ہو کر
نظر انداز ہو جاتی ہے، لاگو نہیں ہوتی۔
:::

اسٹیٹس تبدیلیاں ڈومین ایونٹس (`TicketStatusChanged`، `TicketCompleted` اور دیگر)
خارج کرتی ہیں جو پائپ لائنز ٹرگر کر سکتے ہیں۔ دیکھیں
[پائپ لائن ٹریگرز سیٹ کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/پائپ-لائن-ٹریگرز/)۔

## ٹکٹ تفویض کریں

1. ٹکٹ کھولیں۔
2. پراپرٹیز ریل میں **تفویض شدہ** سیٹ کریں — خود آپ، ورک اسپیس کا کوئی دوسرا
   ممبر، یا کوئی ایجنٹ۔

:::caution[تفویض کرنے سے کوئی کام شروع نہیں ہوتا]
تفویض صرف ملکیت درج کرتی ہے اور بس۔ یہ کوئی اسپیس نہیں بناتی، کوئی اسٹیٹس
نہیں بدلتی اور کسی ایجنٹ کو ڈسپیچ نہیں کرتی — `TicketAssigned` محض ایک آڈٹ
سگنل ہے جس کے پیچھے کوئی ڈسپیچر نہیں۔ کسی ایجنٹ سے کام کرانے کے لیے اسے کسی
اسپیس میں پیغام بھیجیں ([ایجنٹ سے چیٹ کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/ایجنٹ-سے-چیٹ/) دیکھیں)۔

ایک استثنا: `TicketAssigned` ایک ایونٹ ٹائپ ہے جس سے آپ پائپ لائن ٹریگر وائر کر
سکتے ہیں، اس لیے آپ کا اپنا ٹیمپلیٹ کسی تفویض پر ردِ عمل دے سکتا ہے۔
:::

## لیبلز شامل کریں

لیبلز ٹکٹ فہرست سے بلک میں لگائے جاتے ہیں، کسی ایک ٹکٹ سے نہیں — پراپرٹیز ریل
میں لیبل کا کوئی کنٹرول نہیں۔

1. ٹکٹ فہرست میں کسی قطار پر ہوور کریں اور اس کا چیک باکس ٹک کریں۔ جتنے چاہیں ٹک
   کریں؛ کچھ منتخب ہونے پر ایک فلوٹنگ بار ظاہر ہوتی ہے۔
2. اُس بار میں **لیبلز** چپ کھولیں۔
3. کوئی لیبل چنیں۔ یہ ہر اُس منتخب ٹکٹ میں شامل ہو جاتا ہے جس میں وہ نہیں ہے؛
   موجودہ لیبلز کبھی مٹائے نہیں جاتے۔ **لیبلز صاف کریں** اُن سب کو ہٹا دیتا ہے۔
   پکر ورک اسپیس میں کسی ٹکٹ پر پہلے سے موجود لیبلز کی فہرست دیتا ہے۔ ایجنٹس
   `update_ticket` یا `tickets.patch` کے ذریعے نیا نام شامل کر سکتے ہیں۔

## ٹکٹس لنک کریں

تعلقات ٹکٹ کے پراپرٹیز ریل میں موجود **تعلقات** کارڈ پر، یا فہرست کے رائٹ کلک
مینو میں **جوڑیں** کے پیچھے رہتے ہیں۔

1. ٹکٹ کھولیں اور **تعلقات** کارڈ تلاش کریں۔
2. اس کا ایڈ کنٹرول دبائیں اور تعلق منتخب کریں:

| تعلق                | مطلب                                  |
| ------------------- | ------------------------------------- |
| **ذیلی ایشو از…**   | اس ٹکٹ کا والد دوسرا ٹکٹ ہے           |
| **والد از…**        | دوسرا ٹکٹ اس ٹکٹ کا چائلڈ ہے          |
| **بلاک از…**        | یہ ٹکٹ دوسرے سے بلاک ہے               |
| **بلاک کر رہا ہے…** | یہ ٹکٹ دوسرے کو بلاک کرتا ہے          |
| **متعلقہ از…**      | دوطرفہ، کوئی سمت مضمر نہیں            |
| **نقل از…**         | یہ ٹکٹ دوسرے کی نقل ہے                |

3. ہدف ٹکٹ منتخب کریں۔

**اس کی نقل** کارڈ میں ظاہر ہوتا ہے مگر پکر میں نہیں — یہ **نقل از** کا معکوس ہے
اور دوسرے ٹکٹ سے سیٹ ہوتا ہے۔ فہرست میں درج ہر تعلق پر کلک کر کے لنک شدہ ٹکٹ
کھولا جا سکتا ہے اور ہوور پر ہٹایا جا سکتا ہے۔

والد اور ذیلی ایشو کے تعلقات لنک قطاروں کے بجائے خود ٹکٹ پر محفوظ ہوتے ہیں، اس
لیے کوئی والد حذف کرنے سے اس کے چائلڈز بھی کیسکیڈ ہو جاتے ہیں (نیچے دیکھیں)،
جبکہ بلاک کرنے اور متعلقہ لنکس ایسا نہیں کرتے۔

## تعاون کنندگان شامل کریں

تعاون کنندگان ٹکٹ پر ایک روسٹر ہیں — کون شامل ہے، اور کس حیثیت میں۔

1. ٹکٹ کھولیں۔
2. **تعاون کنندہ شامل کریں** کارڈ پر پرسن پلس کنٹرول دبائیں۔
3. کوئی ایجنٹ منتخب کریں۔

تین کردار ہیں **assignee**، **collaborator** (ڈیفالٹ) اور **reviewer**۔ UI پکر
صرف ورک اسپیس ایجنٹس کی فہرست دیتا ہے اور ہمیشہ ڈیفالٹ کردار لکھتا ہے؛ انسان
قطاروں کے طور پر ظاہر ہو سکتے ہیں مگر اُس مینو میں پیش نہیں کیے جاتے۔ MCP ٹول
`add_ticket_collaborator` ایک `role` قبول کرتا ہے۔

تعاون کنندہ شامل کرنا ایک قطار لکھتا ہے اور کوئی ڈومین ایونٹ شائع نہیں کرتا؛
یہ اسپیس تک کوئی رسائی نہیں دیتا۔ کسی ایجنٹ کو گفتگو میں لانے کے لیے اسے اسپیس
ہیڈر سے بطور شریک شامل کریں — [اسپیسز](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/اسپیسز/) دیکھیں۔

## ٹکٹ حذف کریں

پراپرٹیز ریل کے نیچے **ٹکٹ حذف کریں**، رائٹ کلک مینو، یا کئی ٹکٹس منتخب کرنے
کے بعد فلوٹنگ بار کے ڈیلیٹ ایکشن کا استعمال کریں۔

:::caution[حذف کرنا صرف مقامی ہے]
کسی بیرونی ٹریکر سے آیا ہوا ٹکٹ وہاں حذف نہیں ہوتا — کوئی فراہم کنندہ اس کی
حمایت نہیں کرتا — اس لیے یہ اگلے سنک پر دوبارہ ظاہر ہو سکتا ہے۔ حذف کرنا
کیسکیڈ بھی کرتا ہے: ٹکٹ کے تعاون کنندگان اور کوئی بھی ذیلی ٹکٹس اس کے ساتھ چلے
جاتے ہیں۔
:::
