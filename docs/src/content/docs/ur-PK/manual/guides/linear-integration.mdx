سرور پر اپنے صارف کے تحت ایک Linear API کلید پیسٹ کریں، بالکل اُسی طرح جیسے آپ کوئی
forge جوڑتے ہیں۔ ٹکٹس، پروجیکٹس، لنکس، معاونین، تفویض اور اسائنمنٹ سب Control Center کے
اپنے ڈیٹا بیس کے خلاف کام کرتے ہیں اور کسی بیرونی سروس کی ضرورت نہیں —
دیکھیں [ٹکٹس بنائیں اور منظم کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/ٹکٹس-منظم-کریں/)۔

## اپنی Linear کلید محفوظ کریں

**ٹکٹنگ API کلید** **ترتیبات → ورک اسپیس → عام** پر، **ٹکٹنگ** کارڈ میں رہتی ہے۔ یہ
کلید سرور پر آپ کے صارف id کے تحت محفوظ کرتی ہے۔ بغیر کسی نگرانی کے کام کے لیے سرور کی
اپنی کلید `LINEAR_API_KEY` یا **فراہم کنندہ ایپس** کارڈ سے آتی ہے۔ ایجنٹ کے سینڈ باکس
میں کوئی ٹکٹنگ کلید نہیں رکھی جاتی: ایجنٹ Control Center کے اپنے ٹولز کے ذریعے ٹکٹ لکھتے
ہیں، جو پہلے **بیرونی ٹریکر پر لکھیں** قاعدے سے پوچھتے ہیں۔

## نئے ٹکٹس پر Linear کی مہر لگائیں

**ٹکٹنگ فراہم کنندہ** (آن بورڈنگ کا پہلا قدم، اور
`/workspaces/<workspaceId>/api-keys`) `local` اور `linear` پیش کرتا ہے۔ `linear` چننے پر
اُس کے بعد آپ جو ٹکٹس بناتے ہیں اُن پر `provider: linear` کی مہر لگ جاتی ہے۔
