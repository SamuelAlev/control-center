یہ گائیڈ دکھاتی ہے کہ اطلاعات کیسے کنفیگر کی جائیں اور ہر ترتیب واقعی کیا
کنٹرول کرتی ہے۔

اطلاعات دو سطحوں پر پہنچتی ہیں۔ **اطلاعات کا مرکز** — ٹائٹل بار میں موجود گھنٹی —
سرور پر فی ورک اسپیس موجود ایک پائیدار فیڈ پڑھتا ہے۔ **OS ٹوسٹس** ایک الگ اور صرف
ڈیسک ٹاپ کا راستہ ہیں جسے سرور سے بھیجے گئے لائیو فریم کھلاتے ہیں۔

:::note[ویب بلڈ کوئی OS اطلاع نہیں دکھاتا]
ٹوسٹ پائپ لائن صرف ڈیسک ٹاپ بوٹ اسٹرپ بناتا ہے۔ `app.usectrl.dev` پر نہ کوئی OS
ٹوسٹ ہے، نہ کوئی اطلاع کی آواز اور نہ کوئی محیطی بینر — گھنٹی اور اس کی تاریخچہ
پھر بھی کام کرتے ہیں، کیونکہ وہ سرور کی فیڈ پڑھتے ہیں۔ فون کلائنٹ میں اطلاعات کی
کوئی سطح ہی نہیں۔
:::

## اقسام آن یا آف کریں

1. **ترتیبات → آپ → اطلاعات** پر جائیں
2. **اطلاعات فعال کریں** کو آن رہنے دیں
3. اپنی مطلوبہ اقسام ٹوگل کریں۔ بالکل سولہ اقسام ہیں:

| قسم                       | کب فعال ہوتی ہے                                                              |
| ------------------------- | ---------------------------------------------------------------------------- |
| ایجنٹ ختم ہوا             | آپ کے شروع کیے گئے رن میں کسی ایجنٹ نے جواب دیا، یا رن ناکام ہو گیا           |
| PR شائع ہوا               | کسی ایجنٹ نے ایک PR شائع کیا                                                  |
| PR مرج ہو گیا             | کوئی PR مرج ہو گیا                                                            |
| نئے پیغامات               | کسی نے کسی اسپیس میں آپ کا ذکر کیا                                             |
| pull request میں ذکر      | GitHub کی اطلاعاتی پولنگ نے دیکھا کہ آپ کا کسی PR میں ذکر ہوا                   |
| ریویو کی درخواست          | کسی غیر ڈرافٹ PR پر واقعی آپ کا ریویو طلب کیا گیا                             |
| ریویو پرانا               | آپ کے پہلے ریویو کردہ pull request پر نئے کمٹ آ گئے                            |
| مرج کے لیے تیار           | آپ کا لکھا ہوا pull request مرج کے قابل ہو گیا، یا ہونا بند ہو گیا            |
| ریویو فیصلے               | کسی ریویوور نے منظوری دی، تبدیلیاں طلب کیں، یا کوئی منظوری رد ہو گئی            |
| چیکس                      | آپ کے لکھے pull request پر CI ناکام ہوا، یا بحال ہو گیا                       |
| ریویو تھریڈز              | کسی نے ایسے تھریڈ میں جواب دیا یا اسے حل کیا جس میں آپ شامل ہیں                 |
| ٹکٹ تفویض ہوا             | کوئی ٹکٹ تفویض ہوا                                                            |
| ٹکٹ اسٹیٹس بدلا           | کسی ٹکٹ کا اسٹیٹس بدلا                                                        |
| میٹنگ جلد شروع ہو رہی ہے  | کوئی کیلنڈر میٹنگ آپ کی لیڈ ونڈو کے اندر ہے                                   |
| کیلنڈر منقطع ہو گیا       | کسی منسلک کیلنڈر کا OAuth ٹوکن میعاد ختم ہو گیا                               |
| انکلوژر اپ ڈیٹس           | کوئی انکلوژر تصرف میں لیا گیا، واپس لیا گیا یا ناکام ہوا                       |

اس فہرست سے باہر کی کسی چیز کی اطلاع نہیں دی جا سکتی اور نہ اسے فلٹر کیا جا سکتا —
کوئی “ہر چیز دیگر” قسم موجود نہیں۔

یہ ترجیحات آپ کے صارف کے ساتھ ہر ڈیوائس پر جاتی ہیں، چنانچہ فون اور لیپ ٹاپ ہم قدم
رہتے ہیں۔ والیوم جان بوجھ کر استثنا ہے اور ہر ڈیوائس پر الگ رہتا ہے۔

## Quiet hours سیٹ کریں

1. اُسی صفحے پر **Quiet hours** آن کریں
2. شروع اور اختتام کا وقت `HH:MM` میں لکھیں (ڈیفالٹ ونڈو 22:00–08:00 ہے)

Quiet hours کے دوران غیر فوری اطلاعات نظر انداز کر دی جاتی ہیں — نہ قطار میں لگائی
جاتی ہیں اور نہ بعد میں دوبارہ چلائی جاتی ہیں۔

دو اقسام **فوری** ہیں اور ہمیشہ پہنچتی ہیں، Quiet hours _اور_ فوکس موڈ دونوں کو نظر
انداز کرتے ہوئے: **میٹنگ جلد شروع ہو رہی ہے** اور **PR شائع ہوا**۔ میٹنگ کا وہ الرٹ
جو آپ کو صرف بعد میں نظر آئے بے کار ہے، اور وجہ بھی یہی ہے۔

## آواز منتخب کریں

1. **اطلاع کی آواز** تک اسکرول کریں
2. گیارہ شامل آوازوں میں سے کوئی ایک منتخب کریں، یا **کوئی نہیں**
3. اسے سننے کے لیے **ٹیسٹ** بٹن دبائیں اور سلائیڈر سے والیوم مقرر کریں

آواز خود ایپ بجاتی ہے؛ OS اطلاع خاموشی سے دی جاتی ہے تاکہ آپ اسے کبھی دو بار نہ
سنیں۔

## میٹنگ کی لیڈ ٹائم سیٹ کریں

1. **الرٹ لیڈ ٹائم** تک اسکرول کریں
2. **5**، **10**، **15** یا **30** منٹ منتخب کریں

یہ بتاتا ہے کہ کسی کیلنڈر ایونٹ سے کتنا پہلے **میٹنگ جلد شروع ہو رہی ہے** والی اطلاع
آتی ہے۔ ڈیفالٹ 5 منٹ ہے۔

## جانیں کہ کوئی اطلاع کب روک دی جاتی ہے

کوئی اطلاع خاموشی سے نظر انداز کر دی جاتی ہے جب ان میں سے کوئی ایک بھی درست ہو:

- اطلاعات مجموعی طور پر آف ہوں، یا اس کی قسم آف ہو
- آپ پہلے ہی اُس راستے پر ہوں جہاں وہ آپ کو لے جاتی — اور پیغام کی صورت میں، پہلے
  ہی اُس اسپیس میں ہوں
- فوکس موڈ فعال ہو اور قسم فوری نہ ہو
- Quiet hours فعال ہوں اور قسم فوری نہ ہو

یہ جانچیں OS ٹوسٹس پر لاگو ہوتی ہیں۔ پائیدار گھنٹی پھر بھی ایونٹ ریکارڈ کرتی ہے۔

مزید دو روکیں اور بھی اوپر، یعنی سرور جو کچھ بھیجتا ہی ہے اُس میں موجود ہیں:

- کسی دوسرے **انسان** کا وہ پیغام جس میں آپ کا ذکر نہ ہو، کبھی اطلاع نہیں بنتا
- مشترکہ اسپیس میں ایجنٹ کا جواب ہر رکن کو نہیں، صرف اُسے پنگ کرتا ہے جس نے
  وہ رن شروع کیا
- ایجنٹ سے ایجنٹ والی اسپیسز سائیڈ بار میں خاموش کر دی جاتی ہیں، چنانچہ وہ انسان
  کے نہ پڑھے گئے بیج کو کبھی نہیں بڑھاتیں

کسی اسپیس کے اندر کوئی خاموش گوشہ نہیں: ہر گفتگو یکساں اطلاع دیتی ہے، تھریڈز سمیت۔
پڑھے جانے کی حالت اسپیس کے دائرے میں ہوتی ہے، چنانچہ نہ پڑھا ہوا اسپیس کی تمام
گفتگوؤں میں جمع ہوتا ہے، بجائے اس کے کہ فی گفتگو الگ رکھا جائے۔

## اطلاعات کا مرکز پڑھیں اور صاف کریں

1. ٹائٹل بار میں گھنٹی پر کلک کریں

پاپ اوور حالیہ سرگرمی دکھاتا ہے اور ہر اندراج کو ڈیپ لنک کے ذریعے اُس چیز سے جوڑتا
ہے جس کے بارے میں وہ ہے۔ اسے کھولنا ہر چیز کو پڑھا ہوا نشان زد **نہیں** کرتا — ہیڈر
میں **سب پڑھا ہوا نشان زد کریں** استعمال کریں، یا کسی ایک قطار کو نشان زد کریں۔
پڑھے جانے کی حالت آپ کے صارف کے ساتھ ہر ڈیوائس پر جاتی ہے۔

:::note[سب صاف کریں ایک واٹر مارک ہے، حذف نہیں]
**سب صاف کریں** فی صارف ایک واٹر مارک لگاتا ہے جو اُس سے پرانی ہر چیز چھپا دیتا ہے؛
قطاریں باقی رہتی ہیں۔ الگ بات یہ ہے کہ ہر ورک اسپیس صرف اپنی سب سے تازہ **200**
فیڈ قطاریں رکھتی ہے، جو نئی آتے ہی چھانٹ دی جاتی ہیں، جبکہ گھنٹی تازہ ترین **50**
کی سبسکرائب کرتی ہے اور پاپ اوور اُن میں سے زیادہ سے زیادہ **15** فہرست کرتا ہے۔ اس
سے پرانی تاریخچہ پڑھے جانے کی حالت سے قطع نظر ختم ہو چکی ہوتی ہے۔
:::

## خرابیوں کا ازالہ

### macOS پر کوئی OS اطلاع نہیں

ایپ کے آغاز پر اجازت مقامی طور پر طلب کی جاتی ہے۔ اگر آپ نے انکار کیا تھا تو سسٹم
سیٹنگز → اطلاعات میں Control Center کو دوبارہ فعال کریں؛ اسے دوبارہ چلانے کے لیے ایپ
کے اندر کوئی پرامپٹ نہیں۔

### ویب بلڈ پر کچھ نہیں آتا

متوقع ہے — ویب بلڈ میں OS اطلاعات کی پائپ لائن نہیں۔ گھنٹی استعمال کریں۔

### گھنٹی کے بیج پر صفر دکھتا ہے مگر صاف طور پر نئی سرگرمی موجود ہے

جوڑنے کے بعد پڑھے جانے کا نشان والا اسٹریم حل ہونے تک، اندراجات پڑھے ہوئے دکھائے
جاتے ہیں تاکہ ایسا بیج بننے سے بچا جائے جو جھلملائے اور پھر خالی ہو جائے۔ نشان لوڈ
ہوتے ہی یہ ٹھیک ہو جاتا ہے۔

### ایجنٹ کا رن مکمل ہوا مگر مجھے کوئی پنگ نہیں آیا

دیکھیں کہ آپ پہلے ہی اُس اسپیس پر نہیں تھے جہاں یہ ہوا — ایک فعال راستہ اپنا OS ٹوسٹ
خود روک دیتا ہے۔ مشترکہ اسپیس میں کسی اور کا شروع کیا ہوا رن اُسی کو پنگ کرتا ہے، آپ
کو نہیں۔ جو باری بغیر جواب اور بغیر خرابی کے ختم ہو، وہ کچھ نہیں بھیجتی۔
