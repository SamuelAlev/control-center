شارٹ کٹس ایک ہی `const` رجسٹری سے آتے ہیں، جو `lib/core/constants/keybindings.dart` میں `KeybindingRegistry` ہے۔ اس میں **49 بائنڈنگز** ہیں۔ ترتیبات → آپ → کی بائنڈنگز اُس رجسٹری کو ایک **صرف پڑھنے کے قابل حوالے** کے طور پر دکھاتا ہے: نہ کوئی دوبارہ بائنڈ کرنے والا UI ہے اور نہ صارف کی کی بائنڈنگز کی کوئی فائل۔

نیچے `Cmd` بنیادی کمانڈ موڈیفائر ہے — macOS پر ⌘، اور Windows اور Linux پر Ctrl۔ کوئی بائنڈنگ صرف اُس وقت فعال ہوتی ہے جب موجودہ اسکرین پر اُس کے کمانڈ کا کوئی رجسٹرڈ ہینڈلر ہو اور اُس کی `when` شرط پوری ہو؛ `!textInputFocus` کا مطلب ہے کہ کلید اُس کے بجائے فوکس میں موجود ٹیکسٹ فیلڈ کو دے دی جاتی ہے۔

اعداد کی کلیدوں سے نیویگیشن کا کوئی شارٹ کٹ نہیں۔ ان باکس، ٹکٹس، pull requests اور باقی سب سائیڈ بار یا ⌘K سے پہنچتے ہیں۔ آبزرویبلٹی کا بھی کوئی شارٹ کٹ نہیں۔

## عالمی (19)

دائرہ کار `global`، اس لیے یہ شیل میں ہر جگہ فعال رہتے ہیں۔

## pull requests کی فہرست (3)

دائرہ کار `/pull-requests`۔ ان سب کے لیے `route == '/pull-requests'` اور یہ کہ کوئی ٹیکسٹ فیلڈ فوکس میں نہ ہو، لازم ہے، اس لیے جب فہرست کے اوپر PR تفصیل کا روٹ کھلا ہو تو یہ فعال نہیں ہوتے۔

| شارٹ کٹ | عمل                |
| -------- | ------------------ |
| `R`      | تازہ کریں          |
| `Enter`  | PR کھولیں          |
| `F`      | فلٹر مینو کھولیں   |

`Enter` (`pr.list-open`) رجسٹری میں درج ہے اور کی بائنڈنگز کے حوالے میں نظر آتا ہے، مگر **فہرست کی اسکرین اس کے لیے کوئی ہینڈلر رجسٹر نہیں کرتی**، اس لیے یہ فی الحال فعال نہیں ہوتا۔ `F` فلٹر مینو (`pr.list-open-filter`) کھولتا ہے، تلاش نہیں۔

## pull request کی تفصیل (2)

دائرہ کار `/pull-requests/`۔ تازہ کرنے کے لیے یہ لازم ہے کہ کوئی ٹیکسٹ فیلڈ فوکس میں نہ ہو۔ ٹیب بند کرنے کا کوئی ٹیکسٹ اِن پٹ گارڈ نہیں (⌘ کے ساتھ ملایا گیا کی اسٹروک کبھی سادہ متن نہیں ہوتا) اور اُس کے لیے ایک روٹ ریجیکس ہے، اس لیے یہ فہرست پر فعال نہیں ہوتا۔

| شارٹ کٹ        | عمل             | شرط                                  |
| -------------- | --------------- | ------------------------------------ |
| `R`            | تازہ کریں       | کسی فیلڈ میں ٹائپ نہ کر رہے ہوں     |
| `Cmd/Ctrl + W` | ٹیب بند کریں    | `/pull-requests/<…>` لوکیشن پر       |

ٹیب کی تبدیلی (`1`/`2`/`3`)، فائل کا دیکھا گیا/سکیڑنا (`V`/`C`)، فائل فہرست (`T`) اور diff میں تلاش (`Cmd/Ctrl + F`) diff ویوور کے اپنے ہینڈلر کے پاس ہیں — دیکھیں [رجسٹری سے باہر diff ویوور کی کلیدیں](#رجسٹری-سے-باہر-diff-ویوور-کی-کلیدیں)۔

## GitHub صارف اور ٹیم پروفائلز (3)

دائرہ کار `/users/`۔ `when` شرط `/users/<login>` **یا** `/teams/<organization>/<slug>` پر لاگو ایک ریجیکس ہے، اور اُس کے ساتھ یہ بھی کہ کوئی ٹیکسٹ فیلڈ فوکس میں نہ ہو۔

| شارٹ کٹ        | عمل          |
| -------------- | ------------ |
| `R`            | تازہ کریں    |
| `/`            | تلاش پر فوکس |
| `Cmd/Ctrl + F` | تلاش پر فوکس |

## اسپیسز (9)

دائرہ کار `/spaces`۔ `when` شرائط ایک ریجیکس استعمال کرتی ہیں، اس لیے یہ اسپیس فہرست (`/spaces`) اور منتخب اسپیس (`/spaces/<id>`) دونوں پر فعال ہوتی ہیں۔

| شارٹ کٹ                | عمل                    | شرط                     |
| ---------------------- | ---------------------- | ----------------------- |
| `Enter`                | پیغام بھیجیں           | —                       |
| `Cmd/Ctrl + N`         | نئی اسپیس              | `/spaces` روٹ پر        |
| `J`                    | اگلی اسپیس             | کسی فیلڈ میں ٹائپ نہ کر رہے ہوں |
| `K`                    | پچھلی اسپیس            | کسی فیلڈ میں ٹائپ نہ کر رہے ہوں |
| `Cmd/Ctrl + Shift + D` | دبا کر بولنے کی ڈکٹیشن | —                       |
| `Cmd/Ctrl + T`         | ایڈیٹر ٹیب کھولیں       | `/spaces` روٹ پر        |
| `Cmd/Ctrl + W`         | ایڈیٹر ٹیب بند کریں     | `/spaces` روٹ پر        |
| `Cmd/Ctrl + B`         | ایڈیٹر سائیڈ بار ٹوگل کریں | `/spaces` روٹ پر     |
| `Cmd/Ctrl + P`         | فائل پر جائیں              | `/spaces` روٹ پر     |

«فائل پر جائیں» گفتگو کی فائلوں پر ایک چناؤ کار کھولتا ہے۔ کچھ ٹائپ نہ کیا ہو تو یہ وہ فائلیں دکھاتا ہے جو آپ نے حال ہی میں کھولیں؛ ٹائپ کرنے پر گفتگو کے ورک ٹریز کی ہر فائل میں تلاش ہوتی ہے۔ `Enter` منتخب فائل کو نئے ٹیب میں کھولتا ہے، `Cmd/Ctrl + Enter` یا قطار پر اسپلٹ بٹن اسے دائیں جانب ایک پین میں کھولتا ہے، اور حالیہ قطار پر `×` اسے فہرست سے ہٹا دیتا ہے۔

انٹر سے بھیجنے کا اختیار کمپوزر کے ٹیکسٹ فیلڈ کے پاس ہے؛ دبا کر بولنے کا اختیار کمپوزر کے مائیک بٹن کے پاس ہے (اس کا اپنا ہارڈ ویئر کی بورڈ ہینڈلر)۔ دونوں ترتیبات کے حوالے کے لیے رجسٹری میں درج ہیں۔

## رجسٹری سے باہر diff ویوور کی کلیدیں

PR کا diff ویوور یہ خود سنبھالتا ہے (`PrDiffKeyboardHandler`)۔ تلاش/دیکھا گیا/سکیڑنا صرف ترتیبات کے حوالے کے لیے رجسٹری کے کمنٹس میں درج ہیں — کوئی ڈسپیچر ہینڈلر رجسٹر نہیں ہے، اس لیے ڈسپیچر انہیں diff ویو کے حوالے کر دیتا ہے۔ یہ کی بائنڈنگز کے حوالے میں اپنی الگ قطاروں کے طور پر نظر نہیں آتے۔

| شارٹ کٹ        | عمل                                                    |
| --------------- | ------------------------------------------------------ |
| `Cmd/Ctrl + F`  | diff میں تلاش                                          |
| `J` / `K`       | اگلی / پچھلی فائل                                      |
| `V`             | فوکس میں موجود فائل پر دیکھا گیا ٹوگل کریں              |
| `C`             | فوکس میں موجود فائل پر سکیڑنا ٹوگل کریں                 |
| `T`             | فائل فہرست دکھائیں                                      |
| `Enter`         | اگلا تلاش کا مماثل (صرف اُس وقت جب diff میں تلاش کھلی ہو) |
| `Shift + Enter` | پچھلا تلاش کا مماثل                                    |
| `Escape`        | diff میں تلاش بند کریں، یا diff کا منتخب شدہ متن صاف کریں |
| `Cmd/Ctrl + C`  | diff کا منتخب حصہ کاپی کریں                            |

## براؤزر کی محفوظ کردہ ترکیبیں

ویب بلڈ میں براؤزر کچھ ایکسیلیریٹرز کو صفحے تک پہنچنے سے پہلے ہی لے لیتا ہے، اس لیے متعلقہ بائنڈنگز وہاں کبھی فعال نہیں ہو سکتیں۔ ڈیسک ٹاپ پر یہ معمول کے مطابق کام کرتی ہیں۔ بنیادی کمانڈ موڈیفائر کے ساتھ ملانے پر یہ محفوظ ہو جاتی ہیں: `T`، `W`، `N` اور اعداد `1`–`9`۔

اس میں `Cmd/Ctrl + Alt + 1`–`9` سے ورک اسپیس کی تبدیلی، `Cmd/Ctrl + N` (نئی اسپیس، نیا ورک اسپیس، نیا ایجنٹ، ریپوزٹری شامل کریں) اور اسپیسز اور PR تفصیل میں `Cmd/Ctrl + T` / `Cmd/Ctrl + W` شامل ہیں۔
