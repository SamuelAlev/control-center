حوالہ صفحات **وہاں کیا موجود ہے** کو مکمل طور پر اور بغیر کسی تبصرے کے بیان کرتے ہیں۔ جب
آپ کو پہلے سے معلوم ہو کہ آپ کو کیا چاہیے تو انہیں کسی چیز کو دیکھنے کے لیے استعمال کریں:
کسی ٹول کا عین نام، کسی قدم کی قسم، کسی اسٹیٹس کی منتقلی، کوئی روٹ، کوئی شارٹ کٹ۔

یہ شروع سے آخر تک پڑھنے کے لیے نہیں لکھے گئے۔ اس کے لیے
[تصورات](/ur-PK/ہدایت-نامہ/تصورات/) دیکھیں؛ اور کوئی کام سرانجام دینے کے لیے
[طریقہ کار گائیڈز](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/) دیکھیں۔
