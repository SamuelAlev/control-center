## آپ کیا بنائیں گے

اس ٹیوٹوریل کے اختتام تک آپ کے پاس یہ ہوگا:

- آپ کے پروجیکٹ کے نام پر ایک ورک اسپیس
- اس میں رجسٹر شدہ ایک Git ریپوزٹری
- پانچ سیڈ شدہ ایجنٹ، جن میں سے ایک ایسا کنفیگر کیا ہوا کہ اسے چلایا جا سکے
- ایک دوسرا، خالی ورک اسپیس جو تنہائی کی حد ثابت کرتا ہے

آن بورڈنگ پہلے ہی آپ کے لیے ایک ورک اسپیس بنا چکی ہے۔ یہ ٹیوٹوریل جان بوجھ کر ایک بالکل نیا ورک اسپیس بناتا ہے، تاکہ آپ اس عمل کا ہر حصہ دیکھ سکیں۔

شروع کرنے سے پہلے کوئی ایسا Git چیک آؤٹ چنیں جو اِن تینوں شرائط پر پورا اترے — رجسٹریشن کا مرحلہ اس کے علاوہ کچھ قبول نہیں کرتا:

- وہ کسی git ورک ٹری کے اندر ہو
- اس کا ایک `origin` ریموٹ موجود ہو
- اور وہ ریموٹ github.com، gitlab.com یا bitbucket.org کی طرف اشارہ کرتا ہو

## مرحلہ 1: ورک اسپیس بنائیں

1. ٹائٹل بار میں ورک اسپیس چپ پر کلک کریں
2. **ورک اسپیس شامل کریں…** چنیں
3. ایسا نام درج کریں جو پروجیکٹ کی شناخت کرتا ہو، مثلاً "api-service" یا "frontend-v2"
4. اختیاری طور پر کوئی لوگو چنیں
5. **ورک اسپیس شامل کریں** پر کلک کریں

Control Center نئے ورک اسپیس پر منتقل ہو جاتا ہے اور اس کے ان باکس (`/workspaces/<id>/inbox`) پر پہنچتا ہے۔

اس کے پیچھے سرور ایک `WorkspaceCreated` ایونٹ شائع کرتا ہے اور ورک اسپیس میں یہ چیزیں سیڈ کرتا ہے:

- ایک **CEO ایجنٹ**، جس کی شخصیت ہم آہنگی اور تفویض ہے
- چار ماہرین — `qa`، `architect`، `engineer` اور `librarian` — ہر ایک کی اپنی ہدایات اور مہارتیں
- بلٹ اِن پائپ لائن ٹیمپلیٹس اور اُن کی ٹریگر قطاریں

آپ کا بنایا ہوا ہر ورک اسپیس یہ سب کچھ پاتا ہے، صرف پہلا نہیں۔

تصدیق: **ترتیبات → ورک اسپیس → ایجنٹس** کھولیں۔ روسٹر میں پانچ ایجنٹ ہیں، اور ہر ایک کے گرد اسٹیٹس کا ایک کھوکھلا حلقہ ہے۔

## مرحلہ 2: ریپوزٹری رجسٹر کریں

1. **ترتیبات → ورک اسپیس → ریپوزٹریز** پر جائیں
2. **ریپوزٹری شامل کریں** پر کلک کریں
3. اپنے چیک آؤٹ تک براؤز کریں۔ یہ ڈائیلاگ اُن فولڈرز میں چلتا ہے جو `cc_server` چلا رہی مشین پر ہیں — آپ کے کلائنٹ پر نہیں — اور اُنہی روٹس کے اندر رہتا ہے جو وہ سرور ظاہر کرتا ہے (ڈیفالٹ میں اس کے صارف کی ہوم ڈائریکٹری)۔ کسی git چیک آؤٹ کو ایک الگ فولڈر آئیکن اور ایک چیک باکس ملتا ہے؛ عام فولڈر کو کچھ نہیں، چنانچہ صرف چیک آؤٹ ہی منتخب کیے جا سکتے ہیں۔
4. ایک یا زیادہ چیک آؤٹ پر نشان لگائیں اور بیچ رجسٹر کر دیں۔ نیویگیٹ کرتے ہوئے بھی انتخاب برقرار رہتے ہیں، اس لیے آپ ایک ہی پاس میں کئی جمع کر سکتے ہیں اور ایک غلط انتخاب باقی کو کبھی نہیں گراتا۔

Control Center ہر چیک آؤٹ کا `origin` ریموٹ پڑھتا ہے، مالک اور ریپو حل کرتا ہے اور ریپو کی قطار **اِسی ورک اسپیس کے اندر** بناتا ہے۔ اسے لنک کرنے کا کوئی دوسرا مرحلہ نہیں: رجسٹریشن ہی اس کا دائرہ طے کرتی ہے۔

بعد میں کسی اور ورک اسپیس میں وہی چیک آؤٹ رجسٹر کرنے سے ایک دوسری، آزاد ریپو قطار اپنے الگ id کے ساتھ بنتی ہے۔ ورک اسپیسز کے پار کوئی چیک آؤٹ اپنے فائل سسٹم پاتھ سے پہچانا جاتا ہے، id سے کبھی نہیں۔

تصدیق: ریپو فہرست میں اپنے `owner/repo` اور موجودہ برانچ کے ساتھ ظاہر ہوتا ہے۔

## مرحلہ 3: ایک ایجنٹ کو چلانے کے قابل بنائیں

اِس ورک اسپیس نے جو پانچ ایجنٹ ابھی سیڈ کیے ہیں، اُن کا نہ کوئی اڈاپٹر ہے نہ ماڈل۔ ڈسپیچ انہیں **Control Center (built-in)** پر چلاتا ہے اور، ماڈل مقرر نہ ہونے پر، Anthropic سے اس کا ڈیفالٹ ماڈل مانگتا ہے — چنانچہ وہ صرف اُس صورت چلتے ہیں جب آپ نے Anthropic اکاؤنٹ منسلک کیا ہو، اور اگر کیا ہو تو اُس ماڈل پر چلتے ہیں جو آپ نے نہیں چنا۔ پہلی بار چلنے والی آن بورڈنگ اپنا انتخاب پہلے ورک اسپیس کے ہر ایجنٹ پر ایک بار ثبت کر دیتی ہے؛ اس کے بعد آپ کا بنایا ورک اسپیس پانچوں کو غیر سیٹ شروع کرتا ہے۔ اب ایک مقرر کریں۔

1. **ترتیبات → ورک اسپیس → ایجنٹس** کھولیں
2. روسٹر میں `engineer` منتخب کریں
3. **ترتیبات** ٹیب پر **اڈاپٹر** کو `Control Center (built-in)` پر سیٹ کریں اور کوئی **ماڈل** اُس فراہم کنندہ سے چنیں جو آپ نے ترتیبات → سرور → ماڈل فراہم کنندگان کے تحت منسلک کیا ہو
4. **تبدیلیاں محفوظ کریں** دبائیں

تصدیق: ایجنٹ کو دوبارہ کھولیں تو دونوں فیلڈ آپ کے چنے ہوئے انتخاب برقرار رکھتے ہیں۔

ہر ایجنٹ اپنا اڈاپٹر اور ماڈل خود رکھتا ہے، اس لیے جس بھی دوسرے ایجنٹ کو آپ استعمال کرنے کا ارادہ رکھتے ہیں، اس کے لیے یہی دہرائیں۔ [ایجنٹ بنائیں اور کنفیگر کریں](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/ایجنٹ-بنائیں/) فارم کا باقی حصہ بتاتا ہے۔

## مرحلہ 4: تنہائی کی حد دیکھیں

ٹائٹل بار کی چپ سے ایک دوسرا ورک اسپیس بنائیں، بالکل مرحلہ 1 کی طرح۔ پھر اسے دیکھیں:

- **ترتیبات → ورک اسپیس → ریپوزٹریز** خالی ہے۔ ایک منٹ پہلے آپ کا رجسٹر کیا ہوا ریپو وہاں نہیں ہے۔
- **ترتیبات → ورک اسپیس → ایجنٹس** میں پانچ ایجنٹ ہیں، مگر وہ مختلف قطاریں ہیں — مرحلہ 3 میں سیٹ کیا گیا اڈاپٹر غائب ہے۔
- اسپیسز کی فہرست، ٹکٹس اور میموری سب خالی ہیں۔

کچھ بھی لیک نہیں ہوا، کیونکہ لیک ہونے کے لیے کچھ ہے ہی نہیں: ہر ورک اسپیس کی قطاریں اُسی ورک اسپیس کی اپنی ڈیٹا بیس فائل میں رہتی ہیں۔ ایک ورک اسپیس سے دوسری میں پڑھنا کوئی ایسی کوئری نہیں جسے فلٹر کیا جائے، یہ ایسی کوئری ہے جس کے چلنے کی کوئی جگہ ہی نہیں۔ ورک اسپیس حذف کرنا ایک فائل کا لنک توڑنا ہے۔

ٹائٹل بار کی چپ سے واپس جائیں، یا **ورک اسپیسز منظم کریں** کھول کر انہیں ساتھ ساتھ دیکھیں۔

مکمل ماڈل کے لیے [ورک اسپیسز اور تنہائی](/ur-PK/ہدایت-نامہ/تصورات/ورک-اسپیسز/) پڑھیں۔

## خلاصہ

آپ نے ایک ورک اسپیس بنایا، اسے ایک CEO اور چار ماہرین سیڈ کرتے دیکھا، اس میں ایک ریپو رجسٹر کیا، ایک ایجنٹ کو اڈاپٹر اور ماڈل دیا اور تصدیق کی کہ دوسرا ورک اسپیس ان میں سے کچھ بھی شیئر نہیں کرتا۔
