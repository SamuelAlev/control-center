Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-ورک-اسپیس/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-ایجنٹ/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-pr/) — read the diff, comment and merge
4. [Build your first pipeline](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلی-پائپ-لائن/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-چیٹ-برج/) — drive agents from a Slack thread
- [Sign your team in with SSO](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/ur-PK/ہدایت-نامہ/انسٹال/). If you only want the
shortest possible path to a running agent, take the [quick start](/ur-PK/ہدایت-نامہ/فوری-آغاز/)
instead and come back here afterwards.
:::
