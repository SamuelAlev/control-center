ٹیوٹوریلز **اسباق** ہوتے ہیں۔ ہر ایک آپ کو کسی حقیقی چیز سے شروع سے آخر تک، ایک ہی
راستے پر لے جاتا ہے، جہاں راستے میں کوئی فیصلہ نہیں کرنا پڑتا۔ قدموں پر بالکل ویسے ہی عمل کریں اور وہ چل پڑتے ہیں۔

یہ راہ و رسم سیکھنے کے لیے ہیں۔ جب آپ کو پروڈکٹ کی ساخت سمجھ آ جائے تو کسی مخصوص
کام کے لیے [طریقہ کار گائیڈز](/ur-PK/ہدایت-نامہ/طریقہ-کار-گائیڈز/) تیز تر راستہ ہیں۔

انہیں اسی ترتیب سے کریں — ہر ایک پچھلے کو فرض کرتا ہے۔

1. [آپ کا پہلا ورک اسپیس](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-ورک-اسپیس/) — ورک اسپیس بنائیں، ایک ریپو شامل کریں اور تنہائی کا ماڈل دیکھیں
2. [اپنا پہلا ایجنٹ بھیجیں](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-ایجنٹ/) — ایک ایجنٹ کو اڈاپٹر اور ماڈل دیں، پھر اسے کام پر لگائیں
3. [اپنا پہلا pull request ریویو کریں](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-pr/) — ڈف پڑھیں، تبصرہ کریں اور مرج کریں
4. [اپنی پہلی پائپ لائن بنائیں](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلی-پائپ-لائن/) — قدموں کو DAG میں زنجیر بنائیں اور اسے چلائیں

دو مزید الگ تھلگ ہیں؛ جب آپ کے پاس کام کرتا ورک اسپیس ہو تو کوئی ایک بھی کر لیں۔

- [Slack کو اپنے ورک اسپیس سے جوڑیں](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/پہلا-چیٹ-برج/) — ایجنٹس کو Slack تھریڈ سے چلائیں
- [اپنی ٹیم کو SSO سے سائن اِن کرائیں](/ur-PK/ہدایت-نامہ/ٹیوٹوریلز/sso/) — ایک شناختی فراہم کنندہ جوڑیں اور لاگ اِن شروع سے آخر تک کریں

:::note[شروع کرنے سے پہلے]
پہلے Control Center انسٹال کریں — دیکھیں [انسٹال](/ur-PK/ہدایت-نامہ/انسٹال/)۔ اگر آپ کو
چلتے ایجنٹ تک صرف سب سے مختصر راستہ چاہیے تو [فوری آغاز](/ur-PK/ہدایت-نامہ/فوری-آغاز/)
اپنائیں اور اس کے بعد یہاں واپس آ جائیں۔
:::
