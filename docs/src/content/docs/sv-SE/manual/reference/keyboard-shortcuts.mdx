Genvägarna kommer från ett enda `const`-register, `KeybindingRegistry` i `lib/core/constants/keybindings.dart`. Det innehåller **49 bindningar**. Inställningar → Du → Kortkommandon visar registret som en **skrivskyddad referens**: det finns inget gränssnitt för att tilldela om genvägar och ingen fil för egna tangentbindningar.

`Cmd` nedan är den primära kommandomodifieraren — ⌘ på macOS, Ctrl på Windows och Linux. En bindning utlöses bara när dess kommando har en registrerad hanterare på den aktuella skärmen och dess `when`-villkor är uppfyllt; `!textInputFocus` betyder att tangenten i stället skickas vidare till ett fokuserat textfält.

Det finns ingen genväg för att navigera med siffertangenter. Inkorg, ärenden, pull requests och allt annat nås från sidofältet eller med ⌘K. Observability har inte heller någon genväg.

## Lista över pull requests (3)

Omfånget `/pull-requests`. Alla kräver `route == '/pull-requests'` och att inget textfält är fokuserat, så de utlöses inte medan PR-detaljvyn ligger öppen ovanpå listan.

| Genväg | Åtgärd           |
| ------ | ---------------- |
| `R`    | Uppdatera        |
| `Enter` | Öppna PR        |
| `F`    | Öppna filtermeny |

`Enter` (`pr.list-open`) är deklarerad i registret och visas i referensen över kortkommandon, men **listskärmen registrerar ingen hanterare för den**, så den utlöses inte för närvarande. `F` öppnar filtermenyn (`pr.list-open-filter`), inte sökningen.

## Pull request-detaljvyn (2)

Omfånget `/pull-requests/`. Uppdatera kräver att inget textfält är fokuserat. Stäng flik har ingen spärr för textinmatning (en ⌘-modifierad tangentkombination är aldrig vanlig text) och ett rutt-regex så att den inte utlöses i listan.

| Genväg        | Åtgärd    | Villkor                             |
| ------------- | --------- | ----------------------------------- |
| `R`           | Uppdatera | Inte medan du skriver i ett fält    |
| `Cmd/Ctrl + W` | Stäng flik | På en `/pull-requests/<…>`-plats   |

Flikbyte (`1`/`2`/`3`), visad/ihopfälld fil (`V`/`C`), fillistan (`T`) och sökning i diffen (`Cmd/Ctrl + F`) hanteras av diffvyns egen hanterare — se [Tangenter i diffvyn utanför registret](#tangenter-i-diffvyn-utanför-registret).

## Ytor (9)

Omfånget `/spaces`. `when`-villkoren använder ett regex så att de utlöses både i listan över ytor (`/spaces`) och i en vald yta (`/spaces/<id>`).

| Genväg                | Åtgärd                     | Villkor               |
| --------------------- | -------------------------- | --------------------- |
| `Enter`               | Skicka meddelande          | —                     |
| `Cmd/Ctrl + N`        | Ny yta                     | På en `/spaces`-rutt  |
| `J`                   | Nästa yta                  | Inte medan du skriver i ett fält |
| `K`                   | Föregående yta             | Inte medan du skriver i ett fält |
| `Cmd/Ctrl + Shift + D` | Diktering med tryck för att tala | —              |
| `Cmd/Ctrl + T`        | Öppna redigerarflik        | På en `/spaces`-rutt  |
| `Cmd/Ctrl + W`        | Stäng redigerarflik        | På en `/spaces`-rutt  |
| `Cmd/Ctrl + B`        | Växla redigerarens sidofält | På en `/spaces`-rutt |
| `Cmd/Ctrl + P`        | Gå till fil                 | På en `/spaces`-rutt |

Gå till fil öppnar en väljare över samtalets filer. Utan inmatning listar den de filer du senast öppnade; när du skriver söker den i alla filer i samtalets worktrees. `Enter` öppnar den valda filen i en ny flik, `Cmd/Ctrl + Enter` eller delningsknappen på raden öppnar den i en panel till höger, och `×` på en nylig rad tar bort den från listan.

Enter-för-att-skicka hanteras av meddelandefältets textfält; tryck-för-att-tala hanteras av meddelandefältets mikrofonsknapp (med sin egen hanterare för fysiskt tangentbord). Båda finns med i registret för inställningsreferensen.

## Tangenter i diffvyn utanför registret

PR-diffvyn hanterar dessa själv (`PrDiffKeyboardHandler`). Sökning/visad/ihopfällning finns bara med i registrets kommentarer för inställningsreferensen — ingen hanterare registreras i dispatch, så de lämnas vidare till diffvyn. De visas inte som egna rader i referensen över kortkommandon.

| Genväg          | Åtgärd                                               |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Sök i diffen                                         |
| `J` / `K`       | Nästa / föregående fil                               |
| `V`             | Växla visad på den fokuserade filen                  |
| `C`             | Växla ihopfällning på den fokuserade filen           |
| `T`             | Visa fillistan                                       |
| `Enter`         | Nästa sökträff (endast medan sökningen i diffen är öppen) |
| `Shift + Enter` | Föregående sökträff                                  |
| `Escape`        | Stäng sökningen i diffen eller rensa den markerade difftexten |
| `Cmd/Ctrl + C`  | Kopiera det markerade diffpartiet                    |

## Kombinationer som webbläsaren reserverar

I webbversionen fångar webbläsaren upp vissa snabbtangenter innan sidan ser dem, så motsvarande bindningar kan aldrig utlösas där. De fungerar som vanligt i skrivbordsappen. Reserverade i kombination med den primära kommandomodifieraren: `T`, `W`, `N` och siffrorna `1`–`9`.

Det gäller byte av arbetsyta med `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (ny yta, ny arbetsyta, ny agent, lägg till arkiv) och `Cmd/Ctrl + T` / `Cmd/Ctrl + W` i ytor och i PR-detaljvyn.
