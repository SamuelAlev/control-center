Referenssidorna beskriver **vad som finns**, uttömmande och utan kommentarer. Använd
dem för att slå upp något när du redan vet vad du söker: ett exakt verktygsnamn,
en stegtyp, en statusövergång, en rutt, en genväg.

De är inte skrivna för att läsas från början till slut. För det använder du
[koncepten](/sv-SE/handbok/koncept/); för att få något gjort använder du
[how-to-guiderna](/sv-SE/handbok/how-to-guider/).

## Produktens yta

- [MCP-verktyg](/sv-SE/handbok/referens/mcp-verktyg/) — varje verktyg som MCP-servern registrerar, per familj
- [Inbyggda agentverktyg](/sv-SE/handbok/referens/agentverktyg/) — serverbundna harness-verktyg (LSP, AST, debug, eval, vibe)
- [Slash-kommandon](/sv-SE/handbok/referens/slash-kommandon/) — inbyggda kommandon i composern, `/skill:` och användarkommandon
- [Routkarta](/sv-SE/handbok/referens/routkarta/) — varje skärm och URL:en som når den
- [Tangentbordsgenvägar](/sv-SE/handbok/referens/tangentbordsgenvagar/) — hela registret över tangentbindningar
- [Domänhändelser](/sv-SE/handbok/referens/domanhandelser/) — varje händelse som publiceras på domänbussen
- [Stationer](/sv-SE/handbok/referens/stationer/) — varje stationsyta, åtgärdsverb, livscykeltillstånd, port och standardvärde
