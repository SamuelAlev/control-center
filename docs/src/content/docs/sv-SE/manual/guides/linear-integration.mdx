Klistra in en Linear-API-nyckel på servern kopplad till din användare, på samma
sätt som du ansluter en kodvärd. Ärenden, projekt, länkar, medarbetare,
delegering och tilldelning fungerar alla mot Control Centers egen databas utan
att någon extern tjänst krävs — se
[Skapa och hantera ärenden](/sv-SE/handbok/how-to-guider/hantera-arenden/).

## Lagra din Linear-nyckel

**API-nyckel för ärenden** finns under **Inställningar → Arbetsyta → Allmänt**,
på kortet **Ärenden**. Den lagrar nyckeln på servern kopplad till ditt
användar-id. Serverns egen nyckel för obevakat arbete kommer från
`LINEAR_API_KEY` eller kortet **Leverantörsappar** och injiceras som
`TICKETING_API_KEY` endast när den agenten har behörigheten **Tillåt API-anrop
för ärenden**.

## Stämpla nya ärenden som Linear

**Ärendeleverantör** (onboardingens första steg, och
`/workspaces/<workspaceId>/api-keys`) erbjuder `local` och `linear`. Väljer du
`linear` stämplas `provider: linear` på ärenden du skapar från och med då.
