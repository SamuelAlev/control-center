Varje guide löser **ett problem åt någon som redan hittar runt**. De utgår från att du har
Control Center installerat och en arbetsyta på plats, de anger ett mål i rubriken och de
slutar när målet är uppnått.

Om du fortfarande lär dig produkten börjar du med [guiderna](/sv-SE/handbok/guider/).
Vill du förstå _varför_ något beter sig som det gör läser du
[koncepten](/sv-SE/handbok/koncept/).
