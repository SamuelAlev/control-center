Αυτός ο οδηγός δείχνει πώς να δώσετε στον διακομιστή σας τη δική του GitHub App.
Διαρκεί περίπου δύο λεπτά, μόνο ο ιδιοκτήτης του διακομιστή χρειάζεται να το κάνει
και γίνεται μία φορά ανά διακομιστή.

:::note[Ίσως δεν τη χρειάζεστε]
Όταν το Control Center Connect είναι ενεργό, οι άνθρωποι συνδέονται στο GitHub
μέσω της κοινόχρηστης App του Control Center ή της App που χρησιμοποιεί το Connect
του οργανισμού σας. Καταχωρίστε δική σας εφαρμογή όταν επιλέξατε **Χρήση των
δικών μου εφαρμογών** μόνο τότε: η App του διακομιστή ισχύει μόνο σε αυτή την περίπτωση. Όταν η πρόσβαση του διακομιστή σας στο GitHub πρέπει να περνά από μια App που ελέγχετε εσείς, δείτε το [Control Center Connect](/el-GR/εγχειρίδιο/αναφορά/connect/).
:::

Για να συνδέσετε τον δικό σας λογαριασμό στη συνέχεια, δείτε τη
[Ρύθμιση ενσωμάτωσης GitHub](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/ενσωμάτωση-github/).

## Τι κάνει η εφαρμογή

Μία καταχώριση απαντά σε δύο διαφορετικές ανάγκες:

| Ανάγκη                      | Τι την καλύπτει                                  | Γιατί έχει σημασία                                                                            |
| --------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Ένας άνθρωπος συνδέεται** | Το client id και το client secret της εφαρμογής   | Ο καθένας έχει το δικό του διαπιστευτήριο GitHub, στον διακομιστή και σε κάθε συσκευή         |
| **Ο διακομιστής ενεργεί**   | Το ID εφαρμογής και το ιδιωτικό κλειδί            | Πράκτορες, pipelines, περιοδικοί έλεγχοι και απαντήσεις bot παίρνουν tokens για ένα αποθετήριο κάθε φορά |

Η δεύτερη ανάγκη δεν δανείζεται ποτέ ολόκληρο το διαπιστευτήριο ενός ανθρώπου.
Κάθε token που εκδίδει ο διακομιστής καλύπτει ένα αποθετήριο και περιορίζεται σε
ό,τι μπορεί να κάνει εκεί ένα υπόλογο μέλος. Για την ανάγνωση ενός συνδεδεμένου
αποθετηρίου αρκεί η εφαρμογή· για οτιδήποτε γράφει χρειάζεται ένα μέλος που
μπορεί να κάνει push. Η αυτοματοποίηση δεν εγκρίνει ποτέ ένα pull request.

Η εφαρμογή του διακομιστή ισχύει μόνο υπό **Χρήση των δικών μου εφαρμογών**. Με το Control Center ή ένα δικό σας Connect, το Connect εκτελεί κάθε λωρίδα, και το GitHub περιλαμβάνεται· η εφαρμογή του διακομιστή μένει αποθηκευμένη αλλά αχρησιμοποίητη μέχρι να επιστρέψετε. Μια εφαρμογή του χώρου εργασίας ([Δώστε σε έναν χώρο εργασίας άλλη εφαρμογή](#δώστε-σε-έναν-χώρο-εργασίας-άλλη-εφαρμογή)) ισχύει πάντα, σε κάθε λειτουργία. Μια εφαρμογή με
πεδία που λείπουν είναι σφάλμα, όχι μετάπτωση σε εφεδρική λύση: οι συνδέσεις στο
GitHub απορρίπτονται μέχρι να συμπληρωθούν όλα τα πεδία.

## Προϋποθέσεις

- Είστε ο **ιδιοκτήτης του διακομιστή**. Η κάρτα **Εφαρμογές παρόχων** είναι
  αόρατη για όλους τους άλλους
- Ένας λογαριασμός GitHub. Η εφαρμογή δημιουργείται κάτω από αυτόν
- Μια διεύθυνση του διακομιστή που φτάνει το πρόγραμμα περιήγησής σας. Το δημόσιο
  URL του διακομιστή (ή το loopback για τον δικό διακομιστή μιας επιτραπέζιας
  εφαρμογής) είναι εκεί όπου σας επιστρέφει το GitHub

## Δημιουργήστε την με ένα κλικ

1. Μεταβείτε στις **Ρυθμίσεις → Διακομιστής → Ενιαία σύνδεση** και κάντε κύλιση
   στην κάρτα **Εφαρμογές παρόχων**
2. Στο τμήμα **GitHub**, συμπληρώστε προαιρετικά στο **Οργανισμός (προαιρετικό)**
   τον οργανισμό GitHub στον οποίο θα ανήκει η εφαρμογή. Αφήστε το κενό για να τη
   δημιουργήσετε κάτω από τον δικό σας λογαριασμό· η δημιουργία κάτω από έναν
   οργανισμό απαιτεί κάποιον ιδιοκτήτη εκείνου του οργανισμού
3. Πατήστε **Δημιουργία της εφαρμογής μου GitHub**
4. Το πρόγραμμα περιήγησης ανοίγει το GitHub με την εφαρμογή ήδη συμπληρωμένη.
   Πατήστε **Create GitHub App**
5. Το GitHub σας επιστρέφει στον διακομιστή, ο οποίος αποθηκεύει το id της
   εφαρμογής, το ιδιωτικό κλειδί, το client id και το client secret, και μετά
   ανοίγει τη σελίδα εγκατάστασης της εφαρμογής

Τίποτα δεν αντιγράφεται με το χέρι, και ο κωδικός μετατροπής πηγαίνει κατευθείαν
από το GitHub στον διακομιστή σας. Ο σύνδεσμος λειτουργεί μία φορά και λήγει μετά
από δέκα λεπτά· αν έληξε, πατήστε ξανά **Δημιουργία της εφαρμογής μου GitHub**.

Η εφαρμογή ονομάζεται `Control Center <code>` και ζητά ακριβώς ό,τι χρησιμοποιεί
το Control Center:

| Δικαίωμα                                   | Πρόσβαση               |
| ------------------------------------------ | ---------------------- |
| Metadata                                   | Ανάγνωση               |
| Contents                                   | Ανάγνωση και εγγραφή   |
| Pull requests                              | Ανάγνωση και εγγραφή   |
| Issues                                     | Ανάγνωση και εγγραφή   |
| Checks, Actions, Commit statuses           | Ανάγνωση               |
| Organization members                       | Ανάγνωση               |

Τα webhooks είναι απενεργοποιημένα: ο διακομιστής κάνει περιοδικό έλεγχο. Για να
μεταφέρετε αργότερα σε οργανισμό μια εφαρμογή που δημιουργήθηκε κάτω από τον δικό
σας λογαριασμό, χρησιμοποιήστε το **Transfer ownership** στις προχωρημένες
ρυθμίσεις της εφαρμογής στο GitHub.

Σημείο ελέγχου: το τμήμα GitHub γράφει «Ο διακομιστής μπορεί να ενεργεί ως ο
εαυτός του και οι άνθρωποι μπορούν να συνδεθούν».

## Εγκαταστήστε την εκεί όπου βρίσκονται τα αποθετήριά σας

Μια καταχωρισμένη αλλά μη εγκατεστημένη εφαρμογή μπορεί να συνδέει ανθρώπους, αλλά
δεν μπορεί να διαβάσει τίποτα.

1. Στη σελίδα εγκατάστασης που άνοιξε το GitHub, επιλέξτε τον λογαριασμό ή τον
   οργανισμό στον οποίο ανήκουν τα αποθετήριά σας
2. Επιλέξτε **All repositories** ή σημειώστε αυτά που πρέπει να βλέπει αυτός ο
   διακομιστής

Για να την εγκαταστήσετε αργότερα σε άλλον λογαριασμό, ένας διαχειριστής του
χώρου εργασίας ανοίγει τις **Ρυθμίσεις → Χώρος εργασίας → Γενικά**, βρίσκει τις
**Εγκαταστάσεις της εφαρμογής GitHub** στην κάρτα ταυτότητας GitHub και πατά
**Εγκατάσταση εφαρμογής GitHub**. Η λίστα δείχνει κάθε λογαριασμό στον οποίο είναι
εγκατεστημένη η εφαρμογή, και μια εγκατάσταση σε αναστολή επισημαίνεται.

## Εξουσιοδοτήστε αυτόν τον διακομιστή για έναν οργανισμό

Στην κοινόχρηστη App του Control Center, η εγκατάσταση ενός οργανισμού εξυπηρετεί
μόνο τους διακομιστές που έχουν εξουσιοδοτήσει οι διαχειριστές του. Η εγκατάσταση
μέσω της **Εγκατάστασης εφαρμογής GitHub** εξουσιοδοτεί τον διακομιστή που την
ξεκίνησε. Για μια εγκατάσταση που υπάρχει ήδη:

1. Ένας διαχειριστής εκείνου του οργανισμού συνδέεται στο GitHub σε αυτόν τον
   διακομιστή
2. Ανοίγει τις **Ρυθμίσεις → Χώρος εργασίας → Γενικά → Εγκαταστάσεις της
   εφαρμογής GitHub**
3. Η γραμμή του οργανισμού γράφει **Μη εξουσιοδοτημένη**. Πατά **Εξουσιοδότηση
   αυτού του διακομιστή**

Η γραμμή τότε γράφει **Εξουσιοδοτημένη**. Μια δική σας εφαρμογή δεν χρειάζεται
τίποτα από αυτά: κάθε εγκατάστασή της ανήκει στον διακομιστή σας.

## Καταχωρίστε την με το χέρι

Η κάρτα **Εφαρμογές παρόχων** δέχεται και τις τιμές απευθείας, για μια εφαρμογή
που καταχωρίσατε μόνοι σας:

| Ομάδα                          | Πεδία                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Ενέργεια ως διακομιστής**    | **ID εφαρμογής** και **Ιδιωτικό κλειδί** (ολόκληρο το `.pem`, με τις γραμμές `BEGIN` και `END`)        |
| **Σύνδεση ανθρώπων**           | **Client id** και **Μυστικό πελάτη**. Το **URL επιστροφής κλήσης** δείχνει αυτούσιο το URL για καταχώριση |
| **Συνομιλίες pull request**    | **Σύνδεση bot**, που εντοπίζεται όταν δοκιμάζετε τη σύνδεση                                            |

Καταχωρίστε το URL επιστροφής κλήσης `<server origin>/oauth/github/callback`
ακριβώς όπως το δείχνει η κάρτα, αφήστε το **Expire user authorization tokens**
ενεργό και παραχωρήστε τα δικαιώματα του παραπάνω πίνακα. Πατήστε **Δοκιμή**:
ρωτά το GitHub σε ποιους λογαριασμούς είναι εγκατεστημένη η εφαρμογή, ώστε το
«αποθηκεύτηκε» και το «λειτουργεί» να μη συγχέονται.

## Ρυθμίστε την από το `.env` του διακομιστή

Για μια headless ή σεναριοποιημένη εγκατάσταση, ο διακομιστής συμπληρώνει κάθε
πεδίο από το αρχείο `.env` του την πρώτη φορά που δεν έχει αποθηκευμένη τιμή:

```bash
GITHUB_APP_ID=123456
GITHUB_CLIENT_ID=Iv23li0123456789abcd
GITHUB_CLIENT_SECRET=<secret>
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEow…\n-----END RSA PRIVATE KEY-----"
```

Γράψτε το κλειδί **σε μία γραμμή**: μια τιμή του `.env` είναι μία γραμμή, και το
`\n` μέσα σε διπλά εισαγωγικά αποκωδικοποιείται σε αλλαγή γραμμής. Ο διακομιστής
αρνείται να εκκινήσει όταν το `GITHUB_APP_PRIVATE_KEY` ή το `GITHUB_CLIENT_SECRET`
είναι εξαγόμενα στο περιβάλλον της διεργασίας του, όπου θα μπορούσε να τα
διαβάσει κάθε θυγατρική διεργασία· κρατήστε τα στο αρχείο `.env` (σε Docker,
προσαρτήστε το στο `/app/bin/.env`). Η συμπλήρωση γίνεται **μία φορά ανά πεδίο**,
οπότε μια αλλαγή στις Ρυθμίσεις δεν αναιρείται στην επόμενη επανεκκίνηση.

## Δώστε σε έναν χώρο εργασίας διαφορετική εφαρμογή

Ένας χώρος εργασίας μπορεί να χρησιμοποιεί τη δική του εφαρμογή αντί για την
εφαρμογή του διακομιστή. Ένας διαχειριστής του χώρου εργασίας ανοίγει τις
**Ρυθμίσεις → Χώρος εργασίας → Γενικά**, επιλέγει **Χρήση διαφορετικού GitHub App**
στην κάρτα **Ταυτότητα GitHub** και εισάγει το id εκείνης της εφαρμογής, το
ιδιωτικό κλειδί, το client id και το client secret. Τότε τα μέλη συνδέονται σε
εκείνη την εφαρμογή για αυτόν τον χώρο εργασίας. Ένας χώρος εργασίας με δική του
εφαρμογή δεν μεταπίπτει ποτέ στην εφαρμογή του διακομιστή ή στο Connect: όσο τα
πεδία του είναι ελλιπή, η εργασία του στο GitHub απορρίπτεται. Ισχύει ανεξάρτητα από τον τρόπο που ο διακομιστής συνδέει τα άτομα, και με το Connect.

Η κάρτα **Εφαρμογές παρόχων** στην ίδια σελίδα κάνει το ίδιο για το Google Calendar, το Linear και την αναζήτηση GIF. Δείτε [Δώστε σε έναν χώρο εργασίας τη δική του εφαρμογή Linear](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/ενσωμάτωση-linear/#δώστε-σε-έναν-χώρο-εργασίας-τη-δική-του-εφαρμογή-linear) και [Δώστε σε έναν χώρο εργασίας τον δικό του πελάτη Google](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/σύνδεση-ημερολογίου/#δώστε-σε-έναν-χώρο-εργασίας-τον-δικό-του-πελάτη-google).

## Αντιμετώπιση προβλημάτων

### Η «Δημιουργία της εφαρμογής μου GitHub» λέει ότι ο διακομιστής δεν έχει διεύθυνση

Ο διακομιστής δεν έχει δημόσιο URL στο οποίο να μπορεί να επιστρέψει το πρόγραμμα
περιήγησης. Ορίστε το `CC_SERVER_PUBLIC_URL` (ή το `--public-url`) και δοκιμάστε
ξανά.

### Το GitHub λέει ότι ο σύνδεσμος έληξε

Η σελίδα μίας χρήσης χρησιμοποιήθηκε ήδη ή πέρασαν δέκα λεπτά. Ξεκινήστε ξανά από
τις Ρυθμίσεις.

### Η Δοκιμή λέει ότι τα διαπιστευτήρια λειτουργούν αλλά η εφαρμογή δεν είναι εγκατεστημένη πουθενά

Η καταχώριση και η εγκατάσταση είναι ξεχωριστά βήματα. Ανοίξτε τη σελίδα
εγκατάστασης της εφαρμογής ή χρησιμοποιήστε την **Εγκατάσταση εφαρμογής GitHub**
στο Χώρος εργασίας → Γενικά.

### Η Δοκιμή λέει ότι το ιδιωτικό κλειδί δεν μπόρεσε να διαβαστεί

Επικολλήστε ολόκληρο το αρχείο `.pem`, μαζί με τις γραμμές `-----BEGIN` και
`-----END`. Ένα κλειδί `ed25519` ή EC δεν θα λειτουργήσει: οι GitHub Apps
υπογράφουν με RSA.

### Ένα μέλος συνδέθηκε αλλά δεν βλέπει αποθετήρια

Η εφαρμογή δεν είναι εγκατεστημένη στον λογαριασμό στον οποίο ανήκουν ή η
εγκατάστασή της επιλέγει άλλα αποθετήρια. Η σύνδεση παρέχει μόνο ό,τι μπορεί να
δει η εφαρμογή.

### Οι πράκτορες λένε ότι η εγκατάσταση της GitHub App έχει ανασταλεί

Κάποιος ανέστειλε την εγκατάσταση στο GitHub. Επαναφέρετέ την από τις **Settings →
Applications → Installed GitHub Apps** του λογαριασμού.
