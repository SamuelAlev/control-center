Αυτός ο οδηγός καλύπτει τα ειδικά για το GitHub μέρη της ρύθμισης. Το GitHub
είναι ένας από τους τρεις υποστηριζόμενους κεντρικούς υπολογιστές κώδικα — δείτε
[Σύνδεση κεντρικού υπολογιστή κώδικα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/σύνδεση-κεντρικού-υπολογιστή-κώδικα/)
για τη σύνδεση του GitLab ή του Bitbucket και για το πώς ένας χώρος εργασίας τα
συνδυάζει.

## Προϋποθέσεις

- Λογαριασμός GitHub με πρόσβαση στα αποθετήρια στα οποία θέλετε να εργαστείτε
- Έναν διακομιστή που μπορεί να συνδέει ανθρώπους στο GitHub: είτε με τη δική
  του GitHub App (δείτε [Δημιουργία της GitHub App](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/github-app/)) είτε με το
  Control Center Connect, όπως επιλέγει ο ιδιοκτήτης του διακομιστή στις
  **Ρυθμίσεις → Διακομιστής → Ενιαία σύνδεση**

:::note[Τα διαπιστευτήρια μένουν στον διακομιστή, προσαρτημένα σε εσάς]
Τίποτα δεν αποθηκεύεται στο μηχάνημα στο οποίο πληκτρολογείτε. Τη σύνδεσή σας στο
GitHub την κρατά το `cc_server` σας, με κλειδί το αναγνωριστικό χρήστη σας, και
κάθε συσκευή από την οποία συνδέεστε τη χρησιμοποιεί — επιφάνεια εργασίας, web και
τηλέφωνο. Άλλο μέλος του ίδιου διακομιστή δεν μπορεί να τη χρησιμοποιήσει, και η
σύνδεσή του είναι κάτι που το κάνει το ίδιο.
:::

## Σύνδεση στο GitHub

Το GitHub λειτουργεί μόνο με σύνδεση: δεν υπάρχει token για επικόλληση.

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Προφίλ και ταυτότητα → Φιλοξενία κώδικα** (ή στο πρώτο
   βήμα της εισαγωγής)
2. Στη γραμμή **GitHub**, πατήστε **Σύνδεση στο GitHub**
3. Το πρόγραμμα περιήγησης ανοίγει το GitHub. Εγκρίνετε την εφαρμογή

Το πώς ολοκληρώνεται η σύνδεση εξαρτάται από το ποιος την εκτελεί:

- **Η δική εφαρμογή του διακομιστή:** το GitHub στέλνει το πρόγραμμα περιήγησης
  πίσω στον διακομιστή και το παράθυρο διαλόγου το αντιλαμβάνεται μόνο του. Δεν
  χρειάζεται να πληκτρολογήσετε τίποτα
- **Control Center Connect:** η σελίδα του προγράμματος περιήγησης δείχνει έναν
  κωδικό 8 χαρακτήρων. Πληκτρολογήστε τον στο παράθυρο διαλόγου ή αφήστε το
  πρόγραμμα περιήγησης να ανοίξει το Control Center μέσω του συνδέσμου
  `control-center://` και παραλείψτε την πληκτρολόγηση

Σημείο ελέγχου: η γραμμή **GitHub** γράφει «Συνδεθήκατε ως _your-username_».

Το παράθυρο διαλόγου απορρίπτει έναν κωδικό ή σύνδεσμο που δεν ξεκίνησε το ίδιο,
με το μήνυμα **Η σύνδεση δεν ξεκίνησε από εδώ**. Αν κάποιος σας στείλει σύνδεσμο
σύνδεσης, μη συνεχίσετε: η ολοκλήρωσή του θα συνέδεε τον λογαριασμό σας με τον
δικό του διακομιστή.

Πατήστε **Αποσύνδεση** για να αφαιρέσετε τη σύνδεσή σας. Η αποσύνδεση από το
GitHub ή η αφαίρεσή σας από έναν χώρο εργασίας ακυρώνει επίσης κάθε token που
εξέδωσε ο διακομιστής για λογαριασμό σας.

## Για λογαριασμό ποιου ενεργεί το διαπιστευτήριό σας

- **Ό,τι κάνετε εσείς** (άνοιγμα της σελίδας PR, δημοσίευση ανασκόπησης,
  έγκριση, συγχώνευση) εκτελείται με τη **δική σας** σύνδεση και τίποτε άλλο. Αν
  δεν έχετε συνδεθεί, η εφαρμογή το λέει και σας ζητά να συνδεθείτε. Κανένα άλλο
  διαπιστευτήριο δεν σας αναπληρώνει
- **Η εργασία χωρίς κάποιον να πληκτρολογεί** (εκτελέσεις πρακτόρων, pipelines,
  περιοδικός έλεγχος PR, απαντήσεις bot, κλωνοποιήσεις) παίρνει ένα token για ένα
  αποθετήριο, που εκδίδεται από τη GitHub App του διακομιστή ή μέσω του Connect.
  Περιορίζεται σε ό,τι μπορεί να κάνει εκεί ένα υπόλογο μέλος: το μέλος που
  ζήτησε, αλλιώς ο ιδιοκτήτης του χώρου εργασίας. Ένα μέλος που δεν μπορεί να
  κάνει push περιορίζει το token σε ανάγνωση
- **Η αυτοματοποίηση δεν εγκρίνει ποτέ** ένα pull request. Η έγκριση είναι πράξη
  ανθρώπου

## Τι σας προσφέρει η ενσωμάτωση

| Δυνατότητα             | Πώς                                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| Λίστα και λεπτομέρειες PR  | Το GitHub REST API, από τον διακομιστή, με τη δική σας σύνδεση                                                 |
| Εκτελέσεις ελέγχων          | Το GitHub Checks API                                                                                          |
| Δημοσίευση ανασκόπησης   | Ένα βήμα που το ελέγχει ο χρήστης και αναρτά την ανασκόπησή σας στο PR, ως εσείς                                |
| Καταχώριση αποθετηρίου   | Ένα checkout γίνεται δεκτό αν το απομακρυσμένο `origin` του δείχνει στο github.com — ή στο gitlab.com / bitbucket.org          |
| Πρόσβαση πράκτορα στο GitHub | Ένα token για το ένα αποθετήριο της εκτέλεσης ως `GH_TOKEN` / `GITHUB_TOKEN`· τα push περνούν από το Control Center |
| Σήματα ειδοποιήσεων  | Ένας περιοδικός έλεγχος στην πλευρά του διακομιστή των εισερχομένων ειδοποιήσεων του GitHub σας εγείρει «Αναφορά σε pull request» και «Ζητήθηκε ανασκόπηση» |
| Προφίλ χρηστών       | Κάρτες προφίλ στο hover και φιλτράρισμα PR ανά συντάκτη                                                                |

Ορισμένες διαδρομές χρησιμοποιούν το GraphQL API αντί για το REST όπου είναι
φθηνότερο — τη δραστηριότητα κλάδων για τον επιλογέα σύνταξης PR και τη ζωντανή
κατάσταση ανασκόπησης που αποφασίζει αν μια ειδοποίηση αιτήματος ανασκόπησης
εκκρεμεί ακόμη.

## Προσέξτε τις διακοπές του GitHub

Η γραμμή τίτλου εμφανίζει ένα σήμα κατάστασης όταν ένας πάροχος είναι
υποβαθμισμένος, καλύπτοντας τα GitHub, Claude, OpenAI και Kimi. **Κρύβεται όσο όλα
είναι υγιή** — η παρουσία αναφέρει πρόβλημα, όχι η απουσία της.

Πατήστε το σήμα για να ανοίξει ένα αναδυόμενο πλαίσιο με την κατάσταση κάθε παρόχου
και ένα κουμπί ανανέωσης. Οι καταστάσεις ανανεώνονται από μόνες τους κάθε δύο λεπτά.

## Μάθετε πώς ενεργούν οι πράκτορες στο GitHub

- Ένας πράκτορας που δουλεύει σε worktree του GitHub παίρνει ένα token για εκείνο
  το ένα αποθετήριο. Μπορεί να διαβάζει τον κώδικα και να σχολιάζει σε pull
  requests όταν το υπόλογο μέλος μπορεί να κάνει push, και μόνο να διαβάζει όταν
  δεν μπορεί. Ένα push περνά από το Control Center, που ρωτά τον
  κανόνα **Push σε απομακρυσμένο** και μετά το προωθεί με ένα token εγγραφής
  που ο πράκτορας δεν κατέχει ποτέ. Δείτε
  [Ρύθμιση πολιτικών sandbox](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/πολιτικές-sandbox/)
- Τα commit των πρακτόρων χρησιμοποιούν πάντοτε την ταυτότητα Git του αιτούντος τόσο ως συντάκτη όσο και ως committer. Από προεπιλογή, το trailer `Co-Authored-By: Control Center <hi@usectrl.dev>` πιστώνει τον λογαριασμό GitHub `@usectrl` ως συνδημιουργό. Στις **Ρυθμίσεις → Εσείς → Απόδοση συνεισφοράς στα commit** μπορείτε να απενεργοποιήσετε αυτή την πίστωση χωρίς να αλλάξετε την ταυτότητά σας. Η παράκαμψη στις **Ρυθμίσεις → Χώρος εργασίας → Γενικά** υπερισχύει και κλειδώνει τον προσωπικό διακόπτη. Η εγγενής απόδοση συνεισφοράς του Claude Code είναι πάντα απενεργοποιημένη. Η υπογραφή commit εξακολουθεί να απαιτεί δική της έγκυρη ρύθμιση
- Ένα τερματικό που ανοίγετε σε ένα rig παίρνει τη δική σας σύνδεση, περιορισμένη
  στο ένα αποθετήριο, οπότε τα push από εκεί είναι δικά σας
- Όταν δεν μπορεί να εκδοθεί token (κανένας υπόλογος δεν είναι συνδεδεμένος, η
  εφαρμογή δεν είναι εγκατεστημένη στον ιδιοκτήτη ή η εγκατάσταση έχει ανασταλεί),
  η εκτέλεση ξεκινά χωρίς token και οι σημειώσεις της εξηγούν τον λόγο. Δεν
  υπάρχει εφεδρικό διαπιστευτήριο

## Αντιμετώπιση προβλημάτων

### Η λίστα PR είναι κενή και λέει ότι το GitHub δεν είναι συνδεδεμένο

Δεν έχετε συνδεθεί στο GitHub σε αυτόν τον διακομιστή. Πατήστε **Σύνδεση στο
GitHub** στη **Φιλοξενία κώδικα**. Τα αποθετήρια σε άλλα forge δεν επηρεάζονται.

### Η γραμμή GitHub λέει ότι η σύνδεση δεν έχει ρυθμιστεί σε αυτόν τον διακομιστή

Ο διακομιστής δεν έχει ούτε δική του GitHub App ούτε Connect. Ο ιδιοκτήτης του
διακομιστή επιλέγει ένα από τα δύο στις **Ρυθμίσεις → Διακομιστής → Ενιαία
σύνδεση**: η **Δημιουργία της εφαρμογής μου GitHub** διαρκεί περίπου δύο λεπτά.
Δείτε [Δημιουργία της GitHub App](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/github-app/).

### Το παράθυρο διαλόγου λέει ότι ο κωδικός δεν ταιριάζει

Πληκτρολογήστε τον κωδικό ακριβώς όπως τον δείχνει το πρόγραμμα περιήγησης: 8
γράμματα και ψηφία. Πέντε λανθασμένοι κωδικοί τερματίζουν τη σύνδεση· ξεκινήστε
την ξανά.

### Η σύνδεση λέει ότι η εφαρμογή δεν είναι εγκατεστημένη

Η GitHub App δεν έχει εγκατάσταση στον λογαριασμό που κατέχει το αποθετήριο. Ένας
διαχειριστής του χώρου εργασίας την εγκαθιστά από τις **Ρυθμίσεις → Χώρος
εργασίας → Γενικά → Εγκαταστάσεις της εφαρμογής GitHub**. Για έναν οργανισμό στην
κοινόχρηστη App του Control Center, ένας διαχειριστής εκείνου του οργανισμού
μπορεί να χρειαστεί να πατήσει **Εξουσιοδότηση αυτού του διακομιστή**. Δείτε
[Δημιουργία της GitHub App](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/github-app/#εξουσιοδοτήστε-αυτόν-τον-διακομιστή-για-έναν-οργανισμό).

### Όλοι πρέπει να συνδεθούν ξανά στο GitHub

Ο ιδιοκτήτης του διακομιστή έκανε εναλλαγή του κλειδιού Connect του διακομιστή,
άλλαξε διακομιστή Connect, ή ο κατάλογος δεδομένων επαναφέρθηκε σε άλλο μηχάνημα.
Οι συνδέσεις μέσω Connect είναι δεσμευμένες στον διακομιστή που τις έκανε.

### Η προσθήκη αποθετηρίου απορρίπτεται

Η καταχώριση απαιτεί και τα τρία: η διαδρομή βρίσκεται μέσα σε ένα δέντρο εργασίας
git, υπάρχει απομακρυσμένο `origin` και αυτό το απομακρυσμένο δείχνει σε ένα
υποστηριζόμενο forge (github.com, gitlab.com ή bitbucket.org). Δείτε
[Προσθήκη αποθετηρίων σε χώρο εργασίας](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/προσθήκη-αποθετηρίων/).

### Όλα σταματούν να λειτουργούν για λίγο μετά από εντατική χρήση

Αυτός είναι ο διακόπτης κυκλώματος του ορίου ρυθμού. Το GitHub σηματοδοτεί το κύριο
όριό του με ένα `403` που φέρει `x-ratelimit-remaining: 0` και χρόνο επαναφοράς· όταν
δει ένα τέτοιο, ο πελάτης αποτυγχάνει περαιτέρω αιτήματα τοπικά χωρίς κλήση δικτύου
μέχρι να περάσει το παράθυρο, ώστε μια καταιγίδα επαναλήψεων να μην μπορεί να βαθύνει
το όριο. Οι παροδικές αποτυχίες επαναλαμβάνονται έως τρεις φορές με εκθετική
υποχώρηση, τηρώντας το `retry-after`.
