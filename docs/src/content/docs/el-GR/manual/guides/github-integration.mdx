Αυτός ο οδηγός καλύπτει τα ειδικά για το GitHub μέρη της ρύθμισης. Το GitHub
είναι ένας από τους τρεις υποστηριζόμενους κεντρικούς υπολογιστές κώδικα — δείτε
[Σύνδεση κεντρικού υπολογιστή κώδικα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/σύνδεση-κεντρικού-υπολογιστή-κώδικα/)
για τη σύνδεση του GitLab ή του Bitbucket και για το πώς ένας χώρος εργασίας τα
συνδυάζει.

## Προϋποθέσεις

- Λογαριασμός GitHub με πρόσβαση στα αποθετήρια στα οποία θέλετε να εργαστείτε
- Είτε μια GitHub App καταχωρισμένη για τον διακομιστή σας (δείτε
  [Δημιουργία της GitHub App](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/github-app/)) ώστε να μπορείτε να **συνδεθείτε**,
  **είτε** ένα προσωπικό token πρόσβασης με `repo` και `read:org` για επικόλληση

:::note[Τα διαπιστευτήρια μένουν στον διακομιστή, προσαρτημένα σε εσάς]
Τίποτα δεν αποθηκεύεται στο μηχάνημα στο οποίο πληκτρολογείτε. Το διαπιστευτήριό
σας το κρατά το `cc_server` σας, με κλειδί το αναγνωριστικό χρήστη σας, και κάθε
συσκευή από την οποία συνδέεστε το χρησιμοποιεί — επιφάνεια εργασίας, web και
τηλέφωνο. Άλλο μέλος του ίδιου διακομιστή δεν μπορεί να το διαβάσει, και η
σύνδεσή του είναι κάτι που το κάνει το ίδιο.
:::

## Σύνδεση με GitHub

Μια **ροή με κωδικό συσκευής**: το GitHub σας δείχνει έναν σύντομο κωδικό, τον
εγκρίνετε στο github.com και ο διακομιστής παραλαμβάνει το διαπιστευτήριο — χωρίς
URL επανάκλησης, χωρίς θύρα, τίποτα να εκτεθεί. Διαθέσιμη όποτε ο διακομιστής έχει
client id, τον οποίο φέρνει ήδη μια επίσημη έκδοση.

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Προφίλ και ταυτότητα → Φιλοξενία κώδικα** (ή στο πρώτο
   βήμα της εισαγωγής)
2. Στη γραμμή **GitHub**, πατήστε **Σύνδεση με GitHub**
3. Ένα παράθυρο διαλόγου εμφανίζει έναν κωδικό οκτώ χαρακτήρων και ανοίγει το
   [github.com/login/device](https://github.com/login/device) στο πρόγραμμα περιήγησής σας.
   Ο κωδικός βρίσκεται ήδη στο πρόχειρό σας
4. Επικολλήστε τον, εγκρίνετε την εφαρμογή και επιστρέψτε. Η γραμμή αλλάζει από
   μόνη της σε «Συνδεθήκατε ως _your-username_»

Το παράθυρο διαλόγου μπορεί να κλείσει όσο ολοκληρώνετε τη διαδικασία στο πρόγραμμα
περιήγησης — ο διακομιστής συνεχίζει να ερωτά μέχρι να λήξει ο κωδικός (περίπου 15
λεπτά), οπότε η σύνδεση ολοκληρώνεται κανονικά.

## Ή επικολλήστε ένα token

Η εφεδρική λύση όταν ο διακομιστής δεν έχει εφαρμογή, όταν η εφαρμογή δεν είναι
εγκατεστημένη σε λογαριασμό που χρειάζεστε ή όταν απλώς προτιμάτε να
χρησιμοποιήσετε ένα PAT.

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Προφίλ και ταυτότητα → Φιλοξενία κώδικα**
2. Στη γραμμή **GitHub**, πατήστε **Προσθήκη token**
3. Επικολλήστε ένα token με `repo` και `read:org` (classic) και αποθηκεύστε. Ένα
   **εκλεπτυσμένο** token χρειάζεται **Contents** και **Pull requests** (ανάγνωση και
   εγγραφή) στο αποθετήριο, καθώς και **Checks** και **Actions** (ανάγνωση).

Το token ελέγχεται τη στιγμή που αποθηκεύεται, οπότε η γραμμή μπορεί να ονομάσει τον
λογαριασμό στον οποίο ανήκει. Πατήστε **Αποσύνδεση** για να το αφαιρέσετε.

Σημείο ελέγχου: η γραμμή **GitHub** γράφει «Συνδεθήκατε ως _your-username_». Ένα
επίθεμα ονομάζει την πηγή όταν το διαπιστευτήριο που απαντά δεν είναι δικό σας —
«μέσω της εφαρμογής αυτού του διακομιστή» ή «από το περιβάλλον».

:::note[Η σειρά προτεραιότητας είναι σταθερή]
Ένα αίτημα που γίνεται για λογαριασμό σας χρησιμοποιεί το **δικό σας** διαπιστευτήριο
και τίποτα άλλο — το περιβάλλον είναι το διαπιστευτήριο του διακομιστή, όχι το δικό
σας, οπότε δεν σας αναπληρώνει ποτέ. Η εργασία χωρίς άνθρωπο πίσω της (webhooks,
περιοδικός έλεγχος PR, συγχρονισμός εισιτηρίων) χρησιμοποιεί την ταυτότητα εφαρμογής
του διακομιστή και μετά, κατά σειρά, το διαπιστευτήριο του ιδιοκτήτη του διακομιστή
και το περιβάλλον.
:::

## Τι σας προσφέρει η ενσωμάτωση

| Δυνατότητα             | Πώς                                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| Λίστα και λεπτομέρειες PR  | Το GitHub REST API, από τον διακομιστή, με την ταυτότητα της εφαρμογής ή το δικό σας διαπιστευτήριο                              |
| Εκτελέσεις ελέγχων          | Το GitHub Checks API                                                                                          |
| Δημοσίευση ανασκόπησης   | Ένα βήμα που το ελέγχει ο χρήστης και αναρτά την ανασκόπησή σας στο PR                                                             |
| Καταχώριση αποθετηρίου   | Ένα checkout γίνεται δεκτό αν το απομακρυσμένο `origin` του δείχνει στο github.com — ή στο gitlab.com / bitbucket.org          |
| Πρόσβαση πράκτορα στο GitHub | Ο μεσίτης διαπιστευτηρίων εγχέει το token ως `GH_TOKEN` / `GITHUB_TOKEN`, φραγμένο από τις δυνατότητες του πράκτορα      |
| Σήματα ειδοποιήσεων  | Ένας περιοδικός έλεγχος στην πλευρά του διακομιστή των εισερχομένων ειδοποιήσεων του GitHub σας εγείρει «Αναφορά σε pull request» και «Ζητήθηκε ανασκόπηση» |
| Προφίλ χρηστών       | Κάρτες προφίλ στο hover και φιλτράρισμα PR ανά συντάκτη                                                                |

Ορισμένες διαδρομές χρησιμοποιούν το GraphQL API αντί για το REST όπου είναι
φθηνότερο — τη δραστηριότητα κλάδων για τον επιλογέα σύνταξης PR και τη ζωντανή
κατάσταση ανασκόπησης που αποφασίζει αν μια ειδοποίηση αιτήματος ανασκόπησης
εκκρεμεί ακόμη.

## Προσέξτε τις διακοπές του GitHub

Η γραμμή τίτλου εμφανίζει ένα σήμα κατάστασης όταν ένας πάροχος είναι
υποβαθμισμένος, καλύπτοντας τα GitHub, Claude, OpenAI και Kimi. **Κρύβεται όσο όλα
είναι υγιή** — η παρουσία αναφέρει πρόβλημα, όχι η απουσία της.

Πατήστε το σήμα για να ανοίξει ένα αναδυόμενο πλαίσιο με την κατάσταση κάθε παρόχου
και ένα κουμπί ανανέωσης. Οι καταστάσεις ανανεώνονται από μόνες τους κάθε δύο λεπτά.

## Μάθετε πώς ενεργούν οι πράκτορες στο GitHub

- Ένας πράκτορας παίρνει token GitHub μόνο αν έχει **Να επιτρέπονται κλήσεις GitHub API** ή
  **Να επιτρέπεται git push**. Δείτε
  [Ρύθμιση πολιτικών sandbox](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/πολιτικές-sandbox/)
- Τα commits που κάνει ένας πράκτορας συντάσσονται **ως ο πράκτορας** — το
  εμφανιζόμενο όνομα συν ` (agent)`, σε συνθετική διεύθυνση με κλειδί το αναγνωριστικό
  του πράκτορα — ποτέ ως άνθρωπος. Το άτομο που το ζήτησε πιστώνεται με ένα trailer
  `Co-Authored-By`
- Με ρυθμισμένη GitHub App, ο μεσίτης εκδίδει εκλεπτυσμένα token εγκατάστασης με
  εμβέλεια αποθετηρίου και διάρκεια περίπου μίας ώρας ανά εκκίνηση, αντί να
  παραδώσει ένα ευρύ token. Η εγκατάσταση επιλύεται από τον **ιδιοκτήτη** του
  αποθετηρίου της εκτέλεσης, οπότε μια εφαρμογή εγκατεστημένη σε πολλούς λογαριασμούς
  περιορίζεται σωστά σε όποιον αγγίζει η εκτέλεση. Χωρίς εφαρμογή, οι πράκτορες
  λαμβάνουν το token του περιβάλλοντος
- Μια εκτέλεση που τη ζήτησε μέλος το οποίο έχει συνδεθεί ενεργεί με την ταυτότητα
  GitHub **αυτού του μέλους** — το διαπιστευτήριό του συγχωνεύεται μετά το περιβάλλον
  του μεσίτη, οπότε ένα commit ή σχόλιο που κάνει ένας πράκτορας για αυτό το μέλος του
  αποδίδεται

## Αντιμετώπιση προβλημάτων

### Η λίστα PR είναι κενή και λέει ότι το GitHub δεν είναι συνδεδεμένο

Δεν έχετε διαπιστευτήριο GitHub σε αυτόν τον διακομιστή. Συνδεθείτε ή επικολλήστε ένα
token στη **Φιλοξενία κώδικα**. Τα αποθετήρια σε άλλα forge δεν επηρεάζονται — μόνο
τα αποθετήρια του GitHub δεν συνεισφέρουν τίποτα.

### Η γραμμή προσφέρει «Προσθήκη token» αλλά όχι «Σύνδεση με GitHub»

Ο διακομιστής δεν έχει client id — κάτι που είναι η κανονική κατάσταση για μια έκδοση
από πηγαίο κώδικα, αφού τα διαπιστευτήρια ενσωματώνονται μόνο στις επίσημες εκδόσεις.
Δείτε [Δημιουργία της GitHub App](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/github-app/): διαρκεί περίπου δύο λεπτά
και μόνο ο ιδιοκτήτης του διακομιστή χρειάζεται να το κάνει, μία φορά.

### Το παράθυρο σύνδεσης λέει ότι ο πάροχος δεν επέστρεψε κωδικό συσκευής

Η GitHub App υπάρχει αλλά το πλαίσιο ελέγχου **Device flow** είναι ανενεργό.
Ενεργοποιήστε το στις ρυθμίσεις της εφαρμογής (General → Device flow) και δοκιμάστε
ξανά.

### Η γραμμή λέει «μέσω της εφαρμογής αυτού του διακομιστή» ενώ περίμενα τον δικό μου λογαριασμό

Δεν έχετε συνδεθεί· αυτό που βλέπετε είναι η ταυτότητα εφαρμογής του διακομιστή να
απαντά. Πατήστε **Σύνδεση με GitHub** σε αυτή τη γραμμή.

### Ένα εκλεπτυσμένο PAT δεν εμφανίζει κουμπί συγχώνευσης ή κατάσταση ελέγχου

Το token χρειάζεται **Contents** και **Pull requests** (ανάγνωση και εγγραφή), καθώς
και **Checks** και **Actions** (ανάγνωση). Αφού το αλλάξετε, επικολλήστε το ξανά στη
Φιλοξενία κώδικα.

### Η προσθήκη αποθετηρίου απορρίπτεται

Η καταχώριση απαιτεί και τα τρία: η διαδρομή βρίσκεται μέσα σε ένα δέντρο εργασίας
git, υπάρχει απομακρυσμένο `origin` και αυτό το απομακρυσμένο δείχνει σε ένα
υποστηριζόμενο forge (github.com, gitlab.com ή bitbucket.org). Δείτε
[Προσθήκη αποθετηρίων σε χώρο εργασίας](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/προσθήκη-αποθετηρίων/).

### Όλα σταματούν να λειτουργούν για λίγο μετά από εντατική χρήση

Αυτός είναι ο διακόπτης κυκλώματος του ορίου ρυθμού. Το GitHub σηματοδοτεί το κύριο
όριό του με ένα `403` που φέρει `x-ratelimit-remaining: 0` και χρόνο επαναφοράς· όταν
δει ένα τέτοιο, ο πελάτης αποτυγχάνει περαιτέρω αιτήματα τοπικά χωρίς κλήση δικτύου
μέχρι να περάσει το παράθυρο, ώστε μια καταιγίδα επαναλήψεων να μην μπορεί να βαθύνει
το όριο. Οι παροδικές αποτυχίες επαναλαμβάνονται έως τρεις φορές με εκθετική
υποχώρηση, τηρώντας το `retry-after`.
