Επικολλήστε ένα κλειδί API του Linear στον διακομιστή, συνδεδεμένο με τον χρήστη
σας, όπως ακριβώς συνδέετε έναν κεντρικό υπολογιστή κώδικα. Τα εισιτήρια, τα
έργα, οι σύνδεσμοι, οι συνεργάτες, η ανάθεση και ο ορισμός ανατεθειμένου
λειτουργούν όλα με τη βάση δεδομένων του ίδιου του Control Center, χωρίς να
απαιτείται εξωτερική υπηρεσία — δείτε τη
[Δημιουργία και διαχείριση εισιτηρίων](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/διαχείριση-εισιτηρίων/).

## Αποθήκευση του κλειδιού Linear

Το **Κλειδί API εισιτηρίων** βρίσκεται στις **Ρυθμίσεις → Χώρος εργασίας →
Γενικά**, στην κάρτα **Εισιτήρια**. Αποθηκεύει το κλειδί στον διακομιστή με βάση
το αναγνωριστικό χρήστη σας. Το δικό του κλειδί του διακομιστή για εργασία χωρίς
ανθρώπινη παρουσία προέρχεται από το `LINEAR_API_KEY` ή την κάρτα **Εφαρμογές
παρόχων**. Κανένα κλειδί εισιτηρίων δεν τοποθετείται στο sandbox ενός πράκτορα:
οι πράκτορες γράφουν εισιτήρια μέσω των δικών του εργαλείων του Control Center,
που ρωτούν πρώτα τον κανόνα **Εγγραφή σε εξωτερικό tracker**.

## Σήμανση των νέων εισιτηρίων ως Linear

Ο **Πάροχος εισιτηρίων** (το πρώτο βήμα της αρχικής διαμόρφωσης, και το
`/workspaces/<workspaceId>/api-keys`) προσφέρει `local` και `linear`. Αν
επιλέξετε `linear`, από εκεί και πέρα όσα εισιτήρια δημιουργείτε σημαίνονται με
`provider: linear`.
