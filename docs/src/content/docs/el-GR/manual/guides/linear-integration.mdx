Το Linear έχει δύο ταυτότητες στο Control Center, και οι δύο είναι συνδέσεις μέσω
προγράμματος περιήγησης: τη δική σας, για ό,τι κάνετε εσείς, και την εφαρμογή
Control Center του χώρου εργασίας, για ό,τι κάνουν οι πράκτορες και τα pipelines.
Τα εισιτήρια, τα έργα, οι σύνδεσμοι, οι συνεργάτες, η ανάθεση και η εκχώρηση
λειτουργούν όλα πάνω στη βάση δεδομένων του ίδιου του Control Center χωρίς να
απαιτείται εξωτερική υπηρεσία — δείτε τη [Δημιουργία και διαχείριση εισιτηρίων](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/διαχείριση-εισιτηρίων/).

## Προϋποθέσεις

- Ο διακομιστής μπορεί να συνδέει ανθρώπους στο Linear: μέσω του Control Center
  Connect ή με τη δική του εφαρμογή Linear
  ([Καταχώριση της δικής σας εφαρμογής Linear](#καταχώριση-της-δικής-σας-εφαρμογής-linear)).
  Ο ιδιοκτήτης του διακομιστή επιλέγει στις **Ρυθμίσεις → Διακομιστής → Ενιαία
  σύνδεση**
- Ένας διαχειριστής χώρου εργασίας, για να επιλέξει το Linear ως πάροχο
  εισιτηρίων και να συνδέσει την αυτοματοποίηση Linear

## Επιλογή του Linear για τον χώρο εργασίας

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Γενικά** και βρείτε την κάρτα
   **Εισιτήρια**
2. Ορίστε τον **Πάροχο εισιτηρίων** σε **Linear**

Τα εισιτήρια που δημιουργείτε από εκεί και πέρα σημαίνονται με `provider: linear`.
Το **Τοπικό** κρατά τα εισιτήρια στη δική βάση δεδομένων αυτού του διακομιστή και
κρύβει τις γραμμές Linear: δεν υπάρχει τίποτα για αυθεντικοποίηση.

## Σύνδεση στο Linear

Στην ίδια κάρτα, η γραμμή **Linear** είναι δική σας:

1. Κάντε κλικ στο **Σύνδεση στο Linear**
2. Εγκρίνετε στο πρόγραμμα περιήγησης
3. Με τη δική εφαρμογή του διακομιστή, το παράθυρο διαλόγου το αντιλαμβάνεται από
   μόνο του. Μέσω του Connect, πληκτρολογήστε τον κωδικό 8 χαρακτήρων που δείχνει
   το πρόγραμμα περιήγησης ή αφήστε το να ανοίξει το Control Center μέσω του
   συνδέσμου `control-center://`

Ό,τι κάνετε στο Linear από το Control Center εκτελείται με αυτή τη σύνδεση και
τίποτε άλλο. Αν δεν έχετε συνδεθεί, η εφαρμογή σας ζητά να συνδεθείτε αντί να
ενεργήσει ως κάποιος άλλος.

## Σύνδεση της αυτοματοποίησης Linear

Η γραμμή **Αυτοματοποίηση Linear** είναι η εφαρμογή Control Center του χώρου
εργασίας στο Linear. Ο συγχρονισμός εισιτηρίων, τα pipelines και οι πράκτορες
γράφουν με αυτήν, οπότε τα αυτοματοποιημένα issues και σχόλια εμφανίζονται ως
Control Center και όχι ως κάποιο πρόσωπο.

1. Ένας διαχειριστής χώρου εργασίας κάνει κλικ στο **Σύνδεση του Linear για
   αυτοματοποίηση**
2. Εγκρίνει την εφαρμογή για τον χώρο εργασίας Linear στο πρόγραμμα περιήγησης,
   όπως παραπάνω

Η γραμμή τότε εμφανίζει «Συνδέθηκε με _τον χώρο εργασίας σας στο Linear_». Μόνο
οι διαχειριστές του χώρου εργασίας μπορούν να τη συνδέσουν ή να την αποσυνδέσουν.

Κανένα διαπιστευτήριο Linear δεν τοποθετείται στο sandbox ενός πράκτορα: οι
πράκτορες γράφουν εισιτήρια μέσω των εργαλείων του ίδιου του Control Center, τα
οποία ρωτούν πρώτα τον κανόνα **Εγγραφή σε εξωτερικό tracker**.

## Καταχώριση της δικής σας εφαρμογής Linear

Χρησιμοποιήστε τη δική σας εφαρμογή όταν επιλέξατε **Χρήση των δικών μου
εφαρμογών**. Η εφαρμογή του διακομιστή ισχύει μόνο σε αυτήν την περίπτωση: με το Control Center ή ένα δικό σας Connect, το Connect εκτελεί κάθε λωρίδα, και το Linear περιλαμβάνεται, ενώ η εφαρμογή του διακομιστή και το κλειδί API υπηρεσίας μένουν αποθηκευμένα αλλά αχρησιμοποίητα. Μια εφαρμογή του χώρου εργασίας ([παρακάτω](#δώστε-σε-έναν-χώρο-εργασίας-τη-δική-του-εφαρμογή-linear)) ισχύει πάντα, σε κάθε λειτουργία.

1. Δημιουργήστε μια εφαρμογή OAuth στο
   [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new)
2. Προσθέστε αυτούσια και τα δύο URL επιστροφής κλήσης που δείχνουν οι
   **Ρυθμίσεις → Διακομιστής → Ενιαία σύνδεση → Εφαρμογές παρόχων → Linear** στο
   **URL επιστροφής κλήσης**: `<server origin>/oauth/linear/callback` και
   `<server origin>/oauth/linear_app/callback`
3. Επικολλήστε το **Client id** στο τμήμα Linear

Δεν υπάρχει client secret: ο διακομιστής συνδέεται με PKCE. Τα refresh tokens του
Linear λήγουν μετά από 30 ημέρες αχρησίας, οπότε ο διακομιστής ανανεώνει μία φορά
την ημέρα κάθε σύνδεση Linear παλαιότερη των 20 ημερών.

Το ίδιο τμήμα δέχεται ένα προαιρετικό **Κλειδί API υπηρεσίας**. Είναι το δικό
διαπιστευτήριο Linear του διακομιστή για αυτοματοποίηση σε χώρους εργασίας που
δεν έχουν συνδέσει αυτοματοποίηση Linear. Κρατήστε το στις **Ρυθμίσεις** ή στο
αρχείο `.env` του διακομιστή ως `LINEAR_API_KEY`: ο διακομιστής αρνείται να
εκκινήσει όταν το `LINEAR_API_KEY` είναι εξαγόμενο στο περιβάλλον της διεργασίας
του.

## Δώστε σε έναν χώρο εργασίας τη δική του εφαρμογή Linear

Ένας χώρος εργασίας μπορεί να συνδέεται στο Linear μέσω δικής του εφαρμογής αντί για αυτήν του διακομιστή. Μόνο ένας διαχειριστής ή ο ιδιοκτήτης του χώρου εργασίας μπορεί να το ρυθμίσει.

1. Δημιουργήστε μια εφαρμογή OAuth του Linear όπως περιγράφεται παραπάνω
2. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Γενικά → Εφαρμογές παρόχων** και ανοίξτε το **Linear**
3. Επιλέξτε **Χρήση της δικής του εφαρμογής του χώρου εργασίας**
4. Προσθέστε στην εφαρμογή Linear, αυτούσιες, και τις δύο διευθύνσεις URL επιστροφής κλήσης που δείχνει η γραμμή κάτω από **URL επιστροφής κλήσης**
5. Επικολλήστε το **Client id** της και, προαιρετικά, ένα **Κλειδί API υπηρεσίας** για την αυτοματοποίηση αυτού του χώρου εργασίας

Η εφαρμογή του χώρου εργασίας απαντά τότε σε κάθε σύνδεση και αίτημα αυτοματοποίησης του Linear σε αυτόν τον χώρο εργασίας, όποιον τρόπο κι αν χρησιμοποιεί ο διακομιστής για να συνδέει τα άτομα. Δεν καταφεύγει ποτέ στην εφαρμογή του διακομιστή ή στο Connect: μέχρι να οριστεί client id, το Linear είναι απενεργοποιημένο σε αυτόν τον χώρο εργασίας και η γραμμή λέει τι λείπει. Το κλειδί API υπηρεσίας του χρησιμοποιείται μόνο εδώ· χωρίς αυτό, ο συγχρονισμός χρειάζεται το **Σύνδεση του Linear για αυτοματοποίηση**.

Η εναλλαγή ανάμεσα στην εφαρμογή του διακομιστή και στην εφαρμογή του χώρου εργασίας, ή η αλλαγή του client id του χώρου εργασίας, αποσυνδέει όλους τους χρήστες αυτού του χώρου εργασίας από το Linear και αποσυνδέει την αυτοματοποίησή του. Συνδέονται ξανά μέσω της νέας εφαρμογής. Το **Χρήση της εφαρμογής του διακομιστή** διαγράφει τα αποθηκευμένα πεδία του χώρου εργασίας. Τα μυστικά είναι μόνο για εγγραφή: η γραμμή δείχνει μόνο αν έχει αποθηκευτεί κάποιο. Οι άλλοι χώροι εργασίας του διακομιστή δεν επηρεάζονται.

## Αντιμετώπιση προβλημάτων

### Η γραμμή Linear λέει ότι η σύνδεση δεν έχει ρυθμιστεί

Ο διακομιστής δεν έχει ούτε δική του εφαρμογή Linear ούτε Connect. Ο ιδιοκτήτης
του διακομιστή επιλέγει ένα από τα δύο στις **Ρυθμίσεις → Διακομιστής → Ενιαία
σύνδεση**. Όταν ο χώρος εργασίας χρησιμοποιεί τη δική του εφαρμογή, η γραμμή λέει αντ’ αυτού ότι η ρύθμισή του δεν έχει ολοκληρωθεί: ένας διαχειριστής του χώρου εργασίας προσθέτει το client id στις **Ρυθμίσεις → Χώρος εργασίας → Γενικά → Εφαρμογές παρόχων**.

### Ο συγχρονισμός εισιτηρίων αποτυγχάνει με σφάλμα αυθεντικοποίησης

Ο χώρος εργασίας δεν έχει συνδεδεμένη αυτοματοποίηση Linear και ο διακομιστής δεν
έχει κλειδί API υπηρεσίας, οπότε ο συγχρονισμός δεν έχει διαπιστευτήριο. Ένας
διαχειριστής χώρου εργασίας κάνει κλικ στο **Σύνδεση του Linear για
αυτοματοποίηση**.

### Η σύνδεση της αυτοματοποίησης λέει ότι ο χώρος εργασίας Linear είναι συνδεδεμένος αλλού

Η εφαρμογή Control Center εκείνου του χώρου εργασίας Linear είναι ήδη συνδεδεμένη
με άλλον διακομιστή Control Center.
