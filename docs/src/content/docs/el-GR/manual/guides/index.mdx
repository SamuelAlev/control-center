Each guide solves **one problem for someone who already knows their way around**. They
assume you have Control Center installed and a workspace set up, they state a goal in
the title and they stop when the goal is met.

If you are still learning the product, start with the [tutorials](/el-GR/εγχειρίδιο/οδηγοί/).
If you want to understand _why_ something behaves the way it does, read the
[concepts](/el-GR/εγχειρίδιο/έννοιες/).
