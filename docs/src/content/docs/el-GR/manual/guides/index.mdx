Κάθε οδηγός λύνει **ένα πρόβλημα για κάποιον που ξέρει ήδη να κινείται**. Προϋποθέτει
ότι έχετε εγκαταστήσει το Control Center και έχετε στήσει έναν χώρο εργασίας,
διατυπώνει έναν στόχο στον τίτλο και σταματά μόλις επιτευχθεί ο στόχος.

Αν μαθαίνετε ακόμη το προϊόν, ξεκινήστε με τους [οδηγούς](/el-GR/εγχειρίδιο/οδηγοί/).
Αν θέλετε να καταλάβετε _γιατί_ κάτι συμπεριφέρεται όπως συμπεριφέρεται, διαβάστε τις
[έννοιες](/el-GR/εγχειρίδιο/έννοιες/).
