Αυτός ο οδηγός δείχνει πώς να προσθέσετε έναν πράκτορα σε έναν χώρο εργασίας και να τον ρυθμίσετε ώσπου να μπορεί πραγματικά να εκτελεστεί.

Κάθε χώρος εργασίας εφοδιάζεται εξ αρχής με πέντε πράκτορες — έναν CEO και τους `qa`, `architect`, `engineer` και `librarian` — οπότε συνήθως έχετε ήδη πράκτορες πριν ρυθμίσετε κανέναν. Τα παρακάτω βήματα ισχύουν εξίσου για έναν πράκτορα που υπάρχει ήδη και για έναν νέο.

## Πριν ξεκινήσετε

- Βρίσκεστε μέσα σε έναν χώρο εργασίας. Όλη η επιφάνεια βρίσκεται στις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες** (`/settings/workspace/agents`).
- Ο πράκτορας θα χρειαστεί backend. Συνδέστε έναν πάροχο για το ενσωματωμένο harness στις **Ρυθμίσεις → Διακομιστής → Πάροχοι μοντέλων**, ή εγκαταστήστε το CLI του Claude Code στο μηχάνημα που φιλοξενεί το `cc_server`.
- Αν θέλετε ο πράκτορας να φέρει δεξιότητες, εγκαταστήστε τις πρώτα στις **Ρυθμίσεις → Χώρος εργασίας → Δεξιότητες**. Η φόρμα του πράκτορα σας αφήνει να ενεργοποιείτε μόνο δεξιότητες που υπάρχουν ήδη στον χώρο εργασίας.

## Προσθέστε τον πράκτορα

1. Ανοίξτε τις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες**.
2. Κάντε κλικ στο **Νέος πράκτορας**.

Δεν υπάρχει παράθυρο διαλόγου ούτε επιλογέας ρόλου. Δημιουργείται αμέσως ένας πράκτορας με το όνομα «Ανώνυμος πράκτορας» και επιλέγεται στο τμήμα λεπτομερειών στα δεξιά.

Θα πρέπει τώρα να βλέπετε τον πράκτορα «Ανώνυμος πράκτορας» στον κατάλογο στα αριστερά, με την καρτέλα **Ρυθμίσεις** του τμήματος λεπτομερειών του ανοιχτή και ένα πεδίο **Όνομα** που περιέχει «Ανώνυμος πράκτορας».

## Δώστε του όνομα

- **Όνομα** — το σύντομο αναγνωριστικό που χρησιμοποιείται στις @-αναφορές, για παράδειγμα `alice`. Η ανάλυση των αναφορών αντιστοιχίζει το `@` που ακολουθείται από χαρακτήρες λέξης, οπότε ένα όνομα που περιέχει παύλα, τελεία ή κενό δεν μπορεί ποτέ να αναφερθεί.
- **Τίτλος** — η ετικέτα για ανθρώπινη ανάγνωση, για παράδειγμα «Έμπειρος προγραμματιστής».
- **Προτροπή συστήματος** — προαιρετικές πρόσθετες οδηγίες, που εγχέονται ως ενότητα Agent instructions· δεν αντικαθιστούν το υπόλοιπο συναρμολογημένο μήνυμα προτροπής.

Κάντε κλικ στην **Αποθήκευση αλλαγών** στο κάτω μέρος της φόρμας. Κάθε πεδίο αυτής της σελίδας αποθηκεύεται με αυτό το ένα κουμπί.

## Δώστε του προσαρμογέα και μοντέλο

Το αναπτυσσόμενο μενού **Προσαρμογέας** απαριθμεί τους εκτελεστές που διαθέτει πραγματικά το μηχάνημα του διακομιστή. Ο ενσωματωμένος προσαρμογέας βρίσκεται πάντα (είναι ο διακομιστής). Το Claude Code εμφανίζεται μόνο όταν το CLI του εντοπίστηκε σε αυτό το μηχάνημα:

| Προσαρμογέας              | Backend                                                  |
| ------------------------- | -------------------------------------------------------- |
| Control Center (built-in) | Ο βρόχος πράκτορα εντός διεργασίας — χωρίς εξωτερικό CLI |
| Claude Code               | `claude -p --output-format stream-json`                  |

Μόνο ο ενσωματωμένος προσαρμογέας επιβάλλει λειτουργίες, καθοδήγηση, παύση/συνέχεια, συμβόλαια ολοκλήρωσης και υποπράκτορες. Το Claude Code δεν σας παρέχει κανένα από αυτά. Το Cursor, το Codex και οι άλλοι πάροχοι μοντέλων προσαρτώνται στον ενσωματωμένο προσαρμογέα και όχι ως ξεχωριστοί εκτελεστές.

:::note[Ένας κενός προσαρμογέας σημαίνει τον ενσωματωμένο βρόχο]
Ένας πράκτορας του οποίου ο προσαρμογέας δεν έχει οριστεί αποστέλλεται στο **Control Center (built-in)**, τον βρόχο μέσα στον διακομιστή, οπότε δεν χρειάζεται να εγκατασταθεί τίποτα στο μηχάνημα. Εφόσον δεν έχει οριστεί ούτε μοντέλο, ζητά από την Anthropic την προεπιλογή της, οπότε ένας πράκτορας χωρίς καμία απολύτως ρύθμιση εκτελείται μόνο αν έχετε συνδέσει λογαριασμό Anthropic. Οι ειδικοί του αρχικού εφοδιασμού δεν συνοδεύονται από κανένα από τα δύο· ορίστε και τα δύο σε κάθε πράκτορα που σκοπεύετε να χρησιμοποιήσετε.
:::

Το αναπτυσσόμενο μενού **Μοντέλο** καθοδηγείται από τον προσαρμογέα που επιλέξατε. Για τον ενσωματωμένο προσαρμογέα, η λίστα αντλείται ζωντανά από τους παρόχους που έχετε συνδέσει στις **Ρυθμίσεις → Διακομιστής → Πάροχοι μοντέλων**, οπότε ένας πάροχος χωρίς αποθηκευμένο διαπιστευτήριο συνεισφέρει μηδέν μοντέλα.

## Προσθέστε δεξιότητες

Οι **Δεξιότητες** είναι ένας επιλογέας chip πάνω από τα πακέτα δεξιοτήτων που είναι εγκατεστημένα σε αυτόν τον χώρο εργασίας. Πατήστε ένα chip για να το εναλλάξετε· το σύμβολο ελέγχου σημειώνει τα επιλεγμένα. Αν ο χώρος εργασίας δεν έχει δεξιότητες, το πεδίο εμφανίζει «No skills available. Create skills in Settings → Skills first.»

Δεν επιλέγετε εδώ τις δεξιότητες του ίδιου του αποθετηρίου. Ένα αποθετήριο που τις παρέχει (στο `.agents/skills/`, `.claude/skills/` ή `.opencode/skills/`) τις συνεισφέρει αυτόματα σε όποιον πράκτορα εργάζεται σε αυτό το αποθετήριο, και αντικαθίστανται όταν μετακινηθεί σε άλλο — δείτε [Δεξιότητες ανά αποθετήριο](/el-GR/εγχειρίδιο/έννοιες/μοντέλο-πρακτόρων/#repo-scoped-skills).

## Ορίστε τη γραμμή αναφοράς και την περσόνα

- **Αναφέρεται σε** — επιλέξτε έναν άλλον πράκτορα με το όνομά του. Αυτό χτίζει το δέντρο αναφορών που εμφανίζει το κουμπί **Οργανόγραμμα** στην κεφαλίδα της σελίδας. Δεν είναι ο κατάλογος που χρησιμοποιεί ένας επικεφαλής ομάδας όταν αναθέτει — αυτός προέρχεται από τα μέλη της ομάδας και τις δεξιότητές τους.
- **Περσόνα** — ελεύθερο κείμενο που διαμορφώνει τον τόνο και τη συμπεριφορά, για παράδειγμα: «Προτιμά απλές, ευανάγνωστες λύσεις. Γράφει τεστ για κάθε νέο κώδικα.»

## Ρυθμίστε την εκτέλεση

- **Προσπάθεια συλλογισμού** — οι επιλογές προέρχονται από τα δικά του δημοσιευμένα επίπεδα του επιλεγμένου μοντέλου: Low / Medium / High, συν Extra High στα μοντέλα τύπου OpenAI και Extra High + Max στα μοντέλα τύπου Claude. Το πεδίο κρύβεται εντελώς όταν το επιλεγμένο μοντέλο δεν δηλώνει επίπεδα σκέψης και προεπιλέγεται η προεπιλογή του ίδιου του μοντέλου.
- **Μέγεθος παραθύρου πλαισίου** — προσυμπληρώνεται από το παράθυρο πλαισίου του μοντέλου κάθε φορά που αλλάζετε μοντέλο, με chips ενός αγγίγματος για την προεπιλογή του μοντέλου, 200k, 500k και 1M. Μια τιμή που πληκτρολογείτε αφού επιλέξετε το μοντέλο υπερισχύει μέχρι την επόμενη αλλαγή μοντέλου.
- **Χρονικό όριο σιωπής (λεπτά)** — τερματίζει μια εκτέλεση ύστερα από τόσο χρόνο χωρίς έξοδο. Αφήστε το κενό για να χρησιμοποιηθεί η προεπιλογή ανά λειτουργία.

## Παραχωρήστε δικαιώματα

Ένας πράκτορας δεν έχει δικούς του διακόπτες δικαιωμάτων. Το τι μπορεί να κάνει push, να ανοίξει, να συγχωνεύσει ή να φτάσει το ορίζουν οι κανόνες ενεργειών στις **Ρυθμίσεις → Χώρος εργασίας → Δικαιώματα πρακτόρων**, όπου ένας κανόνας μπορεί να περιοριστεί σε αυτόν τον πράκτορα. Από προεπιλογή, ένα push, ένα pull request, μια ανασκόπηση ή συγχώνευση και μια εγγραφή σε tracker σας ρωτούν πρώτα, το καθένα χωριστά, και η πρόσβαση στο δίκτυο επιτρέπεται.

Το token του GitHub του πράκτορα είναι πάντα μόνο για ανάγνωση. Ένα push περνά από το Control Center, που ρωτά τον κανόνα **Push σε απομακρυσμένο** πριν το προωθήσει. Δείτε τη [Ρύθμιση πολιτικών sandbox](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/πολιτικές-sandbox/) για το πώς κάθε κανόνας φτάνει σε μια εκτέλεση.

:::note[Οι κανόνες και το sandbox του λειτουργικού συστήματος είναι ξεχωριστά επίπεδα]
Οι κανόνες αποφασίζουν τι μπορεί να κάνει ένας πράκτορας· το sandbox του λειτουργικού συστήματος περιορίζει πού μπορούν οι διεργασίες του να διαβάζουν, να γράφουν και να συνδέονται. Το `cc_server` τυλίγει τις εκτελέσεις των πρακτόρων στο sandbox του κεντρικού υπολογιστή όπου αυτό υπάρχει — τα Windows δεν έχουν εγγενές backend, και τα Linux και WSL2 χρειάζονται `bwrap` και `socat`. Δείτε [Sandbox και ασφάλεια](/el-GR/εγχειρίδιο/έννοιες/sandbox-και-ασφάλεια/) για το πλήρες σύνολο των ορίων.
:::

## Επαληθεύστε ότι εκτελείται

1. Ανοίξτε τις **Ρυθμίσεις → Διακομιστής → Πάροχοι μοντέλων** και βεβαιωθείτε ότι ο προσαρμογέας που επιλέξατε αναφέρει εγκατεστημένη έκδοση και όχι «Δεν βρέθηκε». Κάντε κλικ στην **Ανανέωση** για επανανίχνευση — η ανίχνευση εκτελείται στο μηχάνημα που φιλοξενεί το `cc_server`, όχι στο μηχάνημα που κοιτάτε.
2. Ανοίξτε έναν χώρο με τον πράκτορα και στείλτε του ένα μήνυμα, ή κάντε του @-αναφορά μέσα σε έναν υπάρχοντα χώρο.
3. Επιστρέψτε στις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες**, επιλέξτε τον πράκτορα και ανοίξτε την καρτέλα **Αρχεία καταγραφής**. Θα πρέπει να εμφανιστεί μια εκτέλεση με σήμα κατάστασης, διάρκεια, ώρα έναρξης και τον προσαρμογέα που χρησιμοποίησε. Η **Προβολή** ανοίγει τη ροή συμβάντων αυτής της εκτέλεσης.

Αν δεν εμφανίζεται απολύτως καμία εκτέλεση, ακολουθήστε τη [Διάγνωση πράκτορα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/διάγνωση-πράκτορα/).

## Διαγράψτε έναν πράκτορα

Επιλέξτε τον στον κατάλογο. Στην καρτέλα **Ρυθμίσεις**, μετακινηθείτε στη **Ζώνη κινδύνου** στο κάτω μέρος της φόρμας και κάντε κλικ στη **Διαγραφή**.
