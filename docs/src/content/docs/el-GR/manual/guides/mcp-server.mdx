Αυτός ο οδηγός δείχνει πώς να συνδέσετε έναν εξωτερικό πελάτη MCP — το
Claude Code, έναν επεξεργαστή, το MCP Inspector — στον δικό του διακομιστή
εργαλείων του Control Center.

Το Control Center καταχωρεί **110** εργαλεία και τα εξυπηρετεί μέσω του Model
Context Protocol, στην έκδοση πρωτοκόλλου `2024-11-05`. Ολόκληρες οικογένειες
εργαλείων που ίσως περιμένετε απουσιάζουν: δεν υπάρχουν εργαλεία συσκέψεων ή
ημερολογίου, ούτε εργαλεία έργων.

## Βρείτε το τελικό σημείο

Η επιφάνεια MCP μοιράζεται τον κύριο ακροατή του `cc_server`. Δεν υπάρχει
ξεχωριστή θύρα MCP.

| Τελικό σημείο | Μέθοδος  | Σκοπός                                                    |
| ------------- | -------- | --------------------------------------------------------- |
| `/mcp`        | `POST`   | Μεταφορά Streamable HTTP — αυτήν χρησιμοποιεί ο πελάτης    |
| `/mcp`        | `DELETE` | Τερματισμός συνεδρίας                                     |
| `/sse`        | `GET`    | Ροή ειδοποιήσεων από τον διακομιστή                        |

Έτσι, μια προεπιλεγμένη τοπική εγκατάσταση βρίσκεται στο
`http://127.0.0.1:9030/mcp`.

1. Μεταβείτε στις **Ρυθμίσεις → Διακομιστής → Διακομιστές MCP**
2. Δείτε την κάρτα **Διακομιστής MCP** — δείχνει αν εκτελείται ή έχει διακοπεί
   και τη θύρα στην οποία ακούει

Η επιφάνεια είναι ενεργοποιημένη από προεπιλογή σε μια νέα εγκατάσταση, οπότε
ένας πελάτης loopback λειτουργεί χωρίς να χρειαστεί να πειράξετε ρυθμίσεις. Το
**Έναρξη με την εκκίνηση της εφαρμογής** ελέγχει αν θα επανέλθει μετά από
επανεκκίνηση· τα **Έναρξη** / **Διακοπή** είναι στοιχεία ελέγχου συνεδρίας που
δεν αλλάζουν αυτή την προτίμηση.

Ο διακομιστής δεσμεύει το loopback από προεπιλογή, οπότε το τελικό σημείο είναι
προσβάσιμο μόνο από το μηχάνημα στο οποίο εκτελείται το `cc_server`, εκτός αν
τον ξεκινήσατε με `--bind any`.

## Συνδέστε έναν πελάτη

Στρέψτε τον πελάτη σας στο τελικό σημείο Streamable HTTP. Η ακριβής μορφή της
διαμόρφωσης είναι θέμα του πελάτη σας· το URL είναι το ίδιο και στις δύο
περιπτώσεις.

```json
{
  "mcpServers": {
    "control-center": {
      "type": "http",
      "url": "http://127.0.0.1:9030/mcp"
    }
  }
}
```

### Claude Code

Το Claude Code δεν θα το διαβάσει από ένα `.mcp.json` ενός έργου — βάζει τους
διακομιστές MCP που ορίζονται σε επίπεδο έργου πίσω από ένα αίτημα έγκρισης που
ένα μη διαδραστικό `claude -p` δεν απαντά ποτέ. Περάστε τη διαμόρφωση ρητά:

```bash
claude --mcp-config /path/to/mcp.json --strict-mcp-config
```

Το `--strict-mcp-config` κάνει το Claude να χρησιμοποιεί μόνο αυτό το αρχείο,
ώστε ο ίδιος διακομιστής να μην εντοπίζεται και από το έργο και να μην
καταχωρίζεται δύο φορές.

Σημείο ελέγχου: ζητήστε από τον πελάτη να παραθέσει τα εργαλεία του. Θα πρέπει
να δείτε καταχωρήσεις `mcp__*` που καλύπτουν εισιτήρια, χώρους, μνήμη, γράφημα
κώδικα και έλεγχο.

## Παροχή MCP πέρα από τον τοπικό υπολογιστή

1. Στις **Ρυθμίσεις → Διακομιστής → Διακομιστές MCP**, στη γραμμή **Token
   ελέγχου ταυτότητας**, πατήστε **Ορισμός** και επικολλήστε ένα token
2. Στείλτε το ως `Authorization: Bearer <token>` σε κάθε αίτημα `POST /mcp`

Μια επιφάνεια χωρίς token απορρίπτει με 403 κάθε καλούντα που δεν προέρχεται
από loopback. Αυτή η συμπεριφορά αποτυγχάνει κλειστά εκ σχεδιασμού: το token
είναι αυτό που καθιστά δυνατή την παροχή εκτός τοπικού υπολογιστή.

Οι αλλαγές στο token εφαρμόζονται αμέσως στην ενεργή επιφάνεια — χωρίς
επανεκκίνηση.

:::note[Το `GET /sse` δέχεται το token στη συμβολοσειρά ερωτήματος]
Η ροή ειδοποιήσεων ελέγχεται ως προς το token όπως κάθε άλλη διαδρομή, αλλά ένα
`EventSource` του προγράμματος περιήγησης δεν μπορεί να στείλει κεφαλίδα
`Authorization` — έτσι το `/sse` δέχεται το token και ως `?token=<token>`. Χωρίς
token απαντά 401.
:::

## Περιορίστε κάθε κλήση σε έναν χώρο εργασίας

Κάθε εργαλείο που αγγίζει δεδομένα εμβέλειας χώρου εργασίας απαιτεί
`workspace_id` και μια κλήση χωρίς αυτό απορρίπτεται αντί να επιλυθεί με βάση
κάποιο «τρέχοντα» χώρο εργασίας:

```json
{
  "workspace_id": "acme",
  "title": "Fix login bug",
  "priority": "high"
}
```

Το id είναι αυτό που εμφανίζεται στο URL του προγράμματος περιήγησης ή της
εφαρμογής: `/workspaces/<workspace_id>/…`. Οι μόνες εξαιρέσεις είναι εργαλεία
που εκτείνονται πραγματικά σε πολλούς χώρους εργασίας, όπως το `list_workspaces`
και τα εργαλεία της ροής ειδήσεων — η ροή ειδήσεων είναι ανά χρήστη και ένας
πράκτορας δεν έχει δικό του χρήστη, οπότε αυτά τα εργαλεία λειτουργούν στις ροές
του ιδιοκτήτη του διακομιστή.

Τα εργαλεία με εμβέλεια αποθετηρίου ελέγχουν επιπλέον ότι το αποθετήριο είναι
συνδεδεμένο με αυτόν τον χώρο εργασίας.

## Μάθετε τι θα απορρίψει η επιφάνεια

- **Περιορισμός ανά λειτουργία.** Μια κλήση επιλύεται ως προς τη λειτουργία του
  χώρου του πράκτορα που καλεί, στην πλευρά του διακομιστή. Ένας πράκτορας σε
  λειτουργία μόνο για ανάγνωση δεν μπορεί να φτάσει σε εργαλείο εγγραφής
  παραλείποντας το `space_id` — η λειτουργία αναζητείται αντ’ αυτού από την
  ενεργή εκτέλεσή του.
- **Περιορισμοί ενεργειών.** Τα εργαλεία που μεταβάλλουν κατάσταση δηλώνουν τις
  κατηγορίες επιδράσεών τους και περνούν από την ίδια πολιτική που χρησιμοποιεί
  το υπόλοιπο προϊόν. Δείτε
  [Ρύθμιση περιορισμών](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/ρύθμιση-περιορισμών/).
- **Επιβεβαίωση.** Κάποια καταστρεπτικά εργαλεία συγκροτούν μια δομή
  επιβεβαίωσης που πρέπει να εγκριθεί πριν προχωρήσει η κλήση.

Ο πλήρης κατάλογος ανακοινώνεται στο `tools/list` χωρίς φραγή ανακάλυψης — ένας
εξωτερικός πελάτης MCP αρνείται να καλέσει εργαλείο που δεν βρίσκεται στην
προσωρινά αποθηκευμένη λίστα του, οπότε η απόκρυψη εργαλείων τα χαλάει αντί να
τα τακτοποιεί.

## Αντιμετώπιση προβλημάτων

### Ο πελάτης δεν βλέπει εργαλεία

- Ελέγξτε ότι η κάρτα **Διακομιστής MCP** δείχνει ότι εκτελείται
- Ελέγξτε ότι η θύρα ταιριάζει με τη θύρα του `cc_server` σας
- Στο Claude Code, ελέγξτε ότι περάσατε τα `--mcp-config` και
  `--strict-mcp-config`

### 403 από μηχάνημα που δεν είναι ο διακομιστής

Δεν έχει ρυθμιστεί token bearer. Ορίστε ένα και στείλτε το.

### Μια κλήση εργαλείου αποτυγχάνει με «Missing or invalid argument: workspace_id»

Προσθέστε το `workspace_id`. Δεν υπάρχει σιωπηρός χώρος εργασίας.

### Μια κλήση εργαλείου απορρίπτεται ως άγνωστη

Τα [Εργαλεία MCP](/el-GR/εγχειρίδιο/αναφορά/εργαλεία-mcp/) παραθέτουν τον
κατάλογο. Καλέστε το όνομα ακριβώς όπως εμφανίζεται εκεί.
