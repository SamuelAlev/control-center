Αυτός ο οδηγός δείχνει πώς να ρυθμίσετε τις ειδοποιήσεις και τι ελέγχει
πραγματικά κάθε ρύθμιση.

Οι ειδοποιήσεις φτάνουν σε δύο επιφάνειες. Το **κέντρο ειδοποιήσεων** — η
καμπάνα στη γραμμή τίτλου — διαβάζει μια διαρκή ροή ανά χώρο εργασίας στον
διακομιστή. Οι **αναδυόμενες ειδοποιήσεις του λειτουργικού συστήματος**
είναι ένα ξεχωριστό μονοπάτι, μόνο για υπολογιστές, που τροφοδοτείται από
ζωντανά πλαίσια που στέλνει ο διακομιστής.

:::note[Η έκδοση για web δεν εμφανίζει ειδοποιήσεις του λειτουργικού συστήματος]
Η διοχέτευση των αναδυόμενων ειδοποιήσεων χτίζεται μόνο από το bootstrap της
έκδοσης για υπολογιστές. Στο `app.usectrl.dev` δεν υπάρχουν αναδυόμενες
ειδοποιήσεις, ούτε ήχοι ειδοποιήσεων, ούτε περιβάλλοντα πανό — η καμπάνα και
το ιστορικό της εξακολουθούν να λειτουργούν, επειδή διαβάζουν τη ροή του
διακομιστή. Ο πελάτης για κινητά δεν έχει καθόλου επιφάνεια ειδοποιήσεων.
:::

## Ενεργοποίηση ή απενεργοποίηση κατηγοριών

1. Μεταβείτε στις **Ρυθμίσεις → Εσείς → Ειδοποιήσεις**
2. Αφήστε την επιλογή **Ενεργοποίηση ειδοποιήσεων** ενεργή
3. Ενεργοποιήστε ή απενεργοποιήστε τις κατηγορίες που θέλετε. Είναι ακριβώς δεκαεπτά:

| Κατηγορία                                | Ενεργοποιείται όταν                                                                          |
| ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| Ο πράκτορας ολοκλήρωσε                   | Ένας πράκτορας απάντησε σε μια εκτέλεση που ξεκινήσατε ή η εκτέλεση απέτυχε                  |
| Ένας πράκτορας σας περιμένει             | Ένας πράκτορας χρειάζεται την έγκρισή σας, σας έκανε μια ερώτηση ή έχει σταματήσει λόγω διαπιστευτηρίων |
| Το PR δημοσιεύτηκε                       | Ένας πράκτορας δημοσίευσε ένα PR                                                             |
| Το PR συγχωνεύθηκε                       | Ένα PR συγχωνεύθηκε                                                                          |
| Νέα μηνύματα                             | Κάποιος σας ανέφερε σε έναν χώρο                                                             |
| Αναφορά σε pull request                  | Ο έλεγχος ειδοποιήσεων του GitHub είδε ότι σας ανέφεραν σε ένα PR                           |
| Ζητήθηκε ανασκόπηση                      | Η ανασκόπησή σας ζητήθηκε πραγματικά για ένα PR που δεν είναι πρόχειρο                      |
| Η ανασκόπηση είναι παλιά                 | Νέα commits έφτασαν σε ένα pull request που έχετε ήδη ανασκοπήσει                           |
| Έτοιμο για συγχώνευση                    | Ένα pull request που συντάξατε έγινε συγχωνεύσιμο ή έπαψε να είναι                           |
| Αποφάσεις ανασκόπησης                    | Ένας ανασκοπητής ενέκρινε, ζήτησε αλλαγές ή απορρίφθηκε μια έγκριση                         |
| Έλεγχοι                                  | Το CI απέτυχε σε ένα pull request που συντάξατε ή ανέκαμψε                                  |
| Νήματα ανασκόπησης                       | Κάποιος απάντησε ή έκλεισε ένα νήμα στο οποίο συμμετέχετε                                   |
| Ανατέθηκε εισιτήριο                      | Ανατέθηκε ένα εισιτήριο                                                                      |
| Άλλαξε η κατάσταση εισιτηρίου            | Ένα εισιτήριο άλλαξε κατάσταση                                                               |
| Η σύσκεψη ξεκινά σύντομα                 | Μια σύσκεψη ημερολογίου βρίσκεται μέσα στο παράθυρο προειδοποίησής σας                      |
| Το ημερολόγιο αποσυνδέθηκε               | Το διακριτικό OAuth ενός συνδεδεμένου ημερολογίου έληξε                                     |
| Ενημερώσεις απομονωμένου περιβάλλοντος   | Ένα περίβλημα καταλήφθηκε, ανακτήθηκε ή απέτυχε                                             |

Οτιδήποτε εκτός αυτής της λίστας δεν μπορεί να ειδοποιήσει ούτε να
φιλτραριστεί — δεν υπάρχει κατηγορία «όλα τα άλλα».

Η ειδοποίηση **Ένας πράκτορας σας περιμένει** ενεργοποιείται μία φορά ανά
αναμονή, τη στιγμή που αυτή ξεκινά: μια εκκρεμής έγκριση (συμπεριλαμβανομένων
των αδειών εκτέλεσης στο sandbox και των εγκρίσεων εργαλείων του Claude Code),
μια ερώτηση `ask_user` ή μια εκτέλεση που έχει σταματήσει επειδή τα
διαπιστευτήριά της δεν μπορούν να την εξυπηρετήσουν. Ανοίγει τον χώρο όπου
απαντάτε και δεν εμφανίζεται όσο βλέπετε ήδη αυτόν τον χώρο.

Αυτές οι προτιμήσεις ακολουθούν τον χρήστη σας σε όλες τις συσκευές, ώστε το
τηλέφωνο και ο φορητός υπολογιστής να μένουν συγχρονισμένα. Η ένταση είναι η
σκόπιμη εξαίρεση και παραμένει ανά συσκευή.

## Ορισμός Quiet hours

1. Στην ίδια σελίδα, ενεργοποιήστε τις **Quiet hours**
2. Πληκτρολογήστε ώρα έναρξης και λήξης σε μορφή `HH:MM` (το προεπιλεγμένο παράθυρο είναι 22:00–08:00)

Κατά τις Quiet hours, οι μη επείγουσες ειδοποιήσεις απορρίπτονται — δεν μπαίνουν
σε ουρά για να εμφανιστούν αργότερα.

Δύο κατηγορίες είναι **επείγουσες** και φτάνουν πάντα, παρακάμπτοντας τις Quiet
hours _και_ τη λειτουργία εστίασης: **Η σύσκεψη ξεκινά σύντομα** και **Το PR
δημοσιεύτηκε**. Μια ειδοποίηση σύσκεψης που τη βλέπετε μόνο εκ των υστέρων
είναι άχρηστη — αυτός είναι ο λόγος.

## Επιλογή ήχου

1. Μετακινηθείτε στο **Ήχος ειδοποίησης**
2. Διαλέξτε έναν από τους έντεκα ενσωματωμένους ήχους ή **Κανένας**
3. Πατήστε το κουμπί δοκιμής για να τον ακούσετε και ρυθμίστε την ένταση με τον δείκτη

Η εφαρμογή αναπαράγει η ίδια τον ήχο· η ειδοποίηση του λειτουργικού συστήματος
παραδίδεται σιωπηλά, ώστε να μην τον ακούσετε δύο φορές.

## Ορισμός χρόνου προειδοποίησης για συσκέψεις

1. Μετακινηθείτε στο **Προειδοποίηση πριν**
2. Διαλέξτε **5**, **10**, **15** ή **30** λεπτά

Τόσο νωρίτερα από ένα γεγονός ημερολογίου ενεργοποιείται η ειδοποίηση **Η
σύσκεψη ξεκινά σύντομα**. Η προεπιλογή είναι 5 λεπτά.

## Πότε μια ειδοποίηση καταστέλλεται

Μια ειδοποίηση απορρίπτεται σιωπηλά όταν ισχύει οποιοδήποτε από τα παρακάτω:

- Οι ειδοποιήσεις είναι απενεργοποιημένες συνολικά ή η κατηγορία της είναι
  απενεργοποιημένη
- Βρίσκεστε ήδη στη διαδρομή στην οποία θα σας πήγαινε — και, για ένα μήνυμα,
  είστε ήδη σε αυτόν τον χώρο
- Η λειτουργία εστίασης είναι ενεργή και η κατηγορία δεν είναι επείγουσα
- Οι Quiet hours είναι ενεργές και η κατηγορία δεν είναι επείγουσα

Αυτοί οι έλεγχοι ισχύουν για τις αναδυόμενες ειδοποιήσεις του λειτουργικού
συστήματος. Η διαρκής καμπάνα καταγράφει ακόμη το γεγονός.

Δύο ακόμη καταστολές βρίσκονται πιο πάνω, σε αυτό που στέλνει ο διακομιστής
εξαρχής:

- Ένα μήνυμα από άλλον **άνθρωπο** στο οποίο δεν σας ανέφεραν δεν γίνεται ποτέ
  ειδοποίηση
- Σε έναν κοινόχρηστο χώρο, η απάντηση ενός πράκτορα ειδοποιεί όποιον ξεκίνησε
  αυτή την εκτέλεση, όχι κάθε μέλος
- Οι χώροι μεταξύ πρακτόρων είναι σε σίγαση στην πλαϊνή στήλη, οπότε δεν
  αυξάνουν ποτέ το σήμα μη αναγνωσμένων του ανθρώπου

Μέσα σε έναν χώρο δεν υπάρχει ήσυχη γωνιά: κάθε συνομιλία ειδοποιεί το ίδιο,
μαζί και τα νήματα. Η κατάσταση ανάγνωσης αφορά ολόκληρο τον χώρο, οπότε τα μη
αναγνωσμένα συγκεντρώνονται από όλες τις συνομιλίες του χώρου αντί να
παρακολουθούνται ανά συνομιλία.

## Ανάγνωση και καθαρισμός του κέντρου ειδοποιήσεων

1. Κάντε κλικ στην καμπάνα στη γραμμή τίτλου

Το αναδυόμενο παράθυρο δείχνει πρόσφατη δραστηριότητα, συνδέοντας κάθε
καταχώριση απευθείας με το θέμα της. Το άνοιγμά του **δεν** σημειώνει τα πάντα
ως αναγνωσμένα — χρησιμοποιήστε τη **Σήμανση όλων ως αναγνωσμένων** στην
κεφαλίδα ή σημειώστε μία μόνο γραμμή. Η κατάσταση ανάγνωσης ακολουθεί τον
χρήστη σας σε όλες τις συσκευές.

:::note[Ο καθαρισμός όλων είναι υδατογράφημα, όχι διαγραφή]
Ο **Καθαρισμός όλων** τοποθετεί ένα υδατογράφημα ανά χρήστη που κρύβει όλα τα
παλαιότερα· οι γραμμές παραμένουν. Ξεχωριστά, κάθε χώρος εργασίας διατηρεί μόνο
τις πιο πρόσφατες **200** γραμμές ροής, οι οποίες κόβονται καθώς φτάνουν νέες,
ενώ η καμπάνα εγγράφεται στις πιο πρόσφατες **50** και το αναδυόμενο παράθυρο
εμφανίζει έως **15** από αυτές. Το ιστορικό πέρα από αυτό χάνεται ανεξάρτητα
από την κατάσταση ανάγνωσης.
:::

## Αντιμετώπιση προβλημάτων

### Καμία ειδοποίηση λειτουργικού συστήματος στο macOS

Η εξουσιοδότηση ζητείται εγγενώς κατά την εκκίνηση της εφαρμογής. Αν την
αρνηθήκατε, ενεργοποιήστε ξανά το Control Center στις Ρυθμίσεις συστήματος →
Ειδοποιήσεις· δεν υπάρχει προτροπή μέσα στην εφαρμογή για να την ξαναζητήσετε.

### Δεν φτάνει τίποτα στην έκδοση για web

Αναμενόμενο — η έκδοση για web δεν έχει διοχέτευση ειδοποιήσεων λειτουργικού
συστήματος. Χρησιμοποιήστε την καμπάνα.

### Το σήμα της καμπάνας δείχνει μηδέν, αλλά υπάρχει σαφώς νέα δραστηριότητα

Μέχρι να ολοκληρωθεί η ροή σημάτων ανάγνωσης μετά τη σύνδεση, οι καταχωρίσεις
εμφανίζονται ως αναγνωσμένες, ώστε να αποφευχθεί ένα σήμα που αναβοσβήνει και
μετά αδειάζει. Σταθεροποιείται μόλις φορτωθεί το σήμα.

### Η εκτέλεση ενός πράκτορα ολοκληρώθηκε, αλλά τίποτα δεν με ειδοποίησε

Ελέγξτε ότι δεν βρισκόσασταν ήδη στον χώρο όπου συνέβη — μια ενεργή διαδρομή
καταστέλλει τη δική της αναδυόμενη ειδοποίηση λειτουργικού συστήματος. Σε έναν
κοινόχρηστο χώρο, μια εκτέλεση που ξεκίνησε κάποιος άλλος ειδοποιεί εκείνον, όχι
εσάς. Ένας γύρος που τελείωσε χωρίς απάντηση και χωρίς σφάλμα δεν στέλνει
τίποτα.
