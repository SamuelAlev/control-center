Αυτός ο οδηγός δείχνει πώς να δουλέψετε τα εισερχόμενα: τη μοναδική επιφάνεια που
συγκεντρώνει ό,τι σας φράζει ή σας ζητά ρητά — εκκρεμείς εγκρίσεις πρακτόρων,
αποτυχημένους συγχρονισμούς εισιτηρίων και κάθε pull request στο οποίο
εμπλέκεστε ως κριτής ή συντάκτης.

## Ανοίξτε τα εισερχόμενα

1. Πατήστε **Εισερχόμενα** στην πλαϊνή στήλη. Το σήμα του μετρά εκκρεμείς
   εγκρίσεις πρακτόρων, αποτυχημένους συγχρονισμούς και ανοιχτά PR που περιμένουν
   την ανασκόπησή σας.
2. Ή πατήστε <kbd>⌘K</kbd> και εκτελέστε την εντολή πλοήγησης **Εισερχόμενα**.
3. Ή μεταβείτε απευθείας μέσω βαθύ συνδέσμου στο `/workspaces/<workspace-id>/inbox`.

Η καταχώριση στην πλαϊνή στήλη εμφανίζει πάντα την τρέχουσα μέτρηση, ώστε να
βλέπετε τη δουλειά ταξινόμησης να συσσωρεύεται χωρίς να ανοίξετε τη σελίδα.

## Διαβάστε τη σοβαρότητα με μια ματιά

Σαρώστε από πάνω προς τα κάτω· τα εισερχόμενα είναι ήδη ταξινομημένα κατά
επείγον:

1. Η καρφιτσωμένη λωρίδα **Χρειάζεται την προσοχή σας** βρίσκεται πάνω από τις
   ενότητες PR. Κάθε κάρτα φέρει μια ετικέτα σοβαρότητας. Οι καταχωρισμένες
   πηγές (ένας πράκτορας κολλημένος σε ένα αίτημα επιβεβαίωσης, ένας
   συγχρονισμός εισιτηρίων του οποίου το αντίγραφο στον προμηθευτή είναι
   παρωχημένο) εκπέμπουν **Αποκλεισμένο**.
2. Μέσα στη λωρίδα, η πιο επείγουσα σοβαρότητα έρχεται πρώτη· σε ισοπαλία
   κερδίζει το στοιχείο που περιμένει περισσότερο.
3. Κάτω από τη λωρίδα, τα PR ομαδοποιούνται σε σταθερές ενότητες του κύκλου ζωής
   ανασκόπησης — **Χρειάζεται την ανασκόπησή σας**, **Επιστράφηκε σε εσάς**,
   **Εγκρίθηκε**, **Πρόχειρα**, **Αναμονή κριτών**, **Συγχώνευση και πρόσφατα
   συγχωνευμένα**, **Αναμονή συντάκτη**. Οι πάνω ενότητες είναι αυτό που χρειάζεται
   _εσάς_· οι υπόλοιπες δείχνουν πού βρίσκονται _τα δικά σας_ PR. Η **Χρειάζεται
   την ανασκόπησή σας** περιλαμβάνει PR που εξακολουθούν να ζητούν μια ομάδα
   στην οποία ανήκετε, σε κεντρικούς υπολογιστές κώδικα που υποστηρίζουν ομάδες
   (το GitHub αφαιρεί την ομάδα μόλις ελέγξει οποιοσδήποτε συμπαίκτης).

Ένα στοιχείο καταλήγει στα εισερχόμενα μόνο όταν φράζει κάτι ή σας ζητά ρητά. Μια
κενή λωρίδα μαζί με μια κενή λίστα ενοτήτων εμφανίζει το **Είστε ενήμεροι** μόνο
όταν αυτό το κενό είναι αξιόπιστο.

## Ένα εισερχόμενο για όλους τους κεντρικούς υπολογιστές κώδικα

Αν ο χώρος εργασίας περιέχει αποθετήρια σε περισσότερους από έναν κεντρικούς
υπολογιστές κώδικα, τα εισερχόμενα τα συγχωνεύουν σε μία ροή — ένα pull request
από το GitHub και ένα από το Bitbucket κάθονται στην ίδια ενότητα, ταξινομημένα
κατά χρόνο και όχι ομαδοποιημένα κατά προμηθευτή. Τα μεταδεδομένα `repo #number`
της γραμμής είναι αυτά που τα ξεχωρίζουν.

Το «δικό σας» επιλύεται **ανά κεντρικό υπολογιστή κώδικα**, επειδή είστε
διαφορετικός λογαριασμός σε καθέναν. Ένα pull request θεωρείται δικό σας, ή ότι
ζητά την ανασκόπησή σας, μόνο όταν ταιριάζει με την ταυτότητά σας στον κεντρικό
υπολογιστή κώδικα όπου ζει πραγματικά το αποθετήριο.

Ένας κεντρικός υπολογιστής κώδικα που είναι εκτός λειτουργίας ή δεν είναι
συνδεδεμένος δεν συνεισφέρει τίποτα και αφήνει την υπόλοιπη λίστα ανέπαφη — μια
χαλασμένη σύνδεση δεν αδειάζει ποτέ ολόκληρη τη λίστα. Η κενή κατάσταση αναφέρει
μια επιφύλαξη αντί για **Είστε ενήμεροι** όταν κάθε ταυτότητα σύνδεσης σε κεντρικό
υπολογιστή κώδικα δεν έχει ακόμη επιλυθεί (**Δεν ήταν δυνατή η επιβεβαίωση του
λογαριασμού σας GitHub** — το κείμενο εξακολουθεί να αναφέρει το GitHub), όταν το
githubstatus.com αναφέρει περιστατικό ή όταν μια εγκατάσταση GitHub App που
καλύπτει συνδεδεμένα αποθετήρια έχει ανασταλεί.

## Καθαρίστε τη λωρίδα προσοχής

Κάθε κάρτα της λωρίδας έχει μία επόμενη ενέργεια:

1. Αν μια κάρτα είναι εκκρεμής επιβεβαίωση πράκτορα, πατήστε **Ανασκόπηση** —
   προσγειώνεστε στον χώρο αυτού του πράκτορα με την εκκρεμή επιβεβαίωσή του.
   Εγκρίνετε ή απορρίπτετε εκεί
   (δείτε [Συνομιλία με πράκτορα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/συνομιλία-με-πράκτορα/)).
2. Αν μια κάρτα λέει **Ο συγχρονισμός απέτυχε** για έναν προμηθευτή, πατήστε
   **Άνοιγμα** — προσγειώνεστε στις **Ρυθμίσεις → Χώρος εργασίας → Γενικά**, όπου
   η κάρτα **Υγεία συγχρονισμού** δείχνει τον τελευταίο συγχρονισμό κάθε σύνδεσης,
   το σερί διαδοχικών αποτυχιών και το τελευταίο αποτέλεσμα. Στα εισερχόμενα
   εμφανίζεται μόνο η τελευταία αποτυχία ανά προμηθευτή, οπότε ένας συγχρονισμός
   που αποκαταστάθηκε καθαρίζει την κάρτα.
3. Οι κάρτες εξαφανίζονται μόνες τους μόλις επιλυθεί η υποκείμενη κατάσταση (ο
   πράκτορας απαντήθηκε, ο συγχρονισμός αποκαταστάθηκε) — δεν υπάρχει τίποτα να
   απορρίψετε χειροκίνητα.

:::note[Αυτές είναι επιβεβαιώσεις ανά γύρο, όχι εγκρίσεις διακυβέρνησης]
Μια κάρτα «έγκρισης πράκτορα» είναι ένας πράκτορας σε λειτουργία που κάνει παύση
για να ζητήσει άδεια για μία ενέργεια, στη δική του συνομιλία. Είναι διαφορετικό
πράγμα από την εγγραφή `Approval` διακυβέρνησης που δημιουργούν οι πράκτορες με τα
εργαλεία MCP έγκρισης — αυτές δεν έχουν καμία ανθρώπινη οθόνη πουθενά στην
εφαρμογή και δεν εμφανίζονται ποτέ εδώ.
:::

:::caution[Η υγεία συγχρονισμού είναι μόνο για ανάγνωση]
Η κάρτα αναφέρεται σε συνδέσεις συγχρονισμού εισιτηρίων· πέρα από ένα κουμπί
**Συγχρονισμός τώρα**, δεν μπορεί να δημιουργήσει, να επεξεργαστεί ή να
επανασυνδέσει καμία, και δεν υπάρχει άλλη οθόνη που να μπορεί. Χωρίς ρυθμισμένη
σύνδεση γράφει απλώς «Δεν υπάρχουν ακόμη συνδέσεις συγχρονισμού», που είναι αυτό
που δείχνει ένας νέος χώρος εργασίας.
:::

## Φιλτράρετε σε ό,τι φράζει

1. Πατήστε <kbd>f</kbd> (χωρίς να έχει εστίαση πεδίο κειμένου) για να ανοίξετε το
   μενού φίλτρων ή πατήστε το κουμπί φίλτρου στη γραμμή εργαλείων.
2. Επιλέξτε οποιονδήποτε συνδυασμό κατάστασης, συντάκτη, κριτών, περιεχομένου,
   ιδιοκτήτη/ονόματος αποθετηρίου, χρονικών διαστημάτων ή **Γρήγορη ανασκόπηση**.
   Οι μετρήσεις όψεων στο μενού δείχνουν πόσα στοιχεία των εισερχομένων ταιριάζει
   κάθε επιλογή.
3. Τα ενεργά φίλτρα εμφανίζονται ως τσιπάκια στη γραμμή πάνω από τη λίστα· πατήστε
   το ✕ ενός τσιπ για να αφαιρέσετε αυτό το κριτήριο.
4. Χρησιμοποιήστε την αριστερή ράγα για να μεταβαίνετε μεταξύ ενοτήτων — κάθε
   καταχώριση δείχνει την τρέχουσα μέτρησή της και η επισήμανση ακολουθεί τη θέση
   κύλισής σας. Πατήστε μια κεφαλίδα ενότητας για να συμπτύξετε ενότητες που δεν
   ταξινομείτε (για παράδειγμα **Πρόχειρα** όταν καθαρίζετε ανασκοπήσεις).
5. Πατήστε μια κεφαλίδα στήλης (τίτλος, αλλαγές ή ενημέρωση) για να ταξινομήσετε
   κάθε ενότητα· πατήστε ξανά την ενεργή στήλη για να αντιστρέψετε τη φορά. Το
   κουμπί επιλογών εμφάνισης ελέγχει την ορατότητα των πρόχειρων, το παράθυρο
   πρόσφατα συγχωνευμένων, τις ιδιότητες γραμμών, τη σειρά και την ομαδοποίηση
   (μόνο η ομαδοποίηση κατά συντάκτη αλλάζει τη διάταξη των εισερχομένων).

Τα φίλτρα εδώ είναι ανεξάρτητα από την ουρά PR — το να περιορίσετε τα εισερχόμενα
δεν αλλάζει ποτέ τα φίλτρα της ουράς και αντίστροφα.

## Ενεργήστε σε ένα στοιχείο PR

1. Πατήστε οποιαδήποτε γραμμή για να ανοίξετε τη σελίδα λεπτομερειών του PR.
2. Αν το PR βρίσκεται στη **Χρειάζεται την ανασκόπησή σας**, ελέγξτε το και
   υποβάλτε την απόφασή σας — δείτε
   [Έλεγχος και συγχώνευση PR](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/έλεγχος-και-συγχώνευση-pr/).
3. Αν το PR βρίσκεται στο **Επιστράφηκε σε εσάς** (ζητήθηκαν αλλαγές ή το CI
   απέτυχε), στείλτε διορθώσεις από το checkout σας ή αναθέστε τη συνέχεια σε έναν
   πράκτορα.
4. Αν το PR βρίσκεται στο **Εγκρίθηκε**, συγχωνεύστε το από τη σελίδα
   λεπτομερειών.
5. Αν προτιμάτε να αναθέσετε μια ανασκόπηση αντί να την κάνετε μόνοι σας, δείτε
   [Αποστολή πρακτόρων ελέγχου](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/αποστολή-πρακτόρων-ελέγχου/) και
   [τον κύκλο ζωής αποστολής](/el-GR/εγχειρίδιο/έννοιες/κύκλος-ζωής-αποστολής/).

Μόλις αλλάξει η υποκείμενη κατάσταση (η ανασκόπησή σας καταχωρίζεται, το PR
συγχωνεύεται), ο ταξινομητής μεταφέρει αυτόματα το PR στη νέα του ενότητα.

## Αναίρεση μιας λανθασμένης ενέργειας

1. Πατήστε <kbd>⌘Z</kbd> για να αναιρέσετε την τελευταία ενέργεια,
   <kbd>⌘⇧Z</kbd> για να την επαναφέρετε.
2. Αν έχει εστίαση ένα πεδίο κειμένου, το ⌘Z επεξεργάζεται το κείμενο του πεδίου
   — πατήστε έξω από το πεδίο πρώτα για να αναιρέσετε μια ενέργεια σε επίπεδο
   εφαρμογής.

## Δείτε τις συντομεύσεις επιτόπου

Πατήστε <kbd>?</kbd> (χωρίς να έχει εστίαση πεδίο κειμένου) για να ανοίξετε το
φύλλο αναφοράς συντομεύσεων πληκτρολογίου. Παραθέτει κάθε δεσμό που είναι ενεργός
στην τρέχουσα διαδρομή, συμπεριλαμβανομένης της συντόμευσης φίλτρου <kbd>f</kbd>
των εισερχομένων. Ο πλήρης χάρτης βρίσκεται στην
[αναφορά συντομεύσεων πληκτρολογίου](/el-GR/εγχειρίδιο/αναφορά/συντομεύσεις-πληκτρολογίου/).

## Χειριστείτε το από την παλέτα εντολών

1. Πατήστε <kbd>⌘K</kbd> οπουδήποτε για να ανοίξετε την παλέτα εντολών.
2. Πληκτρολογήστε **Εισερχόμενα** για να μεταβείτε στη σελίδα ή πληκτρολογήστε έναν
   τίτλο PR — η παλέτα παραθέτει τα pull requests που ταιριάζουν και ανοίγει αυτό
   που θα επιλέξετε.
3. Όσο τα εισερχόμενα είναι ανοιχτά, εκτελέστε **Αντιγραφή συνδέσμου σε αυτή τη
   σελίδα** για να αντιγράψετε αυτό το URL για κοινή χρήση. Η εντολή αντιγράφει την
   τρέχουσα διαδρομή, οπότε είναι το URL των εισερχομένων μόνο όταν βρίσκεστε σε
   αυτή τη σελίδα.

## Ανανέωση κατά παραγγελία

Τα εισερχόμενα ενημερώνονται ζωντανά, αλλά αν υποψιάζεστε παρωχημένα δεδομένα,
πατήστε το χειριστήριο ανανέωσης στη γραμμή εργαλείων — εξαναγκάζει μια άμεση
σάρωση στην πλευρά του διακομιστή σε κάθε συνδεδεμένο κεντρικό υπολογιστή κώδικα
και επαναφέρει τις επικαλύψεις συγχωνευμένων/ελεγμένων. Το εικονίδιο
περιστρέφεται ώσπου να ολοκληρωθούν όλες οι ανακτήσεις.
