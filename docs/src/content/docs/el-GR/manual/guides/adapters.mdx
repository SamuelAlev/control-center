Αυτός ο οδηγός δείχνει πώς να συνδέσετε παρόχους μοντέλων και να επιλέξετε σε
τι εκτελείται ένας πράκτορας.

Όλα όσα περιγράφονται εδώ βρίσκονται σε μία σελίδα: **Ρυθμίσεις → Διακομιστής →
Πάροχοι μοντέλων**. Η καταχώριση στην πλαϊνή στήλη διαβάζεται «Πάροχοι
μοντέλων»· η επικεφαλίδα της σελίδας διαβάζεται «Προσαρμογείς».

## Τι είναι ένας προσαρμογέας

Ένας προσαρμογέας είναι ο _εκτελεστής_ που εκτελεί μια στροφή πράκτορα. Υπάρχουν
δύο και η λίστα είναι σταθερή — δεν μπορείτε να προσθέσετε τρίτο.

| Προσαρμογέας                  | CLI      | Μέσο μεταφοράς                                    |
| ------------------------- | -------- | --------------------------------------------------- |
| Control Center (ενσωματωμένο) | κανένα     | Βρόχος πράκτορα εντός διεργασίας, μιλάει με τους παρόχους μέσω HTTP |
| Claude Code               | `claude` | `claude -p --output-format stream-json`             |

Τα Cursor, Codex, Anthropic, OpenAI και τα υπόλοιπα είναι **πάροχοι** στον
ενσωματωμένο προσαρμογέα, όχι ξεχωριστά CLI. Αυτό που _μπορείτε_ να προσθέσετε
είναι άλλος πάροχος — οποιοδήποτε τελικό σημείο συμβατό με OpenAI ή Anthropic.
Αυτό είναι το επόμενο τμήμα.

:::note[Η ανίχνευση εξετάζει τον διακομιστή, όχι το μηχάνημά σας]
Η κάρτα **Ανιχνευμένοι εκτελεστές** παραθέτει ό,τι βρήκε το `cc_server` στο
`PATH` _του κεντρικού υπολογιστή του διακομιστή_. Σε έναν λεπτό ή web πελάτη
πρόκειται για άλλο μηχάνημα από αυτό που βλέπετε. Εγκαταστήστε το CLI στο
μηχάνημα που εκτελεί το `cc_server`.
:::

## Σύνδεση παρόχου μοντέλων

Ο ενσωματωμένος προσαρμογέας χρειάζεται τουλάχιστον έναν συνδεδεμένο πάροχο για
να μπορεί να εκτελεστεί. Δεκατέσσερις περιλαμβάνονται στον κατάλογο.

1. Μεταβείτε στις **Ρυθμίσεις → Διακομιστής → Πάροχοι μοντέλων**
2. Μετακινηθείτε στους **Πάροχοι και μοντέλα**
3. Βρείτε τον πάροχό σας και συνδέστε τον:

| Πάροχος                                                                                                 | Τρόπος σύνδεσης                                                                                                                |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | Κλειδί API. Η συνδρομή Claude Pro/Max δεν είναι σύνδεση API της Anthropic — για αυτό το πρόγραμμα χρησιμοποιήστε τον προσαρμογέα Claude Code              |
| OpenAI, Codex, Cursor                                                                                    | Σύνδεση OAuth μέσω browser ή κλειδί API. Το Codex είναι ChatGPT Plus/Pro μέσω του backend Codex Responses, όχι εκκίνηση CLI                |
| Kimi Code                                                                                                | Μόνο OAuth μέσω browser — ροή με κωδικό συσκευής. Είναι πρόγραμμα σταθερής χρέωσης, οπότε δεν έχει τιμή ανά token                                 |
| OpenRouter, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API)       | Κλειδί API                                                                                                                       |

Σημείο ελέγχου: το σήμα της γραμμής αλλάζει σε «συνδεδεμένο» και, όταν την
αναπτύξετε, παραθέτει τα μοντέλα που εξυπηρετεί ο συγκεκριμένος πάροχος, καθένα
με την τιμή του ανά εκατομμύριο tokens και το παράθυρο πλαισίου του.

Τα token του OAuth καταλήγουν στη δική του αποθήκη διαπιστευτηρίων του διακομιστή
και ανανεώνονται πριν λήξουν. Τα διαπιστευτήρια των παρόχων είναι **καθολικά για
τον κεντρικό υπολογιστή** — τα μοιράζονται όλοι οι χώροι εργασίας της
εγκατάστασης και δεν περιορίζονται σε έναν.

### Προσθήκη προσαρμοσμένου παρόχου

Χρησιμοποιήστε το για Ollama, LM Studio, vLLM ή ιδιωτική ανάπτυξη.

1. Στους **Πάροχοι και μοντέλα**, κάτω από τους **Προσαρμοσμένους παρόχους**,
   πατήστε **Προσθήκη παρόχου**
2. Συμπληρώστε ένα **Όνομα**, επιλέξτε τον **Τύπο API** (συμβατό με OpenAI ή
   συμβατό με Anthropic) και δώστε το **Base URL** (για παράδειγμα
   `http://localhost:11434/v1`)
3. Προσθέστε ένα **Κλειδί API** αν το τελικό σημείο απαιτεί ένα και μετά πατήστε
   **Προσθήκη παρόχου**

Ένας προσαρμοσμένος πάροχος εμφανίζεται στην ίδια λίστα, με κουμπί διαγραφής που
δεν έχουν τα ενσωματωμένα αδελφά του.

## Επιλογή μοντέλου για έναν πράκτορα

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες** και επιλέξτε τον
   πράκτορα
2. Στην καρτέλα **Ρυθμίσεις**, επιλέξτε τον **προσαρμογέα**
3. Επιλέξτε το **μοντέλο** από το αναπτυσσόμενο μενού δίπλα του

Για τον ενσωματωμένο προσαρμογέα, το αναπτυσσόμενο μενού συναρμολογείται
ζωντανά από τον κατάλογο κάθε συνδεδεμένου παρόχου. Ένας πάροχος χωρίς
αποθηκευμένο διαπιστευτήριο συνεισφέρει μηδέν μοντέλα, γι' αυτό ένα κενό
αναπτυσσόμενο μενού σημαίνει σχεδόν πάντα «τίποτα δεν έχει συνδεθεί ακόμη» και
όχι «τίποτα δεν είναι διαθέσιμο».

:::note[Το models.dev είναι εμπλουτισμός, ποτέ πηγή αναγνωριστικών]
Ο συνοδευτικός κατάλογος [models.dev](https://models.dev) παρέχει τιμή και
παράθυρο πλαισίου για ένα μοντέλο που βρίσκεται ήδη στη ζωντανή λίστα. Δεν
προσθέτει ποτέ αναγνωριστικό μοντέλου. Αν λείπει ένα μοντέλο που περιμένετε, το
τελικό σημείο του παρόχου δεν το επιστρέφει.
:::

Τα αναγνωριστικά μοντέλων για τον ενσωματωμένο προσαρμογέα είναι προσδιορισμένα
ως `provider/model` και μπορεί να φέρουν αλυσίδα εφεδρικών χωρισμένη με `|`. Σε
περίπτωση εφεδρικής επιλογής, το κόστος χρεώνεται με βάση το μοντέλο που
εξυπηρέτησε πραγματικά τη στροφή, όχι αυτό που ζητήσατε.

:::note[Ένας πράκτορας χωρίς προσαρμογέα εκτελείται στον ενσωματωμένο βρόχο]
Κάθε χώρος εργασίας τροφοδοτεί αρχικά πέντε πράκτορες — έναν CEO συν τους `qa`,
`architect`, `engineer` και `librarian` — χωρίς προσαρμογέα και χωρίς μοντέλο. Η
αποστολή καταλήγει στο **Control Center (ενσωματωμένο)** και όχι στη ρύθμιση
**Προεπιλεγμένοι εκτελεστές** αυτής της σελίδας, η οποία είναι προτίμηση της
πλευράς του πελάτη που η διαδρομή αποστολής δεν διαβάζει ποτέ. Το αρχείο
καταγραφής εκτέλεσης καταγράφει `cc-harness` για αυτές τις εκτελέσεις, οπότε η
καταγραφή ονομάζει τι εκτελέστηκε πραγματικά.

Χωρίς μοντέλο επίσης, ο ενσωματωμένος βρόχος ζητά από την Anthropic το
προεπιλεγμένο μοντέλο της. Ένας πράκτορας που έχει μείνει εντελώς ασυμπλήρωτος
εκτελείται, επομένως, αν έχετε συνδέσει λογαριασμό Anthropic, και σε αντίθετη
περίπτωση αποτυγχάνει με `No credential for provider "anthropic"`.

Ολοκληρώνοντας το βήμα του προσαρμογέα στην εισαγωγή, ενημερώνονται αναδρομικά
**όλοι** οι πράκτορες που εξακολουθούν να μην έχουν προσαρμογέα ή μοντέλο — CEO
και ειδικοί, σε κάθε χώρο εργασίας που υπάρχει εκείνη τη στιγμή — με το ζεύγος
που επιλέξατε. Οι χώροι εργασίας που δημιουργούνται αργότερα εξακολουθούν να
τροφοδοτούν και τους πέντε ασυμπλήρωτους. Ορίστε ρητά τον προσαρμογέα και το
μοντέλο σε κάθε πράκτορα που σκοπεύετε να χρησιμοποιήσετε.
:::

## Εγκατάσταση CLI εκτελεστή

Ο ενσωματωμένος προσαρμογέας δεν χρειάζεται εγκατάσταση. Για το Claude Code,
εγκαταστήστε το CLI του **στον κεντρικό υπολογιστή του διακομιστή** με τον δικό
του διαχειριστή πακέτων, για παράδειγμα:

```bash
npm install -g @anthropic-ai/claude-code
```

Έπειτα πατήστε **Ανανέωση** στο επάνω μέρος της σελίδας. Κάθε ανιχνευμένη γραμμή
εμφανίζει την επιλυμένη έκδοση και τη διαδρομή, καθώς και ετικέτες για το αν
υποστηρίζει λειτουργία JSON και επιλογή μοντέλου.

Ένα εξωτερικό CLI κρατά τα δικά του διαπιστευτήρια, στη δική του διαμόρφωση, στον
κεντρικό υπολογιστή του διακομιστή. Το Control Center δεν τα διαχειρίζεται.

:::caution[Τα Ορίσματα προσαρμογέα και οι Μεταβλητές περιβάλλοντος μένουν σε αυτή τη συσκευή]
Κάθε γραμμή προσαρμογέα προσφέρει ένα πεδίο **Ορίσματα** και ένα παράθυρο
διαλόγου **Μεταβλητές περιβάλλοντος**. Οι τιμές αυτές αποθηκεύονται στη συσκευή
σας. Ο διακομιστής διαβάζει τα argv εκκίνησης και το env από τη δική του αποθήκη
ρυθμίσεων. Βάλτε τα κλειδιά των παρόχων στον διακομιστή (OAuth ή το πεδίο
κλειδιού στη σελίδα Πάροχοι μοντέλων), όχι σε αυτά τα δύο πεδία.
:::

## Περιορισμός των παρόχων που μπορεί να χρησιμοποιήσει ένας χώρος εργασίας

Η διακυβέρνηση παρόχων είναι ανά χώρο εργασίας και αξιολογείται με κανόνα
«τελευταία αντιστοίχιση κερδίζει».

1. Στους **Πάροχοι και μοντέλα**, κλείστε τον διακόπτη **Αποδοχή** σε μια γραμμή
   παρόχου

Αυτό γράφει μια δήλωση `deny` για τον συγκεκριμένο πάροχο στον ενεργό χώρο
εργασίας και τα μοντέλα του εξαφανίζονται από τον κατάλογο για αυτόν τον χώρο
εργασίας. Ενεργοποιώντας ξανά τον διακόπτη αφαιρείται η δήλωση.

## Αντιμετώπιση προβλημάτων

### Ένας εκτελεστής εμφανίζεται ως «δεν βρέθηκε»

- Ελέγξτε ότι το CLI βρίσκεται στο `PATH` **του κεντρικού υπολογιστή του
  διακομιστή**, όχι μόνο στο δικό σας
- Μια εφαρμογή επιφάνειας εργασίας που εκκινείται από γραφικό περιβάλλον ξεκινά
  τον διακομιστή της με ελάχιστο `PATH`· ένα CLI εγκατεστημένο σε διαδρομή που
  υπάρχει μόνο σε κέλυφος μπορεί να είναι αόρατο σε αυτήν
- Πατήστε **Ανανέωση** μετά την εγκατάσταση

### Το αναπτυσσόμενο μενού μοντέλων είναι κενό

- Ο προσαρμογέας είναι ο ενσωματωμένος και δεν έχει συνδεθεί κανένας πάροχος —
  συνδέστε έναν στους **Πάροχοι και μοντέλα**
- Ή ο πάροχος είναι συνδεδεμένος αλλά τον απορρίπτει ο διακόπτης διακυβέρνησης
  αυτού του χώρου εργασίας

### Ένα μοντέλο εκτελείται αλλά η τιμή εμφανίζεται ως άγνωστη

Η ζωντανή λίστα μοντέλων φέρει το αναγνωριστικό· η τιμή και το πλαίσιο
προέρχονται από το models.dev. Ένα ολοκαίνουργιο μοντέλο, ή ένα από
προσαρμοσμένο πάροχο, δεν έχει ακόμη καταχώριση στον κατάλογο.
