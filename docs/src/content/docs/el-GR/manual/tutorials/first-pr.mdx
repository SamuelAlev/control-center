## Τι θα φτιάξετε

Μέχρι το τέλος αυτού του οδηγού θα έχετε:

- Ανοίξει ένα pull request στον πάγκο εργασίας PR του Control Center
- Διαβάσει το diff του και αφήσει ένα ενσωματωμένο σχόλιο
- Υποβάλει μια ετυμηγορία ανασκόπησης
- Συγχωνεύσει το PR

Προϋποθέσεις: ολοκληρωμένος ο οδηγός [Αποστείλετε τον πρώτο σας πράκτορα](/el-GR/εγχειρίδιο/οδηγοί/πρώτος-πράκτορας/) και ένα ανοιχτό pull request σε ένα αποθετήριο που είναι καταχωρισμένο σε αυτόν τον χώρο εργασίας. Για τα βήματα της ανασκόπησης, διαλέξτε ένα PR που δεν ανοίξατε εσείς — το κουμπί **Ανασκόπηση** κρύβεται στα δικά σας PR. Η συγχώνευση λειτουργεί ακόμη και σε PR που συντάξατε εσείς.

## Βήμα 1: Ανοίξτε το pull request

1. Πατήστε **Pull requests** στην πλαϊνή στήλη
2. Βρείτε το PR σας και πατήστε το

**Σημείο ελέγχου.** Το PR ανοίγει ως πάγκος εργασίας με καρτέλες — Επισκόπηση, Diff, Έλεγχος εκδόσεων, Συνομιλία, Ενέργειες — εστιασμένος στην **Επισκόπηση**: τον τίτλο και τις ενέργειες, την περιγραφή και το χρονολόγιο δραστηριότητας, και μια πλαϊνή στήλη με κατάσταση, κριτές, ανατεθειμένους, ελέγχους και αλλαγμένα αρχεία. Αν πατήσετε ένα αρχείο εκεί, μεταφέρεστε σε αυτό στην καρτέλα Diff. Η καρτέλα **Ανασκόπηση PR** δεν είναι ανοιχτή μέχρι κάποιος να ζητήσει ανασκόπηση με AI.

:::note[Κενή ουρά με προτροπή «σύνδεση GitHub»]
Αυτή η κατάσταση σημαίνει ότι ο _διακομιστής_ δεν κρατά κάποιο token του GitHub — ο πελάτης σας δεν κρατά ποτέ κάποιο. Ορίστε ένα στις **Ρυθμίσεις → Χώρος εργασίας → Προφίλ και ταυτότητα → Φιλοξενία κώδικα** και μετά ανανεώστε τη λίστα.
:::

## Βήμα 2: Διαβάστε το diff

Ανοίξτε την καρτέλα **Diff**. Ένα πτυσσόμενο δέντρο αρχείων βρίσκεται στα αριστερά και η λωρίδα πάνω από το diff φέρει επιλογέα εύρους commits — περιορίστε το diff σε ένα commit ή σε ένα διάστημα commits — καθώς και τον αριθμό των αρχείων και τις τρέχουσες προσθήκες και διαγραφές.

Το κουμπί ρυθμίσεων στη γραμμή εργαλείων του diff ελέγχει πώς αποδίδεται:

- **Διαχωρισμένη** ή **ενοποιημένη** προβολή
- **Αναδίπλωση γραμμών** ή κύλιση των μακριών γραμμών
- **Συμπλέγματα γραμματοσειράς κώδικα**

Σημειώστε ένα αρχείο ως προβληθέν για να παρακολουθείτε την πρόοδό σας σε ένα μεγάλο diff. Η πλοήγηση με πληκτρολόγιο βρίσκεται στις [Συντομεύσεις πληκτρολογίου](/el-GR/εγχειρίδιο/αναφορά/συντομεύσεις-πληκτρολογίου/).

## Βήμα 3: Αφήστε ένα ενσωματωμένο σχόλιο

1. Περάστε τον δείκτη πάνω από μια γραμμή στο diff — εμφανίζεται ένα μικρό στρογγυλό κουμπί `+` στο περιθώριο
2. Πατήστε το για να σχολιάσετε αυτή τη γραμμή ή σύρετέ το πρώτα κατακόρυφα για να επιλέξετε ένα εύρος
3. Πληκτρολογήστε τα σχόλιά σας. Ο composer προσφέρει δύο τρόπους υποβολής:
   - Το **Έναρξη ανασκόπησης** (ή το **Προσθήκη στην ανασκόπηση**, αν υπάρχει ήδη ανασκόπηση σε εξέλιξη) βάζει το σχόλιο σε ουρά. Η συζήτηση εμφανίζει **Ανασκόπηση σε εκκρεμότητα** μέχρι να υποβάλετε ετυμηγορία στο βήμα 4.
   - Το **Προσθήκη μεμονωμένου σχολίου** το αναρτά αμέσως στο GitHub. Η συζήτηση εμφανίζει **Δημοσίευση…**, μετά **Συγχρονίστηκε**, και προσφέρει επανάληψη αν η ανάρτηση αποτύχει.

Για αυτόν τον οδηγό, χρησιμοποιήστε το **Έναρξη ανασκόπησης**, ώστε το σχόλιο να φύγει μαζί με την ετυμηγορία.

:::caution[Ένα σχόλιο σε ουρά δεν βρίσκεται ακόμη στο GitHub]
Τα **Έναρξη ανασκόπησης** / **Προσθήκη στην ανασκόπηση** κρατούν το σχόλιο τοπικά μέχρι να υποβάλετε ετυμηγορία. Μόνο το **Προσθήκη μεμονωμένου σχολίου** αναρτά αμέσως. Το _σώμα_ της ανασκόπησης που γράφετε στο βήμα 4 είναι ξεχωριστό πρόχειρο.
:::

## Βήμα 4: Υποβάλετε ανασκόπηση

1. Πατήστε **Ανασκόπηση** στη γραμμή ενεργειών της Επισκόπησης — το ίδιο κουμπί βρίσκεται και στη γραμμή εργαλείων της καρτέλας Diff. Κρύβεται στα PR που συντάξατε εσείς και σε PR που έχει κλείσει ή συγχωνευθεί.
2. Γράψτε μια σύνοψη στον composer. Αποθηκεύεται αυτόματα ως πρόχειρο, ώστε να κλείσετε το αναδυόμενο πλαίσιο και να επιστρέψετε.
3. Διαλέξτε ετυμηγορία:
   - **Αίτημα αλλαγών**
   - **Σχόλιο**
   - **Έγκριση**

Η ετυμηγορία είναι το ίδιο το κουμπί. Μετά την **Έγκριση** ή το **Αίτημα αλλαγών**, το κουμπί μετονομάζεται σε **Εγκρίθηκε** ή **Ζητήθηκαν αλλαγές**. Μια ετυμηγορία **Σχόλιο** το αφήνει με την ετικέτα **Ανασκόπηση**.

**Σημείο ελέγχου.** Το κουμπί γράφει «Εγκρίθηκε» ή «Ζητήθηκαν αλλαγές» αν διαλέξατε ένα από αυτά τα δύο.

## Βήμα 5: Συγχώνευση

Το κουμπί **Συγχώνευση** υπάρχει όποτε το GitHub αναφέρει ότι το PR μπορεί να συγχωνευθεί — δεν εξαρτάται από τη δική σας έγκριση. Το χρώμα του δηλώνει ετοιμότητα και όχι άδεια: κύριο όταν οι απαιτούμενες εγκρίσεις και οι έλεγχοι είναι πράσινοι, δευτερεύον όσο εκτελείται ακόμη κάποιος έλεγχος, καταστροφικό όταν ένας ζητούμενος κριτής δεν έχει εγκρίνει ή κάποιος έλεγχος αποτυγχάνει.

1. Πατήστε **Συγχώνευση**
2. Διαλέξτε μέθοδο: **Squash και συγχώνευση**, **Δημιουργία commit συγχώνευσης** ή **Rebase και συγχώνευση**
3. Για τις δύο πρώτες, επεξεργαστείτε τον προσυμπληρωμένο τίτλο και το μήνυμα του commit
4. Επιβεβαιώστε

Τυχόν εκκρεμή προβλήματα — «Οι έλεγχοι αποτυγχάνουν», «Ορισμένες ανασκοπήσεις εκκρεμούν» — παρατίθενται στο αναδυόμενο πλαίσιο πριν επιβεβαιώσετε.

:::caution[Η συγχώνευση είναι μη αναστρέψιμη]
Η συγχώνευση ωθεί commits στο GitHub. Δεν μπαίνει ποτέ στη στοίβα αναίρεσης του Control Center και δεν μπορεί να αναιρεθεί από εδώ.
:::

Μετά τη συγχώνευση, εκπέμπεται ένα γεγονός τομέα `PrMerged`· το καταναλώνουν τα analytics και οι ειδοποιήσεις. Δείτε τα [Γεγονότα τομέα](/el-GR/εγχειρίδιο/αναφορά/γεγονότα-τομέα/) για το τι άλλο τα ακούει.

## Ανασκόπηση με AI

Το Control Center μπορεί να βάλει ένα pipeline ελέγχου σε ένα ανοιχτό PR, αλλά μόνο όταν το ζητήσετε: το πρότυπο `pr_review` έχει χειροκίνητο ενεργοποιητή και τίποτε άλλο.

1. Ανοίξτε το μενού υπερχείλισης στη γραμμή ενεργειών της Επισκόπησης και επιλέξτε **Ερώτηση AI**. Το Control Center ξεκινά την εκτέλεση και ανοίγει την καρτέλα **Ανασκόπηση PR**, ώστε να δείτε τους ειδικούς εν ώρα εργασίας.
2. Οι πράκτορες ελέγχου καταχωρίζουν τα ευρήματά τους ως κόμβους ελέγχου στον χώρο του PR· ένα τελικό βήμα τα ενοποιεί σε μία αναφορά.

Το pipeline σκόπιμα δεν αναρτά στο GitHub — τελειώνει μετά την ενοποίηση. Η δημοσίευση είναι ξεχωριστό βήμα που κάνετε μόνοι σας, με το κουμπί **Δημοσίευση στο GitHub** στην καρτέλα **Ανασκόπηση PR**. Δείτε τη [Χρήση ελέγχου με AI](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/έλεγχος-με-ai/).

## Σύνοψη

Ανοίξατε ένα PR στον πάγκο εργασίας, διαβάσατε το diff με επισήμανση σύνταξης, αφήσατε ένα ενσωματωμένο σχόλιο, υποβάλατε μια ετυμηγορία και συγχωνεύσατε — χωρίς να βγείτε από την εφαρμογή.

**Επόμενο:** [Δημιουργήστε το πρώτο σας pipeline](/el-GR/εγχειρίδιο/οδηγοί/πρώτο-pipeline/) για να αυτοματοποιήσετε ροές εργασίας πολλών βημάτων.
