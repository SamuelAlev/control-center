## Τι θα φτιάξετε

Μέχρι το τέλος αυτού του οδηγού θα έχετε:

- Έναν χώρο εργασίας με το όνομα του έργου σας
- Ένα αποθετήριο Git καταχωρισμένο μέσα του
- Πέντε πράκτορες από τον αρχικό εφοδιασμό, έναν από τους οποίους θα έχετε ρυθμίσει αρκετά ώστε να εκτελείται
- Έναν δεύτερο, κενό χώρο εργασίας που αποδεικνύει το όριο απομόνωσης

Η υποδοχή έχει ήδη δημιουργήσει έναν χώρο εργασίας για εσάς. Αυτός ο οδηγός δημιουργεί σκόπιμα έναν καινούργιο, ώστε να δείτε κάθε μέρος της διαδικασίας.

Πριν ξεκινήσετε, διαλέξτε ένα Git checkout που πληροί και τα τρία παρακάτω — το βήμα της καταχώρισης απορρίπτει οτιδήποτε άλλο:

- βρίσκεται μέσα σε ένα δέντρο εργασίας git
- έχει ένα απομακρυσμένο `origin`
- αυτό το απομακρυσμένο δείχνει στα github.com, gitlab.com ή bitbucket.org

## Βήμα 1: Δημιουργήστε έναν χώρο εργασίας

1. Κάντε κλικ στο τσιπ του χώρου εργασίας στη γραμμή τίτλου
2. Επιλέξτε **Προσθήκη χώρου εργασίας…**
3. Εισαγάγετε ένα όνομα που αναγνωρίζει το έργο, όπως «api-service» ή «frontend-v2»
4. Προαιρετικά, διαλέξτε ένα λογότυπο
5. Κάντε κλικ στο **Προσθήκη χώρου εργασίας**

Το Control Center μεταβαίνει στον νέο χώρο εργασίας και προσγειώνεται στα εισερχόμενά του (`/workspaces/<id>/inbox`).

Πίσω από αυτό, ο διακομιστής εκπέμπει ένα συμβάν `WorkspaceCreated` και εφοδιάζει τον χώρο εργασίας με:

- έναν **πράκτορα CEO**, του οποίου η προσωπικότητα είναι ο συντονισμός και η ανάθεση
- τέσσερις ειδικούς — `qa`, `architect`, `engineer` και `librarian` — καθέναν με τις δικές του οδηγίες και δεξιότητες
- τα ενσωματωμένα πρότυπα pipeline και τις γραμμές ενεργοποιητών τους

Κάθε χώρος εργασίας που δημιουργείτε τα αποκτά όλα αυτά, όχι μόνο ο πρώτος.

Επιβεβαιώστε το: ανοίξτε τις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες**. Πέντε πράκτορες βρίσκονται στη λίστα, ο καθένας με έναν κοίλο δακτύλιο κατάστασης.

## Βήμα 2: Καταχωρίστε ένα αποθετήριο

1. Μεταβείτε στις **Ρυθμίσεις → Χώρος εργασίας → Αποθετήρια**
2. Κάντε κλικ στο **Προσθήκη αποθετηρίου**
3. Περιηγηθείτε στο checkout σας. Το παράθυρο διαλόγου πλοηγείται στους φακέλους του μηχανήματος που εκτελεί το `cc_server` — όχι του πελάτη σας — και μένει μέσα στις ρίζες που εκθέτει αυτός ο διακομιστής (από προεπιλογή, τον αρχικό κατάλογο του χρήστη του). Ένα git checkout παίρνει ξεχωριστό εικονίδιο φακέλου και ένα πλαίσιο επιλογής· ένας απλός φάκελος δεν παίρνει τίποτα από τα δύο, οπότε μόνο checkouts μπορούν να επιλεγούν.
4. Επιλέξτε ένα ή περισσότερα checkouts και καταχωρίστε την παρτίδα. Οι επιλογές διατηρούνται καθώς περιηγείστε, ώστε να συγκεντρώσετε αρκετά σε ένα πέρασμα και μια κακή επιλογή να μην απορρίπτει ποτέ τα υπόλοιπα.

Το Control Center διαβάζει το απομακρυσμένο `origin` κάθε checkout, επιλύει ιδιοκτήτη και αποθετήριο και δημιουργεί τη γραμμή του αποθετηρίου **μέσα σε αυτόν τον χώρο εργασίας**. Δεν υπάρχει δεύτερο βήμα για τη σύνδεσή του: η καταχώριση είναι αυτό που του δίνει εμβέλεια.

Η καταχώριση του ίδιου checkout σε άλλον χώρο εργασίας αργότερα δημιουργεί μια δεύτερη, ανεξάρτητη γραμμή αποθετηρίου με δικό της αναγνωριστικό. Μεταξύ χώρων εργασίας, ένα checkout αναγνωρίζεται από τη διαδρομή του στο σύστημα αρχείων, ποτέ από αναγνωριστικό.

Επιβεβαιώστε το: το αποθετήριο εμφανίζεται στη λίστα με το `owner/repo` και τον τρέχοντα κλάδο του.

## Βήμα 3: Κάντε έναν πράκτορα εκτελέσιμο

Οι πέντε πράκτορες που μόλις εφοδίασε αυτός ο χώρος εργασίας δεν έχουν προσαρμογέα ούτε μοντέλο. Η αποστολή τούς εκτελεί στο **Control Center (ενσωματωμένο)** και, χωρίς ορισμένο μοντέλο, ζητά από την Anthropic το προεπιλεγμένο της — οπότε λειτουργούν μόνο αν έχετε συνδέσει λογαριασμό Anthropic, και σε ένα μοντέλο που δεν διαλέξατε εσείς αν έχετε. Η υποδοχή της πρώτης εκτέλεσης σφραγίζει την επιλογή της σε κάθε πράκτορα του πρώτου χώρου εργασίας, μία φορά· ένας χώρος εργασίας που δημιουργείτε μετά ξεκινά με τους πέντε χωρίς ρύθμιση. Ορίστε έναν τώρα.

1. Ανοίξτε τις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες**
2. Επιλέξτε τον `engineer` στη λίστα
3. Στην καρτέλα **Ρυθμίσεις**, ορίστε τον **Προσαρμογέα** σε `Control Center (built-in)` και διαλέξτε ένα **Μοντέλο** από έναν πάροχο που έχετε συνδέσει στις Ρυθμίσεις → Διακομιστής → Πάροχοι μοντέλων
4. Πατήστε **Αποθήκευση αλλαγών**

Επιβεβαιώστε το: ανοίξτε ξανά τον πράκτορα και τα δύο πεδία κρατούν τις επιλογές σας.

Κάθε πράκτορας φέρει τον δικό του προσαρμογέα και μοντέλο, οπότε επαναλάβετε το ίδιο για κάθε άλλον πράκτορα που σκοπεύετε να χρησιμοποιήσετε. Η [Δημιουργία και ρύθμιση πράκτορα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/δημιουργία-πράκτορα/) καλύπτει τα υπόλοιπα της φόρμας.

## Βήμα 4: Δείτε το όριο απομόνωσης

Δημιουργήστε έναν δεύτερο χώρο εργασίας από το τσιπ της γραμμής τίτλου, ακριβώς όπως στο βήμα 1. Έπειτα κοιτάξτε τον:

- Στις **Ρυθμίσεις → Χώρος εργασίας → Αποθετήρια** δεν υπάρχει τίποτα. Το αποθετήριο που καταχωρίσατε πριν από ένα λεπτό δεν είναι εκεί.
- Στις **Ρυθμίσεις → Χώρος εργασίας → Πράκτορες** υπάρχουν πέντε πράκτορες, αλλά είναι διαφορετικές γραμμές — ο προσαρμογέας που ορίσατε στο βήμα 3 έχει χαθεί.
- Η λίστα χώρων, τα εισιτήρια και η μνήμη είναι όλα κενά.

Δεν διέρρευσε τίποτα, γιατί δεν υπάρχει τίποτα από όπου να διαρρεύσει: οι γραμμές κάθε χώρου εργασίας ζουν στο δικό του αρχείο βάσης δεδομένων. Μια ανάγνωση μεταξύ χώρων εργασίας δεν είναι ένα ερώτημα που φιλτράρεται, είναι ένα ερώτημα που δεν έχει πού να εκτελεστεί. Η διαγραφή ενός χώρου εργασίας είναι η αποσύνδεση ενός αρχείου.

Επιστρέψτε με το τσιπ της γραμμής τίτλου, ή ανοίξτε τη **Διαχείριση χώρων εργασίας** για να τους δείτε δίπλα-δίπλα.

Για το πλήρες μοντέλο, διαβάστε [Χώροι εργασίας και απομόνωση](/el-GR/εγχειρίδιο/έννοιες/χώροι-εργασίας/).

## Σύνοψη

Δημιουργήσατε έναν χώρο εργασίας, τον είδατε να εφοδιάζει έναν CEO και τέσσερις ειδικούς, καταχωρίσατε ένα αποθετήριο μέσα του, δώσατε σε έναν πράκτορα προσαρμογέα και μοντέλο και επιβεβαιώσατε ότι ένας δεύτερος χώρος εργασίας δεν μοιράζεται τίποτα από αυτά.
