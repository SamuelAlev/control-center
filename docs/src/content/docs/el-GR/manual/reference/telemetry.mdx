Το Control Center μπορεί να στέλνει **ψευδωνυμοποιημένα συμβάντα χρήσης** σε μια εγκατάσταση του [Umami](https://umami.is). Τα αναλυτικά χρήσης είναι **απενεργοποιημένα μέχρι να τα ενεργοποιήσει ο διαχειριστής του διακομιστή**. Η ρύθμιση ανήκει στον διακομιστή και ισχύει για κάθε πρόγραμμα-πελάτη που συνδέεται σε αυτόν: την εφαρμογή υπολογιστή, την εφαρμογή web, το τηλέφωνο και τον ίδιο τον διακομιστή.

Τα αναλυτικά χρήσης είναι ξεχωριστά από την **Κοινή χρήση αναφορών σφαλμάτων**, μια ρύθμιση ανά συσκευή για διαγνωστικά καταρρεύσεων και σφαλμάτων.

## Ποιος αποφασίζει

| Διακόπτης | Πού | Αποτέλεσμα |
| --- | --- | --- |
| **Κοινή χρήση αναλυτικών χρήσης** | Αρχική ρύθμιση (βήμα sandbox) και **Ρυθμίσεις → Απόρρητο**. Μόνο ο διαχειριστής του διακομιστή μπορεί να τον αλλάξει· τα άλλα μέλη βλέπουν την τρέχουσα τιμή μόνο για ανάγνωση | Για όλο τον διακομιστή. Αποθηκεύεται ως `telemetry.usage_analytics` στις ρυθμίσεις του διακομιστή. Ανενεργός αν δεν οριστεί σε `true` |
| Τύπος build | Αυτόματα | Τα build debug και profile δεν στέλνουν. Αντί γι’ αυτό γράφουν κάθε συμβάν στο αρχείο καταγραφής debug |
| `CC_ANALYTICS_DEBUG=1` | Περιβάλλον του `cc_server` ή το `.env` του | Επιτρέπει στα build debug και profile του διακομιστή, και κάθε προγράμματος-πελάτη που συνδέεται σε αυτόν, να στέλνουν πραγματικά, για δοκιμές. Ο παραπάνω διακόπτης πρέπει και πάλι να είναι ενεργός |
| `DO_NOT_TRACK=1` | Περιβάλλον του `cc_server` | Σταματά τις αναφορές του ίδιου του διακομιστή, ό,τι κι αν δείχνει ο διακόπτης. Τα προγράμματα-πελάτες εξακολουθούν να ακολουθούν τον διακόπτη |
| Διακομιστής επίδειξης | Αυτόματα | Ο δημόσιος διακομιστής επίδειξης δεν στέλνει τίποτα δικό του. Οι επισκέπτες δεν μπορούν να αλλάξουν τον διακόπτη |

Τα προγράμματα-πελάτες διαβάζουν τη ρύθμιση από τον διακομιστή (`telemetry.config` και στη συνέχεια σε πραγματικό χρόνο μέσω `telemetry.watch`). Μέχρι να έρθει η απάντηση, τα συμβάντα περιμένουν σε μια μικρή προσωρινή μνήμη. Αν η απάντηση είναι αρνητική, η προσωρινή μνήμη απορρίπτεται. Όταν απενεργοποιείται ο διακόπτης, ό,τι βρίσκεται ακόμη σε αναμονή απορρίπτεται και η αποστολή σταματά αμέσως, σε κάθε πρόγραμμα-πελάτη.

## Τι δεν αποστέλλεται ποτέ

- Περιεχόμενο μηνυμάτων, εισιτηρίων, αξιολογήσεων ή συσκέψεων, τίτλοι, prompt, εντολές shell και ερωτήματα αναζήτησης
- Ονόματα, ονόματα σύνδεσης, διευθύνσεις email, avatar και εμφανιζόμενα ονόματα
- Διαδρομές αρχείων, ονόματα αποθετηρίων, ονόματα κλάδων, ονόματα κεντρικών υπολογιστών και URL (ένα αποθετήριο στέλνεται μόνο ως ψευδωνυμοποιημένο `repo_id` και ένας σύνδεσμος σύσκεψης μόνο ως ο πάροχός του)
- Ακατέργαστα αναγνωριστικά κάθε είδους

Κάθε συμβάν περνά από μια πολιτική ιδιοτήτων πριν φύγει από τη διεργασία. Κείμενο, διαδρομές, URL, διευθύνσεις email, μη ψευδωνυμοποιημένα ID και συμβολοσειρές κάτω από κλειδιά όπως `email`, `*_name`, `path`, `title`, `prompt`, `content` ή `token` απορρίπτονται αντί να σταλούν. Μια συμβολοσειρά στέλνεται μόνο αν είναι ένα σύντομο token από κλειστό λεξιλόγιο, όπως μια τιμή enum, μια έκδοση, μια τοπική ρύθμιση ή ένα ID μοντέλου.

## Ψευδωνυμοποιημένα ID

Τα ID στέλνονται, αλλά μόνο ως ψευδώνυμα. Κάθε ID χώρου εργασίας, χώρου, συνομιλίας, πράκτορα, εκτέλεσης, χρήστη και συσκευής αντικαθίσταται από ένα HMAC-SHA256 με το μυστικό αλάτι της ίδιας της εγκατάστασης (`telemetry.pseudonym_salt`), περικομμένο στους 20 δεκαεξαδικούς χαρακτήρες. Ο ίδιος χώρος εργασίας αναφέρει πάντα την ίδια τιμή, ώστε τα συμβάντα να μπορούν να συσχετιστούν και να μετρηθούν, αλλά το ακατέργαστο ID δεν φεύγει ποτέ από την εγκατάσταση. Το αλάτι δημιουργείται στην πρώτη εκκίνηση του διακομιστή και δεν στέλνεται ποτέ στον πάροχο αναλυτικών. Η διαγραφή του καταλόγου δεδομένων του διακομιστή δημιουργεί νέο αλάτι και νέο ID εγκατάστασης, κάτι που αποσυνδέει ό,τι είχε καταγραφεί πριν.

## Προβολές οθονών

Κάθε πλοήγηση καταγράφει μια προβολή σελίδας με URL το **πρότυπο διαδρομής**, όπως `/workspaces/:workspaceId/spaces/:spaceId`, ποτέ τη συγκεκριμένη διεύθυνση. Το όνομα της οθόνης είναι τα σταθερά τμήματα του προτύπου, οπότε στο παράδειγμα είναι `workspaces_spaces`. Οι παράμετροι διαδρομής που τελειώνουν σε `Id` επισυνάπτονται ως ψευδωνυμοποιημένες ιδιότητες `*_id` και οι αριθμητικές (όπως ένας αριθμός PR) ως αριθμοί. Όλες οι άλλες παράμετροι απορρίπτονται.

## Παράδοση

Τα συμβάντα στέλνονται ένα-ένα στο `<host>/api/send` από μια ουρά στη μνήμη έως 200 συμβάντων. Σφάλμα δικτύου, λήξη χρονικού ορίου, `429` ή `5xx` κρατούν το συμβάν και το ξαναδοκιμάζουν με εκθετική καθυστέρηση, από 1 δευτερόλεπτο έως 5 λεπτά. Οποιοδήποτε άλλο `4xx` το απορρίπτει. Τίποτα δεν γράφεται στον δίσκο, οπότε τα συμβάντα που βρίσκονται ακόμη στην ουρά όταν κλείνει η εφαρμογή χάνονται. Η ουρά αδειάζει όταν η εφαρμογή περνά στο παρασκήνιο και όταν ο διακομιστής τερματίζεται.

## Στόχευση ενός build σε άλλη εγκατάσταση

Ο προορισμός ορίζεται κατά το build:

```bash
--dart-define=CC_ANALYTICS_HOST=https://analytics.example.com/
--dart-define=CC_ANALYTICS_WEBSITE_ID=<website uuid>
```

Ο προσαρμογέας παρόχου βρίσκεται στο `packages/cc_analytics`. Η υποστήριξη άλλης υπηρεσίας αναλυτικών σημαίνει προσθήκη ενός προσαρμογέα εκεί. Το σχέδιο παρακολούθησης και οι κανόνες απορρήτου παραμένουν ίδιοι.
