Το Control Center Connect εκτελεί τις συνδέσεις παρόχων για διακομιστές που δεν
έχουν καταχωρίσει δικές τους εφαρμογές. Ένας διακομιστής χρησιμοποιεί είτε το
φιλοξενούμενο Connect του Control Center, είτε ένα Connect που εκτελεί ο
οργανισμός του ([Εκτέλεση διακομιστή Connect](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/εκτέλεση-διακομιστή-connect/)),
είτε κανένα. Η επιλογή βρίσκεται στις **Ρυθμίσεις → Διακομιστής → Ενιαία
σύνδεση → Control Center Connect**, στο `cc_server connect` ή στο `CC_CONNECT_URL`. Ένας χώρος εργασίας την ακολουθεί, εκτός αν ένας διαχειριστής επιλέξει κάτι άλλο για αυτόν στις **Ρυθμίσεις → Χώρος εργασίας → Ενσωματώσεις** ([Η επιλογή ανά χώρο εργασίας](#η-επιλογή-ανά-χώρο-εργασίας)).

## Λωρίδες

Κάθε πάροχος είναι μια λωρίδα. Υπό **Χρήση των δικών μου εφαρμογών** (ή πριν επιλέξει κάποιος), μια λωρίδα εκτελείται στη δική εφαρμογή του διακομιστή όταν αυτή είναι πλήρως διαμορφωμένη, αλλιώς δεν είναι διαθέσιμη. Με το Control Center ή ένα δικό σας Connect, το Connect εκτελεί κάθε λωρίδα που εξυπηρετεί: οι δικές εφαρμογές του διακομιστή μένουν αποθηκευμένες αλλά δεν χρησιμοποιούνται, ούτε για συνδέσεις, ούτε για την αυτοματοποίηση του διακομιστή, ούτε για την κατάσταση που αναφέρει ο διακομιστής. Ένας χώρος εργασίας που έχει κάνει τη δική του επιλογή εκτελεί κάθε λωρίδα με αυτήν την επιλογή αντί για αυτή του διακομιστή.

| Λωρίδα       | Τι χρειάζεται η δική σας εφαρμογή                    | Μέσω του Connect                                                     |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------- |
| `github`     | App id, ιδιωτικό κλειδί, client id και client secret | Οι άνθρωποι συνδέονται στην κοινόχρηστη GitHub App                    |
| `google`     | Client id και client secret                          | Οι άνθρωποι συνδέουν το Google Calendar                              |
| `linear`     | Client id                                            | Οι άνθρωποι συνδέονται στο Linear                                    |
| `linear_app` | Client id                                            | Ένας διαχειριστής χώρου εργασίας συνδέει τον app actor του Linear     |
| `slack`      | Τη σύνδεση της δικής του εφαρμογής Slack ενός χώρου εργασίας | Ένας διαχειριστής χώρου εργασίας συνδέει το Slack στην κοινόχρηστη εφαρμογή Slack |
| `klipy`      | `KLIPY_APP_KEY`                                      | Αναζήτηση GIF, μέσω του Connect ως διακομιστή μεσολάβησης            |

Μια δική σας εφαρμογή που είναι μόνο εν μέρει διαμορφωμένη κάνει τη λωρίδα της
σφάλμα, ποτέ σιωπηλή μετάπτωση στο Connect. Ένας χώρος εργασίας με **Χρήση των δικών μου εφαρμογών** δεν περνά ποτέ από τις εφαρμογές του διακομιστή ούτε από κάποιο Connect, για κανέναν πάροχο. Η αλλαγή της επιλογής Connect του διακομιστή δεν αποσυνδέει κανέναν από έναν χώρο εργασίας που έχει κάνει τη δική του επιλογή.

## Τι βλέπει και τι δεν βλέπει ποτέ το Connect

| Το Connect βλέπει                                                                             | Το Connect δεν βλέπει ποτέ                                                       |
| --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Το αναγνωριστικό εγκατάστασης του διακομιστή και τις υπογραφές αιτημάτων                      | Πηγαίο κώδικα, περιεχόμενα αποθετηρίων, diffs ή κείμενο pull request             |
| Τον λογαριασμό παρόχου που συνδέθηκε, κατά τη διάρκεια της σύνδεσης                           | Εισιτήρια, απομαγνητοφωνήσεις ή οτιδήποτε σε βάση δεδομένων χώρου εργασίας       |
| Σε ποιον χώρο εργασίας ανήκει ένα διαπιστευτήριο, ως αδιαφανές id μέσα στη σφραγίδα            | Τα μυστικά των δικών εφαρμογών του διακομιστή: δεν φεύγουν ποτέ από τον διακομιστή |
| Το αποθετήριο για το οποίο εκδίδεται ένα token GitHub για ένα αποθετήριο                      | Refresh tokens σε αποθήκευση: υπάρχουν μόνο μέσα σε σφραγίδες που κρατά ο διακομιστής |
| Η ομάδα Slack που είναι δεσμευμένη στον διακομιστή                                             | Μυστικά του Linear: ο διακομιστής ανταλλάσσει μόνος του τον κωδικό του Linear    |
| Όρους αναζήτησης GIF, όταν μεσολαβεί για το Klipy                                             | Κωδικούς πρόσβασης, κλειδιά σύζευξης ή κλειδιά παρόχων μοντέλων                  |
| Αναφορές συμβάντων Slack (ομάδα, κανάλι, id μηνύματος) και κείμενο slash command              | Κείμενο μηνυμάτων Slack: το Connect το απορρίπτει κατά την άφιξη και ο διακομιστής διαβάζει το μήνυμα απευθείας από το Slack |

Το Connect κρατά τις σταδιακές συνδέσεις, τα nonces και τις κρυφές μνήμες για το
πολύ 10 λεπτά, και τους ωριαίους μετρητές χρήσης για το πολύ δύο ώρες. Ένα token
GitHub για ένα αποθετήριο, που εκδίδεται ως άτομο, παραμένει καταγεγραμμένο,
σφραγισμένο στη σύνδεση που το ζήτησε, έως ότου λήξει (το πολύ 8 ώρες), ώστε το
Connect να μπορεί να το δώσει ξανά και να το ανακαλέσει κατά την αποσύνδεση. Οι
μόνες μόνιμες εγγραφές του είναι οι δεσμεύσεις Slack (σε ποιον διακομιστή είναι
δεσμευμένη κάθε ομάδα Slack) και τα αναγνωριστικά εγκατάστασης που αποσύρθηκαν.
Τα σφάλματα φέρουν έναν κωδικό, ποτέ την απάντηση του παρόχου. Τα αρχεία
καταγραφής καταγράφουν τα αναγνωριστικά εγκατάστασης μόνο ως κατακερματισμούς με
κλειδί, και ένα token GitHub μόνο ως το `hashed_token` που εμφανίζει για αυτό το
αρχείο καταγραφής ελέγχου του οργανισμού GitHub, ώστε ένας ιδιοκτήτης οργανισμού
να μπορεί να αντιστοιχίσει τα δύο.

## Λειτουργίες

| Λειτουργία | Ρύθμιση                                          | Συμπεριφορά                                                                                                       |
| ---------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Χωρίς ρύθμιση | Νέος διακομιστής                              | Καμία λωρίδα δεν χρησιμοποιεί το Connect. Η αρχική ρύθμιση ζητά από τον ιδιοκτήτη του διακομιστή να επιλέξει      |
| `hosted`   | **Χρήση των εφαρμογών του Control Center**       | `https://connect.usectrl.dev`, με διαμόρφωση υπογεγραμμένη εκτός σύνδεσης. Οι δικές εφαρμογές του διακομιστή δεν χρησιμοποιούνται                                        |
| `custom`   | **Χρήση προσαρμοσμένου διακομιστή Connect**      | Ένα Connect σε URL HTTPS (`http` μόνο στο loopback), αξιόπιστο από την πρώτη χρήση. Οι δικές εφαρμογές του διακομιστή δεν χρησιμοποιούνται                                |
| `off`      | **Χρήση των δικών μου εφαρμογών**                | Καμία λωρίδα δεν χρησιμοποιεί το Connect. Μόνο οι δικές σας εφαρμογές συνδέουν ανθρώπους                         |

Το `CC_CONNECT_URL` στο περιβάλλον ή στο `.env` του διακομιστή κλειδώνει την
επιλογή: `hosted`, `off` ή ένα URL Connect. Οι Ρυθμίσεις δείχνουν τότε το
κλείδωμα και δεν μπορούν να την αλλάξουν.

Αυτό το build δεν περιέχει μεταγλωττισμένο κλειδί φιλοξενούμενης διαμόρφωσης,
οπότε η λειτουργία hosted αναφέρει `hosted_unprovisioned` και δεν εξυπηρετεί καμία
λωρίδα. Οι δικές σας εφαρμογές και ένα προσαρμοσμένο Connect λειτουργούν.

Η φιλοξενούμενη υπηρεσία Connect εκτελείται σε ένα μόνο container. Το κλειδί σφράγισης και το ιδιωτικό κλειδί της κοινόχρηστης GitHub App είναι εκεί μεταβλητές περιβάλλοντος, όχι κλειδιά σε κάποιο vault που μόνο υπογράφει ή αποκρυπτογραφεί, όπως συνιστά το GitHub για το ιδιωτικό κλειδί μιας App. Αυτό είναι γνωστό κενό της τρέχουσας διαμόρφωσης.

Ένας διακομιστής διαβάζει τη διαμόρφωση του Connect το πολύ κάθε 10 λεπτά και
περιμένει το πολύ 5 δευτερόλεπτα για κάθε κλήση. Όταν το Connect δεν είναι
προσβάσιμο, η τελευταία έγκυρη διαμόρφωση παραμένει σε χρήση και οι Ρυθμίσεις την
επισημαίνουν ως παρωχημένη.

## Η επιλογή ανά χώρο εργασίας

**Ρυθμίσεις → Χώρος εργασίας → Ενσωματώσεις → Control Center Connect** υπερισχύει της επιλογής του διακομιστή για έναν χώρο εργασίας. Κάθε μέλος βλέπει την επιλογή και πού εκτελείται κάθε σύνδεση· μόνο ένας διαχειριστής του χώρου εργασίας την αλλάζει.

| Επιλογή | Συμπεριφορά |
| --- | --- |
| **Όπως σε αυτόν τον διακομιστή** | Η προεπιλογή. Ο χώρος εργασίας εκτελείται με ό,τι επέλεξε ο ιδιοκτήτης του διακομιστή· η επιλογή το ονομάζει |
| **Χρήση των εφαρμογών του Control Center** | Το φιλοξενούμενο Connect του Control Center, ό,τι κι αν χρησιμοποιεί ο διακομιστής |
| **Χρήση των δικών μου εφαρμογών** | Μόνο οι εφαρμογές του χώρου εργασίας: η δική του GitHub App, ο δικός του πελάτης Google, η δική του εφαρμογή Linear, το δικό του κλειδί Klipy και η δική του εφαρμογή Slack. Ένας πάροχος χωρίς δική του εφαρμογή είναι εδώ απενεργοποιημένος· μια μερικώς ολοκληρωμένη εφαρμογή είναι σφάλμα ρύθμισης |
| **Χρήση προσαρμοσμένου διακομιστή Connect** | Ένα Connect σε διεύθυνση HTTPS που ορίζει ο χώρος εργασίας. Διευθύνσεις σε ιδιωτικό ή τοπικό δίκτυο απορρίπτονται |

- Κάθε επιλογή εκτός από την **Όπως σε αυτόν τον διακομιστή** κρατά τις συνδέσεις του GitHub και του Linear κάθε ατόμου σε ξεχωριστή θέση του χώρου εργασίας, ώστε να μην αναμειγνύονται με εκείνες του επιπέδου διακομιστή
- Η αλλαγή ζητά πρώτα επιβεβαίωση: όλοι στον χώρο εργασίας συνδέονται ξανά στο GitHub, στο Linear και στο Google Calendar μέσω των νέων εφαρμογών
- Η σύνδεση της εφαρμογής Slack του χώρου εργασίας λειτουργεί κάτω από κάθε επιλογή· το **Προσθήκη του Control Center στο Slack** ακολουθεί την επιλογή
- Το `CC_CONNECT_URL` κλειδώνει επίσης τους χώρους εργασίας εκτός από ένα δικό τους Connect: μπορούν να ακολουθούν τον διακομιστή ή να χρησιμοποιούν τις δικές τους εφαρμογές
- Ένα προσαρμοσμένο Connect ενός χώρου εργασίας εμπιστεύεται κατά την πρώτη χρήση μόνο για εκείνον τον χώρο εργασίας: η **Εμπιστοσύνη στις νέες εφαρμογές** εκεί δεν αλλάζει ποτέ όσα εμπιστεύεται ο διακομιστής ή άλλος χώρος εργασίας

## Ταυτότητα εγκατάστασης


| Στοιχείο                         | Τι είναι                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Κλειδί εγκατάστασης              | Ένας σπόρος 32 byte στο αρχείο μυστικών του διακομιστή (`connect_install_key`), ξεχωριστός από τα κλειδιά σύζευξης συσκευών        |
| Κλειδί ανά Connect               | Ένα κλειδί Ed25519 που παράγεται από τον σπόρο και τη διεύθυνση του Connect. Κάθε αίτημα προς το Connect υπογράφεται με αυτό (RFC 9421) |
| Αναγνωριστικό εγκατάστασης       | 26 χαρακτήρες που παράγονται από εκείνο το δημόσιο κλειδί. Εμφανίζεται στις Ρυθμίσεις και από το `cc_server connect status`        |

Ο ίδιος διακομιστής έχει διαφορετικό αναγνωριστικό εγκατάστασης για κάθε διεύθυνση
Connect. Το αναγνωριστικό αλλάζει μόνο όταν γίνει εναλλαγή του κλειδιού.

## Σφραγισμένα διαπιστευτήρια

Μια σύνδεση μέσω του Connect επιστρέφει μια **σφραγίδα διαπιστευτηρίου**: ένα
κρυπτογραφημένο blob που μόνο το Connect που το δημιούργησε μπορεί να ανοίξει.
Είναι δεμένη στον πάροχο, στη διεύθυνση του Connect, στο αναγνωριστικό
εγκατάστασης, στον χώρο εργασίας, στον λογαριασμό παρόχου, στην εφαρμογή και στη
γενιά του μυστικού.

- Ο διακομιστής αποθηκεύει τη σφραγίδα και το αναγνωριστικό εγκατάστασης για το
  οποίο σφραγίστηκε. Τα access tokens μένουν στη μνήμη
- Για ανανέωση, ο διακομιστής στέλνει πίσω τη σφραγίδα και λαμβάνει ένα νέο access
  token και μια νέα σφραγίδα
- Μια σφραγίδα της οποίας το αναγνωριστικό εγκατάστασης ή η διεύθυνση Connect δεν
  ταιριάζει πλέον διαγράφεται την επόμενη φορά που διαβάζεται, και εκείνος ο
  άνθρωπος συνδέεται ξανά. Αυτό συμβαίνει μετά από εναλλαγή κλειδιού, μετάβαση σε
  άλλο Connect ή επαναφορά καταλόγου δεδομένων σε διαφορετικό διακομιστή
- Μια σφραγίδα που το Connect δεν μπορεί να ανοίξει απορρίπτεται με `access_denied`

## Εγκαταστάσεις GitHub

Μια εγκατάσταση της κοινόχρηστης GitHub App μπορεί να χρησιμοποιηθεί από κάθε
διακομιστή. Το Connect δεν κρατά εγγραφή για το ποιος διακομιστής επιτρέπεται να
τη χρησιμοποιεί.

- Η **Εγκατάσταση εφαρμογής GitHub** στις **Ρυθμίσεις → Χώρος εργασίας → Ενσωματώσεις**
  ανοίγει τη σελίδα εγκατάστασης της εφαρμογής στο GitHub. Ο διακομιστής φτιάχνει
  τον σύνδεσμο από το όνομα της εφαρμογής στη διαμόρφωση του Connect
- Ένα token για ένα αποθετήριο χρειάζεται την εφαρμογή εγκατεστημένη στον λογαριασμό
  που κατέχει το αποθετήριο και την πρόσβαση του συνδεδεμένου ατόμου σε εκείνο το
  αποθετήριο. Είναι το δικό του token, περιορισμένο στον ρόλο του, ποτέ περισσότερο
- Ένας οργανισμός περιορίζει το Control Center στο GitHub: με την αφαίρεση της
  εγκατάστασης, με τον περιορισμό των αποθετηρίων της ή με την αφαίρεση του ατόμου
- Για κλήσεις που μπορεί να κάνει μόνο το ίδιο το άτομο, όπως η καταγραφή των εγκαταστάσεών του, το Connect παραδίδει στον διακομιστή το δικό του token χρήστη της App, όχι token για ένα αποθετήριο. Η σύνδεση σε έναν διακομιστή σημαίνει ότι εμπιστεύεστε εκείνον τον διακομιστή με αυτό το token
- Ένας οργανισμός που επιβάλλει λίστα επιτρεπόμενων διευθύνσεων IP του GitHub δεν μπορεί να χρησιμοποιήσει το φιλοξενούμενο Connect, του οποίου οι διευθύνσεις δεν είναι σταθερές. Καταχωρίζει δική του GitHub App, στους δικούς του διακομιστές ή σε ένα Connect που εκτελεί
- **Αποσύνδεση** ανακαλεί μόνο αυτή τη σύνδεση: το Connect καταναλώνει μία φορά το refresh token της και διαγράφει ό,τι επιστρέφει αυτό, διαγράφει το token χρήστη της και τα tokens ενός αποθετηρίου που εξέδωσε για εκείνη. Κάθε αντίγραφο της σφραγίδας της που κρατείται οπουδήποτε παύει να λειτουργεί. Οι συνδέσεις του ατόμου σε άλλους διακομιστές και χώρους εργασίας συνεχίζουν να λειτουργούν. Για να αφαιρέσετε εντελώς το Control Center από έναν λογαριασμό GitHub, ανακαλέστε το στο GitHub στις **Ρυθμίσεις → Εφαρμογές → Εξουσιοδοτημένες εφαρμογές GitHub → Ανάκληση**

### Το κοινόχρηστο bot

Tokens που εκδίδονται ως bot της App (`as: app`) εμφανίζουν το ίδιο bot στο GitHub για κάθε διακομιστή που χρησιμοποιεί το ίδιο Connect: το GitHub δεν μπορεί να ξεχωρίσει αυτούς τους διακομιστές.

- Κάθε διακομιστής μπορεί να έχει το bot για ανάγνωση και σχολιασμό: `read`, `review` και `comment` (σχόλια, ετικέτες, υπεύθυνοι και αντιδράσεις σε issues και pull requests)
- Η ανασκόπηση ενός pull request ως bot (`bot`, που γράφει pull requests) επιτρέπεται μόνο για διακομιστές που καταγράφει ο διαχειριστής του Connect στο `CONNECT_GITHUB_REVIEW_BOT_INSTALLS`. Κάθε άλλος διακομιστής λαμβάνει `needs_requester` και δημοσιεύει την ανασκόπηση με το token του υπεύθυνου ατόμου, το οποίο το GitHub περιορίζει σε εκείνο το άτομο: η ανασκόπηση εμφανίζεται με το όνομά του. Αυτό καλύπτει τη δημοσίευση αυτόματης ανασκόπησης AI, τα σχόλια ανασκόπησης και τα αιτήματα αξιολογητών
- Το push, η δημιουργία branch και το άνοιγμα pull request (`write`) δεν εκδίδονται ποτέ ως το κοινόχρηστο bot. Χρησιμοποιούν πάντα τη σύνδεση του αιτούντος
- Η έγκριση pull request δεν αυτοματοποιείται ποτέ, με κανένα token
- Ένας διακομιστής ή χώρος εργασίας με τη δική του GitHub App κρατά το bot για όλα αυτά, συμπεριλαμβανομένων των ανασκοπήσεων

### Τι πρέπει να γνωρίζουν οι ιδιοκτήτες και τα μέλη του οργανισμού

- Ένας διακομιστής στον οποίο έχει συνδεθεί κάποιος κρατά το token χρήστη της App του: έως 8 ώρες ανά token, ανανεωμένο έως ότου αποσυνδεθεί. Μπορεί να ενεργεί ως εκείνος σε κάθε αποθετήριο στο οποίο είναι εγκατεστημένη η κοινόχρηστη App και το οποίο μπορεί να φτάσει εκείνος. Το Connect μπορεί να κόψει έναν διακομιστή οριστικά (μια αποσυρμένη ή απορριφθείσα εγκατάσταση), αλλά ένα token που έχει ήδη δοθεί παραμένει έγκυρο έως ότου λήξει
- Η εγκατάσταση της κοινόχρηστης GitHub App σε έναν οργανισμό συναινεί για κάθε διακομιστή Control Center στον οποίο συνδέεται κάποιο μέλος, όχι για έναν μόνο διακομιστή
- Το bot είναι κοινόχρηστο, όπως παραπάνω: ένας οργανισμός δεν μπορεί να διακρίνει στο GitHub ποιος διακομιστής ενήργησε ως bot
- Ένας οργανισμός που θέλει δικό του όριο καταχωρίζει τη δική του GitHub App και εκτελεί το δικό του Connect ([Εκτέλεση διακομιστή Connect](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/εκτέλεση-διακομιστή-connect/)), ή ρυθμίζει την App στους δικούς του διακομιστές

| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Φιλοξενούμενο    | Επαληθεύει μια υπογραφή Ed25519 με κλειδιά μεταγλωττισμένα στο build. Απορρίπτει εποχή χαμηλότερη από την υψηλότερη που έχει δει (`rollback`) |
| Προσαρμοσμένο    | Καρφιτσώνει το app id και το client id του GitHub, τα client id της Google και του Linear και τα app id και client id του Slack στην πρώτη χρήση. Μια αλλαγή παύει τις συνδέσεις μέσω Connect (`pins_changed`) μέχρι ο ιδιοκτήτης του διακομιστή να πατήσει **Εμπιστοσύνη στις νέες εφαρμογές** |

## Λειτουργίες API

Οι ρυθμίσεις του Connect του διακομιστή είναι μόνο για τον ιδιοκτήτη του διακομιστή.

| Λειτουργία            | Τι κάνει                                                                                              |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `connect.status`      | Λειτουργία, URL, κλείδωμα, αναγνωριστικό εγκατάστασης, υγεία, εποχή διαμόρφωσης και πηγή κάθε λωρίδας |
| `connect.configure`   | Ορίζει `hosted`, `custom` (με `url`) ή `off`                                                          |
| `connect.test`        | Ανακτά ξανά τη διαμόρφωση και αναφέρει την υγεία                                                      |
| `connect.confirmPins` | Αποδέχεται τα αλλαγμένα αναγνωριστικά ενός προσαρμοσμένου Connect                                     |
| `connect.rotateKey`   | Δημιουργεί νέο κλειδί εγκατάστασης και νέο αναγνωριστικό εγκατάστασης (το `force` το αντικαθιστά ακόμη και όταν ένα Connect δεν μπόρεσε να αποσύρει το παλιό)· δείτε [Εναλλαγή του κλειδιού εγκατάστασης](#εναλλαγή-του-κλειδιού-εγκατάστασης) |

Η δική επιλογή ενός χώρου εργασίας έχει τις δικές της λειτουργίες, και κάθε μία κατονομάζει τον χώρο εργασίας:

| Λειτουργία | Ποιος | Τι κάνει |
| --- | --- | --- |
| `workspaceConnect.status` | Οποιοδήποτε μέλος | Η επιλογή, το αποτέλεσμα, η υγεία και η πηγή κάθε παρόχου. Το αναγνωριστικό εγκατάστασης και οι εκκρεμείς καρφιτσώσεις μόνο για διαχειριστές |
| `workspaceConnect.set` | Διαχειριστής χώρου εργασίας | Ορίζει `inherit`, `hosted`, `custom` (με `url`) ή `own` |
| `workspaceConnect.test` | Διαχειριστής χώρου εργασίας | Ανακτά ξανά τη διαμόρφωση Connect του χώρου εργασίας και αναφέρει την υγεία |
| `workspaceConnect.confirmPins` | Διαχειριστής χώρου εργασίας | Αποδέχεται τα αλλαγμένα αναγνωριστικά του δικού του προσαρμοσμένου Connect του χώρου εργασίας |

Οι ίδιες οι συνδέσεις χρησιμοποιούν τα `oauth.lanes`, `oauth.begin`,
`oauth.status`, `oauth.complete`, `oauth.connections` και `oauth.disconnect`. Ο
άνθρωπος είναι πάντα ο συνδεδεμένος καλών.

## Σύνδεση μέσω του Connect

1. Ο διακομιστής ζητά από το Connect να ξεκινήσει τη λωρίδα και λαμβάνει το URL
   εξουσιοδότησης του παρόχου, το οποίο ελέγχει πριν το εμφανίσει. Το GitHub
   εμφανίζει πάντα τον επιλογέα λογαριασμού του
2. Ο άνθρωπος εγκρίνει στο πρόγραμμα περιήγησης. Ο πάροχος επιστρέφει στο Connect
3. Το Connect εμφανίζει τι μπορεί να κάνει ως το άτομο ο διακομιστής που ξεκίνησε
   τη σύνδεση, και για πόσο χρονικό διάστημα. Το Connect δεν μπορεί να ξέρει ποιος
   εκτελεί τον διακομιστή, οπότε η σελίδα ζητά από το άτομο να συνεχίσει μόνο αν
   ξεκίνησε το ίδιο τη σύνδεση, και να την κλείσει αν του έστειλε τον σύνδεσμο
   κάποιος άλλος. Όταν το πρόγραμμα περιήγησης βρίσκεται σε άλλο δίκτυο από εκείνο
   από το οποίο ξεκίνησε η σύνδεση, η σελίδα το λέει: αυτό είναι φυσιολογικό για
   φιλοξενούμενο διακομιστή ή άλλη συσκευή, και είναι επίσης ό,τι μοιάζει το
   phishing. Η **Ακύρωση** τερματίζει τη σύνδεση: ο κωδικός του παρόχου δεν
   χρησιμοποιείται ποτέ. Κάθε σελίδα απαντά μία φορά· απάντηση που δεν προήλθε από
   τη σελίδα που μόλις έδειξε το Connect απορρίπτεται
4. Μετά το **Συνέχεια**, το Connect εμφανίζει έναν κωδικό 8 χαρακτήρων και έναν
   σύνδεσμο `control-center://oauth-done`. Όποιος πάρει τον κωδικό παίρνει την
   πρόσβαση που μόλις εγκρίθηκε, γι' αυτό πηγαίνει μόνο εκεί όπου ξεκίνησε η σύνδεση
5. Ο άνθρωπος πληκτρολογεί τον κωδικό στην εφαρμογή ή ακολουθεί τον σύνδεσμο. Ο
   διακομιστής διεκδικεί τη σύνδεση με τον κωδικό και τη δική του απόδειξη του
   αιτήματος

Μια σύνδεση λήγει μετά από 10 λεπτά. Πέντε λανθασμένοι κωδικοί την τερματίζουν. Ένας
σύνδεσμος που δεν ξεκίνησε αυτή η εφαρμογή απορρίπτεται με **Η σύνδεση δεν ξεκίνησε
από εδώ**. Το Connect περιορίζει πόσες συνδέσεις μπορεί να ξεκινήσει μία διεύθυνση
δικτύου, και πόσες φορές εκδίδονται tokens GitHub ανά άτομο και διακομιστή, ανά άτομο
σε όλους τους διακομιστές, ανά διεύθυνση και για ολόκληρη την εφαρμογή. Οι νέες
συνδέσεις έχουν δικό τους όριο, ώστε να μην καθυστερούν ποτέ τις ανανεώσεις που
χρειάζονται άλλοι άνθρωποι. Πέρα από ένα όριο, μια κλήση απορρίπτεται με
`rate_limited`, και ο διακομιστής δοκιμάζει ξανά αργότερα χωρίς να αποσυνδέσει
κανέναν. Μια σύνδεση πέρα από το όριο του ατόμου αναιρείται στο GitHub και
απορρίπτεται.

## Εναλλαγή του κλειδιού εγκατάστασης

Μόνο ο κάτοχος του διακομιστή μπορεί να εναλλάξει το κλειδί, με το **Εναλλαγή κλειδιού** στην κάρτα **Control Center Connect** στις **Ρυθμίσεις → Διακομιστής → Ενιαία σύνδεση**. Δεν υπάρχει εντολή γι' αυτό. Η εναλλαγή:

- Αποσυνδέει όλους από κάθε λωρίδα που εκτελείται μέσω του Connect. Για κάθε διακομιστή Connect με τον οποίο χρησιμοποιούνταν το παλιό κλειδί, ο διακομιστής ανακαλεί τις συνδέσεις GitHub και Slack που κρατά από εκεί (μια σύνδεση Google δεν έχει τι να ανακαλέσει και λήγει)
- Αποσύρει το παλιό αναγνωριστικό εγκατάστασης σε κάθε έναν από αυτούς τους διακομιστές Connect, υπογεγραμμένο με το παλιό κλειδί και αποδεδειγμένο με μία σφραγίδα διαπιστευτηρίου που κρατά ο διακομιστής από εκείνο το Connect. Από τότε το Connect απορρίπτει κάθε αίτημα που γίνεται με το παλιό κλειδί, οπότε μια σφραγίδα ή ένα αντίγραφο του παλιού κλειδιού που πάρθηκε από αυτόν τον διακομιστή δεν χρησιμεύει σε τίποτα, και τα χώρους εργασίας Slack που ήταν δεσμευμένα στο παλιό αναγνωριστικό απελευθερώνονται ώστε να μπορούν να συνδεθούν ξανά. Τα tokens που έχουν ήδη δοθεί παραμένουν έγκυρα έως ότου λήξουν (μία ώρα για token bot, οκτώ ώρες για token ατόμου). Ένας διακομιστής Connect από τον οποίο ο διακομιστής δεν κρατά σφραγίδα δεν έχει τίποτα να αποσύρει και παρακάμπτεται
- Έπειτα δίνει στον διακομιστή νέο κλειδί εγκατάστασης και νέο αναγνωριστικό εγκατάστασης
- Αν ένας διακομιστής Connect δεν είναι προσβάσιμος, ή αρνείται να αποσύρει το παλιό αναγνωριστικό, σταματά πριν αλλάξει κλειδιά και εμφανίζει **Το Connect δεν μπόρεσε να αποσύρει το παλιό κλειδί**. Η **Ανανέωση ούτως ή άλλως** αλλάζει κλειδιά ούτως ή άλλως· τότε το παλιό αναγνωριστικό εγκατάστασης παραμένει χρησιμοποιήσιμο σε εκείνο το Connect έως ότου λήξουν τα tokens του, το πολύ 8 ώρες για GitHub
- Αφήνει ανέγγιχτες τις συνδέσεις μέσω των δικών εφαρμογών του διακομιστή
- Απαιτεί να προστεθεί το νέο αναγνωριστικό εγκατάστασης στη λίστα επιτρεπόμενων
  ενός προσαρμοσμένου Connect

## Κωδικοί κατάστασης

| Κωδικός                | Σημασία                                                                       |
| ---------------------- | ----------------------------------------------------------------------------- |
| `hosted_unprovisioned` | Αυτό το build δεν έχει κλειδί φιλοξενούμενης διαμόρφωσης                      |
| `signature`            | Η φιλοξενούμενη διαμόρφωση απέτυχε στον έλεγχο υπογραφής                      |
| `rollback`             | Το Connect εξυπηρέτησε παλαιότερη διαμόρφωση από όση έχει ήδη δει ο διακομιστής |
| `unreachable`          | Ο διακομιστής δεν μπορεί να φτάσει το Connect                                 |
| `install_blocked`      | Το Connect δεν επιτρέπει αυτό το αναγνωριστικό εγκατάστασης, ή έχει αποσυρθεί |
| `pins_changed`         | Ένα προσαρμοσμένο Connect ανακοίνωσε διαφορετικά αναγνωριστικά εφαρμογών      |
| `protocol`             | Το Connect απάντησε σε μορφή που αυτός ο διακομιστής δεν καταλαβαίνει         |
