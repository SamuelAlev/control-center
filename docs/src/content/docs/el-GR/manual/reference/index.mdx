Οι σελίδες αναφοράς περιγράφουν **τι υπάρχει**, διεξοδικά και χωρίς σχολιασμό.
Χρησιμοποιήστε τις για να αναζητήσετε κάτι όταν ξέρετε ήδη τι ψάχνετε: ένα ακριβές
όνομα εργαλείου, ένα είδος βήματος, μια μετάβαση κατάστασης, μια διαδρομή, μια
συντόμευση.

Δεν είναι γραμμένες για να διαβαστούν από την αρχή ως το τέλος. Για αυτό,
χρησιμοποιήστε τις [έννοιες](/el-GR/εγχειρίδιο/έννοιες/)· για να ολοκληρώσετε κάτι,
χρησιμοποιήστε τους [οδηγούς πρακτικής](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/).

## Η επιφάνεια του προϊόντος

- [Εργαλεία MCP](/el-GR/εγχειρίδιο/αναφορά/εργαλεία-mcp/) — κάθε εργαλείο που καταχωρίζει ο διακομιστής MCP, ανά οικογένεια
- [Ενσωματωμένα εργαλεία πράκτορα](/el-GR/εγχειρίδιο/αναφορά/εργαλεία-πράκτορα/) — εργαλεία harness δεσμευμένα στον διακομιστή (LSP, AST, debug, eval, vibe)
- [Εντολές slash](/el-GR/εγχειρίδιο/αναφορά/εντολές-slash/) — οι ενσωματωμένες εντολές του composer, `/skill:` και εντολές χρήστη
- [Χάρτης διαδρομών](/el-GR/εγχειρίδιο/αναφορά/χάρτης-διαδρομών/) — κάθε οθόνη και το URL που οδηγεί σε αυτήν
- [Συντομεύσεις πληκτρολογίου](/el-GR/εγχειρίδιο/αναφορά/συντομεύσεις-πληκτρολογίου/) — το πλήρες μητρώο συντομεύσεων πλήκτρων
- [Γεγονότα τομέα](/el-GR/εγχειρίδιο/αναφορά/γεγονότα-τομέα/) — κάθε γεγονός που δημοσιεύεται στον δίαυλο τομέα
- [Σταθμοί](/el-GR/εγχειρίδιο/αναφορά/σταθμοί/) — κάθε επιφάνεια σταθμού, ρήμα ενέργειας, κατάσταση κύκλου ζωής, θύρα και προεπιλογή

- [Είδη βημάτων pipeline](/el-GR/εγχειρίδιο/αναφορά/βήματα-pipeline/) — είδη βημάτων, κλειδιά σώματος, διαμόρφωση και αποτελέσματα

- [Αντίγραφο ασφαλείας, εξαγωγή και εισαγωγή](/el-GR/εγχειρίδιο/αναφορά/αντίγραφα-ασφαλείας/) — η διάταξη των στιγμιοτύπων, κάθε λειτουργία αντιγράφου ασφαλείας και διαδρομή μεταφοράς
- [Υποσυστήματα sandbox](/el-GR/εγχειρίδιο/αναφορά/υποσυστήματα-sandbox/) — τα υποσυστήματα εκτέλεσης και η διαθεσιμότητά τους
