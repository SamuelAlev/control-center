Αυτή η αναφορά παραθέτει κάθε πεδίο της οντότητας πράκτορα, μαζί με τις απαριθμήσεις και τις σημαίες που χρησιμοποιεί. Για οδηγίες βήμα προς βήμα για τη δημιουργία ή την επεξεργασία ενός πράκτορα στην εφαρμογή, δείτε [Δημιουργία και ρύθμιση πράκτορα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/δημιουργία-πράκτορα/).

## Πεδία της οντότητας πράκτορα

| Πεδίο                   | Τύπος                  | Απαιτείται | Περιγραφή                                                                                                                                                                                           |
| ----------------------- | ---------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ναι        | Μοναδικό αναγνωριστικό πράκτορα                                                                                                                                                                     |
| `name`                  | `String`               | Ναι        | Σύντομο αναγνωριστικό για @-αναφορές                                                                                                                                                                |
| `title`                 | `String`               | Ναι        | Τίτλος ρόλου αναγνώσιμος από άνθρωπο                                                                                                                                                                |
| `agentMdPath`           | `String`               | Ναι        | Απόλυτη διαδρομή προς το αρχείο ορισμού `.md` του πράκτορα                                                                                                                                          |
| `workspaceId`           | `String`               | Ναι        | Ο χώρος εργασίας στον οποίο ανήκει (μη null)                                                                                                                                                        |
| `reportsTo`             | `String?`              | Όχι        | Αναγνωριστικό γονικού πράκτορα                                                                                                                                                                      |
| `skills`                | `AgentSkills`          | Ναι        | Σύνολο αναγνωριστικών δεξιοτήτων                                                                                                                                                                    |
| `persona`               | `String?`              | Όχι        | Οδηγίες συμπεριφοράς σε ελεύθερο κείμενο                                                                                                                                                            |
| `systemPrompt`          | `String?`              | Όχι        | Παράκαμψη της προεπιλεγμένης προτροπής συστήματος                                                                                                                                                   |
| `adapterId`             | `String?`              | Όχι        | Αναγνωριστικό προσαρμογέα συμπερασμού                                                                                                                                                               |
| `modelId`               | `String?`              | Όχι        | Αναγνωριστικό μοντέλου εντός του προσαρμογέα                                                                                                                                                        |
| `strictMode`            | `bool`                 | Όχι        | Προεπιλογή `false`. Γράφεται στη γραμμή και στο `AGENTS.md` του πράκτορα                                                                                                                            |
| `effort`                | `String?`              | Όχι        | Αναγνωριστικό επιπέδου συλλογισμού (π.χ. `'low'`, `'xhigh'`), που προέρχεται από τα `thinkingLevels` του επιλεγμένου μοντέλου                                                                       |
| `contextSize`           | `int?`                 | Όχι        | Μέγιστο μέγεθος παραθύρου πλαισίου                                                                                                                                                                  |
| `role`                  | `AgentRole?`           | Όχι        | Ο ρόλος του πράκτορα                                                                                                                                                                                |
| `capabilities`          | `AgentCapabilities?`   | Όχι        | Προεπιλογή δυνατοτήτων ανά πράκτορα· όταν είναι null, κατά την αποστολή εφαρμόζεται η προεπιλογή σε επίπεδο χρήστη και μια συνομιλία μπορεί ακόμη να την παρακάμψει                                  |
| `monthlyBudgetCents`    | `int`                  | Όχι        | Μηνιαίο ανώτατο όριο δαπάνης σε σεντς (προεπιλογή `0`, χωρίς όριο)                                                                                                                                   |
| `silenceTimeoutMinutes` | `int?`                 | Όχι        | Παράκαμψη του χρονικού ορίου σιωπής σε λεπτά· πρέπει να είναι null ή μεταξύ 1–240 (επαληθεύεται στον κατασκευαστή)                                                                                  |
| `maxConcurrentTasks`    | `int`                  | Όχι        | Προεπιλογή `1`. Μέγεθος χωρητικότητας που αναφέρει το μοντέλο παρουσίας (οι μετρητές των εκτελέσεων που εκτελούνται και των εκτελέσεων σε ουρά συγκρίνονται με αυτό)                                |
| `visibility`            | `AgentVisibility`      | Όχι        | Προεπιλογή `workspace`                                                                                                                                                                              |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Όχι        | Κατάσταση διακυβέρνησης (προεπιλογή `active`). Γράφεται από το σκληρό όριο του προϋπολογισμού και εμφανίζεται στο οργανόγραμμα και στον κατάλογο παρουσίας. Η αποστολή εξακολουθεί να δέχεται εργασία από πράκτορα σε κατάσταση `paused` |
| `budgetPolicyId`        | `String?`              | Όχι        | Αναγνωριστικό κοινής πολιτικής προϋπολογισμού· όταν είναι null εφαρμόζεται απευθείας το `monthlyBudgetCents`                                                                                        |
| `runtimeProfileId`      | `String?`              | Όχι        | Αναγνωριστικό προσαρμοσμένου προφίλ χρόνου εκτέλεσης                                                                                                                                                |
| `createdAt`             | `DateTime`             | Ναι        | Χρονική σήμανση δημιουργίας                                                                                                                                                                         |

Τα `name` και `title` πρέπει και τα δύο να μην είναι κενά (επαληθεύεται στον
κατασκευαστή). Η προεπιλεγμένη τιμή `0` του `monthlyBudgetCents` σημαίνει χωρίς
όριο. Γράψτε ένα ανώτατο όριο με το `agents.upsert`.

## Απαρίθμηση AgentVisibility

| Τιμή        | Περιγραφή                                                     |
| ----------- | ------------------------------------------------------------- |
| `workspace` | Η προεπιλογή· άγνωστες και null αποθηκευμένες τιμές αναλύονται σε αυτήν |
| `private`   | Ιδιωτική για τον χρήστη που τη δημιούργησε                    |

## Απαρίθμηση AgentLifecycleStatus

| Τιμή       | Περιγραφή                                                                                      |
| ---------- | ---------------------------------------------------------------------------------------------- |
| `active`   | Η προεπιλογή. Το `isDispatchable` είναι αληθές μόνο για αυτή την τιμή                            |
| `paused`   | Ορίζεται από το σκληρό όριο του προϋπολογισμού. Εμφανίζεται στον κατάλογο παρουσίας· η αποστολή εξακολουθεί να δέχεται εργασία |
| `archived` | Αποσυρμένη και κρυμμένη από τους ενεργούς καταλόγους                                            |

## Σημαίες AgentCapabilities

Επιλύονται ανά αποστολή: η προεπιλογή του πράκτορα, με εφεδρική την προεπιλογή σε επίπεδο χρήστη όταν αυτή είναι null, και από πάνω μια παράκαμψη ανά συνομιλία. Επιβάλλονται με απουσία — ο μεσίτης διαπιστευτηρίων απλώς δεν εκδίδει ούτε εγχέει ό,τι καλύπτει μια απενεργοποιημένη δυνατότητα.

| Σημαία             | Τύπος  | Προεπιλογή | Περιγραφή                                                                                  |
| ------------------ | ------ | ---------- | ------------------------------------------------------------------------------------------ |
| `canPushToRepo`    | `bool` | `false`    | Κάνει push commits στο απομακρυσμένο αποθετήριο· ελέγχει μαζί με το `canCallGitHubApi` την έγχυση του token του GitHub |
| `canCallGitHubApi` | `bool` | `false`    | Καλεί το api.github.com· ελέγχει την έγχυση του `GH_TOKEN` και τους τομείς εξόδου του GitHub |
| `canCallTicketing` | `bool` | `false`    | Καλεί το API του παρόχου εισιτηρίων· ελέγχει την έγχυση του κλειδιού API του παρόχου και τους τομείς εξόδου του |
| `canAccessNetwork` | `bool` | `true`     | Αυθαίρετη εξερχόμενη κίνηση. Ελέγχει επίσης τα εργαλεία `web_fetch` και `web_search` του harness |

Το `AgentCapabilities.safeDefault` είναι οι τέσσερις προεπιλογές του κατασκευαστή. Το `legacyDefault` (και οι τέσσερις true) χρησιμοποιείται μόνο από τη μετανάστευση που συμπλήρωσε εκ των υστέρων συνομιλίες οι οποίες είχαν δημιουργηθεί πριν υπάρξουν οι δυνατότητες. Ένα παραμορφωμένο ή κενό αποθηκευμένο blob αναλύεται σε `safeDefault`· το παλαιό κλειδί `canCallLinear` διαβάζεται ως `canCallTicketing`.

## AgentSkills

Ένα αμετάβλητο σύνολο αναγνωριστικών δεξιοτήτων χωρίς διάκριση πεζών-κεφαλαίων. Κατά την αποστολή, αυτά τα slugs συγχρονίζονται ως σύνδεσμοι δεξιοτήτων στο overlay του πράκτορα· στη συνέχεια το harness φορτώνει αυτόματα το frontmatter των συνδεδεμένων δεξιοτήτων στην προτροπή.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (παράγωγη)

Δεν αποθηκεύεται. Επτά τιμές. Η σειρά δήλωσης είναι η σειρά προτεραιότητας (`sortPriority`, καθηλωμένη από τεστ), που είναι και η σειρά με την οποία ταξινομεί ο κατάλογος:

| Κατάσταση   | `sortPriority` | Συνθήκη                                                                                                              |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Οποιαδήποτε καταγραφή εκτέλεσης έχει κατάσταση `running`                                                              |
| `blocked`   | 1              | Η ζωτικότητα της πιο πρόσφατης εκτέλεσης είναι `blocked`, `stalled` ή `looping`                                      |
| `failed`    | 2              | Η κατάσταση της πιο πρόσφατης εκτέλεσης είναι `error` ή η ζωτικότητά της είναι `failed` ή `dead`                      |
| `queued`    | 3              | Μια εκτέλεση έχει αποσταλεί αλλά δεν εκτελείται — παρκαρισμένη πίσω από άλλη εκτέλεση του ίδιου πράκτορα, ή εγγεγραμμένη αλλά όχι ακόμη ξεκινημένη |
| `succeeded` | 4              | Η εκτέλεση ολοκληρώθηκε με επιτυχία                                                                                    |
| `idle`      | 5              | Ο πράκτορας έχει εκτελεστεί στο παρελθόν και δεν έχει τίποτα σε εξέλιξη                                              |
| `neverRun`  | 6              | Δεν υπάρχουν καταγραφές εκτέλεσης                                                                                     |

Τα `queued` και `succeeded` είναι **μόνο ανά εκτέλεση**. Το `deriveAgentLiveState`, που υπολογίζει την κατάσταση καταλόγου για έναν πράκτορα, δεν παράγει ποτέ κανένα από τα δύο — επιστρέφει `neverRun`, `running`, `failed`, `blocked` ή `idle`.
