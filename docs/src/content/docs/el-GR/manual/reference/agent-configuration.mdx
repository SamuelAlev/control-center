Αυτή η αναφορά παραθέτει κάθε πεδίο της οντότητας πράκτορα, μαζί με τις απαριθμήσεις και τις σημαίες που χρησιμοποιεί. Για οδηγίες βήμα προς βήμα για τη δημιουργία ή την επεξεργασία ενός πράκτορα στην εφαρμογή, δείτε [Δημιουργία και ρύθμιση πράκτορα](/el-GR/εγχειρίδιο/οδηγοί-πρακτικής/δημιουργία-πράκτορα/).

## Πεδία της οντότητας πράκτορα

| Πεδίο                   | Τύπος                  | Απαιτείται | Περιγραφή                                                                                                                                                                                           |
| ----------------------- | ---------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ναι        | Μοναδικό αναγνωριστικό πράκτορα                                                                                                                                                                     |
| `name`                  | `String`               | Ναι        | Σύντομο αναγνωριστικό για @-αναφορές                                                                                                                                                                |
| `title`                 | `String`               | Ναι        | Τίτλος ρόλου αναγνώσιμος από άνθρωπο                                                                                                                                                                |
| `agentMdPath`           | `String`               | Ναι        | Απόλυτη διαδρομή προς το αρχείο ορισμού `.md` του πράκτορα                                                                                                                                          |
| `workspaceId`           | `String`               | Ναι        | Ο χώρος εργασίας στον οποίο ανήκει (μη null)                                                                                                                                                        |
| `reportsTo`             | `String?`              | Όχι        | Αναγνωριστικό γονικού πράκτορα                                                                                                                                                                      |
| `skills`                | `AgentSkills`          | Ναι        | Σύνολο αναγνωριστικών δεξιοτήτων                                                                                                                                                                    |
| `persona`               | `String?`              | Όχι        | Οδηγίες συμπεριφοράς σε ελεύθερο κείμενο                                                                                                                                                            |
| `systemPrompt`          | `String?`              | Όχι        | Παράκαμψη της προεπιλεγμένης προτροπής συστήματος                                                                                                                                                   |
| `adapterId`             | `String?`              | Όχι        | Αναγνωριστικό προσαρμογέα συμπερασμού                                                                                                                                                               |
| `modelId`               | `String?`              | Όχι        | Αναγνωριστικό μοντέλου εντός του προσαρμογέα                                                                                                                                                        |
| `strictMode`            | `bool`                 | Όχι        | Προεπιλογή `false`. Γράφεται στη γραμμή και στο `AGENTS.md` του πράκτορα                                                                                                                            |
| `effort`                | `String?`              | Όχι        | Αναγνωριστικό επιπέδου συλλογισμού (π.χ. `'low'`, `'xhigh'`), που προέρχεται από τα `thinkingLevels` του επιλεγμένου μοντέλου                                                                       |
| `contextSize`           | `int?`                 | Όχι        | Μέγιστο μέγεθος παραθύρου πλαισίου                                                                                                                                                                  |
| `role`                  | `AgentRole?`           | Όχι        | Ο ρόλος του πράκτορα                                                                                                                                                                                |
| `monthlyBudgetMicros`    | `int`                  | Όχι        | Μηνιαίο ανώτατο όριο δαπάνης σε μικροδολάρια (προεπιλογή `0`, χωρίς όριο)                                                                                                                                   |
| `silenceTimeoutMinutes` | `int?`                 | Όχι        | Παράκαμψη του χρονικού ορίου σιωπής σε λεπτά· πρέπει να είναι null ή μεταξύ 1–240 (επαληθεύεται στον κατασκευαστή)                                                                                  |
| `maxConcurrentTasks`    | `int`                  | Όχι        | Προεπιλογή `1`. Μέγεθος χωρητικότητας που αναφέρει το μοντέλο παρουσίας (οι μετρητές των εκτελέσεων που εκτελούνται και των εκτελέσεων σε ουρά συγκρίνονται με αυτό)                                |
| `visibility`            | `AgentVisibility`      | Όχι        | Προεπιλογή `workspace`                                                                                                                                                                              |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Όχι        | Κατάσταση διακυβέρνησης (προεπιλογή `active`). Γράφεται από το σκληρό όριο του προϋπολογισμού και εμφανίζεται στο οργανόγραμμα και στον κατάλογο παρουσίας. Η αποστολή εξακολουθεί να δέχεται εργασία από πράκτορα σε κατάσταση `paused` |
| `budgetPolicyId`        | `String?`              | Όχι        | Αναγνωριστικό κοινής πολιτικής προϋπολογισμού· όταν είναι null εφαρμόζεται απευθείας το `monthlyBudgetMicros`                                                                                        |
| `runtimeProfileId`      | `String?`              | Όχι        | Αναγνωριστικό προσαρμοσμένου προφίλ χρόνου εκτέλεσης                                                                                                                                                |
| `createdAt`             | `DateTime`             | Ναι        | Χρονική σήμανση δημιουργίας                                                                                                                                                                         |

Τα `name` και `title` πρέπει και τα δύο να μην είναι κενά (επαληθεύεται στον
κατασκευαστή). Η προεπιλεγμένη τιμή `0` του `monthlyBudgetMicros` σημαίνει χωρίς
όριο. Γράψτε ένα ανώτατο όριο με το `agents.upsert`.

## Δικαιώματα

Ένας πράκτορας δεν φέρει σημαίες δικαιωμάτων. Το push, το άνοιγμα και η δημοσίευση pull requests, η εγγραφή σε tracker και η εξερχόμενη δικτυακή κίνηση είναι κατηγορίες ενεργειών (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) που επιλύουν οι [περιορισμοί](/el-GR/εγχειρίδιο/έννοιες/περιορισμοί/) σε πεδίο εφαρμογής χώρου εργασίας, πράκτορα ή χώρου. Το token του GitHub μιας εκτέλεσης έχει πάντα εμβέλεια μόνο ανάγνωσης· τα push περνούν από την πύλη εκτελέσεων πρακτόρων, που ρωτά τον κανόνα `gitPush` πριν τα προωθήσει.

## AgentSkills

Ένα αμετάβλητο σύνολο αναγνωριστικών δεξιοτήτων χωρίς διάκριση πεζών-κεφαλαίων. Κατά την αποστολή, αυτά τα slugs συγχρονίζονται ως σύνδεσμοι δεξιοτήτων στο overlay του πράκτορα· στη συνέχεια το harness φορτώνει αυτόματα το frontmatter των συνδεδεμένων δεξιοτήτων στην προτροπή.

```
{'flutter', 'dart', 'rest-api'}
```

## Hooks κελύφους

Τα hooks κελύφους επιτρέπουν στον κάτοχο του διακομιστή να τρέχει τα δικά του σενάρια γύρω από μια εκτέλεση του ενσωματωμένου μηχανισμού: μία φορά κατά την έναρξη της συνεδρίας, πριν από κάθε κλήση εργαλείου και μετά από κάθε κλήση εργαλείου. Ένα hook είναι αυθαίρετος κώδικας, γι' αυτό τα hooks είναι ρύθμιση του κεντρικού υπολογιστή. Τα ρυθμίζει μόνο ο κάτοχος του διακομιστή, με το χέρι, στον υπολογιστή του διακομιστή. Δεν υπάρχει ρύθμιση στην εφαρμογή ούτε λειτουργία που να τα γράφει.

Για έναν πράκτορα, τα hooks βρίσκονται στον δικό του φάκελο μέσα στον κατάλογο δεδομένων του διακομιστή:

```text
<data dir>/_agent_hooks/<workspace id>/<agent slug>/hooks.json
```

Το `<agent slug>` είναι το όνομα του φακέλου του πράκτορα στον χώρο εργασίας (`agents/<slug>/`). Ο φάκελος αυτός βρίσκεται έξω από τον αποθηκευτικό χώρο κάθε χώρου εργασίας, και κάθε sandbox κρύβει τον κατάλογο δεδομένων, οπότε κανένα μέλος, καμία εκτέλεση ή τερματικό δεν μπορεί να τον γράψει.

Το `hooks.json` αντιστοιχίζει οποιοδήποτε από τα τρία κλειδιά σε ένα σενάριο, με διαδρομή σχετική με τον φάκελο των hooks:

| Κλειδί         | Πότε εκτελείται                  | Τι σημαίνει ο κωδικός εξόδου                                   |
| -------------- | -------------------------------- | -------------------------------------------------------------- |
| `sessionStart` | Μία φορά, όταν ξεκινά η εκτέλεση | Τίποτα· το hook μόνο παρατηρεί                                 |
| `preTool`      | Πριν από κάθε κλήση εργαλείου    | Το `0` επιτρέπει την κλήση· οτιδήποτε άλλο την απορρίπτει      |
| `postTool`     | Μετά από κάθε κλήση εργαλείου    | Τίποτα· το hook μόνο παρατηρεί                                 |

- Κάθε σενάριο ξεκινά ως δικό του εκτελέσιμο, χωρίς κέλυφος και χωρίς ορίσματα, άρα πρέπει να είναι εκτελέσιμο και να ξεκινά με γραμμή shebang. Παίρνει το συμβάν ως JSON στο stdin: το όνομα του συμβάντος και, για τα hooks εργαλείων, το όνομα του εργαλείου με τα ορίσματά του (`preTool`) ή το αποτέλεσμά του (`postTool`).
- Ένα hook τρέχει ως μία από τις διεργασίες εργαλείων της εκτέλεσης, στον φάκελο του πράκτορα για την εκτέλεση. Όταν ο διακομιστής βάζει τους πράκτορες σε sandbox, τρέχει μέσα στο sandbox της εκτέλεσης. Παίρνει ελάχιστο περιβάλλον και κανένα από τα διαπιστευτήρια της εκτέλεσης: ούτε token κώδικα ή παρόχου ούτε πρόσβαση στην πύλη.
- Κάθε hook έχει 30 δευτερόλεπτα. Η έξοδός του διαβάζεται και πετιέται.
- Το `preTool` αποτυγχάνει κλειστά. Ένας μη μηδενικός κωδικός εξόδου, ένα timeout ή ένα σενάριο που δεν μπορεί να ξεκινήσει απορρίπτει την κλήση εργαλείου.
- Μια διαδρομή που είναι απόλυτη, λείπει ή βγαίνει έξω από τον φάκελο των hooks (μετά την επίλυση συνδέσμων) απορρίπτεται, και το αρχείο καταγραφής της εκτέλεσης λέει ποιο hook απορρίφθηκε και γιατί. Ένα απορριφθέν ή μη αναγνώσιμο hook `preTool` απορρίπτει κάθε κλήση εργαλείου μέχρι να διορθωθεί.
- Ένα μπλοκ `hooks` στο `.agents/harness.json`, είτε σε αποθετήριο είτε στον δικό του φάκελο του πράκτορα, αγνοείται. Ένα αποθετήριο είναι συχνά κώδικας κάποιου άλλου, και ο φάκελος του πράκτορα μπορεί να γραφτεί από μέλη και εκτελέσεις. Το αρχείο καταγραφής της εκτέλεσης λέει ότι το μπλοκ αγνοήθηκε και από πού διαβάζονται τα hooks.

Τα hooks κελύφους ισχύουν μόνο για τον ενσωματωμένο μηχανισμό. Ένα ρυθμισμένο hook `preTool` ή `postTool` κάνει την εκτέλεση να καλεί τα εργαλεία της ένα κάθε φορά.

## AgentLiveState (παράγωγη)

Δεν αποθηκεύεται. Επτά τιμές. Η σειρά δήλωσης είναι η σειρά προτεραιότητας (`sortPriority`, καθηλωμένη από τεστ), που είναι και η σειρά με την οποία ταξινομεί ο κατάλογος:

| Κατάσταση   | `sortPriority` | Συνθήκη                                                                                                              |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Οποιαδήποτε καταγραφή εκτέλεσης έχει κατάσταση `running`                                                              |
| `blocked`   | 1              | Η ζωτικότητα της πιο πρόσφατης εκτέλεσης είναι `blocked`, `stalled` ή `looping`                                      |
| `failed`    | 2              | Η κατάσταση της πιο πρόσφατης εκτέλεσης είναι `error` ή η ζωτικότητά της είναι `failed` ή `dead`                      |
| `queued`    | 3              | Μια εκτέλεση έχει αποσταλεί αλλά δεν εκτελείται — παρκαρισμένη πίσω από άλλη εκτέλεση του ίδιου πράκτορα, ή εγγεγραμμένη αλλά όχι ακόμη ξεκινημένη |
| `succeeded` | 4              | Η εκτέλεση ολοκληρώθηκε με επιτυχία                                                                                    |
| `idle`      | 5              | Ο πράκτορας έχει εκτελεστεί στο παρελθόν και δεν έχει τίποτα σε εξέλιξη                                              |
| `neverRun`  | 6              | Δεν υπάρχουν καταγραφές εκτέλεσης                                                                                     |

Τα `queued` και `succeeded` είναι **μόνο ανά εκτέλεση**. Το `deriveAgentLiveState`, που υπολογίζει την κατάσταση καταλόγου για έναν πράκτορα, δεν παράγει ποτέ κανένα από τα δύο — επιστρέφει `neverRun`, `running`, `failed`, `blocked` ή `idle`.
