Οι συντομεύσεις προέρχονται από ένα μητρώο `const`, το `KeybindingRegistry` στο `lib/core/constants/keybindings.dart`. Περιέχει **49 δεσμεύσεις**. Οι **Ρυθμίσεις → Εσείς → Συντομεύσεις πληκτρολογίου** αποδίδουν αυτό το μητρώο ως **αναφορά μόνο για ανάγνωση**: δεν υπάρχει διεπαφή επαναχορήγησης ούτε αρχείο συντομεύσεων χρήστη.

Το `Cmd` παρακάτω είναι ο κύριος τροποποιητής εντολών — ⌘ στο macOS, Ctrl στα Windows και στο Linux. Μια δέσμευση ενεργοποιείται μόνο όταν η εντολή της έχει καταχωρισμένο χειριστή στην τρέχουσα οθόνη και ισχύει η ρήτρα `when` της· το `!textInputFocus` σημαίνει ότι το πλήκτρο περνά αντ' αυτού σε ένα πεδίο κειμένου που έχει την εστίαση.

Δεν υπάρχει συντόμευση πλοήγησης με πλήκτρα αριθμών. Τα εισερχόμενα, τα εισιτήρια, τα pull requests και τα υπόλοιπα προσεγγίζονται από την πλαϊνή στήλη ή με ⌘K. Ούτε η παρατηρησιμότητα έχει συντόμευση.

## Γενικές (19)

Πεδίο εφαρμογής `global`, οπότε είναι ενεργές οπουδήποτε στο κέλυφος.

## Λίστα pull requests (3)

Πεδίο εφαρμογής `/pull-requests`. Όλες απαιτούν `route == '/pull-requests'` και κανένα πεδίο κειμένου με εστίαση, οπότε δεν ενεργοποιούνται όταν η διαδρομή λεπτομερειών PR είναι ανοιχτή πάνω από τη λίστα.

| Συντόμευση | Ενέργεια          |
| ---------- | ----------------- |
| `R`        | Ανανέωση          |
| `Enter`    | Άνοιγμα PR        |
| `F`        | Άνοιγμα μενού φίλτρων |

Το `Enter` (`pr.list-open`) δηλώνεται στο μητρώο και εμφανίζεται στην αναφορά συντομεύσεων πληκτρολογίου, αλλά **η οθόνη της λίστας δεν καταχωρίζει χειριστή γι' αυτό**, οπότε προς το παρόν δεν ενεργοποιείται. Το `F` ανοίγει το μενού φίλτρων (`pr.list-open-filter`), όχι την αναζήτηση.

## Λεπτομέρειες pull request (2)

Πεδίο εφαρμογής `/pull-requests/`. Η ανανέωση απαιτεί να μην υπάρχει πεδίο κειμένου με εστίαση. Το κλείσιμο καρτέλας δεν έχει φρουρό εισόδου κειμένου (ένας συνδυασμός με ⌘ δεν είναι ποτέ απλό κείμενο) και έχει κανονική έκφραση διαδρομής, ώστε να μην ενεργοποιείται στη λίστα.

| Συντόμευση     | Ενέργεια        | Συνθήκη                        |
| -------------- | --------------- | ------------------------------ |
| `R`            | Ανανέωση        | Δεν πληκτρολογείτε σε πεδίο    |
| `Cmd/Ctrl + W` | Κλείσιμο καρτέλας | Σε τοποθεσία `/pull-requests/<…>` |

Η εναλλαγή καρτελών (`1`/`2`/`3`), η προβολή/σύμπτυξη αρχείου (`V`/`C`), η λίστα αρχείων (`T`) και η αναζήτηση στο diff (`Cmd/Ctrl + F`) ανήκουν στον δικό του χειριστή του προβολέα diff — δείτε [Πλήκτρα προβολέα diff εκτός του μητρώου](#πλήκτρα-προβολέα-diff-εκτός-του-μητρώου).

## Χώροι (9)

Πεδίο εφαρμογής `/spaces`. Οι ρήτρες `when` χρησιμοποιούν κανονική έκφραση, ώστε να ενεργοποιούνται και στη λίστα χώρων (`/spaces`) και σε έναν επιλεγμένο χώρο (`/spaces/<id>`).

| Συντόμευση             | Ενέργεια                            | Συνθήκη                        |
| ---------------------- | ----------------------------------- | ------------------------------ |
| `Enter`                | Αποστολή μηνύματος                  | —                              |
| `Cmd/Ctrl + N`         | Νέος χώρος                          | Σε διαδρομή `/spaces`          |
| `J`                    | Επόμενος χώρος                      | Δεν πληκτρολογείτε σε πεδίο    |
| `K`                    | Προηγούμενος χώρος                  | Δεν πληκτρολογείτε σε πεδίο    |
| `Cmd/Ctrl + Shift + D` | Υπαγόρευση με πίεση για ομιλία      | —                              |
| `Cmd/Ctrl + T`         | Άνοιγμα καρτέλας επεξεργαστή        | Σε διαδρομή `/spaces`          |
| `Cmd/Ctrl + W`         | Κλείσιμο καρτέλας επεξεργαστή       | Σε διαδρομή `/spaces`          |
| `Cmd/Ctrl + B`         | Εναλλαγή πλαϊνής στήλης επεξεργαστή | Σε διαδρομή `/spaces`          |
| `Cmd/Ctrl + P`         | Μετάβαση σε αρχείο                  | Σε διαδρομή `/spaces`          |

Η «Μετάβαση σε αρχείο» ανοίγει έναν επιλογέα με τα αρχεία της συνομιλίας. Χωρίς πληκτρολόγηση εμφανίζει τα αρχεία που ανοίξατε πιο πρόσφατα· όταν πληκτρολογείτε, αναζητά σε όλα τα αρχεία των worktree της συνομιλίας. Το `Enter` ανοίγει το επιλεγμένο αρχείο σε νέα καρτέλα, το `Cmd/Ctrl + Enter` ή το κουμπί διαχωρισμού στη γραμμή το ανοίγει σε ένα τμήμα στα δεξιά, και το `×` σε μια γραμμή πρόσφατου αρχείου το αφαιρεί από τη λίστα.

Η αποστολή με Enter ανήκει στο πεδίο κειμένου του συνθέτη· η πίεση για ομιλία ανήκει στο κουμπί μικροφώνου του συνθέτη (δικός του χειριστής πληκτρολογίου υλικού). Και τα δύο αναφέρονται στο μητρώο για την αναφορά ρυθμίσεων.

## Πλήκτρα προβολέα diff εκτός του μητρώου

Ο προβολέας diff PR τα χειρίζεται μόνος του (`PrDiffKeyboardHandler`). Η αναζήτηση/η προβολή/η σύμπτυξη αναφέρονται στα σχόλια του μητρώου μόνο για την αναφορά ρυθμίσεων — δεν έχει καταχωριστεί χειριστής αποστολέα, οπότε ο αποστολέας τα αφήνει στην προβολή diff. Δεν εμφανίζονται ως δικές τους γραμμές στην αναφορά συντομεύσεων πληκτρολογίου.

| Συντόμευση      | Ενέργεια                                                |
| --------------- | ------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Αναζήτηση στο diff                                      |
| `J` / `K`       | Επόμενο / προηγούμενο αρχείο                             |
| `V`             | Εναλλαγή προβολής στο αρχείο με εστίαση                  |
| `C`             | Εναλλαγή σύμπτυξης στο αρχείο με εστίαση                 |
| `T`             | Εμφάνιση λίστας αρχείων                                 |
| `Enter`         | Επόμενη αντιστοιχία αναζήτησης (μόνο όσο είναι ανοιχτή η αναζήτηση στο diff) |
| `Shift + Enter` | Προηγούμενη αντιστοιχία αναζήτησης                      |
| `Escape`        | Κλείσιμο της αναζήτησης στο diff ή καθαρισμός της επιλογής κειμένου του diff |
| `Cmd/Ctrl + C`  | Αντιγραφή της επιλογής του diff                         |

## Συνδυασμοί που δεσμεύει το πρόγραμμα περιήγησης

Στην έκδοση web, το πρόγραμμα περιήγησης καταναλώνει ορισμένους συνδυασμούς επιτάχυνσης πριν τους δει η σελίδα, οπότε οι αντίστοιχες δεσμεύσεις δεν μπορούν ποτέ να ενεργοποιηθούν εκεί. Λειτουργούν κανονικά στην επιφάνεια εργασίας. Δεσμευμένα σε συνδυασμό με τον κύριο τροποποιητή εντολών: `T`, `W`, `N` και τα ψηφία `1`–`9`.

Αυτό καλύπτει την εναλλαγή χώρου εργασίας με `Cmd/Ctrl + Alt + 1`–`9`, το `Cmd/Ctrl + N` (νέος χώρος, νέος χώρος εργασίας, νέος πράκτορας, προσθήκη αποθετηρίου) και τα `Cmd/Ctrl + T` / `Cmd/Ctrl + W` στους χώρους και στις λεπτομέρειες PR.
