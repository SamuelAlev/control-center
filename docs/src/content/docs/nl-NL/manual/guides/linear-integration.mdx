Linear heeft in Control Center twee identiteiten, en beide zijn aanmeldingen in
de browser: die van jou, voor wat jij doet, en de Control Center-app van de
werkruimte, voor wat agenten en pipelines doen. Tickets, projecten, links,
medewerkers, delegatie en toewijzing werken allemaal tegen de eigen database van
Control Center, zonder dat er een externe dienst nodig is — zie
[Tickets maken en beheren](/nl-NL/handleiding/gidsen/tickets-beheren/).

## Vereisten

- De server kan mensen bij Linear aanmelden: via Control Center Connect, of met
  de eigen Linear-applicatie van de server
  ([Je eigen Linear-applicatie registreren](#je-eigen-linear-applicatie-registreren)).
  De servereigenaar kiest in **Instellingen → Server → Single sign-on**
- Een beheerder van de werkruimte, om Linear als ticketingprovider te kiezen en
  Linear-automatisering te verbinden

## Linear kiezen voor de werkruimte

1. Ga naar **Instellingen → Werkruimte → Algemeen** en zoek de kaart **Tickets**
2. Zet **Ticketingprovider** op **Linear**

Tickets die je vanaf dan aanmaakt, krijgen het stempel `provider: linear`.
**Lokaal** houdt tickets in de eigen database van deze server en verbergt de
Linear-rijen: er valt niets te authenticeren.

## Inloggen bij Linear

Op dezelfde kaart is de rij **Linear** van jou:

1. Klik op **Inloggen bij Linear**
2. Keur goed in je browser
3. Met de eigen applicatie van de server merkt het dialoogvenster dat vanzelf.
   Via Connect typ je de code van 8 tekens die de browser toont, of laat je de
   browser Control Center openen via de `control-center://`-link

Alles wat je vanuit Control Center in Linear doet, draait op deze aanmelding en
niets anders. Ben je niet aangemeld, dan vraagt de app je om je aan te melden in
plaats van als iemand anders te handelen.

## Linear-automatisering verbinden

De rij **Linear-automatisering** is de Control Center-app van de werkruimte in
Linear. Ticketsynchronisatie, pipelines en agenten schrijven ermee, dus
geautomatiseerde issues en opmerkingen verschijnen als Control Center in plaats
van als een persoon.

1. Een beheerder van de werkruimte klikt op **Linear verbinden voor
   automatisering**
2. Die keurt de app goed voor de Linear-werkruimte in de browser, zoals
   hierboven

De rij toont daarna "Verbonden met _je Linear-werkruimte_". Alleen beheerders van
de werkruimte kunnen hem verbinden of loskoppelen.

In de sandbox van een agent komen geen Linear-inloggegevens: agenten schrijven
tickets via de eigen tools van Control Center, die eerst de regel **Naar een
externe tracker schrijven** raadplegen.

## Je eigen Linear-applicatie registreren

Gebruik je eigen applicatie als je **Mijn eigen apps gebruiken** hebt gekozen.
De applicatie van de server geldt alleen onder **Mijn eigen apps gebruiken**. Met de Connect van Control Center of een eigen Connect verzorgt Connect Linear, en de applicatie van de server en de service-API-sleutel blijven opgeslagen maar ongebruikt. Een applicatie van de werkruimte ([hieronder](#geef-één-werkruimte-een-eigen-linear-app)) geldt in alle modi.

1. Maak een OAuth-applicatie aan op
   [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new)
2. Voeg beide callback-URL's toe die **Instellingen → Server → Single sign-on →
   Provider-apps → Linear** onder **Callback-URL’s** toont, letterlijk:
   `<server origin>/oauth/linear/callback` en
   `<server origin>/oauth/linear_app/callback`
3. Plak de **Client-id** in het blok Linear

Er is geen client-secret: de server meldt zich aan met PKCE. De refreshtokens van
Linear verlopen na 30 dagen zonder gebruik, dus de server vernieuwt één keer per
dag elke Linear-aanmelding die ouder is dan 20 dagen.

Hetzelfde blok neemt een optionele **Service-API-sleutel** aan. Dat zijn de eigen
Linear-inloggegevens van de server voor automatisering in werkruimtes die geen
Linear-automatisering hebben verbonden. Bewaar hem in **Instellingen** of in het
`.env`-bestand van de server als `LINEAR_API_KEY`: de server weigert te starten
wanneer `LINEAR_API_KEY` in zijn procesomgeving is geëxporteerd.

## Geef één werkruimte een eigen Linear-app

Een werkruimte kan zich bij Linear aanmelden via een eigen applicatie in plaats van die van de server. Alleen een
beheerder of eigenaar van de werkruimte kan dit instellen.

1. Maak een Linear OAuth-applicatie aan zoals hierboven
2. Ga naar **Instellingen → Werkruimte → Algemeen → Provider-apps** en open **Linear**
3. Kies **Eigen app van deze werkruimte gebruiken**
4. Voeg beide callback-URL's die de regel onder **Callback-URL’s** toont toe aan de Linear-applicatie, precies zoals ze er staan
5. Plak de **Client-id** en eventueel de **Service-API-sleutel** voor de automatisering van deze werkruimte

De applicatie van de werkruimte beantwoordt elke Linear-aanmelding en automatiseringsaanvraag in deze werkruimte,
ongeacht hoe de server mensen aanmeldt. Er wordt nooit teruggevallen op de applicatie van de server of op Connect:
zolang er geen client-id is, staat Linear uit in deze werkruimte en zegt de regel wat er ontbreekt. De
service-API-sleutel wordt alleen hier gebruikt; zonder die sleutel vereist synchronisatie **Linear verbinden voor automatisering**.

Overschakelen tussen de applicatie van de server en die van de werkruimte, of het wijzigen van het client-id van de
werkruimte, meldt iedereen in deze werkruimte af bij Linear en koppelt de automatisering los. Zij melden zich opnieuw
aan via de nieuwe applicatie. **App van deze server gebruiken** verwijdert de opgeslagen velden van de werkruimte.
Geheimen zijn alleen schrijfbaar: de regel toont alleen of er een is opgeslagen. Andere werkruimten op de server
worden niet beïnvloed.

## Problemen oplossen

### De rij Linear zegt dat aanmelden niet is ingesteld

De server heeft geen eigen Linear-applicatie en ook geen Connect. De
servereigenaar kiest er een in **Instellingen → Server → Single sign-on**. Gebruikt de werkruimte een eigen applicatie, dan staat er in de regel in plaats daarvan dat de installatie niet is voltooid: een beheerder van de werkruimte voegt het client-id toe onder **Instellingen → Werkruimte → Algemeen → Provider-apps**.

### Ticketsynchronisatie mislukt met een authenticatiefout

De werkruimte heeft geen Linear-automatisering verbonden en de server heeft geen
service-API-sleutel, dus de synchronisatie heeft geen inloggegevens. Een
beheerder van de werkruimte klikt op **Linear verbinden voor automatisering**.

### Bij het verbinden van automatisering staat dat de Linear-werkruimte elders is verbonden

De Control Center-app van die Linear-werkruimte is al verbonden met een andere
Control Center-server.
