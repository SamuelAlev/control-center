Plak een Linear-API-sleutel op de server bij je gebruiker, net zoals je een
forge verbindt. Tickets, projecten, links, medewerkers, delegatie en toewijzing
werken allemaal tegen de eigen database van Control Center, zonder dat er een
externe dienst nodig is — zie
[Tickets maken en beheren](/nl-NL/handleiding/gidsen/tickets-beheren/).

## Je Linear-sleutel opslaan

**Ticketing-API-sleutel** staat bij **Instellingen → Werkruimte → Algemeen**,
op de kaart **Tickets**. Hij slaat de sleutel op de server op bij je
gebruikers-id. De eigen sleutel van de server voor werk zonder toezicht komt uit
`LINEAR_API_KEY` of de kaart **Provider-apps**. In de sandbox van een agent komt
geen ticketingsleutel: agenten schrijven tickets via de eigen tools van Control
Center, die eerst de regel **Naar een externe tracker schrijven** raadplegen.

## Nieuwe tickets als Linear stempelen

**Ticketingprovider** (de eerste stap van de onboarding, en
`/workspaces/<workspaceId>/api-keys`) biedt `local` en `linear`. Als je
`linear` kiest, wordt `provider: linear` gestempeld op tickets die je vanaf dan
aanmaakt.
