Een project is een groepering van tickets binnen één werkruimte, gericht op een
gedeeld doel. Projecten bestaan alleen in Control Center — ze synchroniseren
nooit naar een externe leverancier zoals Linear.

## Een project aanmaken

1. Vouw in de zijbalk van de werkruimte de groep **Tickets** uit. Die toont
   **Alle tickets**, één rij per niet-gearchiveerd project en dan
   **Nieuw project**.
2. Klik op **Nieuw project**.
3. Vul **Projectnaam** in, eventueel een **Beschrijving**, en kies een **Kleur**.
4. Druk op **Project aanmaken**.

Je komt op het overzicht van het nieuwe project terecht en het project
verschijnt als rij in de zijbalk onder **Tickets**.

## Tickets aan een project toevoegen

Project is een veld per ticket, dat je op twee plaatsen instelt:

- Open het ticket en stel **Project** in het eigenschappenpaneel in.
- Klik met de rechtermuisknop op het ticket in de lijst en gebruik het submenu
  **Project**.

De keuzelijst in het eigenschappenpaneel biedt ook **Nieuw project**, zodat je
een ticket kunt onderbrengen in een project dat je ter plekke aanmaakt. Met
**Geen project** wis je het veld.

Een ticket hoort bij maximaal één project.

:::note[Project is geen bulkactie]
De zwevende balk die verschijnt wanneer je meerdere tickets selecteert, dekt
status, prioriteit, toewijzing, labels en verwijderen. Er is geen projectchip,
dus veel tickets onderbrengen betekent ze één voor één doen.
:::

Je kunt ook vanuit het project beginnen: met **Nieuw ticket** op het overzicht
van het project maak je een ticket aan en onderbreng je het daar.

## De voortgang van een project bekijken

Open een project via zijn rij in de zijbalk, of ga naar
`/workspaces/<workspace-id>/projects/<project-id>`.

Het overzicht toont het pictogram en de naam van het project, een statusbadge,
de beschrijving en een voortgangsbalk met klaar-van-totaal. Daaronder staan de
tickets van het project gegroepeerd per status.

Het aggregeert niets anders — er is geen uitsplitsing per toegewezen persoon en
geen verdeling naar prioriteit. Filter daarvoor in plaats daarvan de
hoofdticketlijst.

## De status van een project wijzigen

Projecten hebben drie statussen:

| Status        | Betekenis            |
| ------------- | -------------------- |
| **Actief**    | Er wordt aan gewerkt |
| **Voltooid**  | Al het werk is gedaan |
| **Gearchiveerd** | Historische referentie |

Gebruik het menu **⋯** in de projectheader. Het biedt **Project bewerken**,
**Markeren als voltooid** / **Markeren als actief**, **Archiveren** /
**Herstellen** en **Project verwijderen**.

Archiveren verbergt het project uit de zijbalklijst en uit de
ticketkeuzelijsten. Het is omkeerbaar — met **Herstellen** zet je het project
terug naar actief — maar zolang een project gearchiveerd is, is het alleen via
de URL bereikbaar.

## Projecten die voor je worden aangemaakt

Wanneer je een orkestratie goedkeurt, wordt er een project aangemaakt en wordt
het bovenliggende ticket daarin ondergebracht, naast alles wat je handmatig hebt
ondergebracht. Gegenereerde werkitems zijn pipeline-stappen, geen ticketrijen,
dus ze verschijnen niet op het projectbord. Dat is het enige geautomatiseerde
pad: geen enkele pipelinenode maakt tickets aan, dus een pipeline kan een
project niet vullen. Zie
[Een orkestratie uitvoeren](/nl-NL/handleiding/gidsen/orkestratie-uitvoeren/).

:::note[Projecten zijn een oppervlak voor de operator]
Maak projecten aan, toon ze, werk ze bij en verwijder ze in de app. Agenten
hebben geen projecttools.
