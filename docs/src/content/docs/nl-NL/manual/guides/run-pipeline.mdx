Deze gids gaat over het met de hand starten van een run. Wil je een run volgen,
de uitvoer van een stap lezen of een fout herstellen, zie
[Pipeline-runs monitoren](/nl-NL/handleiding/gidsen/pipelines-monitoren/).

## Een run starten

1. Klik op **Pipelines** in de zijbalk van de werkruimte.
2. Druk op **Pipeline uitvoeren** in de koptekst. Je komt uit op het startscherm
   (`/workspaces/<workspace-id>/pipelines/run`).
3. Kies een sjabloon in de linkerkolom. Elke kaart toont de naam van het sjabloon,
   de beschrijving en of het invoer verwacht.
4. Vul het invoerformulier aan de rechterkant in. Verplichte velden blokkeren de
   knop tot ze een waarde hebben; een sjabloon zonder invoer zegt dat zelf.
5. Druk op **Pipeline uitvoeren**.

Je komt uit op de detailpagina van de run, met de tijdlijn en het grafiekcanvas
live.

## Als de linkerkolom leeg is

Het startscherm toont een sjabloon alleen wanneer **beide** waar zijn:

- De schakelaar van het sjabloon staat aan in **Instellingen → Werkruimte →
  Pipelinesjablonen**.
- **Handmatige uitvoering toestaan** staat aan in het dialoogvenster **Handmatige
  uitvoering** van de sjablooneditor — die schakelaar is wat de `manual`-trigger
  aanmaakt die het startscherm leest.

Acht van de dertien ingebouwde sjablonen worden uitgeschakeld geleverd:
`external_pr_welcome`, `cross_review`, `ticket_to_pr`, `pr_triage`,
`pre_merge_gate`, `release_notes`, `dep_audit` en `pr_digest`. De engine weigert
een uitgeschakeld sjabloon te starten, dus zet de schakelaar aan voordat je het
hier zoekt.

Er is geen actie **Uitvoeren** per sjabloon in de sjablonenlijst en geen
uitvoerknop in de editor — het startscherm is het enige handmatige toegangspunt.

## Een repository-invoer invullen

Een invoer van het type **Repository** toont een kiezer over de geregistreerde
repo's van de werkruimte. Als je er een kiest, worden `repo_id`,
`repo_local_path`, `repo_full_name` en — wanneer de repo een GitHub-remote
heeft — `repo_owner` en `repo_name` in de run-payload gezet, zodat
stroomafwaartse stappen kunnen lezen wat ze nodig hebben.

## De run volgen

De detailpagina van de run heeft drie delen: een metastrook (starttijd, actieve
duur, stapvoortgang, een foutbanner, **Opnieuw proberen** en **Verwijderen**),
een in- en uitklapbare tijdlijn met duur en kosten per stap, en het
grafiekcanvas. Als je een node selecteert, opent het detailpaneel van die stap.

[Pipeline-runs monitoren](/nl-NL/handleiding/gidsen/pipelines-monitoren/)
behandelt dat allemaal, inclusief hoe je een opgeschorte stap leest en wat je
moet doen als er een faalt.

Elke run die je vanuit de app start, is een echte run.
