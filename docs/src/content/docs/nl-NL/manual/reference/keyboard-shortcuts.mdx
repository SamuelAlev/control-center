Sneltoetsen komen uit één `const`-register, `KeybindingRegistry` in `lib/core/constants/keybindings.dart`. Het bevat **49 bindings**. Instellingen → Jij → Sneltoetsen toont dat register als een **alleen-lezen naslagwerk**: er is geen UI om sneltoetsen opnieuw toe te wijzen, en er is geen bestand met gebruikerssneltoetsen.

Hieronder is `Cmd` de primaire commandotoets — ⌘ op macOS, Ctrl op Windows en Linux. Een binding gaat alleen af wanneer het bijbehorende commando een geregistreerde handler heeft op het huidige scherm en de `when`-clausule ervan waar is; `!textInputFocus` betekent dat de toets in plaats daarvan wordt doorgegeven aan een tekstveld met focus.

Er is geen navigatiesneltoets met cijfertoetsen. Postvak in, tickets, pull requests en de rest bereik je via de zijbalk of ⌘K. Observability heeft ook geen sneltoets.

## Globaal (19)

Scope `global`, dus ze zijn overal in de shell actief.

## Pull request-lijst (3)

Scope `/pull-requests`. Ze vereisen allemaal `route == '/pull-requests'` en dat er geen tekstveld focus heeft, dus ze gaan niet af terwijl de PR-detailroute over de lijst heen openstaat.

| Sneltoets | Actie            |
| --------- | ---------------- |
| `R`       | Vernieuwen       |
| `Enter`   | PR openen        |
| `F`       | Filtermenu openen |

`Enter` (`pr.list-open`) staat in het register en verschijnt in het sneltoetsenoverzicht, maar **het lijstscherm registreert er geen handler voor**, dus op dit moment gaat hij niet af. `F` opent het filtermenu (`pr.list-open-filter`), niet zoeken.

## Pull request-detail (2)

Scope `/pull-requests/`. Vernieuwen vereist dat er geen tekstveld focus heeft. Tabblad sluiten heeft geen bescherming tegen tekstinvoer (een toetscombinatie met ⌘ is nooit platte tekst) en een routeregex, zodat hij niet afgaat in de lijst.

| Sneltoets      | Actie           | Voorwaarde                          |
| -------------- | --------------- | ----------------------------------- |
| `R`            | Vernieuwen      | Niet terwijl je in een veld typt      |
| `Cmd/Ctrl + W` | Tabblad sluiten | Op een `/pull-requests/<…>`-locatie |

Tabbladen wisselen (`1`/`2`/`3`), een bestand als bekeken markeren of samenvouwen (`V`/`C`), de bestandenlijst (`T`) en zoeken in de diff (`Cmd/Ctrl + F`) vallen onder de eigen handler van de diff-viewer — zie [Sneltoetsen van de diff-viewer buiten het register](#sneltoetsen-van-de-diff-viewer-buiten-het-register).

## Profielen van GitHub-gebruikers en -teams (3)

Scope `/users/`. De `when`-clausule is een regex op `/users/<login>` **of** `/teams/<organization>/<slug>`, plus dat er geen tekstveld focus heeft.

| Sneltoets      | Actie          |
| -------------- | -------------- |
| `R`            | Vernieuwen     |
| `/`            | Zoeken focussen |
| `Cmd/Ctrl + F` | Zoeken focussen |

## Ruimtes (9)

Scope `/spaces`. De `when`-clausules gebruiken een regex, zodat ze zowel in de ruimtelijst (`/spaces`) als in een geselecteerde ruimte (`/spaces/<id>`) afgaan.

| Sneltoets              | Actie                  | Voorwaarde            |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | Bericht versturen      | —                     |
| `Cmd/Ctrl + N`         | Nieuwe ruimte          | Op een `/spaces`-route |
| `J`                    | Volgende ruimte        | Niet terwijl je in een veld typt |
| `K`                    | Vorige ruimte          | Niet terwijl je in een veld typt |
| `Cmd/Ctrl + Shift + D` | Druk om te spreken (dicteren) | —              |
| `Cmd/Ctrl + T`         | Editortabblad openen   | Op een `/spaces`-route |
| `Cmd/Ctrl + W`         | Editortabblad sluiten  | Op een `/spaces`-route |
| `Cmd/Ctrl + B`         | Editor-zijbalk wisselen | Op een `/spaces`-route |
| `Cmd/Ctrl + P`         | Ga naar bestand         | Op een `/spaces`-route |

Ga naar bestand opent een kiezer over de bestanden van het gesprek. Zonder invoer toont die de bestanden die je het laatst hebt geopend; typen doorzoekt alle bestanden in de worktrees van het gesprek. `Enter` opent het geselecteerde bestand in een nieuw tabblad, `Cmd/Ctrl + Enter` of de splitsknop op de rij opent het in een deelvenster aan de rechterkant, en het `×` op een recente rij haalt het uit de lijst.

Verzenden met Enter valt onder het tekstveld van de composer; druk-om-te-spreken valt onder de microfoonknop van de composer (met een eigen handler voor een hardwaretoetsenbord). Beide staan in het register vermeld voor het instellingenoverzicht.

## Sneltoetsen van de diff-viewer buiten het register

De PR-diff-viewer handelt deze zelf af (`PrDiffKeyboardHandler`). Zoeken/bekeken/samenvouwen staan alleen in de commentaren van het register vermeld voor het instellingenoverzicht — er is geen dispatcher-handler geregistreerd, dus de dispatcher laat ze aan de diff-weergave. Ze verschijnen niet als eigen rijen in het sneltoetsenoverzicht.

| Sneltoets       | Actie                                                |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Zoeken in diff                                       |
| `J` / `K`       | Volgend / vorig bestand                              |
| `V`             | Bekeken-markering aan- of uitzetten op het bestand met focus |
| `C`             | Samenvouwen aan- of uitzetten op het bestand met focus |
| `T`             | Bestandenlijst tonen                                 |
| `Enter`         | Volgend zoekresultaat (alleen terwijl zoeken-in-diff open is) |
| `Shift + Enter` | Vorig zoekresultaat                                  |
| `Escape`        | Zoeken-in-diff sluiten, of de tekstselectie in de diff wissen |
| `Cmd/Ctrl + C`  | De diff-selectie kopiëren                            |

## Door de browser gereserveerde combinaties

In de webbuild verbruikt de browser sommige acceleratoren voordat de pagina ze ziet, dus de bijbehorende bindings kunnen daar nooit afgaan. Op de desktop werken ze normaal. Gereserveerd in combinatie met de primaire commandotoets: `T`, `W`, `N` en de cijfers `1`–`9`.

Dat geldt voor wisselen tussen werkruimtes met `Cmd/Ctrl + Alt + 1`–`9`, voor `Cmd/Ctrl + N` (nieuwe ruimte, nieuwe werkruimte, nieuwe agent, repository toevoegen) en voor `Cmd/Ctrl + T` / `Cmd/Ctrl + W` in ruimtes en PR-detail.
