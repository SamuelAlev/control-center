Deze referentie somt elk veld van de agent-entiteit op, plus de enums en vlaggen die hij gebruikt. Zie [Een agent maken en configureren](/nl-NL/handleiding/gidsen/agent-maken/) voor een stap-voor-stap doorloop van het maken of bewerken van een agent in de app.

## Velden van de agent-entiteit

| Veld                    | Type                   | Vereist | Beschrijving                                                                                                                                                                                        |
| ----------------------- | ---------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ja      | Unieke identificatie van de agent                                                                                                                                                                   |
| `name`                  | `String`               | Ja      | Korte identificatie voor @-vermeldingen                                                                                                                                                             |
| `title`                 | `String`               | Ja      | Voor mensen leesbare functietitel                                                                                                                                                                   |
| `agentMdPath`           | `String`               | Ja      | Absoluut pad naar het `.md`-definitiebestand van de agent                                                                                                                                           |
| `workspaceId`           | `String`               | Ja      | Eigen werkruimte (niet null)                                                                                                                                                                        |
| `reportsTo`             | `String?`              | Nee     | Id van de bovenliggende agent                                                                                                                                                                       |
| `skills`                | `AgentSkills`          | Ja      | Set skill-identificaties                                                                                                                                                                            |
| `persona`               | `String?`              | Nee     | Vrije tekst met gedragsinstructies                                                                                                                                                                  |
| `systemPrompt`          | `String?`              | Nee     | Overschrijft de standaard systeemprompt                                                                                                                                                             |
| `adapterId`             | `String?`              | Nee     | Id van de inferentieadapter                                                                                                                                                                         |
| `modelId`               | `String?`              | Nee     | Model-id binnen de adapter                                                                                                                                                                          |
| `strictMode`            | `bool`                 | Nee     | Standaard `false`. Wordt naar de rij en naar de `AGENTS.md` van de agent geschreven                                                                                                                 |
| `effort`                | `String?`              | Nee     | Id van het redeneerniveau (bijv. `'low'`, `'xhigh'`), afkomstig uit de `thinkingLevels` van het geselecteerde model                                                                                 |
| `contextSize`           | `int?`                 | Nee     | Maximale grootte van het contextvenster                                                                                                                                                             |
| `role`                  | `AgentRole?`           | Nee     | Agentrol                                                                                                                                                                                            |
| `monthlyBudgetCents`    | `int`                  | Nee     | Maandelijks uitgavenplafond in centen (standaard `0`, onbeperkt)                                                                                                                                    |
| `silenceTimeoutMinutes` | `int?`                 | Nee     | Overschrijving van de stiltetime-out in minuten; moet null zijn of tussen 1–240 liggen (met een assert in de constructor)                                                                          |
| `maxConcurrentTasks`    | `int`                  | Nee     | Standaard `1`. Capaciteitsgetal dat het aanwezigheidsmodel rapporteert (lopende en wachtende aantallen worden ermee vergeleken)                                                                     |
| `visibility`            | `AgentVisibility`      | Nee     | Standaard `workspace`                                                                                                                                                                               |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Nee     | Governancestatus (standaard `active`). Geschreven door de hard-stop van het budget en weergegeven in het organigram en op de aanwezigheidslijst. Dispatch accepteert nog steeds werk van een agent met `paused` |
| `budgetPolicyId`        | `String?`              | Nee     | Id van het gedeelde budgetbeleid; is die null, dan geldt `monthlyBudgetCents` direct                                                                                                                |
| `runtimeProfileId`      | `String?`              | Nee     | Id van het aangepaste runtimeprofiel                                                                                                                                                                |
| `createdAt`             | `DateTime`             | Ja      | Tijdstip van aanmaken                                                                                                                                                                               |

`name` en `title` mogen beide niet leeg zijn (met een assert in de constructor).
Een standaard `monthlyBudgetCents` van `0` betekent onbeperkt. Schrijf een
plafond met `agents.upsert`.

## Enum AgentVisibility

| Waarde      | Beschrijving                                             |
| ----------- | -------------------------------------------------------- |
| `workspace` | De standaard; onbekende en als null opgeslagen waarden worden erop geparseerd |
| `private`   | Privé voor de gebruiker die hem aanmaakt                 |

## Enum AgentLifecycleStatus

| Waarde     | Beschrijving                                                                            |
| ---------- | --------------------------------------------------------------------------------------- |
| `active`   | De standaard. `isDispatchable` is alleen voor deze waarde waar                          |
| `paused`   | Gezet door de hard-stop van het budget. Getoond op de aanwezigheidslijst; dispatch accepteert nog steeds werk |
| `archived` | Buiten gebruik gesteld en verborgen uit actieve lijsten                                 |

## Machtigingen

Een agent draagt geen machtigingsvlaggen. Pushen, pull requests openen en publiceren, naar een tracker schrijven en uitgaand netwerkverkeer zijn actieklassen (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) die de [beveiligingen](/nl-NL/handleiding/concepten/beveiligingen/) bepalen op het bereik werkruimte, agent of ruimte. Het GitHub-token van een run heeft altijd alleen leesrechten; pushes lopen via de agentrun-gateway, die de regel `gitPush` raadpleegt voordat hij ze doorstuurt.

## AgentSkills

Een onveranderlijke, hoofdletterongevoelige set skill-identificaties. Bij het dispatchen worden die slugs gesynchroniseerd als skill-links in de overlay van de agent; de harness laadt daarna de frontmatter van de gelinkte skills automatisch in de prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (afgeleid)

Niet opgeslagen. Zeven waarden. De declaratievolgorde is de prioriteitsvolgorde (`sortPriority`, vastgepind door een test), en dat is de volgorde waarin de ledenlijst sorteert:

| Status      | `sortPriority` | Voorwaarde                                                                                                          |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Minstens één runlog heeft de status `running`                                                                       |
| `blocked`   | 1              | De liveness van de laatste run is `blocked`, `stalled` of `looping`                                                 |
| `failed`    | 2              | De status van de laatste run is `error`, of zijn liveness is `failed` of `dead`                                     |
| `queued`    | 3              | Een run is gedispatcht maar wordt niet uitgevoerd — geparkeerd achter een andere run van dezelfde agent, of geschreven maar nog niet gestart |
| `succeeded` | 4              | De run is met succes afgerond                                                                                       |
| `idle`      | 5              | De agent heeft eerder gedraaid en heeft niets onderweg                                                              |
| `neverRun`  | 6              | Er bestaan geen runlogs                                                                                             |

`queued` en `succeeded` zijn **alleen per run**. `deriveAgentLiveState`, dat de ledenlijststatus van een agent berekent, levert geen van beide op — het retourneert `neverRun`, `running`, `failed`, `blocked` of `idle`.
