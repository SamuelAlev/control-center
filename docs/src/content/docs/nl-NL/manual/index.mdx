Control Center geeft je de leiding over een vloot AI-codeeragenten. Start agenten, kijk ze in realtime werken, review hun pull requests en beheer repo's, werkruimtes en integraties — vanuit een native desktop-app, een browser of je telefoon.

## Wat je kunt doen

- **Berichten naar agenten sturen**: ruimtes zijn de belangrijkste manier om de vloot aan te sturen. Noem een agent met @ en die start in zijn eigen copy-on-write-worktree, zodat meerdere agenten parallel kunnen coderen en reviewen zonder dat jouw checkout wordt aangeraakt
- **De grote opdrachten orkestreren**: geef de orchestrator een doel, keur het plan voor het hele team dat hij voorstelt één keer goed en een gegenereerde [pipeline](/nl-NL/handleiding/concepten/pipelines/) voert het uit
- **Pull requests reviewen en mergen** met een ingebouwde diff-viewer, inline opmerkingen en AI-gestuurde review
- **Agenten wegwerpmachines geven**: een [rig](/nl-NL/handleiding/gidsen/rigs-gebruiken/) is een wegwerp-VM — een browser, een desktop, een telefoon of een omhulde terminal — die de agent bestuurt terwijl jij live meekijkt en kunt overnemen; dev-servers erin worden doorgestuurd naar `localhost`, de browser van de agent en `https://myapp.test`
- **Werkstromen automatiseren** met op DAG's gebaseerde pipelines die door gebeurtenissen of planningen worden geactiveerd
- **Kennis beheren** met geheugen, feiten en beleid per werkruimte
- **Werk volgen** met leverancieronafhankelijke tickets, projecten en delegatie
- **Vergaderingen opnemen** met opname, transcriptie en diarisatie op het apparaat, daarna samengevat in notities, actiepunten en besluiten
- **Je dag overzien** met synchronisatie met Google Agenda, reacties op uitnodigingen, vergadermeldingen en opnemen en koppelen
- **De vloot volgen vanaf je telefoon**: koppel een apparaat aan je server, lees berichten, antwoord en trieer tickets. De telefoon neemt het beste pad dat hij kan bereiken — loopback, LAN, tailnet of TLS — en valt terug op een end-to-end verzegelde relay die frames doorstuurt die hij niet kan lezen
- **Agenten aansturen vanuit Slack**: verbind een werkruimte met een chat-app en noem de bot, antwoord in een Slack-thread of maak een ticket aan met een slash-commando — via een uitgaande verbinding, dus er is geen openbaar eindpunt nodig
- **Integreren** met GitHub, Linear, Slack, Google Agenda en meer dan 100 MCP-tools

## Je hoeft het niet te installeren

Dezelfde applicatie draait in je browser op
[app.usectrl.dev](https://app.usectrl.dev), met dezelfde functies.

Elke client — desktop, web en telefoon — is een dunne renderer boven op een headless server die
je gegevens bezit en het werk doet. De desktop kan die server voor je starten; een
browsertabblad kan dat niet, dus de webapp verbindt met een server die jij draait. Die server
kan op je eigen machine staan (`ws://localhost:9030`, geen certificaat nodig) of op een externe
host die bereikbaar is via TLS, een VPN of een tunnel.

Zie [Installeren](/nl-NL/handleiding/installeren/#use-it-in-your-browser) voor de route via de browser en
[Deployment en clients](/nl-NL/handleiding/concepten/deployment/) voor hoe de drie clients zich tot elkaar verhouden.
