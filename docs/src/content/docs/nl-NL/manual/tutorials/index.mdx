Zelfstudies zijn **lessen**. Elke les leidt je van begin tot eind door iets echts, langs één
pad, zonder dat je onderweg keuzes hoeft te maken. Volg de stappen precies en ze werken.

Ze zijn bedoeld om je weg te leren kennen. Zodra je de vorm van het product kent, zijn de
[how-to-gidsen](/nl-NL/handleiding/gidsen/) de snellere route naar een specifieke taak.

Doe ze in deze volgorde — elke les gaat uit van de vorige.

1. [Je eerste werkruimte](/nl-NL/handleiding/zelfstudies/eerste-werkruimte/) — maak een werkruimte, voeg een repo toe en zie het isolatiemodel
2. [Je eerste agent starten](/nl-NL/handleiding/zelfstudies/eerste-agent/) — geef een agent een adapter en een model en zet hem aan het werk
3. [Je eerste pull request reviewen](/nl-NL/handleiding/zelfstudies/eerste-pr/) — lees de diff, laat een opmerking achter en merge
4. [Je eerste pipeline bouwen](/nl-NL/handleiding/zelfstudies/eerste-pipeline/) — schakel stappen aaneen tot een DAG en voer die uit

Twee andere staan op zichzelf; doe een van beide zodra je een werkende werkruimte hebt.

- [Slack koppelen aan je werkruimte](/nl-NL/handleiding/zelfstudies/eerste-chatbrug/) — stuur agenten aan vanuit een Slack-thread
- [Je team aanmelden met SSO](/nl-NL/handleiding/zelfstudies/sso/) — verbind een identiteitsprovider en doorloop een aanmelding van begin tot eind

:::note[Voordat je begint]
Installeer eerst Control Center — zie [Installeren](/nl-NL/handleiding/installeren/). Wil je alleen de
kortst mogelijke weg naar een draaiende agent, neem dan de [Snelstart](/nl-NL/handleiding/snelstart/)
en kom daarna hier terug.
:::
