## Wat je gaat bouwen

Aan het einde van deze zelfstudie heb je:

- Een opgeslagen pipeline-sjabloon dat een agent met een prompt dispatcht
- Handmatige uitvoeringen ingeschakeld erop, zodat het met de hand kan worden gestart
- Eén voltooide run, met de invoer en uitvoer van de stap zichtbaar

Vereisten: [Je eerste agent starten](/nl-NL/handleiding/zelfstudies/eerste-agent/) is afgerond, dus je hebt een agent met een adapter en een model.

Een pipeline is een DAG van stappen. Sjablonen leggen de graaf vast; runs zijn uitvoeringen. Lees [Pipelines en automatisering](/nl-NL/handleiding/concepten/pipelines/) voor het model erachter; het volledige vocabulaire aan stappen staat in [Pipeline-stapsoorten](/nl-NL/handleiding/referentie/pipeline-stappen/).

## Stap 1: Een sjabloon aanmaken

1. Ga naar **Instellingen → Werkruimte → Pipelinesjablonen**
2. Klik op **Nieuwe template**

De editor opent op een voorbereid skelet met de naam **Nieuwe pipeline** (id `pipeline_N`).
Klik op de titel in de koptekst en hernoem hem — voor deze zelfstudie is
`code_quality_check` een goede naam. Er is geen dialoogvenster voor de id en geen
beschrijvingsveld.

Het canvas is niet leeg. Een nieuw sjabloon is al voorbedraad als **Trigger → Step →
terminal**, waarbij “Step” een prompt-agent-node is en de terminal een
onzichtbare sentinel die de editor opnieuw verbindt met elke bereikbare sink.

Je configureert de Step die er al staat.

## Stap 2: De stap configureren

1. Klik op de node **Step** op het canvas
2. Stel in het paneel **Node-configuratie** aan de rechterkant in:
   - **Agent**: je agent uit de vorige zelfstudie
   - **Prompt-template**: “Controleer de code op de huidige branch op kwaliteitsproblemen. Som op wat je vindt.”
3. Laat **Triggers van** staan — de node is al bedraad om na Trigger af te gaan

## Stap 3: Opslaan

Druk op **Opslaan** in de koptekst van de editor.

**Controlepunt.** De vermelding “Niet-opgeslagen wijzigingen” verdwijnt.

## Stap 4: Handmatige uitvoeringen toestaan

1. Klik op de gestippelde tegel **Trigger toevoegen** op het canvas (of sleep **Handmatige uitvoering**
   uit de sectie Triggers van de node-bibliotheek) en kies **Handmatige uitvoering**.
2. Selecteer die node. Zet in de inspecteur aan de rechterkant **Ingeschakeld** aan —
   “Toon op de uitvoerpagina en start handmatig.”

Dit is niet optioneel en het is makkelijk te missen. Een nieuw sjabloon wordt aangemaakt met **helemaal geen triggerrij**, dus zolang je dit niet aanzet, vermeldt de uitvoerpagina het niet en valt er niets te starten. De schakelaar schrijft de trigger meteen weg; hij wacht niet op nog een keer opslaan.

Dezelfde schakelaar zit achter **Handmatige uitvoering** in de koptekst van de editor, naast de gedeclareerde invoer van het sjabloon.

## Stap 5: Uitvoeren

1. Klik op **Pipelines** in de zijbalk
2. Klik op **Pipeline uitvoeren** in de koptekst
3. Kies `code_quality_check` in de linkerkolom
4. Klik op **Pipeline uitvoeren** in het formulier — je sjabloon declareert geen invoer, dus er valt niets in te vullen

**Controlepunt.** Een toast bevestigt dat de run is gestart en Control Center opent de detailpagina van de run.

De engine maakt het runrecord aan, voltooit de trigger, plant de stap in, dispatcht de agent en voltooit de run wanneer de inkomende tak van de terminal klaar is.

## Stap 6: Het resultaat controleren

Klik op de stap in de run om het detailpaneel ervan te openen:

- De tijdstempels **Gestart** en **Voltooid** en de **Duur**
- **Invoer**: de status die aan de stap is doorgegeven
- **Uitvoer**: wat hij heeft geproduceerd — hier de respons van de agent
- **Agentactiviteit**, met een link naar het gesprek dat de stap heeft aangestuurd

**Controlepunt.** De stap staat op voltooid en de uitvoer bevat de review van de agent.

## Meer stappen toevoegen

Nodes voeg je toe door een item uit de node-bibliotheek links naar het canvas te
slepen, of door net voorbij een node op **Stap toevoegen** (`+`) te drukken.
Sleep van de uitvoerpoort van een node naar een andere node om ze te verbinden,
of selecteer de nieuwe node en vink zijn stroomopwaartse stap aan onder
**Triggers van**.

De terminal-node wordt niet getekend en kan niet worden geselecteerd. De editor
verbindt hem opnieuw met elke bereikbare sink, zodat een node die je achter de
voorbereide Step toevoegt alsnog wordt uitgevoerd.

## Samenvatting

Je hebt een sjabloon aangemaakt, de prompt-agent-node geconfigureerd waarmee het is voorbereid, het opgeslagen, het handmatig uitvoerbaar gemaakt, een run gestart en de invoer en uitvoer van de stap gelezen.

Pipelines worden veel groter dan dit — voorwaardelijke routers, parallelle takken, join-nodes, for-each-fan-out, menselijke poorten — maar de vorm verandert nooit: stappen in een DAG, die status doorgeven.
