title: Keyboard shortcuts
description: The complete keybinding registry, by scope, with the conditions each shortcut fires under.

Shortcuts come from one `const` registry, `KeybindingRegistry` in `lib/core/constants/keybindings.dart`. It holds **48 bindings**. Settings → You → Keybindings renders that registry as a **read-only reference**: there is no rebinding UI and no user keybindings file.

`Cmd` below is the primary command modifier — ⌘ on macOS, Ctrl on Windows and Linux. A binding only fires when its command has a registered handler on the current screen and its `when` clause holds; `!textInputFocus` means the key is passed through to a focused text field instead.

There is no digit-key navigation shortcut. Inbox, tickets, pull requests and the rest are reached from the sidebar or ⌘K. Observability has no shortcut either.

## Pull request list (3)

Scope `/pull-requests`. All require `route == '/pull-requests'` and no focused text field, so they do not fire while the PR detail route is open over the list.

| Shortcut | Action           |
| -------- | ---------------- |
| `R`      | Refresh          |
| `Enter`  | Open PR          |
| `F`      | Open filter menu |

`Enter` (`pr.list-open`) is declared in the registry and appears on the keybindings reference, but **the list screen does not register a handler for it**, so it currently does not fire. `F` opens the filter menu (`pr.list-open-filter`), not search.

## Pull request detail (2)

Scope `/pull-requests/`. Refresh requires no focused text field. Close-tab has no text-input guard (a ⌘-modified stroke is never plain text) and a route regex so it does not fire on the list.

| Shortcut       | Action    | Condition                          |
| -------------- | --------- | ---------------------------------- |
| `R`            | Refresh   | Not typing in a field              |
| `Cmd/Ctrl + W` | Close tab | On a `/pull-requests/<…>` location |

Tab switching (`1`/`2`/`3`), file viewed/collapse (`V`/`C`), the file list (`T`) and find-in-diff (`Cmd/Ctrl + F`) are owned by the diff viewer's own handler — see [Diff viewer keys outside the registry](#diff-viewer-keys-outside-the-registry).

## Spaces (8)

Scope `/spaces`. The `when` clauses use a regex so they fire on both the space list (`/spaces`) and a selected space (`/spaces/<id>`).

| Shortcut               | Action                 | Condition             |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | Send message           | —                     |
| `Cmd/Ctrl + N`         | New space              | On a `/spaces` route  |
| `J`                    | Next space             | Not typing in a field |
| `K`                    | Previous space         | Not typing in a field |
| `Cmd/Ctrl + Shift + D` | Push-to-talk dictation | —                     |
| `Cmd/Ctrl + T`         | Open editor tab        | On a `/spaces` route  |
| `Cmd/Ctrl + W`         | Close editor tab       | On a `/spaces` route  |
| `Cmd/Ctrl + B`         | Toggle editor sidebar  | On a `/spaces` route  |

Enter-to-send is owned by the composer text field; push-to-talk is owned by the composer's mic button (its own hardware-keyboard handler). Both are listed in the registry for the settings reference.

## Diff viewer keys outside the registry

The PR diff viewer handles these itself (`PrDiffKeyboardHandler`). Search/viewed/collapse are listed in the registry comments for the settings reference only — no dispatcher handler is registered, so the dispatcher leaves them to the diff view. They do not appear as their own rows on the keybindings reference.

| Shortcut        | Action                                               |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Search in diff                                       |
| `J` / `K`       | Next / previous file                                 |
| `V`             | Toggle viewed on the focused file                    |
| `C`             | Toggle collapse on the focused file                  |
| `T`             | Show file list                                       |
| `Enter`         | Next search match (only while find-in-diff is open)  |
| `Shift + Enter` | Previous search match                                |
| `Escape`        | Close find-in-diff, or clear the diff text selection |
| `Cmd/Ctrl + C`  | Copy the diff selection                              |

## Browser-reserved combinations

On the web build, the browser consumes some accelerators before the page sees them, so the matching bindings can never fire there. They work normally on desktop. Reserved when combined with the primary command modifier: `T`, `W`, `N` and the digits `1`–`9`.

That covers `Cmd/Ctrl + Alt + 1`–`9` workspace switching, `Cmd/Ctrl + N` (new space, new workspace, new agent, add repository) and `Cmd/Ctrl + T` / `Cmd/Ctrl + W` in spaces and PR detail.
