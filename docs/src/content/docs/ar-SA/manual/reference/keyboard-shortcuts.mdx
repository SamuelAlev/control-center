تأتي الاختصارات من سجل `const` واحد، `KeybindingRegistry` في `lib/core/constants/keybindings.dart`. يحمل **49 ربطًا**. تعرض **الإعدادات ← أنت ← اختصارات لوحة المفاتيح** ذلك السجل بوصفه **مرجعًا للقراءة فقط**: لا واجهة لإعادة التعيين، ولا ملف اختصارات يخص المستخدم.

`Cmd` أدناه هو معدّل الأمر الأساسي — ⌘ على macOS، وCtrl على Windows وLinux. لا يُطلَق الربط إلا حين يكون لأمره معالج مسجّل على الشاشة الحالية ويتحقق شرط `when`؛ ويعني `!textInputFocus` أن المفتاح يُمرَّر إلى حقل النص المركّز بدل ذلك.

لا اختصار تنقّل بمفاتيح الأرقام. يُبلَغ الوارد والتذاكر وطلبات السحب وسواها من الشريط الجانبي أو بـ ⌘K. وقابلية الملاحظة بلا اختصار كذلك.

النطاق `global`، فهي فعّالة في أي موضع من غلاف التطبيق.

## قائمة طلبات السحب (3)

النطاق `/pull-requests`. تشترط كلها `route == '/pull-requests'` وألا يكون حقل نص مركّزًا، فلا تُطلَق ما دام مسار تفاصيل طلب السحب مفتوحًا فوق القائمة.

| الاختصار | الإجراء            |
| -------- | ------------------ |
| `R`      | تحديث              |
| `Enter`  | فتح PR             |
| `F`      | فتح قائمة التصفية  |

`Enter` (`pr.list-open`) مُعلَن في السجل ويظهر في مرجع الاختصارات، لكن **شاشة القائمة لا تسجّل معالجًا له**، فلا يُطلَق حاليًا. يفتح `F` قائمة التصفية (`pr.list-open-filter`)، لا البحث.

## تفاصيل طلب السحب (2)

النطاق `/pull-requests/`. يشترط التحديث ألا يكون حقل نص مركّزًا. إغلاق علامة التبويب بلا حارس لإدخال النص (الضغطة المعدَّلة بـ ⌘ ليست نصًا عاديًا أبدًا)، ومعه تعبير نمطي للمسار كي لا يُطلَق على القائمة.

| الاختصار       | الإجراء              | الشرط                              |
| -------------- | -------------------- | ---------------------------------- |
| `R`            | تحديث                | من غير الكتابة في حقل              |
| `Cmd/Ctrl + W` | إغلاق علامة التبويب  | على موقع `/pull-requests/<…>`      |

تبديل علامات التبويب (`1`/`2`/`3`)، ومشاهدة الملف أو طيّه (`V`/`C`)، وقائمة الملفات (`T`)، والبحث في الفروق (`Cmd/Ctrl + F`) يتولّاها معالج عارض الفروق نفسه — انظر [مفاتيح عارض الفروق خارج السجل](#مفاتيح-عارض-الفروق-خارج-السجل).

## المساحات (9)

النطاق `/spaces`. تستخدم شروط `when` تعبيرًا نمطيًا كي تُطلَق على قائمة المساحات (`/spaces`) وعلى مساحة محدّدة (`/spaces/<id>`) معًا.

| الاختصار               | الإجراء                 | الشرط                    |
| ---------------------- | ----------------------- | ------------------------ |
| `Enter`                | إرسال رسالة             | —                        |
| `Cmd/Ctrl + N`         | مساحة جديدة             | على مسار `/spaces`       |
| `J`                    | المساحة التالية         | من غير الكتابة في حقل    |
| `K`                    | المساحة السابقة         | من غير الكتابة في حقل    |
| `Cmd/Ctrl + Shift + D` | إملاء اضغط للتحدث       | —                        |
| `Cmd/Ctrl + T`         | فتح علامة تبويب المحرر  | على مسار `/spaces`       |
| `Cmd/Ctrl + W`         | إغلاق علامة تبويب المحرر | على مسار `/spaces`      |
| `Cmd/Ctrl + B`         | تبديل الشريط الجانبي للمحرر | على مسار `/spaces`  |
| `Cmd/Ctrl + P`         | الانتقال إلى ملف            | على مسار `/spaces`  |

يفتح «الانتقال إلى ملف» منتقيًا لملفات المحادثة. عندما لا تكتب شيئًا يعرض الملفات التي فتحتها مؤخرًا، وعند الكتابة يبحث في كل ملفات أشجار العمل الخاصة بالمحادثة. يفتح `Enter` الملف المحدد في علامة تبويب جديدة، ويفتحه `Cmd/Ctrl + Enter` أو زر التقسيم في الصف في جزء على اليمين، ويزيل `×` في صف ملف حديث ذلك الملف من القائمة.

يتولّى حقل نص محرر الرسائل الإرسال بـ Enter، ويتولّى زر الميكروفون في محرر الرسائل الضغط للتحدث (معالجه الخاص بلوحة المفاتيح العتادية). كلاهما مُدرَج في السجل لمرجع الإعدادات.

## مفاتيح عارض الفروق خارج السجل

يتولّى عارض فروق طلب السحب هذه المفاتيح بنفسه (`PrDiffKeyboardHandler`). البحث والمشاهدة والطي مُدرجة في تعليقات السجل لمرجع الإعدادات فقط — لا معالج مسجّل لدى الموزّع، فيتركها الموزّع لعارض الفروق. ولا تظهر صفوفًا مستقلة في مرجع الاختصارات.

| الاختصار        | الإجراء                                              |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | البحث في الفروق                                      |
| `J` / `K`       | الملف التالي / السابق                                |
| `V`             | تبديل المشاهدة على الملف المركّز                     |
| `C`             | تبديل الطي على الملف المركّز                         |
| `T`             | عرض قائمة الملفات                                    |
| `Enter`         | المطابقة التالية في البحث (فقط بينما البحث في الفروق مفتوح) |
| `Shift + Enter` | المطابقة السابقة في البحث                            |
| `Escape`        | إغلاق البحث في الفروق، أو مسح تحديد نص الفرق         |
| `Cmd/Ctrl + C`  | نسخ تحديد الفرق                                      |

## التركيبات التي يحجزها المتصفح

في بناء الويب يستهلك المتصفح بعض المسرّعات قبل أن تراها الصفحة، فلا يمكن للربطات المطابقة أن تُطلَق هناك أبدًا. وتعمل كالمعتاد على سطح المكتب. المحجوز عند الجمع مع معدّل الأمر الأساسي: `T` و`W` و`N` والأرقام `1`–`9`.

يغطي ذلك تبديل مساحة العمل بـ `Cmd/Ctrl + Alt + 1`–`9`، و`Cmd/Ctrl + N` (مساحة جديدة، ومساحة عمل جديدة، ووكيل جديد، وإضافة مستودع) و`Cmd/Ctrl + T` / `Cmd/Ctrl + W` في المساحات وفي تفاصيل طلب السحب.
