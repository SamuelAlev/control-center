تصف صفحات المرجع **ما هو موجود**، باستيفاء ومن غير تعليق. ارجع إليها حين تعرف ما تبحث عنه: اسم أداة بعينه، أو نوع خطوة، أو انتقال حالة، أو مسار، أو اختصار.

لم تُكتب لتُقرأ من أولها إلى آخرها. لذلك ارجع إلى [المفاهيم](/ar-SA/دليل-المستخدم/مفاهيم/)؛ ولإنجاز مهمة، استخدم [الأدلة الإرشادية](/ar-SA/دليل-المستخدم/أدلة-إرشادية/).

## سطح المنتج

- [أدوات MCP](/ar-SA/دليل-المستخدم/مرجع/أدوات-mcp/) — كل أداة يسجّلها خادم MCP، حسب العائلة
- [أدوات الوكيل المضمّنة](/ar-SA/دليل-المستخدم/مرجع/أدوات-الوكيل/) — أدوات الإطار المضمّن المرتبطة بالخادم (LSP وAST وdebug وeval وvibe)
- [أوامر الشرطة المائلة](/ar-SA/دليل-المستخدم/مرجع/أوامر-الشرطة-المائلة/) — أوامر حقل الكتابة المضمّنة، و`/skill:`، وأوامر المستخدم
- [خريطة المسارات](/ar-SA/دليل-المستخدم/مرجع/خريطة-المسارات/) — كل شاشة وعنوان URL الذي يبلغها
- [اختصارات لوحة المفاتيح](/ar-SA/دليل-المستخدم/مرجع/اختصارات-لوحة-المفاتيح/) — السجل الكامل لربط المفاتيح
- [أحداث النطاق](/ar-SA/دليل-المستخدم/مرجع/أحداث-النطاق/) — كل حدث يُنشر على ناقل النطاق
- [المنصات](/ar-SA/دليل-المستخدم/مرجع/منصات/) — كل سطح منصة، وفعل إجراء، وحالة دورة حياة، ومنفذ، وقيمة افتراضية

## التهيئة

- [تهيئة الوكيل](/ar-SA/دليل-المستخدم/مرجع/تهيئة-الوكيل/) — كل حقل في الوكيل وما يقرأه
- [أنواع خطوات خط الأنابيب](/ar-SA/دليل-المستخدم/مرجع/خطوات-خط-الأنابيب/) — أنواع الخطوات، ومفاتيح الجسم، والتهيئة، والنتائج
- [واجهة سطر أوامر `cc_server`](/ar-SA/دليل-المستخدم/مرجع/سطر-أوامر-cc-server/) — كل علم، ومتغير بيئة، وأمر فرعي، ومسار دليل البيانات
- [النسخ الاحتياطي والتصدير والاستيراد](/ar-SA/دليل-المستخدم/مرجع/نسخ-احتياطي/) — تخطيط اللقطة، وكل عملية نسخ احتياطي، ومسار نقل
- [خلفيات البيئة المعزولة](/ar-SA/دليل-المستخدم/مرجع/خلفيات-البيئة-المعزولة/) — خلفيات التنفيذ وتوافرها
- [تهيئة SSO](/ar-SA/دليل-المستخدم/مرجع/sso/) — نقاط النهاية والعمليات ورموز الخطأ
- [جسر الدردشة](/ar-SA/دليل-المستخدم/مرجع/جسر-الدردشة/) — المزوّدون والأوامر وبيانات الاعتماد والعمليات

## النماذج
