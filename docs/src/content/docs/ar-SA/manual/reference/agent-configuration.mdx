يسرد هذا المرجع كل حقل في كيان الوكيل، مع التعدادات والأعلام التي يستخدمها. للشرح خطوة بخطوة لإنشاء وكيل أو تحريره في التطبيق، انظر [إنشاء وكيل وتهيئته](/ar-SA/دليل-المستخدم/أدلة-إرشادية/إنشاء-وكيل/).

## حقول كيان الوكيل

| الحقل                   | النوع                  | مطلوب | الوصف                                                                                                                                                         |
| ----------------------- | ---------------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | نعم   | معرّف فريد للوكيل                                                                                                                                             |
| `name`                  | `String`               | نعم   | معرّف قصير للإشارة بـ @                                                                                                                                       |
| `title`                 | `String`               | نعم   | عنوان الدور بصيغة يقرأها الإنسان                                                                                                                              |
| `agentMdPath`           | `String`               | نعم   | المسار المطلق لملف تعريف الوكيل بصيغة `.md`                                                                                                                   |
| `workspaceId`           | `String`               | نعم   | مساحة العمل المالكة (غير فارغة)                                                                                                                               |
| `reportsTo`             | `String?`              | لا    | معرّف الوكيل الأب                                                                                                                                             |
| `skills`                | `AgentSkills`          | نعم   | مجموعة معرّفات المهارات                                                                                                                                       |
| `persona`               | `String?`              | لا    | تعليمات سلوكية بنص حر                                                                                                                                         |
| `systemPrompt`          | `String?`              | لا    | تجاوز لموجّه النظام الافتراضي                                                                                                                                 |
| `adapterId`             | `String?`              | لا    | معرّف محوّل الاستدلال                                                                                                                                         |
| `modelId`               | `String?`              | لا    | معرّف النموذج داخل المحوّل                                                                                                                                    |
| `strictMode`            | `bool`                 | لا    | الافتراضي `false`. يُكتَب في الصف وفي ملف `AGENTS.md` الخاص بالوكيل                                                                                           |
| `effort`                | `String?`              | لا    | معرّف مستوى الاستدلال (مثل `'low'` و`'xhigh'`)، ويُؤخذ من `thinkingLevels` للنموذج المختار                                                                    |
| `contextSize`           | `int?`                 | لا    | الحجم الأقصى لنافذة السياق                                                                                                                                    |
| `role`                  | `AgentRole?`           | لا    | دور الوكيل                                                                                                                                                    |
| `monthlyBudgetCents`    | `int`                  | لا    | سقف الإنفاق الشهري بالسنت (الافتراضي `0`، أي غير محدود)                                                                                                       |
| `silenceTimeoutMinutes` | `int?`                 | لا    | تجاوز مهلة الصمت بالدقائق؛ يجب أن يكون فارغًا أو في المدى 1–240 (يؤكّده المُنشئ)                                                                             |
| `maxConcurrentTasks`    | `int`                  | لا    | الافتراضي `1`. رقم السعة الذي يبلّغ به نموذج الحضور (تُقارَن به أعداد `running` و`queued`)                                                                   |
| `visibility`            | `AgentVisibility`      | لا    | الافتراضي `workspace`                                                                                                                                         |
| `lifecycleStatus`       | `AgentLifecycleStatus` | لا    | حالة الحوكمة (الافتراضي `active`). يكتبها الإيقاف الصارم للميزانية، وتُعرَض في الهيكل التنظيمي وكشف الحضور. يظل الإرسال يقبل العمل من وكيل حالته `paused` |
| `budgetPolicyId`        | `String?`              | لا    | معرّف سياسة الميزانية المشتركة؛ إن كان فارغًا يُطبَّق `monthlyBudgetCents` مباشرة                                                                            |
| `runtimeProfileId`      | `String?`              | لا    | معرّف ملف تعريف زمن التشغيل المخصّص                                                                                                                           |
| `createdAt`             | `DateTime`             | نعم   | طابع وقت الإنشاء                                                                                                                                              |

يجب أن يكون `name` و`title` كلاهما غير فارغ (يؤكّد ذلك المُنشئ). القيمة الافتراضية
`0` للحقل `monthlyBudgetCents` تعني غير محدود. اكتب سقفًا بـ `agents.upsert`.

## تعداد AgentVisibility

| القيمة      | الوصف                                                   |
| ----------- | ------------------------------------------------------- |
| `workspace` | الافتراضي؛ القيم المخزّنة المجهولة والفارغة تُحلَّل إليه |
| `private`   | خاص بالمستخدم الذي أنشأه                                |

## تعداد AgentLifecycleStatus

| القيمة     | الوصف                                                                                 |
| ---------- | ------------------------------------------------------------------------------------- |
| `active`   | الافتراضي. `isDispatchable` صحيح لهذه القيمة وحدها                                   |
| `paused`   | يضبطه الإيقاف الصارم للميزانية. يظهر في كشف الحضور، ويظل الإرسال يقبل العمل         |
| `archived` | متقاعد ومخفي عن الكشوف النشطة                                                         |

## الأذونات

لا يحمل الوكلاء أعلام أذونات. الدفع، وفتح طلبات السحب ونشرها، والكتابة إلى المتتبع، والخروج إلى الشبكة أصناف إجراء (`gitPush` و`prCreate` و`prPublish` و`vendorSyncWrite` و`networkEgress`) تحسمها [الضوابط](/ar-SA/دليل-المستخدم/مفاهيم/ضوابط/) على نطاق مساحة العمل أو الوكيل أو المساحة. رمز GitHub للتشغيل محصور دائمًا في القراءة؛ ويمر الدفع عبر بوابة تشغيل الوكيل، التي تسأل قاعدة `gitPush` قبل تمريره.

## AgentSkills

مجموعة ثابتة من معرّفات المهارات، لا تراعي حالة الأحرف. عند الإرسال تُزامَن هذه المعرّفات وصلات مهارات في تراكب الوكيل، ثم يحمّل الإطار المضمّن البيانات الأمامية للمهارات المربوطة تلقائيًا إلى المطالبة.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (مشتق)

غير مخزّنة. سبع قيم. ترتيب الإعلان هو ترتيب الأولوية (`sortPriority`، ويثبّته اختبار)، وهو الترتيب الذي يُفرَز به الكشف:

| الحالة      | `sortPriority` | الشرط                                                                                                                |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | أي سجل تشغيل حالته `running`                                                                                         |
| `blocked`   | 1              | حيوية آخر تشغيل هي `blocked` أو `stalled` أو `looping`                                                              |
| `failed`    | 2              | حالة آخر تشغيل `error`، أو حيويته `failed` أو `dead`                                                                |
| `queued`    | 3              | التشغيل مُرسَل لكنه غير قيد التنفيذ — مُرجَأ خلف تشغيل آخر للوكيل نفسه، أو مكتوب ولم يبدأ بعد                       |
| `succeeded` | 4              | انتهى التشغيل بنجاح                                                                                                  |
| `idle`      | 5              | الوكيل اشتغل من قبل، وليس لديه عمل جارٍ                                                                              |
| `neverRun`  | 6              | لا توجد سجلات تشغيل                                                                                                  |

`queued` و`succeeded` **للتشغيل الواحد فقط**. `deriveAgentLiveState` يحسب حالة الكشف لوكيل، ولا ينتج أيًا منهما — يعيد `neverRun` أو `running` أو `failed` أو `blocked` أو `idle`.
