كل ما يُضبط في تسجيل الدخول الموحّد، في موضع واحد. تعيش القيم في
صفوف `sso_connections` داخل `global.db` (على نطاق الخادم عن قصد)، وتُحرَّر
عبر **الإعدادات ← الخادم ← تسجيل الدخول الموحّد** أو عمليات RPC
`sso.*`. الصف المحفوظ هو مصدر الحقيقة الوحيد — لا مسار بيئة
`CC_SAML_*` / `CC_OIDC_*` (الاتصال الذي قد يصل من موضعين هو اتصال قد
تخالفه شاشة الإعدادات).

## حقول الاتصال

| الحقل | ينطبق على | الافتراضي | المعنى |
| --- | --- | --- | --- |
| `enabled` | كلاهما | مطفأ | يجوز لتسجيلات الدخول استخدام هذا الاتصال |
| `idpMetadataXml` | SAML | — | XML من نوع `EntityDescriptor` لدى IdP (مطلوب للتفعيل) |
| `spEntityId` | SAML | `<origin>/saml` | معرّف الكيان لدينا، يُثبَّت حين يتغيّر الأصل |
| `emailAttribute` | SAML | `email` | السمة التي تحمل البريد الإلكتروني؛ وNameID على هيئة بريد هو البديل |
| `displayNameAttribute` | SAML | `displayName` | سمة اسم العرض |
| `groupsAttribute` | SAML | `groups` | سمة أسماء المجموعات |
| `clockSkewSeconds` | SAML | 90 | هامش انحراف الساعة عند التحقق من مدة الصلاحية |
| `allowIdpInitiated` | SAML | مطفأ | قبول الاستجابات غير المطلوبة الصالحة (بلا `InResponseTo`)؛ ولا بد أن يطالب المتصفح بمنحة قصيرة الأمد قبل تلقّي بيانات اعتماد مختومة للمستلم |
| `wantResponseSigned` | SAML | مطفأ | اشتراط توقيع على جذر Response (توقيعات التأكيد مطلوبة دائمًا) |
| `issuer` | OIDC | — | عنوان URL الأساسي للمُصدِر (مطلوب للتفعيل) |
| `clientId` | OIDC | — | معرّف العميل العام (مطلوب للتفعيل) |
| `clientSecret` | OIDC | — | للعملاء السرّيين فقط؛ يُخزَّن في ملف الأسرار بصلاحية 0600، ولا يدخل قاعدة البيانات أبدًا — للكتابة فقط عبر RPC (تبلّغ `sso.getConfig` عن `clientSecretPresent`) |
| `groupsClaim` | OIDC | `groups` | المطالبة التي تحمل أسماء المجموعات |
| `defaultRole` | كلاهما | `member` | الدور إن لم تُطابق أي مجموعة — ولا يكون `owner` أبدًا |
| `groupRoleMap` | كلاهما | `{}` | مجموعة → دور؛ تُرفض تعيينات المالك عند الحفظ |
| `autoMember` | كلاهما | مفعّل | إضافة المستخدمين تلقائيًا إلى كل مساحة عمل عند أول تسجيل دخول |
| `allowJit` | كلاهما | مفعّل | توفير JIT للمستخدمين المجهولين عند تسجيل الدخول |

## تهيئة العملية

لا تُبذَر اتصالات SSO من البيئة. العلم المتبقي الوحيد في العملية
يحدد أين يفتح المتصفح عميل الويب بعد استدعاء SSO الراجع:

| المتغير / العلم | المعنى |
| --- | --- |
| `--web-client-url` / `CC_SERVER_WEB_CLIENT_URL` | عنوان URL لعميل الويب لتسليم بيانات اعتماد مختومة؛ وإن تُرك بلا تعيين يبقى التسليم على الأصل نفسه (وهو مفيد فقط إذا كان عميل الويب مقدَّمًا هناك). وفي تسجيل دخول `web-popup`، يُقدَّم `client_origin` مسموح به من علامة التبويب المبدِئة. |

يجب أن يكون عنوان URL للمُصدِر نفسه `https` (يُقبل `http` لمُصدِري
الاسترجاع `localhost` و`127.0.0.1` و`::1` فقط). واستخدم TLS موثوقًا لاستدعاء
IdP الراجع ولمضيف عميل الويب: فالصفحة التي تولّد مفتاح المستلم وجافاسكربت
الصفحة المسلَّم جزءان من حد الثقة. ويحمي HTTPS ذلك الإقلاع؛ وبعد الاقتران،
تشترط جلسات `/rpc` المباشرة والمارّة عبر المرحّل كليهما تشفير Noise وهوية خادم
مثبّتة.

## نقاط نهاية HTTP

| نقطة النهاية | المصادقة | الغرض |
| --- | --- | --- |
| `GET /saml/login?relay=…&handoff_key=…` | بلا مصادقة (إعادة توجيه) | بدء تسجيل الدخول المبدوء من موفّر الخدمة بمفتاح مستلم X25519 يحتفظ به العميل؛ يسلّم `relay=desktop` إلى التطبيق، ويرسل `relay=web-popup` رسالة postMessage إلى علامة تبويب الاتصال المنتظرة (ولا يُؤخَذ بـ `client_origin` الخاص بها إلا حين تثق به قائمة السماح للأصول) |
| `POST /saml/acs` | بلا مصادقة (POST من IdP) | يتحقق من التأكيد ويوفّر المستخدم؛ وتختم تسجيلات الدخول المبدوءة من موفّر الخدمة بيانات اعتماد الجهاز المصكوكة بمفتاح المستلم المبدِئ؛ أما SAML غير المطلوب المسموح فينتج مطالبة مربوطة بالمتصفح بدلًا من ذلك |
| `POST /saml/claim` | منحة متصفح على الأصل نفسه | صرف منحة SAML غير مطلوبة لاستخدام واحد مع كوكيها و`handoff_key` جديد؛ ويعيد بيانات اعتماد مختومة للمستلم، لا مفتاح اقتران صريحًا أبدًا |
| `GET /saml/metadata` | بلا مصادقة | `EntityDescriptor` لموفّر الخدمة لدينا |
| `GET /oidc/login?relay=…&handoff_key=…` / `GET /oidc/callback` | بلا مصادقة | جولة OIDC ذهابًا وإيابًا؛ ويشترط تسجيل الدخول مفتاح المستلم الذي يحتفظ به العميل؛ يسلّم `relay=desktop` إلى التطبيق، و`relay=web-popup` إلى علامة تبويب الاتصال المنتظرة (عرف `client_origin` نفسه) |
| `GET /auth/providers` | بلا مصادقة، CORS `*` | مسبار شاشة الاتصال: اتصالات SSO المعروضة (`id`/`kind`/`label`) مع `pairingEnabled` |
| `/scim/v2/Users…` | Bearer (رمز SCIM) | إنشاء وجلب وسرد مع تصفية وPUT وPATCH وDELETE للمورد Users |
| `/scim/v2/Groups` | Bearer | للقراءة فقط؛ دفع المجموعات يجيب بـ 501 عن قصد |
| `/scim/v2/ServiceProviderConfig` | Bearer | مستند القدرات |

في SAML وOIDC المبدوءين من موفّر الخدمة، يشترط عنوان URL لبدء تسجيل الدخول
`handoff_key` صالحًا (المفتاح العام X25519 للعميل المبدِئ). ويحتفظ الخادم بذلك
المفتاح مع تسجيل الدخول المعلّق، ويختم بيانات اعتماد الجهاز المصكوكة عند
الاستدعاء الراجع بـ X25519 عابر وHKDF-SHA256 وAES-256-GCM مربوطين بأصل الخادم.
ويستخدم تسليم الحاسوب `control-center://pair`، ويستخدم تسليم الويب في العلامة
نفسها جزء عنوان URL، ويرسل `web-popup` رسالة postMessage إلى `client_origin`
المسموح به إن قُدِّم (وإلا فإلى عنوان URL المُهيَّأ لعميل الويب أو أصل الاستدعاء
الراجع). ويسير في ذلك الجزء أو رسالة النافذة المنبثقة المغلّف المختوم، لا مفتاح
اقتران صريح. ويحتفظ العميل المبدِئ بالمفتاح الخاص المقابل لفتحه. وهذا المغلّف
مختلف عن جلسة Noise الإلزامية التي تُنشأ بعد الاقتران.

والاستجابة SAML المبدوءة من IdP (حين تكون مفعّلة) ليس لها مستلم مبدِئ. بدل
ذلك، يضبط ACS كوكي متصفح لمدة خمس دقائق، من نوع HttpOnly وSameSite=Strict،
ويعرض خيارَي **Open web client** / **Open desktop app**. وتولّد تلك الصفحة
مفتاح مستلم جديدًا وترسل نصفه العام ومقبض المنحة إلى `POST /saml/claim` من
الأصل نفسه. وتشترط المطالبة الكوكي والأصل المطابقين (حدّ CSRF)، وتستهلك المنحة
مرة واحدة، ولا تعيد إلا مغلّفًا مختومًا للمستلم. ويحمل جزء الويب/الحاسوب التالي
ذلك المغلّف والمادة الخاصة بمفتاح المستلم كي يفتحه العميل الوجهة، **لا** بيانات
اعتماد جهاز صريحة. ولا يستطيع متصفح آخر أو منحة منتهية صرفها. ويستطيع أصل عميل
الويب الوجهة الوصول إلى الجزء وفكّ تشفيره؛ فصفحة استدعاء راجع مخترقة أو أصل
عميل ويب مخترق يستطيع سرقة بيانات الاعتماد. ولا يجعل التشفير الشفرات المقدَّمة
غير الموثوقة آمنة.

## عمليات RPC

كل عمليات `sso.*` على نطاق الخادم، ومقصورة على **مالك الخادم** (مشغّل
التثبيت، `ServerAuthority.serverOwner`). امتلاك مساحة عمل لا يكفي،
والاقتران وحده لا يمنحها أبدًا.

| العملية | الغرض |
| --- | --- |
| `sso.getConfig` | الاتصال المحفوظ لنوع بعينه |
| `sso.saveConfig` | التحقق والحفظ والتطبيق الفوري |
| `sso.status` | أعلام التفعيل والتهيئة، ووجود رمز وصول SCIM، والأصل المعياري |
| `sso.testConnection` | اختبار اتصال من غير جولة المتصفح ذهابًا وإيابًا (SAML: تحليل البيانات الوصفية وبناء AuthnRequest؛ OIDC: اكتشاف المُصدِر)، ويمكن تمرير قيم ظاهرة على الشاشة لم تُحفَظ |
| `sso.spMetadata` | إصدار `EntityDescriptor` لموفّر الخدمة لأصل بعينه |
| `sso.setPairingEnabled` | السماح بالاقتران اليدوي أو منعه (رموز الدعوة ومفاتيح الاقتران)؛ ويرفض التعطيل ما دام لا يوجد اتصال SSO عامل، حذرًا من انغلاق المشغّل خارج الخادم |
| `sso.sessionPolicy` | قراءة الحد الأقصى لعمر بيانات اعتماد الجهاز ومهلة الخمول لهذا التثبيت (بالدقائق؛ `0` = بلا تعيين) |
| `sso.setSessionPolicy` | تعيين تلك الحدود؛ تُفرَض عند فحص الجهاز، ولا تُعلَن للعملاء |
| `sso.scimRegenerateToken` | توليد رمز وصول bearer لـ SCIM وإعادته (مرة واحدة) |

## رموز أخطاء التحقق

تحمل إخفاقات `cc_saml_verify_response` رمزًا ثابتًا:

| الرمز | المعنى |
| --- | --- |
| `signature` | توقيع مفقود أو غير موثوق أو عُبث به، أو خوارزمية أو تحويل غير مسموح به |
| `expired` | خارج `NotBefore`/`NotOnOrAfter` (بعد تجاوز انحراف الساعة) |
| `audience` | قيد الجمهور لا يسمّينا |
| `destination` | وجهة الاستجابة ليست ACS لدينا |
| `request_match` | `InResponseTo` لا يطابق طلبًا معلّقًا، أو الاستجابة غير مطلوبة بينما ذلك ممنوع |
| `issuer` | المُصدِر ليس IdP المُهيَّأ |
| `recipient` | مستلم تأكيد الموضوع ليس ACS لدينا |
| `malformed` | إخفاق على مستوى XML أو المخطط |
| `status` | الحالة التي أبلغ عنها IdP لم تكن Success |
| `invalid` / `internal` | أي شيء آخر / إخفاق في الوصلة |

## أسطح قاعدة البيانات

- `sso_connections` (global.db) — صف واحد لكل نوع، يعبر مساحات العمل
  عن قصد.
- `users.sso_subject` + `users.sso_issuer` — تثبيت المعرّف الثابت لدى
  الموفّر، فريد لكل `(issuer, subject)` عبر فهرس جزئي.
- `users.deactivated_at` — ختم التعطيل في SCIM.
- يعيش رمز وصول bearer لـ SCIM وسر عميل OIDC في ملف الأسرار بصلاحية
  0600، ولا يدخلان قاعدة البيانات أبدًا.
