These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/ar-SA/دليل-المستخدم/أدلة-إرشادية/); when you want to look
something up, go to the [reference](/ar-SA/دليل-المستخدم/مرجع/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/ar-SA/دليل-المستخدم/مفاهيم/مساحات-العمل/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/ar-SA/دليل-المستخدم/مفاهيم/نموذج-الوكيل/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/ar-SA/دليل-المستخدم/مفاهيم/دورة-حياة-الإرسال/) — what happens between your message and the agent's first token
- [Modes](/ar-SA/دليل-المستخدم/مفاهيم/أوضاع/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/ar-SA/دليل-المستخدم/مفاهيم/سياق-الأدوات/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/ar-SA/دليل-المستخدم/مفاهيم/ذكاء-الشفرة/) — the code graph, language server, structural search and debugger
- [Conversation history](/ar-SA/دليل-المستخدم/مفاهيم/سجل-المحادثة/) — persistence, compaction and forking a transcript
