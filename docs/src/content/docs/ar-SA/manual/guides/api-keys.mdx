يبيّن هذا الدليل أين تُخزَّن كل بيانات اعتماد يستخدمها Control Center، وكيف
تغيّرها.

**لا يُخزَّن شيء على الجهاز الذي تكتب عليه.** تعيش بيانات الاعتماد كلها على
الخادم، وأيها يجيب عن طلب بعينه يتوقف على وجود إنسان خلفه.

| الاعتماد | مكان التخزين | من يستخدمه |
| --- | --- | --- |
| اعتمادك لمضيف الشفرة والتذاكر | ملف أسرار الخادم بصلاحية 0600، ومفتاحه معرّف المستخدم | كل ما تطلبه: سطح طلبات السحب، وتشغيلات وكيلك، وصورك |
| هوية تطبيق الخادم | الملف نفسه، مع `server_settings` لما ليس سرًا | ما لم يطلبه إنسان: خطافات الويب، واستطلاع طلبات السحب، ومزامنة التذاكر |
| مفاتيح مزوّدي النماذج ورموز OAuth | مخزن بيانات اعتماد الخادم | المحوّل المضمّن، لكل مساحة عمل في التثبيت |
| رموز بوت Slack | `<dataDir>/<workspaceId>/chat_credentials/` على الخادم | جسر الدردشة لمساحة العمل تلك |
| بيانات اعتماد واجهة سطر الأوامر الخارجية | ما تستخدمه تلك الواجهة | Claude Code، على مضيف الخادم |

## اعتمادان لـ GitHub يجيبان عن سؤالين مختلفين

- **اعتمادك** يأتي من تسجيل الدخول (تدفق الجهاز) أو من لصق رمز. هو ما يستخدمه
  كل طلب يُقدَّم *نيابة عنك*، فيحمل التعليق المنشور عنك اسمك. لا يقرأه عضو
  آخر، ويتصل كل عضو بحسابه
- **اعتماد الخادم** يأتي من تطبيق GitHub الذي سجّله المشغّل. يجيب عما لا إنسان
  خلفه، فيبقى الوصول إلى مضيف الشفرة قائمًا إذا غادر شخص أو دوّر رمزه

يُضبط اعتمادك في بطاقة **استضافة الكود** ضمن **الإعدادات ← مساحة العمل ← الملف الشخصي والهوية**، واعتماد الخادم في **تطبيقات الموفّرين** ضمن **الإعدادات ← الخادم ← تسجيل الدخول الموحّد**. انظر [إعداد تكامل GitHub](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تكامل-github/)
و[إنشاء تطبيق GitHub](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تطبيق-github/).

:::note[شاشة لا تُفتح إلا بالعنوان]
`/workspaces/<workspaceId>/api-keys` تعرض البطاقتين نفسيهما كما في الخطوة
الأولى من الإعداد الأولي. **لا مدخل لها في التنقل في أي موضع من الواجهة**، ولا
تُفتح إلا بكتابة العنوان. استخدم الإعدادات ← مساحة العمل ← الملف الشخصي والهوية بدلًا من ذلك.
:::

## ضبط مفاتيح مزوّدي النماذج

يتولى المحوّل المضمّن مصادقة المزوّدين بنفسه، وتعيش بيانات الاعتماد هذه على الخادم.

1. افتح **الإعدادات ← الخادم ← مزوّدو النماذج**
2. انزل إلى **الموفّرون والنماذج**
3. اربط المزوّد: OAuth عبر المتصفح لـ OpenAI وCodex وCursor وKimi Code، ومفتاح API لـ Anthropic والبقية

انظر [إدارة المحوّلات والنماذج](/ar-SA/دليل-المستخدم/أدلة-إرشادية/محولات/) للقائمة الكاملة
ولإضافة نقطة نهاية مخصصة.

بيانات الاعتماد هذه **عامة على المضيف**: مفتاح واحد يخدم كل مساحة عمل في
التثبيت. تُجدَّد رموز OAuth قبل أن تنتهي.

تحتفظ واجهات سطر أوامر المحوّلات الخارجية ببيانات اعتمادها، في تهيئتها
الخاصة، على مضيف الخادم. Control Center لا يديرها. صادق Claude Code كما
تقول وثائقه، على الجهاز الذي يعمل عليه `cc_server`.

حوار **متغيرات البيئة** لكل محوّل يكتب إلى جهازك، والخادم يقرأ نسخته، ولا شيء
يصل بين الاثنين. مفتاح يُوضع هناك لإحدى واجهات سطر الأوامر تلك لا يبلغ الخادم. انظر
[إدارة المحوّلات والنماذج](/ar-SA/دليل-المستخدم/أدلة-إرشادية/محولات/).

## ربط مورّد تذاكر

تجمع بطاقة **التذاكر** في **الإعدادات ← مساحة العمل ← عام** طرفي قرار واحد: المورّد الذي
تعيش فيه تذاكرك، وبيانات الاعتماد الخاصة به. اختيار **محلي** يخفي صف
الاعتماد. التذاكر المحلية تعيش في قاعدة هذا الخادم، ولا جهة تُصادَق إليها.

يُخزَّن مفتاحك على الخادم مقابل معرّف المستخدم، كاعتماد مضيف الشفرة. يحتفظ
الخادم بمفتاح Linear الخاص به منفصلًا (**تطبيقات الموفّرين**)، وعليه تعمل
مزامنة التذاكر حين لا يطلب إنسان. لا يُحقن مفتاح يتلقاه وكيل إلا إذا ملك
الوكيل قدرة **السماح باستدعاءات API للتذاكر**. انظر
[إعداد تكامل Linear](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تكامل-linear/).

## التدوير أو الإبطال

- **اعتماد GitHub الخاص بك**: انقر **قطع الاتصال**، ثم سجّل الدخول مجددًا أو
  الصق الرمز الجديد. أبطل القديم على GitHub
- **تطبيق الخادم**: ولّد مفتاحًا خاصًا جديدًا أو سر العميل من صفحة التطبيق على
  GitHub، والصقه في **تطبيقات الموفّرين**، وانقر **اختبار**
- **مزوّد نموذج**: من صفه، سجّل الخروج (OAuth) أو أزل المفتاح، ثم اربطه من جديد
- **Slack**: أعد لصق الرموز في حوار الاتصال. انظر
  [إعداد تكامل Slack](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تكامل-slack/)

## استكشاف الأخطاء وإصلاحها

### قائمة طلبات السحب فارغة مع أن رمزي يعمل في `curl`

افحص العنوان الفرعي لصف **استضافة الكود**. إن سمّى مصدرًا آخر («عبر تطبيق هذا الخادم» أو «من البيئة»)، فالاعتماد الذي تختبره ليس الذي يجيب، واعتمادك لم يُحفظ.

### يُقبل الرمز ثم تفشل الطلبات اللاحقة

يُسبَر الرمز لحظة تخزينه، فيسمّي الصف الحساب الذي يقف خلفه وحده، لا نطاقاته.
رمز نطاقاته أقل مما يلزم يُقبَل، ثم تفشل طلباته واحدًا واحدًا. افحص النطاقات
وانتهاء الصلاحية:

```bash
curl -H "Authorization: token YOUR_TOKEN" https://api.github.com/user
```
