يبين هذا الدليل كيف تربط عميل MCP خارجي — Claude Code، أو محرّر، أو MCP Inspector —
بخادم الأدوات الخاص بـ Control Center.

يسجّل Control Center **110** أداةً ويقدّمها عبر Model Context Protocol بإصدار
البروتوكول `2024-11-05`. عائلات أدوات كاملة قد تتوقعها غائبة: لا أدوات
للاجتماعات ولا للتقويم، ولا أدوات للمشاريع.

## اعثر على نقطة النهاية

سطح MCP على المستمع الرئيسي لـ `cc_server`. لا منفذ منفصل لـ MCP.

| نقطة النهاية | الطريقة | الغرض |
| --- | --- | --- |
| `/mcp` | `POST` | نقل Streamable HTTP — هذا ما يتصل به العميل |
| `/mcp` | `DELETE` | إنهاء الجلسة |
| `/sse` | `GET` | تدفق إشعارات يرسلها الخادم |

إذن عنوان التثبيت المحلي الافتراضي `http://127.0.0.1:9030/mcp`.

1. انتقل إلى **الإعدادات ← الخادم ← خوادم MCP**
2. اقرأ بطاقة **خادم MCP** — تعرض «قيد التشغيل» أو «متوقف»، والمنفذ الذي تستمع عليه

السطح يعمل افتراضيًا على تثبيت جديد. لا يرى رمز البطاقة إلا مالك الخادم، ولا يستطيع تشغيل نقطة النهاية أو إيقافها إلا هو. يتحكم **البدء عند تشغيل التطبيق** في عودة السطح بعد إعادة التشغيل، و**بدء** / **إيقاف** يتحكمان في الجلسة ولا يغيّران ذلك التفضيل.

يربط الخادم loopback افتراضيًا، فلا يصل إلى نقطة النهاية إلا الجهاز الذي يعمل
عليه `cc_server`، ما لم تشغّله بـ `--bind any`.

## احصل على الرمز

كل طلب يحتاج إلى رمز MCP الخاص بالخادم، من أي جهاز، بما فيه loopback. يُنشئ الخادم الرمز في أول مرة يبدأ فيها التشغيل. ولا توجد طريقة لإيقافه، ولا لمسحه.

1. في **الإعدادات ← الخادم ← خوادم MCP**، اعثر على صف **رمز وصول المصادقة**
2. اضغط **إظهار الرمز** وانسخه
3. لاستبداله، اضغط **تدوير الرمز**. يبدّل الخادم إلى الرمز الجديد فورًا، ويُرفض كل عميل ما زال يستخدم القديم حتى تعطيه الجديد

## اربط عميلًا

وجّه عميلك إلى نقطة نهاية Streamable HTTP، وأرسل الرمز بالشكل `Authorization: Bearer <token>` مع كل طلب، بما فيه `GET /sse`. لا طريقة أخرى لإرساله: الرمز في عنوان URL غير مقبول. شكل الإعداد الدقيق شأن عميلك.

```json
{
  "mcpServers": {
    "control-center": {
      "type": "http",
      "url": "http://127.0.0.1:9030/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

### Claude Code

لن يلتقط Claude Code هذا من ملف `.mcp.json` في المشروع — فهو يحجب خوادم MCP
المرتبطة بالمشروع خلف مطالبة موافقة لا يجيب عنها تشغيل `claude -p` غير
التفاعلي. مرّر الإعداد صراحة:

```bash
claude --mcp-config /path/to/mcp.json --strict-mcp-config
```

`--strict-mcp-config` يجعل Claude يقتصر على ذلك الملف، فلا يُكتشَف الخادم نفسه
من المشروع ويُسجَّل مرتين.

نقطة التحقق: اطلب من العميل سرد أدواته. يفترض أن ترى أسماء `mcp__*` تغطي
التذاكر والمساحات والذاكرة ومخطط الشفرة والمراجعة.

## ما يرفضه السطح

يمنح الرمز كل أداة على الخادم، لذلك يرفض السطح أيضًا كل ما قد تكون صفحة ويب أرسلته، قبل أن ينظر إلى الرمز:

| الطلب | الرد |
| --- | --- |
| ترويسة `Origin` ليست صفحة على هذا الجهاز (`http://localhost` أو `http://127.0.0.1` أو `http://[::1]`، بأي منفذ) | `403`، «Cross-origin requests are not accepted» |
| ترويسة `Host` ليست عنوان loopback لهذا المستمع ومنفذه، ولا اسم المضيف العام للخادم | `403`، «Unknown host» |
| طلب `POST` جسمه ليس `application/json` | `415` |
| بلا رمز، أو برمز خاطئ | `401` |

لخدمة MCP خارج المضيف، شغّل الخادم بـ `--bind any` وأرسل الرمز من الجهاز الآخر، مخاطبًا الخادم باسم المضيف العام له.

## قيّد كل استدعاء بمساحة عمل

كل أداة تلمس بيانات على نطاق مساحة العمل تشترط `workspace_id`، ويُرفض
الاستدعاء الذي يخلو منه ولا يُحسم على «مساحة عمل حالية»:

```json
{
  "workspace_id": "acme",
  "title": "Fix login bug",
  "priority": "high"
}
```

المعرّف هو الظاهر في عنوان المتصفح أو التطبيق: `/workspaces/<workspace_id>/…`.
ولا يُستثنى إلا ما يمتد فعلًا عبر مساحات العمل، مثل `list_workspaces` وأدوات
موجز الأخبار. الموجز لكل مستخدم لا لكل مساحة عمل، والوكيل بلا مستخدم يخصه،
فتعمل تلك الأدوات على تغذيات مالك الخادم.

وتتحقق أدوات نطاق المستودع أيضًا من أن المستودع مربوط بمساحة العمل تلك.

## اعرف ما يرفضه السطح

- **بوابة الوضع.** يُحسم الاستدعاء على جهة الخادم وفق وضع مساحة الوكيل
  المستدعي. وكيل في وضع القراءة فقط لا يبلغ أداة كتابة بإسقاط `space_id`،
  فالوضع يُؤخذ من تشغيله النشط.
- **ضوابط الإجراء.** تصرّح الأدوات التي تعدّل الحالة بأصناف أثرها، وتمر
  بالسياسة نفسها التي يستخدمها سائر المنتج. انظر
  [تهيئة الضوابط](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تهيئة-الضوابط/).
- **التأكيد.** تبني بعض الأدوات المدمّرة حمولة تأكيد لا بد من الموافقة عليها
  قبل أن يمضي الاستدعاء.

يُعلن الفهرس كاملًا في `tools/list` بلا بوابة اكتشاف. عميل MCP الخارجي يرفض
استدعاء أداة ليست في قائمته المخزَّنة، فإخفاء الأدوات يعطّلها ولا ينظّف
القائمة.

## خوادم MCP الشخصية تبقى لمالكها

هذا الدليل يخص سطح Control Center نفسه. أما الاتجاه الآخر، وهو خوادم MCP التي تسلّمها Control Center للوكلاء الذين تشغّلهم، فيُدرج تحت **الإعدادات ← الخادم ← خوادم MCP ← خوادم MCP خارجية**. والخوادم المضبوطة على جهاز الخادم لـ Claude وCodex وCursor وGemini وVS Code وWindsurf وOpenCode، أو في `.mcp.json`، تُكتشف هناك تلقائيًا.

تأتي هذه الخوادم المكتشَفة من إعداد أدوات مستخدم الخادم نفسه، وتعمل بهوية ذلك المستخدم وبيانات اعتماده، لذا فهي تخص مالك الخادم:

- لا تتوفر إلا داخل تشغيلات حزام التشغيل المدمج التي يبدؤها مالك الخادم أو يتحمل مسؤوليتها، بما في ذلك الأتمتة في مساحة عمل يتحمل المالك مسؤوليتها.
- لا يحصل تشغيل أي عضو، ولا الأتمتة المرتبطة بعضو، ولا كل تشغيل على خادم بلا مالك مسجَّل، على أيٍّ منها. هناك لا تُدرج الأدوات، ولا يمكن استدعاؤها، ولا تظهر في البحث عن الأدوات.
- لا يسرد هذا السطح هذه الخوادم، ولا يستدعيها، ولا يبحث فيها لأي أحد، بما فيهم رمز المالك، ولا يمرّر مواردها أو مطالباتها. لذلك لا تحصل أداة سطر أوامر للوكلاء تصل إلى Control Center عبر MCP، مثل Claude Code، عليها من خلال Control Center أيضًا؛ بل تستخدم إعدادها الخاص.

لا تتأثر خوادم MCP المضبوطة لمساحة العمل بأي من ذلك.

## استكشاف الأخطاء وإصلاحها

### العميل لا يرى أدواتًا

- تحقق أن بطاقة **خادم MCP** تعرض «قيد التشغيل»
- تحقق أن المنفذ يطابق منفذ `cc_server`
- على Claude Code، تحقق أنك مررت `--mcp-config` و`--strict-mcp-config`

### 401 غير مصرّح به

الطلب يحمل رمزًا مفقودًا، أو رمزًا قديمًا. انسخ الرمز الحالي من صف **رمز وصول المصادقة** وأرسله بالشكل `Authorization: Bearer <token>`. يُتجاهل الرمز في عنوان URL.

### 403 من عميل كان يعمل من قبل

الطلب يحمل `Origin` من صفحة ويب، أو `Host` لا يستجيب له الخادم. استدعِ نقطة النهاية من عميل لا من صفحة متصفح، عبر عنوان loopback للخادم أو اسم مضيفه العام.

### 415 Unsupported Media Type

أرسل أجسام `POST /mcp` بالصيغة `application/json`.

### يفشل استدعاء أداة برسالة "Missing or invalid argument: workspace_id"

أضف `workspace_id`. لا مساحة عمل ضمنية.

### يُرفض استدعاء أداة على أنها مجهولة

يسرد [أدوات MCP](/ar-SA/دليل-المستخدم/مرجع/أدوات-mcp/) الفهرس. استدعِ الاسم
كما يظهر هناك تمامًا.
