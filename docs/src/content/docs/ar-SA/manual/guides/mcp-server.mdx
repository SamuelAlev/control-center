يبين هذا الدليل كيف تربط عميل MCP خارجي — Claude Code، أو محرّر، أو MCP Inspector —
بخادم الأدوات الخاص بـ Control Center.

يسجّل Control Center **110** أداةً ويقدّمها عبر Model Context Protocol بإصدار
البروتوكول `2024-11-05`. عائلات أدوات كاملة قد تتوقعها غائبة: لا أدوات
للاجتماعات ولا للتقويم، ولا أدوات للمشاريع.

## اعثر على نقطة النهاية

سطح MCP على المستمع الرئيسي لـ `cc_server`. لا منفذ منفصل لـ MCP.

| نقطة النهاية | الطريقة | الغرض |
| --- | --- | --- |
| `/mcp` | `POST` | نقل Streamable HTTP — هذا ما يتصل به العميل |
| `/mcp` | `DELETE` | إنهاء الجلسة |
| `/sse` | `GET` | تدفق إشعارات يرسلها الخادم |

إذن عنوان التثبيت المحلي الافتراضي `http://127.0.0.1:9030/mcp`.

1. انتقل إلى **الإعدادات ← الخادم ← خوادم MCP**
2. اقرأ بطاقة **خادم MCP** — تعرض «قيد التشغيل» أو «متوقف»، والمنفذ الذي تستمع عليه

السطح يعمل افتراضيًا على تثبيت جديد، فيعمل عميل loopback من غير فتح الإعدادات.
يتحكم **البدء عند تشغيل التطبيق** في عودة السطح بعد إعادة التشغيل، و**بدء** /
**إيقاف** يتحكمان في الجلسة ولا يغيّران ذلك التفضيل.

يربط الخادم loopback افتراضيًا، فلا يصل إلى نقطة النهاية إلا الجهاز الذي يعمل
عليه `cc_server`، ما لم تشغّله بـ `--bind any`.

## اربط عميلًا

وجّه عميلك إلى نقطة نهاية Streamable HTTP. شكل الإعداد الدقيق شأن عميلك،
والعنوان واحد في الحالين.

```json
{
  "mcpServers": {
    "control-center": {
      "type": "http",
      "url": "http://127.0.0.1:9030/mcp"
    }
  }
}
```

### Claude Code

لن يلتقط Claude Code هذا من ملف `.mcp.json` في المشروع — فهو يحجب خوادم MCP
المرتبطة بالمشروع خلف مطالبة موافقة لا يجيب عنها تشغيل `claude -p` غير
التفاعلي. مرّر الإعداد صراحة:

```bash
claude --mcp-config /path/to/mcp.json --strict-mcp-config
```

`--strict-mcp-config` يجعل Claude يقتصر على ذلك الملف، فلا يُكتشَف الخادم نفسه
من المشروع ويُسجَّل مرتين.

نقطة التحقق: اطلب من العميل سرد أدواته. يفترض أن ترى أسماء `mcp__*` تغطي
التذاكر والمساحات والذاكرة ومخطط الشفرة والمراجعة.

## اجعل MCP متاحًا خارج الجهاز المضيف

1. في **الإعدادات ← الخادم ← خوادم MCP**، ومن صف **رمز وصول المصادقة**، اضغط
   **تعيين** والصق رمزًا
2. أرسله بالشكل `Authorization: Bearer <token>` مع كل طلب `POST /mcp`

سطح بلا رمز يرفض أي متصل من غير loopback باستجابة 403. هذا مغلق عند الفشل عن
قصد: الرمز هو ما يجعل الخدمة خارج الجهاز المضيف ممكنة أصلًا.

تنطبق تغييرات الرمز فورًا على السطح العامل — بلا إعادة تشغيل.

:::note[`GET /sse` يقبل الرمز في سلسلة الاستعلام]
يُفحص تدفق الإشعارات بالرمز كسائر المسارات، لكن `EventSource` في المتصفح لا
يستطيع إرسال ترويسة `Authorization`، فيقبل `/sse` الرمز أيضًا بالشكل
`?token=<token>`. من غير رمز يرد 401.
:::

## قيّد كل استدعاء بمساحة عمل

كل أداة تلمس بيانات على نطاق مساحة العمل تشترط `workspace_id`، ويُرفض
الاستدعاء الذي يخلو منه ولا يُحسم على «مساحة عمل حالية»:

```json
{
  "workspace_id": "acme",
  "title": "Fix login bug",
  "priority": "high"
}
```

المعرّف هو الظاهر في عنوان المتصفح أو التطبيق: `/workspaces/<workspace_id>/…`.
ولا يُستثنى إلا ما يمتد فعلًا عبر مساحات العمل، مثل `list_workspaces` وأدوات
موجز الأخبار. الموجز لكل مستخدم لا لكل مساحة عمل، والوكيل بلا مستخدم يخصه،
فتعمل تلك الأدوات على تغذيات مالك الخادم.

وتتحقق أدوات نطاق المستودع أيضًا من أن المستودع مربوط بمساحة العمل تلك.

## اعرف ما يرفضه السطح

- **بوابة الوضع.** يُحسم الاستدعاء على جهة الخادم وفق وضع مساحة الوكيل
  المستدعي. وكيل في وضع القراءة فقط لا يبلغ أداة كتابة بإسقاط `space_id`،
  فالوضع يُؤخذ من تشغيله النشط.
- **ضوابط الإجراء.** تصرّح الأدوات التي تعدّل الحالة بأصناف أثرها، وتمر
  بالسياسة نفسها التي يستخدمها سائر المنتج. انظر
  [تهيئة الضوابط](/ar-SA/دليل-المستخدم/أدلة-إرشادية/تهيئة-الضوابط/).
- **التأكيد.** تبني بعض الأدوات المدمّرة حمولة تأكيد لا بد من الموافقة عليها
  قبل أن يمضي الاستدعاء.

يُعلن الفهرس كاملًا في `tools/list` بلا بوابة اكتشاف. عميل MCP الخارجي يرفض
استدعاء أداة ليست في قائمته المخزَّنة، فإخفاء الأدوات يعطّلها ولا ينظّف
القائمة.

## استكشاف الأخطاء وإصلاحها

### العميل لا يرى أدواتًا

- تحقق أن بطاقة **خادم MCP** تعرض «قيد التشغيل»
- تحقق أن المنفذ يطابق منفذ `cc_server`
- على Claude Code، تحقق أنك مررت `--mcp-config` و`--strict-mcp-config`

### 403 من جهاز غير الخادم

لم يُضبط رمز Bearer. عيّن واحدًا وأرسله.

### يفشل استدعاء أداة برسالة "Missing or invalid argument: workspace_id"

أضف `workspace_id`. لا مساحة عمل ضمنية.

### يُرفض استدعاء أداة على أنها مجهولة

يسرد [أدوات MCP](/ar-SA/دليل-المستخدم/مرجع/أدوات-mcp/) الفهرس. استدعِ الاسم
كما يظهر هناك تمامًا.
