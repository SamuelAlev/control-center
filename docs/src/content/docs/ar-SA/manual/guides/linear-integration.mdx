الصق مفتاح API لـ Linear على الخادم مقابل مستخدمك، بالطريقة نفسها التي تربط بها
مضيف شفرة. التذاكر والمشاريع والروابط والمتعاونون والتفويض والإسناد، كلها تعمل
على قاعدة بيانات Control Center الخاصة، بلا حاجة إلى خدمة خارجية —
انظر [إنشاء التذاكر وإدارتها](/ar-SA/دليل-المستخدم/أدلة-إرشادية/إدارة-التذاكر/).

## تخزين مفتاح Linear

**مفتاح API للتذاكر** موجود في **الإعدادات ← مساحة العمل ← عام**، على بطاقة
التذاكر. يُخزَّن المفتاح على الخادم مقابل معرّف المستخدم. مفتاح الخادم نفسه
للعمل الذي لا إنسان خلفه يأتي من `LINEAR_API_KEY` أو من بطاقة
**تطبيقات الموفّرين**. لا يوضع أي مفتاح تذاكر في البيئة المعزولة للوكيل: يكتب
الوكلاء التذاكر عبر أدوات Control Center نفسها، وهي تسأل قاعدة
**الكتابة إلى متتبع خارجي** أولًا.

## ختم التذاكر الجديدة بـ Linear

**مزوّد التذاكر** (الخطوة الأولى من الإعداد الأولي، و
`/workspaces/<workspaceId>/api-keys`) يعرض `local` و`linear`. اختيار
`linear` يختم التذاكر التي تنشئها من ذلك الحين بـ `provider: linear`.
