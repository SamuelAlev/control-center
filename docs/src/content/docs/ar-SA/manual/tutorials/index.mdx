Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/ar-SA/دليل-المستخدم/أدلة-إرشادية/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/ar-SA/دليل-المستخدم/دروس/أول-مساحة-عمل/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/ar-SA/دليل-المستخدم/دروس/أول-وكيل/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/ar-SA/دليل-المستخدم/دروس/أول-طلب-سحب/) — read the diff, comment and merge
4. [Build your first pipeline](/ar-SA/دليل-المستخدم/دروس/أول-خط-أنابيب/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/ar-SA/دليل-المستخدم/دروس/أول-جسر-دردشة/) — drive agents from a Slack thread
- [Sign your team in with SSO](/ar-SA/دليل-المستخدم/دروس/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/ar-SA/دليل-المستخدم/تثبيت/). If you only want the
shortest possible path to a running agent, take the [quick start](/ar-SA/دليل-المستخدم/بداية-سريعة/)
instead and come back here afterwards.
:::
