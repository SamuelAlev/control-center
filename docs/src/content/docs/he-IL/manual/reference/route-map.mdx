## מסגרת היישום

מסגרת היישום (`ControlCenterLayout`) עוטפת כל נתיב בתוך סביבת עבודה דרך `ShellRoute`. **כל יעד בתוך המסגרת מקבל קידומת של סביבת עבודה — `/workspaces/:workspaceId/…` — ומזהה סביבת העבודה בכתובת הוא מקור האמת היחיד לסביבת העבודה הפעילה.** רק המשטחים שאינם תלויים בהקשר הם בלי קידומת: `/splash`, `/onboarding` ובורר `/workspaces` החשוף, כולם במסך מלא ומחוץ למסגרת.

שער הקליטה נחשב שלם عندما מחובר לפחות מארח קוד אחד **עבור המשתמש המחובר** ולפחות סביבת עבודה אחת קיימת.

פרטי התחברות חסרים והגדרה חסרה מטופלים בדרכים שונות, והמבחין ביניהם הוא `users.onboarding_finished_at` הנקרא מ־`identity.me` של הקורא עצמו — ולעולם לא "קיימות סביבות עבודה", שכן הנחה זו שגויה ברגע שמישהו מוזמן לסביבת עבודה שהוא מעולם לא יצר. כשאין מארח קוד מחובר, חשבון שהשלים את הקליטה נשאר באפליקציה: מסגרת סביבת העבודה מציגה אזהרה עם קישור ל**הגדרות ← אישי ← פרופיל**, שם נמצאת ההתחברות; חשבון שלא השלים אותה עובר ל־`/onboarding`. כל עוד הדגל אינו ידוע, השומר מחזיק במסך האתחול במקום לנחש, מפני שהוא לעולם אינו מפנה חזרה החוצה מהקליטה.

## נתיבים ללא קידומת

| נתיב                     | מסך                                            |
| ------------------------ | ---------------------------------------------- |
| `/splash`                | מסך האתחול שקובע את שער הקליטה                   |
| `/onboarding`            | חיבור מארח קוד, יצירה או הצטרפות לסביבת עבודה, ארגז חול, מתאם ברירת מחדל ואז קול. שלב סביבת העבודה מדולג כשהחשבון כבר שייך לאחת |

| `/settings/…`                             | —                                         | מסכי הגדרות (להלן)                                                                                                                                                        |

לשיחות ולשרשורים **אין נתיב משלהם** — שרשור הוא שיחה בתוך `/spaces/:spaceId`, שנפתחת כלשונית עורך ולא ממוענת דרך כתובת URL.

אין **נתיב `/dashboard`** ואין מסך לוח בקרה. משטח הניתוח הוא `/observability`, שאליו מגיעים מתחתית סרגל הצד.

אין **פריט "תוכניות" בסרגל הצד**. Plan Studio נפתח כלשונית עורך משורת התוכנית שבשיחה שיצרה אותה; `/plans` ו־`/plans/:kind/:id` הם קישורים ישירים.

ל־`/observability` ול־`/pull-requests/compose` אין רשומה במרשם כותרות הנתיבים או במרשם נתיבי הניווט, ולכן שניהם מציגים את שם האפליקציה בלבד בכותרת החלון ובלי נתיב ניווט.

## נתיבי הגדרות

`/settings` מפנה אל `/settings/you/profile`. כפתור ההגדרות בסרגל הצד וגם `Cmd/Ctrl + ,` מובילים שניהם אל `/settings/you/profile`.

נתיבי ההגדרות מסווגים לפי **היקף** — `you/`, `workspace/`, `server/` — מפני שהמקטע מציין על מי משפיע השינוי. שני נתיבים קדמו לסיווג הזה ואינם מסווגים בכתובת: `/settings/memory` ו־`/settings/pipelines`.

### אישי

| נתיב                          | מסך                                                                        |
| ----------------------------- | -------------------------------------------------------------------------- |
| `/settings/you/profile`       | החשבון שלכם בשרת זה: שם, שם משתמש, תמונה והתחברות (דף הנחיתה של ההגדרות) |
| `/settings/you/profile?section=accounts` | חשבונות מחוברים: ההתחברויות האישיות שלכם לאחסון קוד, כרטוס, לוח שנה וצ'אט, וטיוטות כרטיסים מהצ'אט |
| `/settings/you/appearance`    | ערכת נושא, שפה, טיפוגרפיה וערכת נושא לעורך |
| `/settings/you/audio`         | מיקרופון, הכתבה, זיהוי פגישות ופלט הנוף הצלילי                               |
| `/settings/you/notifications` | מתגים לפי אירוע ושעות שקט                                                   |
| `/settings/you/commits`       | מי מקבל קרדיט על commits מעבודה שאתם מתחילים, ומפתח החתימה שלכם ל-commits   |
| `/settings/you/desktop`       | לאפליקציית שולחן העבודה בלבד: סמל המגש, סגירת החלון ופתיחה בעת הכניסה        |
| `/settings/you/devices`       | טלפונים משויכים ושליטה מרחוק                                                |
| `/settings/you/newsfeed`      | ניהול הפיד: מקורות, רענון ומצב קריאה                                        |
| `/settings/you/links`         | היכן קישורים מחוץ ל-Control Center נפתחים                                   |

`kSettingsNav` ב־`lib/features/settings/settings_nav.dart` הוא מקור האמת היחיד לרשימה הזו. `settings_nav_test.dart` מקבע מזהים ייחודיים, נתיבים ייחודיים, סדר J/K שטוח ואת שלושת ההיקפים. הוא אינו עובר על כל `GoRoute` רשום.
