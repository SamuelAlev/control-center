קיצורי המקלדת מגיעים ממרשם `const` יחיד, `KeybindingRegistry` שב-`lib/core/constants/keybindings.dart`. הוא מכיל **48 צירופים**. המסך **הגדרות → אישי → קיצורי מקלדת** מציג את המרשם הזה כ**עזר לקריאה בלבד**: אין ממשק לשינוי הקצאות ואין קובץ קיצורי מקלדת של המשתמש.

‏`Cmd` בהמשך הוא מקש הפקודה הראשי — ⌘ ב-macOS, ו-Ctrl ב-Windows וב-Linux. צירוף פועל רק כשהפקודה שלו רשומה למטפל במסך הנוכחי וסעיף ה-`when` שלו מתקיים; `!textInputFocus` פירושו שהמקש מועבר לשדה טקסט שבפוקוס במקום זאת.

אין קיצור מקלדת לניווט במקשי ספרות. אל דואר נכנס, כרטיסים, בקשות משיכה וכל השאר מגיעים מסרגל הצד או מ-⌘K. גם לניטור אין קיצור.

## גלובלי (19)

טווח `global`, ולכן הם פעילים בכל מקום במעטפת האפליקציה.

## רשימת בקשות משיכה (3)

טווח `/pull-requests`. כולם דורשים `route == '/pull-requests'` ואין שדה טקסט בפוקוס, ולכן הם אינם פועלים כשנתיב פרטי בקשת המשיכה פתוח מעל הרשימה.

| קיצור | פעולה |
| -------- | ---------------- |
| `R`      | רענון            |
| `Enter`  | פתיחת PR         |
| `F`      | פתיחת תפריט הסינון |

‏`Enter` (`pr.list-open`) מוצהר במרשם ומופיע בעזר קיצורי המקלדת, אבל **מסך הרשימה אינו רושם לו מטפל**, ולכן הוא אינו פועל כרגע. `F` פותח את תפריט הסינון (`pr.list-open-filter`), ולא את החיפוש.

## פרטי בקשת משיכה (2)

טווח `/pull-requests/`. הרענון דורש שאין שדה טקסט בפוקוס. לסגירת הלשונית אין הגנת קלט טקסט (צירוף עם ⌘ הוא לעולם לא טקסט רגיל) ויש לה ביטוי רגולרי לנתיב, כך שהיא אינה פועלת ברשימה.

| קיצור       | פעולה    | תנאי                              |
| -------------- | --------- | ---------------------------------- |
| `R`            | רענון     | לא מקלידים בשדה                    |
| `Cmd/Ctrl + W` | סגירת לשונית | במיקום `/pull-requests/<…>`        |

מעבר בין לשוניות (`1`/`2`/`3`), סימון קובץ כנצפה וכיווצו (`V`/`C`), רשימת הקבצים (`T`) וחיפוש ב-diff (`Cmd/Ctrl + F`) שייכים למטפל של מציג ה-diff עצמו — ראו [מקשי מציג ה-diff מחוץ למרשם](#מקשי-מציג-ה-diff-מחוץ-למרשם).

## פרופילים של משתמשים וצוותים ב-GitHub (3)

טווח `/users/`. סעיף ה-`when` הוא ביטוי רגולרי כנגד `/users/<login>` **או** `/teams/<organization>/<slug>`, ובנוסף אין שדה טקסט בפוקוס.

| קיצור       | פעולה       |
| -------------- | ------------ |
| `R`            | רענון        |
| `/`            | מיקוד בחיפוש |
| `Cmd/Ctrl + F` | מיקוד בחיפוש |

## מרחבים (8)

טווח `/spaces`. סעיפי ה-`when` משתמשים בביטוי רגולרי, ולכן הם פועלים גם ברשימת המרחבים (`/spaces`) וגם במרחב נבחר (`/spaces/<id>`).

| קיצור               | פעולה                 | תנאי                 |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | שליחת הודעה            | —                     |
| `Cmd/Ctrl + N`         | מרחב חדש               | בנתיב `/spaces`       |
| `J`                    | המרחב הבא              | לא מקלידים בשדה        |
| `K`                    | המרחב הקודם            | לא מקלידים בשדה        |
| `Cmd/Ctrl + Shift + D` | הכתבה במצב לחץ ודבר     | —                     |
| `Cmd/Ctrl + T`         | פתיחת לשונית בעורך     | בנתיב `/spaces`       |
| `Cmd/Ctrl + W`         | סגירת לשונית בעורך     | בנתיב `/spaces`       |
| `Cmd/Ctrl + B`         | פתיחה/סגירה של סרגל הצד של העורך | בנתיב `/spaces`       |

שליחה ב-Enter שייכת לשדה הטקסט של תיבת הכתיבה; ההכתבה במצב לחץ ודבר שייכת לכפתור המיקרופון של תיבת הכתיבה (מטפל מקלדת החומרה שלו). שניהם רשומים במרשם לצורך עזר ההגדרות.

## מקשי מציג ה-diff מחוץ למרשם

מציג ה-diff של בקשות משיכה מטפל באלה בעצמו (`PrDiffKeyboardHandler`). חיפוש, סימון כנצפה וכיווץ רשומים בהערות המרשם לצורך עזר ההגדרות בלבד — לא רשום להם מטפל במשגר, ולכן המשגר משאיר אותם לתצוגת ה-diff. הם אינם מופיעים כשורות נפרדות בעזר קיצורי המקלדת.

| קיצור        | פעולה                                               |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | חיפוש ב-diff                                         |
| `J` / `K`       | הקובץ הבא / הקודם                                    |
| `V`             | סימון/ביטול הסימון של הקובץ שבפוקוס כנצפה           |
| `C`             | כיווץ/פריסה של הקובץ שבפוקוס                         |
| `T`             | הצגת רשימת הקבצים                                    |
| `Enter`         | התאמת החיפוש הבאה (רק כשחיפוש ב-diff פתוח)          |
| `Shift + Enter` | התאמת החיפוש הקודמת                                  |
| `Escape`        | סגירת חיפוש ב-diff, או ניקוי בחירת הטקסט ב-diff     |
| `Cmd/Ctrl + C`  | העתקת הבחירה ב-diff                                  |

## צירופים שמורים לדפדפן

בבנייה לווב, הדפדפן צורך חלק מצירופי המקלדת לפני שהעמוד רואה אותם, ולכן הצירופים המתאימים לא יכולים לפעול שם לעולם. בשולחן העבודה הם פועלים כרגיל. הם שמורים כשהם משולבים עם מקש הפקודה הראשי: `T`, `W`, `N` והספרות `1`–`9`.

זה חל על מעבר בין סביבות עבודה עם `Cmd/Ctrl + Alt + 1`–`9`, על `Cmd/Ctrl + N` (מרחב חדש, סביבת עבודה חדשה, סוכן חדש, הוספת מאגר) ועל `Cmd/Ctrl + T` / `Cmd/Ctrl + W` במרחבים ובפרטי בקשת משיכה.
