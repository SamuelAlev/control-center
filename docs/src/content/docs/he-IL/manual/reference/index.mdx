דפי העזר מתארים **מה קיים**, באופן ממצה וללא פרשנות. השתמשו בהם כדי לחפש משהו
כשכבר יודעים מה בדיוק מחפשים: שם של כלי מסוים, סוג שלב, מעבר סטטוס, נתיב או
קיצור מקלדת.

הם אינם כתובים לקריאה רצופה מההתחלה ועד הסוף. לשם כך פנו אל
[המושגים](/he-IL/מדריך-למשתמש/מושגים/); וכדי לבצע משהו פנו אל
[מדריכי How-to](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/).
