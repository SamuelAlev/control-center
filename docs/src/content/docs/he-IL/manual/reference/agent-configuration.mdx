## דגלי AgentCapabilities

נקבעים מחדש בכל שליחה: ברירת המחדל של הסוכן, עם נפילה חזרה לברירת המחדל ברמת המשתמש כשהיא null, ומעליהן עקיפה לפי שיחה. הם נאכפים בדרך השלילה — מתווך פרטי הגישה פשוט אינו מנפיק ואינו מזריק את מה שיכולת כבויה מכסה.

| דגל                 | טיפוס  | ברירת מחדל | תיאור                                                                                       |
| ------------------- | ------ | ---------- | ------------------------------------------------------------------------------------------- |
| `canPushToRepo`     | `bool` | `false`    | דחיפת קומיטים למאגר המרוחק; משמש שער להזרקת אסימון GitHub לצד `canCallGitHubApi`            |
| `canCallGitHubApi`  | `bool` | `false`    | קריאה אל api.github.com; משמש שער להזרקת `GH_TOKEN` ולדומייני היציאה של GitHub               |
| `canCallTicketing`  | `bool` | `false`    | קריאה ל-API של ספק הכרטוס; משמש שער להזרקת מפתח ה-API של הספק ולדומייני היציאה שלו           |
| `canAccessNetwork`  | `bool` | `true`     | יציאה יוצאת שרירותית. משמש שער גם לכלים `web_fetch` ו-`web_search` של מנגנון ההרצה            |

`AgentCapabilities.safeDefault` הוא ארבע ברירות המחדל של הבנאי. `legacyDefault` (ארבעתן true) משמש רק את המיגרציה שמילאה בדיעבד שיחות שנוצרו לפני שהיכולות היו קיימות. blob שמור פגום או ריק מפוענח ל-`safeDefault`; המפתח הישן `canCallLinear` נקרא בתור `canCallTicketing`.

## AgentLiveState (נגזר)

אינו נשמר. שבעה ערכים. סדר ההצהרה הוא סדר העדיפויות (`sortPriority`, מוצמד בבדיקה), והוא הסדר שלפיו ממיין הסגל:

| מצב         | `sortPriority` | תנאי                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | ליומן הרצה כלשהו יש סטטוס `running`                                                                                 |
| `blocked`   | 1              | מצב החיות של ההרצה האחרונה הוא `blocked`, `stalled` או `looping`                                                     |
| `failed`    | 2              | הסטטוס של ההרצה האחרונה הוא `error`, או שמצב החיות שלה הוא `failed` או `dead`                                       |
| `queued`    | 3              | הרצה נשלחה אך אינה מתבצעת — היא חונה מאחורי הרצה אחרת של אותו סוכן, או שנכתבה אך טרם החלה                             |
| `succeeded` | 4              | ההרצה הסתיימה בהצלחה                                                                                                |
| `idle`      | 5              | הסוכן כבר רץ בעבר ואין לו דבר באוויר                                                                                 |
| `neverRun`  | 6              | לא קיימים יומני הרצה                                                                                                |

`queued` ו-`succeeded` הם **להרצה בודדת בלבד**. `deriveAgentLiveState`, שמחשב את מצב הסגל של סוכן, לעולם אינו מפיק אף אחד מהם — הוא מחזיר `neverRun`, `running`, `failed`, `blocked` או `idle`.
