הדביקו מפתח API של Linear בשרת, כשהוא משויך למשתמש שלכם, באותו אופן שבו אתם
מחברים מארח קוד. כרטיסים, פרויקטים, קישורים, משתתפים, האצלה והקצאה פועלים כולם
מול מסד הנתונים של Control Center עצמו, בלי צורך בשירות חיצוני — ראו [יצירה
וניהול של כרטיסים](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/ניהול-כרטיסים/).

## שמירת מפתח Linear

**מפתח API לניהול כרטיסים** נמצא ב**הגדרות ← סביבת עבודה ← כללי**, בכרטיס
**כרטוס**. הוא שומר את המפתח בשרת לפי מזהה המשתמש שלכם. המפתח של השרת עצמו
לעבודה ללא השגחה מגיע מ-`LINEAR_API_KEY` או מהכרטיס **אפליקציות ספק**, ומוזרק
בתור `TICKETING_API_KEY` רק כשהסוכן הזה מחזיק ביכולת **התרת קריאות API של ניהול
כרטיסים**.

## סימון כרטיסים חדשים כ-Linear

**ספק ניהול כרטיסים** (השלב הראשון בתהליך ההיכרות, וגם
`/workspaces/<workspaceId>/api-keys`) מציע את `local` ואת `linear`. בחירה
ב-`linear` מסמנת `provider: linear` על כרטיסים שתיצרו מעתה ואילך.
