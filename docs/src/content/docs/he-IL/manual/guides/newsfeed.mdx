המדריך הזה מראה איך לעצב את עדכוני החדשות: מאילו מקורות הם נשלפים, איך נקראות
כתבות ומה עושה חסימת התוכן.

:::caution[עדכוני החדשות הם לכל משתמש, ולא ברמת סביבת העבודה]
פידים וכתבות שייכים למשתמש המחובר: רשימת הפידים, מצב הקריאה והסימניות שלכם
עוקבים אחריכם לכל סביבת עבודה ולכל מכשיר שממנו אתם נכנסים, ואף משתמש אחר לא רואה
אותם. הפידים נמצאים במסד הנתונים הגלובלי של השרת, כך שכתובת ה-`/newsfeed` נושאת
מזהה של סביבת עבודה רק מפני שכל נתיב בתוך היישום עושה זאת.
:::

## קריאת כתבות

1. לחצו על **עדכוני חדשות** בסרגל הצד
2. עברו בין **הכול**, **שלא נקראו** ו**נשמר** באמצעות מקטעי סרגל הכלים
3. צמצמו את הרשימה באמצעות תיבת החיפוש או בורר המקורות
4. עברו בין רשת המגזין לרשימה הצפופה באמצעות לחצני הפריסה

פתיחת כתבה מסמנת אותה כנקראה. השתמשו ב**סימון הכול כנקרא** בכותרת העמוד — הוא
מופיע רק כשמשהו אינו נקרא — כדי לפנות את הצבר בבת אחת, ובפקד הסימנייה בכרטיס כדי
לשמור כתבה להמשך.

בחירת הפריסה נשמרת בין הפעלות.

## הוספת פיד

1. פתחו את **הגדרות ← אישי ← עדכוני חדשות** (סמל ההגדרות בכותרת עדכוני החדשות
   מוביל לשם ישירות)
2. לחצו על **הוספת פיד**
3. מלאו **שם** ואת **כתובת URL של הפיד** (RSS או Atom)
4. לחלופין, פרשו את **מתקדם** והגדירו **User-Agent** מותאם אישית — יש מפרסמים
   שמגישים תשובה שונה ללקוח ברירת מחדל
5. לחצו על **הוספת פיד**

נקודת ביקורת: הפיד מופיע ברשימת **פידים** והכתבות שלו מגיעות לאחר השליפה
הראשונה. כתובת URL שכבר רשומה נדחית עם ההודעה "פיד עם כתובת URL זו כבר קיים."

ארבעה עשר פידים נוצרים מראש לכל משתמש בשימוש הראשון: Control Center,‏ The Verge,‏
TechCrunch,‏ Hacker News,‏ ByteByteGo,‏ Product Hunt,‏ TLDR AI,‏ Import AI,‏ The
Pragmatic Engineer,‏ Martin Fowler,‏ Will Larson's Irrational Exuberance,‏ The
Engineering Manager,‏ Lea Verou ו-CSS-Tricks.

## ניהול פידים

כל שורה ברשימת **פידים** מציעה שלושה פקדים:

| פקד          | השפעה                                                               |
| ------------ | ------------------------------------------------------------------- |
| מתג          | השבתת הפיד. שורה מושבתת מעומעמת ואינה נשלפת עוד                       |
| סמל רענון    | שליפת הפיד הזה כעת                                                   |
| סמל פח       | מחיקת הפיד, לאחר אישור                                               |

**רענן הכול** בראש הרשימה שולף כל פיד מופעל.

כותרת המשנה של פיד מציגה את התיאור שלו ואת הזמן שחלף מאז השליפה; פיד שנכשל מציג
במקומה את השגיאה, בצבע אזהרה.

אין אפשרות עריכה — כדי לשנות שם, כתובת URL או user agent של פיד, מחקו אותו והוסיפו
אותו מחדש.

השליפה מתבצעת כולה בשרת: פעם אחת לכל משתמש בעת האתחול (ובשימוש הראשון עבור חשבונות
שנוצרו מאוחר יותר), ואחר כך כל 30 דקות.

## חסימת פרסומות ורכיבי מעקב בקורא

1. בהגדרות ← אישי ← עדכוני חדשות, אתרו את **העדפות קריאה**
2. השאירו את **פתח כתבות בתוך היישום** פעיל כדי להשתמש בקורא המובנה, או כבו אותו
   כדי למסור כתבות לדפדפן המערכת
3. השאירו את **חסימת פרסומות, רכיבי מעקב ובאנרים של עוגיות** פעיל

החסימה פעילה כברירת מחדל. הקורא המובנה קיים ב-macOS וב-Windows בלבד: בגרסת הווב
וב-Linux דפדפן המערכת _הוא_ הקורא והכתבה נפתחת בו (לשונית חדשה בווב). בווב מתג
החסימה, הכרטיס **רשימות סינון** והכרטיס **אתרים מהימנים** מוסתרים.

הקורא בתוך היישום אינו מעצב מחדש את הכתבה. הוא מציג את העמוד של המפרסם בתוך webview
מוטמע ומדכא פרסומות, רכיבי מעקב ובאנרים של עוגיות באמצעות רשימות סינון שמורות
במטמון.

### בדיקה או עדכון של רשימות הסינון

הכרטיס **רשימות סינון** מציג כמה כללים להסתרת עוגיות, להסתרת פרסומות ולחסימת רשת
נטענו, וגם אילו פרמטרי מעקב הוא מסיר ומתי הרשימות עודכנו לאחרונה. לחצו על **בדיקת
עדכונים** כדי לרענן אותן.

המקורות הם EasyList,‏ i-dont-care-about-cookies,‏ Fanboy Cookiemonster,‏ כמה רשימות
של uBlock Origin ורשימת פרמטרי המעקב של uBO. עד שההורדה תצליח, הכרטיס מתייג את
הרשימות כברירות מחדל מצורפות שמעולם לא עודכנו — מוני כללי הפרסומות, העוגיות והרשת
נשארים על אפס; הסרת פרמטרי המעקב עדיין משתמשת בקבוצת ברירת מחדל מובנית.

### הוספת אתר לרשימת המותרים

יש אתרים שנשברים תחת החסימה.

1. בהגדרות ← אישי ← עדכוני חדשות, עברו אל **אתרים מהימנים**
2. לחצו על **הוספת אתר מהימן** והזינו את הדומיין

החסימה מדולגת שם.

## פתרון תקלות

### פיד שהוספתי מופיע בסביבת עבודה אחרת

זו התוצאה הצפויה. עדכוני החדשות הם לכל משתמש ולא לפי סביבת עבודה — הפידים שלכם
עוקבים אחריכם לכל מקום שאתם מחוברים בו. ראו את תיבת האזהרה בראש העמוד.

### שורת פיד מציגה שגיאה במקום תיאור

השליפה האחרונה נכשלה והשורה מציגה את הסיבה כפי שהיא. לחצו על סמל הרענון כדי לנסות
שוב ובדקו שכתובת ה-URL עדיין מגישה RSS או Atom. מפרסם שדוחה לקוחות לא מוכרים עשוי
להזדקק ל-user agent מותאם אישית, כלומר למחוק את הפיד ולהוסיף אותו מחדש.

### עמוד כתבה מוצג באופן לקוי

כבו את **חסימת פרסומות, רכיבי מעקב ובאנרים של עוגיות** עבור אותו דומיין דרך **אתרים
מהימנים**, או כבו את **פתח כתבות בתוך היישום** וקראו אותה בדפדפן שלכם.
