המדריך הזה מראה כיצד להגדיר התראות ומה כל הגדרה באמת שולטת בו.

ההתראות מגיעות בשני משטחים. **מרכז ההתראות** — הפעמון שבשורת הכותרת — קורא פיד
מתמשך לפי סביבת עבודה בשרת. **התראות קופצות של מערכת ההפעלה** הן נתיב נפרד,
לשולחן העבודה בלבד, שניזון ממסגרות חיות שהשרת דוחף.

:::note[גרסת הווב אינה מציגה התראות מערכת הפעלה]
צינור ההתראות הקופצות נבנה רק באתחול שולחן העבודה. ב-`app.usectrl.dev` אין
התראות קופצות של מערכת ההפעלה, אין צלילי התראות ואין רצועת באנרים סביבתית —
הפעמון וההיסטוריה שלו עדיין עובדים, משום שהם קוראים את הפיד של השרת. ללקוח
הטלפון אין כלל משטח התראות.
:::

## הפעלה או כיבוי של קטגוריות

1. עברו אל **הגדרות → אישי → התראות**
2. השאירו את **הפעלת התראות** דלוק
3. הפעילו או כבו את הקטגוריות שאתם רוצים. יש בדיוק שש עשרה:

| קטגוריה                  | נקראת כאשר                                                                 |
| ------------------------- | -------------------------------------------------------------------------- |
| הסוכן סיים            | סוכן השיב בהרצה שהתחלתם, או שההרצה נכשלה                          |
| PR פורסם              | סוכן פרסם PR                                                    |
| PR מוזג            | PR מוזג                                                            |
| הודעות חדשות              | מישהו הזכיר אתכם במרחב                                    |
| אוזכרת בבקשת משיכה | סקר ההתראות של GitHub ראה שאוזכרתם בבקשת משיכה                       |
| התבקשה סקירה          | הסקירה שלכם התבקשה בפועל בבקשת משיכה שאינה טיוטה                       |
| הסקירה אינה עדכנית        | קומיטים חדשים נחתו בבקשת משיכה שכבר סקרתם                  |
| מוכן למיזוג           | בקשת משיכה שאתם מחבריה הפכה לניתנת למיזוג, או חדלה מלהיות                     |
| החלטות סקירה          | סוקר אישר, ביקש שינויים, או שאישור שלו נדחה       |
| בדיקות                    | CI נכשל בבקשת משיכה שאתם מחבריה, או התאושש                     |
| שרשורי סקירה          | מישהו השיב בשרשור שאתם משתתפים בו או סימן אותו כנפתר                         |
| כרטיס הוקצה           | כרטיס הוקצה                                                      |
| סטטוס כרטיס השתנה     | כרטיס החליף סטטוס                                                    |
| פגישה מתחילה בקרוב     | פגישה ביומן נכנסת לחלון ההתראה מראש שלכם                              |
| לוח השנה נותק     | תוקף אסימון ה-OAuth של יומן מחובר פג                                 |
| עדכוני מתחם מבודד         | מתחם מבודד הושתלט, פונה או נכשל                           |

כל דבר שאינו ברשימה הזו אינו יכול להתריע או להיות מסונן — אין קטגוריית
״כל השאר״.

ההעדפות האלה עוקבות אחרי המשתמש שלכם בין מכשירים, כך שטלפון ומחשב נייד נשארים
מסונכרנים. עוצמת הקול היא החריג המכוון ונשארת לכל מכשיר בנפרד.

## הגדרת Quiet hours

1. באותו עמוד, הפעילו את **Quiet hours**
2. הקלידו שעת התחלה ושעת סיום בתבנית `HH:MM` (חלון ברירת המחדל הוא 22:00–08:00)

במהלך Quiet hours התראות שאינן דחופות מושלכות — אינן נכנסות לתור ואינן מוצגות
שוב מאוחר יותר.

שתי קטגוריות הן **דחופות** ותמיד נמסרות, תוך עקיפת Quiet hours _ו_מצב ריכוז:
**פגישה מתחילה בקרוב** ו**PR פורסם**. התראת פגישה שרואים רק בדיעבד חסרת ערך,
וזו הסיבה.

## בחירת צליל

1. גללו אל **צליל התראה**
2. בחרו אחד מאחד עשר הצלילים המצורפים, או **ללא**
3. לחצו על כפתור הבדיקה כדי לשמוע אותו, וכוננו את עוצמת הקול עם המחוון

האפליקציה מנגנת את הצליל בעצמה; התראת מערכת ההפעלה נמסרת בשקט, כך שלעולם לא
תשמעו אותו פעמיים.

## הגדרת זמן ההתראה מראש של פגישות

1. גללו אל **זמן התראה מראש**
2. בחרו **5**, **10**, **15** או **30** דקות

זה פרק הזמן שלפני אירוע ביומן שבו נורית התראת **פגישה מתחילה בקרוב**. ברירת
המחדל היא 5 דקות.

## לדעת מתי התראה מושתקת

התראה מושלכת, בשקט, כאשר אחד מאלה מתקיים:

- ההתראות כבויות באופן גלובלי, או שהקטגוריה שלה כבויה
- אתם כבר נמצאים בנתיב שאליו היא הייתה מובילה אתכם — ולגבי הודעה, כבר נמצאים
  באותו מרחב
- מצב ריכוז פעיל והקטגוריה אינה דחופה
- Quiet hours פעילים והקטגוריה אינה דחופה

הבדיקות האלה חלות על התראות קופצות של מערכת ההפעלה. הפעמון המתמשך עדיין רושם את
האירוע.

שני מנגנוני השתקה נוספים פועלים מוקדם יותר במעלה הזרם, במה שהשרת בכלל שולח:

- הודעה של **אדם** אחר בלי אזכור שלכם לעולם אינה הופכת להתראה
- במרחב משותף, תשובה של סוכן מתריעה רק למי שהתחיל את אותה הרצה, לא לכל החברים
- מרחבים של סוכן לסוכן מושתקים בסרגל הצד, ולכן הם לעולם אינם מקפיצים את תג
  ההודעות שלא נקראו של האדם

בתוך מרחב אין פינה שקטה: כל שיחה מתריעה באותה מידה, כולל שרשורים. מצב הקריאה
מוגדר לפי מרחב, ולכן הלא־נקרא נצבר על פני השיחות של מרחב ולא נעקב בנפרד לכל
שיחה.

## קריאה וניקוי של מרכז ההתראות

1. לחצו על הפעמון שבשורת הכותרת

החלונית הקופצת מציגה פעילות אחרונה, כשכל רשומה מקושרת ישירות למה שהיא עוסקת בו.
פתיחתה **אינה** מסמנת הכול כנקרא — השתמשו ב**סימון הכול כנקרא** שבכותרת, או סמנו
שורה בודדת. מצב הקריאה עוקב אחרי המשתמש שלכם בין מכשירים.

:::note[ניקוי הכול הוא סימן מים, לא מחיקה]
**ניקוי הכול** מטביע סימן מים לפי משתמש שמסתיר כל מה ישן יותר; השורות נשארות.
בנפרד מכך, כל סביבת עבודה שומרת רק את **200** שורות הפיד האחרונות שלה, שנגזמות
עם הגעת חדשות, בעוד הפעמון נרשם ל-**50** החדשות ביותר והחלונית הקופצת מציגה עד
**15** מהן. היסטוריה מעבר לכך נעלמה, ללא קשר למצב הקריאה.
:::

## פתרון תקלות

### אין התראות מערכת הפעלה ב-macOS

ההרשאה מתבקשת בנייטיב עם הפעלת האפליקציה. אם דחיתם אותה, הפעילו את Control Center
מחדש תחת הגדרות מערכת → התראות; אין באפליקציה בקשה שיכולה לעורר אותה שוב.

### שום דבר לא מגיע בגרסת הווב

כצפוי — לגרסת הווב אין צינור התראות של מערכת ההפעלה. השתמשו בפעמון.

### תג הפעמון מציג אפס אבל יש בבירור פעילות חדשה

עד שזרם סימוני הקריאה נפתר לאחר ההתחברות, רשומות מוצגות כנקראו כדי למנוע תג
שמהבהב ואז מתרוקן. זה מתייצב ברגע שהסימון נטען.

### ההרצה של סוכן הסתיימה אבל שום דבר לא התריע לי

בדקו שלא הייתם כבר במרחב שבו זה קרה — נתיב פעיל משתיק את ההתראה הקופצת של עצמו.
במרחב משותף, הרצה שמישהו אחר התחיל מתריעה לו, לא לכם. תור שהסתיים בלי תשובה ובלי
שגיאה לא שולח דבר.
