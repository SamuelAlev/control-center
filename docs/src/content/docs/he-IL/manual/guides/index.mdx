כל מדריך פותר **בעיה אחת עבור מי שכבר מכיר את המערכת**. הוא מניח ש-Control Center
מותקן ושסביבת עבודה הוגדרה, הוא מצהיר על יעד בכותרת והוא נעצר כשהמטרה הושגה.

אם אתם עדיין לומדים את המוצר, התחילו עם [המדריכים](/he-IL/מדריך-למשתמש/מדריכים/).
אם אתם רוצים להבין _למה_ משהו מתנהג כפי שהוא מתנהג, קראו את
[המושגים](/he-IL/מדריך-למשתמש/מושגים/).
