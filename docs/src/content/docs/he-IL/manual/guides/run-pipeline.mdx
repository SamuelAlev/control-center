מדריך זה מכסה התחלה של הרצה ביד. כדי לעקוב אחרי הרצה, לקרוא את פלט
השלבים ולהתאושש מכשל, ראו
[מעקב אחר הרצות פייפליין](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/מעקב-פייפליינים/).

## התחלת הרצה

1. לחצו על **פייפליינים** בסרגל הצד של סביבת העבודה.
2. לחצו על **הרצת פייפליין** בכותרת. אתם נוחתים על בורר ההרצה
   (`/workspaces/<workspace-id>/pipelines/run`).
3. בחרו תבנית מהמסילה השמאלית. כל כרטיס מציג את שם התבנית, את התיאור שלה
   ואם היא מקבלת קלטים.
4. מלאו את טופס הקלט מימין. שדות חובה חוסמים את הכפתור עד שיש בהם ערך;
   תבנית בלי קלטים אומרת זאת במפורש.
5. לחצו על **הרצת פייפליין**.

אתם נוחתים בדף הפרטים של ההרצה, עם מפל הזמנים וקנבס הגרף פעילים.

## אם המסילה ריקה

בורר ההרצה מציג תבנית רק כאשר **שני** התנאים האלה מתקיימים:

- המתג של התבנית דלוק ב**הגדרות ← סביבת עבודה ← תבניות פייפליין**.
- **התרת הרצה ידנית** דלוק בתיבת הדו־שיח **הרצה ידנית** של עורך התבנית —
  המתג הזה הוא שיוצר את טריגר ה-`manual` שבורר ההרצה קורא.

שמונה מבין שלוש־עשרה התבניות המובנות מגיעות מושבתות: `external_pr_welcome`,
`cross_review`, `ticket_to_pr`, `pr_triage`, `pre_merge_gate`, `release_notes`,
`dep_audit` ו-`pr_digest`. המנוע מסרב להתחיל תבנית מושבתת, לכן הדליקו את
המתג שלה לפני שתחפשו אותה כאן.

אין פעולת **הרצה** לכל תבנית ברשימת התבניות ואין כפתור הרצה בתוך העורך —
בורר ההרצה הוא נקודת הכניסה הידנית היחידה.

## מילוי קלט של מאגר

קלט מסוג **מאגר** מציג בורר מעל המאגרים הרשומים בסביבת העבודה. בחירה של מאגר
מאכלסת את `repo_id`, `repo_local_path`, `repo_full_name` ואת — כשהמאגר מחזיק
remote של GitHub — `repo_owner` ו-`repo_name` במטען ההרצה, כך ששלבי ההמשך
יכולים לקרוא את אלה שהם זקוקים להם.

## צפייה בהרצה

לדף פרטי ההרצה יש שלושה חלקים: רצועת מטא (זמן התחלה, משך פעילות, התקדמות
השלבים, באנר כשל, **נסה שוב** ו**מחיקה**), מפל זמנים שאפשר לכווץ עם משך ועלות
לכל שלב, וקנבס הגרף. בחירת צומת פותחת את לוח הפרטים של אותו שלב.

[מעקב אחר הרצות פייפליין](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/מעקב-פייפליינים/) מכסה את כל זה,
כולל איך לקרוא שלב מושהה ומה לעשות כששלב נכשל.

כל הרצה שאתם מתחילים מהאפליקציה היא הרצה אמיתית.
