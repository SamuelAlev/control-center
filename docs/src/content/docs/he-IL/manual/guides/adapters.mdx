מדריך זה מראה כיצד לחבר ספקי מודלים ולבחור על מה סוכן רץ.

הכול נמצא בעמוד אחד: **הגדרות ← שרת ← ספקי מודלים**. הערך בסרגל הצד המשני
נקרא "ספקי מודלים"; כותרת העמוד נקראת "מתאמים".

## מהו מתאם

מתאם הוא ה_מריץ_ שמבצע תור של סוכן. יש שניים והרשימה קבועה — אי אפשר להוסיף
שלישי.

| מתאם                      | CLI      | תעבורה                                              |
| ------------------------- | -------- | --------------------------------------------------- |
| Control Center (מובנה)    | אין      | לולאת סוכן בתוך התהליך, שמדברת עם ספקים ב-HTTP        |
| Claude Code               | `claude` | `claude -p --output-format stream-json`             |

Cursor, Codex, Anthropic, OpenAI והשאר הם **ספקים** על המתאם המובנה, ולא CLI
נפרדים. מה שכן _אפשר_ להוסיף הוא ספק נוסף — כל נקודת קצה תואמת OpenAI או
Anthropic. על כך בקטע הבא.

:::note[הזיהוי בודק את השרת, לא את המכונה שלכם]
כרטיס **מריצים שזוהו** מפרט מה `cc_server` מצא ב-`PATH` של _מארח השרת_. בלקוח
רזה או בלקוח web מדובר במכונה שונה מזו שאתם מסתכלים עליה. התקינו את ה-CLI
במכונה שמריצה את `cc_server`.
:::

## חיבור ספק מודלים

המתאם המובנה זקוק לפחות לספק אחד מחובר לפני שהוא יכול לרוץ. בקטלוג יש ארבעה
עשר ספקים.

1. עברו אל **הגדרות ← שרת ← ספקי מודלים**
2. גללו אל **ספקים ומודלים**
3. אתרו את הספק שלכם וחברו אותו:

| ספק                                                                                                      | איך לחבר                                                                                                                      |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Anthropic                                                                                                | מפתח API. מינוי Claude Pro/Max אינו התחברות ל-API של Anthropic — השתמשו במתאם Claude Code בשביל התוכנית הזו                    |
| OpenAI, Codex, Cursor                                                                                    | התחברות OAuth בדפדפן, או מפתח API. Codex הוא ChatGPT Plus/Pro דרך ה-backend של Codex Responses, ולא הרצת CLI                  |
| Kimi Code                                                                                                | OAuth בדפדפן בלבד — זרימת קוד מכשיר. זו תוכנית בתעריף קבוע, ולכן אין לה מחיר לפי טוקן                                          |
| OpenRouter, Groq, Google Gemini, DeepSeek, Mistral, xAI, z.ai, z.ai GLM Coding Plan, Moonshot (Kimi API) | מפתח API                                                                                                                      |

נקודת בקרה: התג בשורה משתנה ל"מחובר", והרחבתה מפרטת את המודלים שאותו ספק מגיש,
כל אחד עם מחירו למיליון טוקנים וחלון ההקשר שלו.

טוקני OAuth נשמרים במאגר פרטי הגישה של השרת עצמו ומתחדשים לפני שפג תוקפם.
פרטי הגישה של הספקים הם **גלובליים למארח** — הם משותפים לכל סביבת עבודה
בהתקנה, ולא מוגבלים לאחת.

### הוספת ספק מותאם אישית

השתמשו בכך עבור Ollama, LM Studio, vLLM או פריסה פרטית.

1. ב**ספקים ומודלים**, תחת **ספקים מותאמים אישית**, לחצו על **הוספת ספק**
2. מלאו **שם**, בחרו את **סוג API** (תואם OpenAI או תואם Anthropic) ותנו
   **כתובת בסיס** (למשל `http://localhost:11434/v1`)
3. הוסיפו **מפתח API** אם נקודת הקצה זקוקה לאחד, ואז לחצו על **הוספת ספק**

ספק מותאם אישית מופיע באותה רשימה, עם כפתור מחיקה שלאחיו המובנים אין.

## בחירת מודל לסוכן

1. עברו אל **הגדרות ← סביבת עבודה ← סוכנים** ובחרו את הסוכן
2. בלשונית **הגדרות**, בחרו את ה**מתאם**
3. בחרו את ה**מודל** מהרשימה הנפתחת שלצדו

עבור המתאם המובנה הרשימה הנפתחת נבנית בזמן אמת מהקטלוג של כל ספק מחובר. ספק
בלי פרטי גישה שמורים אינו תורם אף מודל, ולכן רשימה נפתחת ריקה כמעט תמיד משמעה
"עדיין לא חובר דבר" ולא "אין דבר זמין".

:::note[models.dev הוא העשרה, ולעולם לא מקור למזהים]
הקטלוג המצורף [models.dev](https://models.dev) מספק מחיר וחלון הקשר עבור מודל
שכבר נמצא ברשימה החיה. הוא לעולם אינו מוסיף מזהה מודל. אם מודל שאתם מצפים לו
חסר, נקודת הקצה של הספק אינה מחזירה אותו.
:::

מזהי המודלים של המתאם המובנה הם בפורמט מוסמך `provider/model` ועשויים לשאת
שרשרת גיבוי מופרדת ב-`|`. בשרשרת גיבוי, העלות מחושבת לפי המודל ששירת את התור
בפועל, ולא לפי זה שביקשתם.

:::note[סוכן בלי מתאם רץ על הלולאה המובנית]
כל סביבת עבודה זורעת חמישה סוכנים — CEO ועוד `qa`, `architect`, `engineer`
ו-`librarian` — בלי מתאם ובלי מודל. השליחה נופלת חזרה אל **Control Center
(מובנה)**, ולא אל ההגדרה **מריצי ברירת מחדל** בעמוד הזה, שהיא העדפת לקוח
שמסלול השליחה אינו קורא לעולם. יומן ההרצות רושם `cc-harness` עבור ההרצות
האלה, כך שהתמלול מציין מה בעצם רץ.

כשאין גם מודל, הלולאה המובנית מבקשת מ-Anthropic את מודל ברירת המחדל שלה.
סוכן שנשאר בלי שום הגדרה לכן ירוץ אם חיברתם חשבון Anthropic, ואחרת ייכשל עם
`No credential for provider "anthropic"`.

סיום שלב המתאם בתהליך הכניסה הראשונית מחיל בדיעבד על **כל** סוכן שחסר לו
עדיין מתאם או מודל — CEO ומומחים, בכל סביבת עבודה שקיימת באותו רגע — את הזוג
שבחרתם. סביבות עבודה שנוצרות מאוחר יותר עדיין זורעות את כל החמישה בלי הגדרה.
הגדירו את המתאם והמודל במפורש בכל סוכן שבו אתם מתכוונים להשתמש.
:::

## התקנת CLI של מריץ

המתאם המובנה אינו זקוק להתקנה. עבור Claude Code, התקינו את ה-CLI שלו **במארח
השרת** עם מנהל החבילות של אותו כלי, למשל:

```bash
npm install -g @anthropic-ai/claude-code
```

לאחר מכן לחצו על **רענן** בראש העמוד. כל שורה שזוהתה מציגה את הגרסה והנתיב
שנפתרו, וכן תגים המציינים אם היא תומכת במצב JSON ובבחירת מודל.

CLI חיצוני שומר על פרטי הגישה שלו, בתצורה משלו, במארח השרת. Control Center
אינו מנהל אותם.

:::caution[ארגומנטים ומשתני סביבה של המתאם נשארים במכשיר הזה]
כל שורת מתאם מציעה שדה **ארגומנטים** ותיבת דו־שיח **משתני סביבה**. הערכים
האלה נשמרים במכשיר שלכם. השרת קורא את argv ההפעלה ואת משתני הסביבה ממאגר
ההגדרות שלו עצמו. שימו את מפתחות הספקים בשרת (OAuth או שדה המפתח בעמוד ספקי
מודלים), ולא בשני השדות האלה.
:::

## הגבלת הספקים שסביבת עבודה רשאית להשתמש בהם

השליטה בספקים היא לפי סביבת עבודה ונבחנת לפי העיקרון שההתאמה האחרונה מכריעה.

1. ב**ספקים ומודלים**, כבו את מתג ה**אפשר** בשורת ספק

פעולה זו כותבת הצהרת `deny` עבור אותו ספק בסביבת העבודה הפעילה, והמודלים שלו
יוצאים מהקטלוג של אותה סביבת עבודה. החזרת המתג למצב פועל מסירה את ההצהרה.

## פתרון בעיות

### מריץ מוצג כלא נמצא

- בדקו שה-CLI נמצא ב-`PATH` של **מארח השרת**, ולא רק בשלכם
- אפליקציית שולחן עבודה המופעלת מהממשק הגרפי מפעילה את השרת שלה עם `PATH`
  מינימלי; CLI שהותקן בנתיב הזמין למעטפת בלבד עלול להיות בלתי נראה עבורה
- לחצו על **רענן** לאחר ההתקנה

### הרשימה הנפתחת של המודלים ריקה

- המתאם הוא המובנה ואף ספק אינו מחובר — חברו אחד ב**ספקים ומודלים**
- או שהספק מחובר אך נדחה בידי מתג השליטה של סביבת העבודה הזו

### מודל רץ אך המחיר מוצג כלא ידוע

הרשימה החיה של המודלים נושאת את המזהה; המחיר וההקשר מגיעים מ-models.dev.
למודל חדש לגמרי, או כזה של ספק מותאם אישית, אין עדיין רשומה בקטלוג.
