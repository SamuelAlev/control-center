המדריך הזה מראה כיצד להוסיף סוכן לסביבת עבודה ולהגדיר אותו עד שהוא באמת רץ.

כל סביבת עבודה נזרעת עם חמישה סוכנים — CEO וארבעה מומחים `qa`, `architect`, `engineer` ו־`librarian` — כך שלרוב יש לכם סוכנים עוד לפני שהגדרתם ולו אחד מהם. השלבים שלהלן חלים באותה מידה על סוכן שנזרע ועל סוכן חדש.

## לפני שמתחילים

- אתם בתוך סביבת עבודה. כל המשטח נמצא ב**הגדרות ← סביבת עבודה ← סוכנים** (`/settings/workspace/agents`).
- הסוכן יזדקק לבקאנד. או חברו ספק עבור מנגנון ההרצה המובנה תחת **הגדרות ← שרת ← ספקי מודלים**, או התקינו את ה-CLI של Claude Code במכונה שמארחת את `cc_server`.
- אם אתם רוצים שהסוכן יישא מיומנויות, התקינו אותן קודם תחת **הגדרות ← סביבת עבודה ← מיומנויות**. טופס הסוכן מאפשר רק להדליק ולכבות מיומנויות שכבר קיימות בסביבת העבודה.

## הוספת הסוכן

1. פתחו את **הגדרות ← סביבת עבודה ← סוכנים**.
2. לחצו על **סוכן חדש**.

אין תיבת דו־שיח ואין בורר תפקידים. סוכן בשם "סוכן ללא שם" נוצר מיד ונבחר בחלונית הפרטים משמאל.

כעת אמורים לראות "סוכן ללא שם" בסגל מימין, כשהלשונית **הגדרות** של חלונית הפרטים שלו פתוחה ושדה **שם** מכיל "סוכן ללא שם".

## מתן שם

- **שם** — המזהה הקצר שמשמש באזכורים ב־@, למשל `alice`. ניתוח האזכור מתאים `@` ואחריו תווי מילה, ולכן שם שמכיל מקף, נקודה או רווח לא ניתן לאזכר לעולם.
- **כותרת** — התווית בשפה אנושית, למשל "מפתחת בכירה".
- **הנחיית מערכת** — הוראות נוספות אופציונליות, המוזרקות כקטע "הוראות הסוכן"; הן אינן מחליפות את שאר ההנחיה המורכבת.

לחצו על **שמור שינויים** בתחתית הטופס. כל השדות בעמוד הזה נשמרים בכפתור האחד הזה.

## מתאם ומודל

התפריט הנפתח **מתאם** מפרט את המריצים שקיימים בפועל במארח השרת. המתאם המובנה תמיד נמצא (הוא השרת). Claude Code מופיע רק כשזוהה ה-CLI שלו במארח הזה:

| מתאם                   | בקאנד                                     |
| ------------------------- | ------------------------------------------- |
| Control Center (מובנה) | לולאת הסוכן בתוך התהליך — ללא CLI חיצוני |
| Claude Code               | `claude -p --output-format stream-json`     |

רק המתאם המובנה אוכף מצבים, היגוי, השהיה והמשך, חוזי השלמה וסוכני משנה. Claude Code לא נותן אף אחד מאלה. Cursor, Codex ושאר ספקי המודלים מצטרפים למתאם המובנה, ולא כמה מריצים נפרדים.

:::note[מתאם ריק פירושו הלולאה המובנית]
סוכן שהמתאם שלו לא הוגדר נשלח אל **Control Center (מובנה)**, הלולאה שבתוך השרת, כך שאין צורך להתקין דבר במארח. אם גם מודל לא הוגדר, הוא מבקש מ-Anthropic את ברירת המחדל שלה, ולכן סוכן שלא הוגדר בו דבר רץ רק אם חיברתם חשבון Anthropic. המומחים שנזרעו מגיעים בלי זה ובלי זה; הגדירו את שניהם בכל סוכן שבכוונתכם להשתמש בו.
:::

התפריט הנפתח **מודל** נגזר מהמתאם שבחרתם. עבור המתאם המובנה הרשימה מגיעה חיה מהספקים שחיברתם תחת **הגדרות ← שרת ← ספקי מודלים**, כך שספק בלי פרטי גישה שמורים תורם אפס מודלים.

## הוספת מיומנויות

**מיומנויות** הוא בורר צ'יפים מעל חבילות המיומנויות המותקנות בסביבת העבודה הזו. הקישו על צ'יפ כדי להדליק או לכבות אותו; סימן הסימון מסמן את הנבחרים. אם אין מיומנויות בסביבת העבודה, השדה מציג "No skills available. Create skills in Settings → Skills first."

כאן אתם לא בוחרים את המיומנויות של מאגר מסוים. מאגר שמוסר אותן (ב־`.agents/skills/`, `.claude/skills/` או `.opencode/skills/`) תורם אותן אוטומטית לכל סוכן שעובד באותו מאגר, והן מתחלפות כשהוא עובר לאחר — ראו [מיומנויות בהיקף מאגר](/he-IL/מדריך-למשתמש/מושגים/מודל-הסוכן/#repo-scoped-skills).

## הגדרת שרשרת הדיווח והפרסונה

- **מדווח אל** — בחרו סוכן אחר לפי שם. זה בונה את עץ הדיווח שמוצג בכפתור **תרשים ארגוני** בכותרת העמוד. זה אינו הסגל שראש צוות משתמש בו כשהוא מאציל — הוא נגזר מחברי הצוות ומהמיומנויות שלהם.
- **פרסונה** — טקסט חופשי שמעצב טון והתנהגות, למשל: "מעדיפה פתרונות פשוטים וקריאים. כותבת בדיקות לכל קוד חדש."

## כוונון ההרצה

- **מאמץ חשיבה** — האפשרויות מגיעות מהרמות המפורסמות של המודל הנבחר עצמו: Low / Medium / High, ובנוסף Extra High במודלים בסגנון OpenAI ו-Extra High + Max במודלים בסגנון Claude. השדה מוסתר לחלוטין כשהמודל הנבחר אינו מצהיר על רמות חשיבה, והוא נופל לברירת המחדל של המודל עצמו.
- **גודל חלון ההקשר** — ממולא מראש מחלון ההקשר של המודל בכל פעם שאתם מחליפים מודל, עם צ'יפים בלחיצה אחת עבור ברירת המחדל של המודל, 200k, 500k ו-1M. ערך שהקלדתם אחרי בחירת המודל גובר עד להחלפת המודל הבאה.
- **זמן קצוב לשקט (דקות)** — לסיים הרצה לאחר פרק זמן זה בלי פלט. השאירו ריק כדי להשתמש בברירת המחדל לפי מצב.

## הענקת הרשאות

**הרשאות ארגז חול** מתחיל על "שימוש בברירת המחדל של סביבת העבודה". הדליקו את המתג כדי להגדיר אותן לסוכן הזה, ואז הפעילו או כבו:

- **אפשר git push** — מזריק את טוקן ה-GitHub שהסוכן צריך כדי לדחוף
- **אפשר קריאות ל־API של GitHub** — מאפשר לסוכן לקרוא בקשות משיכה, נושאים ומטא־נתוני מאגרים
- **התרת קריאות API של ניהול כרטיסים** — מזריק את המפתח של ספק הכרטוס
- **אפשר גישה כללית לרשת** — מפעיל גם את הכלים `web_fetch` ו-`web_search` של מנגנון ההרצה המובנה

כל מתג נבדק בידי מתווך פרטי הגישה כשההרצה יוצאת לדרך: יכולת שכבויה פשוט אומרת שהטוקן המתאים לעולם אינו מונפק לסביבת ההרצה.

:::caution[ברירת המחדל של סביבת העבודה היא הסט השמרני של השרת]
סוכן שנשאר על "שימוש בברירת המחדל של סביבת העבודה" רץ כשדחיפה ל-GitHub, API של GitHub וכרטוס **כבויים** ורשת **דלוקה**. ברירות המחדל של היכולות שמוצגות תחת הגדרות ← שרת ← אבחון ופרטיות הן העדפה בצד הלקוח. אם אתם רוצים שסוכן ידחוף או יפתח בקשות משיכה, הדליקו את המתג והעניקו את היכולות במפורש.

היכולות האלה שולטות בפרטי גישה ובכלי מנגנון ההרצה, וזו שכבה נפרדת מארגז החול של מערכת ההפעלה. `cc_server` עוטף הרצות סוכן בארגז החול של המארח היכן שקיים כזה — ב-Windows אין בקאנד מקורי, וב-Linux וב-WSL2 נדרשים `bwrap` ו-`socat`. ראו [ארגז חול ואבטחה](/he-IL/מדריך-למשתמש/מושגים/ארגז-חול-ואבטחה/) לכלל הגבולות.
:::

## אימות שהסוכן רץ

1. פתחו את **הגדרות ← שרת ← ספקי מודלים** וודאו שהמתאם שבחרתם מדווח על גרסה מותקנת ולא "לא נמצא". לחצו על **רענן** כדי לבדוק מחדש — הבדיקה רצה במכונה שמארחת את `cc_server`, לא במכונה שאתם מסתכלים עליה.
2. פתחו מרחב עם הסוכן ושלחו לו הודעה, או אזכרו אותו ב־@ במרחב קיים.
3. חזרו אל **הגדרות ← סביבת עבודה ← סוכנים**, בחרו את הסוכן ופתחו את הלשונית **יומנים**. אמורה להופיע הרצה עם תג סטטוס, משך, זמן התחלה והמתאם שבו השתמשה. **הצגה** פותחת את זרם האירועים של אותה הרצה.

אם לא מופיעה שום הרצה, עברו על [אבחון סוכן](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/אבחון-סוכן/).

## מחיקת סוכן

בחרו אותו בסגל. בלשונית **הגדרות**, גללו אל **אזור מסוכן** בתחתית הטופס ולחצו על **מחיקה**.
