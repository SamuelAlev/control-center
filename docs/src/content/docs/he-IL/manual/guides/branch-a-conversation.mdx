המדריך הזה מראה איך לחזור לנקודה מוקדמת יותר בשיחה ולקחת אותה למקום אחר — תוך שמירה על המסלול שעזבתם.

## הדבר האחד שכדאי לדעת

**הסתעפות לא כותבת דבר.** שיחה היא עץ של הודעות עם מצביע בקצה, וחזרה אחורה מזיזה את המצביע. דבר לא נמחק, דבר לא מוסתר, ומעבר חזרה הוא עוד הזזת מצביע.

זו הסיבה שעריכת הנחיה והרצה מחדש בטוחות כאן: התשובה שהשוויתם מולה עדיין שם.

## ראו את הענפים

```
/tree
```

המנווט מפרט כל הודעה, עם הזחה בכל פיצול, כשהמסלול הנוכחי מסומן **בענף הזה**. שיחה שמעולם לא התפצלה מוצגת כרשימה השטוחה שהייתה תמיד — להסתכל במנווט לא עולה דבר כל עוד אין במה לנווט.

כל שורה מציעה שתי פעולות.

| פעולה                          | השפעה                                                    |
| ------------------------------- | --------------------------------------------------------- |
| **המשך מכאן**          | מזיז את המצביע. ההודעה הבאה שלכם ממשיכה מאותה הודעה. |
| **פיצול לשיחה חדשה** | מעתיק את המסלול עד אותה הודעה אל שיחה חדשה. |

## ענף: נסו גישה אחרת

1. `/tree`
2. מצאו את ההודעה שממנה תרצו להתחיל מחדש — בדרך כלל האחרונה שהייתם מרוצים ממנה.
3. **המשך מכאן.**
4. הקלידו את ההנחיה החדשה.

ההמשך הישן עדיין נמצא בעץ; `/tree` יציג כעת שני מסלולים מאותה נקודה, ותוכלו לעבור ביניהם בחופשיות.

:::note[המסלול שעזבתם עדיין שם]
הסתעפות לא מסתירה ולא מוחקת דבר. `/tree` מפרט כל מסלול, מסמן את הנוכחי **בענף הזה**, והוא הדרך לעבור בין המסלולים.
:::

## פיצול: קחו את זה למקום אחר

פיצול מעתיק את המסלול אל **שיחה חדשה** באותו מרחב. השתמשו בו כששני הכיוונים עתידים להמשיך ולהתפצל, ואתם רוצים אותם זה לצד זה במקום לעבור ביניהם.

לעותק יש מזהי הודעות חדשים. שתי שיחות שחולקות שורות היו מציגות זו לזו הודעות מאוחרות יותר, וזה בדיוק מה שפיצול אמור למנוע.

## שחזור מול ענף

אלה כלים שונים, וההבדל ביניהם חשוב.

|                     | שחזור                                             | ענף                          |
| ------------------- | -------------------------------------------------- | ------------------------------- |
| ההודעות המאוחרות  | מוסתרות מהתמליל                          | עדיין גלויות ב־`/tree`         |
| **עץ העבודה**    | מוחזר לתמונת המצב של אותו תור                 | ללא שינוי                        |
| ביטול                | **ביטול השחזור** מחזיר את האצווה                  | הזזת המצביע בחזרה            |

שחזור הוא מה שתרצו כשהסוכן שינה *קבצים* שתרצו להחזיר. ענף הוא מה שתרצו כשהשיחה פנתה לדרך הלא נכונה אבל הקבצים בסדר.

שחזור מזיז גם את קצה הענף, כך שההודעה הבאה שלכם ממשיכה מהמקום הנכון ולא מזנב שאיש כבר לא רואה.

## הוציאו את זה מהאפליקציה

### `/export`

כותב **קובץ HTML עצמאי לחלוטין**: את כל השיחה עם כרטיסי כלים מתקפלים שמציגים מה הוזן לכל קריאה ומה היא החזירה. בלי גיליון סגנונות, בלי סקריפט ובלי שרת תמונות — זה עובד מדיסק און-קי וזה יעבוד גם בעוד חמש שנים.

- **שולחן העבודה:** `Documents/ControlCenter/exports/`, עם חתימת זמן כך שייצוא שני לא ידרוס את הראשון.
- **ווב:** הורדה בדפדפן.

### `/dump`

מעתיק את התמליל ללוח כ־markdown, עם קריאות כלים בבלוקים מתקפלים. זה הפריט שמדביקים ל־issue.

החשיבה מושמטת בכוונה: זה מרחב הטיוטה של המודל, ודוח באגים נקרא בידי אדם.
