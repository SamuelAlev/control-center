מדריכים הם **שיעורים**. כל אחד מהם מעביר אתכם מההתחלה ועד הסוף דרך משהו אמיתי, במסלול
אחד, בלי שום החלטה בדרך. פעלו לפי השלבים בדיוק — והם עובדים.

הם נועדו לעזור לכם ללמוד את המערכת. ברגע שאתם מכירים את צורת המוצר,
[מדריכי How-to](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/) הם הדרך המהירה יותר אל משימה מסוימת.

עשו אותם לפי הסדר הזה — כל אחד מניח שהקודם לו הושלם.

1. [סביבת העבודה הראשונה שלכם](/he-IL/מדריך-למשתמש/מדריכים/סביבת-העבודה-הראשונה/) — צרו סביבת עבודה, הוסיפו מאגר וראו את מודל הבידוד
2. [שילחו את הסוכן הראשון](/he-IL/מדריך-למשתמש/מדריכים/הסוכן-הראשון/) — תנו לסוכן מתאם ומודל, ואז העמידו אותו לעבודה
3. [סקרו את בקשת המשיכה הראשונה](/he-IL/מדריך-למשתמש/מדריכים/בקשת-המשיכה-הראשונה/) — קראו את ה-diff, הגיבו ומזגו
4. [בנו את הפייפליין הראשון](/he-IL/מדריך-למשתמש/מדריכים/הפייפליין-הראשון/) — שרשרו שלבים ל-DAG והריצו אותו

שניים נוספים עומדים בפני עצמם; עשו כל אחד מהם אחרי שיש לכם סביבת עבודה עובדת.

- [חברו את Slack לסביבת העבודה](/he-IL/מדריך-למשתמש/מדריכים/גשר-הצאט-הראשון/) — הניעו סוכנים מתוך שרשור ב-Slack
- [התחברו עם הצוות באמצעות SSO](/he-IL/מדריך-למשתמש/מדריכים/sso/) — חברו ספק זהויות והעבירו תהליך כניסה אחד מההתחלה ועד הסוף
