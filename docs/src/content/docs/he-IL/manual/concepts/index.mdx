These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/he-IL/מדריך-למשתמש/מדריכים-מעשיים/); when you want to look
something up, go to the [reference](/he-IL/מדריך-למשתמש/עזר/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/he-IL/מדריך-למשתמש/מושגים/סביבות-עבודה/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/he-IL/מדריך-למשתמש/מושגים/מודל-הסוכן/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/he-IL/מדריך-למשתמש/מושגים/מחזור-חיי-שליחה/) — what happens between your message and the agent's first token
- [Modes](/he-IL/מדריך-למשתמש/מושגים/מצבים/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/he-IL/מדריך-למשתמש/מושגים/הקשר-כלים/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/he-IL/מדריך-למשתמש/מושגים/אינטליגנציית-קוד/) — the code graph, language server, structural search and debugger
- [Conversation history](/he-IL/מדריך-למשתמש/מושגים/היסטוריית-שיחה/) — persistence, compaction and forking a transcript
