These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/zh-CN/手册/操作指南/); when you want to look
something up, go to the [reference](/zh-CN/手册/参考/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/zh-CN/手册/概念/工作区/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/zh-CN/手册/概念/智能体模型/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/zh-CN/手册/概念/派发生命周期/) — what happens between your message and the agent's first token
- [Modes](/zh-CN/手册/概念/模式/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/zh-CN/手册/概念/工具上下文/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/zh-CN/手册/概念/代码智能/) — the code graph, language server, structural search and debugger
- [Conversation history](/zh-CN/手册/概念/对话历史/) — persistence, compaction and forking a transcript

## Safety and control

What an agent is allowed to touch and who decides.

- [Sandbox and security](/zh-CN/手册/概念/沙盒与安全/) — what actually constrains an agent run today
- [Guardrails](/zh-CN/手册/概念/护栏/) — one policy engine for every mutating action and how a rule is resolved
- [Authorization](/zh-CN/手册/概念/授权/) — roles, the permission catalog and the audit trail
- [Rigs and enclosures](/zh-CN/手册/概念/机台/) — why agents get disposable VMs instead of your machine, and what the boundary actually is
