教程是**课程**。每一篇都带你从头到尾完整走一遍真实的事情，只有一条路径，沿途无需做任何
决定。严格照着步骤做，就能成功。

它们的作用是让你熟悉产品。等你摸清了产品的轮廓，要完成某个具体任务时，
[操作指南](/zh-CN/手册/操作指南/)是更快的路径。

请按这个顺序来做 —— 每一篇都以前一篇为前提。

1. [你的第一个工作区](/zh-CN/手册/教程/第一个工作区/) —— 创建工作区、添加仓库，并了解隔离模型
2. [派发你的第一个智能体](/zh-CN/手册/教程/第一个智能体/) —— 为智能体配置适配器和模型，然后让它开始工作
3. [审查你的第一个 Pull request](/zh-CN/手册/教程/第一个-pr/) —— 阅读 diff、评论并合并
4. [构建你的第一条流水线](/zh-CN/手册/教程/第一条流水线/) —— 把步骤串成 DAG 并运行

另外两篇彼此独立；等你有了可用的工作区，任选一篇来做。

- [将 Slack 桥接到你的工作区](/zh-CN/手册/教程/第一个聊天桥接/) —— 从 Slack 线程中驱动智能体
- [用 SSO 让团队登录](/zh-CN/手册/教程/sso/) —— 连接身份提供方，并完整走一遍登录流程

:::note[开始之前]
先安装 Control Center —— 参见[安装](/zh-CN/手册/安装/)。如果你只想用最短的路径让智能体
跑起来，那就改用[快速开始](/zh-CN/手册/快速开始/)，之后再回到这里。
:::
