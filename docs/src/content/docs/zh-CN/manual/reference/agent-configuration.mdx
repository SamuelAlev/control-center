本参考列出智能体实体上的每个字段，以及它使用的枚举和标志。关于在应用中创建或编辑智能体的分步讲解，见[创建并配置智能体](/zh-CN/手册/操作指南/创建智能体/)。

## 智能体实体字段

| 字段                    | 类型                   | 必填 | 说明                                                                                                                                                                                                |
| ----------------------- | ---------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | 是   | 唯一的智能体标识符                                                                                                                                                                                  |
| `name`                  | `String`               | 是   | 用于 @ 提及的简短标识符                                                                                                                                                                             |
| `title`                 | `String`               | 是   | 人类可读的职位名称                                                                                                                                                                                  |
| `agentMdPath`           | `String`               | 是   | 智能体 `.md` 定义文件的绝对路径                                                                                                                                                                     |
| `workspaceId`           | `String`               | 是   | 所属工作区（不可为 null）                                                                                                                                                                           |
| `reportsTo`             | `String?`              | 否   | 上级智能体 id                                                                                                                                                                                       |
| `skills`                | `AgentSkills`          | 是   | 技能标识符的集合                                                                                                                                                                                    |
| `persona`               | `String?`              | 否   | 自由文本的行为指令                                                                                                                                                                                  |
| `systemPrompt`          | `String?`              | 否   | 覆盖默认的系统提示词                                                                                                                                                                                |
| `adapterId`             | `String?`              | 否   | 推理适配器 id                                                                                                                                                                                       |
| `modelId`               | `String?`              | 否   | 该适配器内的模型 id                                                                                                                                                                                 |
| `strictMode`            | `bool`                 | 否   | 默认 `false`。会写入该行以及智能体的 `AGENTS.md`                                                                                                                                                    |
| `effort`                | `String?`              | 否   | 推理档位 id（例如 `'low'`、`'xhigh'`），取自所选模型的 `thinkingLevels`                                                                                                                             |
| `contextSize`           | `int?`                 | 否   | 上下文窗口的最大大小                                                                                                                                                                                |
| `role`                  | `AgentRole?`           | 否   | 智能体的角色                                                                                                                                                                                        |
| `monthlyBudgetMicros`    | `int`                  | 否   | 以微美元计的月度支出上限（默认 `0`，即不限）                                                                                                                                                          |
| `silenceTimeoutMinutes` | `int?`                 | 否   | 静默超时的覆盖值，以分钟计；必须为 null 或落在 1–240 之间（由构造函数断言）                                                                                                                         |
| `maxConcurrentTasks`    | `int`                  | 否   | 默认 `1`。在线状态模型报告的容量数值（运行中和队列中的计数都会与它比较）                                                                                                                            |
| `visibility`            | `AgentVisibility`      | 否   | 默认 `workspace`                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | 否   | 治理状态（默认 `active`）。由预算硬性停止写入，并渲染在组织架构图和在线状态名册上。派发仍然会接受来自 `paused` 智能体的工作                                                                        |
| `budgetPolicyId`        | `String?`              | 否   | 共享预算策略 id；为 null 时直接应用 `monthlyBudgetMicros`                                                                                                                                            |
| `runtimeProfileId`      | `String?`              | 否   | 自定义运行时配置 id                                                                                                                                                                                 |
| `createdAt`             | `DateTime`             | 是   | 创建时间戳                                                                                                                                                                                          |

`name` 和 `title` 都必须非空（由构造函数断言）。`monthlyBudgetMicros` 的默认值
`0` 表示不限。要写入一条上限，请使用 `agents.upsert`。

## AgentLifecycleStatus 枚举

| 取值       | 说明                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| `active`   | 默认值。`isDispatchable` 只有在该取值下才为 true                            |

## 权限

智能体不带任何权限标志。推送、打开和发布 pull request、写入跟踪器以及网络出站都是操作类别（`gitPush`、`prCreate`、`prPublish`、`vendorSyncWrite`、`networkEgress`），由[护栏](/zh-CN/手册/概念/护栏/)在工作区、智能体或空间范围内解析。运行的 GitHub 令牌始终是只读范围；推送经过智能体运行网关，网关在转发前询问 `gitPush` 规则。

## AgentSkills

一个不可变、不区分大小写的技能标识符集合。派发时，这些 slug 会作为技能链接同步到智能体的覆盖层中；随后运行器会把被链接技能的前置元数据自动加载到提示词中。

```
{'flutter', 'dart', 'rest-api'}
```

## Shell 钩子

Shell 钩子允许服务器所有者在智能体运行前后运行他们自己的脚本：会话开始时一次、每次工具调用之前、每次工具调用之后、智能体即将结束其轮次时，以及压缩之前。钩子就是任意代码，因此钩子属于主机配置。只有服务器所有者才能手动在服务器所在机器上设置它们。应用中没有相应的设置，也没有任何操作会写入它们。

对于智能体，钩子位于服务器数据目录下它自己的文件夹中：

```text
<data dir>/_agent_hooks/<workspace id>/<agent slug>/hooks.json
```

`<agent slug>` 是工作区中该智能体的文件夹名称（`agents/<slug>/`）。该文件夹位于每个工作区存储之外，并且每个沙箱都会隐藏数据目录，因此没有任何成员、运行或终端能够写入它。

`hooks.json` 把以下五个键中的任意一个映射到一个脚本，路径相对于钩子文件夹：

| 键             | 运行时机                  | 退出码的含义                                                   |
| -------------- | ------------------------- | -------------------------------------------------------------- |
| `sessionStart` | 运行一次，在运行开始时    | 无；钩子只做观察                                               |
| `preTool`      | 每次工具调用之前          | `0` 允许该调用；其他任何值都会拒绝它                           |
| `postTool`     | 每次工具调用之后          | 无；钩子只做观察                                               |
| `stop` | 智能体即将结束其轮次时 | `2` 且标准输出有文本时，以该文本使运行继续；其他任何情况都让轮次结束 |
| `preCompact` | 压缩之前 | `0`：其标准输出会被加入摘要应保留的内容中 |

- 每个脚本都作为独立的可执行程序启动，不经过 shell，也不带任何参数，因此它必须具有可执行权限并以 shebang 行开头。它通过标准输入接收 JSON 格式的事件：事件名称，并且对于工具钩子，还包括工具的名称及其参数（`preTool`）或其结果（`postTool`）。
- 钩子作为该次运行的工具进程之一运行，位于该次运行中智能体的目录下。当服务器对智能体启用沙箱时，它在该次运行的沙箱内运行。它获得的是一个最小化的环境，并且没有该次运行的任何凭据：没有代码托管平台或提供方令牌，也没有网关访问权限。
- 每个钩子有 30 秒时间。`sessionStart`、`preTool` 和 `postTool` 的输出会被读取并丢弃。
- `preTool` 失败即关闭。非零退出、超时或脚本无法启动，都会拒绝该工具调用。
- 绝对路径、不存在的路径，或离开钩子文件夹的路径（解析链接之后判断）都会被拒绝，运行日志会说明哪个钩子被拒绝以及原因。被拒绝或无法读取的 `preTool` 钩子会拒绝每一次工具调用，直到它被修复为止。
- `.agents/harness.json` 中的 `hooks` 块，无论位于仓库中还是智能体自己的文件夹中，都会被忽略。仓库通常是他人的代码，而智能体的文件夹可以被成员和运行写入。运行日志会说明该块已被忽略，以及钩子实际从何处读取。

### stop 与 preCompact 钩子

- `stop` 会接收 `event: "stop"`、智能体的最后一条消息（`last_message`）、`stop_hook_active`（当本次 stop 紧随钩子引起的续行时为 true），以及 `block_count`（至今它已让运行继续了多少次，从 0 起算）。要让运行继续，它需以 `2` 退出，并打印智能体下一步应做什么。该文本被截断为 2,000 个字符后，会以系统消息的形式传给智能体。
- `stop` 钩子在一次运行中最多使运行继续 3 次。此后它不再运行，轮次结束。
- `stop` 采用失败放行策略。超时、脚本无法启动、退出码不是 `2`，或退出码为 `2` 但标准输出为空，都会让轮次结束，因此出错的钩子无法使运行一直保持开启。
- `preCompact` 会接收 `event: "pre_compact"`。其标准输出被截断为 1,000 个字符后，会被加入压缩的重点内容中。脚本失败则不添加任何内容。

Shell 钩子适用于内置 harness。在 Claude Code 上，`stop` 和 `preCompact` 钩子也会运行：Claude Code 自身的 `Stop` 和 `PreCompact` 钩子会请求服务器，服务器以同样的方式运行所有者的脚本。其他三个键仅适用于内置 harness。配置了 `preTool` 或 `postTool` 钩子后，运行会逐个调用其工具。

## AgentLiveState（派生）

不存储。共七个值。声明顺序就是优先级顺序（`sortPriority`，由测试固定），也正是名册排序所依据的顺序：

| 状态        | `sortPriority` | 条件                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | 任何运行日志的状态为 `running`                                                                                       |
| `blocked`   | 1              | 最近一次运行的存活状态为 `blocked`、`stalled` 或 `looping`                                                           |
| `failed`    | 2              | 最近一次运行的状态为 `error`，或它的存活状态为 `failed` 或 `dead`                                                    |
| `queued`    | 3              | 一次运行已被派发但尚未执行——停在同一智能体的另一次运行之后，或已写入但尚未开始                                       |
| `succeeded` | 4              | 该运行成功结束                                                                                                       |
| `idle`      | 5              | 该智能体以前运行过，且当前没有任何进行中的任务                                                                       |
| `neverRun`  | 6              | 不存在任何运行日志                                                                                                   |

`queued` 和 `succeeded` **仅存在于单次运行上**。为智能体计算名册状态的 `deriveAgentLiveState` 永远不会产生这两个值——它返回的是 `neverRun`、`running`、`failed`、`blocked` 或 `idle`。
