Control Center 中的 Linear 有两种身份，两者都是浏览器登录：你自己的身份，用于你所做的操作；以及工作区的 Control Center 应用，用于智能体和流水线所做的操作。工单、项目、链接、协作者、委派和分配都基于 Control Center 自己的数据库运行，无需任何外部服务——参见[创建和管理工单](/zh-CN/手册/操作指南/管理工单/)。

## 前提条件

- 服务器可以让人们登录 Linear：通过 Control Center Connect，或使用服务器自己的 Linear 应用（[注册你自己的 Linear 应用](#注册你自己的-linear-应用)）。由服务器所有者在 **设置 → 服务器 → 单点登录** 中选择
- 工作区管理员，用于选择 Linear 作为工单服务商，以及连接 Linear 自动化

## 为工作区选择 Linear

1. 前往 **设置 → 工作区 → 通用**，找到**工单系统**卡片
2. 将**工单服务商**设为 **Linear**

此后你创建的工单都会被标记上 `provider: linear`。**本地**会把工单保存在该服务器自己的数据库中，并隐藏 Linear 相关的行：没有任何需要认证的对象。

## 登录 Linear

在同一张卡片上，**Linear** 这一行属于你个人：

1. 点击**登录 Linear**
2. 在浏览器中批准
3. 使用服务器自己的应用时，对话框会自行察觉登录完成。通过 Connect 时，输入浏览器显示的 8 位代码，或让它通过 `control-center://` 链接打开 Control Center

你在 Control Center 中对 Linear 做的任何操作，都只使用这次登录，别无其他。如果你尚未登录，应用会要求你登录，而不会冒充别人行事。

## 连接 Linear 自动化

**Linear 自动化**这一行代表工作区的 Control Center 应用在 Linear 中的身份。工单同步、流水线和智能体都用它写入，因此自动化创建的议题和评论会显示为 Control Center，而不是某个人。

1. 工作区管理员点击**连接 Linear 用于自动化**
2. 他们在浏览器中，按上述方式为 Linear 工作区批准该应用

之后这一行会显示“已连接到 _你的 Linear 工作区_”。只有工作区管理员可以连接或断开它。

任何 Linear 凭据都不会放入智能体的沙盒：智能体通过 Control Center 自己的工具写工单，这些工具会先询问**写入外部跟踪器**规则。

## 注册你自己的 Linear 应用

当你选择了**使用我自己的应用**时，就使用你自己的应用。服务器自己的应用只在那种情况下适用：使用 Control Center Connect 或自定义 Connect 时，Connect 会运行每个通道（包括 Linear），服务器的应用和服务 API 密钥会保留但不使用。工作区自己的应用（[见下文](#为一个工作区提供自己的-linear-应用)）在任何模式下都适用。

1. 在 [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new) 创建一个 OAuth 应用
2. 把 **设置 → 服务器 → 单点登录 → 提供商应用 → Linear** 在**回调 URL**下显示的两个回调 URL 原样添加进去：`<server origin>/oauth/linear/callback` 与 `<server origin>/oauth/linear_app/callback`
3. 把**客户端 ID**粘贴到 Linear 区块中

没有客户端密钥：服务器使用 PKCE 登录。Linear 的刷新令牌在 30 天未使用后会过期，因此服务器每天会为所有超过 20 天的 Linear 登录续期一次。

同一区块还可以填写一个可选的**服务 API 密钥**。它是服务器自己的 Linear 凭据，供尚未连接 Linear 自动化的工作区用于自动化。请把它保存在**设置**中，或服务器的 `.env` 文件里的 `LINEAR_API_KEY` 中：当 `LINEAR_API_KEY` 被导出到服务器的进程环境中时，服务器会拒绝启动。

## 为一个工作区提供自己的 Linear 应用

工作区可以改用自己的应用登录 Linear，而不使用服务器的。只有工作区管理员或所有者可以设置。

1. 按上文步骤创建一个 Linear OAuth 应用
2. 前往 **设置 → 工作区 → 通用 → 提供商应用**，打开 **Linear**
3. 选择**使用此工作区自己的应用**
4. 将该行在**回调 URL**下显示的两个回调 URL 原样添加到 Linear 应用中
5. 粘贴它的**客户端 ID**，并可选择为此工作区的自动化填入**服务 API 密钥**

此工作区的应用会响应此工作区中所有 Linear 登录与自动化请求，无论服务器以何种方式让人登录。它绝不会回退到服务器的应用或 Connect：在设置客户端 ID 之前，此工作区的 Linear 处于关闭状态，该行会说明缺少什么。其服务 API 密钥只在这里使用；没有它，同步就需要**连接 Linear 用于自动化**。

在服务器的应用与工作区的应用之间切换，或更改工作区的客户端 ID，会让此工作区中的所有人从 Linear 退出登录，并断开其自动化连接。他们需通过新应用重新登录。**使用本服务器的应用**会删除工作区已保存的字段。密钥仅可写入：该行只显示是否已保存密钥。服务器上的其他工作区不受影响。

## 故障排查

### Linear 这一行提示登录未设置

服务器既没有自己的 Linear 应用，也没有 Connect。服务器所有者可以在 **设置 → 服务器 → 单点登录** 中选择其一。当工作区使用自己的应用时，该行会改为显示设置尚未完成：工作区管理员需在 **设置 → 工作区 → 通用 → 提供商应用** 中添加客户端 ID。

### 工单同步因认证错误而失败

该工作区没有连接 Linear 自动化，而服务器也没有服务 API 密钥，因此同步没有可用的凭据。工作区管理员点击**连接 Linear 用于自动化**即可解决。

### 连接自动化时提示该 Linear 工作区已在别处连接

该 Linear 工作区的 Control Center 应用已经连接到了另一台 Control Center 服务器。
