把你的 Linear API 密钥粘贴到服务器上，并关联到你的用户，就像连接代码托管平台
一样。工单、项目、链接、协作者、委派和分配都基于 Control Center 自己的数据库
运行，无需任何外部服务——参见[创建和管理工单](/zh-CN/手册/操作指南/管理工单/)。

## 存储你的 Linear 密钥

**工单 API 密钥**位于 **设置 → 工作区 → 通用** 的**工单系统**卡片上。它把密钥按
你的用户 id 存储在服务器上。服务器用于无人值守工作的密钥来自 `LINEAR_API_KEY`
或**提供商应用**卡片，并且只有当该智能体具备**允许工单 API 调用**能力时，才会
作为 `TICKETING_API_KEY` 注入。

## 将新工单标记为 Linear

**工单服务商**（入门流程的第一步，以及
`/workspaces/<workspaceId>/api-keys`）提供 `local` 和 `linear` 两个选项。选择
`linear` 后，你此后创建的工单都会被标记上 `provider: linear`。
