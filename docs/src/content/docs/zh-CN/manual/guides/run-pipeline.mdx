本指南介绍如何手动启动一次运行。要观察运行的执行、读取步骤输出以及从失败中恢复，请参阅[监控流水线运行](/zh-CN/手册/操作指南/监控流水线/)。

## 启动一次运行

1. 在工作区侧栏中点击 **流水线**。
2. 在页头按下 **运行流水线**。你会落到运行选择器
   （`/workspaces/<workspace-id>/pipelines/run`）。
3. 在左侧栏中挑选一个模板。每张卡片会显示模板的名称、描述，以及它是否接受输入。
4. 在右侧填写输入表单。必填字段在有值之前会一直禁用按钮；没有输入的模板会明确说明这一点。
5. 按下 **运行流水线**。

你会落到该次运行的详情页，并实时看到时序瀑布图和图画布。

## 如果左侧栏为空

只有当以下**两个**条件都成立时，运行选择器才会显示某个模板：

- 该模板的开关已在 **设置 → 工作区 → 流水线模板** 中打开。
- 模板编辑器的 **手动运行** 对话框中的 **允许手动运行** 已打开——
  正是这个开关创建了运行选择器所读取的 `manual` 触发器。

十三个内置模板中有八个出厂即处于禁用状态：`external_pr_welcome`、
`cross_review`、`ticket_to_pr`、`pr_triage`、`pre_merge_gate`、`release_notes`、
`dep_audit` 和 `pr_digest`。引擎会拒绝启动已禁用的模板，因此请先打开它的开关，
再到这里寻找它。

模板列表上没有针对单个模板的 **运行** 操作，编辑器内部也没有运行按钮——运行选择器是唯一的手动入口。

## 填写仓库输入

类型为 **仓库** 的输入会在工作区已注册的仓库之上渲染一个选择控件。选中一个仓库会把
`repo_id`、`repo_local_path`、`repo_full_name`，以及——当该仓库有 GitHub 远端时——
`repo_owner` 和 `repo_name` 一并填充进运行载荷，因此下游步骤可以读取自己需要的字段。

## 观察运行

运行详情页由三个部分组成：元信息条（开始时间、有效时长、步骤进度、失败横幅、**重试** 和 **删除**）、
一个可折叠的时序瀑布图（带每个步骤的时长与成本）以及图画布。选中某个节点会打开该步骤的详情面板。

[监控流水线运行](/zh-CN/手册/操作指南/监控流水线/) 涵盖了所有这些内容，
包括如何读懂已挂起的步骤，以及某个步骤失败时该怎么办。

你从应用中启动的每一次运行都是真实的运行。
