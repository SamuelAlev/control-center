本指南介绍如何把你的聊天身份关联到你的 Control Center 用户，以及如何取消关联。

每位成员都要针对每个聊天产品做一次。它与连接应用是两回事：连接让整个工作区都能触达机器人，关联则让机器人能认出_你_。

## 为什么必须关联

对于无法解析到某个工作区成员的聊天账户，桥接会拒绝代为操作。这是有意为之——如果没有关联，来自 Slack 的每条消息都只能归到安装应用的那个人名下，审计记录、按主体计算的速率限制以及工单发起人都会指向错误的人。

未关联的成员提及机器人时，会在该 Slack 话题中收到一条说明如何关联的回复。不会有任何任务被派发。

## 使用代码关联

关联需要双方确认：从 Slack 发送代码证明的是该 Slack 账户，而在 Control Center 中确认则证明该账户是你的。

1. 前往 **设置 → 工作区 → 个人资料与身份**，滚动到 **已关联的聊天账户** 卡片
2. 在 Slack 区块上，点击 **关联我的 Slack 账户**。对话框会显示一个一次性代码，例如：

```text
K7M2QP
```

3. 在 Slack 中，以**私信**的方式把这个代码发送给机器人：只发代码，不要附加其他内容
4. 机器人会回复 “Got it. Confirm this Slack account in Control Center to finish linking.”，而你留在那里未关闭的对话框会显示发送该代码的 Slack 个人资料：其名称与 Slack 成员 ID
5. 如果这是你的账户，点击**确认**。关联即告完成，对话框会显示结果，机器人也会在同一条私信中确认
6. 如果这不是你的账户，点击**拒绝**。什么都不会被关联，该代码也随即失效；如果你仍想关联，请点击**获取新代码**重试

关闭对话框不会丢失待认领的请求。之后到达的代码会等待在你个人资料页的 **关联我的 Slack 账户** 行上，并提供同样的**确认**和**拒绝**按钮。

之所以要有确认这一步：如果有人偷看到你的代码，并从别人的 Slack 账户发送它，那么该账户就能以你的身份行事。只有你本人能确认，并且只能确认发送该代码的那个确切的个人资料。

该代码：

- 只能使用一次，生成 **15 分钟** 后过期
- 始终是为_你_生成的，绝不会为队友生成
- 只在与机器人的私信中被接受。在频道里，它只是一条普通消息
- 只能由安装该机器人的 Slack 工作区的正式成员认领，不能由访客或其他组织的人认领
- 会替换你已持有的任何代码，因此再次点击该按钮会让上一个代码失效
- 只保存在内存中，因此服务器重启会让尚未使用的代码失效——请再次点击该按钮

未知、已过期、已被拒绝或为其他工作区生成的代码，失败后的表现完全一样、无从区分：“That code is not valid (or has expired).”

## 通过邮箱自动关联

如果你的 Slack 个人资料带有已确认的邮箱，且该邮箱与某个**已经是此工作区成员**的 Control Center 用户的已验证邮箱一致，那么你第一次与桥接对话时它就会自动关联你。无需代码。

两半都不可少：邮箱匹配证明身份，但只有成员身份才授予访问权，因此即便某个陌生人的邮箱恰好存在于服务器上，也关联不到任何东西。名册会显示每个关联是如何建立的（“按邮箱匹配”或“通过代码关联”）。

自动关联需要 `users:read.email` 权限范围。没有它，Slack 不会提供该邮箱地址，就只能走代码流程。

## 查看谁已关联

名册属于工作区管理，因此它位于界面的另一半：**设置 → 工作区 → 通用 → 聊天桥接 → 已关联账户**。它列出工作区中每一位已关联的成员，以及每人对应的 Slack 账户和关联方式。

你自己的状态在个人资料页上：一旦完成关联，**关联我的 Slack 账户** 这一行会显示“已关联到 _your-slack-id_”；尚未关联时，它会提示你去关联。

名册和待认领的关联都是实时订阅，因为变更发生在另一端：你在 Slack 中发送代码，因此应用发出的任何请求都无法把结果带回来。

## 取消关联

在工作区名册中点击某一行的 **取消关联**。

- 任何人都可以取消自己的关联
- 只有管理员可以取消其他成员的关联
- 取消关联还会吊销该成员尚未使用的关联代码

取消关联后，该 Slack 账户在重新关联之前无法再驱动智能体。已有的空间、转录和工单会保留原有的归属——取消关联并不等于撤回过去的工作。

## 故障排查

### 机器人说我不是此工作区的成员

你的 Slack 账户已关联到某个 Control Center 用户，但该用户在此工作区中不持有成员身份。请让管理员邀请你；参见[多人协作——身份、成员身份与在线状态](/zh-CN/手册/概念/多人协作/)。

### 机器人说我的角色是只读的

`viewer` 和 `guest` 角色无法启动工作。需要管理员把你的角色提升到 `member` 或更高。

### 机器人说代码无效

该代码已过期、已被使用、已被拒绝，或已被更新的代码替换。请再次点击**关联我的 Slack 账户**，并发送新代码。

### 机器人把我的代码当作请求处理了

你是在频道里发送的，或者你的 Slack 账户已经关联过。代码只会在私信中被接受；而来自已关联账户、形如代码的消息只是一条普通请求。
