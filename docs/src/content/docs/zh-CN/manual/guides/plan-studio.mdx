本指南展示如何在 Plan Studio 中处理计划。关于编排和计划文档究竟是什么，参见[编排](/zh-CN/手册/概念/编排/)和[使用计划模式](/zh-CN/手册/操作指南/计划模式/)。

## 打开计划

计划从属于生成它的那个对话，因此你通常也是在对话里打开它：对话中该计划所在的行有一个**打开**操作，Plan Studio 会作为编辑器标签页在对话旁边打开。

:::note[侧边栏中没有“计划”这一项]
这是刻意为之，并非疏漏。位于 `/workspaces/<workspace-id>/plans` 的中心页只是一个可路由的深层链接，所以如果你想要一份常驻列表，请把它加入书签。
:::

该中心页列出三个部分：

- **进行中的计划**——编排，已提议的排在最前，并附上它们的状态、步骤数和修订号。
- **计划文档**——单个智能体在[计划模式](/zh-CN/手册/操作指南/计划模式/)中用 `submit_plan` 提交的计划，只要它们处于已提议或已批准状态。
- **剧本**——已保存的带参数计划模板。

点击卡片即可在 Plan Studio 中打开它。路由是
`/workspaces/<workspace-id>/plans/<kind>/<plan-id>`，其中 `kind` 是
`orchestration` 或 `document`，因此你也可以对单个计划使用深层链接。

如果你打开的是**编排**，你会看到可编辑的画布、版本时间线和审批栏。如果你打开的是**计划文档**，同一张图会以只读方式呈现——计划文档由智能体撰写；你审查、预估并批准或拒绝它们，而一份已批准的文档会显示它所编译成的编排中每个节点的实时运行状态。

## 编辑 DAG

当**编排**处于 `proposed` 状态时可以进行编辑。所有画布编辑都通过键盘完成：

1. 点击画布，然后用**方向键**移动选中项。
2. 按 **n** 添加一个步骤。它会以“新建步骤”之名被选中；在右侧的检查器中重命名它。
3. 在必须最先运行的步骤上按 **e**，然后点击依赖它的步骤（或选中该步骤并按 **Enter**）以建立依赖关系。按 **Esc** 放弃尚未确认的连接。
4. 按 **x** 剪掉所选步骤最新的依赖关系，或在检查器的依赖关系编辑器中切换精确的依赖关系。
5. 按 **Delete** 删除所选步骤；其余步骤的依赖关系中对该步骤的引用也会被移除。

在检查器中，你还可以编辑步骤的描述、角色和输出模式。编辑会在短暂停顿后自动保存为一个新修订；校验错误（显示在审批栏中）会阻止保存，直到你修复它。

只有工作步骤可以编辑。结构性节点——调研、讨论和汇总——是只读的，任何工作已经运行过的步骤也是只读的（它会被标记为“已执行”，因为编辑它会让计划分叉）。

保存以你开始时所在的修订为基础进行乐观并发。如果编排器在你脚下重新规划，你的保存会被拒绝并提示“计划已发生变化”，而不会被合并或静默覆盖；请重新读取当前修订并重做你的编辑。智能体发起的重新规划本身也被限流为每两分钟一次，因此这种情况很少发生。

:::note
画布不支持拖拽重新定位：布局由依赖关系结构计算得出，因此“移动”一个步骤意味着重新连接它的依赖关系。
:::

## 查看费用、时间和风险预估

按审批栏中的**预估**。

- 画布上的每个步骤都会得到一个徽标，其中包含费用区间以及支撑这一区间的样本量；当该步骤的角色从未运行过时，则显示“暂无历史记录”。选中某个步骤可在检查器中查看完整详情：带样本量的费用区间、时长区间，以及由该步骤的来源推导出的影响范围（文件和符号）——当该步骤没有来源时则显示“未知”。
- 审批栏显示计划总计：整体费用区间、关键路径的时长区间（并行分支会重叠，因此这不是各区间之和），以及计划设置了预算时的预算上限。
- 如果只有部分步骤有历史记录，总计会被标记为**部分**，且只覆盖可估算的步骤。如果估算的上限超出预算上限，总计会变红并给出超预算警告。

预估要么诚实，要么缺席：角色没有已完成运行历史的步骤会报告样本量为零，且完全不给出任何区间，并显示为未知，而不是被猜测。请把“暂无历史记录”理解为“没人知道”，而不是“很便宜”。

预算上限只是与这份预估进行展示层面的比较。计划开始运行后，没有任何东西会强制执行它——关于真正能停止支出的控制手段，参见[管理成本](/zh-CN/手册/操作指南/管理成本/)。

## 对比某个修订与更早的提案

每一次编辑和编排器的每一次重新规划都会追加到一个只增不减的修订时间线上，该时间线显示在编排计划左侧的**版本**面板中。

1. 点击某个修订，将它和当前提案进行对比。未选中任何修订时，面板会把上一个修订与当前修订进行对比。
2. 在面板下半部分阅读差异：两个修订之间新增、删除或更改的步骤。
3. 如果计划仍处于 `proposed`，点击某个修订上的回退图标即可回到该修订。回退会把那份提案保存为一个**新**修订——什么也不会丢失。

`propose_orchestration` 和编辑器都会在计划不再是 `proposed` 之后拒绝更改，因此正在进行的运行不会把执行中途的重新规划纳入进来。

## 批准、拒绝或扩大计划

在应用中，对一份已提议计划的决定是一整次做出的：审批栏中的**批准计划**或**拒绝**。**批准计划**始终会批准每一个步骤——没有办法先选中一个子集。当提案存在校验错误时，批准会被阻止，而这些错误就显示在按钮旁边。

批准仅限操作员。它没有对应的 MCP 工具，因此智能体可以提出提案并修订计划，但永远无法批准计划。

一旦编排进入执行中，审批栏会发生变化：

- 如果某个步骤在运行中途停下来提问，选中它并按**继续节点**以恢复它。
- 按**批准所选**可将一个_部分_批准扩大到所选步骤以及它间接依赖的一切（步骤永远不能在其依赖项未被批准的情况下被批准）。该控件出现在每个编排的执行中审批栏上；当计划是被整体批准时，它不产生任何效果。
- 按**取消运行**停止整个编排。

部分批准集合之外的步骤会呈现为已延后，在你扩大该集合之前不会运行。

:::note[部分批准不可能从应用中发起]
只有当某个调用方通过 RPC 调用 `orchestration.approve` 并显式给出 `approved_node_keys` 列表时，部分批准才会存在。应用中的**批准计划**始终批准每一个步骤。计划文档在任何情况下都是整体批准，因此正在执行的文档只提供**取消运行**。
:::

## 运行带参数的剧本

剧本是一份已保存的计划模板，其目标、步骤标题、描述和提示词中带有带类型的 `{{param}}` 占位符。替换是字面进行的——没有表达式语言；如果你需要逻辑，请改用[流水线](/zh-CN/手册/操作指南/创建流水线/)。

1. 在中心页的**剧本**部分，按剧本上的**运行**（或打开 ⌘K 命令面板，在那里选择该剧本）。
2. 填写参数。枚举参数会呈现为下拉菜单；仓库和智能体参数接受仓库或智能体引用；可选参数则回退到其默认值。
3. 选择计划所锚定的**锚定工单**，然后确认。

运行剧本只会**提议**一份计划——实例化出的编排会在 Plan Studio 中以 `proposed` 打开，在你于那里批准它之前什么都不会执行。要删除某个剧本，按其卡片上的垃圾桶图标。

智能体使用 `create_playbook` 和 `run_playbook` 这两个 MCP 工具创建和运行剧本；参见 [MCP 工具参考](/zh-CN/手册/参考/mcp-工具/)。
