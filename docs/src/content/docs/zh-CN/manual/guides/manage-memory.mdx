本指南介绍如何使用工作区的知识存储。

开始之前需要知道的最重要一点：**记忆界面是复核界面，而不是撰写界面。** 事实和策略由智能体写入 —— 通过 `propose_fact` 和 `propose_policy`，并用 `supersede_fact` 和 `supersede_policy` 替换它们。`remember` 写入一条受会话限制的热层条目，之后 `consolidate_memory` 可能会把它提升为事实。录制下来的会议决策会被采集进 `decisions` 域；已完成的智能体运行则没有这种采集。你在这里要做的，是读取它们写下的内容、纠正、停用或删除。

记忆位于**设置 → 工作区 → 记忆**（`/workspaces/<id>/settings/memory`）。它不是侧边栏的顶级入口。

## 三个标签页

该页面只有三个标签页。事实和策略会显示实时计数；图谱则不会：

- **事实** —— 工作区中的每一条事实，并显示其中未被替代的数量
- **策略** —— 按域分组的规范性规则，并显示其中已启用的数量
- **知识图谱** —— 由域、主题、事实和策略构成的可交互画布

域不是由你创建的。当智能体向某个域写入第一条事实或策略时，该域便随之产生；界面中任何地方都没有创建域的控件。

## 复核并纠正事实

1. 打开**事实**标签页。
2. 使用搜索框缩小列表范围。它只是对每条事实的域、主题和内容做简单的子串过滤 —— 没有关键词索引，也不做排序。
3. 使用范围筛选器显示所有范围、仅整个工作区范围的事实，或某一个仓库的事实。
4. 使用排序开关按时间新近度或置信度排序。
5. 点击某条事实的编辑控件。

编辑对话框允许你更改：

- **域** —— 在域之间移动事实
- **主题** —— 它的简短标签
- **内容** —— 知识文本
- **置信度** —— 以 5% 为步进的滑块

保存即可写回。不存在**添加事实**按钮；该对话框只能在已有行上打开。

## 查看已替代的事实

事实标签页有一个**显示已替代**开关。已替代的事实默认隐藏，由该开关显示出来，审计轨迹也正是在这里 —— 替代绝不会删除。

## 删除事实

使用某条事实的删除控件并确认。这是真正的删除，而不是替代：用于那些记录本身就是错误的事实，而让智能体去替代 _内容_ 已经变化的事实。

## 管理策略

**策略**标签页按域对已启用的策略分组，并把未启用的策略降级到末尾的单独一节。针对每条策略，你可以：

- **编辑**它
- **删除**它
- **停用** / **启用**它 —— 这是可逆的选项，通常也是更恰当的选择。只有已启用的策略才会进入智能体的提示词。

与事实一样，这里也没有创建控件。

## 探索知识图谱

**知识图谱**标签页把域、主题、事实和策略铺陈为可导航的节点画布 —— 可平移、缩放、拖动节点。点按某个节点会打开它的详情面板，从那里可以进入同样的编辑对话框。它是查看哪些域真正有内容的最快方式。

## 编辑智能体的工作记忆

工作记忆是每个智能体私有的草稿本，在派发时注入它的提示词。智能体自己通过 `record_observation` 和 `update_my_notes` 写入它，但你也可以直接读取和编辑：

**设置 → 工作区 → 智能体** → 选择该智能体 → **记忆**标签页。

## 访问授权

记忆访问授权把智能体的角色映射为每个域上的一项权限（`none`、`read`、`write`）。用 `memory_access_grant.*` 操作写入它们。

关于它们如何生效，有两点需要理解：

- **读取是失效开放的。** 当某个（角色，域）组合没有对应的授权记录时，实际生效的权限是 `read`。唯一在没有 `write` 时会抛错的写入是 `propose_policy`。事实写入不受授权限制。
- **授权以智能体的角色为键。** 提议类工具会把缺失的 `agent_role` 默认为 `general`。为其他角色写入的授权不会约束这些智能体；而 `general` 授权会。

## 搜索在各处并不相同

有三种不同的东西都被叫作“记忆搜索”，但它们并不一致：

| 位置                            | 作用                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 事实标签页的搜索框              | 对客户端中已加载的事实做子串过滤                                                                      |
| `memory_fact.search` RPC 操作   | 仅做 FTS5 关键词搜索 —— 瘦客户端无法提交查询嵌入，因此混合搜索始终留在主机内部                        |
| 智能体侧的 `search_memory` 工具 | `keyword`、`semantic` 或 `hybrid`（默认）。混合模式融合四个声部：词法、语义、时序和图谱               |

所以，智能体和记忆页面不会以相同方式对同一个查询排序。当你想确认智能体实际能回忆起什么时，去问智能体。

## 嵌入

事实在**写入时**被嵌入，且仅在设备本地嵌入模型已安装时才会嵌入。在**设置 → 服务器 → 诊断与隐私 → 语义搜索**下查看它的状态。如果你想要语义召回，请在智能体开始写入记忆之前安装该模型。
