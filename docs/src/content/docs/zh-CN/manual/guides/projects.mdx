项目是工作区内围绕共同目标对工单的一种分组。项目仅存在于 Control Center——永远不会同步到 Linear 等外部提供方。

## 创建项目

1. 展开工作区侧边栏中的**工单**分组。该分组依次列出**全部工单**、每个未归档项目各占一行，然后是**新建项目**。
2. 点击**新建项目**。
3. 填写**项目名称**、可选的**描述**，并选择一种**颜色**。
4. 点击**创建项目**。

随后你会进入新项目的概览页，该项目也会作为一行出现在侧边栏的**工单**下。

## 将工单归入项目

项目是单个工单上的字段，可在以下两个位置之一设置：

- 打开该工单，在其属性栏中设置**项目**。
- 在列表中右键点击该工单，使用**项目**子菜单。

属性栏中的选择器也提供**新建项目**，因此你可以把工单归入当场创建的项目。**无项目**会清除该字段。

一个工单最多属于一个项目。

:::note[项目不是批量操作]
选中多个工单时出现的浮动栏涵盖状态、优先级、负责人、标签和删除，但不提供项目一项，因此要归入多个工单只能逐个进行。
:::

你也可以从项目入手：项目概览页上的**新建工单**会创建一个工单并将其归入该项目。

## 查看项目进度

从侧边栏中的项目行打开项目，或访问 `/workspaces/<workspace-id>/projects/<project-id>`。

概览页会显示项目的图标和名称、状态徽章、描述，以及一条显示已完成数与总数的进度条。下方则按状态对项目中的工单进行分组。

它不会汇总其他任何内容——没有负责人分布，也没有优先级分布。若要看这些，请改为筛选主工单列表。

## 更改项目状态

项目有三种状态：

| 状态        | 含义                 |
| ------------- | -------------------- |
| **进行中**    | 工作正在进行         |
| **已完成**    | 所有工作均已完成     |
| **已归档**    | 供历史查阅           |

使用项目页顶部的 **⋯** 菜单。它提供**编辑项目**、**标记为已完成**/**标记为进行中**、**归档**/**恢复**以及**删除项目**。

归档会把项目从侧边栏列表和工单选择器中隐藏。该操作可逆——**恢复**会将项目重新置为进行中——但项目在归档期间只能通过 URL 访问。

## 自动创建的项目

批准编排会创建一个项目，并把父工单归入其中，与你手动归入的内容并列。生成的工作项是流水线步骤，而非工单行，因此不会出现在项目看板上。这是唯一的自动化路径：没有任何流水线节点会创建工单，因此流水线无法向项目填充内容。参见[运行编排](/zh-CN/手册/操作指南/运行编排/)。

:::note[项目是面向操作员的界面]
项目的创建、列出、更新和删除都在应用中进行。智能体没有项目相关的工具。
