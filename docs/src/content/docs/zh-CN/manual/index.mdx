## 你可以做什么

- **给智能体发消息**：空间是驱动机群的主要方式。用 @ 提及一个智能体，它就会派发进自己的写时复制工作树，因此多个智能体可以并行写代码和做审查，而不会碰你的检出
- **编排宏大需求**：给编排器一个目标，只需批准一次它提出的全团队计划，随后一条生成的[流水线](/zh-CN/手册/概念/流水线/)就会执行它
- **审查和合并 PR**：内置 diff 查看器、行内评论和 AI 驱动的审查
- **交给智能体一台可丢弃的机器**：一台[机台](/zh-CN/手册/操作指南/使用机台/)就是一台用完即弃的虚拟机——可能是一个浏览器、一个桌面、一部手机，或一个隔离终端——智能体操控着它，而你可以实时观看并随时接管；其中的开发服务器会转发到 `localhost`、智能体的浏览器以及 `https://myapp.test`
- **自动化工作流**：使用由事件或日程触发的、基于 DAG 的流水线
- **管理知识**：具备工作区范围的记忆、事实和策略
- **跟踪工作**：与厂商无关的工单、项目和委派
- **录制会议**：在本机完成采集、转写和说话人分离，再总结为笔记、待办事项和决策
- **一览你的一天**：Google Calendar 同步、RSVP、会议提醒和录制并链接
- **用手机跟踪机群**：把设备与你的服务器配对，即可阅读消息、回复并分拣工单。手机会在它能到达的路径中选出最好的一条——环回、LAN、tailnet 或 TLS——并在必要时退回到一条端到端密封的中继，该中继只转发它读不懂的帧
- **从 Slack 指挥智能体**：把工作区桥接到聊天应用，然后提及机器人、在 Slack 线程中回复，或用斜杠命令提交工单——全程走一条出站连接，因此无需公网端点
- **集成**：对接 GitHub、Linear、Slack、Google Calendar 以及 100 多种 MCP 工具

## 你不必安装它

同一个应用也在浏览器中运行，地址是
[app.usectrl.dev](https://app.usectrl.dev)，功能完全一致。

每个客户端——桌面、Web 和手机——都只是运行在无界面服务器之上的瘦渲染器，服务器
拥有你的数据并实际干活。桌面可以为你启动这台服务器；浏览器标签页做不到，
所以 Web 应用连接的是你自己运行的那一台。这台服务器可以就在你自己的机器上
（`ws://localhost:9030`，无需证书），也可以位于一台可通过 TLS、VPN 或隧道访问的
远程主机上。

浏览器这条路线的说明见[安装](/zh-CN/手册/安装/#use-it-in-your-browser)，
三个客户端之间的关系见[部署与客户端](/zh-CN/手册/概念/部署/)。
