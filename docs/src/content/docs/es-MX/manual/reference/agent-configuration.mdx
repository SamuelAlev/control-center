Esta referencia enumera todos los campos de la entidad de agente, además de las enumeraciones y los indicadores que usa. Para ver un recorrido paso a paso de cómo crear o editar un agente en la aplicación, consulta [Crear y configurar un agente](/es-MX/manual/guias/crear-agente/).

## Campos de la entidad de agente

| Campo                   | Tipo                   | ¿Obligatorio? | Descripción                                                                                                                                                                                        |
| ----------------------- | ---------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Sí            | Identificador único del agente                                                                                                                                                                     |
| `name`                  | `String`               | Sí            | Identificador corto para las menciones con @                                                                                                                                                       |
| `title`                 | `String`               | Sí            | Título del rol legible para las personas                                                                                                                                                           |
| `agentMdPath`           | `String`               | Sí            | Ruta absoluta al archivo `.md` de definición del agente                                                                                                                                            |
| `workspaceId`           | `String`               | Sí            | Espacio de trabajo propietario (no nulo)                                                                                                                                                           |
| `reportsTo`             | `String?`              | No            | Id del agente superior                                                                                                                                                                             |
| `skills`                | `AgentSkills`          | Sí            | Conjunto de identificadores de skills                                                                                                                                                              |
| `persona`               | `String?`              | No            | Instrucciones de comportamiento en texto libre                                                                                                                                                     |
| `systemPrompt`          | `String?`              | No            | Reemplaza el prompt de sistema predeterminado                                                                                                                                                      |
| `adapterId`             | `String?`              | No            | Id del adaptador de inferencia                                                                                                                                                                     |
| `modelId`               | `String?`              | No            | Id del modelo dentro del adaptador                                                                                                                                                                 |
| `strictMode`            | `bool`                 | No            | Predeterminado `false`. Se escribe en la fila y en el `AGENTS.md` del agente                                                                                                                       |
| `effort`                | `String?`              | No            | Id del nivel de razonamiento (p. ej. `'low'`, `'xhigh'`), tomado de los `thinkingLevels` del modelo seleccionado                                                                                    |
| `contextSize`           | `int?`                 | No            | Tamaño máximo de la ventana de contexto                                                                                                                                                            |
| `role`                  | `AgentRole?`           | No            | Rol del agente                                                                                                                                                                                     |
| `monthlyBudgetCents`    | `int`                  | No            | Tope de gasto mensual en centavos (predeterminado `0`, ilimitado)                                                                                                                                  |
| `silenceTimeoutMinutes` | `int?`                 | No            | Anulación del vigilante de silencio en minutos; debe ser nulo o estar entre 1 y 240 (validado en el constructor)                                                                                   |
| `maxConcurrentTasks`    | `int`                  | No            | Predeterminado `1`. Cifra de capacidad que informa el modelo de presencia (los recuentos de ejecuciones en curso y en cola se comparan con ella)                                                   |
| `visibility`            | `AgentVisibility`      | No            | Predeterminado `workspace`                                                                                                                                                                         |
| `lifecycleStatus`       | `AgentLifecycleStatus` | No            | Estado de gobernanza (predeterminado `active`). Lo escribe la parada forzosa del presupuesto y se muestra en el organigrama y en la lista de presencia. El despacho aún acepta trabajo de un agente `paused` |
| `budgetPolicyId`        | `String?`              | No            | Id de la política de presupuesto compartida; cuando es nulo, `monthlyBudgetCents` se aplica directamente                                                                                            |
| `runtimeProfileId`      | `String?`              | No            | Id del perfil de tiempo de ejecución personalizado                                                                                                                                                 |
| `createdAt`             | `DateTime`             | Sí            | Marca de tiempo de creación                                                                                                                                                                        |

`name` y `title` deben ser ambos no vacíos (validado en el constructor). El valor
predeterminado de `monthlyBudgetCents` de `0` significa ilimitado. Escribe un techo con `agents.upsert`.

## Enumeración AgentVisibility

| Valor       | Descripción                                                       |
| ----------- | ----------------------------------------------------------------- |
| `workspace` | El valor predeterminado; los valores almacenados desconocidos y nulos se interpretan como este |
| `private`   | Privado para el usuario que lo creó                               |

## Enumeración AgentLifecycleStatus

| Valor      | Descripción                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------- |
| `active`   | El valor predeterminado. `isDispatchable` es verdadero solo para este valor                     |
| `paused`   | Lo establece la parada forzosa del presupuesto. Se muestra en la lista de presencia; el despacho aún acepta trabajo |
| `archived` | Retirado y oculto de las listas de presencia activas                                            |

## Permisos

Un agente no lleva indicadores de permisos. Hacer push, abrir y publicar pull requests, escribir en un rastreador y la salida a la red son clases de acción (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) que las [barandillas](/es-MX/manual/conceptos/barandillas/) resuelven en el ámbito del espacio de trabajo, del agente o del espacio. El token de GitHub de una ejecución tiene siempre alcance de lectura; los push pasan por la pasarela de ejecuciones de agentes, que pregunta a la regla `gitPush` antes de reenviarlos.

## AgentSkills

Un conjunto inmutable de identificadores de skills que no distingue mayúsculas de minúsculas. En el despacho, esos slugs se sincronizan como enlaces de skills en el overlay del agente; después, el arnés carga automáticamente el frontmatter de las skills enlazadas en el prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (derivado)

No se almacena. Siete valores. El orden de declaración es el orden de prioridad (`sortPriority`, fijado por una prueba), que es el orden con el que se ordena la lista de presencia:

| Estado      | `sortPriority` | Condición                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `running`   | 0              | Algún registro de ejecución tiene el estado `running`                                                                     |
| `blocked`   | 1              | La vitalidad de la ejecución más reciente es `blocked`, `stalled` o `looping`                                             |
| `failed`    | 2              | El estado de la ejecución más reciente es `error`, o su vitalidad es `failed` o `dead`                                    |
| `queued`    | 3              | Una ejecución se despachó pero no se está ejecutando: está en espera detrás de otra ejecución del mismo agente, o se escribió pero aún no ha comenzado |
| `succeeded` | 4              | La ejecución terminó correctamente                                                                                        |
| `idle`      | 5              | El agente ya se ha ejecutado antes y no tiene nada en curso                                                               |
| `neverRun`  | 6              | No existe ningún registro de ejecución                                                                                    |

`queued` y `succeeded` son **solo por ejecución**. `deriveAgentLiveState`, que calcula el estado de un agente para la lista de presencia, nunca produce ninguno de los dos: devuelve `neverRun`, `running`, `failed`, `blocked` o `idle`.
