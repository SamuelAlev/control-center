Los atajos provienen de un único registro `const`, `KeybindingRegistry` en `lib/core/constants/keybindings.dart`. Contiene **48 asignaciones**. **Ajustes → Tú → Atajos de teclado** muestra ese registro como una **referencia de solo lectura**: no hay interfaz para reasignar atajos ni archivo de atajos de teclado del usuario.

`Cmd` a continuación es el modificador de comando principal: ⌘ en macOS y Ctrl en Windows y Linux. Una asignación solo se activa cuando su comando tiene un manejador registrado en la pantalla actual y se cumple su cláusula `when`; `!textInputFocus` significa que la tecla se deja pasar a un campo de texto que tiene el foco.

No hay ningún atajo de navegación con teclas numéricas. La bandeja de entrada, los tickets, las pull requests y lo demás se alcanzan desde la barra lateral o con ⌘K. Observabilidad tampoco tiene atajo.

## Global (19)

Alcance `global`, así que están activos en cualquier parte del shell.

### Sistema

| Atajo                                       | Acción                                                  | Condición                                                        |
| ------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Paleta de comandos                                      | —                                                                |
| `Shift + /` (`?`)                           | Hoja de referencia de atajos de teclado                 | No estar escribiendo en un campo                                 |
| `Cmd/Ctrl + Z`                              | Deshacer                                                | No estar escribiendo en un campo (un campo con el foco conserva su propio deshacer) |
| `Cmd/Ctrl + Shift + Z`                      | Rehacer                                                 | No estar escribiendo en un campo                                 |
| `Cmd/Ctrl + Shift + T`                      | Cambiar tema                                            | —                                                                |
| `Cmd/Ctrl + ,`                              | Abrir ajustes (abre en `/settings/you/appearance`)       | —                                                                |
| `Cmd/Ctrl + Shift + Alt + F`                | Alternar modo enfoque                                   | —                                                                |
| `Cmd/Ctrl + Shift + W`                      | Alternar el selector de espacios de trabajo              | —                                                                |
| `Cmd/Ctrl + ]`                              | Espacio de trabajo siguiente                            | —                                                                |
| `Cmd/Ctrl + [`                              | Espacio de trabajo anterior                             | —                                                                |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | Cambiar al espacio de trabajo 1–9                       | —                                                                |

## Lista de pull requests (3)

Alcance `/pull-requests`. Todos requieren `route == '/pull-requests'` y que ningún campo de texto tenga el foco, así que no se activan mientras la ruta de detalle de la PR está abierta sobre la lista.

| Atajo   | Acción                 |
| ------- | ---------------------- |
| `R`     | Actualizar             |
| `Enter` | Abrir PR               |
| `F`     | Abrir el menú de filtros |

`Enter` (`pr.list-open`) está declarado en el registro y aparece en la referencia de atajos de teclado, pero **la pantalla de la lista no registra un manejador para él**, así que por ahora no se activa. `F` abre el menú de filtros (`pr.list-open-filter`), no la búsqueda.

## Detalle de pull request (2)

Alcance `/pull-requests/`. Actualizar requiere que ningún campo de texto tenga el foco. Cerrar pestaña no tiene protección de entrada de texto (una combinación con el modificador ⌘ nunca es texto plano) y sí una expresión regular de ruta, así que no se activa en la lista.

| Atajo          | Acción          | Condición                       |
| -------------- | --------------- | ------------------------------- |
| `R`            | Actualizar      | No estar escribiendo en un campo |
| `Cmd/Ctrl + W` | Cerrar pestaña  | En una ubicación `/pull-requests/<…>` |

El cambio de pestañas (`1`/`2`/`3`), marcar como visto o contraer archivos (`V`/`C`), la lista de archivos (`T`) y buscar en el diff (`Cmd/Ctrl + F`) los maneja el propio manejador del visor de diferencias; consulta [Teclas del visor de diferencias fuera del registro](#teclas-del-visor-de-diferencias-fuera-del-registro).

## Bandeja de entrada (1)

| Atajo | Acción                 |
| ----- | ---------------------- |
| `F`   | Abrir el menú de filtros |

Requiere `route == '/inbox'` y que ningún campo de texto tenga el foco.

## Perfiles de usuario y de equipo de GitHub (3)

Alcance `/users/`. La cláusula `when` es una expresión regular contra `/users/<login>` **o** `/teams/<organization>/<slug>`, además de que ningún campo de texto tenga el foco.

| Atajo          | Acción         |
| -------------- | -------------- |
| `R`            | Actualizar     |
| `/`            | Enfocar búsqueda |
| `Cmd/Ctrl + F` | Enfocar búsqueda |

## Espacios (8)

Alcance `/spaces`. Las cláusulas `when` usan una expresión regular, así que se activan tanto en la lista de espacios (`/spaces`) como en un espacio seleccionado (`/spaces/<id>`).

| Atajo                  | Acción                       | Condición                       |
| ---------------------- | ---------------------------- | ------------------------------- |
| `Enter`                | Enviar mensaje               | —                               |
| `Cmd/Ctrl + N`         | Nuevo espacio                | En una ruta `/spaces`           |
| `J`                    | Espacio siguiente            | No estar escribiendo en un campo |
| `K`                    | Espacio anterior             | No estar escribiendo en un campo |
| `Cmd/Ctrl + Shift + D` | Dictado con pulsar para hablar | —                             |
| `Cmd/Ctrl + T`         | Abrir pestaña del editor     | En una ruta `/spaces`           |
| `Cmd/Ctrl + W`         | Cerrar pestaña del editor    | En una ruta `/spaces`           |
| `Cmd/Ctrl + B`         | Alternar la barra lateral del editor | En una ruta `/spaces`    |

El envío con Enter lo maneja el campo de texto del compositor; pulsar para hablar lo maneja el botón de micrófono del compositor (su propio manejador de teclado físico). Ambos aparecen en el registro para la referencia de ajustes.

## Selector de espacios de trabajo (2)

Alcance `/workspaces`, activos solo en el propio selector.

| Atajo          | Acción                            |
| -------------- | --------------------------------- |
| `Cmd/Ctrl + N` | Nuevo espacio de trabajo          |
| `Enter`        | Abrir el espacio de trabajo seleccionado |

`Enter` requiere que ningún campo de texto tenga el foco.

## Teclas del visor de diferencias fuera del registro

El visor de diferencias de las PR maneja estas teclas por su cuenta (`PrDiffKeyboardHandler`). Buscar, visto y contraer solo aparecen en los comentarios del registro para la referencia de ajustes: no hay ningún manejador del despachador registrado, así que el despachador se las deja a la vista de diff. No aparecen como filas propias en la referencia de atajos de teclado.

| Atajo           | Acción                                                       |
| --------------- | ------------------------------------------------------------ |
| `Cmd/Ctrl + F`  | Buscar en el diff                                            |
| `J` / `K`       | Archivo siguiente / anterior                                 |
| `V`             | Alternar visto en el archivo con el foco                     |
| `C`             | Alternar contraído en el archivo con el foco                 |
| `T`             | Mostrar la lista de archivos                                 |
| `Enter`         | Siguiente coincidencia de búsqueda (solo mientras la búsqueda en el diff está abierta) |
| `Shift + Enter` | Coincidencia de búsqueda anterior                            |
| `Escape`        | Cerrar la búsqueda en el diff o limpiar la selección de texto del diff |
| `Cmd/Ctrl + C`  | Copiar la selección del diff                                 |

## Combinaciones reservadas por el navegador

En la compilación web, el navegador consume algunos aceleradores antes de que la página los vea, así que las asignaciones correspondientes nunca se activan ahí. En escritorio funcionan con normalidad. Están reservadas al combinarse con el modificador de comando principal: `T`, `W`, `N` y los dígitos `1`–`9`.

Eso abarca el cambio de espacio de trabajo con `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nuevo espacio, nuevo espacio de trabajo, nuevo agente, agregar repositorio) y `Cmd/Ctrl + T` / `Cmd/Ctrl + W` en espacios y en el detalle de PR.
