Las páginas de referencia describen **lo que hay**, de forma exhaustiva y sin comentarios.
Úsalas para consultar algo cuando ya sabes qué buscas: el nombre exacto de una herramienta,
un tipo de paso, una transición de estado, una ruta, un atajo.

No están escritas para leerse de principio a fin. Para eso, usa los
[conceptos](/es-MX/manual/conceptos/); para lograr algo concreto, usa las
[guías prácticas](/es-MX/manual/guias/).

## La superficie del producto

- [Herramientas MCP](/es-MX/manual/referencia/herramientas-mcp/) — todas las herramientas que registra el servidor MCP, agrupadas por familia
- [Herramientas de agente integradas](/es-MX/manual/referencia/herramientas-de-agente/) — herramientas del harness vinculadas al servidor (LSP, AST, debug, eval, vibe)
- [Comandos slash](/es-MX/manual/referencia/comandos-slash/) — integradas del compositor, `/skill:` y comandos de usuario
- [Mapa de rutas](/es-MX/manual/referencia/mapa-de-rutas/) — cada pantalla y la URL con la que se llega a ella
- [Atajos de teclado](/es-MX/manual/referencia/atajos-de-teclado/) — el registro completo de asignaciones de teclas
- [Eventos de dominio](/es-MX/manual/referencia/eventos-de-dominio/) — cada evento publicado en el bus de dominio
- [Rigs](/es-MX/manual/referencia/rigs/) — cada superficie de rig, verbo de acción, estado del ciclo de vida, puerto y valor predeterminado
