Cada guía resuelve **un problema para alguien que ya conoce el producto**. Suponen que
tienes Control Center instalado y un espacio de trabajo configurado, plantean un objetivo
en el título y terminan cuando ese objetivo se cumple.

Si apenas estás aprendiendo el producto, empieza por los
[tutoriales](/es-MX/manual/tutoriales/). Si quieres entender _por qué_ algo se comporta
como se comporta, lee los [conceptos](/es-MX/manual/conceptos/).
