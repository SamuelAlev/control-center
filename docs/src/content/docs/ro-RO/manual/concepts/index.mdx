These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/ro-RO/manual/ghiduri-practice/); when you want to look
something up, go to the [reference](/ro-RO/manual/referinta/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/ro-RO/manual/concepte/spatii-de-lucru/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/ro-RO/manual/concepte/modelul-agentilor/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/ro-RO/manual/concepte/ciclul-de-viata-al-trimiterii/) — what happens between your message and the agent's first token
- [Modes](/ro-RO/manual/concepte/moduri/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/ro-RO/manual/concepte/contextul-instrumentelor/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/ro-RO/manual/concepte/intelligence-pentru-cod/) — the code graph, language server, structural search and debugger
- [Conversation history](/ro-RO/manual/concepte/istoricul-conversatiilor/) — persistence, compaction and forking a transcript
