Această referință listează fiecare câmp al entității de agent, plus enumerările și flag-urile pe care le folosește. Pentru un parcurs pas cu pas de creare sau editare a unui agent în aplicație, vezi [Creează și configurează un agent](/ro-RO/manual/ghiduri-practice/creeaza-agent/).

## Câmpurile entității de agent

| Câmp                    | Tip                    | Obligatoriu | Descriere                                                                                                                                                                                           |
| ----------------------- | ---------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Da          | Identificator unic al agentului                                                                                                                                                                      |
| `name`                  | `String`               | Da          | Identificator scurt pentru @-mențiuni                                                                                                                                                                |
| `title`                 | `String`               | Da          | Titlu de rol lizibil pentru oameni                                                                                                                                                                   |
| `agentMdPath`           | `String`               | Da          | Cale absolută către fișierul de definiție `.md` al agentului                                                                                                                                         |
| `workspaceId`           | `String`               | Da          | Spațiul de lucru proprietar (non-null)                                                                                                                                                               |
| `reportsTo`             | `String?`              | Nu          | Id-ul agentului părinte                                                                                                                                                                              |
| `skills`                | `AgentSkills`          | Da          | Set de identificatori de skill-uri                                                                                                                                                                   |
| `persona`               | `String?`              | Nu          | Instrucțiuni de comportament în text liber                                                                                                                                                           |
| `systemPrompt`          | `String?`              | Nu          | Suprascrie promptul de sistem implicit                                                                                                                                                               |
| `adapterId`             | `String?`              | Nu          | Id-ul adaptorului de inferență                                                                                                                                                                       |
| `modelId`               | `String?`              | Nu          | Id-ul modelului în cadrul adaptorului                                                                                                                                                                |
| `strictMode`            | `bool`                 | Nu          | Implicit `false`. Se scrie în rând și în `AGENTS.md`-ul agentului                                                                                                                                     |
| `effort`                | `String?`              | Nu          | Id-ul nivelului de raționament (de ex. `'low'`, `'xhigh'`), preluat din `thinkingLevels` ale modelului selectat                                                                                      |
| `contextSize`           | `int?`                 | Nu          | Dimensiunea maximă a ferestrei de context                                                                                                                                                            |
| `role`                  | `AgentRole?`           | Nu          | Rolul agentului                                                                                                                                                                                      |
| `monthlyBudgetCents`    | `int`                  | Nu          | Plafon lunar de cheltuieli, în cenți (implicit `0`, nelimitat)                                                                                                                                       |
| `silenceTimeoutMinutes` | `int?`                 | Nu          | Suprascriere a timeout-ului de tăcere, în minute; trebuie să fie null sau între 1–240 (verificat în constructor)                                                                                     |
| `maxConcurrentTasks`    | `int`                  | Nu          | Implicit `1`. Cifra de capacitate pe care o raportează modelul de prezență (numărătorile de rulări în execuție și în coadă sunt comparate cu ea)                                                     |
| `visibility`            | `AgentVisibility`      | Nu          | Implicit `workspace`                                                                                                                                                                                 |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Nu          | Starea de guvernanță (implicit `active`). Scrisă de oprirea dură a bugetului și afișată în organigramă și în lista de prezență. Trimiterea acceptă în continuare muncă de la un agent `paused`       |
| `budgetPolicyId`        | `String?`              | Nu          | Id-ul politicii de buget partajate; când este null, se aplică direct `monthlyBudgetCents`                                                                                                            |
| `runtimeProfileId`      | `String?`              | Nu          | Id-ul profilului de runtime personalizat                                                                                                                                                             |
| `createdAt`             | `DateTime`             | Da          | Marca temporală a creării                                                                                                                                                                            |

`name` și `title` trebuie să fie ambele ne-goale (verificat în constructor). Valoarea
implicită `0` a `monthlyBudgetCents` înseamnă nelimitat. Scrie un plafon cu `agents.upsert`.

| Valoare     | Descriere                                                    |
| ----------- | ------------------------------------------------------------ |
| `workspace` | Implicită; valorile stocate necunoscute și null se interpretează ca aceasta |
| `private`   | Privată pentru utilizatorul care a creat-o                    |

## Enumerarea AgentLifecycleStatus

| Valoare    | Descriere                                                                                                        |
| ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `active`   | Implicită. `isDispatchable` este true doar pentru această valoare                                                |
| `paused`   | Setată de oprirea dură a bugetului. Afișată în lista de prezență; trimiterea acceptă în continuare muncă         |
| `archived` | Retrasă și ascunsă din listele de prezență active                                                                |

## Permisiuni

Un agent nu are indicatori de permisiune. Push-ul, deschiderea și publicarea pull request-urilor, scrierea într-un tracker și ieșirea în rețea sunt clase de acțiuni (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) pe care [guardrail-urile](/ro-RO/manual/concepte/guardrail-uri/) le rezolvă la nivelul spațiului de lucru, al agentului sau al spațiului. Tokenul GitHub al unei rulări are întotdeauna acces doar la citire; push-urile trec prin gateway-ul rulărilor de agenți, care întreabă regula `gitPush` înainte de a le transmite.

## AgentSkills

Un set imuabil, insensibil la majuscule, de identificatori de skill-uri. La trimitere, aceste slug-uri sunt sincronizate ca legături de skill-uri în overlay-ul agentului; harness-ul încarcă apoi automat frontmatter-ul skill-urilor legate în prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (derivat)

Nu este stocat. Șapte valori. Ordinea declarării este ordinea de prioritate (`sortPriority`, fixată de un test), care este ordinea după care sortează lista de prezență:

| Stare       | `sortPriority` | Condiție                                                                                                              |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Orice jurnal de rulare are starea `running`                                                                           |
| `blocked`   | 1              | Vitalitatea ultimei rulări este `blocked`, `stalled` sau `looping`                                                    |
| `failed`    | 2              | Starea ultimei rulări este `error`, sau vitalitatea ei este `failed` sau `dead`                                       |
| `queued`    | 3              | O rulare este trimisă, dar nu se execută — parcată în spatele altei rulări a aceluiași agent, sau scrisă, dar încă nepornită |
| `succeeded` | 4              | Rularea s-a încheiat cu succes                                                                                        |
| `idle`      | 5              | Agentul a rulat deja și nu are nimic în curs                                                                          |
| `neverRun`  | 6              | Nu există niciun jurnal de rulare                                                                                     |

`queued` și `succeeded` sunt **doar per rulare**. `deriveAgentLiveState`, care calculează starea din lista de prezență pentru un agent, nu produce niciuna dintre ele — returnează `neverRun`, `running`, `failed`, `blocked` sau `idle`.
