Scurtăturile provin dintr-un singur registru `const`, `KeybindingRegistry` din `lib/core/constants/keybindings.dart`. El conține **49 de scurtături**. Setări → Tu → Scurtături afișează acel registru ca **referință doar în citire**: nu există interfață de reatribuire și niciun fișier de scurtături al utilizatorului.

`Cmd` de mai jos este modificatorul principal de comandă — ⌘ pe macOS, Ctrl pe Windows și Linux. O scurtătură se declanșează doar când comanda ei are un handler înregistrat pe ecranul curent și clauza ei `when` este îndeplinită; `!textInputFocus` înseamnă că tasta este transmisă mai departe unui câmp de text focusat.

Nu există nicio scurtătură de navigare cu taste numerice. Inbox-ul, tichetele, pull request-urile și restul se ating din bara laterală sau cu ⌘K. Nici Observabilitate nu are scurtătură.

## Global (19)

Domeniul `global`, deci sunt active oriunde în shell.

### Sistem

| Scurtătură                                  | Acțiune                                          | Condiție                                                   |
| ------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Paletă de comenzi                                | —                                                          |
| `Shift + /` (`?`)                           | Fișă de referință cu scurtăturile de tastatură   | Nu tastezi într-un câmp                                    |
| `Cmd/Ctrl + Z`                              | Anulează                                         | Nu tastezi într-un câmp (un câmp focusat își păstrează propria anulare) |
| `Cmd/Ctrl + Shift + Z`                      | Refă                                             | Nu tastezi într-un câmp                                    |
| `Cmd/Ctrl + Shift + T`                      | Comută tema                                      | —                                                          |
| `Cmd/Ctrl + ,`                              | Deschide setările (ajunge la `/settings/you/appearance`) | —                                                          |
| `Cmd/Ctrl + Shift + Alt + F`                | Comută modul focus                               | —                                                          |
| `Cmd/Ctrl + Shift + W`                      | Comută selectorul de spații de lucru             | —                                                          |
| `Cmd/Ctrl + ]`                              | Spațiul de lucru următor                         | —                                                          |
| `Cmd/Ctrl + [`                              | Spațiul de lucru anterior                        | —                                                          |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | Comută la spațiul de lucru 1–9                   | —                                                          |

## Lista de pull request-uri (3)

Domeniul `/pull-requests`. Toate cer `route == '/pull-requests'` și niciun câmp de text focusat, așa că nu se declanșează cât timp ruta de detaliu PR este deschisă peste listă.

| Scurtătură | Acțiune                  |
| ---------- | ------------------------ |
| `R`        | Reîmprospătează          |
| `Enter`    | Deschide PR              |
| `F`        | Deschide meniul de filtre |

`Enter` (`pr.list-open`) este declarat în registru și apare în referința de scurtături, dar **ecranul de listă nu înregistrează un handler pentru el**, așa că momentan nu se declanșează. `F` deschide meniul de filtre (`pr.list-open-filter`), nu căutarea.

## Detaliu de pull request (2)

Domeniul `/pull-requests/`. Reîmprospătarea nu cere niciun câmp de text focusat. Închiderea filei nu are gardă de introducere de text (o combinație cu ⌘ nu este niciodată text simplu) și are o expresie regulată de rută, ca să nu se declanșeze în listă.

| Scurtătură     | Acțiune   | Condiție                           |
| -------------- | --------- | ---------------------------------- |
| `R`            | Reîmprospătează | Nu tastezi într-un câmp       |
| `Cmd/Ctrl + W` | Închide fila | Pe o locație `/pull-requests/<…>` |

Comutarea filelor (`1`/`2`/`3`), marcarea ca vizualizat și plierea fișierului (`V`/`C`), lista de fișiere (`T`) și căutarea în diff (`Cmd/Ctrl + F`) aparțin handlerului propriu al vizualizatorului de diff — vezi [Scurtături ale vizualizatorului de diff din afara registrului](#scurtături-ale-vizualizatorului-de-diff-din-afara-registrului).

## Profiluri de utilizator și de echipă GitHub (3)

Domeniul `/users/`. Clauza `when` este o expresie regulată care se potrivește cu `/users/<login>` **sau** cu `/teams/<organization>/<slug>`, plus absența unui câmp de text focusat.

## Spații (9)

Domeniul `/spaces`. Clauzele `when` folosesc o expresie regulată, așa că se declanșează atât în lista de spații (`/spaces`), cât și într-un spațiu selectat (`/spaces/<id>`).

| Scurtătură             | Acțiune                        | Condiție              |
| ---------------------- | ------------------------------ | --------------------- |
| `Enter`                | Trimite mesajul                | —                     |
| `Cmd/Ctrl + N`         | Spațiu nou                     | Pe o rută `/spaces`   |
| `J`                    | Spațiul următor                | Nu tastezi într-un câmp |
| `K`                    | Spațiul anterior               | Nu tastezi într-un câmp |
| `Cmd/Ctrl + Shift + D` | Dictare cu apăsare pentru a vorbi | —                  |
| `Cmd/Ctrl + T`         | Deschide fila editorului       | Pe o rută `/spaces`   |
| `Cmd/Ctrl + W`         | Închide fila editorului        | Pe o rută `/spaces`   |
| `Cmd/Ctrl + B`         | Comută bara laterală a editorului | Pe o rută `/spaces` |
| `Cmd/Ctrl + P`         | Accesează fișierul                | Pe o rută `/spaces` |

„Accesează fișierul” deschide un selector peste fișierele conversației. Fără text introdus, listează fișierele deschise cel mai recent; tastarea caută în toate fișierele din worktree-urile conversației. `Enter` deschide fișierul selectat într-o filă nouă, `Cmd/Ctrl + Enter` sau butonul de împărțire de pe rând îl deschide într-un panou în dreapta, iar `×` de pe un rând recent îl elimină din listă.

Trimiterea cu Enter aparține câmpului de text al compozitorului; apăsarea pentru a vorbi aparține butonului de microfon al compozitorului (care are propriul handler de tastatură hardware). Ambele sunt listate în registru pentru referința din setări.

## Scurtături ale vizualizatorului de diff din afara registrului

Vizualizatorul de diff pentru PR le gestionează singur (`PrDiffKeyboardHandler`). Căutarea, marcarea ca vizualizat și plierea sunt listate în comentariile registrului doar pentru referința din setări — nu este înregistrat niciun handler în dispatcher, așa că dispatcherul le lasă în seama vizualizării de diff. Ele nu apar ca rânduri separate în referința de scurtături.

| Scurtătură      | Acțiune                                              |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Caută în diff                                        |
| `J` / `K`       | Fișierul următor / anterior                          |
| `V`             | Comută starea de vizualizat pe fișierul focusat      |
| `C`             | Comută plierea fișierului focusat                    |
| `T`             | Afișează lista de fișiere                            |
| `Enter`         | Potrivirea următoare (doar cât timp căutarea în diff este deschisă) |
| `Shift + Enter` | Potrivirea anterioară                                |
| `Escape`        | Închide căutarea în diff sau șterge selecția de text din diff |
| `Cmd/Ctrl + C`  | Copiază selecția din diff                            |

## Combinații rezervate de browser

În versiunea web, browserul consumă unele acceleratoare înainte ca pagina să le vadă, așa că scurtăturile corespunzătoare nu se pot declanșa niciodată acolo. Pe desktop funcționează normal. Sunt rezervate când sunt combinate cu modificatorul principal de comandă: `T`, `W`, `N` și cifrele `1`–`9`.

Asta acoperă comutarea între spațiile de lucru cu `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (spațiu nou, spațiu de lucru nou, agent nou, adaugă depozit) și `Cmd/Ctrl + T` / `Cmd/Ctrl + W` în spații și în detaliul PR-ului.
