Paginile de referință descriu **ce există**, exhaustiv și fără comentarii. Folosește-le
ca să cauți ceva atunci când știi deja ce urmărești: un nume exact de instrument,
un tip de pas, o tranziție de stare, o rută, o scurtătură.

Nu sunt scrise ca să fie citite de la un capăt la altul. Pentru asta, folosește
[conceptele](/ro-RO/manual/concepte/); ca să duci ceva la bun sfârșit, folosește
[ghidurile practice](/ro-RO/manual/ghiduri-practice/).

## Suprafața produsului

- [Instrumente MCP](/ro-RO/manual/referinta/instrumente-mcp/) — fiecare instrument pe care îl înregistrează serverul MCP, pe familii
- [Instrumente agent integrate](/ro-RO/manual/referinta/instrumente-agent/) — instrumente de harness legate de server (LSP, AST, debug, eval, vibe)
- [Comenzi slash](/ro-RO/manual/referinta/comenzi-slash/) — comenzi integrate ale compozitorului, `/skill:` și comenzi ale utilizatorilor
- [Hartă de rute](/ro-RO/manual/referinta/harta-de-rute/) — fiecare ecran și URL-ul care duce la el
- [Scurtături de tastatură](/ro-RO/manual/referinta/scurtaturi-de-tastatura/) — registrul complet de asocieri de taste
- [Evenimente de domeniu](/ro-RO/manual/referinta/evenimente-de-domeniu/) — fiecare eveniment publicat pe bus-ul de domeniu
- [Stații](/ro-RO/manual/referinta/statii/) — fiecare suprafață de stație, verb de acțiune, stare din ciclul de viață, port și valoare implicită
