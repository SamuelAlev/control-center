## Ce vei construi

La finalul acestui tutorial, vei avea:

- Un agent pe care l-ai creat și configurat singur
- Un spațiu în care vorbești tu și acel agent
- O rulare finalizată, cu muncă comisă într-un worktree izolat și un rând în jurnalul de rulare al agentului

Cerințe preliminare: [Primul tău spațiu de lucru](/ro-RO/manual/tutoriale/primul-spatiu-de-lucru/) finalizat, astfel încât acest spațiu de lucru să aibă un repo înregistrat și cel puțin un furnizor de modele conectat.

## Pasul 1: Creează un agent

1. Mergi la **Setări → Spațiu de lucru → Agenți**
2. Apasă pe **Agent nou**. Un agent numit „Agent fără nume” este creat imediat și selectat în listă — nu există niciun dialog de creare și nimic de confirmat. Îl configurezi pe loc.
3. În fila **Setări**, completează:
   - **Nume**: ceva scurt și memorabil, cum ar fi `alice`. Este ceea ce tastezi după `@`.
   - **Titlu**: ce face, de ex. „Inginer backend”
   - **Adaptor**: `Control Center (built-in)`. Alege-l deliberat — doar harness-ul încorporat poate fi dirijat în timpul rulării și pus pe pauză la limita unui tur și nu are nevoie de niciun CLI instalat pe gazda serverului.
   - **Model**: alege din lista pe care o servește furnizorul conectat
   - **Abilități**: atașează-le pe cele potrivite, de ex. `testing` sau `architecture`
4. Apasă **Salvează modificările**

:::note[Un agent fără adaptor rulează pe bucla încorporată]
Când câmpul Adaptor nu este completat, trimiterea revine la **Control Center (built-in)** — bucla de agent din interiorul serverului, așa că nu este nimic de instalat pe gazdă. Are totuși nevoie de un model: dacă nu este setat niciunul, cere modelul implicit de la Anthropic, ceea ce funcționează dacă ai conectat un cont Anthropic și altfel eșuează cu `No credential for provider "anthropic"`. Setează-le oricum pe amândouă în mod explicit, altfel vei rula pe un model pe care nu l-ai ales.
:::

**Punct de control.** Rândul din listă arată numele agentului tău și un inel de stare gol.

## Pasul 2: Pornește un spațiu

1. În bara laterală, găsește secțiunea **Spații** și apasă butonul **+**
2. Dă un nume spațiului
3. Sub **Adaugă agenți**, selectează agentul pe care tocmai l-ai creat
4. Dacă spațiul de lucru are repo-uri, alege pe care dintre ele să lucreze acest spațiu
5. Apasă **Creează**

Spațiul se deschide. În fundal, Control Center creează un worktree copy-on-write al repo-urilor selectate pentru această conversație, pe propria lui ramură. Checkout-ul tău sursă nu este niciodată modificat.

## Pasul 3: Trimite o sarcină

Tastează o sarcină concretă și mică pentru repo-ul pe care l-ai înregistrat. Ceva cu un rezultat verificabil funcționează cel mai bine — adaugă un test, corectează un lint, redenumește un simbol.

Apasă Enter. Nu este nevoie să menționezi pe nimeni cu `@`: cu un singur agent în spațiu, un mesaj simplu îl trezește. Într-un spațiu cu mai mulți agenți, `@name` alege unul.

Control Center compune promptul din instrucțiunile agentului, persona lui, skill-urile lui și contextul spațiului, apoi trimite rularea.

**Punct de control.** Butonul de trimitere al composerului se transformă în buton de oprire — un agent lucrează în această conversație — și începe să sosească text.

## Pasul 4: Privește-l cum lucrează

Conversația afișează rularea pe măsură ce se desfășoară:

- **Raționament**, afișat în linie în timp ce agentul gândește
- **Apeluri de instrumente**: citiri și scrieri de fișiere, căutări, comenzi shell, fiecare cu rezultatul lui
- **Text**: rezumate, explicații și întrebări pentru tine

Dacă agentul întreabă ceva, răspunde în conversație și își reia lucrul.

Pentru metricile proprii unei rulări și comenzile ei de pauză, reluare și oprire, găsește agentul aflat în rulare în secțiunea **Agenți** din panoul General al spațiului și alege **Deschide activitatea**.

În panoul de activitate, insigna de stare afișează **În rulare**, apoi **Reușit** când rularea se încheie. O rulare care se blochează sau intră în buclă afișează **Blocat**; una care dă eroare afișează **Eșuat**. În registrul de agenți, inelul din listă este gol înainte de prima rulare și plin odată ce agentul redevine inactiv.

Ce limitează rularea: propriul worktree copy-on-write, datele de autentificare intermediate pentru ea la lansare și revocate la desființare, un mediu sanitizat, suprafața de instrumente pe care o permite modul ei și guardrail-urile de acțiune. Efectele precum împingerea unei ramuri sau deschiderea unui pull request trec printr-o poartă separată — vezi [Guardrail-uri](/ro-RO/manual/concepte/guardrail-uri/).

## Pasul 5: Verifică rezultatul

1. Deschide **Setări → Spațiu de lucru → Agenți** și selectează-ți agentul
2. Deschide fila **Jurnale**

**Punct de control.** Un rând de rulare, care arată starea, durata, orele de început și de sfârșit și adaptorul pe care a rulat.

Modificările agentului sunt comise pe ramura conversației, în worktree-ul ei. Commit-urile sunt scrise ca agentul, iar tu ești creditat într-un trailer `Co-Authored-By:`.

## Obținerea unui pull request

Nimic nu deschide un pull request de la sine. Dacă vrei unul, cere-l în aceeași conversație:

> Împinge această ramură și deschide un pull request către ramura implicită.

Împingerea (`gitPush`) și crearea de PR (`prCreate`) cer implicit aprobarea ta, așa că așteaptă-te la o confirmare înainte de fiecare. Dacă niciun aprobator nu este conectat când se declanșează cererea, acțiunea este refuzată, nu permisă — guardrail-urile eșuează închis.

PR-ul este deschis sub identitatea GitHub al cărei token a fost folosit de rulare — a ta, dacă ai stocat un token personal — nu sub numele agentului. Paternitatea agentului apare pe commit-uri.

Îl poți deschide și singur: panoul **Control sursă** al spațiului are un buton **Creează pull request** care aduce ramura conversației în ecranul de compunere, iar **Pull request-uri → PR nou** deschide același ecran gol. De aici continuă următorul tutorial.

## Recapitulare

Ai creat un agent, i-ai configurat adaptorul și modelul, i-ai dat un spațiu și o sarcină și ai privit cum o rulare reală se încheie într-un worktree izolat fără să atingi checkout-ul.

**În continuare:** [Revizuiește primul pull request](/ro-RO/manual/tutoriale/primul-pr/) ca să înveți fluxul de revizuire.
