Acest ghid arată cum să configurezi notificările și ce controlează de fapt
fiecare setare.

Notificările sosesc pe două suprafețe. **Centrul de notificări** — clopoțelul din
bara de titlu — citește un flux durabil, pe spațiu de lucru, de pe server.
**Toast-urile OS** sunt o cale separată, doar pentru desktop, alimentată de
cadre live trimise de pe server.

:::note[Versiunea web nu afișează notificări OS]
Conducta de toast-uri este construită doar de bootstrap-ul de desktop. Pe
`app.usectrl.dev` nu există toast-uri OS, nici sunete de notificare și nici
bannere ambientale — clopoțelul și istoricul lui funcționează în continuare,
pentru că citesc fluxul de pe server. Clientul pentru telefon nu are deloc
suprafață de notificări.
:::

## Activează sau dezactivează categorii

1. Mergi la **Setări → Tu → Notificări**
2. Lasă **Activează notificările** activat
3. Comută categoriile dorite. Sunt exact șaisprezece:

| Categorie                        | Se declanșează când                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| Agentul a terminat               | Un agent a răspuns într-o rulare pornită de tine sau rularea a eșuat                 |
| PR publicat                      | Un agent a publicat un PR                                                            |
| PR fuzionat                      | Un PR a fost fuzionat                                                                |
| Mesaje noi                       | Cineva te-a menționat într-un spațiu                                                 |
| Menționat într-un pull request   | Interogarea de notificări a GitHub a văzut că ești menționat într-un PR              |
| Revizuire solicitată             | Revizuirea ta a fost chiar solicitată pe un PR care nu este ciornă                   |
| Revizuire învechită              | Au aterizat commit-uri noi pe un pull request pe care l-ai revizuit deja             |
| Gata de fuziune                  | Un pull request pe care l-ai scris a devenit fuzionabil sau a încetat să fie         |
| Decizii de revizuire             | Un recenzent a aprobat, a cerut modificări sau i-a fost respinsă o aprobare          |
| Verificări                       | CI a eșuat pe un pull request pe care l-ai scris sau și-a revenit                    |
| Fire de revizuire                | Cineva a răspuns într-un fir în care ești sau l-a rezolvat                           |
| Tichet asignat                   | Un tichet a fost asignat                                                             |
| Starea tichetului s-a schimbat   | Un tichet și-a schimbat starea                                                       |
| Întâlnirea începe curând         | O întâlnire din calendar este în fereastra ta de avans                               |
| Calendar deconectat              | Tokenul OAuth al unui calendar conectat a expirat                                    |
| Actualizări mediu izolat         | Un mediu izolat a fost preluat, recuperat sau a eșuat                                |

Orice în afara acestei liste nu poate fi notificat sau filtrat — nu există o
categorie „toate celelalte”.

Aceste preferințe te însoțesc pe toate dispozitivele, așa că telefonul și
laptopul rămân în pas. Volumul este excepția deliberată și rămâne per dispozitiv.

## Setează orele de liniște

1. Pe aceeași pagină, activează **Quiet hours**
2. Tastează o oră de început și una de sfârșit în format `HH:MM` (fereastra
   implicită este 22:00–08:00)

În timpul orelor de liniște, notificările neurgente sunt eliminate — nu puse în
coadă și redate mai târziu.

Două categorii sunt **urgente** și se livrează întotdeauna, ocolind orele de
liniște _și_ modul focus: **Întâlnirea începe curând** și **PR publicat**. O
alertă de întâlnire pe care o vezi abia după aceea nu are nicio valoare, iar
acesta este motivul.

## Alege un sunet

1. Derulează până la **Sunet de notificare**
2. Alege unul dintre cele unsprezece sunete incluse sau **Niciunul**
3. Apasă butonul de test pentru a-l auzi și setează volumul cu glisorul

Aplicația redă sunetul ea însăși; notificarea OS este livrată în tăcere, așa că
nu îl auzi niciodată de două ori.

## Setează timpul de avans pentru întâlniri

1. Derulează până la **Timp de avans al alertei**
2. Alege **5**, **10**, **15** sau **30** de minute

Atât de devreme înainte de un eveniment din calendar se declanșează notificarea
**Întâlnirea începe curând**. Valoarea implicită este 5 minute.

## Află când o notificare este suprimată

O notificare este eliminată, în tăcere, când oricare dintre acestea este
adevărată:

- Notificările sunt oprite global sau categoria ei este oprită
- Ești deja pe ruta către care te-ar duce — și, pentru un mesaj, deja în acel
  spațiu
- Modul focus este activ și categoria nu este urgentă
- Orele de liniște sunt active și categoria nu este urgentă

Aceste verificări se aplică toast-urilor OS. Clopoțelul durabil înregistrează
totuși evenimentul.

Încă două suprimări există mai în amonte, în ceea ce trimite serverul de la bun
început:

- Un mesaj în care nu ești menționat, de la o altă **persoană**, nu devine
  niciodată o notificare
- Într-un spațiu partajat, răspunsul unui agent o anunță pe persoana care a
  pornit rularea, nu pe fiecare membru
- Spațiile agent-la-agent sunt dezactivate în bara laterală, așa că nu
  incrementează niciodată badge-ul de necitite al persoanei

Într-un spațiu nu există niciun colț liniștit: fiecare conversație notifică la
fel, inclusiv firele. Starea de citire este limitată la spațiu, așa că necititele
se cumulează pe conversațiile unui spațiu, în loc să fie urmărite per
conversație.

## Citește și golește centrul de notificări

1. Dă clic pe clopoțelul din bara de titlu

Popover-ul arată activitatea recentă, cu link direct din fiecare intrare către
subiectul ei. Deschiderea lui **nu** marchează totul ca citit — folosește
**Marchează tot ca citit** din antet sau marchează un singur rând. Starea de
citire te însoțește pe toate dispozitivele.

:::note[Golește tot este un marcaj, nu o ștergere]
**Golește tot** aplică un marcaj per utilizator care ascunde tot ce este mai
vechi; rândurile rămân. Separat, fiecare spațiu de lucru păstrează doar cele mai
recente **200** de rânduri de flux, curățate pe măsură ce sosesc altele noi, în
timp ce clopoțelul se abonează la cele mai noi **50**, iar popover-ul afișează
până la **15** dintre ele. Istoricul de dinainte a dispărut, indiferent de
starea de citire.
:::

## Depanare

### Nicio notificare OS pe macOS

Autorizarea este solicitată nativ la lansarea aplicației. Dacă ai refuzat-o,
reactivează Control Center din Setări sistem → Notificări; nu există niciun
prompt în aplicație care să o declanșeze din nou.

### Nu ajunge nimic în versiunea web

Așteptat — versiunea web nu are nicio conductă de notificări OS. Folosește
clopoțelul.

### Badge-ul clopoțelului arată zero, dar există clar activitate nouă

Până când fluxul de marcaje de citire se rezolvă după conectare, intrările sunt
afișate ca citite pentru a evita un badge care clipește și apoi se golește. Se
stabilizează odată ce marcajul se încarcă.

### Rularea unui agent s-a terminat, dar nu m-a anunțat nimic

Verifică dacă nu erai deja în spațiul în care s-a întâmplat — o rută activă își
suprimă propriul toast OS. Într-un spațiu partajat, o rulare pornită de altcineva
îl anunță pe acela, nu pe tine. O tură încheiată fără răspuns și fără eroare nu
trimite nimic.
