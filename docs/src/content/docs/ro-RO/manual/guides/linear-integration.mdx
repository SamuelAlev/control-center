Lipește o cheie API Linear pe server, asociată utilizatorului tău, exact la fel
cum conectezi un forge. Tichetele, proiectele, legăturile, colaboratorii,
delegarea și atribuirea funcționează toate pe baza propriei baze de date a
Control Center, fără să fie nevoie de vreun serviciu extern — vezi
[Creează și gestionează tichete](/ro-RO/manual/ghiduri-practice/gestioneaza-tichete/).

## Stochează cheia Linear

**Cheie API ticketing** se află în **Setări → Spațiu de lucru → General**, pe
cardul **Ticketing**. Ea stochează cheia pe server, asociată ID-ului tău de
utilizator. Cheia proprie a serverului pentru lucrul nesupravegheat provine din
`LINEAR_API_KEY` sau din cardul **Aplicații provider**. Nicio cheie de ticketing
nu este pusă în sandbox-ul unui agent: agenții scriu tichete prin instrumentele
proprii ale Control Center, care întreabă mai întâi regula **Scrie într-un
tracker extern**.

## Marchează tichetele noi ca Linear

**Provider de ticketing** (primul pas din onboarding și
`/workspaces/<workspaceId>/api-keys`) oferă `local` și `linear`. Alegerea
variantei `linear` marchează cu `provider: linear` tichetele pe care le creezi
de acum înainte.
