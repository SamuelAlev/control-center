Acest ghid îți arată cum să revii la un punct anterior dintr-o conversație și să o duci în altă direcție — păstrând totodată calea pe care ai părăsit-o.

## Singurul lucru care merită știut

**Ramificarea nu scrie nimic.** O conversație este un arbore de mesaje cu un pointer în vârf, iar întoarcerea înapoi mută pointerul. Nimic nu este șters, nimic nu este ascuns, iar comutarea înapoi este o altă mutare de pointer.

De aceea, editarea unui prompt și rularea lui din nou este sigură aici: răspunsul cu care îl comparai este încă acolo.

## Vezi ramurile

```
/tree
```

Navigatorul listează fiecare mesaj, indentat la fiecare bifurcare, cu calea curentă marcată **Pe această ramură**. O conversație care nu a fost niciodată bifurcată se afișează ca lista plată care a fost dintotdeauna — navigatorul nu costă nimic privit până când nu există ceva de navigat.

Fiecare rând oferă două acțiuni.

| Acțiune                          | Efect                                                    |
| ------------------------------- | --------------------------------------------------------- |
| **Continuă de aici**          | Mută pointerul. Următorul tău mesaj continuă din acel mesaj. |
| **Bifurcă într-o conversație nouă** | Copiază calea până la acel mesaj într-o conversație nouă. |

## Ramură: încearcă o abordare diferită

1. `/tree`
2. Găsește mesajul de la care vrei să reîncepi — de obicei ultimul care ți-a convenit.
3. **Continuă de aici.**
4. Scrie noul prompt.

Continuarea veche este încă în arbore; `/tree` va arăta acum două căi din acel punct, iar tu poți comuta liber între ele.

:::note[Calea pe care ai părăsit-o este încă acolo]
Ramificarea nu ascunde și nu șterge nimic. `/tree` listează fiecare cale, o marchează pe cea curentă cu **Pe această ramură** și este modalitatea prin care comuți.
:::

## Bifurcare: du-o în altă parte

Bifurcarea copiază calea într-o **conversație nouă** din același spațiu. Folosește-o atunci când cele două direcții vor continua să divergă și le vrei una lângă alta, în loc să comuți.

Copia are id-uri de mesaj noi. Două conversații care ar partaja rânduri ar arăta mesajele ulterioare ale celeilalte, iar asta este exact lucrul pe care o bifurcare trebuie să îl împiedice.

## Revert versus ramură

Sunt instrumente diferite, iar diferența contează.

|                     | Revert                                             | Ramură                          |
| ------------------- | -------------------------------------------------- | ------------------------------- |
| Mesajele ulterioare  | Ascunse din transcript                          | Încă vizibile în `/tree`         |
| **Worktree**-ul    | Revenit la snapshotul acelui tur                 | Neatins                        |
| Anulare                | **Anulează revertul** restaurează lotul                  | Mută pointerul înapoi            |

Revert este ceea ce vrei atunci când agentul a modificat *fișiere* pe care vrei să le recuperezi. Ramura este ceea ce vrei atunci când conversația a luat-o în direcția greșită, dar fișierele sunt în regulă.

Revenirea mută și vârful ramurii, așa că următorul tău mesaj continuă din locul potrivit, nu dintr-o coadă pe care nu o mai vede nimeni.

## Scoate-o din aplicație

### `/export`

Scrie un **fișier HTML autonom**: întreaga conversație, cu carduri de instrument pliabile care arată ce a primit fiecare apel și ce a returnat. Fără foaie de stil, fără script, fără gazdă de imagini — funcționează de pe un stick USB și va funcționa și peste cinci ani.

- **Desktop:** `Documents/ControlCenter/exports/`, cu marcă de timp, astfel încât un al doilea export să nu îl suprascrie pe primul.
- **Web:** o descărcare în browser.

### `/dump`

Copiază transcriptul în clipboard ca markdown, cu apelurile de instrument în blocuri pliabile. Acesta este cel pe care să îl lipești într-un issue.

Raționamentul este lăsat deoparte în mod deliberat: este spațiul de lucru al modelului, iar un raport de eroare este citit de o persoană.
