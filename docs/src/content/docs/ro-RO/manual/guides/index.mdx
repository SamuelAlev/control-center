Fiecare ghid rezolvă **o problemă pentru cineva care știe deja să se descurce**.
Ghidurile presupun că ai Control Center instalat și un spațiu de lucru configurat,
enunță un obiectiv în titlu și se opresc atunci când obiectivul este atins.

Dacă încă înveți produsul, începe cu [tutorialele](/ro-RO/manual/tutoriale/).
Dacă vrei să înțelegi _de ce_ ceva se comportă într-un anumit fel, citește
[conceptele](/ro-RO/manual/concepte/).
