Collez une clé API Linear sur le serveur pour votre utilisateur, de la même
manière que vous connectez un hébergeur de code. Les tickets, les projets, les
liens, les collaborateurs, la délégation et l’attribution s’appuient tous sur la
base de données propre à Control Center, sans qu’aucun service externe ne soit
nécessaire — voir [Créer et gérer des
tickets](/fr-FR/manuel/guides/gerer-tickets/).

## Enregistrer votre clé Linear

**Clé API de ticketing** se trouve dans **Paramètres → Espace de travail →
Général**, sur la carte Tickets. Elle stocke la clé sur le serveur en
l’associant à votre identifiant utilisateur. La clé propre au serveur, destinée
au travail sans intervention, provient de `LINEAR_API_KEY` ou de la carte
**Applications fournisseur**, et n’est injectée sous le nom `TICKETING_API_KEY`
que lorsque cet agent dispose de la capacité **Autoriser les appels API de
tickets**.

## Marquer les nouveaux tickets comme Linear

**Fournisseur de tickets** (première étape de l’intégration initiale, et
`/workspaces/<workspaceId>/api-keys`) propose `local` et `linear`. Choisir
`linear` appose `provider: linear` sur les tickets que vous créez à partir de ce
moment.
