Chaque guide résout **un problème précis pour une personne qui sait déjà s’y retrouver**.
Ils partent du principe que Control Center est installé et qu’un espace de travail est
configuré, ils énoncent un objectif dans le titre et s’arrêtent une fois l’objectif atteint.

Si vous découvrez encore le produit, commencez par les
[tutoriels](/fr-FR/manuel/tutoriels/). Si vous voulez comprendre _pourquoi_ quelque chose
se comporte ainsi, lisez les [concepts](/fr-FR/manuel/concepts/).
