Ce guide vous montre comment utiliser les espaces. Un **espace** est la surface
de messagerie de Control Center : un salon rattaché à un espace de travail, avec
un ou plusieurs participants (vous et/ou des agents), qui possède un arbre de
travail en copie sur écriture par dépôt pour lequel il a été créé.

Les salons en tête-à-tête et les salons multi-agents ne sont que des espaces,
distingués uniquement par le nombre de participants. La seule exception : les
espaces que les agents ouvrent pour se parler — voir [Espaces entre
agents](#espaces-entre-agents) ci-dessous.

## Créer un espace

1. Accédez à **Espaces**
2. Cliquez sur le bouton **+** à côté du titre Espaces
3. Donnez-lui un **nom** — obligatoire. Un nom vide est refusé ; la boîte de
   dialogue reste ouverte
4. Ajoutez éventuellement des agents de l’espace de travail
5. Si l’espace de travail contient des dépôts, choisissez ceux pour lesquels cet
   espace provisionne des arbres de travail. Tous sont sélectionnés par défaut ;
   désélectionner tous les dépôts crée un espace où rien n’est extrait
6. Confirmez

Les espaces sont rattachés à un espace de travail : vous ne voyez que les agents
de l’espace de travail courant, et un espace n’expose jamais de données
provenant d’un autre espace de travail.

Chaque dépôt est extrait dans `repos/<name>/` à l’intérieur de l’espace. Un
dépôt qui embarque ses propres skills d’agent les met à la disposition de
l’agent qui y travaille — un seul ensemble de dépôt à la fois, permuté au fil
des déplacements de l’agent. Depuis le compositeur, vous pouvez atteindre
n’importe lequel d’entre eux avec `/skill:<repo>:<name>`. Voir
[Skills limités au dépôt](/fr-FR/manuel/concepts/modele-agent/#repo-scoped-skills).

La surface se trouve à l’adresse `/workspaces/<id>/spaces`, et un espace donné à
`/workspaces/<id>/spaces/<spaceId>`.

## Définir le mode de l’espace

Un nouvel espace démarre dans le mode par défaut. Changez-le depuis le **menu
déroulant des modes**, à l’extrême gauche de la barre d’outils du compositeur —
ni depuis la boîte de dialogue de création (qui n’a pas de champ de mode), ni
depuis l’en-tête de l’espace.

| Mode            | Effet                                                                                                                |
| --------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Agent**       | Accès complet. Le mode par défaut ; `chat` en interne, affiché sous le nom « Agent » dans le menu déroulant          |
| **Plan**        | Lecture et recherche uniquement ; le livrable est un plan typé                                                       |
| **Orchestrate** | Lecture et recherche, plus un unique verbe `propose_orchestration` ; le plan ne s’exécute qu’après votre approbation |

Shift+Tab bascule entre le mode plan et le mode agent sans ouvrir le menu
déroulant.

Un quatrième mode, **review**, existe mais n’est pas proposé dans le menu
déroulant — il est appliqué automatiquement aux espaces de revue de PR.

Le mode est stocké sur l’espace : un même agent peut donc être en mode plan dans
un espace et en mode agent dans un autre. Toutes les conversations d’un espace
partagent le mode de cet espace.

:::caution[Surveillez le badge d’application du mode]
Un badge apparaît à côté du menu déroulant des modes lorsque les agents de
l’espace s’exécutent sur un adaptateur incapable d’imposer le mode que vous avez
choisi. Seul le harnais intégré de Control Center filtre la surface d’outils et
contrôle chaque appel ; les adaptateurs Claude Code et ACP reçoivent le mode
sous forme de requête, que leur exécuteur peut honorer ou non. L’absence de
badge signifie « aucune garantie n’est avancée », et non « vérifié sûr ».
:::

Voir [Modes](/fr-FR/manuel/concepts/modes/) pour le modèle complet.

## Gérer les participants et l’autonomie par agent

Cliquez sur l’icône des personnes dans l’en-tête de l’espace pour ouvrir
**Gérer les participants**. Pour chaque agent déjà présent dans l’espace, vous
pouvez :

- Le retirer de l’espace
- Définir son **Autonomie** pour cet espace : **Par défaut**, **Proposer
  uniquement**, **Agir avec approbation** ou **Agir librement**

Le curseur d’autonomie s’applique par couple (espace, agent) : un agent auquel
vous faites confiance dans un salon peut donc être limité à « proposer
uniquement » dans un autre.

## Réagir à un message

Survolez un message et cliquez sur l’icône de sourire pour ouvrir la palette de
réactions. Elle forme un ensemble fixe de six réactions : 👍 👎 🎉 ❤️ 👀 ✅. Il
n’existe pas de sélecteur d’emoji libre — toucher une réaction l’active ou la
désactive pour vous, et les puces agrégées apparaissent sous le message.

## Ouvrir une conversation

Un espace héberge plusieurs conversations à la fois, toutes sur un pied
d’égalité — aucune n’est principale. Un espace conserve toujours au moins une
conversation active : vous ne pouvez pas archiver la dernière conversation
active, et ouvrir un espace qui n’en a encore aucune crée une conversation
permanente sans titre.

Les conversations apparaissent sous forme d’onglets dans l’éditeur, et sous
forme de lignes imbriquées sous l’espace dans la barre latérale dès qu’il y en a
plus d’une. **Nouvelle conversation** se trouve dans le menu de nouvel onglet de
l’éditeur et crée une conversation sans titre, sans demande de titre — le modèle
de titre la nomme d’après le premier message. Utilisez-en une pour mener un
travail parallèle avec le même agent et le même arbre de travail.

Chaque conversation conserve son propre historique de messages et ses propres
sessions d’agent, tout en partageant les arbres de travail et le mode de
l’espace. Fermer un onglet le masque ; **Archiver la conversation** (ligne de la
barre latérale ou menu contextuel de l’onglet de chat) n’archive que cette
conversation.

## Démarrer un fil

Survolez n’importe quel message et choisissez **Démarrer un fil**. Cela ouvre
une conversation ancrée à ce message : l’ancre initialise le contexte d’agent de
la nouvelle conversation avec une seule ligne, et l’historique de la
conversation parente n’est **pas** copié.

Dès qu’un fil a des réponses, le message auquel il est rattaché gagne une ligne
juste en dessous — les visages de ceux qui ont pris la parole, le nombre de
réponses et le moment où la dernière réponse est arrivée. Cette ligne est le
chemin de retour : cliquer dessus ouvre (ou met au premier plan) l’onglet du
fil. C’est la seule trace qu’un fil laisse dans le flux dont il a bifurqué, et
c’est bien pour cela qu’elle existe.

L’onglet d’un fil s’intitule `Thread: <name>` et porte le glyphe de branche, de
sorte que deux onglets d’un même espace ne sont jamais confondus.

Les fils ne s’imbriquent jamais — s’ancrer à un message déjà situé dans un fil
est refusé. L’en-tête de la conversation renvoie au message d’ancrage. Supprimer
le message d’ancrage supprime le fil, et archiver la conversation parente ne
bloque pas ses fils existants.

## État de lecture

Les marques de lecture sont limitées à l’espace, et non à la conversation :
ouvrir n’importe quelle conversation de l’espace efface les non-lus de tout le
salon. Les non-lus s’agrègent toujours sur l’ensemble des conversations d’un
espace, fils compris. Lorsque les conversations sont listées sous l’espace, le
point de non-lu se place sur la conversation qui contient du travail non vu, et
non sur la ligne parente.

## Espaces entre agents

Les espaces que les agents ouvrent pour se parler sont regroupés à part dans la
barre latérale, sous **Agents**, repliés par défaut et affichés en grisé. Ils
n’incrémentent jamais votre pastille de non-lus — le bavardage des agents est
silencieux par construction, et non grâce à un réglage que vous devez trouver.

Le type d’un espace prend l’une de cinq valeurs : `topic` (la valeur par défaut
de tout ce que vous créez), `agentPeer`, `system` (géré par un pipeline), `pr`
(créé lorsqu’une surface de PR a besoin d’une ancre d’arbre de travail, et
masqué de la barre latérale tant qu’il n’a pas de messages) et `slack` (créé par
la passerelle de chat pour un fil Slack ou un message privé de robot, et traité
comme une conversation humaine ordinaire).
