Les pages de référence décrivent **ce qui existe**, de façon exhaustive et sans commentaire.
Utilisez-les pour retrouver une information précise lorsque vous savez déjà ce que vous
cherchez : le nom exact d’un outil, un type d’étape, une transition de statut, une route, un
raccourci.

Elles ne sont pas faites pour être lues d’un bout à l’autre. Pour cela, consultez les
[concepts](/fr-FR/manuel/concepts/) ; pour accomplir une tâche, consultez les
[guides pratiques](/fr-FR/manuel/guides/).

## La surface produit

- [Outils MCP](/fr-FR/manuel/reference/outils-mcp/) — tous les outils que le serveur MCP enregistre, par famille
- [Outils d’agent intégrés](/fr-FR/manuel/reference/outils-agent/) — outils de harnais liés au serveur (LSP, AST, debug, eval, vibe)
- [Commandes slash](/fr-FR/manuel/reference/commandes-slash/) — les commandes intégrées du composeur, `/skill:` et les commandes utilisateur
- [Carte des routes](/fr-FR/manuel/reference/carte-des-routes/) — chaque écran et l’URL qui y mène
- [Raccourcis clavier](/fr-FR/manuel/reference/raccourcis-clavier/) — le registre complet des raccourcis clavier
- [Événements de domaine](/fr-FR/manuel/reference/evenements-de-domaine/) — chaque événement publié sur le bus d’événements de domaine
- [Rigs](/fr-FR/manuel/reference/rigs/) — chaque surface de rig, verbe d’action, état de cycle de vie, port et valeur par défaut
