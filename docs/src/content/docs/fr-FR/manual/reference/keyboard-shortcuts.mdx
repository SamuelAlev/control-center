Les raccourcis proviennent d’un unique registre `const`, `KeybindingRegistry`, dans `lib/core/constants/keybindings.dart`. Il contient **48 raccourcis**. Paramètres → Vous → Raccourcis clavier affiche ce registre sous forme de **référence en lecture seule** : il n’existe aucune interface de réaffectation ni aucun fichier de raccourcis utilisateur.

Dans la suite de cette page, `Cmd` désigne le modificateur de commande principal — ⌘ sous macOS, Ctrl sous Windows et Linux. Un raccourci ne se déclenche que si sa commande dispose d’un gestionnaire enregistré sur l’écran courant et si sa clause `when` est vraie ; `!textInputFocus` signifie que la touche est transmise à un champ de texte qui a le focus.

Il n’existe aucun raccourci de navigation par les touches numériques. La boîte de réception, les tickets, les demandes de tirage et le reste s’atteignent depuis la barre latérale ou avec ⌘K. L’observabilité n’a pas de raccourci non plus.

## Global (19)

Portée `global` : ils sont donc actifs partout dans le shell.

| Raccourci                                   | Action                                              | Condition                                                       |
| ------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------- |

| `Cmd/Ctrl + Z`                              | Annuler                                             | Ne pas saisir dans un champ (un champ qui a le focus conserve sa propre annulation) |

## Liste des demandes de tirage (3)

Portée `/pull-requests`. Tous exigent `route == '/pull-requests'` et qu’aucun champ de texte n’ait le focus ; ils ne se déclenchent donc pas lorsque la route de détail d’une PR est ouverte par-dessus la liste.

| Raccourci | Action                |
| --------- | --------------------- |
| `R`       | Actualiser            |
| `Enter`   | Ouvrir la PR          |
| `F`       | Ouvrir le menu de filtres |

`Enter` (`pr.list-open`) est déclaré dans le registre et figure dans la référence des raccourcis, mais **l’écran de liste n’enregistre aucun gestionnaire pour cette touche**, il ne se déclenche donc pas actuellement. `F` ouvre le menu de filtres (`pr.list-open-filter`), et non la recherche.

## Détail d’une demande de tirage (2)

Portée `/pull-requests/`. L’actualisation exige qu’aucun champ de texte n’ait le focus. La fermeture d’onglet n’a pas de garde de saisie de texte (une combinaison modifiée par ⌘ n’est jamais du texte brut) et dispose d’une expression régulière de route, si bien qu’elle ne se déclenche pas sur la liste.

| Raccourci      | Action         | Condition                              |
| -------------- | -------------- | -------------------------------------- |
| `R`            | Actualiser     | Ne pas saisir dans un champ            |
| `Cmd/Ctrl + W` | Fermer l’onglet | Sur un emplacement `/pull-requests/<…>` |

Le changement d’onglet (`1`/`2`/`3`), le marquage « vu » et le repli d’un fichier (`V`/`C`), la liste des fichiers (`T`) et la recherche dans le diff (`Cmd/Ctrl + F`) sont gérés par le gestionnaire propre à la visionneuse de diff — voir [Touches de la visionneuse de diff hors du registre](#touches-de-la-visionneuse-de-diff-hors-du-registre).

## Profils d’utilisateur et d’équipe GitHub (3)

Portée `/users/`. La clause `when` est une expression régulière appliquée à `/users/<login>` **ou** `/teams/<organization>/<slug>`, et exige en plus qu’aucun champ de texte n’ait le focus.

| Raccourci      | Action              |
| -------------- | ------------------- |
| `R`            | Actualiser          |
| `/`            | Aller à la recherche |
| `Cmd/Ctrl + F` | Aller à la recherche |

## Espaces (8)

Portée `/spaces`. Les clauses `when` utilisent une expression régulière, si bien qu’ils se déclenchent à la fois sur la liste des espaces (`/spaces`) et sur un espace sélectionné (`/spaces/<id>`).

| Raccourci              | Action                             | Condition             |
| ---------------------- | ---------------------------------- | --------------------- |
| `Enter`                | Envoyer le message                 | —                     |
| `Cmd/Ctrl + N`         | Nouveau espace                     | Sur une route `/spaces` |
| `J`                    | Espace suivant                     | Ne pas saisir dans un champ |
| `K`                    | Espace précédent                   | Ne pas saisir dans un champ |
| `Cmd/Ctrl + Shift + D` | Dictée par appui pour parler       | —                     |
| `Cmd/Ctrl + T`         | Ouvrir un onglet d’éditeur         | Sur une route `/spaces` |
| `Cmd/Ctrl + W`         | Fermer l’onglet d’éditeur          | Sur une route `/spaces` |
| `Cmd/Ctrl + B`         | Basculer la barre latérale de l’éditeur | Sur une route `/spaces` |

L’envoi par Entrée est géré par le champ de texte du compositeur de messages ; l’appui pour parler est géré par le bouton micro du compositeur (son propre gestionnaire de clavier physique). Les deux figurent dans le registre pour la référence des paramètres.

## Sélecteur d’espace de travail (2)

| Raccourci      | Action                          |

| `Cmd/Ctrl + N` | Nouvel espace de travail        |
| `Enter`        | Ouvrir l’espace de travail      |

`Enter` exige qu’aucun champ de texte n’ait le focus.

## Touches de la visionneuse de diff hors du registre

La visionneuse de diff des PR gère ces touches elle-même (`PrDiffKeyboardHandler`). La recherche, l’état « vu » et le repli figurent dans les commentaires du registre uniquement pour la référence des paramètres — aucun gestionnaire de répartiteur n’est enregistré, le répartiteur les laisse donc à la vue de diff. Ils n’apparaissent pas comme des lignes distinctes dans la référence des raccourcis clavier.

| Raccourci       | Action                                                              |
| --------------- | ------------------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Rechercher dans le diff                                             |
| `J` / `K`       | Fichier suivant / précédent                                         |
| `V`             | Basculer l’état « vu » du fichier actif                   |
| `C`             | Basculer le repli du fichier actif                                  |
| `T`             | Afficher la liste des fichiers                                      |
| `Enter`         | Correspondance suivante (uniquement lorsque la recherche dans le diff est ouverte) |
| `Shift + Enter` | Correspondance précédente                                           |
| `Escape`        | Fermer la recherche dans le diff ou effacer la sélection de texte du diff |
| `Cmd/Ctrl + C`  | Copier la sélection du diff                                         |

## Combinaisons réservées au navigateur

Dans la version web, le navigateur intercepte certains raccourcis avant que la page ne les voie ; les raccourcis correspondants ne peuvent donc jamais se déclencher dans ce contexte. Ils fonctionnent normalement sur ordinateur. Sont réservés lorsqu’ils sont combinés au modificateur de commande principal : `T`, `W`, `N` et les chiffres `1`–`9`.

Cela concerne le changement d’espace de travail avec `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nouvel espace, nouvel espace de travail, nouvel agent, ajouter un dépôt) et `Cmd/Ctrl + T` / `Cmd/Ctrl + W` dans les espaces et le détail d’une PR.
