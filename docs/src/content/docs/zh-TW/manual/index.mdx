Control Center 讓你指揮一整支 AI 程式設計代理機群。啟動代理、即時觀看它們工作、審查它們的 PR，並管理儲存庫、工作區與整合——無論是原生桌面應用程式、瀏覽器還是手機。

## 你可以做什麼

- **向代理傳訊息**：空間是驅動機群的主要方式。@提及代理，它就會派送進自己的寫入時複製工作樹，因此多個代理可以平行編寫與審查程式碼，而不會動到你的檢出
- **編排大型需求**：給編排器一個目標，只要核准一次它提出的整團隊計畫，接著就會由一條產生的[管線](/zh-TW/手冊/概念/管線/)執行
- **審查並合併 PR**：內建差異檢視器、行內留言與 AI 驅動的審查
- **交給代理用完即丟的機器**：一部[機台](/zh-TW/手冊/操作指南/使用機台/)就是一台用完即丟的虛擬機——可能是瀏覽器、桌面、手機或隔離艙終端機——由代理操作，而你可以即時觀看並隨時接手；其中的開發伺服器會轉送到 `localhost`、代理的瀏覽器與 `https://myapp.test`
- **自動化工作流程**：採用由事件或排程觸發、以 DAG 為基礎的管線
- **管理知識**：具備工作區範圍的記憶、事實與政策
- **追蹤工作**：與供應商無關的工單、專案與委派
- **錄製會議**：在裝置上完成擷取、轉錄與語者分離，再摘要成筆記、行動項目與決策
- **掌握你的一天**：Google Calendar 同步、RSVP、會議提醒與錄製並連結
- **用手機跟上機群**：將裝置與你的伺服器配對，即可閱讀訊息、回覆與整理工單。手機會走它能觸達的最佳路徑——回送、LAN、tailnet 或 TLS——並退回到一條端對端密封的中繼，只轉送它無法解讀的訊框
- **從 Slack 驅動代理**：把工作區橋接到聊天應用程式，接著提及機器人、在 Slack 討論串中回覆，或用斜線指令建立工單——全程經由對外連線，因此不需要公開端點
- **整合** GitHub、Linear、Slack、Google Calendar 與超過 100 種 MCP 工具

## 你不一定要安裝它

同一個應用程式也在你的瀏覽器中執行，網址是
[app.usectrl.dev](https://app.usectrl.dev)，功能完全相同。

每個用戶端——桌面、網頁與手機——都只是無介面伺服器上的精簡渲染層，該伺服器
擁有你的資料並實際完成工作。桌面版可以代你啟動該伺服器；瀏覽器
分頁則不行，因此網頁應用程式會連線到你自行執行的伺服器。該伺服器可以就在你自己
的機器上（`ws://localhost:9030`，無需憑證），也可以位於可透過
TLS、VPN 或隧道觸達的遠端主機上。

瀏覽器這條路徑請參閱[安裝](/zh-TW/手冊/安裝/#use-it-in-your-browser)，
三個用戶端之間的關係請參閱[部署與用戶端](/zh-TW/手冊/概念/部署/)。
