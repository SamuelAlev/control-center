將 Linear API 金鑰貼到伺服器上並關聯到你的使用者，就像連接託管平台一樣。工單、
專案、連結、協作者、委派與指派全都透過 Control Center 自己的資料庫運作，不需要
任何外部服務——請參閱[建立與管理工單](/zh-TW/手冊/操作指南/管理工單/)。

## 儲存你的 Linear 金鑰

**工單 API 金鑰**位於 **設定 → 工作區 → 一般** 的**工單**卡片上。它會把金鑰按你
的使用者 id 儲存在伺服器上。伺服器用於無人看管工作的金鑰來自 `LINEAR_API_KEY`
或**供應商應用程式**卡片，而且只有在該代理具備**允許工單 API 呼叫**能力時，才會
以 `TICKETING_API_KEY` 注入。

## 將新工單標記為 Linear

**工單供應商**（新手導引的第一步，以及
`/workspaces/<workspaceId>/api-keys`）提供 `local` 與 `linear`。選擇 `linear`
後，你此後建立的工單都會被標上 `provider: linear`。
