本指南說明如何塑造新聞動態：它會從哪些來源拉取內容、文章如何閱讀，以及內容封鎖的作用。

:::caution[新聞動態以使用者為單位，而非以工作區為範圍]
摘要與文章都屬於已登入的使用者：你的摘要清單、已讀狀態與書籤會跟著你進入每一個工作區，也會跟著你到每一台登入過的裝置，其他使用者看不到它們。摘要存放在伺服器的全域資料庫中，因此 `/newsfeed` URL 之所以帶有工作區 id，只是因為應用程式內的每一條路由都是如此。
:::

## 閱讀文章

1. 點選側邊欄中的 **Newsfeed**
2. 用工具列的分段控制項在 **全部**、**未讀** 與 **已儲存** 之間切換
3. 用搜尋框或來源選擇器縮小清單範圍
4. 用版面按鈕在雜誌式格狀版面與緊湊清單之間切換

開啟文章會將它標示為已讀。使用頁面標題列中的 **全部標示為已讀**——它只有在還有未讀內容時才會出現——一次清空積壓，並用卡片上的書籤控制項把文章留待之後閱讀。

版面選擇會在各次啟動之間保持不變。

## 新增摘要

1. 開啟 **設定 → 你 → Newsfeed**（新聞動態標題列中的設定圖示會直接帶你到那裡）
2. 按下 **新增動態來源**
3. 填寫 **名稱** 與 **摘要網址**（RSS 或 Atom）
4. 可視需要展開 **進階** 並設定自訂的 **User-Agent**——有些出版者會對預設用戶端給出不同的回應
5. 按下 **新增動態來源**

檢查點：摘要會出現在 **摘要** 清單中，它的文章會在第一次抓取後送達。已經訂閱過的 URL 會被拒絕，並顯示「已有相同網址的摘要。」

首次使用時，每位使用者都會預先植入十四個摘要：Control Center、The Verge、TechCrunch、Hacker News、ByteByteGo、Product Hunt、TLDR AI、Import AI、The Pragmatic Engineer、Martin Fowler、Will Larson 的 Irrational Exuberance、The Engineering Manager、Lea Verou 與 CSS-Tricks。

## 管理摘要

**摘要** 清單中的每一列都提供三個控制項：

| 控制項       | 作用                                               |
| ------------ | -------------------------------------------------- |
| 開關         | 停用該摘要。停用的資料列會變暗，且不再被抓取       |
| 重新整理圖示 | 立即抓取這一個摘要                                 |
| 垃圾桶圖示   | 刪除該摘要，會先要求確認                           |

清單頂端的 **全部重新整理** 會抓取每一個已啟用的摘要。

摘要的副標題會顯示它的描述，以及上次抓取是多久以前；抓取失敗的摘要會改在該位置以警告色顯示錯誤。

沒有任何編輯入口——若要變更摘要的名稱、URL 或 User-Agent，請將它刪除後重新新增。

抓取完全在伺服器上執行：每位使用者在啟動時抓取一次（之後建立的帳號則在首次使用時抓取），之後每 30 分鐘一次。

## 在閱讀器中封鎖廣告與追蹤器

1. 在 設定 → 你 → Newsfeed 中，找到 **閱讀偏好**
2. 讓 **在應用程式中開啟文章** 保持開啟，以使用內建閱讀器；或將它關閉，把文章交給系統瀏覽器
3. 讓 **封鎖廣告、追蹤器與 Cookie 橫幅** 保持開啟

封鎖預設為開啟。嵌入式閱讀器僅支援 macOS 與 Windows：在 Web 版與 Linux 上，系統瀏覽器_就是_閱讀器，文章會在其中開啟（Web 版為新分頁）。在 Web 版上，封鎖切換開關、**篩選清單** 卡片與 **信任的網站** 卡片都會被隱藏。

應用程式內閱讀器不會重新編排文章。它會在嵌入式 webview 中轉譯出版者的頁面，並使用快取的篩選清單抑制廣告、追蹤器與 Cookie 橫幅。

### 檢查或更新篩選清單

**篩選清單** 卡片會顯示已載入多少條隱藏 Cookie、隱藏廣告與網路封鎖規則，以及它會移除哪些追蹤參數，還有這些清單上次更新的時間。按下 **檢查更新** 即可重新整理它們。

來源包括 EasyList、i-dont-care-about-cookies、Fanboy Cookiemonster、若干 uBlock Origin 清單，以及 uBO 的追蹤參數清單。在下載成功之前，卡片會把這些清單標示為從未更新過的內建預設清單——廣告、Cookie 與網路規則的數量維持為零；追蹤參數移除仍會使用一套內建的預設規則。

### 將網站加入允許清單

有些網站在封鎖下會無法正常運作。

1. 在 設定 → 你 → Newsfeed 中，前往 **信任的網站**
2. 按下 **新增信任網站** 並輸入網域

在這些網站上會跳過封鎖。

## 疑難排解

### 我新增的摘要出現在另一個工作區中

這是預期行為。新聞動態以使用者為單位，而不是以工作區為單位——你的摘要會跟著你到所有你已登入的地方。請見開頭的警告。

### 摘要資料列顯示錯誤而非描述

上次抓取失敗了，資料列會原樣顯示原因。按下重新整理圖示重試，並確認該 URL 仍在提供 RSS 或 Atom。拒絕未知用戶端的出版者可能需要自訂的 User-Agent，這表示你要先刪除該摘要再重新新增。

### 文章頁面顯示異常

透過 **信任的網站** 為該網域關閉 **封鎖廣告、追蹤器與 Cookie 橫幅**，或關閉 **在應用程式中開啟文章**，改在瀏覽器中閱讀。
