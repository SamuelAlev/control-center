本指南說明如何執行專注時段：這是一段計時的區塊，期間 Control Center 會抑制非緊急通知，並在你的其他視窗上方懸浮一個倒數膠囊。本指南也會介紹在其下（預設）播放的聲景——一段由你的伺服器即時合成的無盡環境音軌，由你選擇的情境、室外的天氣以及一天中的時段共同塑造。

專注時段是 shell 層級的功能。它不綁定任何支柱——不會改變版面配置、隱藏側邊欄，也不會更動 PR 審查介面。

:::note[僅限桌面版]
懸浮膠囊與聲景的彈出式迷你播放器都是原生同層視窗，僅由桌面版啟動程序掛載。`app.usectrl.dev` 的網頁版兩者皆無，也沒有作業系統通知管道，因此專注時段在那裡既沒有東西可顯示，也沒有東西可抑制。聲景面板與其播放功能則在你連上伺服器的任何地方都能運作。
:::

## 開始專注時段

1. 點擊標題列右側的專注圖示（工具提示 **開始專注時段**）
2. 在對話方塊中輸入選用的**目標**——你正在做什麼
3. 選擇**時長**：25m、50m、1h、1h 30m 或 2h。預設為 50m，並會記住你上次的選擇
4. 按下**開始**

檢查點：標題列按鈕會由顯示剩餘分鐘數的強調色標籤取代，懸浮膠囊會出現在你的其他視窗上方，且在**隨專注模式啟動**開啟時，聲景會開始播放。

另外兩個進入點也能開啟同一個時段：

- **⌘K → Start focus session** 會開啟同一個對話方塊。
- **⌘⇧⌥F** 會以你記住的時長、不帶目標立即開始時段——它會略過對話方塊。再按一次則結束時段。

## 讀懂懸浮膠囊

膠囊是一個無邊框的小視窗，你可以把它拖到任何位置。它會顯示：

- 一個即時線上狀態圓點，以及以 `mm:ss` 表示的剩餘時間
- 你的目標；未設定目標時顯示「Focus session」
- 沿著底邊的細進度列

將游標移到上方會顯示兩個動作：

- **Pause** / **Resume**——停止倒數。暫停只作用於膠囊；時段本身仍保持運作。
- **Complete**——結束時段。

無論主視窗使用什麼佈景主題，膠囊都固定採用深色配色，因為它懸浮在任意桌面內容之上。

如果你從標題列關閉膠囊，時段仍會繼續執行。按下專注標籤旁邊的子母畫面按鈕（工具提示 **最小化為浮動列**）即可把它叫回來。

## 了解哪些通知會被抑制

時段運作期間，Control Center 會捨棄除兩種類別以外的所有通知，這兩類一律會送達：

- **會議即將開始**——事後才看到的會議提醒毫無價值
- **PR 已發布**

其餘一切在整個時段期間都會被無聲抑制——沒有音效，也沒有作業系統快顯通知。被抑制的通知不會排入佇列等待稍後送達。

## 播放聲景

1. 點擊標題列右側的揚聲器圖示（工具提示 **聲景**）以開啟面板
2. 選擇**情境**——**專注**、**上升**、**放鬆**或**睡眠**
3. 按下**播放**

檢查點：**正在播放**卡片會顯示目前場景的名稱——你工作區所在地的天氣、以 °C 表示的溫度，以及位置標籤。當它顯示「正在調整環境音…」時，表示場景仍在解析中。

音軌不是循環播放。你的伺服器會持續根據情境、工作區所在地的即時天氣與一天中的時段合成它。雨聲聽起來明亮而繁忙，暴風雨響亮而陣陣強風，霧則悶沉；夜晚比正午更暗、殘響更多。情境決定了它的語彙：

| 情境 | 聲音                                                             |
| ---- | ---------------------------------------------------------------- |
| 專注 | 溫和而警醒的環境音，帶有低沉的脈動——意在陪伴工作                  |
| 上升 | 輕快的旋律，帶有柔和的脈動——適合工作令人感到沉重時                |
| 放鬆 | 更溫暖、更和諧的和聲襯底，沒有節拍                                |
| 睡眠 | 幾乎沒有事件發生的低沉持續音，殘響深沉                            |

播放中切換情境會把播放交給新的情境，而不會停止。

面板也可以從 ⌘K 的 **Focus** 類別開啟，就在專注時段旁邊。

## 塑造聲音

- **調性**（專注、上升與放鬆）——一個帶有可拖曳圓鈕的方形調音板。水平方向是**柔和**到**活力**（發生多少變化），垂直方向是**空靈**到**明亮**（聽起來多開闊）。連點兩下調音板可重設回中性中心；方向鍵可微調圓鈕。你的調性會依情境分別記住，而調整會滑順地融入正在播放的混音——音訊串流永不重新開始。睡眠情境依設計無法調音。
- **音量**——從 0 到 100% 的滑桿，預設為 60%。它與系統音量分開，並且會被記住。
- **位置**——從工作區自動偵測。按下**重新整理天氣**以重新取得場景。

## 彈出迷你播放器

音訊播放時，標題列會多出第二個按鈕（工具提示 **彈出播放器**）。它會懸浮出一個小型、始終置頂的 HUD，包含播放/暫停、天氣圖示、場景名稱與**返回應用程式**按鈕——當專注時段讓你完全投入另一個應用程式時很方便。

從迷你播放器暫停並不會關閉它；只有它的關閉按鈕（或結束應用程式）才會移除它。

## 一起使用兩者

這兩個功能由聲景面板中的一個開關連結：**隨專注模式啟動**，預設為開啟。

- 開始專注時段時，若目前沒有正在播放的內容，就會啟動聲景。
- 結束時段時——無論以何種方式結束，包括計時器到期——都會停止聲景，即使你是手動啟動聲景也一樣。

關閉該開關即可讓兩者各自獨立。

## 結束時段

下列任一操作都會結束時段：

- 點擊標題列中的專注標籤（工具提示 **專注模式作用中—點擊以結束**）
- 按下膠囊上的 **Complete**
- 按下 **⌘⇧⌥F**
- 在 ⌘K 中選擇 **Exit focus mode**
- 讓計時器到期——時段會在歸零時自動完成

膠囊會關閉，通知會立即恢復，聲景則停止。

## 了解哪些內容不會保留

一個時段只存在於單次應用程式執行期間。結束並重新開啟 Control Center 後，你會以未運作狀態與重置的計時器開始，即使是在時段進行到一半也一樣——沒有當機復原，也沒有時段歷程記錄。

只有兩件事會延續：你偏好的時長與封鎖通知旗標。目標、已耗費的時間與膠囊的開啟狀態都不會。

播放也同樣短暫——聲景在啟動時一律處於停止狀態。你的情境、音量與各情境調性會保留；音訊串流本身永遠不會自行恢復。

## 疑難排解

### 找不到調音板

你目前處於睡眠情境，它刻意設計成無法調音。切換到專注或放鬆即可找回調音板。

### 重新啟動應用程式後完全沒有聲音

這是設計使然——播放一律在應用程式啟動時停止。開啟面板並再次按下**播放**。如果仍然沒有聲音，請檢查面板的音量滑桿，它與系統音量分開。

### 天氣或溫度看起來不對

場景會跟隨目前作用中工作區的位置。在面板中按下**重新整理天氣**即可重新取得。
