本指南說明如何建立團隊、為團隊指定隊長，以及把工作路由到團隊。

團隊是單一工作區內一組具名的代理，其中一個代理會被指定為團隊的**隊長**。把工單指派給團隊會喚醒隊長，由它拆解工作並委派給成員；當某個成員的執行完成後，隊長會再次被喚醒，決定接下來要做什麼。

在 **設定 → 工作區 → 代理 → 團隊** 建立團隊、重新命名團隊，並為團隊配置成員。把工作路由到團隊有兩種方式：代理以該團隊的 `team_id` 呼叫 `assign_ticket`，或由管線的 **Team dispatch** 節點派送團隊（不指派工單）。工單的負責人選擇器只會列出你與個別代理。

## 建立團隊

1. 開啟 **設定 → 工作區 → 代理**（`/settings/workspace/agents`）。
2. 在頁首點擊**團隊**。
3. 點擊**新增團隊**。
4. 輸入**名稱**（例如「backend」或「review squad」）以及選填的**描述**，然後點擊**建立**。

團隊隨即建立並被選取，其編輯器會在右側窗格中開啟。

## 設定隊長

整個功能都取決於這一步。在團隊的編輯器中：

1. 在**隊長**之下挑選一個代理。說明文字對它的描述一字不差：「接收團隊指派工作並分派給最適合成員的協調者。」
2. 可選填**運作指示** —— 一段自由文字，會隨每張路由過來的工單一併交給隊長。

把某個代理提升為隊長時，若它原本不是成員，也會一併成為成員。留在**沒有隊長**狀態的團隊形同虛設：有工作路由過來時不會派送任何東西，而把現任隊長從成員清單中移除，團隊就會再次失去隊長。

## 新增成員

在同一個編輯器中，使用成員卡片從工作區新增代理，或把他們移除。成員就是隊長據以委派工作的名冊。

團隊以工作區為範圍：只有本工作區內的代理可以加入。

## 為團隊提供空間

團隊不會自動獲得團隊空間。如果你需要一個，請從**空間**建立一個普通空間，並把團隊的代理加入其中。`Team` 攜帶名稱、描述、隊長、運作指示與成員 —— 沒有空間關聯。

## 回報關係是另一回事

每個代理還有一個**直屬主管**欄位，在 **設定 → 工作區 → 代理** 中設定。它會建構出工作區的回報樹，你可以在代理頁面用**組織圖**按鈕查看。

它不會驅動團隊路由。隊長會依技能與角色，從團隊的成員名冊中挑選委派對象，而不是從回報鏈中挑選。記憶存取授權以代理的角色為鍵，而不是以回報鏈為鍵；沒有任何分析介面會依團隊或階層彙總。委派護欄會限制深度並偵測循環，但從不要求目標必須是自己的下屬。

## 路由過來的工單會做什麼

當工單確實帶有團隊指派時：

1. 團隊的隊長會連同該工單、團隊的運作指示與成員名冊一起被派送。
2. 隊長會向成員委派工作，並用 `record_team_activity` 工具記錄自己的評估 —— `action`（已委派）、`no_action`（沒有更多要做的事，這會停止後續再次觸發）或 `failed`。
3. 每個完成的成員執行都會再次喚醒隊長，並受 no_action 護欄約束。

管線的 **Team dispatch** 節點是另一個進入點。它接收團隊 ID、提示詞與分派模式：

- `allParallel` —— 為每個成員各建立一個任務並放入同一個共用的隱藏對話，一直暫停到所有執行都完成，而每個成員的輸出都會收集在該節點的輸出鍵之下
- `manager` —— 只派送隊長，由它在對話中進行協調
