本指南說明如何手動啟動一次執行。若要觀察執行、讀取步驟輸出以及從失敗中復原，請參閱
[監控管線執行](/zh-TW/手冊/操作指南/監控管線/)。

## 啟動一次執行

1. 在工作區側邊欄點選 **管線**。
2. 在頁首按下 **執行管線**。你會落在執行選取器
   （`/workspaces/<workspace-id>/pipelines/run`）。
3. 從左側欄挑選一個範本。每張卡片會顯示範本的名稱、說明，以及它是否接受輸入。
4. 在右側填寫輸入表單。必填欄位在有值之前會一直停用按鈕；沒有輸入的範本會明白說明
   這一點。
5. 按下 **執行管線**。

你會落在該次執行的詳情頁，時序瀑布圖與圖形畫布都會即時更新。

## 如果左側欄是空的

只有在下列**兩個**條件都成立時，執行選取器才會顯示某個範本：

- 該範本的開關已在 **設定 → 工作區 → 管線範本** 中開啟。
- 範本編輯器的 **手動執行** 對話框中的 **允許手動執行** 已開啟 ——
  正是這個開關建立了執行選取器所讀取的 `manual` 觸發器。

十三個內建範本中有八個出廠時即為停用：`external_pr_welcome`、
`cross_review`、`ticket_to_pr`、`pr_triage`、`pre_merge_gate`、`release_notes`、
`dep_audit` 與 `pr_digest`。引擎會拒絕啟動已停用的範本，因此在這裡尋找它之前，請先
開啟它的開關。

範本清單上沒有針對個別範本的 **執行** 動作，編輯器內也沒有執行按鈕 ——
執行選取器是唯一的手動進入點。

## 填寫儲存庫輸入

類型為 **儲存庫** 的輸入會在該工作區已註冊的儲存庫之上顯示一個選擇器。選取其中一個會把
`repo_id`、`repo_local_path`、`repo_full_name`，以及 —— 當該儲存庫有 GitHub 遠端時 ——
`repo_owner` 與 `repo_name` 填入執行承載內容，讓下游步驟可以讀取各自需要的欄位。

## 觀察執行

執行詳情頁由三個部分組成：中繼資訊列（開始時間、有效時長、步驟進度、失敗橫幅、
**重試** 與 **刪除**）、可折疊的時序瀑布圖（含每個步驟的時長與成本），以及圖形畫布。
選取某個節點會開啟該步驟的詳細資料面板。

[監控管線執行](/zh-TW/手冊/操作指南/監控管線/)涵蓋了這一切，包括如何讀懂已暫停的
步驟，以及某個步驟失敗時該怎麼辦。

你從應用程式啟動的每一次執行都是真實的執行。
