本指南說明如何操作工作區的知識儲存。

開始之前你必須知道的重點是：**記憶介面是檢閱的介面，而不是撰寫的介面。** 事實與政策是由代理寫入的 —— 透過 `propose_fact` 與 `propose_policy`，並以 `supersede_fact` 與 `supersede_policy` 取代它們。`remember` 會寫入一筆受工作階段限制的熱層項目，之後 `consolidate_memory` 可能將其提升為事實。已記錄的會議決策會被收集進 `decisions` 領域；已完成的代理執行則不會進行收集。你在這裡所做的，就是讀取它們寫下的內容、加以修正、停用，或刪除。

記憶位於 **設定 → 工作區 → 記憶**（`/workspaces/<id>/settings/memory`）。它不是側邊欄中的頂層目的地。

## 三個分頁

這個頁面恰好有三個分頁。事實與政策會顯示即時數量；圖譜則不會：

- **事實** —— 工作區中的每一條事實，並附上尚未被取代者的數量
- **政策** —— 依領域分組的規範性規則，並附上啟用中者的數量
- **知識圖譜** —— 由領域、主題、事實與政策構成的互動式畫布

領域不是你建立的東西。當代理把第一條事實或政策寫進某個領域時，該領域才隨之存在；介面中任何地方都沒有建立領域的控制項。

## 檢閱並修正事實

1. 開啟 **事實** 分頁。
2. 使用搜尋框縮小清單範圍。它只是對每條事實的領域、主題與內容進行單純的子字串篩選 —— 沒有關鍵字索引，也沒有排名。
3. 使用範圍篩選器顯示所有範圍、僅限整個工作區的事實，或單一儲存庫的事實。
4. 使用排序切換鈕，依時間新近度或信心排序。
5. 點擊某條事實的編輯控制項。

編輯對話框可讓你變更：

- **領域** —— 將事實移到其他領域
- **主題** —— 它的簡短標籤
- **內容** —— 知識文字
- **信心** —— 以 5% 為級距的滑桿

儲存即可寫回。沒有 **新增事實** 按鈕；這個對話框只會從既有的資料列開啟。

## 查看已被取代的事實

事實分頁有一個 **顯示已被取代者** 開關。已被取代的事實預設為隱藏，並由該開關顯示出來，稽核軌跡就在那裡 —— 取代永遠不會刪除。

## 刪除事實

使用某條事實的刪除控制項並確認。這是真正的刪除，而非取代：請把它用在當初根本不該記錄的事實上，至於*內容*已經推進的事實，則交由代理以取代方式處理。

## 管理政策

**政策** 分頁會依領域將啟用中的政策分組，並把未啟用者降到末尾的區段。針對每條政策，你可以：

- **編輯** 它
- **刪除** 它
- **停用** / **啟用** 它 —— 可逆的選項，通常也是正確的選擇。只有啟用中的政策會進入代理提示。

與事實相同，這裡沒有建立控制項。

## 探索知識圖譜

**知識圖譜** 分頁將領域、主題、事實與政策攤開成一張可瀏覽的節點畫布 —— 可平移、縮放、拖曳節點。點選節點會開啟其詳細資料面板，從中可觸及相同的編輯對話框。這是查看哪些領域確實有內容最快的方式。

## 編輯代理的工作記憶

工作記憶是每個代理各自的私有草稿區，會在派送時注入其提示。代理會以 `record_observation` 與 `update_my_notes` 自行寫入，但你也可以直接讀取與編輯它：

**設定 → 工作區 → 代理** → 選取該代理 → **記憶** 分頁。

## 存取授權

記憶存取授權會將代理的角色對應到每個領域的一項權限（`none`、`read`、`write`）。以 `memory_access_grant.*` 操作寫入它們。

關於它們如何生效，有兩件事必須了解：

- **讀取採失效即開放。** 當某個 (role, domain) 組合沒有對應的授權資料列時，實際生效的權限是 `read`。唯一在缺少 `write` 時會拋出錯誤的寫入是 `propose_policy`。事實寫入不受授權限制。
- **授權是以代理的角色為鍵。** 提案工具會把缺少的 `agent_role` 預設為 `general`。為其他角色寫入的授權不會約束這些代理；`general` 授權則會。

## 搜尋並非處處相同

有三種不同的東西都被稱為「記憶搜尋」，而它們並不一致：

| 位置 | 作用 |
| --- | --- |
| 事實分頁的搜尋框 | 對已載入用戶端的事實進行子字串篩選 |
| `memory_fact.search` RPC 操作 | 僅使用 FTS5 關鍵字搜尋 —— 精簡用戶端無法提交查詢嵌入，因此混合搜尋始終留在主機內部 |
| 代理端的 `search_memory` 工具 | `keyword`、`semantic` 或 `hybrid`（預設）。混合模式融合四個聲部：詞彙、語意、時序與圖譜 |

因此，代理與記憶頁面對同一個查詢的排名不會相同。當你想確認代理實際上能回想起來什麼時，去問代理。

## 嵌入

事實會在**寫入當下**建立嵌入，而且只有在裝置端嵌入模型已安裝時才會如此。在 **設定 → 伺服器 → 診斷與隱私 → 語意搜尋** 底下檢查它的狀態。如果你想要語意召回，請在代理開始寫入記憶之前先安裝模型。
