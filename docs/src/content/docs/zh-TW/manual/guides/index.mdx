每篇指南都為**已經熟悉操作方式的人解決一個問題**。這些指南假設你已安裝
Control Center 並設好工作區，它們在標題中說明目標，並在目標達成後就結束。

如果你還在認識這個產品，請從[教學](/zh-TW/手冊/教學/)開始。
如果你想了解某件事_為什麼_會有這樣的行為，請閱讀
[概念](/zh-TW/手冊/概念/)。
