專案是工作區範圍內、朝共同目標推進的一組工單。專案僅存在於 Control Center——永遠不會同步到
Linear 等外部供應商。

## 建立專案

1. 展開工作區側邊欄中的**工單**群組。它會依序列出**所有工單**、每個未封存專案各佔一列，然後是
   **新增專案**。
2. 點擊**新增專案**。
3. 填寫**專案名稱**、選填的**描述**，並挑選一種**顏色**。
4. 按下**建立專案**。

你會進入新專案的概覽，而該專案會以側邊欄的一列出現在**工單**之下。

## 將工單歸入專案

專案是單張工單上的欄位，可在下列兩個位置的任一個設定：

- 開啟該工單，在其屬性欄中設定**專案**。
- 在清單中右鍵點擊該工單，並使用**專案**子選單。

屬性欄中的選擇器也提供**新增專案**，因此你可以把工單歸入當下建立的專案。**無專案**會清空該欄位。

一張工單最多只屬於一個專案。

:::note[專案不是批次操作]
選取多張工單時出現的浮動工具列涵蓋狀態、優先順序、負責人、標籤與刪除。它沒有專案這一項，因此
要歸入多張工單，只能一次處理一張。
:::

你也可以從專案著手：專案概覽上的**新增工單**會建立一張工單並歸入該專案。

## 查看專案進度

從側邊欄中的專案列開啟專案，或前往
`/workspaces/<workspace-id>/projects/<project-id>`。

概覽會顯示專案的圖示與名稱、狀態徽章、描述，以及一條顯示已完成數與總數的進度條。下方則依狀態
將專案中的工單分組。

它不會彙總其他任何內容——沒有負責人明細，也沒有優先順序分布。若需要這些，請改為篩選主工單
清單。

## 變更專案狀態

專案有三種狀態：

| 狀態        | 意義                 |
| ------------- | -------------------- |
| **進行中**    | 工作正在進行         |
| **已完成**    | 所有工作均已完成     |
| **已封存**    | 供歷史查閱           |

使用專案標頭的 **⋯** 選單。它提供**編輯專案**、**標示為已完成**／**標示為進行中**、**封存**／
**還原**以及**刪除專案**。

封存會把專案從側邊欄清單與工單選擇器中隱藏。此操作可逆——**還原**會把專案改回進行中——但專案在
封存期間只能透過 URL 存取。

## 為你建立的專案

核准編排會建立一個專案，並把父工單歸入其中，與你手動歸入的內容並列。產生的工作項目是管線
步驟，而不是工單列，因此不會出現在專案看板上。這是唯一的自動化路徑：沒有任何管線節點會建立
工單，因此管線無法為專案填入內容。請參閱
[執行編排](/zh-TW/手冊/操作指南/執行編排/)。

:::note[專案是操作者介面]
專案的建立、列出、更新與刪除都在應用程式中進行。代理沒有專案相關的工具。
