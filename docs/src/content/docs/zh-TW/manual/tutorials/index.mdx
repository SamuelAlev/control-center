Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/zh-TW/手冊/操作指南/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/zh-TW/手冊/教學/第一個工作區/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/zh-TW/手冊/教學/第一個代理/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/zh-TW/手冊/教學/第一個-pr/) — read the diff, comment and merge
4. [Build your first pipeline](/zh-TW/手冊/教學/第一條管線/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/zh-TW/手冊/教學/第一個聊天橋接/) — drive agents from a Slack thread
- [Sign your team in with SSO](/zh-TW/手冊/教學/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/zh-TW/手冊/安裝/). If you only want the
shortest possible path to a running agent, take the [quick start](/zh-TW/手冊/快速入門/)
instead and come back here afterwards.
:::
