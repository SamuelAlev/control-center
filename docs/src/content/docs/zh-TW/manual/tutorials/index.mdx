教學是**課程**。每一篇都會帶你從頭到尾完整走過一件真實的事，只有一條路徑，沿途不需要做出任何決定。嚴格照著步驟做，就能順利完成。

它們的用途是讓你熟悉產品。等你摸清了產品的輪廓，要完成某個特定任務時，
[操作指南](/zh-TW/手冊/操作指南/)是更快的途徑。

請依這個順序來做 —— 每一篇都以前一篇為前提。

1. [你的第一個工作區](/zh-TW/手冊/教學/第一個工作區/) —— 建立工作區、加入儲存庫，並了解隔離模型
2. [派送你的第一個代理](/zh-TW/手冊/教學/第一個代理/) —— 為代理設定配接器和模型，然後讓它開始工作
3. [審查你的第一個 Pull request](/zh-TW/手冊/教學/第一個-pr/) —— 閱讀 diff、留言並合併
4. [建立你的第一條管線](/zh-TW/手冊/教學/第一條管線/) —— 把步驟串成 DAG 並執行

另外兩篇彼此獨立；等你有了可用的工作區，任選一篇來做。

- [將 Slack 橋接至工作區](/zh-TW/手冊/教學/第一個聊天橋接/) —— 從 Slack 討論串中指揮代理
- [用 SSO 讓團隊登入](/zh-TW/手冊/教學/sso/) —— 連接身分提供者，並完整走一遍登入流程

:::note[開始之前]
請先安裝 Control Center —— 參閱[安裝](/zh-TW/手冊/安裝/)。如果你只想用最短的路徑讓代理
跑起來，那就改用[快速入門](/zh-TW/手冊/快速入門/)，之後再回到這裡。
:::
