本參考列出代理實體上的每一個欄位，以及它使用的各種列舉與旗標。若要在應用程式中逐步建立或編輯代理，請見[建立並設定代理](/zh-TW/手冊/操作指南/建立代理/)。

## 代理實體欄位

| 欄位                    | 類型                   | 必填 | 說明                                                                                                                                                                                                |
| ----------------------- | ---------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | 是   | 唯一的代理識別碼                                                                                                                                                                                    |
| `name`                  | `String`               | 是   | 用於 @提及 的簡短識別碼                                                                                                                                                                             |
| `title`                 | `String`               | 是   | 人類可讀的角色職稱                                                                                                                                                                                  |
| `agentMdPath`           | `String`               | 是   | 代理 `.md` 定義檔的絕對路徑                                                                                                                                                                         |
| `workspaceId`           | `String`               | 是   | 所屬工作區（不可為 null）                                                                                                                                                                           |
| `reportsTo`             | `String?`              | 否   | 上層代理的 id                                                                                                                                                                                       |
| `skills`                | `AgentSkills`          | 是   | 技能識別碼的集合                                                                                                                                                                                    |
| `persona`               | `String?`              | 否   | 自由文字的行為指示                                                                                                                                                                                  |
| `systemPrompt`          | `String?`              | 否   | 覆寫預設的系統提示                                                                                                                                                                                  |
| `adapterId`             | `String?`              | 否   | 推論配接器的 id                                                                                                                                                                                     |
| `modelId`               | `String?`              | 否   | 該配接器內的模型 id                                                                                                                                                                                 |
| `strictMode`            | `bool`                 | 否   | 預設 `false`。會寫入該資料列以及代理的 `AGENTS.md`                                                                                                                                                  |
| `effort`                | `String?`              | 否   | 推論等級 id（例如 `'low'`、`'xhigh'`），取自所選模型的 `thinkingLevels`                                                                                                                             |
| `contextSize`           | `int?`                 | 否   | 情境視窗的大小上限                                                                                                                                                                                  |
| `role`                  | `AgentRole?`           | 否   | 代理角色                                                                                                                                                                                            |
| `capabilities`          | `AgentCapabilities?`   | 否   | 依代理的能力預設值；為 null 時，派送時會套用使用者層級預設值，而對話仍可覆寫                                                                                                                        |
| `monthlyBudgetCents`    | `int`                  | 否   | 每月支出上限，以美分計（預設 `0`，即不限）                                                                                                                                                          |
| `silenceTimeoutMinutes` | `int?`                 | 否   | 靜默逾時的覆寫值，以分鐘計；必須為 null 或落在 1–240 之間（由建構函式斷言）                                                                                                                         |
| `maxConcurrentTasks`    | `int`                  | 否   | 預設 `1`。線上狀態模型所回報的容量數值（執行中與佇列中的計數都會與它比較）                                                                                                                          |
| `visibility`            | `AgentVisibility`      | 否   | 預設 `workspace`                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | 否   | 治理狀態（預設 `active`）。由預算硬性停止寫入，並顯示在組織圖與線上狀態名冊上。派送仍會接受來自 `paused` 代理的工作                                                                                |
| `budgetPolicyId`        | `String?`              | 否   | 共享預算原則的 id；為 null 時直接套用 `monthlyBudgetCents`                                                                                                                                          |
| `runtimeProfileId`      | `String?`              | 否   | 自訂執行階段設定檔的 id                                                                                                                                                                             |
| `createdAt`             | `DateTime`             | 是   | 建立時間戳記                                                                                                                                                                                        |

`name` 與 `title` 都必須非空（由建構函式斷言）。`monthlyBudgetCents` 的預設值
`0` 代表不限。如要寫入上限，請使用 `agents.upsert`。

| 取值        | 說明                                       |
| ----------- | ------------------------------------------ |
| `workspace` | 預設值；未知與 null 的已儲存值都會解析為它 |
| `private`   | 僅對建立它的使用者可見                     |

## AgentLifecycleStatus 列舉

| 取值       | 說明                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| `active`   | 預設值。`isDispatchable` 唯有在此取值下才為 true                            |
| `paused`   | 由預算硬性停止設定。會顯示在線上狀態名冊上；派送仍會接受工作               |
| `archived` | 已退役，並從使用中的名冊中隱藏                                              |

## AgentCapabilities 旗標

每次派送時解析：先取代理的預設值，為 null 時回退至使用者層級預設值，最上層再疊加依對話的覆寫值。強制方式靠的是「不存在」——被停用的能力所涵蓋的內容，憑證仲介根本不會簽發或注入。

| 旗標               | 類型   | 預設值  | 說明                                                                                      |
| ------------------ | ------ | ------- | ----------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false` | 將提交推送至遠端；與 `canCallGitHubApi` 一同閘控 GitHub 權杖的注入                        |
| `canCallGitHubApi` | `bool` | `false` | 呼叫 api.github.com；閘控 `GH_TOKEN` 的注入以及 GitHub 的對外連線網域                     |
| `canCallTicketing` | `bool` | `false` | 呼叫工單供應商的 API；閘控供應商 API 金鑰的注入及其對外連線網域                            |
| `canAccessNetwork` | `bool` | `true`  | 任意的對外連線。也會閘控執行環境的 `web_fetch` 與 `web_search` 工具                       |

`AgentCapabilities.safeDefault` 就是這四個欄位的建構函式預設值。`legacyDefault`（四者全為 true）只由那次遷移使用——它回填了能力存在之前所建立的對話。格式錯誤或為空的已儲存資料塊會解析為 `safeDefault`；舊版鍵 `canCallLinear` 會被讀作 `canCallTicketing`。

## AgentSkills

一組不可變、不區分大小寫的技能識別碼。派送時，這些 slug 會以技能連結的形式同步到代理的覆蓋層中；執行環境接著會把已連結技能的 frontmatter 自動載入提示中。

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState（衍生）

不儲存。共七個值。宣告順序即優先順序（`sortPriority`，由測試固定），也正是名冊排序所依據的順序：

| 狀態        | `sortPriority` | 條件                                                                                                                |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | 任何執行日誌的狀態為 `running`                                                                                       |
| `blocked`   | 1              | 最近一次執行的存活狀態為 `blocked`、`stalled` 或 `looping`                                                           |
| `failed`    | 2              | 最近一次執行的狀態為 `error`，或其存活狀態為 `failed` 或 `dead`                                                      |
| `queued`    | 3              | 一次執行已派送但尚未執行——停在同一代理的另一個執行之後，或是已寫入但尚未開始                                         |
| `succeeded` | 4              | 該次執行成功結束                                                                                                     |
| `idle`      | 5              | 該代理先前執行過，且目前沒有進行中的工作                                                                             |
| `neverRun`  | 6              | 不存在任何執行日誌                                                                                                   |

`queued` 與 `succeeded` **僅存在於單次執行上**。為代理計算名冊狀態的 `deriveAgentLiveState` 永遠不會產生這兩個值——它傳回的是 `neverRun`、`running`、`failed`、`blocked` 或 `idle`。
