參考頁面以窮盡、不加評論的方式說明**實際上有什麼**。當你已經知道自己要找什麼時，
就用它們來查閱：確切的工具名稱、某種步驟類型、某個狀態轉換、某條路由、某組快捷鍵。

這些頁面並非為了讓你從頭讀到尾而寫。若想從頭閱讀，請使用
[概念](/zh-TW/手冊/概念/)；若想完成某件事，請使用
[操作指南](/zh-TW/手冊/操作指南/)。

## 產品介面

- [MCP 工具](/zh-TW/手冊/參考/mcp-工具/) —— MCP 伺服器註冊的每一個工具，依家族分組
- [內建代理工具](/zh-TW/手冊/參考/代理工具/) —— 綁定伺服器的執行環境工具（LSP、AST、debug、eval、vibe）
- [斜線指令](/zh-TW/手冊/參考/斜線指令/) —— 輸入區內建指令、`/skill:` 與使用者指令
- [路由圖](/zh-TW/手冊/參考/路由圖/) —— 每一個畫面，以及能連到它的 URL
- [鍵盤快捷鍵](/zh-TW/手冊/參考/鍵盤快捷鍵/) —— 完整的按鍵綁定登錄表
- [領域事件](/zh-TW/手冊/參考/領域事件/) —— 領域匯流排上發佈的每一個事件
- [機台](/zh-TW/手冊/參考/機台/) —— 每一個機台介面、動作動詞、生命週期狀態、連接埠與預設值

## 設定

- [代理設定](/zh-TW/手冊/參考/代理設定/) —— 代理上的每一個欄位，以及哪些東西會讀取它
- [管線步驟類型](/zh-TW/手冊/參考/管線步驟/) —— 步驟類型、主體索引鍵、設定與結果
- [`cc_server` CLI](/zh-TW/手冊/參考/cc-server-cli/) —— 每一個旗標、環境變數、子命令與資料目錄路徑
- [備份、匯出與匯入](/zh-TW/手冊/參考/備份/) —— 快照的配置、每一項備份操作與傳輸途徑
- [沙箱後端](/zh-TW/手冊/參考/沙箱後端/) —— 各種執行後端及其可用性
- [SSO 設定](/zh-TW/手冊/參考/sso/) —— 端點、操作與錯誤碼
- [聊天橋接](/zh-TW/手冊/參考/聊天橋接/) —— 供應商、指令、認證資訊與操作

## 模型

- [工單生命週期](/zh-TW/手冊/參考/工單生命週期/) —— 狀態、轉換與工作流程引擎
- [詞彙表](/zh-TW/手冊/參考/詞彙表/) —— 整份手冊通篇使用的領域詞彙
