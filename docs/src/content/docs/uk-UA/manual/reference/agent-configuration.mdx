Цей довідник перелічує всі поля сутності агента, а також переліки та прапорці, які вона використовує. Покроковий опис того, як створити чи відредагувати агента в застосунку, дивіться на сторінці [Створити й налаштувати агента](/uk-UA/керівництво/практичні-посібники/створити-агента/).

## Поля сутності агента

| Поле                    | Тип                    | Обов’язкове | Опис                                                                                                                                                                                                                                                                  |
| ----------------------- | ---------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Так         | Унікальний ідентифікатор агента                                                                                                                                                                                                                                       |
| `name`                  | `String`               | Так         | Короткий ідентифікатор для @-згадок                                                                                                                                                                                                                                   |
| `title`                 | `String`               | Так         | Зрозуміла людині назва ролі                                                                                                                                                                                                                                           |
| `agentMdPath`           | `String`               | Так         | Абсолютний шлях до файлу визначення `.md` агента                                                                                                                                                                                                                      |
| `workspaceId`           | `String`               | Так         | Робочий простір-власник (не null)                                                                                                                                                                                                                                     |
| `reportsTo`             | `String?`              | Ні          | ID батьківського агента                                                                                                                                                                                                                                               |
| `skills`                | `AgentSkills`          | Так         | Набір ідентифікаторів навичок                                                                                                                                                                                                                                         |
| `persona`               | `String?`              | Ні          | Довільний текст із вказівками щодо поведінки                                                                                                                                                                                                                          |
| `systemPrompt`          | `String?`              | Ні          | Перевизначення типового системного промпту                                                                                                                                                                                                                            |
| `adapterId`             | `String?`              | Ні          | ID адаптера виведення                                                                                                                                                                                                                                                 |
| `modelId`               | `String?`              | Ні          | ID моделі в межах адаптера                                                                                                                                                                                                                                            |
| `strictMode`            | `bool`                 | Ні          | Типово `false`. Записується в рядок і в `AGENTS.md` агента                                                                                                                                                                                                            |
| `effort`                | `String?`              | Ні          | ID рівня міркування (наприклад, `'low'`, `'xhigh'`), узятий із `thinkingLevels` вибраної моделі                                                                                                                                                                       |
| `contextSize`           | `int?`                 | Ні          | Максимальний розмір контекстного вікна                                                                                                                                                                                                                                |
| `role`                  | `AgentRole?`           | Ні          | Роль агента                                                                                                                                                                                                                                                           |
| `capabilities`          | `AgentCapabilities?`   | Ні          | Типовий набір можливостей для агента; коли null, під час запуску діє типове значення рівня користувача, а розмова все одно може його перевизначити                                                                                                                     |
| `monthlyBudgetCents`    | `int`                  | Ні          | Місячна стеля витрат у центах (типово `0` — без обмежень)                                                                                                                                                                                                             |
| `silenceTimeoutMinutes` | `int?`                 | Ні          | Перевизначення тайм-ауту тиші в хвилинах; має бути null або в діапазоні 1–240 (перевіряється в конструкторі)                                                                                                                                                          |
| `maxConcurrentTasks`    | `int`                  | Ні          | Типово `1`. Показник ємності, який повідомляє модель присутності (кількість запущених і тих, що в черзі, порівнюється з ним)                                                                                                                                          |
| `visibility`            | `AgentVisibility`      | Ні          | Типово `workspace`                                                                                                                                                                                                                                                    |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Ні          | Статус управління (типово `active`). Записується жорсткою зупинкою бюджету й показується на організаційній схемі та в списку присутності. Диспетчеризація все одно приймає роботу від агента зі станом `paused`                                                       |
| `budgetPolicyId`        | `String?`              | Ні          | ID спільної політики бюджету; коли null, безпосередньо застосовується `monthlyBudgetCents`                                                                                                                                                                            |
| `runtimeProfileId`      | `String?`              | Ні          | ID користувацького профілю середовища виконання                                                                                                                                                                                                                       |
| `createdAt`             | `DateTime`             | Так         | Мітка часу створення                                                                                                                                                                                                                                                  |

`name` і `title` мають бути непорожніми (перевіряється в конструкторі). Типове значення `monthlyBudgetCents`, `0`, означає відсутність обмежень. Записуйте стелю через `agents.upsert`.

## Прапорці AgentCapabilities

Визначаються під час кожного запуску: типове значення агента, яке за null спадає до типового значення рівня користувача, а зверху — перевизначення для окремої розмови. Забезпечується через відсутність — брокер облікових даних просто не створює й не інжектує те, що покриває вимкнена можливість.

| Прапорець          | Тип    | Типово  | Опис                                                                                     |
| ------------------ | ------ | ------- | ---------------------------------------------------------------------------------------- |
| `canPushToRepo`    | `bool` | `false` | Надсилати коміти в remote; разом із `canCallGitHubApi` керує інжекцією токена GitHub      |
| `canCallGitHubApi` | `bool` | `false` | Викликати api.github.com; керує інжекцією `GH_TOKEN` і доменами виходу GitHub             |
| `canCallTicketing` | `bool` | `false` | Викликати API провайдера тікетів; керує інжекцією API-ключа провайдера та його доменами виходу |
| `canAccessNetwork` | `bool` | `true`  | Довільні вихідні запити. Також керує інструментами harness `web_fetch` і `web_search`     |

`AgentCapabilities.safeDefault` — це всі чотири типових значення конструктора. `legacyDefault` (усі чотири `true`) використовує лише міграція, яка заднім числом заповнила розмови, створені до появи можливостей. Некоректно сформований або порожній збережений blob зводиться до `safeDefault`; застарілий ключ `canCallLinear` читається як `canCallTicketing`.

## AgentSkills

Незмінний набір ідентифікаторів навичок без урахування регістру. Під час запуску ці назви синхронізуються як посилання на навички в оверлеї агента; далі harness автоматично завантажує frontmatter пов’язаних навичок у промпт.

## AgentLiveState (виведений)

Не зберігається. Сім значень. Порядок оголошення — це порядок пріоритету (`sortPriority`, закріплений тестом), і саме за ним сортує реєстр:

| Стан        | `sortPriority` | Умова                                                                                                                   |
| ----------- | -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Будь-який журнал запуску має статус `running`                                                                            |
| `blocked`   | 1              | Живучість останнього запуску — `blocked`, `stalled` або `looping`                                                        |
| `failed`    | 2              | Статус останнього запуску — `error`, або його живучість — `failed` чи `dead`                                             |
| `queued`    | 3              | Запуск диспетчеризовано, але він не виконується — стоїть за іншим запуском того самого агента, або записаний, але ще не розпочатий |
| `succeeded` | 4              | Запуск завершився успішно                                                                                                |
| `idle`      | 5              | Агент уже запускався і нічого не виконує                                                                                 |
| `neverRun`  | 6              | Журналів запуску не існує                                                                                                |

`queued` і `succeeded` існують **лише для окремого запуску**. `deriveAgentLiveState`, який обчислює стан агента для реєстру, ніколи не видає жодного з них — він повертає `neverRun`, `running`, `failed`, `blocked` або `idle`.
