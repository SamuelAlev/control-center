Сполучення клавіш походять з одного реєстру-`const` — `KeybindingRegistry` у `lib/core/constants/keybindings.dart`. Він містить **48 сполучень**. Сторінка Налаштування → Ви → Сполучення клавіш показує цей реєстр як **довідник лише для читання**: інтерфейсу для перепризначення немає, як і файлу користувацьких сполучень.

`Cmd` нижче — це основний модифікатор команд: ⌘ у macOS, Ctrl у Windows і Linux. Сполучення спрацьовує лише тоді, коли для його команди на поточному екрані зареєстровано обробник і виконується умова `when`; `!textInputFocus` означає, що натомість клавішу буде передано сфокусованому текстовому полю.

Гарячої клавіші для навігації цифрами немає. До розділу «Вхідні», тікетів, pull request і решти можна дійти з бічної панелі або через ⌘K. Для розділу «Спостережуваність» сполучення теж немає.

## Глобальні (19)

Область застосування — `global`, тож вони діють будь-де в оболонці.

### Системні

| Сполучення                                  | Дія                                                        | Умова                                                            |
| ------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Палітра команд                                             | —                                                                |
| `Shift + /` (`?`)                           | Довідка сполучень клавіш                                   | Не під час введення в поле                                       |
| `Cmd/Ctrl + Z`                              | Відмінити                                                  | Не під час введення в поле (сфокусоване поле має власне скасування) |
| `Cmd/Ctrl + Shift + Z`                      | Повторити                                                  | Не під час введення в поле                                       |
| `Cmd/Ctrl + Shift + T`                      | Перемкнути тему                                            | —                                                                |
| `Cmd/Ctrl + ,`                              | Відкрити налаштування (відкривається на `/settings/you/appearance`) | —                                                                |
| `Cmd/Ctrl + Shift + Alt + F`                | Перемкнути режим фокусу                                    | —                                                                |
| `Cmd/Ctrl + Shift + W`                      | Перемкнути перемикач робочих просторів                     | —                                                                |
| `Cmd/Ctrl + ]`                              | Наступний робочий простір                                  | —                                                                |
| `Cmd/Ctrl + [`                              | Попередній робочий простір                                 | —                                                                |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | Перейти до робочого простору 1–9                           | —                                                                |

## Список pull request (3)

Область застосування — `/pull-requests`. Усі вони вимагають `route == '/pull-requests'` і відсутності сфокусованого текстового поля, тож не спрацьовують, коли поверх списку відкрито маршрут деталей PR.

| Сполучення | Дія                        |
| ---------- | -------------------------- |
| `R`        | Оновити                    |
| `Enter`    | Відкрити PR                |
| `F`        | Відкрити меню фільтра      |

`Enter` (`pr.list-open`) оголошено в реєстрі, і він з’являється в довіднику сполучень, але **екран списку не реєструє для нього обробник**, тож наразі він не спрацьовує. `F` відкриває меню фільтра (`pr.list-open-filter`), а не пошук.

## Деталі pull request (2)

Область застосування — `/pull-requests/`. Для оновлення потрібна відсутність сфокусованого текстового поля. Закриття вкладки не має перевірки на введення тексту (сполучення з модифікатором ⌘ ніколи не буває звичайним текстом) і має регулярний вираз маршруту, тож не спрацьовує у списку.

| Сполучення     | Дія             | Умова                               |
| -------------- | --------------- | ----------------------------------- |
| `R`            | Оновити         | Не під час введення в поле          |
| `Cmd/Ctrl + W` | Закрити вкладку | На маршруті `/pull-requests/<…>`    |

Перемикання вкладок (`1`/`2`/`3`), позначення переглянутих файлів і згортання (`V`/`C`), список файлів (`T`) і пошук у діффі (`Cmd/Ctrl + F`) належать власному обробнику переглядача діффів — див. [Клавіші переглядача діффів поза реєстром](#клавіші-переглядача-діффів-поза-реєстром).

## Вхідні (1)

| Сполучення | Дія                   |
| ---------- | --------------------- |
| `F`        | Відкрити меню фільтра |

Вимагає `route == '/inbox'` і відсутності сфокусованого текстового поля.

## Профілі користувачів і команд GitHub (3)

Область застосування — `/users/`. Умова `when` — це регулярний вираз проти `/users/<login>` **або** `/teams/<organization>/<slug>`, плюс відсутність сфокусованого текстового поля.

| Сполучення     | Дія            |
| -------------- | -------------- |
| `R`            | Оновити        |
| `/`            | Фокус на пошук |
| `Cmd/Ctrl + F` | Фокус на пошук |

## Простори (8)

Область застосування — `/spaces`. Умови `when` використовують регулярний вираз, тож вони спрацьовують і у списку просторів (`/spaces`), і у вибраному просторі (`/spaces/<id>`).

| Сполучення             | Дія                                | Умова                  |
| ---------------------- | ---------------------------------- | ---------------------- |
| `Enter`                | Надіслати повідомлення             | —                      |
| `Cmd/Ctrl + N`         | Новий простір                      | На маршруті `/spaces`  |
| `J`                    | Наступний простір                  | Не під час введення в поле |
| `K`                    | Попередній простір                 | Не під час введення в поле |
| `Cmd/Ctrl + Shift + D` | Диктування «натисніть, щоб говорити» | —                    |
| `Cmd/Ctrl + T`         | Відкрити вкладку редактора         | На маршруті `/spaces`  |
| `Cmd/Ctrl + W`         | Закрити вкладку редактора          | На маршруті `/spaces`  |
| `Cmd/Ctrl + B`         | Перемкнути бічну панель редактора  | На маршруті `/spaces`  |

Надсилання клавішею Enter належить текстовому полю редактора повідомлень; диктування «натисніть, щоб говорити» належить кнопці мікрофона в редакторі повідомлень (її власний обробник апаратної клавіатури). Обидва перелічено в реєстрі для довідки в налаштуваннях.

## Вибір робочого простору (2)

Область застосування — `/workspaces`; діють лише на самому екрані вибору робочого простору.

| Сполучення     | Дія                            |
| -------------- | ------------------------------ |
| `Cmd/Ctrl + N` | Новий робочий простір          |
| `Enter`        | Відкрити вибраний робочий простір |

`Enter` вимагає відсутності сфокусованого текстового поля.

| -------------- | -------------------------- | ---------------------------------------------- |
| `J`            | Наступна сторінка налаштувань | Будь-який маршрут `/settings`, не під час введення |
| `K`            | Попередня сторінка налаштувань | Будь-який маршрут `/settings`, не під час введення |

## Клавіші переглядача діффів поза реєстром

Переглядач діффів PR обробляє їх сам (`PrDiffKeyboardHandler`). Пошук, позначення переглянутих і згортання перелічено в коментарях реєстру лише для довідки в налаштуваннях — обробника диспетчера не зареєстровано, тож диспетчер залишає їх переглядачу діффів. Вони не з’являються окремими рядками в довіднику сполучень.

| Сполучення      | Дія                                                   |
| --------------- | ----------------------------------------------------- |
| `Cmd/Ctrl + F`  | Пошук у діффі                                         |
| `J` / `K`       | Наступний / попередній файл                           |
| `V`             | Перемкнути позначку переглянутого для файлу у фокусі  |
| `C`             | Перемкнути згортання файлу у фокусі                   |
| `T`             | Показати список файлів                                |
| `Enter`         | Наступний збіг пошуку (лише коли відкрито пошук у діффі) |
| `Shift + Enter` | Попередній збіг пошуку                                |
| `Escape`        | Закрити пошук у діффі або зняти виділення тексту в діффі |
| `Cmd/Ctrl + C`  | Копіювати виділене в діффі                            |

## Комбінації, зарезервовані браузером

У вебзбірці браузер перехоплює деякі комбінації раніше, ніж їх побачить сторінка, тож відповідні сполучення там ніколи не спрацьовують. На настільному застосунку вони працюють нормально. Зарезервовано в поєднанні з основним модифікатором команд: `T`, `W`, `N` і цифри `1`–`9`.

Це охоплює перемикання робочих просторів `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (новий простір, новий робочий простір, новий агент, додати репозиторій) і `Cmd/Ctrl + T` / `Cmd/Ctrl + W` у просторах і деталях PR.
