У Linear у Control Center дві ідентичності, і обидві — входи через браузер: ваша —
для того, що робите ви, і застосунок Control Center робочого простору — для
того, що роблять агенти й конвеєри. Тікети, проєкти, зв’язки, учасники,
делегування й призначення працюють із власною базою даних Control Center, без
потреби в зовнішній службі — див. [Створювати й керувати тікетами](/uk-UA/керівництво/практичні-посібники/керувати-тікетами/).

## Передумови

- Сервер уміє виконувати вхід людей у Linear: через Control Center Connect або з
  власним застосунком Linear сервера
  ([Зареєструвати власний застосунок Linear](#зареєструвати-власний-застосунок-linear)).
  Власник сервера вибирає це в **Налаштування → Сервер → Єдиний вхід**
- Адміністратор робочого простору — щоб вибрати Linear як провайдера тікетів і
  підключити автоматизацію Linear

## Вибрати Linear для робочого простору

1. Перейдіть у **Налаштування → Робочий простір → Загальні** й знайдіть картку
   **Тікетинг**
2. Установіть для **Провайдер тікетів** значення **Linear**

Тікети, які ви створюєте відтепер, позначаються `provider: linear`. **Локально**
зберігає тікети у власній базі даних цього сервера й приховує рядки Linear:
автентифікуватися там нема до чого.

## Увійти в Linear

На тій самій картці рядок **Linear** — ваш:

1. Натисніть **Увійти в Linear**
2. Підтвердьте в браузері
3. З власним застосунком сервера діалог сам помічає вхід. Через Connect введіть
   8-символьний код, який показує браузер, або дозвольте браузеру відкрити
   Control Center за посиланням `control-center://`

Усе, що ви робите в Linear із Control Center, виконується через цей вхід і більше
нічого. Якщо ви не ввійшли, застосунок просить вас увійти, а не діє від імені
когось іншого.

## Підключити автоматизацію Linear

Рядок **Автоматизація Linear** — це застосунок Control Center робочого простору в
Linear. Синхронізація тікетів, конвеєри й агенти пишуть через нього, тож
автоматично створені задачі й коментарі з’являються від імені Control Center, а
не людини.

1. Адміністратор робочого простору натискає **Підключити Linear для автоматизації**
2. Він підтверджує застосунок для робочого простору Linear у браузері, як описано
   вище

Після цього рядок показує «Підключено до _вашого робочого простору Linear_».
Підключати й відключати його можуть лише адміністратори робочого простору.

Облікові дані Linear не потрапляють у пісочницю агента: агенти пишуть тікети
через власні інструменти Control Center, які спершу запитують правило **Запис у
зовнішній трекер**.

## Зареєструвати власний застосунок Linear

Використовуйте власний застосунок, якщо ви вибрали **Використовувати власні
застосунки**. Застосунок сервера застосовується лише тоді: з Control Center Connect або власним Connect Connect обслуговує всі канали, включно з Linear, а застосунок сервера та сервісний ключ API лишаються збереженими, але невикористаними. Застосунок робочого простору ([нижче](#надайте-одному-робочому-простору-власний-застосунок-linear)) діє в будь-якому режимі.

1. Створіть застосунок OAuth на сторінці
   [linear.app/settings/api/applications/new](https://linear.app/settings/api/applications/new)
2. Додайте дослівно обидва URL зворотного виклику, які **Налаштування → Сервер →
   Єдиний вхід → Застосунки провайдера → Linear** показує в полі **URL
   зворотного виклику**: `<server origin>/oauth/linear/callback` і
   `<server origin>/oauth/linear_app/callback`
3. Вставте **ID клієнта** в блок Linear

Секрету клієнта немає: сервер входить із PKCE. Токени оновлення Linear спливають
після 30 днів без використання, тож сервер раз на день оновлює кожен вхід у
Linear, старший за 20 днів.

Той самий блок приймає необов’язковий **Сервісний ключ API**. Це власні облікові
дані Linear сервера для автоматизації в робочих просторах, які не підключили
автоматизацію Linear. Зберігайте його в Налаштуваннях або у файлі `.env` сервера
як `LINEAR_API_KEY`: сервер відмовляється запускатися, коли `LINEAR_API_KEY`
експортовано в середовище його процесу.

## Надайте одному робочому простору власний застосунок Linear

Робочий простір може входити в Linear через власний застосунок замість застосунку сервера. Налаштувати це може лише адміністратор або власник робочого простору.

1. Створіть OAuth-застосунок Linear, як у наведених вище кроках
2. Перейдіть до **Налаштування → Робочий простір → Загальні → Застосунки провайдерів** і відкрийте **Linear**
3. Оберіть **Використовувати власний застосунок робочого простору**
4. Додайте до застосунку Linear обидві callback-URL, які рядок показує в полі **URL зворотного виклику**, дослівно
5. Вставте його **ID клієнта** і, за бажанням, **Сервісний ключ API** для автоматизації цього робочого простору

Застосунок робочого простору відповідає на кожен вхід у Linear і запит автоматизації в цьому робочому просторі, незалежно від того, як сервер автентифікує людей. Він ніколи не повертається до застосунку сервера чи Connect: доки не задано ID клієнта, Linear у цьому робочому просторі вимкнено, а рядок пояснює, чого бракує. Його сервісний ключ API використовується лише тут; без нього для синхронізації потрібне **Підключити Linear для автоматизації**.

Перемикання між застосунком сервера та застосунком робочого простору або зміна ID клієнта робочого простору виводить усіх у цьому робочому просторі з Linear і відключає їхню автоматизацію. Вони знову входять через новий застосунок. **Використовувати застосунок сервера** видаляє збережені поля робочого простору. Секрети лише для запису: рядок показує лише, чи збережено один із них. Інші робочі простори на сервері не змінюються.

## Усунення несправностей

### Рядок Linear повідомляє, що вхід не налаштовано

Сервер не має ні власного застосунку Linear, ні Connect. Власник сервера вибирає
один із варіантів у **Налаштування → Сервер → Єдиний вхід**. Коли робочий простір використовує власний застосунок, рядок натомість повідомляє, що його налаштування не завершено: адміністратор робочого простору додає ID клієнта в **Налаштування → Робочий простір → Загальні → Застосунки провайдерів**.

### Синхронізація тікетів завершується помилкою автентифікації

У робочого простору не підключено автоматизацію Linear, а в сервера немає
сервісного ключа API, тож у синхронізації немає облікових даних. Адміністратор
робочого простору натискає **Підключити Linear для автоматизації**.

### Під час підключення автоматизації повідомляється, що робочий простір Linear підключено деінде

Застосунок Control Center цього робочого простору Linear уже підключено до
іншого сервера Control Center.
