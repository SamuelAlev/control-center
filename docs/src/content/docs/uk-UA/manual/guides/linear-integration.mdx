Вставте ключ API Linear на сервері для свого користувача — так само, як
підключаєте forge. Тікети, проєкти, зв’язки, учасники, делегування й
призначення працюють із власною базою даних Control Center, без потреби в
зовнішній службі — див. [Створювати й керувати тікетами](/uk-UA/керівництво/практичні-посібники/керувати-тікетами/).

## Зберегти ключ Linear

**Ключ ticketing API** міститься в **Налаштування → Робочий простір → Загальні**,
на картці **Тікетинг**. Він зберігає ключ на сервері для ідентифікатора вашого
користувача. Власний ключ сервера для роботи без нагляду надходить із
`LINEAR_API_KEY` або з картки **Застосунки провайдера** і підставляється як
`TICKETING_API_KEY`, лише коли той агент має можливість
**Дозволити виклики ticketing API**.

## Позначати нові тікети як Linear

**Провайдер тікетів** (перший крок початкового налаштування, а також
`/workspaces/<workspaceId>/api-keys`) пропонує `local` і `linear`. Якщо вибрати
`linear`, на тікетах, які ви створюєте відтоді, проставляється
`provider: linear`.
