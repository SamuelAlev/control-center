Кожен посібник розв’язує **одну проблему для того, хто вже орієнтується в продукті**.
Вони припускають, що у вас уже встановлено Control Center і налаштовано робочий
простір, вони називають мету в заголовку й завершуються, щойно мети досягнуто.

Якщо ви ще вивчаєте продукт, почніть із [посібників](/uk-UA/керівництво/посібники/).
Якщо хочете зрозуміти, _чому_ щось поводиться саме так, читайте
[поняття](/uk-UA/керівництво/поняття/).
