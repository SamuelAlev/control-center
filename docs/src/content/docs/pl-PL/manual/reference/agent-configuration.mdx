Niniejsza dokumentacja referencyjna wymienia każde pole encji agenta oraz używane przez nią typy wyliczeniowe i flagi. Instrukcję krok po kroku tworzenia i edytowania agenta w aplikacji znajdziesz w sekcji [Utwórz i skonfiguruj agenta](/pl-PL/podrecznik/poradniki/tworzenie-agenta/).

## Pola encji agenta

| Pole                    | Typ                    | Wymagane | Opis                                                                                                                                                                                                                                                                |
| ----------------------- | ---------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Tak      | Unikatowy identyfikator agenta                                                                                                                                                                                                                                      |
| `name`                  | `String`               | Tak      | Krótki identyfikator używany we wzmiankach @                                                                                                                                                                                                                        |
| `title`                 | `String`               | Tak      | Czytelny dla człowieka tytuł stanowiska                                                                                                                                                                                                                             |
| `agentMdPath`           | `String`               | Tak      | Bezwzględna ścieżka do pliku definicji `.md` agenta                                                                                                                                                                                                                 |
| `workspaceId`           | `String`               | Tak      | Obszar roboczy będący właścicielem (nigdy nie jest pusty)                                                                                                                                                                                                           |
| `reportsTo`             | `String?`              | Nie      | Identyfikator agenta nadrzędnego                                                                                                                                                                                                                                    |
| `skills`                | `AgentSkills`          | Tak      | Zestaw identyfikatorów skillów                                                                                                                                                                                                                                      |
| `persona`               | `String?`              | Nie      | Swobodny tekst z instrukcjami behawioralnymi                                                                                                                                                                                                                        |
| `systemPrompt`          | `String?`              | Nie      | Nadpisanie domyślnego promptu systemowego                                                                                                                                                                                                                           |
| `adapterId`             | `String?`              | Nie      | Identyfikator adaptera inferencji                                                                                                                                                                                                                                   |
| `modelId`               | `String?`              | Nie      | Identyfikator modelu w obrębie adaptera                                                                                                                                                                                                                             |
| `strictMode`            | `bool`                 | Nie      | Domyślnie `false`. Zapisywane w wierszu i w pliku `AGENTS.md` agenta                                                                                                                                                                                                 |
| `effort`                | `String?`              | Nie      | Identyfikator poziomu rozumowania (np. `'low'`, `'xhigh'`), czerpany z `thinkingLevels` wybranego modelu                                                                                                                                                             |
| `contextSize`           | `int?`                 | Nie      | Maksymalny rozmiar okna kontekstu                                                                                                                                                                                                                                   |
| `role`                  | `AgentRole?`           | Nie      | Rola agenta                                                                                                                                                                                                                                                         |
| `monthlyBudgetCents`    | `int`                  | Nie      | Miesięczny limit wydatków w centach (domyślnie `0`, bez limitu)                                                                                                                                                                                                     |
| `silenceTimeoutMinutes` | `int?`                 | Nie      | Nadpisanie limitu ciszy w minutach; musi być null albo mieścić się w zakresie 1–240 (weryfikowane w konstruktorze)                                                                                                                                                  |
| `maxConcurrentTasks`    | `int`                  | Nie      | Domyślnie `1`. Liczba określająca pojemność, którą raportuje model obecności (porównuje się z nią liczbę uruchomień w toku i w kolejce)                                                                                                                              |
| `visibility`            | `AgentVisibility`      | Nie      | Domyślnie `workspace`                                                                                                                                                                                                                                               |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Nie      | Status zarządzania (domyślnie `active`). Zapisywany przez twarde zatrzymanie budżetu i wyświetlany na schemacie organizacyjnym oraz liście obecności. Wysyłanie nadal przyjmuje pracę od agenta w stanie `paused`                                                    |
| `budgetPolicyId`        | `String?`              | Nie      | Identyfikator współdzielonej polityki budżetowej; gdy null, bezpośrednio obowiązuje `monthlyBudgetCents`                                                                                                                                                            |
| `runtimeProfileId`      | `String?`              | Nie      | Identyfikator niestandardowego profilu środowiska uruchomieniowego                                                                                                                                                                                                  |
| `createdAt`             | `DateTime`             | Tak      | Znacznik czasu utworzenia                                                                                                                                                                                                                                           |

`name` i `title` muszą być niepuste (weryfikowane w konstruktorze). Domyślna
wartość `monthlyBudgetCents` wynosząca `0` oznacza brak limitu. Pułap ustawisz za pomocą `agents.upsert`.

| Rola       | Etykieta | Opis                              |
| ---------- | -------- | --------------------------------- |
| `ceo`      | CEO      | Koordynacja i delegowanie         |
| `coder`    | Coder    | Implementacja kodu                |
| `reviewer` | Reviewer | Recenzowanie i analiza PR-ów      |
| `qa`       | QA       | Testowanie i zapewnianie jakości  |

| `devops`   | DevOps   | Infrastruktura i wdrażanie        |
| `pm`       | PM       | Zarządzanie produktem             |

## Wyliczenie AgentVisibility

| Wartość     | Opis                                                              |
| ----------- | ----------------------------------------------------------------- |
| `workspace` | Wartość domyślna; nieznane i puste zapisane wartości trafiają tutaj |
| `private`   | Prywatna dla użytkownika, który ją utworzył                       |

## Wyliczenie AgentLifecycleStatus

| Wartość    | Opis                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------- |
| `active`   | Wartość domyślna. `isDispatchable` ma wartość true tylko dla tej wartości                        |
| `paused`   | Ustawiany przez twarde zatrzymanie budżetu. Pokazywany na liście obecności; wysyłanie nadal przyjmuje pracę |
| `archived` | Wycofany i ukryty na aktywnych listach obecności                                                 |

## Uprawnienia

Agent nie ma flag uprawnień. Push, otwieranie i publikowanie pull requestów, zapis do trackera i ruch wychodzący sieci to klasy akcji (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`), które [guardraile](/pl-PL/podrecznik/koncepcje/guardraile/) rozstrzygają w zakresie obszaru roboczego, agenta lub przestrzeni. Token GitHub uruchomienia zawsze ma zakres tylko do odczytu; push przechodzi przez bramę uruchomień agentów, która przed przekazaniem go dalej pyta regułę `gitPush`.

## AgentSkills

Niezmienny zestaw identyfikatorów skillów, w którym wielkość liter nie ma znaczenia. Przy wysłaniu te slugi są synchronizowane jako dowiązania skillów w nakładce agenta; harness wczytuje następnie frontmatter dowiązanych skillów do promptu.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (pochodny)

Nie jest zapisywany. Siedem wartości. Kolejność deklaracji to kolejność priorytetów (`sortPriority`, przypięta testem), czyli kolejność, według której sortuje lista obecności:

| Stan        | `sortPriority` | Warunek                                                                                                              |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Dowolny dziennik uruchomienia ma status `running`                                                                    |
| `blocked`   | 1              | Żywotność najnowszego uruchomienia to `blocked`, `stalled` lub `looping`                                              |
| `failed`    | 2              | Status najnowszego uruchomienia to `error` albo jego żywotność to `failed` lub `dead`                                 |
| `queued`    | 3              | Uruchomienie zostało wysłane, ale nie jest wykonywane — czeka za innym uruchomieniem tego samego agenta albo zostało zapisane, lecz jeszcze nie wystartowało |
| `succeeded` | 4              | Uruchomienie zakończyło się pomyślnie                                                                                 |
| `idle`      | 5              | Agent działał już wcześniej i nie ma nic w toku                                                                       |
| `neverRun`  | 6              | Nie istnieje żaden dziennik uruchomienia                                                                              |

`queued` i `succeeded` dotyczą **wyłącznie pojedynczego uruchomienia**. `deriveAgentLiveState`, który wylicza stan agenta na liście obecności, nigdy nie zwraca żadnego z nich — zwraca `neverRun`, `running`, `failed`, `blocked` lub `idle`.
