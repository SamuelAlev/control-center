Skróty pochodzą z jednego rejestru `const`, `KeybindingRegistry` w `lib/core/constants/keybindings.dart`. Zawiera on **48 przypisań**. Ustawienia → Ty → Skróty klawiszowe wyświetla ten rejestr jako **dokumentację referencyjną tylko do odczytu**: nie ma interfejsu do ponownego przypisywania skrótów ani pliku skrótów użytkownika.

W dalszej części strony `Cmd` oznacza główny modyfikator polecenia — ⌘ w macOS oraz Ctrl w Windows i Linuksie. Przypisanie działa tylko wtedy, gdy jego polecenie ma zarejestrowany handler na bieżącym ekranie, a jego klauzula `when` jest spełniona; `!textInputFocus` oznacza, że klawisz jest przekazywany do pola tekstowego, które ma fokus.

Nie ma skrótu do nawigacji klawiszami cyfr. Do Skrzynki, zgłoszeń, pull requestów i pozostałych ekranów dociera się z paska bocznego albo przez ⌘K. Obserwowalność również nie ma skrótu.

## Globalne (19)

Zakres `global`, więc działają wszędzie w powłoce aplikacji.

## Lista pull requestów (3)

Zakres `/pull-requests`. Wszystkie wymagają `route == '/pull-requests'` i braku pola tekstowego z fokusem, więc nie działają, gdy nad listą jest otwarty widok szczegółów PR-a.

| Skrót   | Akcja                    |
| ------- | ------------------------ |
| `R`     | Odśwież                  |
| `Enter` | Otwórz PR                |
| `F`     | Otwórz menu filtrów      |

`Enter` (`pr.list-open`) jest zadeklarowany w rejestrze i pojawia się w dokumentacji skrótów, ale **ekran listy nie rejestruje dla niego handlera**, więc obecnie nie działa. `F` otwiera menu filtrów (`pr.list-open-filter`), a nie wyszukiwanie.

## Szczegóły pull requesta (2)

Zakres `/pull-requests/`. Odświeżanie wymaga braku pola tekstowego z fokusem. Zamykanie karty nie ma zabezpieczenia przed polem tekstowym (kombinacja z modyfikatorem ⌘ nigdy nie jest zwykłym tekstem) i ma wyrażenie regularne trasy, więc nie działa na liście.

| Skrót          | Akcja     | Warunek                            |
| -------------- | --------- | ---------------------------------- |
| `R`            | Odśwież   | Brak pisania w polu                |
| `Cmd/Ctrl + W` | Zamknij kartę | W lokalizacji `/pull-requests/<…>` |

Przełączanie kart (`1`/`2`/`3`), oznaczanie pliku jako wyświetlony i zwijanie (`V`/`C`), lista plików (`T`) oraz wyszukiwanie w diffie (`Cmd/Ctrl + F`) należą do własnego handlera przeglądarki diffów — zobacz [Klawisze przeglądarki diffów poza rejestrem](#klawisze-przeglądarki-diffów-poza-rejestrem).

## Profile użytkowników i zespołów GitHub (3)

Zakres `/users/`. Klauzula `when` to wyrażenie regularne dopasowywane do `/users/<login>` **albo** `/teams/<organization>/<slug>`, plus brak pola tekstowego z fokusem.

| Skrót          | Akcja                   |
| -------------- | ----------------------- |
| `R`            | Odśwież                 |
| `/`            | Przejdź do wyszukiwania |
| `Cmd/Ctrl + F` | Przejdź do wyszukiwania |

## Przestrzenie (8)

Zakres `/spaces`. Klauzule `when` używają wyrażenia regularnego, więc działają zarówno na liście przestrzeni (`/spaces`), jak i w wybranej przestrzeni (`/spaces/<id>`).

| Skrót                  | Akcja                                  | Warunek               |
| ---------------------- | -------------------------------------- | --------------------- |
| `Enter`                | Wyślij wiadomość                       | —                     |
| `Cmd/Ctrl + N`         | Nowa przestrzeń                        | W trasie `/spaces`    |
| `J`                    | Następna przestrzeń                    | Brak pisania w polu   |
| `K`                    | Poprzednia przestrzeń                  | Brak pisania w polu   |
| `Cmd/Ctrl + Shift + D` | Dyktowanie „Przyciśnij i mów”          | —                     |
| `Cmd/Ctrl + T`         | Otwórz kartę edytora                   | W trasie `/spaces`    |
| `Cmd/Ctrl + W`         | Zamknij kartę edytora                  | W trasie `/spaces`    |
| `Cmd/Ctrl + B`         | Przełącz panel boczny edytora          | W trasie `/spaces`    |

Wysyłanie klawiszem Enter należy do pola tekstowego kompozytora; dyktowanie „Przyciśnij i mów” należy do przycisku mikrofonu w kompozytorze (ma własny handler klawiatury sprzętowej). Oba są wymienione w rejestrze na potrzeby dokumentacji ustawień.

## Klawisze przeglądarki diffów poza rejestrem

Przeglądarka diffów PR-a obsługuje je samodzielnie (`PrDiffKeyboardHandler`). Wyszukiwanie, oznaczanie jako wyświetlone i zwijanie są wymienione tylko w komentarzach rejestru, na potrzeby dokumentacji ustawień — nie zarejestrowano żadnego handlera dyspozytora, więc dyspozytor pozostawia je widokowi diffu. Nie pojawiają się jako osobne wiersze w dokumentacji skrótów.

| Skrót           | Akcja                                                     |
| --------------- | --------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Szukaj w diffie                                            |
| `J` / `K`       | Następny / poprzedni plik                                  |
| `V`             | Przełącz oznaczenie „wyświetlone” dla pliku z fokusem      |
| `C`             | Przełącz zwijanie pliku z fokusem                          |
| `T`             | Pokaż listę plików                                         |
| `Enter`         | Następne dopasowanie (tylko gdy wyszukiwanie w diffie jest otwarte) |
| `Shift + Enter` | Poprzednie dopasowanie                                     |
| `Escape`        | Zamknij wyszukiwanie w diffie albo wyczyść zaznaczenie tekstu w diffie |
| `Cmd/Ctrl + C`  | Skopiuj zaznaczenie w diffie                               |

## Kombinacje zarezerwowane przez przeglądarkę

W wersji webowej przeglądarka przechwytuje niektóre skróty, zanim zobaczy je strona, więc pasujące przypisania nigdy tam nie działają. W aplikacji desktopowej działają normalnie. Zarezerwowane w połączeniu z głównym modyfikatorem polecenia: `T`, `W`, `N` oraz cyfry `1`–`9`.

Dotyczy to przełączania obszarów roboczych przez `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nowa przestrzeń, nowy obszar roboczy, nowy agent, dodanie repozytorium) oraz `Cmd/Ctrl + T` / `Cmd/Ctrl + W` w przestrzeniach i w szczegółach PR-a.
