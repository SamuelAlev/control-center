Samouczki to **lekcje**. Każdy prowadzi Cię od początku do końca przez coś realnego, jedną
ścieżką, bez decyzji do podjęcia po drodze. Wykonaj kroki dokładnie, a zadziałają.

Służą do nauki poruszania się po produkcie. Gdy znasz już kształt produktu,
[poradniki](/pl-PL/podrecznik/poradniki/) są szybszą drogą do konkretnego zadania.

Wykonaj je w tej kolejności — każdy zakłada poprzedni.

1. [Twój pierwszy obszar roboczy](/pl-PL/podrecznik/samouczki/pierwszy-obszar-roboczy/) — utwórz obszar roboczy, dodaj repozytorium i zobacz model izolacji
2. [Wyślij pierwszego agenta](/pl-PL/podrecznik/samouczki/pierwszy-agent/) — przypisz agentowi adapter i model, a potem postaw go do pracy
3. [Zrecenzuj pierwszy pull request](/pl-PL/podrecznik/samouczki/pierwszy-pr/) — przeczytaj diff, skomentuj i scal
4. [Zbuduj pierwszy potok](/pl-PL/podrecznik/samouczki/pierwszy-potok/) — połącz kroki w DAG i uruchom go

Dwa kolejne są niezależne; wykonaj którykolwiek z nich, gdy masz już działający obszar roboczy.

- [Połącz Slack z obszarem roboczym](/pl-PL/podrecznik/samouczki/pierwszy-most-czatu/) — kieruj agentami z wątku Slacka
- [Zaloguj zespół przez SSO](/pl-PL/podrecznik/samouczki/sso/) — połącz dostawcę tożsamości i przeprowadź logowanie od początku do końca

:::note[Zanim zaczniesz]
Najpierw zainstaluj Control Center — zobacz [Instalacja](/pl-PL/podrecznik/instalacja/). Jeśli chcesz tylko
najkrótszą możliwą drogę do działającego agenta, skorzystaj z [szybkiego startu](/pl-PL/podrecznik/szybki-start/)
i wróć tutaj później.
:::
