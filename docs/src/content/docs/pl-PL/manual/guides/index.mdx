Każdy poradnik rozwiązuje **jeden problem osoby, która już zna produkt**. Zakłada, że masz
zainstalowany Control Center i skonfigurowany obszar roboczy, formułuje cel w tytule
i kończy się, gdy cel zostanie osiągnięty.

Jeśli dopiero poznajesz produkt, zacznij od [samouczków](/pl-PL/podrecznik/samouczki/).
Jeśli chcesz zrozumieć, _dlaczego_ coś działa w taki sposób, przeczytaj
[koncepcje](/pl-PL/podrecznik/koncepcje/).
