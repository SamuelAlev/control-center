Wklej klucz API Linear na serwerze, przypisany do swojego użytkownika — tak samo
jak łączysz forge. Zgłoszenia, projekty, powiązania, współpracownicy, delegowanie
i przypisywanie działają na własnej bazie danych Control Center i nie wymagają
żadnej zewnętrznej usługi — zobacz
[Twórz i zarządzaj zgłoszeniami](/pl-PL/podrecznik/poradniki/zarzadzanie-zgloszeniami/).

## Zapisz klucz Linear

**Klucz API zgłoszeń** znajduje się w **Ustawienia → Obszar roboczy → Ogólne**,
na karcie **Zgłoszenia**. Przechowuje klucz na serwerze, przypisany do Twojego
identyfikatora użytkownika. Własny klucz serwera do pracy bez udziału człowieka
pochodzi ze zmiennej `LINEAR_API_KEY` lub z karty **Aplikacje dostawców** i jest
wstrzykiwany jako `TICKETING_API_KEY` tylko wtedy, gdy ten agent ma uprawnienie
**Zezwalaj na wywołania API zgłoszeń**.

## Oznaczaj nowe zgłoszenia jako Linear

**Dostawca zgłoszeń** (pierwszy krok konfiguracji oraz
`/workspaces/<workspaceId>/api-keys`) oferuje `local` i `linear`. Wybranie
`linear` nadaje zgłoszeniom tworzonym od tego momentu znacznik
`provider: linear`.
