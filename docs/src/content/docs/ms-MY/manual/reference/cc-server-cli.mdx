Setiap flag proses menerima flag CLI atau pemboleh ubah persekitaran; flag diutamakan,
kemudian persekitaran, kemudian lalai. Kelayakan pihak ketiga ialah pengecualian —
lihat di bawah.

:::caution[Flag yang tidak dikenali diabaikan secara senyap]
Penghurai argumen ditulis sendiri dan melangkau apa-apa yang tidak dikenali, jadi salah taip
(`--tls-key-file`, `--bindany`) tidak menghasilkan ralat — pelayan cuma bermula dengan
lalai. Periksa baris log permulaan apabila sesuatu flag kelihatan tidak berkesan.
:::

## Teras

| Flag            | Persekitaran           | Lalai                                            | Maksud                                                                                                         |
| --------------- | ---------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `--data-dir`    | `CC_SERVER_DATA_DIR`   | direktori data aplikasi setiap pengguna OS (lihat di bawah) | Pangkalan data, rahsia, model dan media cache                                                        |
| `--port`        | `CC_SERVER_PORT`       | `9030`                                           | Port TCP (`0` = sementara)                                                                                     |
| `--bind`        | `CC_SERVER_BIND`       | `loopback`                                       | `loopback`, atau `any`/`all`/`0.0.0.0` untuk setiap antara muka (memerlukan TLS atau `--insecure`)             |
| `--repo-roots`  | `CC_SERVER_REPO_ROOTS` | direktori rumah pengguna pelayan                 | Direktori asas dipisahkan koma yang boleh disemak imbas oleh klien semasa mendaftarkan repo. Menyemak imbas melebihi sesuatu akar akan ditolak |
| `--log-level`   | `CC_SERVER_LOG_LEVEL`  | `warning`                                        | `debug`, `info`, `warning`, atau `error`. Baris semasa but/sedia sentiasa dicetak                              |
| `--server-name` | `CC_SERVER_NAME`       | nama hos mesin                                   | Nama yang dipaparkan dalam pemilih, penemuan dan permukaan penggandingan                                      |

## Kebolehcapaian dan TLS

| Flag                | Persekitaran                | Lalai                         | Maksud                                                                                                                                                       |
| ------------------- | --------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--tls-cert`        | `CC_SERVER_TLS_CERT`        | tidak ditetapkan              | Rantai sijil PEM. Menyajikan `wss://` dalam proses apabila ditetapkan bersama kunci                                                                          |
| `--tls-key`         | `CC_SERVER_TLS_KEY`         | tidak ditetapkan              | Kunci persendirian PEM yang sepadan dengan sijil                                                                                                             |
| `--insecure`        | `CC_SERVER_INSECURE`        | mati                          | Benarkan ikatan bukan loopback teks biasa. Hanya di belakang proksi penamat TLS pada rangkaian yang dipercayai; diabaikan apabila TLS dikonfigurasikan        |
| `--public-url`      | `CC_SERVER_PUBLIC_URL`      | diperoleh daripada ikatan     | URL RPC yang dihebahkan oleh pelayan ini kepada klien berganding. **Tetapkan ini secara eksplisit di belakang proksi, NAT atau terowong** — lalai hanyalah tekaan pada ikatan setempat |
| `--allowed-origins` | `CC_SERVER_ALLOWED_ORIGINS` | `https://app.usectrl.dev`     | Asalan penyemak imbas dipisahkan koma yang dibenarkan mendail `/rpc` merentas asalan. Loopback dan klien natif sentiasa dibenarkan                             |
| `--web-client-url`  | `CC_SERVER_WEB_CLIENT_URL`  | tidak ditetapkan              | Asalan klien web yang dihoskan yang menjadi tempat panggilan balik daftar masuk tunggal dipantulkan semula                                                   |
| `--signaling-url`   | `CC_SERVER_SIGNALING_URL`   | `wss://signaling.usectrl.dev` | Broker geganti yang disertai oleh pelayan ini supaya telefon dapat mencapainya tanpa laluan langsung                                                          |
| `--mdns`            | `CC_SERVER_MDNS`            | `auto`                        | Pengiklanan LAN: `auto` (hanya apabila diikat melebihi loopback), `on`, `off`. Penemuan hanya mengiklankan kewujudan — menyertai masih memerlukan penggandingan |
| `--tunnel`          | `CC_SERVER_TUNNEL`          | `off`                         | Penyedia terowong terurus: `off`, `cloudflared`, `ngrok`, `tailscale`. Pendedahan awam adalah pilihan masuk                                                 |
| `--tunnel-binary`   | `CC_SERVER_TUNNEL_BINARY`   | diselesaikan daripada `PATH`  | Laluan binari terowong yang eksplisit                                                                                                                        |
| `--tunnel-sha256`   | `CC_SERVER_TUNNEL_SHA256`   | tidak ditetapkan              | SHA-256 yang dijangka bagi binari itu, disahkan sebelum setiap pelahiran                                                                                     |
| `--tunnel-args`     | `CC_SERVER_TUNNEL_ARGS`     | kosong                        | Argumen tambahan dipisahkan koma untuk pemanggilan terowong                                                                                                  |

## Pengindeksan dan kelayakan pihak ketiga

| Flag                     | Persekitaran                    | Lalai                                 | Maksud                                                                                                                      |
| ------------------------ | ------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `--sandbox`              | `CC_SERVER_SANDBOX`             | `on`                                  | Sama ada larian ejen dibalut dalam kotak pasir natif OS hos apabila tersedia. Pilihan keluar, bukan pilihan masuk — lihat di bawah |
| `--code-index`           | `CC_SERVER_CODE_INDEX`          | `on`                                  | Suis mati lapangan untuk pengindeksan graf kod latar belakang. `off` but dengan bersih tanpa bina semula                    |
| `--code-index-defer`     | `CC_SERVER_CODE_INDEX_DEFER`    | `15`                                  | Saat untuk menahan sapuan indeks pertama selepas sepanduk sedia (dihadkan 0–300)                                            |
| `--tool-deferral`        | `CC_SERVER_TOOL_DEFERRAL`       | `on`                                  | Sama ada larian harness menghantar set alat residen yang kecil serta indeks nama, lalu memuatkan selebihnya pada penggunaan pertama. Lihat di bawah |
| `--credential-gate`      | `CC_SERVER_CREDENTIAL_GATE`     | `900`                                 | Saat sesuatu larian diparkirkan sambil menunggu manusia membetulkan kelayakan yang tidak dapat melayaninya (dihadkan 0–3600). Lihat di bawah |

Nilai kosong bagi sesuatu kelayakan dibaca sebagai tidak ditetapkan, jadi sandaran
terbina masih terpakai. Binaan daripada sumber tidak membawa sebarang kelayakan terbina.

Google Calendar dan pemilih GIF Klipy **hanya melalui persekitaran** — tiada
flag `--google-client-id` / `--klipy-app-key` (flag yang tidak dikenali diabaikan).
Tetapkan `GOOGLE_OAUTH_CLIENT_ID` + `GOOGLE_OAUTH_CLIENT_SECRET`, dan
`KLIPY_APP_KEY`, dalam persekitaran (atau `.env` di sebelah pelayan). Nilai kosong
menyahdayakan ciri itu dan bukan menggagalkan but.

### `--sandbox`

Pelayan menyiasat hos sekali semasa but dan membalut pelaksanaan perintah ejen dalam
kotak pasir natif OS apabila bahagian belakang tersedia: `sandbox-exec` (Seatbelt) pada macOS,
`bwrap` serta `socat` pada Linux dan WSL2. Di tempat tiada — Windows, atau hos Linux
yang kekurangan alat tersebut — larian jatuh kembali kepada sanitasi persekitaran, polisi
perintah dan guardrail tindakan, dan log permulaan menyatakan keadaan yang berkuat kuasa.

`--sandbox off` ialah suis mati lapangan bagi kes yang tidak dapat dilihat oleh
siasatan: hos tempat profil kotak pasir itu sendiri berkelakuan salah. Ia tidak
memerlukan bina semula dan pelayan merekodkan amaran sepanjang hayat proses supaya
keadaan itu tidak pernah senyap.

### `--tool-deferral`

Larian harness terbina menghantar set residen kecil takrifan alat serta indeks nama
sahaja bagi selebihnya, yang memuatkan skemanya pada kali pertama digunakan. Ia
memangkas blok alat sebanyak kira-kira 78% dan mengekalkan set yang sentiasa kelihatan
dalam julat tempat model memilih alat dengan andal. Alat yang ditangguhkan kekal
boleh dipanggil dengan nama sepanjang masa, dan `search_tools` menemuinya mengikut
niat. Lihat [Konteks alat dan caching prompt](/ms-MY/manual-pengguna/konsep/konteks-alat).

`--tool-deferral off` menjadikan setiap alat yang diterima residen semula, menghasilkan
semula permintaan yang dibuat oleh pelayan sebelum penundaan wujud. Ia ialah suis mati
bagi model yang mengendalikan permukaan dua peringkat dengan teruk — satu flag dan bukan
bina semula. Ia hanya menjejaskan harness terbina; `tools/list` MCP yang dilihat oleh
klien luaran sentiasa katalog yang lengkap.

### `--credential-gate`

Larian yang kelayakan pembekalnya hilang atau habis akan **diparkirkan** dan bukan
digagalkan: pengendali menerima gesaan untuk membetulkannya, dan larian itu bersambung
semula jika mereka berbuat demikian. Tarikh akhir lalainya ialah 900 saat (15 minit),
dihadkan kepada 0–3600.

Tarikh akhir itu sengaja jauh lebih panjang daripada tarikh akhir gesaan kelulusan:
kelulusan ialah keputusan yang dibuat seseorang dalam beberapa saat, manakala
membetulkan kelayakan bermakna membuka terminal, mendaftar masuk dan kembali semula.
Had atas itulah yang menghalang larian tanpa pengawasan — langkah pipeline, pencetus
cron, webhook — daripada menunggu seseorang yang sedang tidur. Apabila ia tamat,
larian itu gagal dengan mesej yang sama seperti jika ia digagalkan sejak awal.

`--credential-gate=0` ialah suis mati: tiada apa yang pernah diparkirkan dan kelayakan
yang buruk menamatkan giliran tepat seperti sebelum pintu ini wujud.

## Subperintah

| Perintah                                      | Apa yang dilakukannya                                                                               |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `cc_server`                                   | Menjalankan pelayan sehingga `SIGINT`/`SIGTERM`                                                     |
| `cc_server pair`                              | Menyediakan peranti dan mencetak id serta kunci penggandingannya. Selamat terhadap direktori data yang sudah disajikan oleh pelayan — pelayan yang berjalan akan mengambil peranti itu tanpa permulaan semula |
| `cc_server calendar connect --workspace <id>` | Menyambungkan akaun Google ke ruang kerja melalui aliran kod peranti, kemudian keluar               |
| `cc_server update`                            | Menyemak, memuat turun dan mengesahkan keluaran berdiri sendiri yang lebih baharu                   |
| `cc_server --version`                         | Mencetak versi binaan dan SHA git — identiti yang sama yang dihebahkan oleh `/healthz` dan jabat tangan RPC |

### `pair`

| Flag           | Lalai                                                     | Maksud                                                                                                                                                               |
| -------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--device`     | `web-client`                                              | Id peranti. Platform disimpulkan daripadanya, jadi `--device desktop` menempa baris desktop dan `--device ios`/`android` menempa baris telefon; apa-apa yang lain dianggap web |
| `--label`      | nama platform serta nama hos mesin ini                    | Nama paparan dalam senarai peranti                                                                                                                                   |
| `--host`       | `localhost`, atau `<this-host>` apabila diikat pada mana-mana antara muka | Hos untuk disematkan dalam URL yang dicetak. Tetapkannya kepada IP LAN atau hos terowong yang benar-benar akan didail oleh klien                          |
| `--client-url` | tidak ditetapkan                                          | Asalan klien **web** yang dihoskan. Menambah pautan dalam yang boleh diimbas dan QR terminal                                                                         |

`pair` juga menerima flag teras `--data-dir`, `--port` dan `--bind`: flag itu
memilih direktori data untuk ditulis dan membentuk URL pelayan yang dicetak (`ws` pada loopback,
`wss` apabila `--bind any`). Menjalankan semula `pair` untuk `--device` yang sama
memutar kuncinya dan menggugurkan sesi aktif peranti itu. Kelayakan yang ditempa di
sini **tiada tarikh luput**, tidak seperti 30 hari yang ditetapkan oleh penggandingan
dalam apl.

:::caution[QR `--client-url` bukan QR telefon]
`pair --client-url` mengisi borang sambungan klien **web** (URL pelayan,
id peranti dan kunci dalam serpihan URL). Telefon digandingkan dengan muatan
berbeza yang ditempa daripada panel penggandingan dalam apl — deskriptor sambungan
penuh pelayan serta tarikh luput. Kedua-duanya tidak boleh saling ditukar — lihat [Gandingkan peranti](/ms-MY/manual-pengguna/panduan-cara/gandingkan-peranti/).
:::

### `update`

`--apply` menggantikan pemasangan; ia ditolak selagi pelayan masih menjawab pada port
yang dikonfigurasikan melainkan anda memberikan `--force`. `--allow-downgrade` membenarkan
keluaran yang lebih lama.

Perintah itu menolak secara terus, dengan penjelasan dan bukan ralat, bagi pemasangan
yang tidak dimilikinya:

| Persekitaran                   | Dikesan oleh                                | Apa yang dikatakannya                                       |
| ------------------------------ | ------------------------------------------- | ----------------------------------------------------------- |
| Pelayan terbenam desktop       | `CC_EMBEDDED=1` atau `CC_BOOTSTRAP_DEVICE_ID` | Kemas kini apl itu sebaliknya — pemasang menukar keseluruhan pokok |
| Checkout sumber `dart run`     | laluan skrip berakhir dengan `.dart`        | Kemas kininya dengan git                                    |
| Docker                         | penanda kontena                             | Tarik imej yang lebih baharu                                |

## Kitaran hayat proses

`cc_server` berjalan sehingga `SIGINT` / `SIGTERM`. Satu pemboleh ubah persekitaran
tambahan mengawalnya, dan ia ditetapkan oleh desktop dan bukan oleh anda:

| Pemboleh ubah            | Kesan                                                                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `CC_EXIT_WITH_PARENT=1`  | Pelayan keluar apabila proses induknya keluar, dikesan oleh induk menutup hujung tulis paip stdinnya. Desktop menetapkannya supaya apl yang ranap tidak pernah meninggalkan pelayan yatim yang memegang direktori data |

Tetapkannya sendiri hanya jika anda menyelia `cc_server` sebagai proses anak dan
mahukan jaminan yang sama.

## Susun atur direktori data

Direktori data lalai ialah `~/Library/Application Support/control-center` pada macOS,
`%APPDATA%\control-center` pada Windows dan `$XDG_DATA_HOME/control-center` (jika tidak
`~/.local/share/control-center`) di tempat lain. `.cc_server` yang relatif kepada cwd hanya
digunakan apabila tiada direktori rumah atau data apl dapat diselesaikan.

| Laluan                            | Kandungan                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------- |
| `global.db`                       | Daftar ruang kerja, pengguna, peranti berganding, suapan berita dan barisan armada |
| `<workspaceId>/workspace.db`      | Satu pangkalan data bagi setiap ruang kerja — ejen, ruang, tiket, memori, graf kod |
| `<workspaceId>/chat_credentials/` | Token bot sembang, sebagai JSON biasa, supaya ia bergerak bersama ruang kerja   |
| `secrets.json`                    | Kunci penggandingan, identiti apl pembekal, token setiap pengguna dan Google, SSO (`0600`) |
| `backups/<timestamp>/`            | Satu snapshot pemasangan — `manifest.json`, `global.db` dan salinan setiap ruang kerja |
| `backups/exports/`                | Eksport satu ruang kerja, `<workspaceId>-<timestamp>.db`                         |
| `backups/transfer/`               | Kawasan persediaan untuk muat turun dan muat naik sandaran; disapu oleh laluan yang menulisnya |
| `models/`                         | Model pembenaman, diarisasi dan pertuturan pada peranti                          |
| `meetings/<meetingId>/`           | Audio mesyuarat yang disimpan                                                    |
| `rigs/images/`                    | Imej cakera stesen yang diimport (permukaan desktop QEMU)                        |
| `rigs/smolvm/<rigId>/`            | Keadaan masa jalan microVM setiap stesen (rahsia broker, `0600`)                 |
| `rigs/smolvm-packs/`              | Pek mesin yang telah diekstrak — cache yang mempercepat but stesen berulang     |
| `rigs/tls/`                       | Pihak berkuasa sijil domain dev untuk HTTPS stesen (kunci `0600`)                |
| `rigs/run/<rigId>/`               | Tindanan QEMU, imej benih dan kunci setiap VM (`0600`)                           |
