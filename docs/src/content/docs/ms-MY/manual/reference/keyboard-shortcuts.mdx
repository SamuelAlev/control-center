Pintasan datang daripada satu daftar `const`, `KeybindingRegistry` dalam `lib/core/constants/keybindings.dart`. Ia mengandungi **48 ikatan**. Tetapan → Anda → Ikatan kekunci memaparkan daftar itu sebagai **rujukan baca sahaja**: tiada UI pengikatan semula dan tiada fail ikatan kekunci pengguna.

`Cmd` di bawah ialah pengubah arahan utama — ⌘ pada macOS, Ctrl pada Windows dan Linux. Sesuatu ikatan hanya berfungsi apabila perintahnya mempunyai pengendali berdaftar pada skrin semasa dan klausa `when`-nya dipenuhi; `!textInputFocus` bermaksud kekunci itu diserahkan kepada medan teks yang difokuskan.

Tiada pintasan navigasi kekunci angka. Peti masuk, tiket, pull request dan yang lain dicapai daripada bar sisi atau ⌘K. Kebolehcerapan juga tiada pintasan.

## Global (19)

Skop `global`, jadi ia aktif di mana-mana dalam shell.

### Sistem

| Pintasan                                    | Tindakan                                         | Syarat                                                     |
| ------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| `Cmd/Ctrl + K`                              | Palet perintah                                   | —                                                          |
| `Shift + /` (`?`)                           | Helaian pintasan papan kekunci                   | Bukan sedang menaip dalam medan                           |
| `Cmd/Ctrl + Z`                              | Buat asal                                        | Bukan sedang menaip dalam medan (medan yang difokuskan menyimpan buat asal sendiri) |
| `Cmd/Ctrl + Shift + Z`                      | Buat semula                                      | Bukan sedang menaip dalam medan                           |
| `Cmd/Ctrl + Shift + T`                      | Togol tema                                       | —                                                          |
| `Cmd/Ctrl + ,`                              | Buka tetapan (berakhir pada `/settings/you/appearance`) | —                                                          |
| `Cmd/Ctrl + Shift + Alt + F`                | Togol modus fokus                                | —                                                          |
| `Cmd/Ctrl + Shift + W`                      | Togol penukar ruang kerja                        | —                                                          |
| `Cmd/Ctrl + ]`                              | Ruang kerja seterusnya                           | —                                                          |
| `Cmd/Ctrl + [`                              | Ruang kerja sebelumnya                           | —                                                          |
| `Cmd/Ctrl + Alt + 1` … `Cmd/Ctrl + Alt + 9` | Tukar ke ruang kerja 1–9                         | —                                                          |

## Senarai pull request (3)

Skop `/pull-requests`. Semuanya memerlukan `route == '/pull-requests'` dan tiada medan teks yang difokuskan, jadi ia tidak berfungsi semasa laluan butiran PR dibuka di atas senarai.

| Pintasan | Tindakan         |
| -------- | ---------------- |
| `R`      | Muat semula      |
| `Enter`  | Buka PR          |
| `F`      | Buka menu penapis |

`Enter` (`pr.list-open`) diisytiharkan dalam daftar dan muncul pada rujukan ikatan kekunci, tetapi **skrin senarai tidak mendaftarkan pengendali untuknya**, jadi ia tidak berfungsi buat masa ini. `F` membuka menu penapis (`pr.list-open-filter`), bukan carian.

## Butiran pull request (2)

Skop `/pull-requests/`. Muat semula memerlukan tiada medan teks yang difokuskan. Tutup tab tiada pengawal input teks (ketukan yang diubah suai dengan ⌘ tidak sekali-kali teks biasa) dan mempunyai regex laluan supaya ia tidak berfungsi pada senarai.

| Pintasan       | Tindakan  | Syarat                             |
| -------------- | --------- | ---------------------------------- |
| `R`            | Muat semula | Bukan sedang menaip dalam medan  |
| `Cmd/Ctrl + W` | Tutup tab | Pada lokasi `/pull-requests/<…>`   |

Pertukaran tab (`1`/`2`/`3`), fail dilihat/kuncup (`V`/`C`), senarai fail (`T`) dan cari dalam diff (`Cmd/Ctrl + F`) dimiliki oleh pengendali paparan diff sendiri — lihat [Kekunci paparan diff di luar daftar](#kekunci-paparan-diff-di-luar-daftar).

## Peti masuk (1)

| Pintasan | Tindakan         |
| -------- | ---------------- |
| `F`      | Buka menu penapis |

Memerlukan `route == '/inbox'` dan tiada medan teks yang difokuskan.

## Profil pengguna dan pasukan GitHub (3)

Skop `/users/`. Klausa `when` ialah regex terhadap `/users/<login>` **atau** `/teams/<organization>/<slug>`, serta tiada medan teks yang difokuskan.

| Pintasan       | Tindakan     |
| -------------- | ------------ |
| `R`            | Muat semula  |
| `/`            | Fokus carian |
| `Cmd/Ctrl + F` | Fokus carian |

## Ruang (8)

Skop `/spaces`. Klausa `when` menggunakan regex supaya ia berfungsi pada senarai ruang (`/spaces`) dan ruang yang dipilih (`/spaces/<id>`).

| Pintasan               | Tindakan               | Syarat                |
| ---------------------- | ---------------------- | --------------------- |
| `Enter`                | Hantar mesej           | —                     |
| `Cmd/Ctrl + N`         | Ruang baharu           | Pada laluan `/spaces` |
| `J`                    | Ruang seterusnya       | Bukan sedang menaip dalam medan |
| `K`                    | Ruang sebelumnya       | Bukan sedang menaip dalam medan |
| `Cmd/Ctrl + Shift + D` | Dikte tekan untuk bercakap | —                 |
| `Cmd/Ctrl + T`         | Buka tab editor        | Pada laluan `/spaces` |
| `Cmd/Ctrl + W`         | Tutup tab editor       | Pada laluan `/spaces` |
| `Cmd/Ctrl + B`         | Togol bar sisi editor  | Pada laluan `/spaces` |

Hantar dengan Enter dimiliki oleh medan teks komposer; tekan untuk bercakap dimiliki oleh butang mikrofon komposer (pengendali papan kekunci perkakasan tersendiri). Kedua-duanya disenaraikan dalam daftar untuk rujukan tetapan.

## Pemilih ruang kerja (2)

Skop `/workspaces`, aktif hanya pada pemilih itu sendiri.

| Pintasan       | Tindakan                |
| -------------- | ----------------------- |
| `Cmd/Ctrl + N` | Ruang kerja baharu      |
| `Enter`        | Buka ruang kerja yang dipilih |

`Enter` memerlukan tiada medan teks yang difokuskan.

## Tetapan (5)

| Pintasan       | Tindakan               | Skrin                               |
| -------------- | ---------------------- | ----------------------------------- |
| `J`            | Halaman tetapan seterusnya | Mana-mana laluan `/settings`, bukan menaip |
| `K`            | Halaman tetapan sebelumnya | Mana-mana laluan `/settings`, bukan menaip |

## Suapan berita (5)

| Pintasan | Tindakan         |
| -------- | ---------------- |
| `J`      | Artikel seterusnya |
| `K`      | Artikel sebelumnya |
| `Enter`  | Buka artikel     |
| `S`      | Togol penanda buku |
| `R`      | Muat semula suapan |

## Kekunci paparan diff di luar daftar

Paparan diff PR mengendalikannya sendiri (`PrDiffKeyboardHandler`). Carian/dilihat/kuncup disenaraikan dalam komen daftar untuk rujukan tetapan sahaja — tiada pengendali penghantar berdaftar, jadi penghantar menyerahkannya kepada paparan diff. Ia tidak muncul sebagai baris tersendiri pada rujukan ikatan kekunci.

| Pintasan        | Tindakan                                             |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Cari dalam diff                                      |
| `J` / `K`       | Fail seterusnya / sebelumnya                         |
| `V`             | Togol dilihat pada fail yang difokuskan              |
| `C`             | Togol kuncup pada fail yang difokuskan               |
| `T`             | Tunjukkan senarai fail                               |
| `Enter`         | Padanan carian seterusnya (hanya semasa cari-dalam-diff dibuka) |
| `Shift + Enter` | Padanan carian sebelumnya                            |
| `Escape`        | Tutup cari-dalam-diff, atau kosongkan pemilihan teks diff |
| `Cmd/Ctrl + C`  | Salin pemilihan diff                                 |

## Kombinasi yang ditempah penyemak imbas

Pada binaan web, penyemak imbas menggunakan sesetengah pemecut sebelum halaman melihatnya, jadi ikatan yang sepadan tidak sekali-kali boleh berfungsi di situ. Ia berfungsi seperti biasa pada desktop. Ditempah apabila digabungkan dengan pengubah arahan utama: `T`, `W`, `N` dan digit `1`–`9`.

Itu merangkumi pertukaran ruang kerja `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (ruang baharu, ruang kerja baharu, ejen baharu, tambah repositori) dan `Cmd/Ctrl + T` / `Cmd/Ctrl + W` dalam ruang dan butiran PR.
