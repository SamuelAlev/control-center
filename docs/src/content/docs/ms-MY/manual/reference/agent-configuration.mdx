Rujukan ini menyenaraikan setiap medan pada entiti ejen, beserta enum dan bendera yang digunakannya. Untuk panduan langkah demi langkah mencipta atau mengedit ejen dalam aplikasi, lihat [Cipta dan konfigurasikan ejen](/ms-MY/manual-pengguna/panduan-cara/cipta-ejen/).

## Medan entiti ejen

| Medan                   | Jenis                  | Wajib | Penerangan                                                                                                                                                                                          |
| ----------------------- | ---------------------- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Ya    | Pengecam unik ejen                                                                                                                                                                                  |
| `name`                  | `String`               | Ya    | Pengecam pendek untuk @-sebutan                                                                                                                                                                     |
| `title`                 | `String`               | Ya    | Tajuk peranan yang boleh dibaca manusia                                                                                                                                                             |
| `agentMdPath`           | `String`               | Ya    | Laluan mutlak ke fail definisi `.md` ejen                                                                                                                                                           |
| `workspaceId`           | `String`               | Ya    | Ruang kerja pemilik (bukan nol)                                                                                                                                                                     |
| `reportsTo`             | `String?`              | Tidak | Id ejen induk                                                                                                                                                                                       |
| `skills`                | `AgentSkills`          | Ya    | Set pengecam kemahiran                                                                                                                                                                              |
| `persona`               | `String?`              | Tidak | Arahan tingkah laku dalam bentuk teks bebas                                                                                                                                                         |
| `systemPrompt`          | `String?`              | Tidak | Atasi prompt sistem lalai                                                                                                                                                                           |
| `adapterId`             | `String?`              | Tidak | Id penyesuai inferens                                                                                                                                                                               |
| `modelId`               | `String?`              | Tidak | Id model dalam penyesuai itu                                                                                                                                                                        |
| `strictMode`            | `bool`                 | Tidak | Lalai `false`. Ditulis ke baris dan ke `AGENTS.md` ejen                                                                                                                                             |
| `effort`                | `String?`              | Tidak | Id tahap penaakulan (cth. `'low'`, `'xhigh'`), bersumber daripada `thinkingLevels` model yang dipilih                                                                                               |
| `contextSize`           | `int?`                 | Tidak | Saiz maksimum tetingkap konteks                                                                                                                                                                     |
| `role`                  | `AgentRole?`           | Tidak | Peranan ejen                                                                                                                                                                                        |
| `monthlyBudgetCents`    | `int`                  | Tidak | Had perbelanjaan bulanan dalam sen (lalai `0`, tanpa had)                                                                                                                                           |
| `silenceTimeoutMinutes` | `int?`                 | Tidak | Pengatasan tamat masa senyap dalam minit; mesti null atau dalam 1–240 (disahkan oleh pembina)                                                                                                       |
| `maxConcurrentTasks`    | `int`                  | Tidak | Lalai `1`. Angka kapasiti yang dilaporkan oleh model kehadiran (kiraan sedang berjalan dan beratur dibandingkan dengannya)                                                                          |
| `visibility`            | `AgentVisibility`      | Tidak | Lalai `workspace`                                                                                                                                                                                   |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Tidak | Status tadbir urus (lalai `active`). Ditulis oleh hentian keras belanjawan dan dipaparkan pada carta organisasi serta senarai kehadiran. Penghantaran masih menerima kerja daripada ejen `paused`     |
| `budgetPolicyId`        | `String?`              | Tidak | Id polisi belanjawan bersama; apabila null, `monthlyBudgetCents` terpakai secara langsung                                                                                                            |
| `runtimeProfileId`      | `String?`              | Tidak | Id profil masa jalan tersuai                                                                                                                                                                        |
| `createdAt`             | `DateTime`             | Ya    | Cap masa penciptaan                                                                                                                                                                                 |

`name` dan `title` kedua-duanya mesti tidak kosong (disahkan oleh pembina). Lalai
`monthlyBudgetCents` bernilai `0` bermakna tanpa had. Tetapkan siling dengan `agents.upsert`.

## Enum AgentLifecycleStatus

| Nilai      | Penerangan                                                                             |
| ---------- | -------------------------------------------------------------------------------------- |
| `active`   | Lalai. `isDispatchable` benar hanya untuk nilai ini                                     |
| `paused`   | Ditetapkan oleh hentian keras belanjawan. Dipaparkan pada senarai kehadiran; penghantaran masih menerima kerja |
| `archived` | Bersara dan tersembunyi daripada senarai aktif                                          |

## Kebenaran

Ejen tidak membawa bendera kebenaran. Push, membuka dan menerbitkan pull request, menulis ke penjejak dan keluar rangkaian ialah kelas tindakan (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) yang diselesaikan oleh [guardrail](/ms-MY/manual-pengguna/konsep/guardrail/) pada skop ruang kerja, ejen atau ruang. Token GitHub sesuatu larian sentiasa berskop baca; push melalui gerbang larian ejen, yang bertanya kepada peraturan `gitPush` sebelum memajukannya.

## AgentSkills

Set pengecam kemahiran yang tidak boleh diubah dan tidak sensitif huruf besar/kecil. Semasa penghantaran, slug tersebut disegerakkan sebagai pautan kemahiran dalam overlay ejen; harness kemudian memuatkan secara automatik frontmatter kemahiran yang dipautkan ke dalam prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (terbitan)

Tidak disimpan. Tujuh nilai. Susunan pengisytiharan ialah susunan keutamaan (`sortPriority`, dipakukan oleh ujian), iaitu susunan yang digunakan oleh senarai kehadiran untuk menyusun:

| Keadaan     | `sortPriority` | Syarat                                                                                                              |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Mana-mana log larian berstatus `running`                                                                            |
| `blocked`   | 1              | Keaktifan larian terbaharu ialah `blocked`, `stalled` atau `looping`                                                |
| `failed`    | 2              | Status larian terbaharu ialah `error`, atau keaktifannya `failed` atau `dead`                                       |
| `queued`    | 3              | Satu larian dihantar tetapi tidak dilaksanakan — tersekat di belakang larian lain bagi ejen yang sama, atau sudah ditulis tetapi belum dimulakan |
| `succeeded` | 4              | Larian itu selesai dengan jayanya                                                                                   |
| `idle`      | 5              | Ejen pernah berjalan sebelum ini dan tiada apa-apa yang sedang berjalan                                             |
| `neverRun`  | 6              | Tiada log larian wujud                                                                                              |

`queued` dan `succeeded` adalah **untuk setiap larian sahaja**. `deriveAgentLiveState`, yang mengira keadaan senarai bagi sesuatu ejen, tidak pernah menghasilkan kedua-duanya — ia mengembalikan `neverRun`, `running`, `failed`, `blocked` atau `idle`.
