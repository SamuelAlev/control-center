## Cangkerang aplikasi

Cangkerang aplikasi (`ControlCenterLayout`) membalut setiap laluan dalam ruang kerja melalui `ShellRoute`. **Setiap destinasi dalam cangkerang berawalan ruang kerja — `/workspaces/:workspaceId/…` — dan id ruang kerja dalam URL ialah satu-satunya sumber kebenaran bagi ruang kerja aktif.** Hanya permukaan pra-konteks yang tiada awalan: `/splash`, `/onboarding`, `/signed-out` dan pemilih `/workspaces` kosong, semuanya skrin penuh dan di luar cangkerang.

Gerbang itu lengkap apabila sekurang-kurangnya satu hos kod disambungkan **bagi pengguna yang telah daftar masuk** dan sekurang-kurangnya satu ruang kerja wujud.

Kelayakan yang hilang dan persediaan yang hilang ialah dua skrin yang berbeza, dan pembezanya ialah `users.onboarding_finished_at` yang dibaca daripada `identity.me` pemanggil itu sendiri — bukan sekali-kali "ruang kerja wujud", yang salah sebaik sahaja seseorang dijemput ke ruang kerja yang tidak pernah diciptanya. Tanpa hos kod disambungkan, akaun yang telah melalui onboarding pergi ke `/signed-out` untuk mengesahkan semula; yang belum pergi ke `/onboarding`. Selagi bendera itu masih tidak diketahui, pengawal mengekalkan skrin pemula dan bukannya meneka, kerana ia tidak pernah mengubah hala keluar semula daripada onboarding.

## Laluan tanpa awalan

| Laluan                     | Skrin                                            |
| -------------------------- | ------------------------------------------------ |
| `/splash`                  | Skrin pemula permulaan yang menyelesaikan gerbang onboarding |
| `/onboarding`              | Sambungkan hos kod, cipta atau sertai ruang kerja, kotak pasir, penyesuai lalai, kemudian suara. Langkah ruang kerja digugurkan apabila akaun itu sudah menyertai satu |
| `/signed-out`              | Daftar masuk semula: kad sambungan hos kod yang sama yang dipaparkan oleh Tetapan, tanpa bar langkah dan tanpa butang teruskan — penghala keluar dengan sendirinya sebaik sahaja hos kod melaporkan masuk |
| `/workspaces`              | Senarai dan pemilih ruang kerja                  |
| `/workspaces/:workspaceId` | Mengubah hala ke `/workspaces/:workspaceId/inbox` |

Laluan di bawah menggugurkan awalan `/workspaces/:workspaceId`.

Perbualan dan benang **tiada laluan sendiri** — benang ialah perbualan di dalam `/spaces/:spaceId`, dibuka sebagai tab editor dan bukannya dialamatkan melalui URL.

Tiada **laluan `/dashboard`** dan tiada skrin papan pemuka. Permukaan analitik ialah `/observability`, dicapai daripada pengaki bar sisi.

Tiada **item "Plans" dalam bar sisi**. Plan Studio terbuka sebagai tab editor daripada baris rancangan itu dalam perbualan yang menghasilkannya; `/plans` dan `/plans/:kind/:id` ialah pautan dalam.

`/observability` dan `/pull-requests/compose` tiada entri dalam daftar tajuk laluan atau remah roti, jadi kedua-duanya memaparkan nama apl kosong dalam tajuk tetingkap dan tiada jejak remah roti.

## Laluan tetapan

`/settings` mengubah hala ke `/settings/you/appearance`. Butang tetapan bar sisi dan `Cmd/Ctrl + ,` kedua-duanya menuju ke `/settings/you/appearance`.

Laluan tetapan menggunakan ruang nama mengikut **skop** — `you/`, `workspace/`, `server/` — kerana segmen itu menyatakan siapa yang dipengaruhi oleh sesuatu perubahan. Dua laluan wujud sebelum ruang nama itu diperkenalkan dan tidak berskop dalam URL: `/settings/memory` dan `/settings/pipelines`.

### Anda

| Laluan                        | Skrin                                                                      |
| ----------------------------- | -------------------------------------------------------------------------- |
| `/settings/you/appearance`    | Tema, bahasa, tipografi, tema editor (halaman pendaratan tetapan)          |
| `/settings/you/notifications` | Togol bagi setiap acara, waktu senyap                                      |
| `/settings/you/keybindings`   | Rujukan pintasan papan kekunci (baca sahaja)                               |
| `/settings/you/audio`         | Mikrofon, imlak, pengesanan mesyuarat dan output landskap bunyi            |
| `/settings/you/devices`       | Telefon berganding dan kawalan jauh                                        |
| `/settings/you/newsfeed`      | Pengurusan suapan: sumber, muat semula, keadaan bacaan                     |

### Ruang kerja

| Laluan                              | Skrin                                                                                               |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- |
| `/settings/workspace/profile`      | Profil dan identiti dalam ruang kerja ini: nama, pengarang git, hos kod, kalendar |
| `/settings/workspace/general`      | Nama, logo, glob rahsia, konkurensi semakan, penamaan cawangan, kesihatan segerak, jambatan sembang, zon bahaya |
| `/settings/workspace/meetings`     | Templat nota mesyuarat dan profil suara tersimpan                                                    |
| `/settings/workspace/members`      | Senarai ahli, jemputan, jejak audit. Jejak audit dipecahkan kepada halaman dengan `?cursor=` pilihan |
| `/settings/workspace/repositories` | Repositori yang didaftarkan dalam ruang kerja ini                                                    |
| `/settings/workspace/agents`       | Identiti ejen yang didaftarkan                                                                       |
| `/settings/workspace/skills`       | Konfigurasi kemahiran                                                                                |
| `/settings/memory`                 | Memori ruang kerja: fakta, polisi, graf pengetahuan                                                  |
| `/settings/workspace/permissions`  | Kebenaran ejen: matriks guardrail dan prob Bagaimana jika?                                           |
| `/settings/pipelines`              | Templat pipeline                                                                                     |
| `/settings/pipelines/:templateId`  | Editor templat pipeline (kanvas seret dan lepas)                                                     |

### Pelayan

| Laluan                          | Skrin                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| `/settings/server/connection`  | Sambungan dan status                                                                  |
| `/settings/server/sso`         | Daftar masuk tunggal (peruntukan SAML, OIDC, SCIM)                                    |
| `/settings/server/providers`   | Penyedia model dan penyesuai                                                          |
| `/settings/server/mcp`         | Pelayan MCP terbina dan luaran                                                        |
| `/settings/server/voice`       | Model suara dan mesyuarat (ASR, diarisasi)                                            |
| `/settings/server/rigs`        | Stesen: apa yang hos ini boleh but, imej asas, imej tersuai, mesin yang sedang berjalan |
| `/settings/server/sandbox`     | Geran exec kotak pasir: program yang boleh dijalankan ejen daripada salinan kerja mereka bagi repositori anda |
| `/settings/server/diagnostics` | Diagnostik dan privasi: pengotakpasiran, pembenaman, enjin segerak, pengelogan, pelaporan ranap |
| `/settings/server/backup`      | Sandaran dan pulih: snapshot pemasangan, eksport setiap ruang kerja, import dan padam  |
| `/settings/server/about`       | Perihal dan kemas kini                                                                |

`kSettingsNav` dalam `lib/features/settings/settings_nav.dart` ialah satu-satunya sumber kebenaran bagi senarai ini. `settings_nav_test.dart` memakukan id unik, laluan unik, susunan J/K yang diratakan dan ketiga-tiga skop. Ia tidak merentasi setiap `GoRoute` yang didaftarkan.
