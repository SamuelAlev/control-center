Tutorials are **lessons**. Each one takes you end to end through something real, in one
path, with no decisions to make along the way. Follow the steps exactly and they work.

They are for learning your way around. Once you know the shape of the product, the
[how-to guides](/ms-MY/manual-pengguna/panduan-cara/) are the faster route to a specific task.

Do them in this order — each one assumes the previous.

1. [Your first workspace](/ms-MY/manual-pengguna/tutorial/ruang-kerja-pertama/) — create a workspace, add a repo and see the isolation model
2. [Dispatch your first agent](/ms-MY/manual-pengguna/tutorial/ejen-pertama/) — give an agent an adapter and a model, then put it to work
3. [Review your first pull request](/ms-MY/manual-pengguna/tutorial/pr-pertama/) — read the diff, comment and merge
4. [Build your first pipeline](/ms-MY/manual-pengguna/tutorial/pipeline-pertama/) — chain steps into a DAG and run it

Two more stand alone; do either once you have a working workspace.

- [Bridge Slack to your workspace](/ms-MY/manual-pengguna/tutorial/jambatan-sembang-pertama/) — drive agents from a Slack thread
- [Sign your team in with SSO](/ms-MY/manual-pengguna/tutorial/sso/) — connect an identity provider and take a login end to end

:::note[Before you start]
Install Control Center first — see [Install](/ms-MY/manual-pengguna/pasang/). If you only want the
shortest possible path to a running agent, take the [quick start](/ms-MY/manual-pengguna/mula-pantas/)
instead and come back here afterwards.
:::
