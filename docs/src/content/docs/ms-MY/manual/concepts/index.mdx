These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/ms-MY/manual-pengguna/panduan-cara/); when you want to look
something up, go to the [reference](/ms-MY/manual-pengguna/rujukan/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/ms-MY/manual-pengguna/konsep/ruang-kerja/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/ms-MY/manual-pengguna/konsep/model-ejen/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/ms-MY/manual-pengguna/konsep/kitaran-hayat-penghantaran/) — what happens between your message and the agent's first token
- [Modes](/ms-MY/manual-pengguna/konsep/modus/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/ms-MY/manual-pengguna/konsep/konteks-alat/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/ms-MY/manual-pengguna/konsep/kepintaran-kod/) — the code graph, language server, structural search and debugger
- [Conversation history](/ms-MY/manual-pengguna/konsep/sejarah-perbualan/) — persistence, compaction and forking a transcript
