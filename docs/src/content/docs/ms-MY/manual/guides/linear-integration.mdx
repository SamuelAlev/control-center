Tampal kunci API Linear pada pelayan terhadap pengguna anda, sama seperti anda
menyambungkan hos kod. Tiket, projek, pautan, kolaborator, perwakilan dan
penugasan semuanya berfungsi terhadap pangkalan data Control Center sendiri
tanpa memerlukan perkhidmatan luar — lihat
[Cipta dan urus tiket](/ms-MY/manual-pengguna/panduan-cara/urus-tiket/).

## Simpan kunci Linear anda

**Kunci API tiket** berada di **Tetapan → Ruang kerja → Umum**, pada kad
**Tiket**. Ia menyimpan kunci itu pada pelayan terhadap id pengguna anda. Kunci
pelayan sendiri untuk kerja tanpa pengawasan datang daripada `LINEAR_API_KEY`
atau kad **Apl penyedia**. Tiada kunci penetikan diletakkan dalam kotak pasir
ejen: ejen menulis tiket melalui alat Control Center sendiri, yang bertanya
kepada peraturan **Tulis ke penjejak luaran** terlebih dahulu.

## Tandakan tiket baharu sebagai Linear

**Penyedia tiket** (langkah pertama onboarding, dan
`/workspaces/<workspaceId>/api-keys`) menawarkan `local` dan `linear`. Memilih
`linear` menandakan `provider: linear` pada tiket yang anda cipta selepas itu.
