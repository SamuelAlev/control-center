Les pages de référence décrivent **ce qui existe**, de façon exhaustive et sans
commentaire. Servez-vous-en pour retrouver un élément lorsque vous savez déjà ce que
vous cherchez : un nom d’outil exact, un type d’étape, une transition de statut, une
route, un raccourci.

Elles ne sont pas conçues pour être lues d’un bout à l’autre. Pour cela, consultez les
[concepts](/fr-CA/manuel/concepts/); pour accomplir une tâche, consultez les
[guides pratiques](/fr-CA/manuel/guides/).

## La surface du produit

- [Outils MCP](/fr-CA/manuel/reference/outils-mcp/) — chaque outil que le serveur MCP enregistre, par famille
- [Outils d’agent intégrés](/fr-CA/manuel/reference/outils-agent/) — les outils de harnais liés au serveur (LSP, AST, debug, eval, vibe)
- [Commandes slash](/fr-CA/manuel/reference/commandes-slash/) — les commandes intégrées du composeur, `/skill:` et les commandes utilisateur
- [Carte des routes](/fr-CA/manuel/reference/carte-des-routes/) — chaque écran et l’URL qui y mène
- [Raccourcis clavier](/fr-CA/manuel/reference/raccourcis-clavier/) — le registre complet des raccourcis clavier
- [Événements de domaine](/fr-CA/manuel/reference/evenements-de-domaine/) — chaque événement publié sur le bus d’événements
- [Rigs](/fr-CA/manuel/reference/rigs/) — chaque surface de rig, verbe d’action, état du cycle de vie, port et valeur par défaut
