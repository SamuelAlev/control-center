Les raccourcis proviennent d’un seul registre `const`, `KeybindingRegistry`, dans `lib/core/constants/keybindings.dart`. Il contient **48 associations**. Paramètres → Vous → Raccourcis clavier affiche ce registre sous forme de **référence en lecture seule** : il n’existe aucune interface de réassignation ni aucun fichier de raccourcis utilisateur.

`Cmd` désigne ci-dessous le modificateur de commande principal — ⌘ sous macOS, Ctrl sous Windows et Linux. Une association ne se déclenche que si sa commande possède un gestionnaire enregistré sur l’écran courant et si sa clause `when` est vraie; `!textInputFocus` signifie que la touche est plutôt transmise au champ de texte ayant le focus.

Il n’existe aucun raccourci de navigation par touches numériques. La boîte de réception, les tickets, les demandes de tirage et le reste s’atteignent depuis la barre latérale ou avec ⌘K. L’observabilité n’a pas de raccourci non plus.

## Global (19)

Portée `global` : ils sont donc actifs partout dans la coquille.

## Liste des demandes de tirage (3)

Portée `/pull-requests`. Tous exigent `route == '/pull-requests'` et l’absence de champ de texte ayant le focus, de sorte qu’ils ne se déclenchent pas lorsque la route de détail d’une PR est ouverte par-dessus la liste.

| Raccourci | Action                  |
| -------- | ----------------------- |
| `R`      | Actualiser              |
| `Enter`  | Ouvrir la PR            |
| `F`      | Ouvrir le menu de filtres |

`Enter` (`pr.list-open`) est déclaré dans le registre et figure dans la référence des raccourcis clavier, mais **l’écran de liste n’enregistre aucun gestionnaire pour cette touche**, de sorte qu’elle ne se déclenche pas actuellement. `F` ouvre le menu de filtres (`pr.list-open-filter`), et non la recherche.

## Détail d’une demande de tirage (2)

Portée `/pull-requests/`. L’actualisation exige l’absence de champ de texte ayant le focus. La fermeture d’onglet n’a aucune protection liée à la saisie de texte (une combinaison modifiée par ⌘ n’est jamais du texte brut) et s’appuie sur une expression régulière de route, de sorte qu’elle ne se déclenche pas dans la liste.

| Raccourci      | Action        | Condition                          |
| -------------- | ------------- | ---------------------------------- |
| `R`            | Actualiser    | Aucune saisie dans un champ        |
| `Cmd/Ctrl + W` | Fermer l’onglet | À un emplacement `/pull-requests/<…>` |

Le changement d’onglet (`1`/`2`/`3`), le marquage comme vu et le repli de fichiers (`V`/`C`), la liste de fichiers (`T`) et la recherche dans le diff (`Cmd/Ctrl + F`) appartiennent au gestionnaire propre à la visionneuse de diff — voir [Touches de la visionneuse de diff hors du registre](#touches-de-la-visionneuse-de-diff-hors-du-registre).

## Profils d’utilisateur et d’équipe GitHub (3)

Portée `/users/`. La clause `when` est une expression régulière appliquée à `/users/<login>` **ou** à `/teams/<organization>/<slug>`, et exige en plus l’absence de champ de texte ayant le focus.

| Raccourci      | Action                 |
| -------------- | ---------------------- |
| `R`            | Actualiser             |
| `/`            | Aller à la recherche   |
| `Cmd/Ctrl + F` | Aller à la recherche   |

## Espaces (8)

Portée `/spaces`. Les clauses `when` utilisent une expression régulière, de sorte qu’elles se déclenchent à la fois dans la liste des espaces (`/spaces`) et dans un espace sélectionné (`/spaces/<id>`).

| Raccourci              | Action                          | Condition                   |
| ---------------------- | ------------------------------- | --------------------------- |
| `Enter`                | Envoyer le message              | —                           |
| `Cmd/Ctrl + N`         | Nouvel espace                   | Sur une route `/spaces`     |
| `J`                    | Espace suivant                  | Aucune saisie dans un champ |
| `K`                    | Espace précédent                | Aucune saisie dans un champ |
| `Cmd/Ctrl + Shift + D` | Dictée : appuyer pour parler    | —                           |
| `Cmd/Ctrl + T`         | Ouvrir un onglet d’éditeur      | Sur une route `/spaces`     |
| `Cmd/Ctrl + W`         | Fermer l’onglet d’éditeur       | Sur une route `/spaces`     |
| `Cmd/Ctrl + B`         | Basculer la barre latérale de l’éditeur | Sur une route `/spaces` |

L’envoi par la touche Entrée appartient au champ de texte du composeur; l’appui pour parler appartient au bouton de microphone du composeur (son propre gestionnaire de clavier matériel). Les deux figurent dans le registre pour la référence des paramètres.

## Sélecteur d’espace de travail (2)

## Touches de la visionneuse de diff hors du registre

La visionneuse de diff des PR gère elle-même ces touches (`PrDiffKeyboardHandler`). La recherche, le marquage comme vu et le repli ne sont mentionnés que dans les commentaires du registre, à titre de référence pour les paramètres — aucun gestionnaire de répartiteur n’est enregistré, de sorte que le répartiteur les laisse à la vue de diff. Ils ne figurent pas comme lignes distinctes dans la référence des raccourcis clavier.

| Raccourci       | Action                                               |
| --------------- | ---------------------------------------------------- |
| `Cmd/Ctrl + F`  | Rechercher dans le diff                              |
| `J` / `K`       | Fichier suivant / précédent                          |
| `V`             | Basculer le marquage comme vu sur le fichier ayant le focus |
| `C`             | Basculer le repli sur le fichier ayant le focus      |
| `T`             | Afficher la liste de fichiers                        |
| `Enter`         | Correspondance de recherche suivante (uniquement pendant que la recherche dans le diff est ouverte) |
| `Shift + Enter` | Correspondance de recherche précédente               |
| `Escape`        | Fermer la recherche dans le diff ou effacer la sélection de texte du diff |
| `Cmd/Ctrl + C`  | Copier la sélection du diff                          |

## Combinaisons réservées au navigateur

Dans la version web, le navigateur consomme certains raccourcis avant que la page ne les voie, de sorte que les associations correspondantes ne peuvent jamais s’y déclencher. Elles fonctionnent normalement dans l’application de bureau. Sont réservés lorsqu’ils sont combinés au modificateur de commande principal : `T`, `W`, `N` et les chiffres `1`–`9`.

Cela couvre le changement d’espace de travail par `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (nouvel espace, nouvel espace de travail, nouvel agent, ajout d’un dépôt) ainsi que `Cmd/Ctrl + T` / `Cmd/Ctrl + W` dans les espaces et le détail d’une PR.
