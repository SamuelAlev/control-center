Ce guide vous montre comment remodeler l’application de robot côté fournisseur
sans quitter Control Center.

## Prérequis

- Le rôle `owner` ou `admin` dans l’espace de travail
- Un fournisseur **connecté**. La ligne **Personnaliser le bot** n’apparaît qu’une fois l’espace de travail connecté
- Une application que Control Center peut gérer. Pour Slack, cela veut dire que la connexion détient un jeton d’actualisation de configuration d’application (`xoxe-…`) ; sinon, la ligne l’indique et reste désactivée

## Ce que vous pouvez modifier

| Champ | Signification | Limite |
| --- | --- | --- |
| **Nom de l’app** | Comment le fournisseur liste l’application | 1–35 caractères |
| **Nom du bot (ce que l’on tape après @)** | Ce que les membres tapent après `@` | 1–80 caractères |
| **Description courte** | La ligne que le fournisseur affiche | 140 caractères ou moins |
| **Ce que le bot dit savoir faire** | Affiché au-dessus d’un message direct avec le robot | 300 caractères ou moins |
| **Commande** | La commande que les membres invoquent, sans la barre oblique | En minuscules, uniquement `a–z 0–9 _ -`, tronquée à 32 caractères |
| **Messages directs** | Si le robot offre l’expérience de messages directs et d’agent | Activé ou désactivé |

Control Center valide les quatre champs de texte avant d’appeler le fournisseur,
de sorte que vous obtenez « the app name must be between 1 and 35 characters »
plutôt qu’un `invalid_manifest` opaque venu d’un serveur que vous ne pouvez pas
voir. La commande n’est pas rejetée, mais normalisée : une barre oblique en tête
est retirée, le reste passe en minuscules, tout ce qui sort de `a–z 0–9 _ -` est
supprimé et un résultat vide retombe sur `cc`.

## Modifier le robot

1. Allez dans **Paramètres → Espace de travail → Général** et faites défiler jusqu’à la carte **Ponts de messagerie**
2. Dans le bloc du fournisseur, cliquez sur **Personnaliser le bot**
3. La boîte de dialogue s’ouvre sur les valeurs _en direct_ de l’application, relues depuis le fournisseur — vous partez donc d’une modification que quelqu’un a faite dans l’interface de Slack elle-même
4. Modifiez ce dont vous avez besoin, puis enregistrez

La lecture de ces valeurs en direct coûte une rotation de jeton du côté de Slack,
et c’est pourquoi la ligne exige un clic délibéré plutôt qu’une lecture au
chargement de la page.

L’écriture superpose vos modifications à la définition actuelle de l’application.
Tout ce que Control Center ne modélise pas — une deuxième commande slash que vous
avez ajoutée dans Slack, une étape de flux de travail, un réglage sans rapport —
survit intact. Les portées et les événements sont fusionnés, jamais soustraits.

Après l’enregistrement, Control Center relit l’identité du robot pour que le nom
dans les paramètres corresponde au nom dans l’application de clavardage.

## Réinstaller quand les permissions changent

:::caution[Réinstaller après un changement de permissions]
Slack applique immédiatement la nouvelle définition de l’application, mais
conserve l’autorisation installée telle qu’elle était. Réinstallez l’application
pour qu’un changement de permissions prenne effet. La passerelle continue de
fonctionner avec l’autorisation précédente jusqu’à ce que vous le fassiez.
:::

Quand un enregistrement change les permissions, la boîte de dialogue reste
ouverte et affiche « Slack a modifié les permissions de l’app. Réinstallez-la
pour qu’elles prennent effet », avec un bouton **Réinstaller l’app** qui ouvre la
page d’installation de cette application dans l’équipe Slack. Dans Slack, cela
correspond à **Install App → Reinstall to Workspace**.

## Renommer la commande slash

Modifiez **Commande** et enregistrez. La passerelle écrit ensuite les instructions
avec la commande utilisée lors du dernier appel, de sorte que le texte d’aide et
les instructions de liaison suivent le renommage au lieu de nommer une commande
qui n’existe plus.

Le renommage ne casse pas les fils existants de la passerelle : les fils sont
indexés par conversation, et non par commande.

## Ce que Control Center ne modifiera pas

- **Paramètres structurels.** Le transport (Socket Mode), les portées requises et les abonnements aux événements sont imposés, pas proposés. Une application qu’on peut réduire au silence depuis un écran de paramètres est un ticket de soutien, pas une fonctionnalité
- **L’icône du robot.** Seuls les réglages d’application propres au fournisseur peuvent la modifier, et la boîte de dialogue le dit
- **Les migrations de fonctionnalités propres au fournisseur.** Une application déjà sur l’ancienne forme d’assistant de Slack la conserve ; cette boîte de dialogue modifie une description, elle ne migre pas une application

## Dépannage

### Aucune ligne Personnaliser le bot n’apparaît

L’espace de travail n’est pas encore connecté. La ligne n’apparaît qu’une fois que
le bloc du fournisseur affiche une connexion active. Voir [Configurer l’intégration Slack](/fr-CA/manuel/guides/integration-slack/).

### La ligne Personnaliser le bot est désactivée

La connexion n’a aucun identifiant de gestion d’application — le sous-titre de la
ligne indique « Control Center a besoin d’un jeton de configuration d’app pour
modifier le bot. Reconnectez-vous en en fournissant un. » Pour Slack, générez une
paire de jetons de configuration d’application sur
[api.slack.com/apps](https://api.slack.com/apps) et reconnectez-vous avec le
jeton d’actualisation rempli. C’est le comportement attendu pour une application
construite à la main ou créée au moyen de **Créer dans Slack**, parce que Slack
ne signale jamais quelle application il a créée.

### « Control Center does not know which app to edit »

La connexion stockée ne porte aucun identifiant d’application — typiquement une
application connectée à la main avant qu’un identifiant ne soit enregistré.
Reconnectez l’espace de travail ou créez l’application depuis Control Center.

### Le nouveau nom du robot n’est pas encore apparu dans le clavardage

Les fournisseurs mettent brièvement en cache les métadonnées de l’application. Si
le nom est encore périmé après une minute, vérifiez si l’enregistrement vous a
demandé de réinstaller l’application.
