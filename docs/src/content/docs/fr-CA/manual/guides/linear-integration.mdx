Collez une clé API Linear sur le serveur, associée à votre utilisateur, de la
même façon que vous connectez une forge. Les tickets, les projets, les liens, les
collaborateurs, la délégation et l’attribution fonctionnent tous avec la base de
données propre à Control Center, sans qu’aucun service externe ne soit
nécessaire — consultez
[Créer et gérer des tickets](/fr-CA/manuel/guides/gerer-tickets/).

## Stocker votre clé Linear

**Clé API de ticketing** se trouve dans **Paramètres → Espace de travail →
Général**, sur la carte Tickets. Elle stocke la clé sur le serveur en
l’associant à votre identifiant utilisateur. La clé propre au serveur, destinée
au travail sans intervention, provient de `LINEAR_API_KEY` ou de la carte
**Applications fournisseur**. Aucune clé de tickets n’est placée dans le bac à
sable d’un agent : les agents écrivent les tickets via les outils de Control
Center, qui interrogent d’abord la règle **Écrire dans un outil de suivi
externe**.

## Estampiller les nouveaux tickets comme Linear

**Fournisseur de tickets** (première étape de la configuration initiale, et
`/workspaces/<workspaceId>/api-keys`) propose `local` et `linear`. Choisir
`linear` estampille `provider: linear` sur les tickets que vous créez à partir
de ce moment.
