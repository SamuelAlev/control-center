Chaque guide résout **un seul problème pour une personne qui connaît déjà bien le
produit**. Il suppose que Control Center est installé et qu’un espace de travail est
configuré, il énonce un objectif dans son titre et il s’arrête lorsque l’objectif est
atteint.

Si vous êtes encore en train d’apprendre le produit, commencez par les
[tutoriels](/fr-CA/manuel/tutoriels/). Si vous voulez comprendre _pourquoi_ quelque chose
se comporte de telle manière, consultez les [concepts](/fr-CA/manuel/concepts/).
