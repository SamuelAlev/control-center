Os atalhos vêm de um único registo `const`, `KeybindingRegistry` em `lib/core/constants/keybindings.dart`. Contém **49 associações**. Definições → Você → Atalhos de teclado apresenta esse registo como uma **referência só de leitura**: não existe interface de reatribuição nem ficheiro de atalhos do utilizador.

`Cmd` abaixo é o modificador de comando principal — ⌘ no macOS, Ctrl no Windows e no Linux. Uma associação só é acionada quando o respetivo comando tem um handler registado no ecrã atual e a sua cláusula `when` se verifica; `!textInputFocus` significa que a tecla é encaminhada para um campo de texto em foco.

Não existe nenhum atalho de navegação por teclas numéricas. A caixa de entrada, os tickets, as pull requests e o resto alcançam-se a partir da barra lateral ou com ⌘K. A Observabilidade também não tem atalho.

## Global (19)

Âmbito `global`, por isso estão ativos em qualquer ponto do shell.

## Lista de pull requests (3)

Âmbito `/pull-requests`. Todos exigem `route == '/pull-requests'` e que nenhum campo de texto esteja em foco, por isso não são acionados enquanto a rota de detalhe da PR estiver aberta sobre a lista.

| Atalho  | Ação                   |
| ------- | ---------------------- |
| `R`     | Atualizar              |
| `Enter` | Abrir PR               |
| `F`     | Abrir o menu de filtros |

`Enter` (`pr.list-open`) está declarado no registo e aparece na referência de atalhos de teclado, mas **o ecrã da lista não regista um handler para ele**, por isso atualmente não é acionado. `F` abre o menu de filtros (`pr.list-open-filter`), e não a pesquisa.

## Detalhe da pull request (2)

Âmbito `/pull-requests/`. A atualização exige que nenhum campo de texto esteja em foco. Fechar o separador não tem guarda de entrada de texto (uma combinação modificada com ⌘ nunca é texto simples) e tem uma expressão regular de rota, para não ser acionado na lista.

| Atalho         | Ação           | Condição                              |
| -------------- | -------------- | ------------------------------------- |
| `R`            | Atualizar      | Não está a escrever num campo         |
| `Cmd/Ctrl + W` | Fechar separador | Numa localização `/pull-requests/<…>` |

A mudança de separador (`1`/`2`/`3`), o marcar um ficheiro como visto e o recolher (`V`/`C`), a lista de ficheiros (`T`) e a pesquisa no diff (`Cmd/Ctrl + F`) são geridos pelo handler próprio do visualizador de diffs — consulte [Teclas do visualizador de diffs fora do registo](#teclas-do-visualizador-de-diffs-fora-do-registo).

## Perfis de utilizador e de equipa do GitHub (3)

Âmbito `/users/`. A cláusula `when` é uma expressão regular aplicada a `/users/<login>` **ou** `/teams/<organization>/<slug>`, além de exigir que nenhum campo de texto esteja em foco.

## Espaços (9)

Âmbito `/spaces`. As cláusulas `when` usam uma expressão regular, por isso são acionadas tanto na lista de espaços (`/spaces`) como num espaço selecionado (`/spaces/<id>`).

| Atalho                 | Ação                                    | Condição                   |
| ---------------------- | --------------------------------------- | -------------------------- |
| `Enter`                | Enviar mensagem                         | —                          |
| `Cmd/Ctrl + N`         | Novo espaço                             | Numa rota `/spaces`        |
| `J`                    | Espaço seguinte                         | Não está a escrever num campo |
| `K`                    | Espaço anterior                         | Não está a escrever num campo |
| `Cmd/Ctrl + Shift + D` | Ditado com premir para falar            | —                          |
| `Cmd/Ctrl + T`         | Abrir separador do editor               | Numa rota `/spaces`        |
| `Cmd/Ctrl + W`         | Fechar separador do editor              | Numa rota `/spaces`        |
| `Cmd/Ctrl + B`         | Alternar a barra lateral do editor      | Numa rota `/spaces`        |
| `Cmd/Ctrl + P`         | Ir para o ficheiro                      | Numa rota `/spaces`        |

«Ir para o ficheiro» abre um seletor com os ficheiros da conversa. Sem nada escrito, lista os ficheiros que abriu mais recentemente; ao escrever, pesquisa em todos os ficheiros das worktrees da conversa. `Enter` abre o ficheiro selecionado num novo separador, `Cmd/Ctrl + Enter` ou o botão de dividir na linha abre-o num painel à direita, e o `×` numa linha recente remove-o da lista.

O envio com Enter é gerido pelo campo de texto do compositor; o premir para falar é gerido pelo botão de microfone do compositor (o seu próprio handler de teclado físico). Ambos estão listados no registo para a referência de definições.

## Teclas do visualizador de diffs fora do registo

O visualizador de diffs das PR trata destas teclas por si próprio (`PrDiffKeyboardHandler`). Pesquisar, visto e recolher estão listados nos comentários do registo apenas para a referência de definições — não está registado nenhum handler do distribuidor, por isso o distribuidor deixa-as à vista de diff. Não aparecem como linhas próprias na referência de atalhos de teclado.

| Atalho          | Ação                                                                              |
| --------------- | --------------------------------------------------------------------------------- |
| `Cmd/Ctrl + F`  | Pesquisar no diff                                                                 |
| `J` / `K`       | Ficheiro seguinte / anterior                                                      |
| `V`             | Alternar «visto» no ficheiro em foco                                              |
| `C`             | Alternar «recolhido» no ficheiro em foco                                          |
| `T`             | Mostrar lista de ficheiros                                                        |
| `Enter`         | Ocorrência seguinte da pesquisa (apenas com a pesquisa no diff aberta)           |
| `Shift + Enter` | Ocorrência anterior da pesquisa                                                   |
| `Escape`        | Fechar a pesquisa no diff ou limpar a seleção de texto do diff                     |
| `Cmd/Ctrl + C`  | Copiar a seleção do diff                                                          |

## Combinações reservadas pelo navegador

Na versão web, o navegador consome alguns aceleradores antes de a página os ver, por isso as associações correspondentes nunca chegam a ser acionadas aí. Funcionam normalmente no computador. Ficam reservadas quando combinadas com o modificador de comando principal: `T`, `W`, `N` e os dígitos `1`–`9`.

Isso abrange a mudança de espaço de trabalho com `Cmd/Ctrl + Alt + 1`–`9`, `Cmd/Ctrl + N` (novo espaço, novo espaço de trabalho, novo agente, adicionar repositório) e `Cmd/Ctrl + T` / `Cmd/Ctrl + W` nos espaços e no detalhe da PR.
