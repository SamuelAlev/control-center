As páginas de referência descrevem **o que existe**, de forma exaustiva e sem
comentários. Utilize-as para procurar uma informação quando já sabe o que procura: o
nome exato de uma ferramenta, um tipo de passo, uma transição de estado, uma rota, um
atalho.

Não foram escritas para serem lidas do início ao fim. Para isso, consulte os
[conceitos](/pt-PT/manual/conceitos/); para realizar uma tarefa, consulte os
[guias práticos](/pt-PT/manual/guias/).

## A superfície do produto

- [Ferramentas MCP](/pt-PT/manual/referencia/ferramentas-mcp/) — todas as ferramentas que o servidor MCP regista, por família
- [Ferramentas de agente integradas](/pt-PT/manual/referencia/ferramentas-de-agente/) — ferramentas de harness ligadas ao servidor (LSP, AST, debug, eval, vibe)
- [Comandos slash](/pt-PT/manual/referencia/comandos-slash/) — comandos integrados do compositor, `/skill:` e comandos do utilizador
- [Mapa de rotas](/pt-PT/manual/referencia/mapa-de-rotas/) — todos os ecrãs e o URL que conduz a cada um
- [Atalhos de teclado](/pt-PT/manual/referencia/atalhos-de-teclado/) — o registo completo de atalhos de teclado
- [Eventos de domínio](/pt-PT/manual/referencia/eventos-de-dominio/) — todos os eventos publicados no bus de domínio
- [Rigs](/pt-PT/manual/referencia/rigs/) — todas as superfícies de rig, verbos de ação, estados do ciclo de vida, portas e predefinições
