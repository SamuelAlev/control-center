Esta referência enumera todos os campos da entidade agente, além das enumerações e dos indicadores que utiliza. Para um guia passo a passo sobre como criar ou editar um agente na aplicação, consulta [Criar e configurar um agente](/pt-PT/manual/guias/criar-agente/).

## Campos da entidade agente

| Campo                   | Tipo                   | Obrigatório | Descrição                                                                                                                                                                                          |
| ----------------------- | ---------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `String`               | Sim         | Identificador único do agente                                                                                                                                                                      |
| `name`                  | `String`               | Sim         | Identificador curto para @menções                                                                                                                                                                  |
| `title`                 | `String`               | Sim         | Cargo legível por humanos                                                                                                                                                                          |
| `agentMdPath`           | `String`               | Sim         | Caminho absoluto para o ficheiro de definição `.md` do agente                                                                                                                                      |
| `workspaceId`           | `String`               | Sim         | Espaço de trabalho proprietário (não nulo)                                                                                                                                                         |
| `reportsTo`             | `String?`              | Não         | Id do agente superior                                                                                                                                                                              |
| `skills`                | `AgentSkills`          | Sim         | Conjunto de identificadores de skills                                                                                                                                                              |
| `persona`               | `String?`              | Não         | Instruções de comportamento em texto livre                                                                                                                                                         |
| `systemPrompt`          | `String?`              | Não         | Substitui o prompt de sistema predefinido                                                                                                                                                          |
| `adapterId`             | `String?`              | Não         | Id do adaptador de inferência                                                                                                                                                                      |
| `modelId`               | `String?`              | Não         | Id do modelo dentro do adaptador                                                                                                                                                                   |
| `strictMode`            | `bool`                 | Não         | Predefinido `false`. Escrito na linha e no `AGENTS.md` do agente                                                                                                                                   |
| `effort`                | `String?`              | Não         | Id do nível de raciocínio (por exemplo, `'low'`, `'xhigh'`), obtido a partir dos `thinkingLevels` do modelo selecionado                                                                            |
| `contextSize`           | `int?`                 | Não         | Dimensão máxima da janela de contexto                                                                                                                                                              |
| `role`                  | `AgentRole?`           | Não         | Função do agente                                                                                                                                                                                   |
| `monthlyBudgetCents`    | `int`                  | Não         | Limite de gastos mensal em cêntimos (predefinido `0`, ilimitado)                                                                                                                                   |
| `silenceTimeoutMinutes` | `int?`                 | Não         | Substituição do tempo limite de silêncio em minutos; tem de ser nulo ou estar entre 1 e 240 (verificado no construtor)                                                                             |
| `maxConcurrentTasks`    | `int`                  | Não         | Predefinido `1`. Número de capacidade que o modelo de presença reporta (as contagens de execuções em curso e em fila são comparadas com ele)                                                      |
| `visibility`            | `AgentVisibility`      | Não         | Predefinido `workspace`                                                                                                                                                                            |
| `lifecycleStatus`       | `AgentLifecycleStatus` | Não         | Estado de governação (predefinido `active`). Escrito pela paragem rígida do orçamento e apresentado no organigrama e na lista de presenças. O despacho continua a aceitar trabalho de um agente `paused` |
| `budgetPolicyId`        | `String?`              | Não         | Id da política de orçamento partilhada; quando é nulo, aplica-se diretamente `monthlyBudgetCents`                                                                                                  |
| `runtimeProfileId`      | `String?`              | Não         | Id do perfil de runtime personalizado                                                                                                                                                              |
| `createdAt`             | `DateTime`             | Sim         | Data e hora de criação                                                                                                                                                                             |

`name` e `title` têm de ser ambos não vazios (verificado no construtor). Um
`monthlyBudgetCents` predefinido de `0` significa ilimitado. Define um teto com
`agents.upsert`.

## Enumeração AgentVisibility

| Valor       | Descrição                                                          |
| ----------- | ------------------------------------------------------------------ |
| `workspace` | O predefinido; valores armazenados desconhecidos e nulos são interpretados como este |
| `private`   | Privado para o utilizador que o criou                              |

## Enumeração AgentLifecycleStatus

| Valor      | Descrição                                                                                |
| ---------- | ---------------------------------------------------------------------------------------- |
| `active`   | O predefinido. `isDispatchable` é true apenas para este valor                            |
| `paused`   | Definido pela paragem rígida do orçamento. Apresentado na lista de presenças; o despacho continua a aceitar trabalho |
| `archived` | Retirado e oculto das listas de presenças ativas                                         |

## Permissões

Um agente não transporta indicadores de permissão. Fazer push, abrir e publicar pull requests, escrever num rastreador e a saída de rede são classes de ação (`gitPush`, `prCreate`, `prPublish`, `vendorSyncWrite`, `networkEgress`) que as [barreiras](/pt-PT/manual/conceitos/barreiras/) resolvem no âmbito do espaço de trabalho, do agente ou do espaço. O token do GitHub de uma execução tem sempre âmbito de leitura; os pushes passam pelo gateway de execuções de agentes, que pergunta à regra `gitPush` antes de os reencaminhar.

## AgentSkills

Um conjunto imutável e insensível a maiúsculas e minúsculas de identificadores de skills. No despacho, esses slugs são sincronizados como ligações de skills na sobreposição do agente; o harness carrega depois automaticamente o frontmatter das skills ligadas para o prompt.

```
{'flutter', 'dart', 'rest-api'}
```

## AgentLiveState (derivado)

Não é armazenado. Sete valores. A ordem de declaração é a ordem de prioridade (`sortPriority`, fixada por um teste), que é a ordem pela qual a lista ordena:

| Estado      | `sortPriority` | Condição                                                                                                             |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `running`   | 0              | Algum registo de execução tem o estado `running`                                                                     |
| `blocked`   | 1              | A vivacidade da execução mais recente é `blocked`, `stalled` ou `looping`                                            |
| `failed`    | 2              | O estado da execução mais recente é `error`, ou a sua vivacidade é `failed` ou `dead`                                |
| `queued`    | 3              | Uma execução foi despachada mas não está a ser executada — em espera atrás de outra execução do mesmo agente, ou registada mas ainda não iniciada |
| `succeeded` | 4              | A execução terminou com êxito                                                                                        |
| `idle`      | 5              | O agente já correu antes e não tem nada em curso                                                                     |
| `neverRun`  | 6              | Não existe nenhum registo de execução                                                                                |

`queued` e `succeeded` são **apenas por execução**. `deriveAgentLiveState`, que calcula o estado da lista para um agente, nunca produz nenhum deles — devolve `neverRun`, `running`, `failed`, `blocked` ou `idle`.
