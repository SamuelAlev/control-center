Cole uma chave de API do Linear no servidor, associada ao seu utilizador, da
mesma forma que liga um forge. Tickets, projetos, ligações, colaboradores,
delegação e atribuição funcionam todos sobre a própria base de dados do Control
Center, sem ser preciso nenhum serviço externo — consulte
[Criar e gerir tickets](/pt-PT/manual/guias/gerir-tickets/).

## Guardar a chave do Linear

A **Chave de API de tickets** encontra-se em **Definições → Espaço de trabalho →
Geral**, no cartão **Tickets**. Guarda a chave no servidor associada ao id do seu
utilizador. A chave do próprio servidor para trabalho sem supervisão vem de
`LINEAR_API_KEY` ou do cartão **Aplicações do fornecedor**. Nenhuma chave de
tickets é colocada na sandbox de um agente: os agentes escrevem tickets através
das ferramentas do próprio Control Center, que perguntam primeiro à regra
**Escrever num rastreador externo**.

## Marcar os novos tickets como Linear

O **Fornecedor de tickets** (o primeiro passo do onboarding e
`/workspaces/<workspaceId>/api-keys`) oferece `local` e `linear`. Escolher
`linear` marca com `provider: linear` os tickets que criar a partir daí.
