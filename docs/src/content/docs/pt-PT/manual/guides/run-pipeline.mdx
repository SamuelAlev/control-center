Este guia explica como iniciar uma execução à mão. Para acompanhar uma execução,
ler a saída dos passos e recuperar de uma falha, consulte
[Monitorizar execuções de pipeline](/pt-PT/manual/guias/monitorizar-pipelines/).

## Iniciar uma execução

1. Clique em **Pipelines** na barra lateral do espaço de trabalho.
2. Prima **Executar pipeline** no cabeçalho. Aterra no lançador
   (`/workspaces/<workspace-id>/pipelines/run`).
3. Escolha um modelo na barra lateral esquerda. Cada cartão mostra o nome do
   modelo, a sua descrição e se aceita entradas.
4. Preencha o formulário de entradas à direita. Os campos obrigatórios bloqueiam
   o botão enquanto não tiverem um valor; um modelo sem entradas indica-o.
5. Prima **Executar pipeline**.

Aterra na página de detalhe da execução, com a cascata de tempos e o canvas do
grafo em direto.

## Se a barra lateral esquerda estiver vazia

O lançador só mostra um modelo quando **as duas** condições se verificam:

- O interruptor do modelo está ativado em **Definições → Espaço de trabalho →
  Modelos de pipeline**.
- **Permitir execução manual** está ativado na caixa de diálogo **Execução
  manual** do editor do modelo — é esse interruptor que cria o gatilho `manual`
  que o lançador lê.

Oito dos treze modelos integrados vêm desativados: `external_pr_welcome`,
`cross_review`, `ticket_to_pr`, `pr_triage`, `pre_merge_gate`, `release_notes`,
`dep_audit` e `pr_digest`. O motor recusa iniciar um modelo desativado, por isso
ative o respetivo interruptor antes de o procurar aqui.

Não existe uma ação **Executar** por modelo na lista de modelos nem um botão de
execução dentro do editor — o lançador é o único ponto de entrada manual.

## Preencher uma entrada de repositório

Uma entrada do tipo **Repositório** apresenta um seletor sobre os repos
registados do espaço de trabalho. Escolher um preenche `repo_id`,
`repo_local_path`, `repo_full_name` e — quando o repo tem um remoto do GitHub —
`repo_owner` e `repo_name` no payload da execução, para que os passos a jusante
leiam o que precisarem.

## Acompanhar a execução

A página de detalhe da execução tem três partes: uma faixa de metadados (hora de
início, duração ativa, progresso dos passos, um banner de falha, **Tentar
novamente** e **Eliminar**), uma cascata de tempos recolhível com a duração e o
custo de cada passo e o canvas do grafo. Selecionar um nó abre o painel de
detalhe desse passo.

[Monitorizar execuções de pipeline](/pt-PT/manual/guias/monitorizar-pipelines/)
aborda tudo isto, incluindo como ler um passo suspenso e o que fazer quando um
falha.

Todas as execuções que iniciar a partir da aplicação são reais.
