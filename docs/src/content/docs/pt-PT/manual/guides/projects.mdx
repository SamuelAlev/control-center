Um projeto é um agrupamento de tickets com âmbito de espaço de trabalho em
torno de um objetivo comum. Os projetos são exclusivos do Control Center —
nunca são sincronizados com um fornecedor externo como o Linear.

## Criar um projeto

1. Expanda o grupo **Tickets** na barra lateral do espaço de trabalho. Este
   apresenta **Todos os tickets**, uma linha por cada projeto não arquivado e,
   por fim, **Novo projeto**.
2. Clique em **Novo projeto**.
3. Preencha o **Nome do projeto**, uma **Descrição** opcional e escolha uma
   **Cor**.
4. Prima **Criar projeto**.

É levado para a visão geral do novo projeto e o projeto aparece como uma linha
na barra lateral, sob **Tickets**.

## Adicionar tickets a um projeto

O projeto é um campo de ticket único, definido num de dois locais:

- Abra o ticket e defina **Projeto** no painel de propriedades.
- Clique com o botão direito no ticket na lista e use o submenu **Projeto**.

O seletor do painel de propriedades também oferece **Novo projeto**, para que
possa colocar um ticket num projeto que crie na hora. **Sem projeto** limpa o
campo.

Um ticket pertence a, no máximo, um projeto.

:::note[O projeto não é uma ação em massa]
A barra flutuante que aparece quando seleciona vários tickets abrange o estado,
a prioridade, o responsável, as etiquetas e a eliminação. Não tem nenhum chip
de projeto, por isso colocar muitos tickets num projeto obriga a fazê-lo um a
um.
:::

Também pode começar pelo projeto: **Novo ticket** na visão geral do projeto
cria um ticket e coloca-o aí.

## Consultar o progresso do projeto

Abra um projeto a partir da respetiva linha na barra lateral ou aceda a
`/workspaces/<workspace-id>/projects/<project-id>`.

A visão geral mostra o glifo e o nome do projeto, um distintivo de estado, a
descrição e uma barra de progresso de concluídos em relação ao total. Abaixo,
os tickets do projeto são agrupados por estado.

Não agrega mais nada — não há decomposição por responsável nem distribuição por
prioridade. Para isso, filtre antes a lista principal de tickets.

## Alterar o estado do projeto

Os projetos têm três estados:

| Estado        | Significado                     |
| ------------- | ------------------------------- |
| **Ativo**     | O trabalho está em curso        |
| **Concluído** | Todo o trabalho está concluído  |
| **Arquivado** | Referência histórica            |

Use o menu **⋯** no cabeçalho do projeto. Este oferece **Editar projeto**,
**Marcar como concluído** / **Marcar como ativo**, **Arquivar** / **Restaurar**
e **Eliminar projeto**.

Arquivar oculta o projeto da lista da barra lateral e dos seletores de tickets.
É reversível — **Restaurar** repõe o projeto como ativo —, mas, enquanto está
arquivado, o projeto só é acessível por URL.

## Projetos criados por si

Aprovar uma orquestração cria um projeto e coloca nele o ticket ascendente, a
par de tudo o que colocou manualmente. Os itens de trabalho gerados são passos
de pipeline, não linhas de ticket, pelo que não aparecem no quadro do projeto.
É o único percurso automatizado: nenhum nó de pipeline cria tickets, por isso
um pipeline não consegue preencher um projeto. Consulte
[Executar uma orquestração](/pt-PT/manual/guias/executar-orquestracao/).

:::note[Os projetos são uma superfície de operador]
Crie, liste, atualize e elimine projetos na aplicação. Os agentes não têm
ferramentas de projeto.
