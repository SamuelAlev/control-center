Cada guia resolve **um problema para quem já conhece bem** o produto. Partem do
princípio de que tem o Control Center instalado e um espaço de trabalho configurado,
enunciam um objetivo no título e terminam quando o objetivo é atingido.

Se ainda está a aprender o produto, comece pelos
[tutoriais](/pt-PT/manual/tutoriais/). Se quer perceber _porque_ algo se comporta como
se comporta, leia os [conceitos](/pt-PT/manual/conceitos/).
