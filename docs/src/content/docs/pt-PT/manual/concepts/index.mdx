These pages explain **how Control Center works and why**. They are for understanding,
not for doing: no page here is a procedure to follow. When you want to accomplish a
specific task, go to the [how-to guides](/pt-PT/manual/guias/); when you want to look
something up, go to the [reference](/pt-PT/manual/referencia/).

Read them in any order. If you are new, the core model is the place to start.

## Core model

The four ideas everything else is built on.

- [Workspaces and isolation](/pt-PT/manual/conceitos/espacos-de-trabalho/) — the tenant boundary and why it is enforced by the database layout rather than by query discipline
- [The agent model](/pt-PT/manual/conceitos/modelo-de-agentes/) — what an agent is made of: identity, role, skills, capabilities, adapter and model
- [Agent dispatch lifecycle](/pt-PT/manual/conceitos/ciclo-de-vida-do-despacho/) — what happens between your message and the agent's first token
- [Modes](/pt-PT/manual/conceitos/modos/) — how `chat`, `plan`, `review` and `orchestrate` change what an agent may do
- [Tool context and prompt caching](/pt-PT/manual/conceitos/contexto-de-ferramentas/) — why an agent sees a subset of its tools, how it reaches the rest and what keeps the provider cache warm
- [Code intelligence](/pt-PT/manual/conceitos/inteligencia-de-codigo/) — the code graph, language server, structural search and debugger
- [Conversation history](/pt-PT/manual/conceitos/historico-de-conversa/) — persistence, compaction and forking a transcript
